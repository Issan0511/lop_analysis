## 1. 問い

[[kubo_review_v4.2_0831]] §1 の提案は、吸収域を作るのは ReLU のゲートであり、**µ と $b$ はそこへの到達を駆動する 2 本のチャネル**である、という形をしている。消灯条件は 1 本しかない（[[吸収不等式の命題化_0824]] = [[命題リスト]] Q26）:

$$\hat p_i = 0 \iff \beta_i \le -\kappa_i,\qquad
\beta_i = \frac{s_i}{\sigma_i},\quad s_i = w_i\cdot\mu + b_i,\quad
\kappa_i = \frac{\lVert w_{i,\rm free}\rVert_1}{\lVert w_{i,\rm free}\rVert_2}$$

$\mu$ と $b$ は $s_i$ の 2 項として入る。**2 チャネル説が正しければ、両方を止めた系では壁への到達が止まる。** 本走はこれを介入で割る。

- **$b$ チャネルの遮断** = 隠れ層 bias にだけ weight decay を掛ける（`wd_b`。$W$・$v$・出力バイアス $c$ には掛けない）
- **$\mu$ チャネルの遮断** = 層入力の EMA 中心化（`A_layer_input_centering`、`center_alpha=0.01`、両層）

この 2 因子を直交させ、**交互作用込みで 1 走 1 spec で判定する**。

### 1.1 いまの証拠が要因計画になっていない理由（4 点）

4 セルは既に走っているが、要因計画としては使えない。

1. **別 spec・別 run・別 bootstrap seed**（`bias_wd_0901` は `20260902`、`bias_wd_std_seediso_0901` は `20260904`）
2. **seed 集合が揃っていない。** `S_main`（std × $b$ 遮断）は seed 7 が step 3,381,000 で発散し除外の n=9、centered 側は n=10。9/1 のチャットで並べた表の +9.10 は `S_sub` 側の対応集合（seed 2 除外）、+2.98 は `S_main` 側の対応集合（seed 7 除外）で、**分母の seed 集合が違う 2 つの数を同じ表に並べていた**
3. **交互作用が事前登録されていない**
4. **B02 水準がセル間で桁で違う**のに endpoint が劣化量だけになっている（「落ちる余地」の汚染。§6.1）

### 1.2 他の 2×2 と混同しない

この repo には現在 3 つの別々の 2×2 がある。**本走は (C) である。**

| | 因子 | 状態 |
|---|---|---|
| (A) 積の構造 | µ/Σ の有無 × 片道ゲートの有無 | [[中心主張v4.2草案_0830]]。**別配置の 4 セルであって要因計画ではない** |
| (B) §20 の交絡割り | µ ダイヤル × タスク可識別性ダイヤル | [[論点マップ]] §20・未走・未設計 |
| **(C) 本走** | **$b$ チャネル遮断 × µ チャネル遮断** | 事後配置が存在。**これを要因計画に変換する** |

### 2.1 ★ 事後の数字は「加法的な分解」を支持していない（9/1 の言い方の訂正）

9/1 のチャットでは「std の 9.1 dex のうち約 2/3 が $b$ 自走、約 1/3 が µ の壁」という**加法的**な言い方をした。上の表で交互作用を取ると、

- 劣化（B10−B02）: $b$ 遮断の効果は std で **−6.343**、centered で **−0.454**。**交互作用 +5.889**
- 到達水準（B10）: $b$ 遮断の効果は std で **−2.481**、centered で **−0.565**。**交互作用 +1.916**

**単独遮断の効果の和（−6.343 と −8.923）が全体（−9.377）を超えている**ので、2 チャネルは加法的ではなく**強く劣加法**である。したがって事前登録すべき仮説は「劣化量が 2 成分の和に分解できる」ではなく、**「両方を止めたときにだけ止まる（両方が必要）」という必要性の形**である。§6.2 はこの形で書く。

**「2/3 : 1/3」は主張に載せない**（§9-6）。

## 3. 設計

- condA: `m=20`, `f=15`, teacher width 100, $\beta=0.7$, $T=10{,}000$, batch 1
- learner: ReLU、hidden **`[100,100]`（4 セルとも深さ 2）**、plain SGD、`lr=0.01`、Kaiming uniform
- 5,000,000 step（= task 500）、seed 10 本、CPU、`OMP_NUM_THREADS=1`、checkpoint は step 0 / 5M
- 走の宿主は `mlp2_phase1_0829` の腕実行経路（`setup_arm_p1` / `train_arm_p1` / `forward_centered` / `exact_layer_record_p1`）。`wd_b` は `VecMLPL.set_weight_decay_b` で構築後に差し込む（乱数も状態も消費しない）
- **深さを 4 セルで揃える**のは、対応ペア比較を深さ内に閉じるため（深さをまたぐ paired 比較は禁止）。副産物として床が `1e-23` 一本で済む
- **`generator_offset = 20260905`**（D1・新規系列）。既用は `0` / `20260830` / `20260831`。**`--seeds` を変えるだけでは同一系列になる**（T0b の事故 → [[9月運用_0901]] §3-1）。seed は 0–9 の 10 本で、offset により実現が別になる

### 3.1 腕

$\lambda$ は前段の段階 A（`results/bias_wd_pilot_0901/grid_selection.json`）が凍結した主水準 **1e-3 のみ**。**本 spec では選び直さない**（§9-8）。用量副水準は置かない（本走の目的は用量反応ではなく直交化である）。

| 腕名 | 意味 | hidden | `centered_layers` | `wd_b` |
|---|---|---|---|---:|
| `none` | 無介入 | [100,100] | `[]` | 0 |
| `bwd` | $b$ チャネルのみ遮断 | [100,100] | `[]` | 1e-3 |
| `cen` | µ チャネルのみ遮断 | [100,100] | `[1,2]` | 0 |
| `both` | 両遮断 | [100,100] | `[1,2]` | 1e-3 |

更新式は $b \leftarrow b - \eta(g_b + \lambda b)$（**decoupled ではない素の L2 勾配**）。掛けるのは**両層の隠れ層 bias のみ**。分岐を置かず常に `gb + wd_b*b` を計算する（$\lambda=0$ 腕が WD 経路を通したうえで bit 一致することを検査可能にするため。§7 S1）。

見積もり: 深さ 2・5M・10 seed で 1 腕 ≈ 38 分（`bias_wd_0901` の実績）。4 腕で **約 2.5 時間**（逐次）。腕ごとの独立プロセス並列は可（軌道不変・`OMP_NUM_THREADS=1` 共通）。

### 3.2 seed 単位隔離（`spec_bias_wd_std_seediso_0901` §2 を継承）

`bwd` 腕は前段で seed 7 が step 3,381,000 で発散した実績がある。**同種の発散が再び起きる前提で設計する。**

- 1,000 step ごとの probe で seed ごとに `W1/W2/b1/b2/v/c` の有限性を見る
- 非有限 seed のみを停止・`seed_status/` に記録・**その seed の全時点を解析から除外**（発散前の部分軌道も使わない）
- 乱数対応を崩さないため隔離後も入力側の乱数消費は継続。停止 seed は lr=0 として有限ゼロへ quarantine
- **各腕 2/10 seed まで除外可。** 3 本目で腕を停止し `ARM_INVALID_EXCLUSION_LIMIT`
- **主比較は 4 腕の完走 seed の共通集合のみ**を使う。共通集合が 8 本未満なら `CONTRAST_INVALID_TOO_FEW_PAIRED` として主判定を出さない
- 補充・seed 追加・途中再開・rescue・winsorize は行わない

## 6. 事前登録判定

### 6.1 共主 endpoint 2 本

吸収・凍結のある系では総和と率の両方を出す（[[運用ルール]] §5 教訓⑰）。ここでは **劣化量と到達水準の両方**を出す。

| ID | 定義 |
|---|---|
| **E-drift** | `mean(log10 unfit)` の **B10 − B02**（劣化量） |
| **E-level** | `mean(log10 unfit)` の **B10**（到達水準） |

**主判定は E-drift で行い、E-level を必ず併記する。** 事後では 2 つの順位が入れ替わっている（劣化量では `both` が最良、到達水準では `bwd` 単独が −4.330 で最良）。この入れ替わりは B02 水準がセル間で桁違いであること（「落ちる余地」の汚染）に由来しうるので、**規則を先に固定する**:

- **S-ceiling（§7）** で B02 水準の 4 セル間最大差を測る。**3 dex を超えたら `CEILING_CONTAMINATED` フラグを立て、`summary.md` に「E-drift 単独では読まない」と明記する**
- E-drift と E-level で結論の向きが食い違ったら `LADDER_INVERTS` を立て、**どちらも単独で引かない**

### 6.2 主判定（3 条件の連言）

等価限界 **$\Delta = 0.15$ dex**（D4）。**出所を明記する**: 継承候補だった 0.10 dex は `spec_bias_wd_0901` §5.1(b) の**静的水準**用であり、劣化量に対して事前登録された値ではなかった。0.15 は既存 seed 群 0–9 における両遮断セルの E-drift の paired bootstrap CI 幅 0.112（Claude の事後計算・§2 と同じファイル）から、**判定可能域に入る最小の値として較正した**。D1 により較正元（offset 0）と本走（offset 20260905）は**別サンプル**である。Issa 指定域は 0.15–0.20 で、保守側（等価と宣言しにくい側）を採った。

CI はすべて seed 水準の paired percentile bootstrap 95%。

| 条件 | 内容 | しきい |
|---|---|---|
| **(a) 両遮断で止まる** | `both` の E-drift の 95% CI | $[-\Delta, +\Delta]$ に**収まる**（等価） |
| **(b) $b$ チャネルが実在** | `bwd − none` の対応差（E-drift）の CI **上端** | $< -\Delta$ |
| **(c) µ チャネルが実在** | (i) `bwd` の E-drift の CI **下端** $> +\Delta$ **かつ** (ii) `both − bwd` の対応差の CI **上端** $< -\Delta$ | 両方 |

**決定木（この順で評価する）**

1. **(a) が偽で、`both` の E-drift の CI 下端 $> +\Delta$** → `RESIDUAL_UNEXPLAINED` — 2 チャネルを両方止めても**劣化が残る**。到達チャネルが他にある
2. **(a) が偽で、`both` の E-drift の CI 上端 $< -\Delta$** → `OVERSHOOT_IMPROVES` — 両遮断は劣化を止めるだけでなく**改善させる**。「壁への到達を止めた」ではなく「別の何かを良くした」可能性を含むので、機構の主張には使わない
3. **(a) が偽で、CI が $\pm\Delta$ をまたぐ** → `INCONCLUSIVE_WIDE` — 判定不能。**「タイトな null」と混ぜない**（[[保持測定spec_0829]] の教訓）
4. **(a) 真・(b) 偽** → `MU_CHANNEL_ONLY` — $b$ 遮断は効かない
5. **(a) 真・(b) 真・(c) 偽** → `B_CHANNEL_ONLY` — $b$ 遮断だけで止まり、µ 側に残りがない
6. **3 条件すべて真** → `TWO_CHANNELS_BOTH_NECESSARY`

**注意**: (a) は等価判定であり、「CI が 0 を含む」ではなく「CI が $\pm\Delta$ に**収まる**」を要求する。1–3 の分岐は (a) の否定を**符号で割る**ためのもので、劣化残存（1）と過剰改善（2）を同じラベルに流さない。

### 6.3 副判定

| ID | 内容 | ラベル |
|---|---|---|
| **I（交互作用）** | `(bwd − none) − (both − cen)` の対応差（E-drift・E-level それぞれ） | CI が $\pm\Delta_{\rm int}$ 内 → `ADDITIVE` ／ CI 下端 $> +\Delta_{\rm int}$ → `SUBADDITIVE` ／ CI 上端 $< -\Delta_{\rm int}$ → `SUPERADDITIVE`。$\Delta_{\rm int} = 0.50$ dex |

**I は事前に劣加法が見込まれている**（§2.1 の事後値 +5.889）。したがって `SUBADDITIVE` が出ても**予測の確認であって独立の証拠ではない**旨を `summary.md` に明記する。

### 6.4 集計規約

- 主 endpoint は **`mean(log10 unfit)`**（seed ごとにブロック内 50 点の $\log_{10}$ を平均）。`log10(mean unfit)` も出力するが**判定には使わない**
- 床は **`1e-23`**。`mlp2_phase1_0829` の S6 較正を継承し、**本走では再較正しない**。各腕の `floor_frac` を `block_levels.csv` に出す
- CI は paired percentile bootstrap、`B = 20000`、**`bootstrap_seed = 20260906`**（既用: `20260829` / `20260902` / `20260903` / `20260904`。流用しない）
- studentized も併算し、退化検出（`degenerate_se_tol=1e-15`、`degenerate_frac_max=0.01`、`degenerate_width_ratio_max=100`）を `ci_degenerate` 列に出す。**percentile が主**
- 二値割合の CI は Clopper–Pearson

1. **§1.2 の (A)・(B) と混同しない。** 本走は「$b$ チャネル遮断 × µ チャネル遮断」であって、「µ/Σ × 片道ゲート」でも「µ ダイヤル × 可識別性ダイヤル」でもない

4. **本走は新規乱数系列（`generator_offset = 20260905`）で回すので、前段 4 セルとは別サンプルである。** 逆に言えば、前段の committed 腕との bit 一致は取れない。S0 は「実装が既存 harness と同値であること」を示すだけで、**本走の腕の正しさを保証しない**
5. **「$b$ だけの weight decay で LoP が治る」と一般に書かない。** スコープは condA・幅100・hidden `[100,100]`・$T=10^4$・batch=1・`lr=0.01`・plain SGD・5M step・$\lambda=$1e-3
6. **「2/3 : 1/3」の比を主張に載せない。** $\lambda$ 依存・床効果・E-drift/E-level の選択に依存する（§2.1）。載せてよいのは**分解の存在**であって比の数値ではない

8. **$\lambda$ を結果を見て選び直さない**
