## 0. 問い

境界窓 1000 step のうち、$b$ と $\sigma$ の降下は**いつ**起きているか。

- **B1（EMA の遅れ）** が原因なら、降下は $1/\alpha = 100$ step のスケールに乗る
- **B2（切替ショック）** が原因なら、降下は**残差の減衰時定数** $\tau_{\rm fit}$ に乗る

**この 2 つの時定数が分離していなければ、本走は原理的に判別できない。** そこで 2 段階にする。

## 1. 走の構成

`mlp2_phase1_0829` の `L1w100_A1` と**同一 config・同一 seed の再走**。介入も学習も一切変えず、**記録格子だけ**を変える。

| | 既存 | 本走 |
|---|---|---|
| 記録 | 1000 step 刻み | 1000 step 刻み（既存点を全部保存）＋ **各境界の $[-300, +300]$ を 20 step 刻み** |

記録は乱数を消費しないので、**既存点では既存ログと bit 一致するはず**。これを S0' で強制する（§4）。

### 段階1（安い・判定基準の凍結前に回す）

**seed 0 のみ・最初の 20 タスク（200,000 step）だけ**を細粒度で回し、$\tau_{\rm fit}$ を測る。

- $\tau_{\rm fit}$ := 境界後、`unfit`（または `residual_var`）が「境界直前の定常水準の $e$ 倍差」まで戻るまでの step 数の、タスク・seed 中央値
- **ゲート判定**:
  - $\tau_{\rm fit} \notin [30, 330]$（すなわち $1/\alpha = 100$ と 3 倍以上離れている） → **`TIMESCALES_SEPARABLE`**。段階2 へ進み、§3 の判定基準をそのまま凍結する
  - $\tau_{\rm fit} \in [30, 330]$ → **`TIMESCALES_NOT_SEPARABLE`**。**段階2 を回さず、[[オラクル中心化_spec_0831]] に一本化する。** 本 spec はここで失効させ `spec/失効/` へ移す

### 段階2（`TIMESCALES_SEPARABLE` のときのみ）

seed 0–9・5M・全境界で細粒度記録。

## 2. 記録する量

境界近傍の細粒度点で、ユニットごとに:

- `b_raw`（生のバイアス）、`denom`（$\sigma$）、`M`、`B`、`p_hat`
- `mu_norm`（第1層入力の残差平均のノルム。**EMA の遅れが直接見える唯一の量**）
- 集約側: `unfit`、`residual_var`、`signal_var`

`mu_norm` の境界直後のピークと減衰時定数は、B1 の**直接の署名**である。1000 step 格子では観測できなかった（境界の記録時点では既に再収束していた）。

## 3. Endpoint と判定基準（段階1 のゲート通過後に凍結・**段階2 の実行前**）

### P1 主判定 — 降下の局在

境界後の窓 $[0, 300]$ step において、$b^{\rm raw}$ の累積変化 $C(s) := b(s) - b(0)$ を取り、境界窓全体の降下 $\Delta b^{\rm bnd}_{\rm total} := b(1000) - b(0)$ に対する比

$$F_{100} := \frac{C(100)}{\Delta b^{\rm bnd}_{\rm total}},\qquad F_{300} := \frac{C(300)}{\Delta b^{\rm bnd}_{\rm total}}$$

をユニットごとに出し、seed 別中央値 → seed クラスタ bootstrap（$B=10{,}000$・percentile・seed `20260829` 継承）。

- $F_{300}$ の CI 下限 > 0.8 → **`LAG_WINDOW_LOCALIZED`**（B1 支持）
- $F_{300}$ の CI 上限 < 0.4 → **`SHOCK_SPREAD`**（B2 支持）
- それ以外 → **`INCONCLUSIVE_LOCALIZATION`**

$\Delta b^{\rm bnd}_{\rm total}$ が 0 に近いユニットで比が発散するので、**$\lvert\Delta b^{\rm bnd}_{\rm total}\rvert$ が seed 内下位 20% のユニットを除外**し、除外数を記録する（教訓⑬と同じ退化対策）。

### P2 副判定 — $\mu$ の再出現

`mu_norm` の境界後ピーク値とその減衰時定数 $\tau_\mu$。

- $\tau_\mu$ が $[50, 200]$（$\approx 1/\alpha$）に入る → **`EMA_LAG_OBSERVED`**（B1 の前提が実在することの確認）
- ピークが定常値の 2 倍未満 → **`NO_MU_REVIVAL`**（このとき B1 は前提から崩れるので、P1 が `LAG_WINDOW_LOCALIZED` を出しても B1 とは読まない）

### P3 副判定 — $\sigma$ の側

$\log\sigma$ について P1 と同じ $F_{300}$。$b$ と $\sigma$ の局在が一致するか（同じ機構か別か）を見る。REPORT_ONLY。

## 5. スコープ・引用上の注意

- condA・w100・隠れ1層・$T=10^4$・batch=1・lr=0.01・`center_alpha=0.01`・5M
- **本走は B1/B2 の「局在」を測るのであって、介入していない。** 因果の判別は [[オラクル中心化_spec_0831]] が担う。本走単独で「原因は EMA の遅れである」と書かない
