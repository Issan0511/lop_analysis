# 通常の CE・逆伝播で持続する非沈降反例（2026-10-26）

依頼: 学習が進むのに沈まない、一時的ではない反例を作り、成立条件を解析する。
既存の自己項の符号、更新を変更した介入、一歩だけの反例では完了としない。
この spec は以下の走を実行する前に commit する。探索の出発点は解析的に選んだ構成であり、ランダム発見とは呼ばない。

## 対象・指標

二値分類の普通の平均 binary cross entropy with logits。
`f(x)=sum_i v_i ReLU(w_i·x+b_i)+c`。W、b、v、c の全てを PyTorch autograd と通常の optimizer で更新する。
補助損失、勾配置換、detach、固定層、正則化、ゲート固定は使わない。全データ・ラベルは学習中固定。
主張の対象は通常学習。課題切替、ViT、繰り返しランダムラベルの沈降にそのまま移さない。

unit ごとの前活性の平均 μ、母標準偏差 σ（ddof=0）、r=μ/σ、正側率、CE、accuracy を測る。
μ と r の両方が各 step で非減少し、全 unit が実際に動き、CE が下がることを主反例の数値条件とする。
σ=0 は無効。単なる停止や readout だけの学習を反例として数えない。
永続性は有限走から推測せず、無限時刻の数学的証明で示す。

## 構成と実行前の予測

入力 x=-2,+2、ラベル 0,1。2 unit の初期値 W=(-0.75,+0.75)、b=(-0.25,-0.25)、v=(-0.5,+0.5)、c=0。
各 unit は自分が支えるクラスのみで開く。対称性は通常 GD 自体で保たれる。
active 前活性を s、readout の絶対値を u、q=1/(1+exp(us)) とすると、学習率 η の通常 GD は
`s'=s+(5η/2)u q`, `u'=u+(η/2)s q`。両者は増え、CE→0、μ→+∞、r→1/4。
この構成は最初から accuracy=1 であり、主走の学習進展は CE と margin の改善で判定する。
別の c=2 の腕は初期 accuracy=1/2 から学習させる。

非対称な 2 入力にも拡張する。拡張入力 ξ=(x,1) の Gram 行列を K とする。
各 unit の active / inactive 前活性を A>0、B<0 とし、正しいクラスを支える符号の v を持たせる。
K_ab<0、K_aa+K_ab>0、I=A K_ab-B K_aa>0 なら、通常更新でゲート・v の符号・I が保たれ、μ と r が増える。
これらは厳密な不等式なので、入力・初期パラメータの開集合で成り立つ。
この開集合では gradient flow の CE→0 を証明する。任意の一定 step 幅で CE が毎回減るとの一般化はしない。

## 数値走（float64・CPU・独立な seed は同時にベクトル化してよい）

1. 主反例: SGD η=0.05、100,000 steps。
2. 条件の境界・破壊、各 20,000 steps、SGD η=0.05:
   - 同じ初期値で c=2（初期の誤分類）。
   - 入力 ±1（K_ab=0）と ±0.5（K_ab>0）。
   - ±2 で b=1（μ は上がるが r は下がる予測。幅による r の低下と μ 沈降を区別）。
   - ±2 で v の符号を反転、|v|=0.5 / 0.75。
     gradient flow の境界 `u²-s²/5=0` の両側。前者は readout の再整列、後者は閉鎖を予測するが、有限 GD の結果は独立に報告。
   - 入力 -1.5,4.5、negative-class unit は A=1,B=-0.1 を実現する W=-1.1/6,b=0.725、positive unit は W=0.75,b=-0.25。
     negative unit は K_aa+K_ab<0、I<0。クラス純度だけでは μ/r の上昇に不十分な例。
3. 開集合の非対称性: seed 0–31、2 次元 2 入力 (-2,0),(2,0) の各座標に U[-0.1,0.1]、W=(-0.75,0),(0.75,0) の各座標に U[-0.05,0.05]、b=-0.25+U[-0.05,0.05]、|v|=0.5+U[-0.1,0.1]、c=U[-2,2]。全て 20,000 steps、SGD η=0.05。初期条件が定理の不等式を満たすかを先に検査し、失敗を隠すための seed 除外・再抽選をしない。
4. クラス内のばらつき: seed 0–7、各クラス 32 入力。正側 (linspace(1.8,2.2), U[-0.05,0.05]) とその負側、上記の初期パラメータ摂動。20,000 steps、SGD η=0.05。二点の r の定理は適用しない。ゲート純度・μ/r の実測で範囲を明記する。
5. 幅: seed 0–7、32 unit（各クラス16）、入力 ±2。W の各符号側の絶対値=0.75+U[-0.05,0.05]、b=-0.25+U[-0.05,0.05]、|v|=0.1+U[-0.02,0.02]、c=U[-2,2]。20,000 steps、SGD η=0.05。
6. optimizer 感度: 主反例で minibatch 1 の SGD η=0.05 と full-batch Adam η=0.01、各 20,000 steps。SGD の標本選択 seed=0。Adam の無限時間の保証は主張しない。

## 検算・記録

- 独立な NumPy の CE 勾配（W,b,v,c の全て）と autograd を初期・途中・末尾で照合。
- 正しいクラスへの所属を表す実ゲートを毎 step 観測。固定しない。
- 主定理の対称 GD 再帰と独立な閉形式を照合。非対称例は I の不変量・r の有限差分式も検査。
- 初期・対数間隔・末尾の状態と観測を raw に保存。全 step について単調性違反数、最小差分、ゲート変化をオンライン集計する。
- 浮動小数点の単調性違反閾値は -1e-12、勾配照合の絶対誤差上限 1e-10。ゼロや極小差分から無限時間の厳密性を主張しない。
- `verdict.csv` と `summary.md` を数値の出所とし、証明・限界・再現コマンドを保存する。
- 生データは `~/Projects/obsidian-research-data/nonsinking_ce_1026/` へ SHA-256 付きで退避し、コード・spec・結果・証明を main に統合する。
