## 0. 一行

柱3 は「`eval_loss` は $\|\boldsymbol\mu\|$ 2.33 → 3.04 の間でほぼ 0 から 0.37 へ跳ぶ」を閾値型の根拠にしている。この測定は **1M step で止まっており、区間内に点が無い**。用量を時間について厳密に一定に保った 5 点を 5M まで走らせ、**同一走の中で 1M 窓と 5M 窓の発症数を並べて**、跳びが残るか消えるか・帯の位置が動くかを見る。

## 1. 前身 spec が失効した理由（実行前監査 2026-08-30）

[[柱3遷移帯の時間依存_spec_0829]] は「既存 `mu_titration_0823` の下側 3 腕を 5M へ延ばすだけ」という設計だった。Code 側レビューと本チャットの独立検証で、以下が判明した。

**用量ダイヤルが用量ではなかった。** `center_alpha` は入力平均の EMA 更新率であり、

$$\text{running\_mean} \leftarrow (1-\alpha)\,\text{running\_mean} + \alpha\,x, \qquad \boldsymbol\mu = \mathbb E[x] - \text{running\_mean}$$

（`src/train.py:367`, `src/ratchet_log.py:91`）。したがって $\|\boldsymbol\mu\|$ は時定数 $1/\alpha$ で減衰する**過渡量**である。さらに `analysis/mu_titration/mu_titration.py:514` の bulk マスクは全区間 `(step%1000==0) & (dist>100)` で、`dose_response.csv` の `mu_norm` はその**全期間中央値**。表の 2.333 は末尾値ではない。

入力統計のみを切り出した検算（ネットワーク非依存）で、1M の committed 値を 1% 以内で再現したうえで窓別に見ると：

| 腕（旧） | 100–200k | 900k–1M | 2.4–2.5M | 4.5–5M | 末尾 dose |
|---|---:|---:|---:|---:|---:|
| `alpha_1e-6` | 2.663 | 2.067 | 1.889 | 1.870 | 7.48 |
| `alpha_3e-6` | 2.273 | 1.767 | 1.798 | 1.732 | 6.93 |
| `alpha_1e-5` | 1.550 | 1.532 | 1.497 | 1.471 | 5.88 |

**5M では 3 腕とも遷移帯 9.33–12.16 の外（下）に沈み、用量コントラストも消える。** 「時間を延ばす実験」が「用量を下げる実験」になる。

**そして構造的に、EMA 中心化では帯の中に定常状態を作れない。** $\alpha$ をどれだけ小さくしても $t \gg 1/\alpha$ で running mean は全体平均 $0.5\cdot\mathbf 1$ に収束し、残る用量は

$$\|\boldsymbol\mu\|_\infty = \sqrt{15\times 0.25} = 1.9365 \qquad (\text{dose } 7.75)$$

が上限。帯は 9.33 から始まる。**腕名や主出力を変えても解決しない設計上の欠陥**なので、改訂ではなく後継 spec を立てる。

前身 spec への他の指摘（記録点数の sanity 検査・未フィット率の再計算不能・verdict の強さ・bootstrap の推定対象）は §11 で個別に閉じる。

## 3. 設計

### 3.1 用量の固定（本走の核）

学習器入力を $x_{\rm in} = x - \gamma\cdot(0.5\cdot\mathbf 1_{20})$ とする。$k$ を現タスクの flip bit のうち 1 の個数として、

$$\|\boldsymbol\mu\|^2 = k\,(1-\gamma) + 3.75\,\gamma^2 + 1.25\,(1-\gamma)^2 = 5\gamma^2 - (k+2.5)\gamma + (k+1.25)$$

が厳密に成り立つ（数値検証 20000 例で反例 0）。目標 $M=\|\boldsymbol\mu\|$ に対して**タスク境界ごとに** $\gamma$ を解き直す：

$$\gamma(k) = \frac{(k+2.5) - \sqrt{(k+2.5)^2 - 20\,(k+1.25-M^2)}}{10}$$

小さい方の根を取る（$\gamma=0$ 側と連続）。判別式は $k=0..15$・全 5 腕で最小 34.1 と常に正なので、**全ケースで解が存在する**。

$k$ は境界でしか動かないので $\gamma$ は区分定数。**用量は走行中ずっと厳密に一定**になる。

**重要な帰結（介入の性格）**: $k$ が小さいとき $\gamma<0$ になる、すなわち平均を**足す**側に回る。発生率は下端腕で 5.9%、上端腕で 50.0%。したがって本介入は「中心化の強度」ではなく**双方向の $\boldsymbol\mu$ オフセット**である。$k$ は教師側の量なので、これは**オラクル制御**であり学習手法の候補ではない（§10）。

**情報漏洩がないことの確認**: オフセットは $\mathbf 1$ 方向のスカラー倍で、$k$ は入力の第 1–15 成分（flip bit そのもの）の決定的関数。学習器が既に見ている情報の関数なので、タスク識別性に新しい情報を足さない。

**向きの回転**: $\gamma$ は $\|\boldsymbol\mu\|$ だけでなく向きも変える。$\cos(\boldsymbol\mu, \boldsymbol\mu|_{\gamma=0})$ は全腕で中央値 0.972–0.999、5 パーセンタイル 0.945–0.982。**帯の範囲では回転は小さい**が、REPORT_ONLY で実測を出す。

$\gamma(k)$ は乱数を消費しないので、**6 腕は init・教師・入力列・flip 軌道が bit 一致するはず**。§4 の S-pair で確認し、通れば 6 腕すべて paired。

### 3.4 実装

宿主は `src/mlp2_phase1.py` の機構（層入力変換フック・深さ 1 腕 `L1w100_A1` が既存・`unfit = residual_var/signal_var` を毎記録点で保存・S6 床較正・退化ガード）。`ratchet_log.py` / `mu_titration.py` の経路は**使わない**（前身 spec の記録点数 sanity 検査の決め打ちと、未フィット率が保存されていない問題が構造的に消えるため）。

必要な新規実装は 3 点のみ：

1. `forward_centered` の層 0 の `mean` を、EMA ではなく $\gamma(k)\cdot 0.5\cdot\mathbf 1$ に差し替えるモード（タスク境界で再計算）。評価（32 パターン厳密計算）にも同じオフセットを適用する
2. 記録点で `eval_loss_exact` を追加保存（`unfit` は既存）。**両方を同時に持つ**ことで柱3 の元 endpoint との橋渡しを残す
3. step 1,000,000 での `state_hash` 保存

### 5.2 主 endpoint（D3 に従い Phase 0b と指標を揃える）

**発症 = $U_k \ge 0.05$**（Phase 0 から Phase 0b・Phase 1 へ引き継いだ閾値。変更しない）。

- **P1**: 各腕の $n_{\rm onset}(5\mathrm{M})$（0–10）
- **P2**: **同一走の中での** $n_{\rm onset}(1\mathrm{M})$（0–10）

派生量として **遷移点 $g^*$ = $n_{\rm onset}\ge 5$ となる最小 dose**（該当なしなら NA）を 1M と 5M それぞれで定義する。

**主 verdict（下端腕 `dose933` について。前身 spec の主問いを継承）**

| $n_{\rm onset}(5\mathrm{M})$ | verdict |
|---|---|
| ≥ 5 | **`ONSET_SPREADS_BY_5M`** — 帯の下端は 5M までに発症した |
| 0 | **`NO_ONSET_BY_5M`** — 5M までに発症を観測しなかった |
| 1–4 | **`PARTIAL_ONSET_BY_5M`** |

**副 verdict（帯の位置）**

| $g^*(5\mathrm{M})$ vs $g^*(1\mathrm{M})$ | verdict |
|---|---|
| $g^*(5\mathrm{M}) < g^*(1\mathrm{M})$ | **`BAND_MOVES_DOWN_BY_5M`** |
| 等しい | **`BAND_STABLE_TO_5M`** |
| $g^*(1\mathrm{M})$ が NA | **`ANCHOR_FAILED`** — 1M の絵が再現しない。結果を読まず設計側を疑う |

**verdict の強さの制限（前身 spec からの修正点）**: $n_{\rm onset}=0$ が言えるのは「5M までに発症を観測しなかった」だけである。seed 発症確率の二項モデルで 0/10 の片側 95% 上限は $0.05^{1/10}$ から $p \le 0.2589$。**「用量の閾値は本物」「無限時間でも発症しない」とは書かない。** §8 の本文更新も同じ強さに落とす。

**飽和ガード（教訓⑪・事前登録）**: $n_{\rm onset}$ が 6 腕とも 0、または 6 腕とも 10 になった場合、二値 endpoint は判別情報を持たない。そのとき判定を §5.3 の水準側（seed 中央値 $\log_{10}U$）へ落とす。**この分岐を事前に書いておく。**

### 5.3 連続の伴走量（主判定と同格で登録）

- 各腕の seed 中央値 $\log_{10}U(5\mathrm{M})$ と $\log_{10}U(1\mathrm{M})$
- seed 内対応差 $\Delta_k = \log_{10}U_k(5\mathrm{M}) - \log_{10}U_k(1\mathrm{M})$（腕ごと）
- 用量反応の跳び $J$ = 隣接腕間の $\log_{10}U$ 差の最大値。1M と 5M で並べる

### 5.4 副次（REPORT_ONLY）

`strict_dead` / `alive` / `eff_rank` / $\|w\|$ / 壁深さ $D=-\mathrm{median}_i M_i$ の時系列。実測 $\gamma(k)$ の分布と $\cos(\boldsymbol\mu,\boldsymbol\mu|_{\gamma=0})$。`eval_loss_exact` の用量反応（柱3 の元 endpoint との橋渡し）。

**`eff_rank` は「死」と「平均支配」を区別しない**（[[現在地]] 開いている穴 3）。本走でも同じ限界が掛かる。

### 5.5 CI（推定対象を明記。前身 spec からの修正点）

| 量 | 方法 |
|---|---|
| $n_{\rm onset}$（各腕） | **Clopper–Pearson の厳密二項 CI**。bootstrap は使わない（$n=10$ の計数なので） |

## 10. 引用上の注意

- **本介入はオラクル制御であって学習手法ではない。** $\gamma(k)$ は教師側の $k$ を使う。引用禁止 C の「A1（動的修復走）はオラクルであって学習手法ではない」と同じ格で扱い、「$\boldsymbol\mu$ を定数に保つ前処理を提案した」とは**書かない**
- **介入は双方向**（$k$ が小さいとき平均を足す）。「中心化の強度」とは書かない
- **用量が定数なのは本走だけ。** 既存の `mu_titration_0823` も `ratchet_log_0819` も用量は走行中に動いている。**旧走の用量点と本走の用量点を同じ軸に並べるときは、旧側が「走行中の中央値」であることを必ず併記する**
- **`eval_loss` と未フィット率を混ぜない**（教訓⑤）。本走は両方を保存するので、比較するときはどちらの量かを明示する
- **1M 窓は「同一走の中の 1M 相当位置」であって、既存 1M 走の再現ではない。** 用量の定義が違うので bit 再現は `dose_off` 腕でしか成立しない
- 深さ 1 の dose 帯と第2層の dose 帯の対応づけは**示唆であって証明ではない**（深さをまたぐ・$\Sigma$ の構造が違う）
