# 追補 1: ABAB を最初から最後まで SGD で回す（sgd_postfit_cifar_0923）

書いた: Claude, 2026-09-23 15:0x。依頼: Issa「先ほどの ABAB を最初から最後まで SGD で回したいです」。
本体 spec: `specs/spec_sgd_postfit_cifar_0923.md`（エンジンの postfit フック、trace、ce_st）。本体と同じ問い（W の伸びは Adam のせいか）の一部なので、同じブランチ・同じ results フォルダの下に置く。

## 0. 問い（Issa の仮説）

ABAB（2 つのラベルづけ A, B を交互）で、A→B で残る残渣と B→A で残る残渣は真逆のはずなので、「W は増えた分だけ減る」、つまり有界になるはず。

Adam の ABAB（altlabels_cifar_0923）で分かっていること。A 課題末と B 課題末の W を周期ごとに「中心 M_j = (W_{2j−1}+W_{2j})/2」と「半差 D_j = (W_{2j}−W_{2j−1})/2」に分けると、次のようになる（seed 0–4 の中央値）。

| 走 | 半差 ‖D‖² | 中心 ‖M‖² |
|---|---|---|
| 全長 | t5 以降 190〜200 で一定 | 1 課題あたり約 800 で伸び続ける |
| 停止チェーン（各課題を hit999+500 で打ち切る） | 約 52 で一定 | 1 課題あたり約 150 で伸び続ける |

- ラベルで決まる残渣（半差）は、仮説どおり打ち消し合っている。
- 伸びるのは、ラベルによらず毎課題足される共通分（中心）。中心の伸びの約 8 割は収束後の区間、残り 2 割は当てはめの中から来る。
- 当てはめの中の分の候補は、Adam の正規化（勾配の雑音しかない座標にも ≈ lr の一歩を打つ）。

**問い**: 当てはめも収束後も plain SGD（勾配に比例する一歩）にすると、ABAB の中心は伸びなくなるか（W は有界になるか）。

## 1. 設計

エンジンに postfit のモード **sgd_all** を足した。全課題の全更新で p ← p − η g（ミニバッチ勾配、6 テンソル全部、モーメンタムなし、WD なし）とし、Adam の m, v は 0 のまま動かさない。

| 腕 | ラベル | 最適化法 | 課題 | seed |
|---|---|---|---|---|
| **SA_abab** | ABAB（seed の rlc_labels の 1 回目と 2 回目の draw = altlabels の LR_abab と同じ A, B） | SGD η*（全更新） | 50 × 30,000 更新 | 0–9（R=10、graph） |
| **SA_iid** | IID（課題ごとに新しい draw） | SGD η*（全更新） | 50 × 30,000 更新 | 0–9 |

- 課題 1–2 は 2 腕で同じ計算になる（ABAB の A, B は IID の課題 1, 2 のラベル）。
- LR/std、batch 16、trace は 100 更新ごと（ce_st 付き）、課題末スナップショット。keep_ckpts は付けない。

## 2. η* の決め方（試走、見る前に固定）

- 格子は η ∈ {0.01, 0.03, 0.1, 0.3}。各 η で SA_abab の課題 1–4（A, B, A, B）を R=10、seed 0–9 で回す。
- **合格(η)**: 4 課題とも全 slot で次の 3 条件を満たすこと。
  1. 損失が全部有限。
  2. hit999 に 30,000 更新以内に届く。
  3. hit999 より後の全 eval で正解数 ≥ 1,188（本体の試走と同じ「落ち込み」の基準）。
- **η* = 自分とそれ以下の格子点が全部合格な、最大の格子点**。大きいほど当てはめが速いので、30,000 更新の中の収束後の区間も長く取れる。
- 分岐: どの η も 2 を満たさなければ、2 を hit99（1,188）に緩めてもう一度選び、その旨を書く。それでもだめなら本走はせず報告する。

## 3. 測るもの・判定

- **中心と半差**（SA_abab、周期 j = (2j−1, 2j)、W1 の課題末スナップショットから）: ‖M_j‖²、‖D_j‖²、中心の移動 ‖M_{j+1} − M_j‖² と、その半径成分 2⟨M_j, M_{j+1} − M_j⟩。
- **g_early**（周期 j = 2..7、課題 3–14）と **g_late**（周期 j = 14..25、課題 27–50）: ‖M_j‖² を課題の位置 x_j = 2j − 0.5 に回帰した傾きの、seed の中央値（1 課題あたり）。
- **Q9（主、Issa の仮説）**:
  - g_late ≤ 0.1·g_early かつ g_late ≤ 15/課題 → **BOUNDED**（中心の伸びが止まった）。
  - g_late ≥ 0.5·g_early → **GROWING**。
  - それ以外 → **SLOWING**。
  - 15/課題は、Adam の停止チェーンの中心の伸び（約 150/課題）の 1/10。
- **Q10**: 半差 ‖D_j‖² は j = 5..25 で有界か。傾き（seed 中央値）が、‖D‖² の平均の 1% 以下 / 課題なら BOUNDED_DIFF。
- **Q11**: SA_iid の N = ‖W1‖²（課題末）の t26–50 の傾き（seed 中央値）と、SA_abab の g_late との比。
- **Q12（記述）**: hit999 の推移（SA_abab と SA_iid）と、Adam の LR_abab・LR_iid との比較。
- 検査:
  - **C10**: sgd_all が独立な参照実装（seed ごと・eager・R=1・同じ乱数の流れ）の plain SGD と、150 更新の変位で相対誤差 < 1e−3 で一致する。変異対照（η×1.1、バイアス凍結）は失敗すること。m, v は厳密に 0。**済み（全 seed 1e−6、変異は 0.5）**。
  - **C11**: 試走の課題 1–4（η*）が本走の課題 1–4 と一致する（SA_abab）。SA_abab と SA_iid の課題 1–2 が一致する。
