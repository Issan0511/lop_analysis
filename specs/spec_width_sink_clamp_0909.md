## 0. 何を閉じるか
[[駆動源問題_0909]] §5.3「幅との結合」と §6 条件 5（「幅が増える理由」と「幅があると下向きになる理由」を分ける）。
観測（[[上端の張り付き_事後_0909]]・事後）: 素 Adam の 4 活性化で、タスク終端に折れ目 0 より上にある前活性の割合 **p⁺ = P(z>0)** が 80 タスクにわたって ±10% で保たれ（leaky 0.16・ELU 0.20・Snake 0.29・WD 入りは 0.5）、その間に平均 z̄ は 2〜3 倍沈み、幅 σ は 1.7〜2.4 倍に伸びる。
**Issa の問い: 幅が先か、沈下が先か。** 既存の [[幅と沈下の介入_結果_0909]] は一発摂動で、しかも `star_i` を厳密保存するため p⁺ を動かしていない（介入直後の frac(z̄ᵢ>0) は κ 3 水準で同値）。自然な漂流の**駆動を止める**検定は未実施。本 spec は**連続クランプ**で一方を止め、他方が続くかを見る。新規学習軌道は作るが、保存済み task20 状態からの決定的再生のみ（GPU 走なし）。

## 1. 継続と腕
開始状態 = task20 終端（`results/boundary_tasks20_40_0909/source/{ARM}_{iv}_s{seed}_states.pt` の `boundaries[0]` の `before`・`adam_before`・SNA は V）。継続は **t21..t100（80 タスク × 625 更新）**。t21 は保存 `perm`、t22 以降は `boundaries[0]['rng_after_perm']` から生成器 3 本（perm/data/batch）を生かしたまま引く。この経路は `task20to100_0908` と同一なので、無介入継続は (i) t21..40 の保存 20 状態を params・Adam・V とも差 0、(ii) t100 の `results/boundary_groups_0908/{prefix}_task100.pt` を差 0、(iii) `results/task20to100_0908/{prefix}.npz` のタスク終端 81 点（zmean・star・within）を 1e−10 で再現しなければならない。

腕: **LR/none・SNA/none × seed0..2 × 介入 3 = 18 継続**（＋seed0 の変異対照）。l2 腕は沈まない（p⁺ 0.5・0.37）ので入れない。ELU は task20 の保存状態が無いので入れない（必要なら別 spec）。

介入は**毎更新、Adam 更新の直後**に適用する。Adam の m・v・t と Snake の V には触らない（クランプは最適化器の外側）。対象は第 1 層のみ。
- **`ref`**: 無介入。参照。
- **`wclamp`（幅クランプ）**: W1 の行 i を W_i = m_i·1 + W̃_i（行平均＋中心化）と書き、更新後に **W̃_i ← W̃_i · c_i / ‖W̃_i‖**、c_i = 開始時（t20 終端）の ‖W̃_i‖。m_i・b_i・W2・W3 は触らない。行和・star_i・z̄ の置換平均は不変（κ 腕と同じ性質）。除去した半径成分 **Π_i = Σ_更新 log(‖W̃_i‖_更新後 / c_i)** を「圧力」として積算し、タスク終端で書き出す。
- **`dclamp`（深さクランプ）**: 更新後に **b ← b + δ·1**（全ユニット同じスカラー δ、double で決める）で、設定点の平均 **s̄ = (1/100) Σ_i (Σ_j W_ij·μ + b_i)**（μ = `mu_mean`）を開始時の s̄(20) に戻す。W は触らない。積算 **K = Σδ**（クランプ補正）と、学習が動かした分 **Δs̄_learned(t) = s̄_更新後クランプ前(t) − s̄(20) − K(t−1)** を記録する。恒等式 s̄(t) − s̄(20) = Δs̄_learned + K を検算。

leaky は正斉次なので `wclamp` の尺度を W2 が機能的に補償し得る。補償は止めない（W2 列ノルムを記録して報告する）。`dclamp` は関数を直接変える。両腕とも test 精度を必ず併記する。

## 3. 判定（事前登録）
seed ごとに、同 seed の `ref` との対で定義する（同じ開始状態・同じストリーム）。**窓は固定**: 「late」= **t61–100**（40 点）、「total」= t20 → t91–100 平均。3 seed とも同じラベルのときだけ付ける。CI・有意差なし。極値の選択なし。

**参照量**（各 seed、`ref`）: late 傾き **b_Z,ref** = z̄_inv を task に OLS 回帰した傾き（t61–100）、**b_S,ref** = σ_inv の同傾き、**p⁺_ref^late** = p⁺_cur の t61–100 平均。見込み（事後値）: b_Z,ref ≈ −0.013/task、b_S,ref ≈ +0.010/task、p⁺_ref^late ≈ 0.16 (LR)・0.29 (SNA)。

**A. `wclamp` — 幅を止めると沈下は止まるか**
- 後期沈下比 **R_A = b_Z,A / b_Z,ref**。3 seed とも R_A < 0.25 → `SINK_STOPS_WITH_WIDTH`；> 0.75 → `SINK_AUTONOMOUS`；他 `SINK_PARTIAL`。
  前期（t21–40）は開始時の力の残り（ラグ）で沈み得る。[[沈下の機構_事後解析_0909]] §2 の静的力は κ≈0.85 で零を横切るので、幅固定でも t20 より 0.2–0.3 深い所まで沈んでから止まる読みがある。ラグを主判定に混ぜないため後期窓を使う。total 比 R_A^total = [z̄_A(91–100) − z̄(20)] / [z̄_ref(91–100) − z̄(20)] は併記。
- 上端 **Δp_A = p⁺_A^late − p⁺_ref^late**。3 seed とも |Δp_A| < 0.03 → `EDGE_HELD`；Δp_A < −0.05 → `EDGE_DETACHES_DOWN`；他 `EDGE_PARTIAL`。（等価限界 0.03、効果限界 0.05。p⁺ の 1 点の seed 内 sd は 0.011–0.016、40 点平均なら 0.003。）
- 副（ラベル無し）: 圧力 Π（t21–100 の平均 per-unit）を ref の log(σ_inv(100)/σ_inv(20)) と並べる（圧力が続くか）。W2 列ノルムの ref 比。精度差（2 pt 超で★）。between_inv の ref 比。

**B. `dclamp` — 沈下を止めても幅は伸びるか**
- 後期幅比 **G_B = b_S,B / b_S,ref**。3 seed とも G_B > 0.75 → `WIDTH_GROWS_REGARDLESS`；< 0.25 → `WIDTH_NEEDS_SINK`；他 `WIDTH_PARTIAL`。‖W̃‖ 版の比を併記。
- 上端 **Δp_B = p⁺_B^late − p⁺_ref^late**。3 seed とも Δp_B > +0.05 → `EDGE_LIFTS`；|Δp_B| < 0.03 → `EDGE_HELD_WITHOUT_SINK`；他 `EDGE_PARTIAL`。
- 副: **K_B = K(100) / −[z̄_ref(91–100) − z̄(20)]**（深さを固定しても学習の押し下げが続くか・増幅するか。ラベル無し）。between_inv の ref 比。精度差（2 pt 超で★）。

**組み合わせの読み**（結果を見る前に固定）
| A | B | 読み |
|---|---|---|
| `SINK_STOPS_WITH_WIDTH` + `EDGE_HELD` | `WIDTH_GROWS_REGARDLESS` + `EDGE_LIFTS` | **幅が先。** 沈下は幅への追随で、張り付きはその帰結。駆動源問題は「幅があるとなぜ下向きか」に還元 |
| `SINK_AUTONOMOUS` + `EDGE_DETACHES_DOWN` | `WIDTH_NEEDS_SINK` | **沈下が先。** 幅は沈下の結果。張り付きは「沈んだ分だけ伸びる」 |
| `SINK_AUTONOMOUS` + `EDGE_DETACHES_DOWN` | `WIDTH_GROWS_REGARDLESS` + `EDGE_LIFTS` | **独立な二過程。** 張り付きは同じ時間則の偶然の同期で、p⁺ 一定は法則ではない |
| `SINK_STOPS_WITH_WIDTH` | `WIDTH_NEEDS_SINK` | 双方向の拘束。どちらが先とは言えない |
| — | `EDGE_HELD_WITHOUT_SINK` | 深さを固定しても占有率が保たれる ＝ 占有率の調節は W̃ の向き（整列）で速く、深さの漂流は別の遅い過程（[[上端の張り付き_事後_0909]] §3 の「1 タスクで揃う」と整合）。この場合 p⁺ は深さの制御変数ではなく、A の判定だけが残る |
| `SINK_PARTIAL` / `WIDTH_PARTIAL` | — | 3 seed の R_A・G_B を連続量として報告し、ラベルは付けない |

**進捗ゲート G1**: `ref` が §1 の (i)(ii)(iii) をすべて満たす。1 つでも外れたら全腕無効で停止。
**G2（クランプの実効性）**: `wclamp` は毎更新後 |‖W̃_i‖ − c_i| / c_i ≤ 1e−6（float32）を全ユニット・全更新で満たす（硬い検査。破れたら停止）。σ_inv が t21–100 で開始値の **±15%** を超えたら判定に★（‖W̃‖ の固定が前活性幅の固定になっていない旨を報告。ref は t40 で +37%）。`dclamp` は毎更新後 |s̄ − s̄(20)| ≤ 1e−6（double、硬い検査）。

## 4. 事前予測（記名）
- **Claude**: A = `SINK_STOPS_WITH_WIDTH` ＋ `EDGE_HELD`；B = `WIDTH_GROWS_REGARDLESS`（G_B ≥ 1。負側ゲートが開くぶん堆積が増えて加速する側）＋ `EDGE_LIFTS`。組み合わせは第 1 行「幅が先」。副で K_B > 1（深さを固定すると押し下げは増幅）。根拠: κ0.7 で深さが 5–10 タスクで上向きに応答したこと（幅より深い状態から戻る力がある）、静的力が κ≈0.85 で零を横切る復元型であること、直交堆積が新タスク由来で深さに依らないこと。**最も弱いのは B の `EDGE_LIFTS`**: 占有率は W̃ の整列でも 1 タスクで調節されるので `EDGE_HELD_WITHOUT_SINK` に落ちる可能性がある。その場合でも A の判定は独立に立つ。
- **Issa**: 追補で登録する（結果を読む前）。仮説「幅が先」がそのまま第 1 行なら両者一致で、走は確証走。分岐するなら B の `EDGE` か A の `PARTIAL` の見込み。
- 通算: Issa 8.5/9、Claude 2.5/9。重みは Issa 側。
- 反証の形: `wclamp` で後期も ref の 3/4 以上の速さで沈めば Claude 外れ（沈下は幅に依らない）。`dclamp` で幅の伸びが 1/4 以下に落ちれば「幅→深さの一方向」が外れる。

## 5. 検算と変異対照
すべての検査に変異対照を付け、対照が実際に検査を落とすことをアサートする（空虚な S 検査を 6 回作った履歴があるため）。
1. **G1 (i)(ii)(iii)** の厳密再現。対照: 開始状態の W1[0,0] に +1e−3 → t21 終端で maxabs > 1e−4。
2. **生成器の継続**: t22..40 で引いた perm が保存 `boundaries[j]['perm']` と exact 一致。対照: perm 生成器を 1 回余分に進めると不一致。
3. **`wclamp` 恒等式**: 毎更新後 |‖W̃_i‖ − c_i|/c_i ≤ 1e−6；クランプ前後で行平均 m_i と b_i は差 0；W2・W3 は差 0。対照: 1 更新だけクランプを飛ばすと ‖W̃_i‖ が c_i から > 1e−5 外れる（float32 で検出可能な最小の更新幅は 1e−3 級）。
4. **`dclamp` 恒等式**: 毎更新後 |s̄ − s̄(20)| ≤ 1e−6；W1 はクランプ前後で差 0；b の変化はスカラー（max − min = 0）；帳簿 s̄(t) − s̄(20) = Δs̄_learned + K が ≤ 1e−9。対照: δ を 0.99δ にすると t21 終端で |s̄ − s̄(20)| > 1e−4。
5. **測定の非侵襲**: `ref` は測定込みで G1 を通す。対照: 測定側で W1 に +1e−9（LR）／act.update（SNA）を入れると G1 (i) が落ちる。
6. **G2 の対照は `ref` 自身**（σ_inv +37%/t40、s̄ の漂流 −0.8/t40）。
失敗は隠さず停止する。

## 6. 集計・保存・運用
seed 内は時系列（80 タスク × 3 phase）、seed 間は 3 本並記。ラベルは 3/3 一致のみ。加法恒等式（帳簿）は seed 単位で検算。
CPU 1 thread・最大 2 process（並列数をコア数に合わせない）。1 継続 **400 秒上限**（`task20to100_0908` の実測は 80 タスクで ≈ 30 秒＋測定。クランプの追加コストは行ノルム 100 本／更新で無視できる）。全体 ≈ 20–40 分。
**3 commit 構成**: spec 単独 commit → 実装 commit → 結果 commit。CSV・verdict・summary・図を commit、ユニット別 npz は SHA 照合付きで `obsidian-research-data/width_sink_clamp_0909` へ。既存 run の出力は上書きしない。
**限界**: 開始状態は t20 の一系列（CPU 再生）。クランプは関数保存でない（`wclamp` は leaky でも W2 の補償を要し、`dclamp` は関数を直接変える）。`wclamp` が固定するのは ‖W̃_i‖（重み空間）であって σ_inv,i そのものではない（G2 で ±15% を要求）。ユニット単位の結合は検定しない（集団の主張）。`wclamp` の毎更新射影は Nero 型の制約付き Adam と同型（[[文献照合_W増大メカニズム_0909]] §6）で、その意味で「WD 以外の幅規制」の陽性対照を兼ねる。leaky では折れ目シフト ≡ bias シフトなので「折れ目を動かす」腕は設けない（[[上端の張り付き_事後_0909]] §4）。

## Log — Claude が裁定した未決（Issa 未確認・結果を読む前に変えてよい）
1. `dclamp` は**集団平均** s̄ を固定する（ユニット別 star_i の固定ではない）。集団の主張に合わせた最小介入。ユニット間の広がりは自由で、between_inv を副測定に置いた。
2. `wclamp` は**ユニット別**ノルム c_i を固定する（全行共通のスカラーではない）。κ 腕と同じ「行ごとの幅」の定義に合わせた。
3. 地平線は **80 タスク（t21–100）**。20 タスクでは後期窓が取れない。参照は既存の `task20to100_0908` と `task100.pt` で bit 一致が取れる。
4. 腕は LR/none・SNA/none のみ。l2 は沈まない、ELU は task20 の保存状態が無い。
5. p⁺ の主判定は**現 perm**。inv は併記。
6. 後期窓は **t61–100 の OLS 傾き**（単点差は 1 タスクのジッタ ±0.1 で 0.25 閾値が割れない）。
7. 占有率クランプ（p⁺ を b で固定する腕）は**設けない**: 自然軌道が既に p⁺ 一定なので、クランプは偏差にしか働かず `ref` と区別できない。
