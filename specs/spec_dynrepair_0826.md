## 1. 何を一度に測るのか（そして、何が独立していないのか）

4 つの目的を 1 本の走に束ねる。ただし**独立な 4 つではない**。先に依存関係を明示しておく。

| # | 目的 | 判定ID | 独立性 |
|---|---|---|---|
| 1 | **O 畳み判定** — 蹴り上げ後に `eval_loss` が実際に改善するか。ゼロなら [[機能盲目性_0823]] §3 の O を畳む | **O-1** | — |
| 2 | **condA CBP との裁定** — 便益は「スイッチを開ける」ことから来るのか、「W を取り替える」ことから来るのか | **C-1** | O-1 と別の量（アーム間差） |
| 3 | **ΔL 因果の半歩** — 作業6 の観察的 PROTECTIVE が、介入で作り直した母集団でも再現するか | **F-1** | O-1 と別の母集団（復活ユニット内） |
| 4 | **合唱団予言** — 復活ユニットは再凍結し、`dead_frac` は介入前水準へ戻る | **Ch-1** | **O-1 とほぼ同じ石**（下記） |

**O-1 と Ch-1 は独立でない。** 「歌い手が足りていないのではなく、合唱団は既に歌い切っている」が正しいなら、復活ユニットには稼ぐ残差がなく、`eval_loss` は改善せず（O-1 = FOLD）、稼がないので保護もされず再凍結する（Ch-1 = PASS）。逆も同様。したがって**一石四鳥ではなく、実質は「二石＋二確認」**である。§7.5 に 2×2 の解釈表を先に凍結し、独立な 4 票のように扱わない。

## 2. 起点と前提（既記の引用）

- 静的 O（[[機能盲目性_0823]] §3、`results/function_blind_0823/`）: seed 平均 NMSE **0.143367 → 0.009148**、回復率 **93.619% [89.706%, 97.672%]**。W・v を固定し、`dead_0.05` の bias を最良入力で preactivation 0.5 になる位置へ蹴り上げてから、全 hidden bias と出力 offset `c` のみを最適化した**オラクル**である
- 作業6（[[直接機能量による選抜確認_0823]]）: `ΔL` high−low の調整 RD **−0.2353 [−0.2812, −0.2325]**、凍結率 low/high = **0.4018 / 0.1668**、判定 **PROTECTIVE**。ただし**観察的**
- CBP（[[論点マップ]] §8、`cbp_harm_0815`）: reset は残差の有無に関わらない固定コスト、便益は実容量損失に比例、**`dead_frac` は治療の要否を決めない**（+0.349 [+0.216, +0.503]）。アンカーとして「条件 A では CBP 有効のまま（dead 0.968→0.034、eval 0.937→0.005）」が記録されている。**この 2 数値は本 spec の判定には使わない**（走の設定・幅・seed 数を本 note では確認していない。§9 S7 で同一土俵に載せ直す）
- 一過性の前例（[[論点マップ]] §2、`rank_int_0814`）: **状態への介入は場に再輸送され、~100k step で再崩壊**した。本走はその構図が bias 経路でも起きるかを見る
- `dead_frac_0.05` の実測水準は 0.87–0.99（[[停止条件]]）
- **起点スナップショットの実測構成（0826 に確認）**: 各 seed で `dead_0.05` が **76–98 個**、alive は **2–24 個**。この非対称が A3 の設計を規定する（§3.2.1・§13）

**用語**（作業1 の裁定に従う）:

- `strict_dead := p̂ = 0`（凍結）／`near_off := 0 < p̂ < 0.05`／`dead_0.05 := p̂ < 0.05`（旧互換）
- **復活 := p̂ > 0**、**実用復活 := p̂ ≥ 0.05**。蹴り上げ対象は `dead_0.05` なので `near_off` を含む。**「復活した」を `p̂ ≥ 1/32` で数えない**（1 パターンだけ開いた個体を復活と呼ぶことになる）
- **再凍結 := 介入後に一度 `p̂ > 0` になった個体が、再び `p̂ = 0` に入ること**

#### 3.2.1 A3 の定義（0826 改訂・実行可能形）

初版は「A1 と同数の alive ユニット」を要求していたが、**実スナップショットでは alive が 2–24 個しかなく、`dead_0.05` の 76–98 個と重複なしで同数を取れない**（§13）。以下を登録形とする。

- 対象: **その seed の全 alive ユニット**（`p̂ ≥ 0.05`）
- 摂動: `Δb_i = ε_i · c_s`、`ε_i ∈ {+1, −1}` を等確率・独立に引く（`placebo_seed = 20260826`、**事前固定**）
- 符号の割当順: seed 昇順、その seed 内では unit index 昇順。`placebo_seed` から作る **CPU NumPy `Generator(PCG64)`** の単一ストリームをこの順に消費する。学習用 torch generator は消費しない
- 大きさ: `c_s` は **`‖Δb^A3‖₂ = κ_s`** となるよう seed ごとに決める。`c_s = κ_s / √(n_alive,s)`
- **`κ_s` の定義（曖昧さを潰す）**: `κ_s := ‖b^A1 − b^A0‖₂`、すなわち**介入直後の全 hidden bias の総変位**（蹴り上げ成分 ＋ オラクル最適化成分、100 成分すべて）。**蹴り上げ成分のみではない**。A1 のオラクル最適化は alive の bias も動かすので、総変位で揃えないと「同じだけ動かした」にならない
- `c` と `v`、`W` は触らない

**この設計が何を統制し、何を統制しないか（判定前に固定）**

- 統制する: 「**bias 空間で同じ大きさだけ動かせば、方向に関係なく学習が再開する**」という説明
- 統制しない: 「同じ**ユニット数**を触る」「同じ **per-unit の大きさ**で触る」。alive が痩せているため、**A3 の per-unit 変位は A1 の per-unit 変位より 2–7 倍大きくなる**（`√(n_dead/n_alive)` 倍）
- したがって **A3 は無害なプラセボではなく、破壊寄りの対照になりうる**。alive の margin 中央値は +1.0758（[[論点マップ]] 8/22 節）なので、`c_s` がこれを超える seed では**プラセボ自体が生存者を殺す**
- **読み方の制約（先に凍結）**: A3 で `U` が悪化しても、それを「摂動は無効」の証拠として引かない。S5-A3 の実測（§9）で **A3 起因の致死が 0 に近い seed に限って**、A3 は「同大の無方向摂動では改善しない」の対照として使える。致死が出た seed では **A3 は破壊対照**であり、その読みだけを書く
- **`n_alive,s` と `c_s` は seed ごとに 3.5 倍程度ばらつく**（alive 2–24）。しかも alive が多い seed ほど健全なので、**処置強度が seed の健全さと逆相関する**。A3 は seed プールでの平均を主にせず、**seed 別に併記**する

### 3.3 継続の長さと記録

- 継続 **ΔT = 200,000 step（= 20 タスク）**
- 記録: 介入直後 1 タスク（10,000 step）は **100 step ごと**、以降は **1,000 step ごと**
- 各記録点で保存: `p̂`, `p_count`, `pre_max`, `x`, `r`, `w_norm`, `b`, `v`, 未フィット率、`strict_dead`
- `ΔL_i`（32 パターン全列挙・単独消音の厳密損失増分）は **介入直後（t=500,000⁺）と各タスク先頭**でのみ計算
- unit 単位の時系列は集計 CSV に押し込まず、`logs/unit_traj_<arm>.npz` に固定 shape で保存する（§10）。Git には入れず、SHA-256 と shape を `raw_sha256.csv` に残す

## 4. 指標

- **未フィット率** `U(t) := E[(ŷ-y)²] / Var(y)`（無次元 NMSE）。condA の現在タスクの **32 パターン全列挙**で `E` と `Var` を厳密計算し、固定 MC eval batch は使わない。8/20 教訓⑤に従い、生の `eval_loss` をアーム間で比較しない

- **再凍結時間** `τ_i`: 復活ユニット `i` が再び `p̂ = 0` に入るまでの step 数。長窓終端で未再凍結なら右打ち切り

- **`ΔL_i`**: 作業6 と同一定義（`utility_nmse`）

## 6. 判定基準（**結果を見る前に凍結**）

等価幅は**静的 O の効果量 0.1343 の 10%** を基準に `δ = 0.0134` と置く。以下すべて seed-paired。

### 6.1 O-1（主判定）— O を畳むか

短窓終端の `D_A1` に対して:

| 条件 | 判定 | 含意 |
|---|---|---|
| CI 上端 < **−δ** | **PERSISTENT** | 修復は再開後も効く。O は動的にも生き、柱3 の容量残存が強くなる |
| CI 全体が **[−δ, +δ]** に収まる | **FOLD** | 改善ゼロ。**既記の基準どおり O の主張を畳む**（`dead_frac` が機能の代理にならないのと同じ罠） |
| CI 下端 > **+δ** | **HARMFUL** | 介入は有害。別論点（perturb-only の毒と同型）へ |
| 上記以外 | **INCONCLUSIVE** | 精度不足として記録し、seed を足す判断は別途 |

長窓終端の `D_A1` は同じ表で**副次**として出す。**短窓が主**。

### 6.2 C-1（裁定）— 便益はスイッチか、W の取り替えか

`D_A1 − D_A2`（= `U_A1 − U_A2`）に対して、短窓・長窓それぞれで:

| 条件 | 判定 | 含意 |
|---|---|---|
| CI 全体が **[−δ, +δ]** | **SWITCH_SUFFICIENT** | bias を開くだけで CBP 型と同等。**学習済み W に利用可能な容量が残っていた**を動的にも支持 |
| CI 下端 > **+δ**（A2 が良い） | **REPLACEMENT_NEEDED** | 便益は W の取り替えから来る。O の容量主張は静的オラクルの範囲を出ない |
| CI 上端 < **−δ**（A1 が良い） | **SWITCH_SUPERIOR** | 取り替えは過剰な破壊。CBP の適用条件の未明示という既記の指摘が強くなる |
| 上記以外 | **INCONCLUSIVE** | — |

**スコープ明記**: one-shot・同一ユニット集合・condA 限定。CBP の継続適用への外挿は禁止。

### 6.3 F-1（ΔL 因果の半歩）

- 母集団: **A1 で実用復活（`p̂ ≥ 0.05`）したユニットのみ**
- 群: 介入直後の `ΔL_i` 三分位（各 seed × **介入直後の `pre_max_post`** 五分位セル内で切る。介入前値は `pre_max_pre` として別列に残す。介入後は `p_count` がほぼ揃うので層別は `pre_max_post` のみ）
- 転帰: 短窓終端の `strict_dead`
- 有効セル規則: 比較する 2 群の**両方**に 1 曝露以上あるセルのみ（作業6 の `primary_cell_valid` と同型）

| 条件 | 判定 | 含意 |
|---|---|---|
| 調整 RD（high−low）の CI 上端 < **−0.05** | **PROTECTIVE** | 作業6 の関連が、介入で作り直した母集団でも再現。**因果の半歩** |
| CI 全体が **[−0.05, +0.05]** | **NULL** | 介入後は機能が守らない。作業6 の関連に選択効果が混じっていた可能性が上がる |
| 上記以外 | **INCONCLUSIVE** | — |

**「半歩」と呼ぶ理由を判定文に必ず併記する**: 介入したのは `p̂`（スイッチ）であって `ΔL` ではない。`ΔL` はランダム化されておらず、依然として観察量である。**PROTECTIVE でも「機能が凍結を防ぐ因果効果」とは書かない**（[[機能盲目性_0823]] §5 の禁止事項をそのまま継承）。

### 6.4 Ch-1（合唱団予言）

**仮説（合唱団説）**: 生存者集団は既に現タスクを歌い切っている。復活ユニットには稼ぐ残差がないので、保護されず、元の水準まで再凍結する。

事前予言 2 本。**両方満たしたときのみ PASS**。

| # | 予言 | 判定条件 |
|---|---|---|
| **Ch-a** | 復活ユニットは再凍結する | 長窓終端の再凍結率が **≥ 0.80**、かつ `τ` の中央値 **< 50,000 step（5 タスク）** |
| **Ch-b** | `dead_frac` は元の水準へ戻る | 長窓終端の `dead_frac_0.05`(A1) − (A0) の CI 全体が **[−0.05, +0.05]** |

- 片方のみ成立 → **PARTIAL**（どちらが成立したかを明記）
- Ch-b の **CI 上端 < −0.05**（A1 の `dead_frac` が等価域より低い側に残る）→ **REJECTED_LOW**。「復活ユニットは仕事を見つけた」ことになり、[[停止条件]] の残る候補 (a) 罠幾何説／(b) 低次成分の稼ぎ説の判別に直接効く。**CI 下端 < −0.05 だけでは REJECTED にしない**（CI が等価域を跨ぐなら INCONCLUSIVE）
- Ch-b の **CI 下端 > +0.05**（A1 の `dead_frac` が A0 より高い）→ **REJECTED_HIGH**。修復が凍結を促進した別機序として記録する
- `frozen_frac` 版も**副次**として同じ表で出す（不可逆性を語るのはこちら）
- Kaplan–Meier 曲線（A1 の復活ユニット、右打ち切りあり）は**記述**として必ず出す

### 6.5 検出力ガード（事前登録）

- **G1**: F-1 の有効セル保持率が復活ユニット総数の **40% 未満**なら、F-1 は**記述扱い**とし判定に用いない
- **G2**: いずれかの CI 半幅が **0.10 を超えたら**、判定を上書きせず「精度不足」として別ラベルで記録する
- **G3**: A1 の実用復活率が **0.5 未満**なら、F-1 と Ch-a の母集団が痩せているので**両方を記述扱い**にする
- **G4（0826 追加）**: A3 起因の致死（介入直後に alive → `p̂ < 0.05` へ落ちた個体）が **1 seed でも 50% を超えたら**、A3 はプラセボではなく**破壊対照**としてのみ記録し、「同大の無方向摂動は改善しない」という読みには使わない
- どのガードが立っても、**seed を足したり層別を緩めたりしない**（結果を見てからの設計変更を禁じる）

## 7. 事前に決めておく分岐

### 7.1 O-1 = FOLD のとき

- [[機能盲目性_0823]] §3 の O を「**静的オラクルの容量診断であり、学習の再開には移らない**」に格下げする
- [[中心主張v3草案_0823]] 柱3 の残り半分（「スイッチを開けば利用可能な学習済み W が残る」）に、**動的には移らない**という但し書きを足す
- 静的 O の数値（0.143367 → 0.009148）は**取り消さない**。測っているものが違う

## 8. 実装上の罠（先に潰す）

- **乱数の独立化**: 作業6 で見つかった「seed 番号だけでは乱数系列が変わらない」実装上の罠を踏まない。本走は新規初期化ではなく既存 snapshot の完全 resume なので、`generator_offset` は起点走と同じ **0** に固定し、snapshot 内の各 generator state を真の起点とする。config 値・全 state hash を `manifest.csv` に記録する
- **アーム間のビット同一性**: 入力ストリーム・タスク境界・教師は全アームで**ビット同一**にする（`teachw_0820` の S2 と同型）。介入以外の差をゼロにする。**A3 の符号引きは学習用 RNG と別ストリーム**（`placebo_seed`）から取り、A0 の軌道に影響を与えない
- **境界のオフバイワン**: flip は記録点 B と B+1 の**間**で起きる。境界ペアの定義は `(s % T == 0) & (gap == 1) & (s > 0)`。**`s // T` ではタスクが分かれない**（8/22c の初回計算がこれで汚染された）
- **µ̂ が動く点を跨がない**: `cos` の増分を境界跨ぎで比較しない。生の `x = w·µ̂` で測る（8/21b 教訓⑦、8/22c の正規化注意）
- **恒真の回避**: 「復活ユニットの再凍結率」は蹴り上げ直後に `p̂ > 0` であることを実測で確認してから数える（S5）。P4 の事前登録指標がトートロジーだった前例に倣う
- **オラクル最適化の再現**: A1 の bias 最適化は作業2 O と**同一実装・同一コマンド**を呼ぶ。書き直さない
- **`n_alive` の実測**: `κ_s` と `c_s` は実行時に seed ごと計算し、`manifest.csv` に `n_dead,s` / `n_alive,s` / `κ_s` / `c_s` を全部残す。**本 note の 76–98 / 2–24 を定数として実装に埋めない**
