### 1.3 起案文から直す技術的前提

1. **訓練は autograd**。`step()` は `torch.autograd.grad(lossv.sum(), P)` を使う。`Act.dphi` は `evaluate()` の診断用で、訓練の勾配の差し込み口ではない。訓練の局所微分と診断微分を別列に保存する。
2. **GELU/SiLU では絶対値が必要**。負の微分をすべて「1e−6 未満」と数えると、有意な応答がある負勾配域まで消失扱いになる。主量は `abs(g_train) < DEAD_TOL`。起案文どおりの符号つき条件は比較用にだけ残す。
3. **`dead_frac` はペア割合ではない**。既存列は `mean_i(max_x abs(dphi) < 1e−6)`（全画像で低応答のユニット割合）。今回の主量は全 1200×100 ペアの割合であり、名前・分母を分ける。
4. **R=1 と R=20 を同一視しない**。`replay_stack()` は元の slot 順を使える。`replay()` の単独評価は丸めが変わるとコードに明記されている。主再生は元の R=20・元の順序・元の CUDA 環境で行う。R=1/CPU は主判定の代用にしない。
5. **t00 は専用経路**。既存 `replay_stack(task=0)` はラベル生成ループが空で `y` 未定義。t00 は保存状態・入力を組み立て、同じ `forward` だけを呼ぶ。ラベル・online・memo を捏造しない。
6. **KKT1 は W,b だけでは再生できない**。snapshot の `V1,V2` から元の演算順で alpha を復元する。t≥1 の保存 z は float16、hist の `m1,m2` と alpha は float32。float16 z は微分・帳簿の計算には使わない。

## 4. 登録する読み出し

### 4.1 状態と応答

層入力を `h1=X`、`h2=a1`、画像数 N=1200、ユニット数 H=100 とする。

- 各 (arm,cond,seed,task,layer,unit): 画像間の平均前活性 m、標準偏差 sd（**母標準偏差・ddof=0**）、最大/最小 z、正側割合、W の行ノルム、bias、`cos(w,mu)`。`mu_l=mean_x h_l` のベクトル・ノルムを保存。
- `m/sd` はユニットごとに作る。sd=0 かつ m≠0 は符号つき無限大、m=sd=0 は未定義。未定義の個数を保存し、勝手な epsilon を分母に足さない。元 `zsd` の PyTorch 既定（ddof=1）との照合は別列で行う。
- `g_train` は保存状態の同じ `Act.phi` に対する autograd の要素別微分。z を独立 leaf、保存 V を定数として `grad(phi(z).sum(), z)` で計算する。`train=True` と `False` が一致することも対象6腕で検査する。これは終端状態の局所微分であり、訓練中全ミニバッチの微分履歴ではない。
- 主低応答率 `Q_l = count(abs(g_train)<tau)/(NH)`、厳密零率 `Z_l = count(g_train==0)/(NH)`。`tau=DEAD_TOL=1e−6` は既存コードの操作的定義を継承し、Adam の epsilon から導いた停止閾値とは呼ばない。`g_train<0`、`g_train<tau`、平均 g、平均 abs(g)、ユニット別のペア割合も保存。
- 診断側 `g_diag=Act.dphi(z)` でも同じ列を計算し、元の `dead_frac` を再現する。両微分の差・厳密零判定の不一致数を全状態で保存する。符号反転と応答消失を混同しない。
- online は元 `per_task.csv` の**更新前ミニバッチ精度のタスク平均**。hist の `acc` は末尾評価であり online の代用にはしない。初回 online<0.5 は `LOW_FROM_TASK1` とし、「学べていた能力を失った」とは書かない。

### 4.2 四項帳簿

保存 W,b と忠実再生した h（float32）を float64 に正確に cast し、mu は画像について float64 で平均する。帳簿の端点は `m_alg=W mu+b`。元 float32 forward の画像平均 `m_replay` は別に保持し、その差は §7 の丸め上界で照合する。これにより float32 の affine 丸めを輸送項へ混入させない。

旧状態を t−1、新状態を t と書く。ユニット i ごとに

$$
\begin{aligned}
S_{t,i}&=(w_{t,i}-w_{t-1,i})^\top\mu_{t-1},\\
U_{t,i}&=w_{t-1,i}^\top(\mu_t-\mu_{t-1}),\\
C_{t,i}&=(w_{t,i}-w_{t-1,i})^\top(\mu_t-\mu_{t-1}),\\
B_{t,i}&=b_{t,i}-b_{t-1,i},\\
\Delta m_{t,i}^{alg}&=S_{t,i}+U_{t,i}+C_{t,i}+B_{t,i}.
\end{aligned}
$$

第2層が主。第1層にも同じ式を適用し、固定画像ゆえ U=C=0 となることを照合する。mu1 が非ゼロでも時間差はゼロ。第1層の恒真なゼロを独立の機構発見とは数えない。

時刻を合計してからユニットを**算術平均**し、最後に seed ごとの比を作る（§5）。中央値の4項を足して中央値の Δm と呼ばない。各項・Δm のユニット中央値と四分位は記述列として別保存する。死亡ユニットへの条件付け・タスクごとの個体選び直しはしない。

### 4.3 上流の伸びと回転

`r=norm(mu), e=mu/r` とし、連続する2点で

$$
\Delta\mu=\Delta r\,\frac{e_t+e_{t-1}}2
+\frac{r_t+r_{t-1}}2\,\Delta e.
$$

右辺第1項に旧 w を掛けたものを `U_growth`、第2項を `U_rotation` とする。両者の和は U。Δr<0 も符号を保ち、伸びという名前で正成分だけを抜かない。

補助として、w の行ノルムと単位方向も同じ対称差分で分け、旧 mu を掛けて `S_growth+S_rotation=S` を得る。**SELF_CARRIES は W ノルム成長が運んだことと同義ではない**。この補助帳簿とノルム・cos の時系列を併記する。

mu または w の端点ノルムが0なら方向分解は `UNDEFINED_DIRECTION`、ベクトルの四項帳簿は保存する。ゼロに近く方向の丸め誤差区間が判別を支えない場合も方向比は未定義とする。恣意的な小さい定数で方向を正規化しない。

### 4.4 窓と出力単位

- **主窓**: 各seedの t00→T*。T* は §5.1、1≤T*≤10。区間は t=1,...,T* の隣接端点差の和。タスク内部の経路は復元しない。

## 5. 登録する判定

閾値0.5は「ペアの過半」「寄与の半分」「seedの過半」という**操作的な多数規則**に由来する。online 0.5 と微分1e−6は親の操作的定義を継承するだけで、機構からの理論的臨界値ではない。推測統計の有意差判定は置かない。

### 5.1 R1: 先に低応答になる層

1. 各層で `T_l=min{t in 1..10: Q_l(t)>0.5}`。無ければ未到達。**Q=0.5ちょうどは超過に含めない**。最小の有限 T_l を T* とする。
2. T1<T2 は `L1_FIRST`、T2<T1 は `L2_FIRST`、同じ有限時刻なら `SIMULTANEOUS`。タスク内の先後は不明なので深さで勝手に解くことはしない。
3. 初期にQ_l(0)>0.5で、最初の該当時点まで一度もQ_l≤0.5を観測していなければ、その層の理由を `INITIAL_LOW` とする。R1 の層名は記録するが、新しい閾値通過としての支持・予測的中には使わない。特に ReLU は初期から負側の微分が0なのでこの開示が必要。
4. **両層とも t10まで未到達のときだけ**、`T_A=min{t in 1..10: online(t)<0.5}` を探す。あればその時点の `D_l=mean_i abs(m_i/sd_i)` を比較し、大きい層を `FALLBACK_L1` / `FALLBACK_L2`、T*=T_A とする。∞対∞、未定義ユニットあり、丸め区間が重なって順序を決められない場合は `FALLBACK_TIE`。fallback は微分消失の証拠ではなく幾何的な候補。
5. 閾値もonlineも該当しなければ `NO_EVENT_BY_T10`、主窓T*なし。t11–t50の最初の通過は参考欄にのみ記載し、主判定を差し替えない。
6. online初回低下時刻 T_A はすべてのモデルで別列に持つ。ゲート通過より先にonlineが下がっても、後のゲート通過の主規則を差し替えない。そのずれを報告する。

腕×条件の10seedを分母に、同じ**理由つきラベル**が6seed以上ならそのラベル、どれも過半でなければ `SPLIT`。層だけの票数も併記するが、fallback・INITIAL_LOW を新規通過と混ぜて過半にしない。欠測・検査失敗があるセルは `INAPPLICABLE`、9seedの多数決へ縮めない。

S4/S5へ渡す層は新規の `L1_FIRST/L2_FIRST` に過半がある場合の候補。`SIMULTANEOUS/SPLIT/FALLBACK/INITIAL_LOW` なら単一層への自動決定はしない。**「崩壊層」はこの操作的名称であり、A6だけで因果的なボトルネック層を確定しない。**

### 5.2 R2: 第2層の運び手

R1 が第1層であっても、第2層帳簿は同じ T* まで報告する。ただし `L2_LEDGER_WHEN_L1_FIRST` と明示し、第1層の死因を第2層の比から説明しない。

seed ごとに `A_k=mean_i sum_(t=1..T*) k_(t,i)`（k=S,U,C,B）、`D=mean_i(m_alg(T*)−m_alg(0))`。閉包が成立したとき、D<0が丸め上界込みで確定すれば `f_k=A_k/D`。各 f の和は1だが、**負値・1超を許す**（打ち消しのある符号つき純寄与）。absを取ってから正規化しない。

| 条件 | seed の R2 |
|---|---|
| f_U≥1/2、f_S<1/2 | `UPSTREAM_CARRIES` |
| f_S≥1/2、f_U<1/2 | `SELF_CARRIES` |
| 両方≥1/2、または両方<1/2 | `MIXED`。前者に `BOTH_GE_HALF`、後者に `NEITHER_GE_HALF` |
| D>0が確定 | `NO_NET_SINK` |
| D=0またはDの丸め区間が0を含む | `UNRESOLVED_NET_CHANGE`、比はNA |
| 比の丸め区間が1/2をまたぐ | `UNRESOLVED_SHARE` |
| T*なし／初期から低応答 | `NO_EVENT`／`INITIAL_LOW_REPORT_ONLY`、比は報告のみ |

半分の境界は比を先に丸めず `A_U−D/2` 等を評価して判定する。D<0なので符号の反転に注意。厳密に同値なら≥側、算術誤差で符号が未確定なら unresolved。交差・biasの符号つき f と、`abs(A_B)/abs(D)` は必ず併記する。

腕×条件では同じR2ラベルが6/10以上なら採用、他は `SPLIT`。各ラベルの件数・各比のseed中央値と範囲・10seed全行を出す。未定義seedを捨てて分母を縮めない。平均の比で seed別判定を上書きしない。

### 5.3 R3: 上流の中身（報告）

同じ区間・同じ集約で `A_Ugrowth/A_U` と `A_Urotation/A_U` を報告し、和が1になることを検査する。A_Uの丸め区間に0が入れば比はNA、二つの生の総量を残す。符号・1超を保持し、方向未定義の区間が一つでもあればそのseedの方向比は未定義。新しい勝敗ラベルは設けない。KKT1/LRは全量REPORT_ONLY。

### 5.4 結論の限界

`UPSTREAM_CARRIES` は保存端点間で旧 W による入力平均変化が正味沈降の半分以上を占めたという記述である。入力平均への介入の媒介率ではない。交差項の大きさは観測間隔に依存し、1タスクの粗い刻みを1更新の力や連続時間の速度と読まない。負側の深さ・Q・online は別々に報告し、一方を他方の定義にしない。

## 7. 検査（実装後に実施・現時点は未実施）

### 7.1 算術から作る許容

- **S-snap**: 元のR・スロット順・float32・CUDAで再生し、各層・各slot・各時点の `mean_x z` と hist の m を照合する。差の上界は起案文の `2*eps32*max_i(abs(m_replay_i),abs(m_hist_i))` を同じ層の全ユニットに用いる。スケールが0なら厳密一致。元と同一演算のためbit一致も記録する。保存float16 zへのcastと元snapshotは完全一致を要求する。**R=1やCPUにこの狭い帯を適用しないし、失敗を見て帯を広げない。** 不一致なら検査結果を保存して停止し、slot、元コード、データ、実行環境を照合する。
- **帳簿の閉包**: float64の機械単位丸めを u64=2^-53、`gamma_n=n*u/(1−n*u)` とする。nは実際の演算数に基づく。d項の内積は保守的に `gamma_(2d)*sum abs(products)`、N画像の和は `gamma_(N−1)*sum abs(values)`、平均の除算・差・和にはそれぞれ1演算の絶対誤差を足し、入力側の誤差も伝播させる。4項の再加算と2端点の差に至る両経路の上界を足した値を閉包の許容とする。**相対誤差を小さい正味変位で割って検査しない。** 正規化・sqrtを含む方向分解は同じ演算誤差区間を伝播し、ノルム区間が0を含む場合は方向不定とする。
- **float32 forwardとm_alg**: hとWを保存float32の実数値とみなす。affineの画像平均丸めは、d個の積和とbias加算の上界 `gamma_(2d+2)(u32) * [mean_x sum_j abs(w_j*h_xj)+abs(b)]` から導く（u32=2^-24）。さらにfloat64の画像平均・mu計算・内積の上界を加える。TF32や低精度の積を使っていた場合はこの仮定が成立しないため、元設定を照合するまでPASSとしない。subnormal/flush設定と非有限値を記録し、通常相対丸めモデルの範囲外の演算には実装の最小数から導いた絶対誤差も加える。
- 上界計算自体の丸めは外向きに広げる。R2/R3の分母・比の判別にも同じ上界を使う。固定の「1e−8より大きければ可」や、観測した差に合わせた許容倍率を足さない。
- 閾値tauと厳密零について、訓練微分と診断微分の一致を仮定しない。主量は実際の元phiに対するautogradで定義される。ELUの零化位置を起案文の「−87付近」や別エンジンのexpm1床に固定しない。
