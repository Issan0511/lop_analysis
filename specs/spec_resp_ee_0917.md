## 0. 一行と問い

**RL の ELU→ELU 箱の自然な軌道を途中のタスク終端で分岐させ、第2層が訓練で使う「応答」だけを別の時刻のものに差し替える。分岐点では特徴・予測・損失・重み・Adam 履歴を 1 bit も変えない。** そのうえで、次の新しいラベルをどれだけ学べるかを比べる。

- **Q1（主・復元）**: 崩壊した t10 の網に、t2 の第2層の応答の場を与えると、次のタスクを学べるようになるか。**P1 = E(R2_10) − E(N10)**。
- **Q2（主・沈降）**: 健康な t2 の網に、t10 の第2層の応答の場を与えると、学べなくなるか。**P2 = E(N2r) − E(S2_10r)**（両腕とも Adam を初期化）。
- **Q3（副）**: 応答の形を保ったまま大きさだけを一様に下げる階段（Δ = 5, 10, 15, 20, 30）で、どこから学べなくなるか。Adam の ε の位置と float32 の 0 の位置（§1.3）と照合する。
- **Q4（副・報告のみ）**: 復元・沈降の時刻依存（t5〜t20）、第1層との比較、Adam 履歴の役割、継続 2 タスク目での持続。

## 1. なぜ

### 1.1 H4 に残っていること

作業リスト H4 の閉じる条件は「有限の更新予算・固定した対象入力のもとで、輸送に伴う低応答化と再学習の低下が対応し、応答への介入が低下を変える」。残作業は (1) 同じ設定で上流へ戻る、(2) 機能的な応答を定義する（平均前活性で死亡判定しない。φ′ と ε を並べるだけでは停止機構の検証にならない）。

anchor 0913 は RL の t20・ELU 第2層の沈んだ 20 個体に固定補正を入れ、初期特徴を揃えたまま応答を戻すと再学習が 12% → 75% になった（`DIRECTIONAL_RESPONSE_SUPPORT`）。残る穴は次の 5 つ。

1. **逆向きがない。** 健康な網から応答だけを奪って学べなくなるかは見ていない。
2. **層全体ではない。** 選んだ 20 個体だけを変えた。
3. **形を戻していない。** 平均を −1 へ寄せる一様なシフトで、入力ごとの応答の形は戻していない。
4. **箱が違う。** 0913 の Codex runner で、H2・H3 の EE 版（mucap_ee_0917）と同じ軌道ではない。
5. **ε の帰属が未検証。** 「微分が小さい」と「Adam の ε に負ける」を分けていない。

本 spec は同じ箱（mucap_ee_0917 の ref と bit 一致、S0）で、1〜5 を一度に扱う。mucap_ee_0917 が「第1層の W 成長を止めると第2層は崩れないか」（上流）を答え、本 spec が「第2層の応答が再学習を決めるか」（下流）を答える。

### 1.3 実装中に見つけたこと（登録前）: この箱の ELU の訓練中の微分は、float32 で z < −16.64 のとき厳密に 0

ホストの ELU は `where(z > 0, z, expm1(min(z, 0)))`（`src/elu_growth_0909.py`）。PyTorch は expm1 の逆伝播を「出力 + 1」で計算する。−1 の近くの float32 の刻みは $2^{-24}$ で、この計算機の float32 の expm1 カーネルは $e^z<2^{-24}$ で −1 を返す（最近接丸めなら境界は $2^{-25}$ のはずだが、実測では切り捨て。微分が 0 になる最大の float32 は z = −16.635534、次の値で $2^{-24}$）。したがって **オプティマイザが受け取る微分は z < ln 2⁻²⁴ = −16.64 で厳密に 0**、その上では $2^{-24}$ 刻みに量子化される（z = −15 で 2.98e−7、真値 3.06e−7）。境界はカーネルの性質なので、計算機に依存する。float64 では同じことが z < −36.7 付近で起きる。`F.elu` は入力から exp で微分を作るので、この性質を持たない（z = −20 で 2.06e−9）。検査 S4b で bit 単位に確認した。

既存の診断（`gate_mean`・`dphi`）は解析的な exp(z) で、訓練で使われた微分ではない。本箱の自然な状態で両者を並べると（seed 0 / 1、固定 1200 枚、第2層）:

| 状態 | (ユニット, 画像) のうち訓練の微分が厳密に 0 | 全画像で 0 のユニット | 平均 φ′（exp） |
|---|---|---|---|
| t2 | 0 / 0 | 0 / 0 | 0.698 / 0.689 |
| t10 | **0.964 / 0.911** | 0.14 / 0.02 | 0.0034 / 0.0098 |

**t10 の第2層は、訓練の上ではほとんど ReLU の死と同じ状態にある。** 平均の exp(z) が 0.003 あるのは、−16.64 より上に残った少数の (ユニット, 画像) が運んでいる。

含意:

- 本 spec は応答を 2 通り記録する。訓練の微分（`dphi_train` = expm1 + 1、float32）と、解析的な exp(z)。「機能的な応答」の候補として、訓練の微分の平均・厳密な 0 の割合・有効入力数 $n_{\rm eff}=(\sum_x g)^2/(N\sum_x g^2)$ を並べる。
- 一様シフトの階段（§2.4）は、Adam の ε を横切る位置と float32 の 0 の位置が近い（下表）。Δ = 5・10・15 は両方より下、Δ = 30 は両方より上、Δ = 20 はその間にある。
- 過去の読みのうち「ELU の微分は厳密に 0 にならない」「凍結を止めたのは Adam の ε」（0914 層別キメラの事後の読み）と、0916 の ε 介入の読みは、この性質を入れて読み直す必要がある。**本 spec はその再判定をしない**（別作業として記録する）。
- この発見は §7 の予測を書いた後、登録の前に得た。予測は Issa の指示（「同じ予測で」）どおり変えていない。

## 2. 設計

### 2.1 箱（mucap_ee_0917 の ref）

- Random Label MNIST。seed ごとに MNIST 訓練集合から 1200 枚を固定、画素/255。各タスクで 1200 枚それぞれに独立一様な 10 クラスラベル。
- 784–100–100–10、**両隠れ層とも ELU(α=1)**（`elu_growth_0909.ELU(1.0)`、§1.3 の実装）、出力線形。初期化は宿主 `H.init_params(seed)`。
- Adam lr=1e−3・β=(0.9, 0.999)・ε=1e−8、正則化なし。batch 16、80 epoch × 75 更新 = **6000 更新/タスク**、各 epoch で標本順を引き直す。
- seed 0–9。CPU・1 スレッド・`torch.set_flush_denormal(True)`。
- 更新則は `src/resp_ee_0917.py` の `train_task` に書き下した。宿主 `run_one`（ref・ELU→ELU）と bit 一致（S1）、mucap_ee_0917 の ref の記録とタスクごとの正解率が一致（S0、seeds 0–1・t1–22）。

### 2.2 接頭部と分岐点

1 プロセス 1 seed。自然な軌道を task 22 まで回し、task 2・5・7・10・15・20 の終端で状態を保存する（全パラメータ、Adam の m・v・t、ラベルと標本順の乱数生成器の状態、固定 1200 枚上の両層の前活性 $z_1,z_2$）。各腕は一つの分岐点から、**接頭部と同じ乱数の続きで**新しい 2 タスクを学ぶ。したがって自然腕 N⟨t⟩ は接頭部の task t+1・t+2 そのもの（状態の sha256 一致を走行中に記録、S2）。同じ分岐点の腕は同じラベル・同じ標本順を見る。

### 2.3 応答の場の移植

層 $l$ の各ユニット $i$・各画像 $x$ にシフト $d_i(x)$ を固定し、分岐点のパラメータ $p_0$ を凍結した網の前活性を $z^0_i(x)$ として、

$$
a_i(x)=\phi\big(z^0_i(x)\big)+\Big[\phi\big(z_i(x)+d_i(x)\big)-\phi\big(z^0_i(x)+d_i(x)\big)\Big].
$$

- 分岐点では $z=z^0$（同じ演算・同じビット）なので括弧は厳密に 0。**特徴・logit・損失は自然な網と bit 一致**（S3）。
- 訓練の微分は $\partial a_i/\partial z_i=\phi'_{\rm train}(z_i+d_i)$（S4）。学習が進むと $z$ が動き、応答の引数は $z+d$ として一緒に動く。
- $z^0$ はキャッシュせず、毎ミニバッチ $p_0$ から計算し直す（これで一致が厳密になる）。
- anchor 0913 の $F=0,K=1$ の関数を、ユニット×画像ごとのシフトに一般化したもの。$d$ は固定で、更新も減衰もしない。

シフトの種類:

- **場（field）**: $d_i(x)=z^{(\rm src)}_i(x)-z^{(\rm br)}_i(x)$。分岐点で、ユニットは時刻 src のときと同じ入力ごとの応答を返す（S3 で丸めの上界内を確認）。
- **一様（uniform）**: 全ユニット・全画像で $d=-\Delta$。応答の形（画像間の相対的な重み $e^{z}$）を保ったまま大きさを $e^{-\Delta}$ 倍にする（正側に残る画像を除く）。

### 2.4 腕（26 腕、seed ごとに全部）

「r」は Adam を初期化した腕（m=v=0・t=0、最初の一歩は lr·g/(|g|+ε)、S5）。

| 腕 | 分岐点 | 変える層 | シフト | Adam | 役割 |
|---|---|---|---|---|---|
| N2, N5, N7, N10, N15, N20 | t | — | — | 継続 | 自然な継続 |
| N2r, N10r | 2 / 10 | — | — | 初期化 | Adam 初期化だけの効果 |
| **R2_10** | 10 | 2 | 場: t2 | 継続 | **P1** |
| R2_5, R2_7, R2_15, R2_20 | t | 2 | 場: t2 | 継続 | 復元の時刻依存 |
| R2_10r | 10 | 2 | 場: t2 | 初期化 | 復元（両方初期化） |
| **S2_10r** | 2 | 2 | 場: t10 | 初期化 | **P2** |
| S2_5r, S2_7r, S2_15r, S2_20r | 2 | 2 | 場: t′ | 初期化 | 沈降の時刻依存 |
| S2_10 | 2 | 2 | 場: t10 | 継続 | 古い v の効果 |
| S2u5r, S2u10r, S2u15r, S2u20r, S2u30r | 2 | 2 | 一様: −Δ | 初期化 | 大きさの階段 |
| S1u20r | 2 | 1 | 一様: −20 | 初期化 | 層の比較 |

**沈降側を Adam 初期化で比べる理由**: t2 の Adam は健康な勾配の大きさの v を持つ。応答を t10 のものに替えて勾配が桁で小さくなると、古い v で割られて一歩が消え、応答そのものでなく「Adam の分母の遅れ」で学べなくなる。自然な t10 の網の v はその小さい勾配に馴染んでいる。初期化した腕同士（N2r 対 S2_10r）で比べると、この人工物が消える。S2_10 − S2_10r で人工物の大きさを報告する。

**復元側を Adam 継続で比べる理由**: 自然な t10 の網と同じ状態から始める比較が主問題。応答を戻した直後の一歩は、古い小さい v のため最大 (1−β₁)/√(1−β₂) ≈ 3.16 倍に膨らむ（有界な過渡）。R2_10r − N10r を副比較に置く。

## 3. 測る量

継続タスクごとに（`runs/s<seed>/arms.csv`）:

- 全 6000 更新の更新前ミニバッチの正解率と CE（float32 で保存し float64 で平均）。最初の 75 更新、最後の 750 更新。
- タスク終端の 1200 枚での正解率・CE（腕自身の forward）。
- W1・W2・W3 の一歩の RMS / lr（タスク平均・最初の 75 更新）。更新 1・75・1500・6000 で $\sqrt{\hat v}<\varepsilon$ の座標割合。
- 分岐点の直前に、最初の epoch の 75 ミニバッチで各重みの勾配の座標ごとの RMS（更新しない）。ε を下回る割合と厳密に 0 の割合（`pf_eps_*`・`pf_zero_*`）。
- 分岐点（開始）と各タスク終端のユニット量（両層、float64）: 前活性の平均・SD・最大、訓練の引数 $z+d$ の平均・最大・正の割合、**訓練の微分の平均・厳密な 0 の割合・全画像 0 のユニット割合・有効入力数**、exp(z+d) の平均（対数平均も）・低ゲート割合・有効入力数、$\|\mu_2\|$。
- 状態の sha256、分岐点での logit の一致（1200 枚と最初のミニバッチ）、自然腕の接頭部との一致。

接頭部（`prefix.csv`）: 各タスクの正解率・CE・終端正解率・上記のユニット要約・状態の sha256。`dstar.json`: §1.3 の算術（seed ごと）。`units.npz`: ユニット別の配列と更新ごとの CE・正解率・一歩。`branch_states.pt`: 分岐点の状態（独立の再計算用）。

## 4. endpoint

### 4.1 主量

**E = 継続 1 タスク目の online 正解率**（6000 更新の更新前ミニバッチ正解率の平均）。腕の比較は seed 内の差。未知画像への汎化ではなく、1200 枚の新しいランダム割当をどれだけ覚えながら学べたかの量。

### 4.2 床（1 タスク）

腕の継続タスクが **AT_FLOOR** ⇔ $E\le F+3\sqrt{F(1-F)/1200}$、$F$ はそのタスクのラベルでの最多クラスの割合（最良の定数予測器の正解率）。導出: 新しいラベルについて何も学ばない網の正解率の期待値は高々 $F$ で、その超過は 1200 個のラベルの二項ばらつき（割合 $F$ で上から抑える）。

### 4.3 適合率（階段）

$F_\Delta=(E({\rm S2u}\Delta{\rm r})-0.1)/(E({\rm N2r})-0.1)$。0.1 は 10 クラスの偶然水準。seed ごとに作り、seed 平均 $\bar F_\Delta$ を使う。

## 5. 判定

### 5.1 帯の算術

有効 seed の差の平均・SD・**97.5% 対応差 t 区間**（df = n−1、主 2 比較の Bonferroni）。95% 区間も併記。SD = 0 なら区間を作らず同一差を示す。符号: 下端 > 0 なら +、上端 < 0 なら −、他は 0。t 分位点は mucap_ee_0917 の実装（公表表と 1e−6 で照合、S6）。

### 5.2 適用条件

- **(A) 完全性**: seed が有効 ⇔ 登録 commit が一致・flush 有効・80 epoch、接頭部 22 タスクが有限、26 腕 × 2 タスクが揃って有限、全腕で分岐点の logit が自然な網と一致（1200 枚と最初のミニバッチ）、自然腕 6 本が接頭部と状態 sha256 で一致。**有効 seed が 8 未満なら INAPPLICABLE。**
- **(B) 現象がある**: 自然な学習能力の差 E(N2) − E(N10) の 95% 区間の下端 > 0、かつ全有効 seed で第2層の平均 φ′（exp）が t2 > t10。満たさなければ **NOT_REPRODUCED**。

### 5.3 主ラベル

| P1（97.5%） | P2（97.5%） | ラベル |
|---|---|---|
| どちらかが − | | **RESPONSE_REVERSED** |
| + | + | **RESPONSE_BOTH_WAYS** |
| + | 0 | RESTORE_ONLY |
| 0 | + | SINK_ONLY |
| 0 | 0 | RESPONSE_NOT_SHOWN |

回復率（報告のみ）: ρ1 = mean P1 / mean(E(N2) − E(N10))、ρ2 = mean P2 / mean(E(N2r) − E(N10r))。

### 5.4 階段の記述ラベル（登録・主判定ではない）

$\Delta^*$ の seed 中央値の q0.1・q0.9 で段を分ける。下の段 = Δ < q0.1、上の段 = Δ > q0.9（間の段はどちらにも入れない）。

- 下の段がすべて $\bar F\ge0.5$、上の段がすべて $\bar F<0.5$ → **EPS_CONSISTENT**
- 下の段のどれかが $\bar F<0.5$ → **DROPS_BEFORE_EPS**（上の段で残る段もあれば NONMONOTONE）
- 上の段のどれかが $\bar F\ge0.5$ → **SURVIVES_PAST_EPS**
- どちらかの段が空 → PARTIAL(…)

§1.3 の算術では上の段は Δ = 30 だけで、そこは float32 の 0 の段でもある。**EPS_CONSISTENT は「ε か float32 の 0 のどちらか」と整合という意味で、ε と 0 を分けたことにはしない。** Δ = 15（ε より下・18% が 0）と Δ = 20（ε の中・95% が 0）の $\bar F$ と、腕ごとの `pf_eps_w2`・`pf_zero_w2`・`zero2_start` を並べて報告する。

### 5.5 読み方（登録）

- RESPONSE_BOTH_WAYS → **この箱では、第2層の応答の場が、同じ重み・同じ特徴・同じ Adam 状態の網の再学習を両方向に決める。** H4 の「応答への介入が低下を変える」をこの箱で満たす。自然な崩壊の全量を応答が媒介したとは書かない（固定補正を持つ人工的な関数変更）。
- RESTORE_ONLY → 応答を戻すと学べるが、応答を奪っても（Adam を初期化すれば）学べる。応答の喪失は十分条件でない。
- SINK_ONLY → 応答を奪うと学べなくなるが、崩壊後に応答だけ戻しても学べない。崩壊後の網には応答以外の損傷（W3・第1層・特徴）がある。
- RESPONSE_NOT_SHOWN → この箱の再学習の差は第2層の応答の場では説明されない。
- 階段: 下の段で落ちる（DROPS_BEFORE_EPS）なら、大きさ（ε・0）でなく**応答の形**（少数画像への集中）が効く。上の段だけで落ちるなら、ε か float32 の 0 のどちらかで説明できる。
- 事後の順位相関（腕をまたぐ E 対 訓練の微分の平均・0 の割合・有効入力数・ε 域）は報告のみ。因果とはしない。
- すべて「この ELU→ELU・乱数ラベル・6000 更新・固定 1200 枚・float32 の expm1 実装の ELU」に限る。

## 8. 費用と実行

- 1 seed = 接頭部 22 タスク（132,000 更新）＋ 26 腕 × 2 タスク（312,000 更新）＋ 分岐点の診断。S-cost と S0 の実測から見積もる（§6.1）。
