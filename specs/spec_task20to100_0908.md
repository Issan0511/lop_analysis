# タスク20〜100の前活性分布追跡 spec 0908
状態: 検証中 / 更新: 2026-09-08
親: [[初期タスクの形成過程と正負更新収支_結果_0908]]
Issaの「20〜100」はタスク番号。直前の更新数20〜100の測定は依頼の取り違えであり、本仕様がユーザーの対象区間に対応する。過去のtask20/task100付近は既知のため、既存軌道の追加記録・記述解析とする。

## 固定する窓と対象
同じCPU軌道、SNA/LR × none/L2、seed0..2。タスク20終端の保存状態（全パラメータ・Adam・Snake V・RNG）からtask21..100を625更新ずつ継続する。新しい初期値や介入は導入しない。タスク20から100まで81時点の各タスク終端を同じ512 probe入力のそのタスクの置換で測る。
第1層のユニット別平均前活性・入力内分散・設定点star・W行和成分・biasを保存。集団のmean(zbar)、ユニット平均分布の10/50/90%点、平均入力内分散、ユニット平均間分散を出す。
主量はtask100終端−task20終端の同じ量の差。補助に固定区間20→40→60→80→100の差を出し、一様な下降か途中で止まるかも記述。seed内差→3seed中央値/範囲・負差seed数（<−1e-6）で示す。中央値どうしの差を差の中央値として扱わない。定常性検定・因果帰属・自己項の判定は行わない。

## 検算と保存
task20終端のsource after_625と完全同一から再開。data/batch RNGはtask20の記録点からそのタスクの抽選だけ進め、perm RNGは記録済みのtask20置換直後を使用。task100終端は既存boundary_groups_0908のtask100 checkpointの全パラメータ・Adam・Snake V・perm・各RNGと完全一致を要求。失敗は保存し、同一軌道との主張を止める。
CPU1thread/プロセス、最大2プロセス、1走900秒上限。全12走。コード/specを実行前commit/push。各taskのユニット別配列、集約CSV、図、source/code/data hashを結果repoへ保存（小さいnpzのみ）。既存大型checkpointは変更しない。結果ノートと履歴、現在地の解釈を必要最小限で更新。主張の採否は変更しない。
