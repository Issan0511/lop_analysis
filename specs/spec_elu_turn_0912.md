## 0. 何を決めるか

[[回る速さが幅の正体か_結果_0912]] で、leaky の幅の害は**回る速さ** $\omega$（1 更新でユニットの向きが回る角度）で完全に説明された。一方 [[個体別3分表_結果_0911]] は**ゲートの低いユニットは Adam の一歩も短い**（ELU で ρ(ḡ, κ2) = +0.86・Adam は補償しない）と示している。ならば飽和したユニットは回るのが遅く、**飽和は害になるはず**。しかし [[ゲート被覆か非線形性か_結果_0911]] では ELU の害は幅で 96% 説明され、飽和側に残りがない。

**統一する読み**: $\omega$ を分子と分母に分ける。

$$\omega \;\approx\; \frac{\lVert\Delta\tilde W_i\rVert}{\lVert\tilde W_i\rVert} \;=\; \frac{\text{一歩の長さ（ゲートが決める）}}{\text{ユニットの長さ（幅が決める）}}$$

- **幅を動かす実験**（クランプ）は分母を 3.5 倍動かす。分子の飽和による変化（≈2 倍）を圧倒するので、飽和が無害に**見えた**。
- **幅を固定して負側の帯 τ を振る実験**（[[高ゲート帯の幅ダイヤル_結果_0911]]: τ = 0.3/1/3 で L = 2.68/1.86/0.65 pt、‖W̃‖ は +1.2%）は**分子だけ**を動かしている。**あれは飽和の害そのものを測っていた**ことになる。

**本走の問い**: τ ダイヤルは本当に $\omega$ を動かしているか。動かしているなら、**leaky で測った傾き 1.05 pt/octave がそのまま τ の効果量を説明するか**。

## 3. 判定（事前登録・seed 3/3 一致でラベル、混在は `MIXED`）

**M0 操作チェック**: 全錨との G1（maxabs ≤ 1e−10・件数ガード）、角度の 2 式突合 ≤ 1e−6、球面三角不等式 ≤ 1e−8、`CELU1w` のクランプ検査と変異対照 3 本（合格幅は検査の許容の 10 倍・[[threshold-derivation-rule]]）。**ω の分解の検算**: $\log\omega$ と $\log(\text{step}/\lVert\tilde W\rVert)$ の差が全腕で 0.15 以内（一歩がほぼ接線方向であることの確認。外れたら M3 は記述のみ）。すべて満たせば `MANIPULATION_OK`。**M0 が外れたら M1–M4 は `NOT_TESTABLE`。**
可検定性（M0 と独立に記録）: L(`CELU03`) − L(`CELU3`) ≥ 1.0 pt（前走 2.02）。

**M1 決定的 — τ は ω を動かすか、長さでなく**:
- $r_\omega$ ≥ 2.0 かつ |log₂ $r_N$| < 0.3 → **`TAU_MOVES_OMEGA_NOT_LENGTH`**
- $r_\omega$ ≤ 1.2 → **`TAU_DOES_NOT_MOVE_OMEGA`**（飽和は回る速さ以外の経路で効いている）
- 他 → `M1_PARTIAL`

**M2 leaky の傾きが τ の効果量を説明するか**: 予測 ΔL = $b\cdot\log_2 r_\omega$、実測 ΔL = L(`CELU03`) − L(`CELU3`)。
- |予測 − 実測| < 0.5 pt → **`LEAKY_SLOPE_ACCOUNTS`**（活性化をまたいで ω の効き方が同じ）
- ≥ 1.0 pt → **`SLOPE_DOES_NOT_ACCOUNT`**
- 他 → `M2_PARTIAL`

**M3 ユニット内で分子と分母の両方が効くか**（各腕・late 窓・hard-dead 除外・偏 Spearman のタスク中央値・seed 別）: ω_i と ḡ_i（log‖W̃ᵢ‖ を制御）、ω_i と −log‖W̃ᵢ‖（ḡ_i を制御）。
- 両方 ≥ +0.3 が 3/3 → **`BOTH_ENTER`**／ゲートだけ → `GATE_ONLY`／長さだけ → `LENGTH_ONLY`／他 `M3_PARTIAL`

**M4 活性化をまたぐ 1 本の線**（記述・ラベルあり）: 本走 5 腕 ＋ [[回る速さが幅の正体か_結果_0912]] の leaky 6 腕を同じ (log₂ω, L) 軸に置く。leaky の直線からの ELU 4 腕の残差の中央値 $\delta$。
- |δ| < 0.5 pt → **`ONE_LINE`**（c_act は ω に吸収される）
- |δ| ≥ 1.0 pt → **`OFFSET`**（ω で説明した後に活性化固有の切片が残る＝c_act の正体はそこ）
- 他 → `M4_PARTIAL`

**可検定性**: 発散は `DIVERGED`。late 窓のタスク内 CE 改善が 90% 未満なら `LEARNING_BROKEN`。
