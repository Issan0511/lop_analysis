## 0. 一行

境界窓で税（F_self）と稼ぎ（F_rest）を積分し、**死亡個体を再分類死 / 輸送死に分けて**、死亡個体の沈下に税が占める割合の中央値を seed 単位ペアブートストラップ CI 付きで再推定する。

## 1. 何を足し、何を足さないか

**測る項目の集合は vault `中和と境界窓.md` §4・§5 と同一。** 新しい指標を足さない。本 spec が追加するのは次の 2 点だけで、それが「格上げの実体」である:

1. **群分け** — 死亡個体を再分類死 / 輸送死に分ける（ラベルは `results/dead2path_0821/events.csv`）
2. **seed 単位ペアブートストラップの CI** — スモークには CI が無い

**足さないもの（明示的な禁止）**:

- 相殺比 `|F_gate|/|F_self|` の境界前後プロファイル（`中和と境界窓.md` §8-3）。これは「次の測定」であって §4・§5 の項目ではない
- **陣営（`sign(v_i)`）別の符号分布**（同 §8-2、[[命題リスト]] Q17 = 穴A）。**同じ npz を触るので最も手が滑る箇所**。本 spec の出力にこの集計を含めない
- `summary.md` に機構の考察を書かない

## 2. 入力とデータ構造（確認済み）

- `results/ratchet_log_0819/logs/seed{0..9}.npz` — 10 seed で step グリッドが byte 一致、`width=100`、`period=10000`、`lr` 一致、`run_id` 一意。`F_self` / `F_rest` / `F_gate` / `p_hat` / `w_norm` / `v` はいずれも (20901, 100) float32、NaN/Inf なし
- `F_self + F_rest = F_gate` の最大絶対残差 1.49e-08〜2.98e-08（float32 精度内）。**積分には保存されている `F_gate` を使い、`F_self + F_rest` で作り直さない**（float32 の桁落ちを避けるため別途保存されている）
- `results/dead2path_0821/events.csv` — 群ラベル。11,808 行、列は `seed, run_id, unit, pair_index, step_prev, step_post, path, pair_win, reignited, permanent, p_hat_prev, p_hat_post, d_cos, d_wnorm, v, w_norm_prev`。`path ∈ {transport, reclass}`
- 境界は 99 個実現（k = 1..99、step = k·10⁴）。100 番目（t = 10⁶）では flip が起きない。step 999,900–999,999 の毎 step 記録は**境界窓ではない**ので除外する

### 記録グリッド（本 spec の中心的な制約）

| 区間 | 記録間隔 | 点数 |
|---|---|---|
| `[B−100, B+100]` | 1 step | 201 |
| `(B+100, B+1000]` | 900 step | 1 |
| `(B+1000, B+2000]` | 1000 step | 1 |
| その他 | 1000 step | — |

10 seed × 99 境界すべてで例外なし（`step` 差分ヒストグラム `{1: 19900, 900: 199, 1000: 801}`）。

## 3. 定義（事前固定）

- **ユニット事件**: 三つ組 (seed, 境界 index k, unit i)、k = 1..99。10 × 99 × 100 = 99,000 が上限
- **alive / dead**: p̂ ≥ 0.05 / p̂ < 0.05（`teachw_0820`・`spec_dead2path_0821` と同規約）
- **対象**: 境界 B = k·10⁴ の**時点で alive** な個体のみ（B の記録点で判定）
- **死亡個体**: 対象のうち、**そのタスク中**（記録ペアの左端が [B, B+10⁴) に入るペア）で p̂ が 0.05 を上から下へ跨いだ個体。最初のクロスで代表させる
- **生存個体**: 対象のうち、タスク終端（次の境界 B+10⁴ の記録点）まで一度も下抜けしない個体
- **群ラベル**: 死亡個体の代表クロスが `events.csv` の `path` で `reclass` なら**再分類死**、`transport` なら**輸送死**。突合キーは `(seed, unit, step_prev)`（`events.csv` 内で一意であることを S3 で確認する）

### 積分窓（S1 の処置 — 両方を出す）

スモークの窓 `[B+1, B+2000]` は本番ログでは毎 step 再現できない（§2 の表）。**両方を事前登録し、両方を出す。**

| ID | 窓 | 刻み | 役割 |
|---|---|---|---|
| **W-wide** | `[B+1, B+2000]` | 毎 step 100 点 ＋ 粗点 2 点（B+1000, B+2000） | **主判定**。スモークと同じ窓定義を維持する |
| **W-narrow** | `[B+1, B+100]` | 毎 step 100 点（厳密） | **副次**。刻みの粗さを含まない対照 |

- 積分は**台形則**。W-wide では `(B+100, B+2000]` の 2 点が窓の時間長の 95% を代表する
- 利用可能な粗点だけを使った台形推定では、`(B+100, B+2000]` が積分に占める割合は `|F_self|` **94.7%** / `|F_rest|` **94.0%**（この推定自体が同じ粗さの制約を受ける）
- **差の解釈を書かない。** W-wide と W-narrow は別の量であり、どちらかが「正しい」わけではない

## 4. 識別限界（先に書く）

1. **W-wide の 95% は 2 点で代表される。** 主判定の点推定は刻みの粗さに支配される。CI は seed 間のばらつきのみを反映し、**この離散化誤差を含まない**
2. **§5 の窓外積分は粗いグリッド（Δ=1000）でしか計算できない。** スモークの窓内/窓外比較と同じ精度にはならない
3. **スモークとの直接比較は窓定義が同じ W-wide のみ**で成り立つ。ただしスモークは R=8・100k step・9 境界、本番は 10 seed・1M step・99 境界で、母集団が違う
4. **再分類死は窓の左端で既に死んでいる。** 境界ペア (B, B+1) で死ぬので、窓 `[B+1, …]` の積分はゲート閉鎖後の値になり、構造的にほぼゼロになる。これは**バグではなく群分けの目的そのもの**であり、`中和と境界窓.md` §7 の留保（「再分類死は積分がほぼゼロなので died 群の税・稼ぎが小さい一因かもしれない」）を定量化する
5. **`events.csv` の来歴**。§6 S4 と §9 を参照

## 5. 判定基準（事前登録・commit 前に固定）

`中和と境界窓.md` §4・§5 と同じ項目集合を、**全群 / 輸送死 / 再分類死 / 生存**の 4 列で出す。CI は全て seed 単位ペアブートストラップ。

| ID | 統計量 | 群 | 基準 |
|---|---|---|---|
| **L1** | **主判定**: 死亡個体のうち窓内正味が下向き（∫F_gate < 0）のものについて、`∫F_self / ∫F_gate` の**中央値** | 全群 / 輸送死 / 再分類死 | **判定なし・点推定と CI を報告**。スモーク値 **0.245** を併記する。輸送死群の値が「群分けをしても税が主役にならない」ことを示すかを見る |
| **L2** | 死亡個体のうち窓内正味が下向きの割合 | 同上 | 報告のみ（スモーク 0.683） |
| **L3** | ∫F_self / ∫F_rest / ∫F_gate の**平均** | 死亡 4 群 / 生存 | 報告のみ（スモーク: 死亡 −0.016 / −0.015 / −0.055、生存 −1.66 / +1.65 / −0.028） |
| **L4** | 死亡個体のうち**稼ぎ自体が負**（∫F_rest < 0）の割合 | 同上 | 報告のみ（スモーク 0.538） |
| **L5** | 死亡個体のうち「**稼ぎを失って税に沈んだ**」（∫F_rest ≥ 0 かつ ∫F_gate < 0）の割合 | 同上 | 報告のみ（スモーク 0.145） |
| **L6** | 生存個体の**タスク残り区間** `[B+2000, B+10⁴)` の ∫F_self / ∫F_rest | 生存 | 報告のみ（スモーク −9.50 / +9.39）。粗いグリッドで積分する（§4-2） |
| **L7** | 窓内 / 窓外の Σ F_gate・Σ F_self と、正味が負の割合 | 全対象 | 報告のみ（スモーク: 窓内 −0.076 / −5.71 / 0.568、窓外 +0.000 / −48.19 / 0.465） |
| **L8** | 正味変位に占める窓内の割合 | 全対象 | 報告のみ（スモーク 0.375） |

**L1〜L8 のすべてを W-wide と W-narrow の両方で出す。** L1 のみ主判定として `verdict.csv` の先頭に置く。

**判定を置かない理由**: Q2b の証拠欄は既に「棄却寄り」で確定しており、本 spec の役割は数値の格上げ（CI を付け、群別に分ける）であって、新たな採否判定ではない。`命題リスト.md` の運用メモに従い、**null 結果も同じ形式で報告する**。
