## 0. 一行

死（p̂ の 0.05 下抜け）を、境界の実効閾値ジャンプによる **再分類死** と、タスク内の力による **輸送死** に記録構造から一意に分離し、分離後に P3（単調輸送）と E1（駆動分解）を再判定する。

## 1. 背景 — なぜ他の解析より先か

由来: 台帳スモークの副産物（vault: 台帳（実効バイアスの縮退）§5）。1 境界あたり alive 582 個中 31 個（5.3%）が再分類死、dead 218 個中 36 個（16.5%）が再点灯。**R=8・100k step のスモーク**。

混在の危険は「死の分類が曖昧になる」ことではなく、**cos(u, µ̂) を基準にした量が境界で意味を変える**ことにある。µ̂ は flip_state から決まるので境界で跳ぶ。したがって境界を跨ぐ Δcos は輸送ではなく**座標の張り替え**である。既出数値のうち何が汚染され得るかを先に切り分ける:

| 既出数値 | 基準量 | 混在の影響 |
|---|---|---|
| P3 median PE 0.3959 | cos の増分 | **要再計算**（降下窓が境界を跨ぐと張り替えを輸送として数える） |
| E1 rest 符号安定率 0.806 / 比 0.6176 | 降下ユニットの µ̂ 射影 | **要群別再計算**（「降下」の定義が cos 経由） |
| E1 self 符号安定率 1.000 | 同上 | 構造的（Q2 の定理）なので群に依らず 1.000 のはず → S3・D3 の検算に使う |
| P4-mech 0.3153 / P4-move 0.7651 | **‖w‖ の変位** | 影響なし（µ̂ の跳びは w を動かさない）。再計算しない |
| 力の台帳（Q2b スモーク、中和 99.5% / 税寄与 24.5%） | 死亡個体の積分 | **要組み直し**（別 spec。本 spec は群ラベルを供給するところまで） |

現論文での役割は防衛に限る。**機構（なぜ跳ぶか＝台帳の縮退）は次論文**（vault: 論文スコープ分離）。本 spec から現論文へ渡すのは「境界で各ユニットの発火閾値が離散的にずれる」の一文と、群別に組み直した P3・E1 の数値のみ。

## 2. 記録構造 — 本解析が成立する理由（構造確認済み、seed 0）

- 記録点: バルク 1000 step 毎 ＋ 各境界の ±100 step を毎 step。seed あたり 20,901 点（うち 1 step 刻み 19,900 点）
- flip は **step ≡ 0 (mod 10⁴) の記録点とその次（+1）の間**で起きる（seed 0 で 99/99。全 seed の検証は S2）
- **粗い区間（1000 / 900 step）は flip を跨がない**（唯一 (0, 1000) だけが step ≡ 0 を含むが、ここに flip イベントは無い）
- → 隣接記録ペアは「**境界ペア** (B, B+1), B ≡ 0 (mod 10⁴)」か「**µ̂ 固定ペア**」に**排他的に分類できる**。打ち切りが生じるのは死亡時刻の分解能だけで、**経路の分類には生じない**
- 保存量: `step, cos_u_mu, p_hat, w_norm, b, v, F_self, F_rest, F_gate, G, flip_state, E_delta, mu_norm, ratio_mu_cov, cos_G_mu, G_dot_mu, eval_loss_exact`。**w の座標は保存されていない** → b_eff ジャンプ ±w_ik は直接計算できない（§4）

## 3. 定義（事前固定）

- alive / dead: p̂_i ≥ 0.05 / p̂_i < 0.05（teachw_0820 と同規約）
- **死亡イベント**: 隣接記録ペア (t_n, t_{n+1}) で p̂_i が閾値を上から下へ跨ぐこと
- **再分類死**: 死亡イベントのペアが境界ペアであるもの
- **輸送死**: それ以外（µ̂ 固定ペア）。時刻分解能は窓内 1 step / バルク 1000 step
- **再点灯**: 下抜け後に p̂ ≥ 0.05 へ戻ること
- **恒久死**: 初回下抜け以降、1M step まで再点灯しないこと
- ユニット単位の群ラベルは「**恒久死をもたらした死亡イベント**」で代表させる（恒久死に至らないユニットは group=alive）。イベント単位の集計とユニット単位の集計を混ぜず、両方を別表で出す

## 4. 識別限界（先に書く）

1. 境界ペアでは (i) µ̂ の張り替えと (ii) 1 step 分の SGD が同時に起きる。(ii) の大きさは**同一窓内の非境界ペア**の分布が経験的な上限を与える（対照が実データの中にある）
2. w の座標が無いので「輸送ゼロ」は ‖w‖ の変位と上記の窓内対照で示す。**厳密なゼロは主張しない**
3. µ̂ 固定ペアの Δcos は純粋な輸送、境界ペアの Δcos は純粋な張り替え（＋1 step 分の SGD）。この分割は記録構造から厳密で、推定を含まない
4. 死亡時刻の分解能が群で非対称（再分類死は必ず 1 step、輸送死はバルクだと 1000 step）。**時間あたりのハザード・t50 を群間で比較しない**（S4）

## 5. 判定基準（事前登録・commit 前に固定）

| ID | 予測 | 統計量 | 基準 |
|---|---|---|---|
| **D0** | 前提ゲート: 二経路がともに非自明に存在する | 恒久死に占める再分類死の割合 r（seed bootstrap CI 付き） | 0.10 ≤ r ≤ 0.90 で D1–D3 へ進む。**r < 0.10 なら「実質単一経路（輸送死）」として Q16 を弱め、分離は不要と結論**（＝既出数値はそのまま救われる）。r > 0.90 なら逆に輸送死が実質不在で、部品 2・P3 の描像そのものを再考 |
| **D1** | 再分類死は輸送を伴わない | 境界ペアでの \|Δ‖w‖\| の中央値 vs 同一窓内の非境界ペアの \|Δ‖w‖\| 分布 | 中央値が非境界ペア分布の 95 パーセンタイル以下。FAIL なら「1 step でゲートが閉じる」の描像が壊れるので、再分類死の定義から作り直す |
| **D2** | **主判定**: P3 は混在アーティファクトではない | 輸送死のみ・µ̂ 固定ペアの増分のみで PE を再計算し、median PE と帰無分布を比較（帰無は spec_ratchet_log_0819 P3 と**同一の**符号置換 null、窓ごと 1000 回） | median PE > 帰無 95 パーセンタイル。**FAIL なら「死亡は単調輸送」（Q4・論点マップ §0 部品）を撤回**する |
| **D3** | E1 の群別再計算 | self / rest の µ̂ 射影の符号安定率と比を、輸送死・再分類死・生存の 3 群別に | self の符号安定率は 3 群すべてで 1.000（Q2 の定理の帰結）。**崩れたら解析コードのバグとして扱い**、rest の群差の解釈に進まない |
| **D4** | 混在の量の評価（報告のみ） | 分離前後の median PE の差、境界跨ぎ増分が Σ\|Δcos\| に占める割合、群別のイベント数・恒久死数 | 判定なし |
| **D5** | 探索（判定なし・**追跡しない**） | 再分類死の再点灯率・恒久化率、死亡直前 p̂ の分布、群別の ‖w‖・\|v\| | 判定なし。Q10（停止条件）に接続しうるが、8/21 の線引きにより**記録に留める** |

## 6. サニティ（事前登録）

- **S1**: `OMP_NUM_THREADS=1`（規約統一）。numpy / python のバージョンを `meta.json` に記録
- **S2**: 境界インデックスを**ハードコードしない**。`flip_state` の差分から機械的に決定し、全 10 seed で「変化ペアの先頭が step ≡ 0 (mod 10⁴)」が 99/99 であることを確認。1 件でも外れたら中止して原因究明（オフバイワンは 8/19b の既知の落とし穴）
- **S3**: **既出数値の再現を先に通す**。分離前の全体で P3 median PE = 0.39592990555641694（n_window=766、帰無 95%点 0.2177）、E1 self 符号安定率 1.0、rest 0.8059758、比 0.6176014 を `results/ratchet_log_0819/verdict.csv` と照合。再現できなければ解析コードのバグなので分離に進まない
- **S4**: §4-4 の分解能非対称を summary に明記し、時間ベースの群間比較を出力に含めない
