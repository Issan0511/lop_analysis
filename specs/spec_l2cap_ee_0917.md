## 0. 一行と問い

崩れる箱（RL・ELU→ELU）で、**W の成長への介入が第2層の輸送と応答を変え、崩壊を防ぐ**例はまだ無い。第1層の上限は崩壊を遅らせるだけだった（mucap_ee_0917）。affine なしの入力 LN は救ったが（l2_wall_0916）、それは $\|\mu_2\|$ の伸びへの介入で、W の成長への介入ではない。

- **Q1（主）**: 第1層の成分上限（mucap_ee の cap_both）に、**第2層の各行のノルムの上限**を足す（cap12）と、第2層は床に落ちず、応答が ref より残るか。
- **Q2**: 第2層の上限だけ（cap2）では。第1層の上限だけ（cap1 = mucap_ee の cap_both の再走）では。
- **Q3**: cap12 に加えて両隠れ層の bias を task 1 終端値に固定する（cap12_bfix）と。cap12 が崩れたとき、担い手が bias か、残りの経路（壁の距離・向きの揃い）かを分ける。
- **Q4（機構・報告のみ）**: 輸送 $\bar z_2=q_2\|\mu_2\|+b_2=\|w_2\|\cos(w_2,e_2)\|\mu_2\|+b_2$ のどの因子が動いたか。崩壊の時刻は $\bar z_2$ が訓練の微分の零点 $\ln 2^{-24}=-16.64$ を越える時刻と一致するか。

## 1. なぜ（既存データ・REPORT_ONLY・登録判定ではない）

### 1.1 mucap_ee_0917 の第2層の分解（10 seed 平均・タスク終端・記録の units.npz から事後）

$\bar z_2=q_2\|\mu_2\|+b_2$ は各点で残差 5e−5 以下で成り立つ（$q_2$ はその時点の $\mu_2$ 方向の成分）。

| 腕 | t | $\bar z_2$ | $q_2\|\mu_2\|$ | $b_2$ | $\|w_2\|$ | $\cos(w_2,e_2)$ | $\|\mu_2\|$ |
|---|---|---|---|---|---|---|---|
| ref | 5 / 10 / 100 | −8.3 / −50.9 / −152.9 | −8.3 / −50.8 / −152.8 | −0.04 / −0.11 / −0.13 | 3.0 / 3.9 / 4.1 | −0.16 / −0.20 / −0.19 | 17.8 / 69.6 / 202.7 |
| cap_both | 10 / 14 / 20 / 100 | −10.8 / −16.7 / −28.6 / −79.1 | −10.3 / −16.2 / −28.1 / −78.5 | −0.40 / −0.47 / −0.55 / −0.61 | 5.2 / 6.0 / 6.7 / 7.0 | −0.30 / −0.33 / −0.36 / −0.37 | 6.7 / 8.3 / 11.7 / 30.7 |
| cap_perp | 10 / 14 / 100 | −8.3 / −14.7 / −136.3 | −8.3 / −14.7 / −136.4 | 0.00 / −0.02 / +0.05 | 4.1 / 4.9 / 6.4 | −0.15 / −0.15 / −0.11 | 13.7 / 21.1 / 206.8 |
| cap_par | 10 / 20 / 100 | −34.1 / −82.8 / −152.1 | −33.5 / −81.9 / −151.1 | −0.61 / −0.90 / −1.01 | 4.3 / 5.1 / 5.6 | −0.39 / −0.45 / −0.46 | 19.8 / 35.5 / 58.9 |

- **輸送は全腕で重みの項が担い、$b_2$ は 1 以下。** ref は $\|\mu_2\|$ の爆発、cap_both は $\|w_2\|$ の成長（1.6 → 7.0）と向きの揃い（cos −0.37）で沈んだ。**第1層で $\|\mu_2\|$ を抑えても、第2層の行が 4 倍に育って同じ深さへ運んだ。**
- **崩壊の時刻と $\bar z_2\approx-16.6$ が重なる**: cap_both と cap_perp の $T_{1/2}$（中央値 14.5・14）の t14 で $\bar z_2$ は −16.7・−14.7。この ELU 実装は float32 で $z<-16.64$ の訓練の微分が厳密に 0（resp_ee_0917 の発見）。
- 第2層の行の t1 終端のノルムは平均 1.61。$|q_2\|\mu_2\||\le\|w_2\|\,\|\mu_2\|$ なので、**$\|w_2\|$ を 1.61 に止めると、cap_both の $\|\mu_2\|$（t20 で 11.7・t100 で 30.7）のもとでは向きが完全に揃っても $|\bar z_2-b_2|$ は t20 で 19・t100 で 49 以下**。観測された最大の揃い（cos ≈ 0.46）なら 9・23。
- cap_both の $\|\mu_2\|$ の後半の伸び（t30 以降）は、第1層の bias が +4〜+6 に育って作った常時点灯ユニットによる（崩壊の後）。cap12_bfix はこの経路も塞ぐ。

### 1.2 同じ箱の下流側（resp_ee_0917）

崩壊した t10 の網に t2 の第2層の応答の場を戻すと次のタスクを 0.90 で学び（自然継続 0.14）、健康な t2 の網に t10 の場を渡すと 0.72 → 0.46 に落ちた（`RESPONSE_BOTH_WAYS`）。**本実験が救えれば、同じ箱で「W の成長 → 輸送 → 応答 → 学習能力」を一本につなぐ足場になる**（移植の当て直しは本 spec の範囲外）。

## 2. 設計

### 2.1 箱（mucap_ee_0917 と同一）

Random Label MNIST（1200 枚固定・画素/255・毎タスク一様乱数ラベル）、784–100–100–10、両隠れ層 ELU(α=1)、宿主の初期化、Adam lr 1e−3・β (0.9, 0.999)・ε 1e−8（moment はタスクをまたいで保持）、batch 16、6000 更新/タスク、**100 タスク**、seed 0–9、CPU 1 スレッド、`torch.set_flush_denormal(True)`、第1層の帳簿 off。

### 2.2 腕（5 腕 × seed 0–9 = 50 run）

| 腕 | 第1層（$\|q_i\|,\|v_i\|$ の上限） | 第2層（$\|w_{2,i}\|$ の上限） | bias |
|---|---|---|---|
| ref | — | — | 自由 |
| cap1 | あり（mucap_ee の cap_both と同じ） | — | 自由 |
| cap2 | — | あり | 自由 |
| **cap12** | あり | あり | 自由 |
| cap12_bfix | あり | あり | **$b_1,b_2$ を task 1 終端値に固定** |

- 半径はすべてその run 自身の task 1 終端値。task 2 の最初の更新から、各 Adam 更新の直後に、第1層の上限（平行 → 直交）→ 第2層の行ノルム上限 → bias の書き戻しの順で適用する。
- **第2層の上限**（`src/l2cap_ee_0917.cap_row_norm_`）: $\|w_{2,i}\|>r_i$ の行だけ $w_{2,i}\leftarrow w_{2,i}\,r_i/\|w_{2,i}\|$（向きを保つ）。上限以下の行は 1 bit も書かない。小さい行を膨らませない。第2層の bias・第3層・moment は触らない。
- **bias の固定**: 各更新の後に $b_1,b_2$ を task 1 終端値へ書き戻す（Adam の moment は触らない）。
- 第3層（$W_3,b_3$）は全腕で自由。
- cap1 と ref は mucap_ee_0917 の cap_both と ref と同じ呼び出しで、task 1–2 の記録と bit 一致することを S0b で確かめた。全 100 タスクの一致は本走後に報告する（判定には使わない）。

### 2.3 全腕で同一であるべきもの（S5）

seed ごとに init・subset・全ラベル・全標本順・task 1 終端の状態の sha256。

## 4. endpoint

### 4.1 主 endpoint と床（mucap_ee_0917 と同じ。E2 だけ訓練の微分に替えた）

**主窓 $W$ = task 51–100**。形成窓 task 2–10・11–50 は副報告。

- **E1（機能）**: online 精度の窓内タスク平均 − task 1 の online。
- **E2（第2層の応答）**: 第2層の**訓練の微分** `dtrain_mean_l2` を「画像平均 → 全 100 ユニットの算術平均 → 窓内タスク終端の算術平均」、task 1 からの変化。
- 腕の効果は seed 内の対応差 $\delta=\Delta_{\mathrm{arm}}-\Delta_{\mathrm{ref}}$。
- **床**: run ごとに主窓の `major_frac` の平均 $F$ と標本 SD $s$ から $F+3s/\sqrt{50}$。主窓の online 平均がこれ以下なら AT_FLOOR。腕は全有効 seed で AT_FLOOR なら FLOORED、全 seed で上なら ALIVE、割れたら SPLIT。

### 4.2 副 endpoint（判定の代用にしない。1 は §5.3 の時間ラベルに使う）

1. **崩壊の時刻 $T_{1/2}$**: 適合率 $(A(t)-0.1)/(A(1)-0.1)$ が task 2 以降で初めて 1/2 を下回るタスク（右打切り）。
2. **輸送**: 主窓の第2層 $\Delta\bar z_2$ と $\Delta b_2$ の、ref との対応差（95% 区間）。$\bar z_2=q_2\|\mu_2\|+b_2$ の重みの項（`q_l2`×`mu2_norm`）の水準。
3. **零点を越える時刻**: 第2層のユニット平均 $\bar z_2$ が初めて $\ln 2^{-24}=-16.64$ を下回るタスク（報告のみ）。§1.1 の「崩壊の時刻と零点」の読みを、本走の全 run で $T_{1/2}$ と並べる。
4. **第2層の幾何と経路**: $\|\mu_2\|$、$c_2=\|\mu_2\|/\mathrm{sd}(e_2^\top a_1)$、$d_2$、$\sigma_2$、$\|w_2\|$、`dtrain_zero_l2`、解析的な $e^z$ のゲート、吸収（$U_2<0$ が 5 タスク連続）。
5. **$\|\mu_2\|$ の担い手**: 第1層の常時点灯ユニットの割合と $\|\mu_2\|^2$ の占有。
6. **第1層**: 訓練の微分・$d_1$・$\sigma_1$・$\|v\|$・$q$。FLOORED の腕では凍っているので腕間の機構比較に使わない。
7. **性能**: online・`memo_acc` の窓平均。

## 5. 判定

### 5.1 帯の算術

主 2 endpoint それぞれで、有効 seed の $\delta$ の平均・SD・**97.5% 対応差 t 区間**（2 量の Bonferroni）。95% も併記。SD = 0 なら実測の同一差。符号は区間の下端 > 0 で +、上端 < 0 で −、それ以外 0。t 分位点は 0916 の実装（公表表と 1e−6 で照合）。

### 5.2 適用条件

- **(A)** 全 seed で 5 腕の task 1 終端 sha256・ラベル・標本順が一致、100 タスク完走、online と両層の微分診断が有限。有効 seed 8 未満なら全ラベル INAPPLICABLE。
- **(B)** ref が有効 seed の 8 割以上で主窓 AT_FLOOR、かつ ref の $\Delta E2$ の 95% 区間の上端 < 0。満たさなければ全ラベル NOT_REPRODUCED。
- **(C)** 各介入腕・各有効 seed で、task 2–10 の全タスクについて、その腕の介入の記録（cap1: `rows_par`・`rows_perp`、cap2: `rows_w2`、cap12: その 3 つ、cap12_bfix: その 3 つと `rows_bfix`）が > 0。満たさない腕は INAPPLICABLE。

**IMPAIRED**（読みのフラグ・判定を変えない）: 介入腕の task 2–5 の平均適合率が「ref の値 − (1 − ref の値)」を下回る seed が過半数。上限で学べなくなって「崩壊しない」ように見える腕を区別する。

### 5.3 ラベル

**主 = cap12 − ref（97.5%）**。cap1・cap2・cap12_bfix − ref は 95%。cap12 − ref の 95% も参考に出す。

| 腕の床の状態 | $s_{E1}$ | $s_{E2}$ | ラベル |
|---|---|---|---|
| FLOORED | — | — | **COLLAPSED** |
| SPLIT | — | — | **SPLIT** |
| ALIVE | + | + | **RESCUED** |
| ALIVE | + | 0 / − | RESCUED_FUNCTION_ONLY |
| ALIVE | 0 / − | — | ALIVE_UNRESOLVED |

(A)/(C) を満たさなければ INAPPLICABLE、(B) を満たさなければ NOT_REPRODUCED。**時間**: 各介入腕の $T_{1/2}$ を seed ごとに ref と比べ（打切りは観測されたどの時刻より遅い）、同じを除いた数で両側の正確な符号検定、p < 0.05 で EARLIER / LATER、それ以外 NO_TIMING_DIFF。交互作用 $\delta_{\mathrm{cap12}}-\delta_{\mathrm{cap1}}-\delta_{\mathrm{cap2}}$ を 95% で報告。

### 5.4 読み方（登録）

- **cap12 が RESCUED** → この箱で初めて「W の成長への介入が輸送と応答を変え、崩壊を防いだ」例になる。§4.2-2 の輸送の差と、IMPAIRED でないことを併記する。次は同じ網に resp_ee_0917 の移植を当て、上流と下流を一本につなぐ（別 spec）。
- **cap12 が COLLAPSED か SPLIT** → V10 の「W 増大が崩壊を引き起こす」は担い手を限定して書き直す。
  - cap12_bfix が RESCUED → **bias が残りの経路**（第1層の bias による $\|\mu_2\|$ の伸びか $b_2$）。§4.2-2 の $\Delta b_2$ と §4.2-5 の担い手で、どちらの bias かを書く。
  - cap12_bfix も COLLAPSED → 重みのノルムも bias も止めたのに崩れる。**向きの揃いと壁の距離 $c_2$**（§4.2-4）を担い手の候補として書く。
- **cap2 が RESCUED、cap1 が COLLAPSED** → 第2層自身の成長を止めるだけで足りる。第1層の $\|\mu_2\|$ の爆発は、止めた $\|w_2\|$ の下では崩壊を運べない。
- **cap2 が COLLAPSED、cap12 が RESCUED** → 上流と自己の両方を止める必要がある（交互作用で確かめる。単独腕の未決を「両方必要」とは書かない）。
- IMPAIRED の腕では「可塑性を守った」と書かない。上限で学習そのものを止めた可能性として書く。
- RESCUED は「この箱で 100 タスク床に落ちなかった」であり、無限時間の非崩壊ではない。
- §4.2-3（零点を越える時刻）は報告のみ。一致しても「訓練の微分の零点が崩壊を決める」の証明とはしない。
- すべて「この ELU→ELU・乱数ラベル・6000 更新・task 2 開始・task 1 終端の半径・100 タスク」に限る。

## 8. 費用と実行

- S-cost（cap12_bfix・6 プロセス同時・2 タスク）の 1 更新あたりの時間に、mucap_ee_0917 の flush パイロットの伸び（退避したログから計算・sha256 照合）を掛けて 100 タスクへ投影する。mucap_ee_0917 の実測は 1 run 7–15 分・40 run で 1 時間 19 分（6 並列）だったので、50 run で 2 時間前後を想定する。
- **S-cost 実測（登録前・別セッションの 6 ジョブが走っている負荷の下）: 1.31 ms/更新 → 1 run 22 分（伸び 1.69 倍込み）、6 並列で 3.1 時間**、peak RSS 1.34 GiB。
- 並列数は min(MAX_SLOTS, S-cost のスロット, 起動時の空きメモリで収まる数)。4 未満なら起動しない。**登録時点で別セッション（swish_battle_0917）が 6 ジョブ・swap 5 GB を使っているので、MAX_SLOTS=4 で起動する**（4–5 時間を想定）。キューは seed 順（seed 0 の 5 腕 → seed 1 …）。`provenance.json` のある shard は飛ばす。
- 起動は本 spec の登録 commit を runner に書き込み、全検査を再実行して all_pass になってから。
