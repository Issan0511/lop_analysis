## 1. 動機 — なぜ作業2 H では閉じないのか

作業6 は「高 `ΔL` 群ほど凍りにくい」（調整 RD **−0.2353 [−0.2812, −0.2325]**、PROTECTIVE）を出した。当然出る反論は:

> **その効果、`r`（µ̂ 直交成分＝背の高さ）の言い換えではないのか。**

`xr分解と生存機構_0822` §17 で `r` は「出力を作っている成分」と同定されており（`Spearman(reach, r) = +0.73`）、`ΔL` が高いユニットは `r` も大きいと予想される。作業6 は exact `p_count` × `pre_max` 五分位で**壁までの距離**を揃えているが、**`r` そのものでは層別していない**。

### 1.1 作業2 H は代替にならない（8/24 に spec を読んで確認）

一見、作業2 H（`r` 三分位 → 消灯）が INCONCLUSIVE だったので「`r` は関係ない」と読めるが、これは**誤読**である。`specs/spec_function_blind_0823.md` を確認した結果:

| | 作業2 H | 作業6 |
|---|---|---|
| 起点 | `t0 ∈ {200k, 300k, 400k, 500k, 600k}`（5 ランドマーク） | `t0 = B+1`（61 タスク全部） |
| **追跡窓** | **`(t0, t0+300000]` = 300k step ≒ 30 タスク** | **`t0 → t0+10000` = 1 タスク** |
| 層別 | `p_hat` × `x` の 3×3 三分位 | exact `p_count` × `pre_max` 五分位 |
| `r` の測定時点 | **各 t0 で切り直し**（L57）。**古い値ではない** | — |
| 転帰 | `any_hit` / `end_dead_0.05` | `end_strict_dead` |

- **`r` の測定時点は問題ではなかった。** 各 t0 のリスク集合で三分位を切り直しており、陳腐化していない
- **真の原因は追跡窓が 30 倍長いこと。** `any_hit` は 1.000 / 0.997 / 0.995、`end_dead_0.05` 占有率は 0.905 / 0.919 / 0.898。**どの群も 9 割以上が死に切っており、天井で差が消えている**
- したがって H の null は「`r` は死と無関係」の証拠ではなく、「**窓が長すぎて全員死んだ**」の記録である。**`r` は per-task ハザードの土俵では未測定**

### 1.2 これは作業6 と作業2 O の両立説明とも同型

per-task ハザードでは選抜が効くが、終点構成では効かない（誰が死ぬかではなく、いつ死ぬかに効く）——これは `機能盲目性_0823` の O と作業6 が衝突しない理由と**同じ構図**である。H の天井は失敗ではなく、この構図の別の現れとして読める。

## 4. 群と層別

### 4.1 幾何セル（作業6 と厳密に同一）

`cell = t0 × p_count × margin5_bin`。`p_count := round(32*p_hat)` で完全層別し、各 `t0 × p_count` 内で `pre_max` を五分位（cut = `np.quantile(v,[0.2,0.4,0.6,0.8])`、`bin = searchsorted(cuts, value, side='left')`）。**作業6 の `cell_id` をそのまま使う。**

### 4.2 追加層

検出力を保つため、追加層は**三分位ではなく中央値分割**とする（三分位ではセルが痩せる）。

- `r_half`: 各幾何セル**内**で `r` の中央値分割（同値は上位側へ）
- `u_half`: 各幾何セル**内**で `utility_nmse` の中央値分割（同値は上位側へ）

### 4.3 有効セル規則

作業6 の `primary_cell_valid` と同型: 比較する 2 群の**両方**に 1 曝露以上あるセルのみ採用。

## 7. 判定基準（**結果を見る前に凍結**）

### 7.1 R1（主判定）— `ΔL` は `r` の言い換えか

| 条件 | 判定 | 含意 |
|---|---|---|
| 調整 RD の CI が 0 を含まず、点推定が **≤ −0.15** | **SPECIFIC** | `ΔL` は `r` に還元されない固有の効果。候補 (a)（需要側 `F_rest`）が残る |
| CI が **[−0.05, +0.05] に完全に収まる** | **REDUCIBLE** | `ΔL` 効果は `r` で説明される。候補 (b) 採用、新機構は不要 |
| 上記いずれでもない | **INCONCLUSIVE** | 判定保留。追加層別では閉じない |

規則順: `SPECIFIC > REDUCIBLE > INCONCLUSIVE`（重複しない設計だが明示する）。

### 7.2 R2（副次判定）— `r` 自体の保護効果

- CI が 0 を含まず負 → `r` にも保護効果あり（両方効く。§8 の同時モデルへ）
- CI が [−0.05, +0.05] に収まる → `r` は per-task ハザードでも効かない。H の null が窓長のせいだけでなく実質的でもあったことになる
- それ以外 → INCONCLUSIVE

### 7.3 検出力ガード（事前登録）

- **G1**: R1 の有効セル保持率が、作業6 主解析の有効曝露数（`n_low = 5023`, `n_high = 4431`）に対して **40% 未満**なら、R1 は **記述的扱い**とし判定に用いない
- **G2**: R1 の CI 半幅が **0.10 を超えたら** INCONCLUSIVE を上書きせず、「精度不足」として別ラベルで記録する
- どちらのガードが立っても、**R を追加したり層別を緩めたりしない**（結果を見てからの設計変更を禁じる）

## 8. 事前に決めておく分岐

- R1 が SPECIFIC かつ R2 も有意 → `ΔL` と `r` の**同時**効果。この場合のみ、追加で `cell_id × r_half × u_half` の 2×2 記述表を出す（**判定には使わない・記述のみ**）
- R1 が REDUCIBLE → `直接機能量による選抜確認_0823` の主張文に「効果は `r` に還元される」の但し書きを足す。**PROTECTIVE の判定自体は取り消さない**（転帰と方向は変わらない）
- いずれの場合も、`吸収不等式の命題化_0824` §5 の **κ（形状量）は本解析の対象外**。κ は保存されておらず、`w_free` の全成分が要る。κ を測るには再計装が必要 → 別 spec（未起票）
