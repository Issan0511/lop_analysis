## 2. 定義

- 層 ℓ の unit i の位置 m_i = w_i·ȳ_ℓ（bias なし）。ȳ_ℓ は FFN ℓ の入力（LN2 の出力 γ⊙x̂）の token 平均。probe は課題の鎖の probe（両端とも同じ probe で評価し、データの差を除く）。
- 窓: (i) 切替直後 100 更新（課題 t−1 末 → 課題 t 更新 100）、(ii) 課題の残り（更新 100 → 課題末）。課題 1〜10・40〜50・90〜100。加えて粗い窓 課題 10 末 → 25 末 → 39 末（L0 が沈む時期。交差項が大きいので報告のみ）。
- 分解（恒等式、残差を記録）: Δm_i = Δw_i·ȳ_a ＋ w_a,i·Δȳ ＋ Δw_i·Δȳ。どれも窓の始まりの幅 σ_a,i で割る。層ごとに unit の平均と、沈む unit（窓で Δm < 0）に限った平均。
- データの差: 同じ重みで、課題 t の probe と課題 t+1 の probe の m_i の差（Δμ/σ）。
- 上流の項の尺度: 窓ごとの |w_a·Δȳ| の unit 中央値と、‖w_a‖ の unit 中央値、‖Δȳ‖。比 |w·Δȳ| / (‖w‖‖Δȳ‖)（揃い）も出す。
- 回転: 課題ごとの cos(w_i^{(t)}, w_i^{(t−1)}) の unit 中央値（課題末どうし）。相対歩幅の代理として lr/‖w_i‖ の中央値。
- (B) 担い手の出所: ȳ₁ を残差の項（埋め込み・注意 0・FFN0・注意 1）の token 平均の LN2₁ 後の射影で割る（seed 1000 の方法と同じ。方法の正本は chargpt の quicklook の解析）。
- (C) 切替窓の分岐（別セッション）: 課題 t−1 末の checkpoint（重み＋Adam）から課題 t の 100 更新を再生。腕: 対照（元の走とビット一致を確認）、FFN0 の出力の共通成分（バッチの token 平均）を窓の始まりの値に固定、同じく注意 1 の出力の共通成分を固定。L1 の切替の変位 Δμ/σ と、その自分・上流の分を比べる。t ∈ {2, 3, 5, 10, 41, 45, 50}、seed 0〜9。

## 3. 予測（計算前・Opus 5.5。Issa の予測は「入力の変化 × 幅」）

- P-A1: C3-2 の L0 の課題の残りの窓（40〜50）で、沈み（負の量）の 6 割以上が上流（w·Δȳ）の seed が 8/10 以上。
- P-A2: |w·Δȳ| は ‖w‖ と一緒に伸びる。C3-2 の L0 で課題 90〜100 の |w·Δȳ| の中央値は課題 1〜10 の 2 倍以上、ReLUcap-2 では 1.3 倍以下（それぞれ 8/10 以上）。‖Δȳ‖ は腕で 1.5 倍以内。
- P-A3: 自分の項（Δw·ȳ）の窓 (ii) の平均は、cap と対照で差が小さい（cap − 対照 の中央値が +0.05 Δμ/σ 以内）。相対歩幅の読みなら cap の自分の項が上向きに大きく出る。
- P-A4: 課題ごとの回転 cos の中央値は、cap が対照より小さくない（1 − cos が cap で 1.2 倍以上大きい seed は 5/10 以下）。
- P-A5: データそのものの差は小さい（|Δμ/σ| の中央値 ≤ 0.1、両腕・全課題末）。
- P-B1: 課題 1〜10 の ȳ₁ に占める FFN0 の割合は 0.6 以上が 8/10 seed 以上。P-B2: 課題 90〜100 では 0.5 未満が 6/10 以上。
