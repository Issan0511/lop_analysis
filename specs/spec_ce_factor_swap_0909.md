# CE符号反転の要因交換 spec 0909
状態: 検証中 / 更新: 2026-09-09
親: [[タスク20から40の切替直後勾配と下降寄与_結果_0909]] / [[セッション引き継ぎ_0909_現在CE符号反転]]
Issa依頼「上向きだった現在CEの寄与が、何の変化によって下向きになるのか切り分ける方法」。boundary_tasks20_40_0909 の保存済み境界状態を再利用する**診断走**で、新規学習も新規軌道も作らない。加法的な寄与分解であり、因果的必要性の証明ではない。

## 対象と再生
run: ce_factor_swap_0909。source は `results/boundary_tasks20_40_0909/source/{ARM}_{iv}_s{seed}_states.pt` をそのまま読む（再生成しない・SHAをbackup_manifestと照合）。ARM=LR/SNA、iv=none/l2、seed=0..2 の12腕seed、各 task21..40 の20境界。優先解釈対象は素LR、SNAとl2は比較。
各境界で `before` 状態・`adam_before`・`rng_after_perm` から**更新1..40**を元と同じ層化抽出・バッチ順・coupled L2・Snake EMA順序で再生する。前回は20更新までだったので20を超える区間はここで初めて計装する。窓は {1}{2..5}{6..10}{11..20}{21..30}{31..40} を事前固定。窓は固定境界で、極値を選ぶ操作はしない。

## 固定診断集合（案A）
学習ミニバッチの抽選とモデル状態の変化を分けるため、各境界で**同一の診断集合**上の CE 勾配を毎更新計算する。診断集合は当該タスクの `order` 末尾512標本（`xs[-512:]`、更新1..40が使う先頭640標本と交わらない）。64標本×8ブロックに分け、ブロック間の一致を頑健性として報告する。診断計算はパラメータ・Adam・SnakeのEMA/alphaを一切更新しない。乱数も追加消費しない。
評価は既存と同じ固定probe（seedごとtest512・同一置換）の平均入力 μ への射影 Δz̄_i = ΔW_i·μ + Δb_i。**勾配を生成する集合（診断512）と Δz̄ を評価する probe（test512）は別物として常に書き分ける。**

## 分解の恒等式
第1層について標本s・ユニットiの CE 寄与を
 δ_{s,i} = (1/B_d) · g_{s,i} · Σ_k J_{k,i}(s) r_{s,k},  g=φ'(z1), J_{ki}=Σ_j W3_{kj} φ'(z2_{s,j}) W2_{ji}, r_s=softmax(logit_s)−onehot(y_s)
とし、観測済み Adam 係数 C^W_i, C^b_i（= −lr/(1−β1^t)/(√(v_t/(1−β2^t))+ε)）から受け手重み
 w_{s,i} = Σ_j C^W_{ij} x_{s,j} μ_j + C^b_i
を作る。現在CE寄与の射影は厳密に
 Δz̄^{CE}_i = (1−β1) Σ_s δ_{s,i} w_{s,i}
に (s,i) 分解される。x≥0・μ≥0・C<0 より w<0 は常に成り立つので、符号は δ の重み付き和の符号の反転である。
**この量は過去の一次モーメントを分離した現在CE分であって、Adam非依存の生勾配ではない。** v_t には現在勾配も履歴もl2も入る。

## 上押しと下押し（案B）
t_{s,i}=(1−β1) δ_{s,i} w_{s,i} を符号で分け、U=Σ_{t>0} t、D=Σ_{t<0} |t|、net=U−D。各更新でU・D・netを記録し、Δnet=ΔU−ΔD を分解する。判定は事前固定で **|ΔU|>2|ΔD| なら U_DOMINANT（上押しの消失）／|ΔD|>2|ΔU| なら D_DOMINANT（下押しの増大）／それ以外 BOTH**。「下向きの力が生まれた」を先に仮定しない。
切替直後（更新0）の診断標本のz1符号で (s,i) を固定分類した群別のU・D・netも保存する。現在時点の符号による分類は副測定。**受け手側の固定正負マスクと混同しない。**

## 要因交換（案C）
入力（診断512）とprobeを固定し、状態Aと状態Bの間で4要因 {r, J, g, D} を交換した全16セルを再計算する。
- 状態対は事前固定で2組: **(A,B)=(更新1, 更新15)** を主、**(更新1, 更新40)** を副。どちらも結果を見る前に固定し、事後に別の更新へ動かさない。
- J は W2・W3・φ'(z2) の3つから成る。主表の後に **gate2 のみ交換 / (W2,W3) のみ交換** の副分解を回す。SNAでは g・gate2 に alpha が入るので **alpha のみ交換** も副分解に入れる。
- Adam 分母は交換時に**観測済みの値を独立の固定因子**として扱う。交換後の仮想勾配で分母を再計算しない（それは別実験）。正スカラーの bias correction は符号を変えないが、定義は全セルで統一する。
- 交換したセルは実在するネットワーク状態とは限らない。

### 判定規則（事前登録）
セル値 N(X_r,X_J,X_g,X_D) = 境界内の net（ユニット平均）→ seedごと20境界の中央値。3 seed すべてで同符号のときだけラベルを付ける。CI・有意差は出さない。
- SUFFICIENT(F): F だけ B、他は A で、N が N(A,A,A,A) と逆符号
- NECESSARY(F): F だけ A、他は B で、N が N(B,B,B,B) と逆符号
- ちょうど1つの F が両方 → `SINGLE_FACTOR_<F>` / 2つ以上 → `MULTI_FACTOR` / 0 → `INTERACTION_ONLY`
- **進捗ゲートG1**: 素LRの診断集合上の現在CE net が更新15で3 seedとも負にならなければ、符号反転は学習ミニバッチの抽選側の性質である。その場合の主判定は `BATCH_LOTTERY` とし、16セル表は記述として残すが機構の結論には使わない。読み替えて別の主張にしない。

### 併走する比較（案A由来）
同じ診断勾配について、(1) 実際のAdam倍率、(2) 更新1で凍結した座標倍率、(3) 生CE勾配の同一方向への射影（−lr·g、SGD方向）の3通りを毎更新記録する。倍率を固定しても反転するかで D の寄与を独立に見る。

- 反証されうる形: r を A に戻しても負のままなら r は必要でない。

## 検算と変異対照
すべての検査に**変異対照**を付け、対照が実際に検査を落とすことをアサートする（空虚な検査を6回作った履歴があるため）。
1. δ の解析式 = autograd の dL/dz1（許容 1e-7）。対照: g を +0.1 した式で > 1e-5 になること。
2. (s,i) 和 = パラメータ空間からの射影（許容 1e-12）。対照: r を1.01倍して > 1e-9。
3. 40更新の再生 probe 平均 = source の `dense1`（許容 2e-5）。対照: W1[0,0] に 1e-3 を足した再生で > 1e-5。
4. 16セルの対角 (A,A,A,A)・(B,B,B,B) = その更新で記録した診断 net（許容 1e-12）。対照: 単独交換セルが対角と異なること。
5. U − D = net（許容 1e-15）。対照: U の符号条件を反転した集計が一致しないこと。
6. 追加の診断 forward が学習側の勾配・パラメータ・Adam・EMA を変えないこと（各腕 seed0 の初境界で差 0）。対照: 診断側で act.update を呼ぶ変異が再生を壊すこと。
失敗は隠さず停止する。
