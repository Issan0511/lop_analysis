## 0. 一行

`act_offset_0906` の事後の読み「**井戸の底（φ+c=0 の点）が、そのユニットの支持と同じ線形領域の中にあるときだけ、ユニットはそこに正確に座る。無ければ折れ目へ引かれ、ラチェットが押し返して釣り合う**」を、(1) 傾き a を変えて底 −c/a を動かし、(2) v を凍らせて経路を切り、(3) 雑音を消し、(4) c を細かく振って、事前に予測を書いてから試す。あわせて (5) 幅（‖w_free‖ の成長）が a・v・雑音・c にどう追随するかを同じログから読む。

## 2. 判定（ブロック 1・2 のみ）

**ブロック 1（`SEAT_TRACKS_WELL`）**: c=+0.5 の 4 腕について、「下」群の z̄ 中央値と −c/a（−2.5 / −1.67 / −1.0 / −0.71）の差の CI が **±0.3 に内包**される腕の数 k。
- `SEAT_TRACKS_WELL`: k = 4
- `SEAT_TRACKS_WELL_SHALLOW_ONLY`: k ≥ 2 で、外れるのが a ≥ 0.5 の腕だけ（底が折れ目に近く、上の枝の底 −c=−0.5 と融合する）
- `SEAT_OFF_WELL`: k ≤ 1
- `NOT_DETERMINED`: 発散 3/10 超・未定着・「下」群が 20% 未満の腕が 2 本以上

**ブロック 2（`C_VIA_V_ONLY`）**: v 凍結下の Δz̄(±0.5) = 腕 − `LRvf1`（ユニット対応・両腕 ALIVE）。
- `C_VIA_V_ONLY`: ±0.5 の両方で Δz̄ の CI ⊂ [−0.5, +0.5] かつ Δzmax の CI ⊂ [−0.3, +0.3]
- `C_NOT_ONLY_VIA_V`: どちらかで CI が 0 を外す（→ c は v 以外の経路でも z̄ を動かす＝私の勾配の帳簿が間違い）
- `NOT_DETERMINED`: 発散・未定着・`LRvf1` の unfit が act_offset の `LRoff0` の 80 倍超（edge_law 5-c と同じ足切り）
