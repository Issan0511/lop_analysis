## 2. 何が理論的に未決か

### 2.1 ELU は正斉次でない（Q1 の根）

ReLU の比が定数なのは `ReLU(cz) = c ReLU(z)`（正斉次）だから。ELU は負側が `alpha*(e^z - 1)` で `-alpha` に床打ちするので正斉次でなく、比が事前活性のスケール `s = sd(z)` に依存する。`z ~ N(0, s^2)`、`alpha = 1` のとき

```
E[phi]   = s/sqrt(2*pi) + exp(s^2/2)*Phi(-s) - 1/2
E[phi^2] = s^2/2 + exp(2*s^2)*Phi(-2s) - 2*exp(s^2/2)*Phi(-s) + 1/2
g(s)     = E[phi] / sd(phi)

g(0.35) = 0.08   g(1) = 0.20   g(2) = 0.33   g(4) = 0.45   g(inf) = 0.684
```

**ELU が µ を消せるのは `s` が小さい範囲だけで、`s` が育つと ReLU に漸近する。** 導出はチャット `elu_swamp_0830` の事後計算（未事前登録・引用不可）。数値は §5.1 の判定閾値の根拠としてのみ使う。

### 2.2 沈下は Σ を痩せさせずに µ を作る（Q1 のもう一つのレバー）

ReLU の凍結ユニット（`p_hat = 0`）は出力恒等 0 で、`mu^(2)` からも `Sigma^(2)` からも同時に消える。**ELU で全 32 パターン `z<0` に沈んだユニットは出力がほぼ定数 `-alpha` になり、`Sigma^(2)` には効かないまま `mu^(2)` に `-alpha` を寄与する。** つまり ELU には「沈下そのものが下流の µ を作る」という ReLU に無い経路がある。Clevert の「ELU は平均活性を 0 に寄せる」は生きているユニットについての言明で、この経路を排除しない。

> **格**: これは導出であって Clevert の主張ではない。チャット側の静的計算（commit 済み ckpt を反実仮想で ELU に通したもの）で符号は付いたが、**事後・未事前登録・学習なし**なので数値を引かない。

### 2.3 段差の壁 → 粘性の坂（Q2 の根）

1 step の壁座標の変化は活性化関数によらず

```
dz_i = -2*eta*delta*v_i*phi'(z_i)*(x.x' + 1)
```

で、`phi'(z)` がドリフトにも揺れにも同じ係数で掛かる**可動度**として働く。ReLU は `1[z>0]`（閉じると恒等ゼロ＝厳密な吸収）、ELU は `z<=0` で `alpha*e^z`（連続な粘性勾配）。

自己項（税）の符号は逆になる。`d/dz_i (1/2) E[o_i^2] = v_i^2 * phi(z_i) * phi'(z_i)` は、ReLU では `phi*phi' = phi >= 0` で常に `z` を下げるが、**ELU では `z<0` で `phi<0, phi'>0` なので `z` を上げる**。ELU の自己項は折れ目への復元力で、沼へ押し込む片符号の力ではない。

一方、駆動ゼロでも可動度が場所依存の拡散 `dz = phi'(z)*sigma*dW` の滞在密度は `p(z) ∝ phi'(z)^-2 = e^(-2z)`（`z<0`）で低可動度域に溜まる。積分が発散するので厳密には吸収でなく null-recurrent（戻るが期待時間が無限）で、**有限ホライズンでは実効的な壁**。復元力 `f>0` を加えると平衡深さが有限になり

```
p(z) ∝ e^(-2z) * exp(-(2f/sigma^2) * e^(-z))
z*   = log(f / sigma^2)
```

`f ∝ v_i^2` なので、**読み出し重みの小さいユニットほど深く沈む**という含意が付く。

> **格**: §2.3 全体が導出であり未検証。特に `z*` の式は 1 次元・`v_i` 固定・`sigma` 一定の近似で、実際には `v_i` も学習される（`dL/dv_i = 2*delta*phi(z_i) != 0` は沈下しても消えない）。**登録するのは検定であって結論ではない。**

### 2.4 本走が答えないこと（明示）

- **柱2 の「片道の壁・不可逆吸収」は ELU には literal には適用されない。** ELU に吸収集合は無い。本走が問うのは「機構（無方向の揺れ＋可動度の非対称）が軟らかい版でも成り立つか」であって、柱2 の再確認ではない
- **rsl_rl / PPO への接続は本走の外。** 実用側は Adam（命題リスト Q15 の成立条件から外れる）・幅 512 級・別の教師。v4 と同じく**予測として書き、測定の主張と混ぜない**
- ELU の `alpha` は 1.0 単一値。**掃かない**
- ReLU 側の既存結論を書き換えない

## 4. 設計

### 4.1 腕（5 本）

| 腕 | 活性化 | 中心化 | 役割 |
| --- | --- | --- | --- |
| `R_none` | ReLU | なし | **`mlp2_phase1_0829` の `L2_none` を bit 再現する**（S0'） |
| `R_A1` | ReLU | 第1層 | 同 `L2_A1` を bit 再現する（S0'）。Q1 の対照の基準 |
| `E_none` | ELU | なし | ELU で LoP が出るか。入力 µ（dose ≈ 12）下での沈下 |
| `E_A1` | ELU | 第1層 | **本命。** 観測正規化＋ELU に対応する配置 |
| `E_Aall` | ELU | 両層 | **Q2 の判別腕。** 第2層の µ を消しても沈下が残るか |

**`E_Aall` を入れる理由**: 沈下が µ 駆動なら第2層の中心化で止まり、無方向の拡散＋可動度勾配なら止まらない（可動度 `e^z` は中心化に不変）。Q2 の 2 説を介入で分ける唯一の腕。

### 4.2 腕の対応づけ

活性化関数の変更も中心化も**乱数を消費しない**ので、5 腕は init・教師・入力列・flip 軌道が bit 一致する。したがって全腕が seed 単位で対応がつき、paired bootstrap を使える。

- **ただし ReLU 腕と ELU 腕は step 1 以降で軌道が分岐する。** ペアリングが落とすのは init・教師・入力実現の分散だけで、「同一個体の追跡」ではない。引用時にこの一行を落とさない
- **S-pair（§6）でこの前提を検査する。** 落ちたら paired 統計は使わない

### 4.3 実装

`src/nets.py` の `VecMLPL` に活性化オプションを足す。**ReLU の実行経路は 1 行も触らない**（S0' が守る）。

- 前向き: `a = where(z>0, z, alpha*expm1(z))`。`expm1` を使う（`z -> 0-` で桁落ちしない）
- 後ろ向き: `phi'(z) = 1`（`z>0`）／`phi(z)+alpha`（`z<=0`）。**前向きの `a` を再利用する形で書く**（`exp` を 2 回呼ばない・数値一致を保つ）
- **勾配は閉形式のまま。autograd に切り替えない**（S0' が不可能になる）
- 中心化は Phase 1 の層別 `centered` フラグと `running_mean` をそのまま使う

### 4.4 ELU での用語（新規・`用語と記号` に 1 行足す）

ELU にゲートは無いので `strict_dead`（`p_hat = 0`）は定義できない。代わりに

```
沈下（submerged）:  max over 32 patterns of z_i(x) <= 0
zbar_i           :  E_support[z_i]
```

- **`submerged_frac` を verdict に使わない。** 沈下は死ではない（`phi' = alpha*e^z > 0` なので勾配は流れ続ける）。`strict_dead` を verdict に使わない cbp_harm 裁定と同じ理由が、より強く当てはまる
- **§5.0 の G0b は例外ではない。** そこで使うのは表現型の記述としてであって、「沈下したから機能が失われた」ではない。沈下と機能損失の関係そのものが `ABSORPTION_ISOLATED` の中身なので、**片方を他方の代理にすると恒真になる**（教訓②）
- ReLU 腕では従来どおり `strict_dead` を REPORT_ONLY で記録し、**ELU 腕の `submerged_frac` と同じ列に混ぜない**

### 5.1 Q1 — 第2層の dose は抑えられるか再生されるか【主 endpoint】

対象は `E_A1` の第2層入力 dose = `||mu^(2)|| / sqrt(tr Sigma^(2) / d_2)`（32 パターン厳密サポート上・タスク末尾記録点のみ・位相を揃える）。

**P1a（水準）**: 末尾窓の seed 中央値。

| 条件 | ラベル | 読み |
| --- | --- | --- |
| < 2.0 | `MU_SUPPRESSED` | Clevert regime。`g(s) <= 0.2` すなわち `s <~ 1` に対応（dose = sqrt(d_2)*g(s) = 10*g(s)） |
| >= 9.33 | `MU_REGENERATED` | 柱3 の遷移帯下端（dose 単位 9.33–12.16）に到達 |
| その間 | `MU_INTERMEDIATE` | ReLU の 7.18 と同水準かを併記 |

**閾値 2.0 と 9.33 は結果を見る前に凍結。** 2.0 は §2.1 の閉形式、9.33 は `柱3遷移帯の時間依存_spec_0829` §1b の換算による。**dose と生の `||mu||_2` を混同しない。**

**P1b（傾き）**: 各 seed でタスク末尾 dose 系列（500 点）とタスク番号の Spearman。seed 中央値 ＋ studentized bootstrap。**増加 = CI が 0 を上に外す。**

- ReLU `R_A1` の対応値（Phase 1 committed は Δ median −0.905 [−0.932, −0.874] で減少側）と paired 差を取る
- **P1b が Q1 の判別線。** 水準だけでは §2.1（`s` 依存）と §2.2（沈下レバー）を分けられない。傾きが上向きなら沈下レバーが効いている

**P1c（レバーの分離・事前登録）**: 各記録点で第1層の `sd(z_i)` 中央値 `s` と沈下率を出し、実測 dose を `10*g(s)`（§2.1 の閉形式）と比べる。

| 署名 | 読み |
| --- | --- |
| 実測 ≈ `10*g(s)` | dose の動きは事前活性スケールで説明できる（§2.1 のみ） |
| 実測 >> `10*g(s)` かつ 沈下率と正相関 | **沈下が µ を作っている**（§2.2） |

格: P1c は P1a/P1b の verdict を上書きしない。閉形式はガウス近似で、事前活性は 32 パターン離散。一致・不一致のどちらも近似の妥当性の話に落ちうる。

### 5.2 Q2 — 沈下は駆動か拡散か【主 endpoint】

**位相の扱い（重要）**: 増分はすべて**タスク内の隣接記録点**（`lop_every=1000`、T=1e4 なので 1 タスクあたり 9 区間）で取る。タスク境界を跨がない。境界では flip ビットが変わりサポートが変わるので、`zbar_i` の跳びは重みの移動を意味しない（教訓⑦・引用禁止 C）。

対象ユニット: 区間**始点**で沈下しているもの。**始点で条件付ける**（終点や区間平均で条件付けると平均への回帰が符号に化ける）。

**P2a（可動度スケーリング）**: 始点の `zbar_i` でビン分割し、ビンごとに `sd[dzbar_i]` を出す。`log sd` を `zbar` に回帰した傾き `beta`。

| 条件 | ラベル |
| --- | --- |
| `beta` の CI が 1 を含む | `MOBILITY_SCALING` — 拡散が `phi' = alpha*e^z` に従う |
| CI が 1 を外し 0 を含む | `NO_SCALING` — 可動度勾配で説明できない |
| その他 | `PARTIAL_SCALING` |

**P2b（駆動対雑音比）**: 同じビンで `rho = median[dzbar_i] / sd[dzbar_i]`（無次元）。沈下領域（`zbar<0`）のビンをプールした seed 中央値。

| 条件 | verdict |
| --- | --- |
| `rho <= -0.3` | `DRIFT_DOMINATED_DOWNWARD` — **Issa 予測の側**。µ 方向の駆動で沼へ押される |
| `abs(rho) < 0.1` | `NOISE_DOMINATED` — **Claude 予測の側**。無方向の揺れで沈む |
| `rho >= +0.3` | `DRIFT_DOMINATED_UPWARD` — 自己項の復元力が正味で勝つ |
| その他 | `MIXED` |

閾値 0.3 / 0.1 は結果を見る前に凍結。**符号と大きさを別々に報告する**（符号だけでは §2.3 の 2 説を分けられない）。

**P2c（µ 駆動の介入判別）**: `E_A1` と `E_Aall` の第2層で P2a・P2b を比べる（paired）。

| 署名 | 読み |
| --- | --- |
| `E_Aall` で `rho` が 0 へ寄り、`E_A1` で負 | 沈下は **µ 駆動**（Issa 側） |
| 両腕で `rho ≈ 0` かつ両腕で `MOBILITY_SCALING` | 沈下は **拡散＋可動度**（Claude 側） |
| `E_Aall` で沈下率だけが下がり `rho` は変わらない | µ は沈下の速さを変えるが機構は拡散 |

**P2c が Q2 の本命。** 観察的な条件付けではなく介入なので、引用禁止 E の「層別後の観察的関連を因果介入と呼ばない」に抵触しない。

### 5.3 副次（REPORT_ONLY）

- **`z* ∝ log v_i^2` の検定**: 末尾窓の沈下ユニットについて Spearman(`zbar_i`, `log v_i^2`)。seed 中央値 ＋ bootstrap。正なら §2.3 の平衡深さの式と整合し、選抜が `|v_i|` という機能量を見ていることになる。機能盲目性の ELU 版は ReLU（RD = −0.2353・PROTECTIVE）と結論が変わりうる。**`v_i` は沈下しても学習され続けるので観察的関連であり、因果ではない**
- 層別の `dose` / `mu_norm` / `sigma_rms` / `||w||` / `eff_rank` / `eff_rank_W` / `alive`（ReLU 腕）/ `submerged_frac`（ELU 腕）/ `wcos_mean` / `stable_rank_W` / `top1_frac` の時系列
- **`||w||` は主要共変量として事前登録**（Phase 0/0b/1 から継続。Chiley §3.4 と Dohare 図 4b の教訓）
- 未フィット率の早期窓と末尾窓の paired Δ。**署名表は Phase 1 で欠陥が判明しているので、署名ラベルは付けず生の Δ と傾きだけ報告する**

### 5.4 退化・検閲の扱い

- **`Sigma^(2)` の退化ガード**: `sqrt(w_i^T Sigma^(2) w_i) < 1e-8` を `NA` とし、**件数を判定と同格で報告する**。ELU では沈下ユニットの出力が定数に寄るので `Sigma^(2)` の実効ランクは ReLU より落ちやすい。`NA` が末尾窓で 20% を超えたら、その腕の dose と壁座標を `DEGENERATE` と立てて判定に使わない
- 床検閲: 各腕の床（1e-23）にかかった点の割合を列に持つ。20% 超で `CENSORED`、paired 統計を判定に使わず符号検定へ
- **数値発散**: Phase 1 §5.7 の実行追補を逐語継承。probe ごとに重み・bias・読み出し・`running_mean` の NaN/±Inf を検出し、検出した腕は `NUMERIC_DIVERGENCE` に固定して停止。seed 除外・再初期化・LR 低下・clipping による救済をしない。**`L2_A2` の前例（step 141000・task 15・seed 7）があるので、これは形式ではない**
