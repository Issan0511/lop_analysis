## 0. 一行と問い

**resp_ee_0917 で再学習と最もよく並んだ「訓練の微分を運ぶ実効的な画像数」$n_{\rm eff}$ を、resp_ee の中だけで「次のタスクをどれだけ学べるか（F）」への曲線と予測帯に変換して固定する。そのうえで、介入をしない自然軌道の 4 箱で、分岐点ごとの F がその帯に入るかを見る。**

- 同じ GPU 走に乗る残りのモデル（B の LR・ELU1・R・SILU、PM の同じ組、L の EE・LE・LL と PM の EL）は**副の箱**として同じ採点をし、報告だけする。

### 2.2 分岐点で「次のタスクを 1 つ学ばせる」

設計案は自然軌道を分岐させて 1 タスク学ばせる。Adam を引き継ぐ分岐は、自然軌道の次のタスクと演算まで同じなので、**自然軌道を 1 本走らせ、分岐 t の E = タスク t+1 の online 正解率**とする（走らせる本数が減るだけで、量は同じ）。予測子は**タスク t+1 の開始時**（入力は t+1 のもの、重みはまだ動いていない）に読む。RL では入力が変わらないのでタスク t の終端と同じ値になり（S2 で bit 確認）、PM では新しい置換が入った状態で読む（S2 で「終端と違う」ことを確認）。

### 2.3 予測子 $n_{\rm eff}$

g = その箱の逆伝播が実際に掛けている微分（CPU 箱: expm1 + 1 = resp_ee の `neffT`、GPU 箱: 各エンジンの `gate()`）。ユニット i、固定画像 N = 1200 枚（PM は置換後の 1200 枚）について

$$
n_{{\rm eff},i}=\frac{\big(\sum_x |g_i(x)|\big)^2}{N\sum_x g_i(x)^2},\qquad n_{\rm eff}^{(l)}=\operatorname*{mean}_i n_{{\rm eff},i}
$$

全画像で g = 0 のユニットは 0 として平均に入れる（resp_ee と同じ）。和は float64。

- **|g| を主にする理由**: GELU と SiLU は負の微分を持つ。重みの勾配は $\delta_i(x)\,g_i(x)\,a(x)$ の和で、乱数ラベルの下では誤差 δ の符号が画像ごとに変わるので、g の符号どうしが打ち消し合うことを「応答が少ない」と読むのは筋が違う。ELU・ReLU・leaky では |g| = g で、resp_ee の量と一致する。符号つき（$\sum g$ を使う）は副。
- 対照（§3.1 (b)）: 同じ層の微分の平均 mean |g|（CPU 箱は resp_ee の `gtr`）と、厳密な 0 の割合。

### 2.4 F

$$
F=\operatorname{clip}\!\Big(\frac{E-0.1}{E_0-0.1},\,0,\,1\Big),\qquad E_0=\text{同じ seed の分岐 t2 の }E\ (=\text{タスク 3 の online 正解率})
$$

設計案の定義に clip を足した。予測は「学習能力の喪失」についてのもので、t2 を上回る学習（PM では普通に起きる）は 1 に揃える。F(t2) は定義により 1。

### 2.5 較正（resp_ee の中で閉じる。新しい箱のデータに触れない）

**設計案からの変更**: 設計案は「resp_ee の 26 腕（10 seed 平均）で fit」。本 spec は **resp_ee の自然軌道（prefix）の t = 2–21 × seed 0–9 の 200 点**で fit する。理由は 2 つ。

1. 新しい箱はすべて自然軌道なので、較正も自然軌道で揃える。
2. 26 腕には人工の腕（t2 の網に後の時刻の場を移植）が入っていて、**同じ $n_{\rm eff}$ で自然の腕より E が 0.3 高い**（S2_10r 0.464 と N10 0.137 は、どちらも $n_{\rm eff}$ = 0.0074）。同じ手順で 26 腕を fit すると帯の半幅が **±0.48** になり、ほとんど何でも「入る」ので検定にならない。26 腕の fit は副として残す（`arms26`）。

seed を 1 つずつ抜いた検証（LOSO）: 9 seed で fit・帯を作り、抜いた seed の t = 2, 5, 10, 20 を採点。

## 3. 判定

### 3.1 箱ごとの条件

**(a)** 箱の（分岐点 × seed）のうち、F が帯に入る数が $\lceil 0.8\,n\rceil$ 以上（RL の箱 n = 15 で 12、PM_GELU n = 18 で 15）。
算術: 帯が名目どおり 95% を覆うなら、15 点で 12 未満になる確率は 0.5%、18 点で 15 未満は 1.1%（二項分布）。覆いが 50% の箱が通る確率は 1.8% / 0.4%、70% なら 30% / 16%。

**(b)** 箱の外の 3 箱（RL_GELU・PM_GELU・RL_EL）の分岐点を合わせた 48 点で、Spearman(F, x) が Spearman(F, 微分の平均) と Spearman(F, −厳密な 0 の割合) の両方より大きい。相手が定数で定義できないときは $n_{\rm eff}$ の勝ち。層は各箱の主の層。

### 3.2 ラベル

| ラベル | 条件 |
|---|---|
| **NOT_PREDICTIVE** | RL_EE_cpu が (a) を満たさない（同じ箱の新しい seed でも外れる） |
| **GENERALIZES** | 4 箱とも (a)、かつ (b) |
| **PREDICTS_NOT_BEST** | 4 箱とも (a)、(b) を満たさない（予測はするが、微分の平均などより優れない） |
| **BOX_SPECIFIC** | RL_EE_cpu は (a) を満たし、箱の外の少なくとも 1 箱が満たさない（どの箱かを併記） |
| INVALID | 走の欠け、登録 commit 以外や未 commit のコードで始まった走、分岐点の継続が有限でない |

設計案の 3 ラベルに `PREDICTS_NOT_BEST` を足した（(a) は全部通るが (b) が落ちる場合が、設計案の表では宙に浮いていた）。

### 3.3 報告のみ

- **記録との一致**: B と ext150（t1–150）、L と layer_chimera（t1–50）の共有列が bit 一致か（`LINKED` / `DIFFERS`）。判定の条件にはしない（新しい軌道でも問いは成り立つ）。「既知の運命」を引用するときだけ使う。
- **外れの向き**: below（F が帯より下 = $n_{\rm eff}$ が学習能力を過大に見る）と above。
- **時刻**: seed ごとに、f(x) < 0.5 になる最初の分岐点 $T_x$ と、F < 0.5 になる最初の分岐点 $T_F$（全 t）。
- **予測子の変種**（全箱）: `min`（min 曲線）・`L2`（第2層だけ、主曲線）・`signed`（符号つき、主曲線）・`rel`（§2.5）・`arms26`。分岐点での採点、全 t で帯に入る割合、箱の中の順位相関。
- **副の箱**: §2.1 の残りのモデル。主の層がない箱（leaky→leaky）は `min` と `L2` だけ。

## 8. 言えること・言えないこと

- 言える: 「機能的な応答」を、resp_ee の自然軌道で較正した $n_{\rm eff}$ の曲線で定義したとき、それが箱をまたいで再学習を予測するか。外れるなら、どの箱でどちら向きか（応答が残っているのに学べない箱があるか）。
- 言えない: なぜ $n_{\rm eff}$ が落ちるか（上流の問い）。介入による因果（それは resp_ee と動く場の設計案の側）。GPU の箱の $n_{\rm eff}$ は `exp(z)` の微分で、CPU の箱の expm1 の 0 を含まない。箱をまたぐ比較には、乱数の流れと逆伝播の実装の違いも混ざる。
- 較正は 1 箱・1 活性化・200 点（10 seed）。帯は seed 内の相関を無視した conformal で、覆いの保証は近似（LOSO で確認）。F は E0（t2）で正規化するので、t2 の点は健康な $n_{\rm eff}$ の水準の検査にもなる（§2.5）。
