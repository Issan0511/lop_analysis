## 3. CHB の bias 凍結・重み WD・bias WD への分解

**run id:** `chb_decompose_200_1018`  
**推奨ファイル:** `specs/spec_chb_decompose_200_1018.md`  
**継承:** `relu_doors_0919`、`ch_chb_200_0919` のエンジン、seed10–19 の参照は `ch_chb_performance_1011`。

### 3.1 問いと固定する箱

RC/raw/ReLU、C＋H、200課題、seed10–19。C は各seedの固定1200枚の**平均画像**を引く。H は両隠れ層の ReLU 出力からunit別EMAを引く（係数0.01、初期0、勾配なし、課題境界で保持、宿主と同じ更新順・訓練評価で同じ値）。lr=1e−3、30,000更新/課題、出力bias自由。

**追加腕はすべて task1 の最初から新規に200課題学ぶ。** CH/CHBのt50状態から別の介入を追加する実験ではない。全腕で初期W/b・データ・ラベル・バッチ列をseed対応させる。

### 3.2 腕と更新の厳密な形

係数は CHB の既存値 **λ=0.1713** に固定し、今回再probe・探索しない。

| 腕 | 毎更新の操作 | 状態 |
|---|---|---|
| `CH` | C＋H、すべてのbias自由、WDなし | 既存seed10–19を資格確認して参照 |
| `CHB` | C＋H、Adam後b1=0、b2←(1−ηλ)b2、b3自由、WのWDなし | 同上 |
| `CH_bfreeze` | C＋H、b1/b2を**初期値**で凍結。勾配経路を切りAdam対象から除く。b3自由 | 新規 |
| `CH_wWD` | C＋H、Adam後 **W1/W2のみ** (1−ηλ) 倍。全bias・W3は自由 | 新規 |
| `CH_bWD` | C＋H、Adam後 **b1/b2のみ** (1−ηλ) 倍。b1ゼロ化はしない。W・b3自由 | 新規 |

`CH_wWD` の「重みだけ」は隠れ層W1/W2と固定する。出力W3にもWDを掛けるとlogit尺度への別介入になるので混ぜない。W/bを一括したoptimizerの`weight_decay`引数には置き換えない。

順序は宿主のforward/backward→全自由パラメータのAdam→指定のdecoupled減衰/ゼロ化、Hの更新は宿主の位置のまま。momentを減衰・射影しない。凍結したbiasのmomentは生成しない（束ね配管で必要なら常時0の非更新bufferとし、チェックで確認）。

元CHBは **b1をランダム初期化し、最初のAdam更新の直後からゼロにする**。t0からbiasを除去した別条件へ直さない。bfreezeは小さい非零の初期biasを保つので、CHBと初期から同一ではない。

### 3.3 主量・判定（m=7）

W[a,s]=t181–200 online のseed内平均。基準2腕と3新腕のWを平均・中央値・全seedで報告する。

判定用7区間: 各新腕−CHの3本、各新腕−CHBの3本、CHB−CHの1本。

先に参照差 POS(CHB−CH) を確認する。成立しなければ `NOT_REPRODUCED` とし、残りの連続値はすべて報告する。成立した場合:

| 主ラベル | 必要十分な登録条件 |
|---|---|
| `BIAS_STOP_SUFFICES` | POS(bfreeze−CH) と NI(bfreeze,CHB)、POS(bWD−CH) と NI(bWD,CHB)、EQ(wWD−CH) |
| `WD_EXPLAINS` | POS(wWD−CH) かつ NI(wWD,CHB) |
| `MIXED` | その他 |

NIは「0.5pt超劣らない」を示したこと、EQは両方向0.5pt以内を示したこと。両者を混同せず、CHB以上へ改善した腕を「違うので失敗」としない。差が同等性幅内に収まるなどして両候補が成立した場合は共通規則によりMIXED（OVERLAPPING_EVIDENCE）とし、どちらかへ強制帰属しない。

**理論からの方向予測（署名付き確率とは別）。** biasへの2介入がCHBの近く、wWDがCHの近くという方向を検証する。ただし **bWDはbiasを止める操作ではなく、有限の減衰である**。Adamの歩幅とλの釣り合いによる `|b|≈1/λ` は近似で、全更新の上界ではない。bWDだけ失敗した場合、凍結も失敗した場合、幅sが縮んでrが悪化した場合を区別する。

### 3.4 診断と読みの上限

全200課題について b1/b2 の全unit値、符号付き平均・中央値・絶対平均、m/s/r、native微分平均とVar_x、死亡率、Wノルムを記録。t31–50とt181–200の各量と差、b1とm1のずれも出す。Cは実数では平均0だが、float32の平均残りは測って `m1=W1·mean(x_C)+b1` の恒等式として照合する。

Adamの実更新量 `||ΔW||/||W||`、候補更新とWDによる変位を分けて記録する。WD_EXPLAINSが成立しても「WDのどの経路か」までは決まらない。重みWDは特徴・biasの勾配・rも変えるため、**実効学習率だけが原因**とは書かない。BIAS_STOP_SUFFICESも「この2つのbias介入が性能保持に十分だった」と限定し、biasが唯一の原因という意味にしない。

凍結とゼロ化の比較は「ゼロという値が必須か」を調べるが、初期biasは小さいので広い値域での定数biasの無害性までは言わない。どれも予防介入で、崩壊後の回復ではない。

### 3.5 S 検査

| S | 本物で要求 | 必ず落とす変異 |
|---|---|---|
| S-reference | 参照はperformance_1011のseed10–19。設定・ラベル/バッチ・ソースhashと元の全200課題行を確認 | 旧seed0–9を比較／t181–200を別窓へ |
| S-nochange | 拡張runnerのCH/CHBが宿主と同じ短縮軌道。再利用資格は元のcommit/hashと自然再現で確認 | CHに微小WD／CHBのb1を初期から0へ |
| S-freeze | 非零biasかつ非零bias勾配のfixtureでb1/b2が初期値とbit一致、W/b3は更新 | 更新後だけ値を書き戻す／b3も凍結／biasのmoment更新を残す |
| S-wWD | 更新候補からW1/W2だけ指定倍率で縮み、b/W3/m/v/tcは通常どおり | coupled L2／W3も減衰／b2も減衰 |
| S-bWD | b1/b2だけ指定倍率で縮む。非零b1を使い、ゼロ化でないと確認 | b1を毎回0／b2だけWD／momentまで減衰 |
| S-center | EMAが各層で元の式・順番、平均恒等式が独立参照と整合 | 課題ごとEMA reset／EMAへ勾配を通す |
| S-resume | checkpoint→再開がP/Adam/EMA/RNG/時刻を含め連続走と一致 | EMA欠落／ラベルRNGをseedから再生成 |
| S-stats | 人工の3パターン、参照不成立、欠測、NI/EQ境界を区別 | t区間が0を含めばEQとする／同じseed以外で対応 |

参照の200課題を再利用するためのqualificationに失敗した場合、CH/CHBも同じ条件で再走する。異なる数値環境の平均値をそのまま混ぜない。
