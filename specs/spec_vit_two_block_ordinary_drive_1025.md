# 通常学習の沈降の符号：逆伝播ゲートと誤差の対応の診断

2026-10-25、Issa「通常の誤差最小化から、なぜその向きが出やすいのかについてできるとこまで」。既存の浅層沈降・深層浮上とT5結果を見た後の追加診断。新しい長期訓練ではなく、保存状態からの一歩。下の比較を実行前に固定する。過去のspecの登録判定は変更しない。

## 問い

固定入力・fc1だけの更新でも沈む第1blockで、ReLUの逆伝播による入力の選別が沈降に必要か。それとも選別を外しても下流から届く誤差に沈降方向が残るか。画像間の対応の診断であり、学習の複製間共分散T5とは異なる。

## 対象

既存seed0–4、課題10/60、起点100/500、両blockの全40状態。全250画像と保存ラベル。元のモデル・Adam状態・float32・TF32無効を維持する。入力と残差をcacheし、fc1以外は固定。起点のforwardは全腕で同じ。

## 比較

c = 各画像のCEを活性化出力aで微分した値。全tokenを含む。g = 1[z >= 0]（元のclampの微分）。入力uとcは起点で固定し、fc1へ渡す信号だけ変更する。

- relu: c*g（通常更新）。
- all_open: c（逆伝播のゲートを1にする）。
- rate_gate: c*mean_image(g)。token/unit別の開口率を保ち、画像とのゲートの対応を平均化する。画像を一様に並べ替えたゲートの平均勾配に相当する。
- no_image_pairing: mean_image(c)*g。token/unitごとの誤差の平均を保ち、画像ごとの誤差の対応を平均化する。これは「T5除去」ではない。

各変更腕に、fc1のweight+biasの勾配normをreluと揃えた腕も併記する（正のスカラー倍率、方向は不変）。勾配ゼロの場合は無効と明記する。これらは変更した逆伝播の診断で、一般に元の損失の勾配ではない。

1. 起点のAdam分母を固定したD、momentumなし、lr=1e-4の一次Δμ・Δrと有限一歩。
2. 同じ保存Adam履歴からの実Adam一歩。腕ごとに履歴を戻す。両方とも一歩後の元のforwardでCE・accuracyを測る。
3. full-batchの生SGDの一次方向も報告。ReLUゲートを外す効果をAdamの存在と混同しない。

主要判定は起点状態ごとの符号と全5seedでの成立数。unitを独立seedとして検定しない。有限一歩で止まっても長期の沈降除去とは呼ばない。学習維持の十分条件として一歩のCE減少だけを使わない。

## 式と検査

CEの信号は c_nti = sum_{k != y_n} p_nk * (d f_nk/d a_nti - d f_ny/d a_nti)。正ならその活動を下げることが局所的に損失を下げる。これは前活性の平均やμ/σの符号を自動的に決めない。

固定入力のμ_i=w_i^T m+b_iに対し、Δμ_i=-eta/N sum_nt (m^T D_wi u_nt+D_bi)c_nti g_nti。rの一次変化にはσの微分も入れる。単に「ゲートが非対称だから沈む」とは結論しない。

通常腕の構成したfc1勾配を元CEのautogradと照合。c*gの符号分割と平均化の差は加法性を検査する。μ/rのパラメータ微分は独立なfloat64 autogradで照合。起点のcache forwardと元forwardをbit一致確認。各腕後もfc1以外をdigestで照合。通常腕の有限一歩は既存T5 full-batchのs1と照合する。失敗時は後続を停止し、基準を後付けで緩めない。

raw出力は既存archiveのordinary_drive/、結果表・理論整理は既存実験フォルダへ保存する。この診断の結果を見ずに決めた比較であり、浅層の沈降という問い自体は事後選択である。
