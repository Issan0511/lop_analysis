## 0. 一行

**本編の c=±2 は lr 0.01 で走らない**（前検査で 10/10 seed が step 1,000 に発散）。しかし ±2 は本編の判別力の主力で、しかも §4 の `OFFSET_SIGNED` の定義が ±2 の符号反転を要求しているため、±2 を失うと**判定は `NOT_DETERMINED` 確定**になる。そこで **lr を下げた {c=0, −2, +2} の 3 腕ラダー**を別に登録し、そこで符号の判定を行う。

## 1. 発散の事実と機構（前検査・`results/_preflight_act_offset_0906/preflight.json`）

30k step・10 seed・登録 lr 0.01:

| 腕 | 結果 |
|---|---|
| `LRoff0_1216` / `LRoffm0p5_1216` / `LRoffp0p5_1216` / `Eoffm1_1216` / `Eoffp1_1216` | 完走（有限・`lr_used` 0.01・新列あり）。S-limit も PASS |
| `LRoffm2_1216` / `LRoffp2_1216` | **step 1,000 で 10/10 seed 発散**（`net.Ws.1`・`net.bs.1`・`net.v`・`net.c` が非有限） |

機構: 出力は $\hat y=\sum_i v_i(\varphi_i+c)+c_{\rm out}$ で、**同じ定数が幅 $h$ の全ユニットに乗る**ため、$v$ 空間の一様方向 $(1,\dots,1)/\sqrt h$ に**コヒーレントな曲率**
$$\lambda \approx 2\,h\,c^2 \qquad (h=100,\ c=2 \Rightarrow \lambda\approx800)$$
が立つ。SGD の安定条件 $\eta<2/\lambda$ は $c=2$ で $\eta<0.0025$ を要求し、登録 lr 0.01 は 4 倍これを超える。これは `edge_law_0905` の b オフセット ±5/±4 が step 1,000 で即死したのと**同型**（一様な定数を全ユニットに入れる介入は $h$ 倍のコヒーレント曲率を作る）。

**未登録診断**（scratchpad `diag_lr/`・30k・本追補の lr を選ぶためだけに使う。判定には入れない）: `LRoffp2` は lr 0.005 で 1 seed 発散、**0.0025 と 0.00125 で完走**。`LRoffm2` は 0.0025 で完走。ELU c=±1（$\lambda\approx200$）は lr 0.01 で完走。

## 2. 腕（3 本・幅 100・深さ 1・a=0.1・用量 12.16・10 seed）

| 腕 | 活性化 | c | lr | step | 役割 |
|---|---|---|---|---|---|
| `LRoff0_lr0p00125_1216` | `leaky_off_0` | 0 | 0.00125 | 40M | **このラダーの参照**（同じ lr・同じ地平線） |
| `LRoffm2_lr0p00125_1216` | `leaky_off_m2` | −2 | 0.00125 | 40M | H-mag: 浮く |
| `LRoffp2_lr0p00125_1216` | `leaky_off_p2` | +2 | 0.00125 | 40M | H-mag: 深く沈む |

- **lr = 0.00125 を選ぶ理由**: $\lambda\eta\approx1$ で安定境界 $\lambda\eta=2$ に対し**係数 2 の余裕**を取る。0.0025 はちょうど境界で、`edge_law_0905` の ELU lr 0.02 が step 581k で落ちた前例（初期に耐えても後で落ちる）を踏む恐れがある。
- **40M step を選ぶ理由**: $\eta\cdot\text{step}=50{,}000$ を本編（0.01 × 5M）と**揃える**。`edge_law_0905` §4.5-d の流儀（lr 0.005 腕を 10M にした）を踏襲。緩和時間は $\tau_{\rm ens}\approx73$ タスク × 8 ≈ 584 タスクなので、4,000 タスクは約 7τ。
- フックは既存の `lr` フック（`hooks: {type: lr, value: 0.00125}`）。`lr_used` 列に書かれる（S-lr）。
- checkpoints `[0, 1000000, 5000000, 40000000]`。

## 4. 判定（事前登録・本ラダーだけで閉じる）

$\Delta(c)=$ 腕 $c$ − `LRoff0_lr0p00125_1216`（seed 対応・ユニット対応）。

- **`OFFSET_SIGNED_B`**（候補 1 = H-mag）: $\Delta\bar z(+2)$ の CI 上端 $<0$ **かつ** $\Delta\bar z(-2)$ の CI 下端 $>0$（符号が反対）。
- **`OFFSET_IRRELEVANT_B`**（候補 2 = H-slope）: $c=\pm2$ の**両方**で $\Delta z_{\max}$ の CI ⊂ $[-0.3,+0.3]$ かつ $\Delta\bar z$ の CI ⊂ $[-0.5,+0.5]$。
- **`OFFSET_OTHER_B`**（H-v など）: いずれかで CI が 0 を外すが `SIGNED_B` の型でない（両符号で深い／両符号で浅い等）。
- **`NOT_DETERMINED`**: 発散 3/10 seed 超、settle 3 窓の単調ドリフトが主窓 CI 幅を超えて未定着、または 3 腕のどれかが欠落。
- それ以外 **`INCONCLUSIVE`**。

**本編 §4 との違いは 1 点だけ**: 本編の `OFFSET_SIGNED` は「$|\Delta\bar z|$ が $\pm0.5$ より $\pm2$ で大きい（単調）」を要求するが、**本ラダーには ±0.5 が無いので単調性は検査しない**。代わりに §5 の REPORT でラダー A の ±0.5 と**符号の向きだけ**を照合する（lr が違うので水準は比較しない）。

**総合ラベルは 2 つ出し、畳まない**（`edge_law_0905` の命題 1 が 4 ラベル併記だったのと同じ流儀）:

| ラダー | lr | c | 判定 |
|---|---|---|---|
| A（本編） | 0.01 | 0, ±0.5（**±2 は `NOT_RUN`**） | 本編 §4 の 5 ラベル。±2 が無いので `OFFSET_SIGNED` は原理的に出ず、`NOT_DETERMINED` になる見込み |
| B（本追補） | 0.00125 | 0, ±2 | 上の 4+1 ラベル。**符号の主判定はこちら** |

## 5. REPORT（登録外・併記）

- ラダー A の $\Delta(\pm0.5)$ と ラダー B の $\Delta(\pm2)$ の**符号の一致**（水準は比較しない）。
- 本編 §4 の REPORT 一式をラダー B にも出す: $|v|$・$\|w\|$・線形化率（$|v|<0.05$）・出力バイアス $c_{\rm out}$ の末尾値（$c\sum v$ を吸収しているか）・復元場（条件 $\bar z(t-2{\rm task})$・変位 $\bar z(t+1{\rm task})-\bar z(t)$）の零点。
- $\lambda\eta$ の実測代理として、末尾の $\|w\|$ と $|v|$ が lr で何倍違うか（ラダー A の c=0 と ラダー B の c=0 の比・**REPORT のみ**）。

## 9. 引用上の注意（本編 §8 に足す）

1. **ラダー B の lr は登録値ではない**ので、lr 0.01 の腕（ラダー A・元マシンの `LRnull_1216` など）とは**水準比較しない**。参照はラダー B の `LRoff0_lr0p00125_1216` だけ。
2. **ラダー B の $\Delta$ の「大きさ」は lr 0.00125 での量**であり、lr 0.01 での大きさとは限らない。持ち出してよいのは**向き（符号）**まで。
3. 本編の ±2 が `NOT_RUN` なのは**発散**であって「効果が無かった」ではない。ラダー A の判定を「±2 に効果なし」と読まない。
4. $\lambda\approx2hc^2$ は**設計のための見積り**（$\varphi$ の寄与を落とした上界寄りの近似）であって測定値ではない。「$\lambda$ を測った」と書かない。
