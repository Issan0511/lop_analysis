# hsweep_rlmnist_0924 — 隠れ幅 h を振って「削らないのは容量が余っているから」を因果で決める

2026-09-24、Claude。Issa の依頼。親: vault `論文作成/実効変位とWの関係_0924訂正_幅の固定点は観測地平で不成立` §7・§7.1。

## 問い

RL-MNIST 固定入力（画像 1,200 枚固定、毎課題ラベルを引き直す）で、各課題の第 1 層の変位（実効計量、入力の中心化共分散 Σ で測る）は、次の課題で 21% 削られたあとほぼ触られず、40 課題後も半分が残る（h=100、Codex の effdisp_inputscope_0924 LR_X0Y1 の走ゼロ再計算）。Issa の仮説: **古い変位を削らないのは容量（読み出しが無視できる方向）が余っているから。** 下流 W3·W2 が読むのはユニット空間 h のうち 9 次元で、残りの方向にある変位は損失に効かず削られない。h を減らして無視できる方向を無くせば、削りが増えて幅が止まるはず。

対立仮説: 削りは損失が必要とする分（新ラベルが勝つまで古い関数を抑える分）で決まり、容量は変位の置き場所を変えるだけ。残留は h によらず約 0.5 のまま。

## 設計

- 網: 784-h-h-10 MLP、leaky 0.1、h ∈ {8, 16, 32, 64, 100, 300}。PyTorch 既定初期化（U(±1/√fan_in)）。
- 課題: 固定 1,200 枚（seed ごとの層化部分集合、`rl_subset`）、毎課題新しい乱数ラベル（`effdisp_inputscope_labels`、第 1 課題は seed 内で共通）。50 課題 × 30,000 更新（400 epoch × 75）。
- 最適化: Adam lr 1e-3、β (0.9, 0.999)、ε 1e-8、weight decay なし、batch 16、状態持越し。float32、CPU。
- seed 200–204（Codex の走と同じ）。h=100 は Codex の LR_X0Y1 と初期値・ラベル列・batch 順が同一で、device だけ違う（参照）。
- エンジン: `src/hsweep_rlmnist_0924.py`（codex/effdisp_inputscope_0924 の `src/effdisp_inputscope_mnist_0924.py` 0277e4d を h 付きに写したもの）。保存は課題末ごとに W・b・Adam の m/v（`state_NNN.npz`）、入力 bank と共分散。
- 全 30 系列。生データは `~/Projects/obsidian-research-data/hsweep_rlmnist_0924/`。

## 量（第 1 層、Σ 計量）

V_t = tr(W_t Σ W_tᵀ)、D_t = W_{t+1} − W_t、Q_t = ‖D_t‖_Σ²、X_t = ⟨W_t, D_t⟩_Σ、c = X/√(VQ)、ρ = √(Q/V)。

1. **残留 f_k**: 課題 s の変位が k 課題後に残る割合 ⟨W_{s+1+k} − W_s, D_s⟩_Σ / ‖D_s‖_Σ²。s = 20..39 の平均、k = 0..10（主）、s = 20..29 で k ≤ 20（副）。主評価は **f_10**。
2. **収支**（t41–50）: B = −2ΣX/ΣQ、ΣQ/mean V、c<0 の割合、ΔV/課題、log V 対 log t の傾き、後半/前半の平均比。P1・P2 は effdisp_validation_0924 の登録定義そのまま（P1: B ∈ [.9, 1.1] かつ ΣQ/meanV ≥ .1 かつ c<0 割合 ≥ .8。P2: P1 かつ |傾き| ≤ .2 かつ 後半/前半 ∈ [.9, 1.1]）。seed 4/5 以上で群通過。
3. **読まれる/読まれない**: 課題末の W3·W2（クラス中心化、rank ≤ min(9, h)）の行空間への射影で D_s を分け、各部の ‖·‖_Σ² の分担と f_1・f_10。h=8 では読まれる部分空間がユニット空間全体になるので、分担は定義上 1。
4. **当てはまりの門**: 課題末の訓練正解率の seed 中央値（t41–50）。**≥ .99 の腕だけを「当てはまる腕」として仮説の判定に使う。** 当てはまらない腕（h が小さすぎる）は別表で報告し、判定に数えない。
5. 参考: 素のノルム ‖W1‖²、V_Σ/‖W1‖²、ρ、c、ユニットあたりの幅。

## 判定

当てはまる腕の中で h を落としていったとき、

- **CAPACITY**: f_10 が h とともに単調に落ち、最小の当てはまる h で f_10 ≤ .3（seed 中央値）、かつその腕で B ≥ .98 または P2 通過。
- **LOSS_SET**: 当てはまる全腕で f_10 が h=100 の値 ±.1 に入り、B は [.88, .97]、P2 は全滅。
- **PARTIAL**: f_10 は落ちる（最小の当てはまる h で h=100 より .1 以上低い）が .3 には届かず、幅も止まらない。
- どれでもなければ OTHER として記述。
