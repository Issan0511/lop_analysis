## 1. 背景：本走で顕在化した2つの交絡

### 交絡1: レジーム A の dironly は「方向アーム」ではなく「方向＋マージン」アーム

本体 §3.4 の設計では dironly は b を保持する。レジーム B（β = b/‖w‖、µ=0）ではこれが意図どおり働き、**b が深い負のままなのでゲートは開かない**（reopen_frac 0.011、M は none と小数点4桁一致）。

しかしレジーム A では β = (wᵀµ + b)/‖w‖_Σ であり、**u を引き直すと wᵀµ が引き直される＝マージンがランダムに再抽選される**。したがって A の dironly は新特徴と新マージンを同時に投入しており、本体 §6 の P 表はこの分離を持たない。

**傍証（本走データからの再計算）**: レジーム A の treated ゲート再開率は posonly 0.206 / dironly 0.281 / full 0.324 で、**性能順序（full > dironly > posonly）と完全に一致**する。新特徴の有用性が便益の源なら、便益はゲート開通率と独立に伸びてよいはずだが、そうなっていない。

### 交絡2: 3つの reset アームが `a←0` を共有

`a_i ← 0` のユニットは出力に寄与せず、δ が a を経由してしか届かないため**そのユニットへの勾配もほぼ止まる**。よって posonly は「操舵権限を回復したユニット」ではなく「操舵権限は回復したが操舵信号が届かないユニット」である可能性がある。

**傍証（本走データからの再計算）**: posonly-treated を窓内でゲート再開を経験したかで層別すると、Δcos(u,µ̂) の中央値は **再開あり −0.017（上位25% は +0.079）/ 再開なし −0.077** と二峰的。勾配が実際に流れたユニットだけ正側に寄る＝窒息説と整合。

加えて Δ_arm は全て共通床 V（a←0 だけの便益）を含むため、本体が報告した比（posonly 0.704、dironly 0.936）は **1 に向かって膨らむ上限**としてしか読めない。

## 2. 追補アームの定義

本体 §3.4 と同じ treated 集合・同じ fresh draw g_i（同一 seed 系列、ユニットごと1本）を使う。**本体アームと bit 単位で同じスナップショットから分岐すること**（`--reuse-snapshot`）。

| アーム | w_i | b_i | a_i | 意図 |
|---|---|---|---|---|
| **posflip** | ‖g_i‖ · (**−**w_i/‖w_i‖) | b_init（=0） | 0 | 新特徴ゼロ・マージン反転。posonly の符号違い |
| **vzero** | **保持** | **保持** | 0 | 共通床 V の測定。座標も方向も触らない |
| **dirkeep**（副次・任意） | ‖w_i‖ · (g_i/‖g_i‖) | b_init（=0） | 0 | dironly の b を戻した版。b 保持の寄与を分離 |

- posflip は**新しいランダム方向を一切引かない**（元の方向の符号反転のみ）。ノルムは posonly と同一（‖g_i‖）にして、posonly との差がマージン反転のみになるようにする
- vzero は treated の w, b を一切変更しない。**vzero が none と有意差を持つ場合、本体の全 Δ が V を含むことの直接証拠**になる
- レジーム A のみで実行してよい（交絡1・2はともに A の解釈問題）。レジーム B は G0 void のため追補しない。ただし vzero は B でも安価なら取得（PC-4 系の傍証）

## 4. 判定基準（事前登録 — 実行前に固定）

統計: paired seed bootstrap、`rng = np.random.default_rng(20260819)`、B=10,000、95%CI。本体アームとのペアは同一 seed・同一スナップショット由来なので厳密ペア。

| ID | 統計量 | 予測 | 判定 | 帰結 |
|---|---|---|---|---|
| **Q1**（主判定） | Δ_posflip − 0.9·Δ_dironly | ≥ 0 | CI 下限 > 0 で PASS、点推定のみ正で weak | PASS: **dironly の便益はマージンで説明され尽くす**。新特徴の寄与ほぼゼロ → B1 は「マージン主成分」へ絞り込み |
| **Q2** | Δ_dironly − Δ_posflip | > 0 | CI 0 除外 | PASS: 新特徴に固有の寄与あり → **B1 改訂**（座標に還元されない成分が実在）。Q1 と排他ではないので両者の点推定で強さを読む |
| **Q3** | Δ_posflip − Δ_posonly | > 0 | CI 0 除外 | PASS: マージン反転が操舵回復に上乗せ。マージン ≫ 操舵の直接測定 |
| **Q4** | Δ_vzero | — | 報告のみ | 共通床 V。**Δ_vzero / Δ_full が本体の比の下駄**。0.05 超なら本体 §11 の比表現に補正注記を入れる |
| **Q5** | 補正比 (Δ_posonly − Δ_vzero)/(Δ_full − Δ_vzero) 等 | — | 報告のみ | 床を抜いた比。分母が正の bootstrap 標本が 0.95 未満なら CI 非報告（家内規約） |
| **Q6** | posflip-treated の median Δcos(u, µ̂) | — | 報告のみ | P7 との比較用 |
| **Q7**（P7 の交絡解消） | vzero-treated の median Δcos(u, µ̂) | — | 報告のみ | **a←0 のみで負に振れるなら P7 の負値は窒息の副作用**。ゼロ近傍なら P7 は力学的知見として残る |
| Q8（dirkeep 実施時） | Δ_dirkeep − Δ_dironly | — | 報告のみ | b 保持の寄与 |

**帰結マッピング**:

- Q1 PASS → 本走の「dironly > posonly」は**「マージン回復 > 操舵回復」**と読む。B1 は棄却でも改訂でもなく**マージン主成分への絞り込み**
- Q2 PASS かつ Q1 FAIL → **B1 改訂**。座標に還元されない新特徴成分が実在
- Q7 が明確に負 → P7 の解釈を撤回し、`[[ノルム増大と不可逆性]]` の関門文を「a←0 交絡下の観測」に格下げ
- Q7 がゼロ近傍 → P7 は 1/‖w‖ 操舵切断への反証候補として関門に残す（ただし a 保持アームでの再測を次の宿題に）

## 9. 実装ノート（事前登録コミット時に追記、§4 の判定基準は不変）

- **実行主体**: 本追補の実装・実行は外部エージェント（OpenAI Codex, gpt-5.6-sol, reasoning=ultra）に委譲する。引き継ぎ資料は `specs/HANDOFF_posreset_addendum.md`。
- **§2 の記号 a_i**: 本体 §12 と同じく、実装上は `VecMLP.v`（隠れ→出力の読み出し重み）。実装の `a` は活性ベクトルで別物。
- **posflip のマージン反転が「反転」である根拠**: b_init=0 なので β_post = (w_postᵀµ)/‖w_post‖_Σ。w_post = −‖g‖·ŵ_pre より w_postᵀµ = −‖g‖·ŵ_preᵀµ。すなわち β の符号が厳密に反転する（‖w‖_Σ は符号不変）。posonly は同じ ‖g‖ スケールで符号を保つので、**posonly と posflip の差は β の符号のみ**。
- **Q1 の「≥ 0」の読み**: 統計量 Δ_posflip − 0.9·Δ_dironly の bootstrap CI 下限 > 0 を PASS とする（本体 §6 の「CI が 0 を除外」と同じ片側の読み）。
- **スナップショット共有**: 追補は本体の `results/posreset_0819/snapshots/A_w100_cont_step500000.pt` を読むが、出力先は `results/posreset_0819_add/`。本体ディレクトリへの書き込みは一切禁止（read-only で開くこと）。
