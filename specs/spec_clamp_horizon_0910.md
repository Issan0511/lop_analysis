# 長い地平線で沈下と幅を分ける spec 0910
状態: 検証中 / 更新: 2026-09-10
親: [[長い地平線でのleakyとELUの分岐_結果_0910]] / [[幅か沈下か_クランプ介入_結果_0909]] / [[幅の規制は可塑性を買うか_0910]]
run id: `clamp_horizon_0910`

## 0. 何を決めるか

Issa の指摘（2026-09-10）: 「Snake に比べて leaky も ELU も同程度に悪いのは、沈下が原因と言えるのではないか」。
`long_horizon_0910` の t400 で、累積精度損失は leaky −4.3 / ELU −3.1 / Snake −0.9 pt。この順序は **‖W̃‖（15.2 / 13.7 / 9.0）でも z̄（−8.3 / −8.3 / −1.6）でも同じように付く**。**n=3 の腕間相関では沈下と幅を分けられない。**

分けられるのは介入である。`width_sink_clamp_0909`（t21–100）では:

| 腕 | 状態 | 精度差 vs ref |
|---|---|---|
| leaky `dclamp` | 沈下を止め、幅は 75–97% 伸びる | +0.4 pt |
| leaky `wclamp` | 幅を止める（結果として沈下もほぼ止まる） | +1.3 |
| ELU `dclamp` | 沈下を止め、幅は 29–66% 伸びる | −0.2 |
| **ELU `wclamp`** | **幅を止めるが沈下は続く（−6.9、ref −6.5 より深い）** | **+1.1** |

ELU の 2 腕が「浅いのに戻らない／深いのに戻る」の両方を出しているが、**これは t61–100 の窓で、損失が出るのは t301–400 である**。**同じ介入を t400 まで伸ばして、長い地平線でも同じ乖離が成り立つかを決める。**

## 1. 走

開始状態・分岐は `width_sink_clamp_0909` と同一（init から t1–20 を 1 回、そこから bit 一致の t20 状態で分岐、毎更新クランプ）。**継続を t21–400 に伸ばす。**

| 腕 | 固定するもの | 実装 |
|---|---|---|
| `ref` | — | 無介入 |
| `dclamp` | m̄（沈下の実体） | 毎更新後、全行に同じ定数を足して m̄ = m̄(t20) |
| `wclamp` | ‖W̃ᵢ‖（中心化ノルム）を t20 の値 c_i に固定 | W̃ᵢ ← W̃ᵢ·c_i/‖W̃ᵢ‖ |
| `wcap2` | ‖W̃ᵢ‖ の**上限**を 2c_i（超えたときだけ射影） | ‖W̃ᵢ‖ > 2c_i のとき W̃ᵢ ← W̃ᵢ·2c_i/‖W̃ᵢ‖ |

`wcap2` は「t20 の水準に留め置く」と「成長を止める」を分けるための用量点。‖W̃‖ ∝ √t なので 2c_i には t ≈ 80 で達し、そこから拘束が効く。

腕: **LR・ELU1 × 4 クランプ × seed 0–2 = 24 継続。** Snake は沈下も幅も小さく `dclamp` がほぼ no-op なので入れない（対照は `long_horizon_0910` の ref を引く）。`mclamp` は t21–100 で精度に効かなかったので落とす。
測定はタスク終端のみ（`long_horizon_0910` と同じ）。1 継続 ≈ 10 分、2 プロセスで **合計 ≈ 30 分**。

## 2. 判定（事前登録）

窓は固定: **late = t301–400**、**base = t16–20**（クランプ開始時の水準・その seed の共有前置き）。精度は窓内タスク終端の中央値。

各 seed について
$$L_{\rm ref}=\mathrm{acc_{base}}-\mathrm{acc_{ref}(late)},\qquad
\rho_C=\frac{\mathrm{acc}_C(\rm late)-\mathrm{acc_{ref}(late)}}{L_{\rm ref}}$$

$\rho_C$ は「その腕が ref の累積損失の何割を取り戻したか」。$\rho=1$ で全部、$\rho=0$ で無効果。

**可検定性ゲート G0**: $L_{\rm ref}\ge 2.0$ pt。下回る seed はその腕の比を `NOT_TESTABLE_NO_LOSS` とする（`long_horizon_0910` の実測は leaky 4.4・ELU 4.0 pt なので通る見込み）。

**主判定**（腕ごとに、可検定な 3 seed が 3/3 一致したときだけ）

| 判定 | 規則 |
|---|---|
| **A 深さ** | ρ_dclamp ≥ 0.5 → `DEPTH_REMOVES_LOSS`／≤ 0.2 → `DEPTH_NO_EFFECT`／他 `DEPTH_PARTIAL` |
| **B 幅** | ρ_wclamp ≥ 0.5 → `WIDTH_REMOVES_LOSS`／≤ 0.2 → `WIDTH_NO_EFFECT`／他 `WIDTH_PARTIAL` |
| **C 乖離（ELU）** | ρ_wclamp ≥ 0.5 **かつ** z̄_wclamp(late) ≤ z̄_ref(late) + 1.0（沈下が止まっていない）→ `WIDTH_WITHOUT_DEPTH` |
| **D 乖離（両腕）** | ρ_dclamp ≥ 0.5 **かつ** ‖W̃‖_dclamp(late)/‖W̃‖_ref(late) ≥ 0.75（幅は伸びている）→ `DEPTH_WITHOUT_WIDTH` |
| **E 用量** | 3 seed とも −0.1 ≤ ρ_wcap2 ≤ ρ_wclamp + 0.1 → `WIDTH_DOSE_MONOTONE`／3 seed とも ρ_wcap2 > ρ_wclamp + 0.1 → `CAP_BEATS_CLAMP`／他 `DOSE_PARTIAL` |

**C と D は排他ではない。両方立てば「どちらを止めても戻る」＝ 分離できていない**（そのときは §5 の副測定で読む）。

**進捗ゲート**
- **G1（再現）**: `ref`・`dclamp`・`wclamp` の t21–100 のタスク終端が `width_sink_clamp_0909` の committed 出力（`zbar_inv`・`sigma_inv`・`star_sd`・`acc`・per-unit npz）と **maxabs ≤ 1e−10**。1 つでも外れたら全腕を無効として停止する。
- **G2（クランプの実効性）**: `width_sink_clamp_0909` と同じ検査（毎ステップ現状態・float32 の証明可能上界で床を張る）。`wcap2` は「‖W̃ᵢ‖ ≤ 2c_i·(1+1e−6) が全ステップで成立」かつ「拘束が効いていないステップでは W1 が差 0」。
- **G3（学習が壊れていない）**: late 窓のタスク内 CE 改善（更新 20 → 625）が 90% 以上のタスクで正。**精度でゲートしない**（精度が判定量なので循環する）。外れた腕seed は `NOT_TESTABLE_LEARNING_BROKEN`。
- **G4（`dclamp` が深さを保っている）**: |z̄_dclamp(late) − z̄_dclamp(t20)| < 0.25 × |z̄_ref(late) − z̄_ref(t20)|。
- **G5（`wclamp` が沈下を止めていない＝C の前提）**: ELU の `wclamp` で z̄(late) ≤ z̄_ref(late) + 1.0。満たさなければ C は `NOT_TESTABLE_DEPTH_ALSO_STOPPED`。

## 3. 事前予測（記名・走る前）

- **Issa（沈下側・Claude による読み替え。本人の確認は結果を読む前に取る）**: **A `DEPTH_REMOVES_LOSS`**。沈下を止めれば損失は消える。ELU の C `WIDTH_WITHOUT_DEPTH` は**立たない**（t61–100 で見えた乖離は短い窓の産物で、t400 では沈下の効果が勝つ）。
- **Claude（幅側）**: **A `DEPTH_NO_EFFECT`**（ρ_dclamp ≤ 0.2）、**B `WIDTH_REMOVES_LOSS`**（ρ_wclamp 0.5–0.8）、**C `WIDTH_WITHOUT_DEPTH` が立つ**、D は立たない、E `WIDTH_DOSE_MONOTONE`（ρ_wcap2 ≈ 0.3）。
- **分岐点は A と C。** A が `REMOVES` なら Issa、`NO_EFFECT` なら Claude。C が立てば幅側が決定的。
- **両者外れの形**: A・B とも `REMOVES`（どちらを止めても戻る＝介入では分離できない）か、A・B とも `NO_EFFECT`（損失の原因は第 1 層の外）。
- 通算: Issa 9/11 前後、Claude 3.5/11（`long_horizon_0910` で Claude は 4/4 外し、Issa は B が惜しい）。**重みは Issa 側に置く。**

## 追補 1（2026-09-10・**結果を読む前**・敵対的レビューの指摘 15 件を反映）

**登録時点の状態**: 本走は 1 度目の投入を 13 分で**停止**した（下記 R1 が走の最後で必ず落ちて出力を捨てるため）。**結果は 1 つも書かれておらず、判定量は一切見ていない**（読んだのはレビューの指摘と、既発表 `width_sink_clamp_0909` の検算値のみ）。腕・クランプ・窓・ρ の定義は変えない。変えるのは**ラベルの決め方とゲートの帰属**である。

### R1. 対照の下限が走の長さで育つ（blocker・実装）

`_controls` の反空虚下限は `100 × max(limit(ck_main, key), ck_main[key])` で、`limit` は `c5_mbar_abs` を **走全体の running max** `f32_rowmean_bound` で床上げする。一方 `dclamp/p90` の対照値は t21 だけを再走して測るので**走の長さに依らない定数**。t100 → t400 で ‖W‖ が約 2 倍になると下限だけが 2 倍になり、対照が下限を割る。既発表の検算値で確認: 余裕は t100 で LR s2 1.78×・ELU1 s0 1.82× なので、**t400 では 0.89×・0.91× で落ちる**。落ちるのは 400 タスクを回し切った後・出力を書く前なので、その腕seed の計算が丸ごと失われる。
**修正**: 対照の下限は、対照が実際に走る状態（t20）の床で評価する（`f32_rowmean_bound_t20` を `base` を取った直後に確定して使う）。

### R2. D の第 2 項が落ちようがない（blocker・判定）

D は「深さを止めても**幅は伸びている**のに損失が消える」という乖離のはずだが、第 2 項に **水準比** ‖W̃‖_dclamp(late)/‖W̃‖_ref(late) ≥ 0.75 を使っていた。`dclamp` は行平均に定数を足すだけで W̃ に触れないので、この比は構造的に 1 付近（既発表の t61–100 で LR 0.965–0.976・ELU1 0.993–1.001）。**D は事実上「A が REMOVES」と同じで、乖離の情報を持たない。**
**修正**: D の第 2 項を、§1 が較正に使ったのと同じ量 —— **late 窓の σ_inv の傾き比** `b_S(dclamp)/b_S(ref) ≥ 0.75` —— に差し替える（既発表で ELU1 は 0.29–0.66、LR は 0.75–0.97 なので、実際に落ちうる）。

### R3. ρ ≤ 0.2 が「害」を「無効果」に飲み込む（判定）

`ρ < 0` は「止めたら**悪くなった**」＝ 沈下が保護的だったという積極的な所見であって null ではない。旧規則ではこれが `NO_EFFECT` に落ち、§3 が「A が NO_EFFECT なら Claude」と読んでしまう。既発表を新規則で採点すると ELU1 の ρ_dclamp は t61–100 で **−0.39 / −0.20 / −0.06** で、まさにこの帯に入る。
**修正**: 害の帯を先に切る。**ρ ≤ −0.2 → `DEPTH_HARMS` / `WIDTH_HARMS`**、無効果は **−0.2 < ρ ≤ 0.2**。**`HARMS` はどちらの記名予測も支持しない**（両者外れ）と §3 に明記する。

### R4. `REMOVES` が「水準のずれ」と「蓄積が止まった」を分けない（判定）

ρ は late 窓の中央値だけで決まるので、**ref と同じ速さで落ち続けているが定数だけ上にずれている腕**（現タスクへの正則化利得）でも ρ ≥ 0.5 になる。区別する量（late 傾き）は §5 で「ラベル無し」にしてあったので判定に入らない。
**修正**: `REMOVES` に傾きの条件を足す。**ρ ≥ 0.5 かつ slope_late(C) ≥ slope_late(ref) + 0.3 pt/100task** のときだけ `REMOVES`。ρ ≥ 0.5 だが傾きが ref と同等（差 < 0.3）なら **`LEVEL_SHIFT_ONLY`**。

### R5. C・D がゲートを継承していない（実装・判定）

G0/G3 で無効になった seed は ρ が NaN になるが、C と D はそれを**否定側の `NOT_SHOWN`** に落としていた。§3 は「C が立てば幅側が決定的」なので、学習が壊れた seed のせいで幅側が negative に採点される。G4（`dclamp` が深さを保ったか）も A にしか掛かっておらず、**「深さを保てなかった」と「深さの機構が立った」が同じ行に並びうる**。
**修正**: ゲートとラベルの対応を明示する。

| ゲート | 無効にするラベル |
|---|---|
| G0（L_ref ≥ 2 pt） | A・B・C・D・E すべて → `NOT_TESTABLE_NO_LOSS` |
| G3（学習が壊れていない） | その腕のラベル（dclamp → A・D、wclamp → B・C、wcap2 → E）→ `NOT_TESTABLE_LEARNING_BROKEN` |
| G4（dclamp が深さを保つ） | **A と D** → `NOT_TESTABLE_DEPTH_NOT_HELD` |
| G5（wclamp が沈下を止めていない） | **C のみ** → `NOT_TESTABLE_DEPTH_ALSO_STOPPED` |

### R6. E が何も言っていない（判定）

`−0.1 ≤ ρ_wcap2 ≤ ρ_wclamp + 0.1` は ρ_wclamp が大きいと上端が自由になり、**「ρ_wcap2 が −0.1 以上」以上のことを言わない**。(0.02, 0.95) も (0.90, 0.95) も同じラベルになる。
**修正**: 用量を判定可能な帯に割る。**B が `REMOVES` でなければ E は `NOT_TESTABLE_NO_WIDTH_EFFECT`。** そのうえで
- ρ_wcap2 ≥ 0.5·ρ_wclamp − 0.1 → **`DOSE_GRADED`**（2 倍でも半分以上戻る＝水準に効く）
- ρ_wcap2 ≤ 0.2·ρ_wclamp → **`DOSE_THRESHOLD`**（2 倍まで許すとほぼ戻らない＝成長そのものが害）
- ρ_wcap2 > ρ_wclamp + 0.1 → **`CAP_BEATS_CLAMP`**
- 他 → `DOSE_PARTIAL`

### R7. §3 の裁定が同じ結果に 2 つの答えを出す（判定）

「A が REMOVES なら Issa」（無条件）と「A・B とも REMOVES なら両者外れ」が両立しない。
**修正**: 裁定を条件付きに置き換える（旧の無条件形は破棄）。

| A | B | 裁定 |
|---|---|---|
| `DEPTH_REMOVES_LOSS` | `REMOVES` **でない** | **Issa（沈下側）の勝ち** |
| `DEPTH_NO_EFFECT` または `DEPTH_HARMS` | `WIDTH_REMOVES_LOSS` | **Claude（幅側）の勝ち** |
| 両方 `REMOVES` | | **両者外れ**（介入では分離できない。§5 の共通下流量を読む） |
| 両方 `NO_EFFECT`/`HARMS` | | **両者外れ**（損失の原因は第 1 層の外） |
| いずれかが `LEVEL_SHIFT_ONLY` | | その腕は「蓄積を止めた」と数えない。裁定は残りの組み合わせで読む |

**C は裁定を上書きしない**（幅側の**追加の**証拠として読む）。D も同様。

### R8. 実装側の残りの修正（すべて検査の実効性・判定量は不変）

- C6（分散分解の恒等式）が記録されるだけで assert されていなかった → `TOL` に追加し、`decompose_crosscheck` と C6 の変異対照を足す。
- `_assert` が **ck に無いキーを黙って飛ばす** → 全 `TOL` キーの存在を要求する（短走フラグのときだけ免除）。
- G1 の per-unit 側に**件数のガードが無い**（キーが 1 つも一致しなくても 0.0 で通る）→ 期待件数（3 クランプ × 80 タスク × 5 量）を要求。さらに §4 が登録済みの **G1 変異対照（初期値 +1e−3）が実装されていなかった**ので足す。
- `cap_bind_steps > 0` を長走で要求する（上限が一度も効かない `wcap2` は `ref` と同じもの）。
- `cap_wt_shrinks` の assert は構造上落ちない → 「拘束したステップで行ノルムが 2c_i に 1e−6 で復元している」に置き換える（`cap4` 変異で落ちる）。
- 登録済みの `cap4` 変異が**呼ばれていなかった** → 上限超えの合成状態から `loop` を 1 タスク回して、ループ内の検査が発火することを確かめる。
- `clamp_tail_absdiff`（bias・W2・W3 を触らない）は恒真 → `tail` 変異対照を足す。
- `c5_sd_rel` の対照が無かった → 既存の `dclamp/rowscale` 変異が実際に壊すので、その値を読んで assert する。

**以上はすべて結果を見る前の修正である。** 修正後にコードを commit し、走り直す。
