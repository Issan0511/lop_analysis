## 0. 何を決めるか

Issa の区別: 「深いところに残っているから使えない」とも「ゲートが残るからちゃんと使われている」とも、まだ言えない。ユニットごとに **ゲート**（φ′ の入力平均）・**更新**（実際に動いた重み）・**貢献**（そのユニットを消したときの損失変化）を同時に測らないと、低ゲート集団が「くすぶっている」のか「Adam に補償されて動いている」のか「動かないが有用な特徴を保持している」のかが分からない。

事後の材料（未登録・9/10 夜の手元集計）: leaky ではゲート下位 10% のユニットのほうが ‖W̃ᵢ‖² の増分が大きい（0.80 対 上位 0.48）。ELU では下位 10% がほぼ止まる（0.12 対 0.44）。これは **Adam の座標正規化が leaky の 0.1 倍を消している**（深い leaky ユニットは「利得 0.1 の線形ユニット」として更新され続ける）という読みを示唆するが、更新の大きさは ‖W̃ᵢ‖ の正味増分でしか見ていない。本 spec で毎更新の歩幅と貢献を測る。

同時に、**主軸 B の更新条件**（V9 §10: wclamp と ref の間で ρ と同じ順序で動く機能量）に対し、個体別の量のどれが wclamp で動くかを記述する。

## 1. 走

箱 B・committed の host。**LR / ELU1 / SNA × seed 0–2 = 9 走。** t1–20 を共有前置き、t20 状態から `ref` と `wclamp` の 2 分岐を t21–100（`width_sink_clamp_0909` と同一の分岐点・同一の射影実装）。**両分岐とも committed の per-unit 配列（`width_sink_clamp_0909`・6 配列 × t21–100）を bit で再現しなければならない**（G1）。訓練ループの 1 更新は committed の `C.loop` と文字どおり同じ式（Adam・射影・検査）で、計装は `no_grad` の読み出しだけ。

**測定（両分岐）**

毎タスク終端（t21–100）:
- ゲート: ḡᵢ = mean_x φ′、offᵢ = P_x[φ′ < 0.25]（固定プローブ 512 枚・現置換）、hard-dead フラグ（max_x |φ′| < 1e−6）
- 読み出し代理: rᵢ = ‖W2[:, i]‖ · sd_x(a1ᵢ)
- 既存の per-unit 測定（zbar_i・sd_i・cnorm_i・m_i・bias_i・star_i）と test 精度

late 窓 t61–100 では加えて:
- **更新（毎更新の帳簿）**: dW̃ᵢ,s = 更新後 − 更新前 の第 1 層行 i の中心化成分（射影後の**実現した**更新）。S²ᵢ = Σ_s ‖dW̃ᵢ,s‖²（歩幅の予算）、D²ᵢ = ‖Σ_s dW̃ᵢ,s‖²（タスク増分）、ρᵢ = D²ᵢ / S²ᵢ（経路持続・[1, 625]）。κ2ᵢ = Adam 状態から作った正規化歩幅 (m̂/(√v̂+ε))² の行 i・784 座標・625 更新の平均（射影前の Adam の一歩）。graw²ᵢ = 生勾配 ‖∂L/∂W1 の行 i‖² の 625 更新平均。
- **貢献（タスク終端）**: 平均置換アブレーション ΔCEᵢ = CE(a1 の列 i をプローブ平均で置換) − CE（固定プローブ 512 枚・現置換）。t61・t80・t100 では test 1 万枚の Δaccᵢ も。

## 2. 量の定義（登録）

Spearman はユニットにわたって（hard-dead を除く）、タスクごとに取り、late 窓の中央値 → seed 中央値。

- **B1 ゲート → 歩幅**: ρ_S = Spearman_i(ḡᵢ, S²ᵢ)、ρ_g = Spearman_i(ḡᵢ, graw²ᵢ)、ρ_κ = Spearman_i(ḡᵢ, κ2ᵢ)、ρ_D = Spearman_i(ḡᵢ, D²ᵢ)。`ref` 分岐で判定。
- **B2 慢性の芯**: core = t81–100 の**すべて**でゲート下位 10% にいたユニット（`ref` 分岐）。芯の貢献比 = median_{i∈core} |ΔCEᵢ| / median_{i∉core} |ΔCEᵢ|（late 窓・タスク中央値）。
- **B3 wclamp で動く量**（同 seed の対・late 窓中央値の wclamp − ref）: Ḡ = mean_i ḡᵢ、Cov = mean_i offᵢ、S² = mean_i S²ᵢ、ρ = mean_i ρᵢ、κ2 = mean_i κ2ᵢ、graw² = mean_i graw²ᵢ、参加数 P = exp(H(pᵢ))（pᵢ = |ΔCEᵢ| / Σ|ΔCE|・貢献の実効ユニット数）、Gini(|ΔCE|)、‖W2col‖ の平均、hard-dead 数。

## 3. 判定（事前登録）

**B1（腕ごと・3 seed が同じ帯に入ったときだけ。混在は `MIXED`）**

| 条件 | ラベル |
|---|---|
| ρ_g ≥ +0.5 かつ ‖ρ_S‖ ≤ 0.2 | `ADAM_COMPENSATES`（ゲートは生勾配を決めるが歩幅は決めない） |
| ρ_g ≥ +0.5 かつ ρ_S ≥ +0.5 | `GATE_SETS_STEP`（補償されない） |
| ρ_g ≥ +0.5 かつ ρ_S ≤ −0.5 | `GATE_INVERTS_STEP`（低ゲートほど大きく動く） |
| ρ_g < +0.5 | `GATE_NOT_EVEN_GRADIENT`（ゲートが生勾配も並べない） |
| 他 | `PARTIAL` |

**B2（腕ごと）**

| 条件 | ラベル |
|---|---|
| core が 3 seed とも空 | `NO_CORE` |
| 貢献比 ≤ 0.2（core が空でない seed すべて） | `CORE_INERT` |
| 貢献比 ≥ 0.8 | `CORE_CONTRIBUTES` |
| 他 | `CORE_PARTIAL` |

**B3（量ごと・3 腕 × 3 seed = 9 対）**: 9 対すべてで同符号かつ seed 中央値の相対変化 ≥ 10% → `<量>_UP` / `<量>_DOWN`；他 → `<量>_STATIC`。2 水準しか無いので「ρ と同じ順序」は検定できない。**B3 は記述ラベルであり、候補の絞り込みに使う**（動かない量は主軸 B の経路候補から外す）。

## 4. 進捗ゲートと変異対照

- **G1（再現・両分岐）**: `ref` と `wclamp` の per-unit 6 配列 × t21–100（480 配列ずつ）と前置き t1–20（`ref`・6 配列 × 20）が `width_sink_clamp_0909` の committed 出力と **maxabs ≤ 1e−10**、件数ガード付き。変異対照: 初期値 W1[0,0] += 1e−3 で t1 が 1e−4 超で外れる。計装の非侵襲: 計装は読み出しのみ。G1 が両分岐で 0.0 なら計装は軌道を動かしていない。
- **G2（射影の実効性）**: committed の `c3_cnorm_rel`・`c3_m_absdiff`・`clamp_tail_absdiff` とその変異対照（skip / rowscale / tail）。
- **G3（Adam の一歩の再構成）**: `ref` 分岐で、Adam 状態から再構成した一歩と実現した更新の差が相対 1e−6 以内（`step_persistence_0910` C5 と同じ）。β₁ を 0.8 にした対照で 1e−2 超。
- **G4（帳簿の恒等式）**: 1 ≤ ρᵢ ≤ 625(1+1e−9)（Cauchy–Schwarz）。Σ_s dW̃ᵢ,s = W̃ᵢ(終端) − W̃ᵢ(開始) が 1e−12。
- **G5（アブレーションの健全性）**: W2 の列 i を 0 にした複製で ΔCEᵢ が厳密に 0（他ユニットの経路に触れていない）。全 100 ユニットを同時に平均置換するとプローブ精度 ≤ 0.2（定数予測に落ちる）。
- **G6（学習が壊れていない）**: late 窓でタスク内 CE 改善（更新 20 → 625）が 90% 以上のタスクで正。
- 時間上限 1500 s / 走。
