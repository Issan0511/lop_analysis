# 深さ2のT5複製実験（基準走の結果を見る前に登録）

前goal turnはprogress: T5の定義訂正、深さ2の基準走を開始、複製軸の測定式を独立なautogradで検算した。基準走の起動は2026-10-25 06:18:54 UTC。以下の実測・複製は本specとrunnerのcommit、およびgate成功後に行う。

## 対象と条件

基準走seed0–4、課題10/60、更新100/500、FFN1/2を全て用いる。計40状態。100更新時点を無条件に「適合後」とは呼ばず、各状態のCE・正答率を残す。

対象FFNのfc1（weight+bias）だけを学習する。他の全パラメータを固定し、対象FFNの入力uおよび残差hを同じ画像からcacheする。前段の輸送を除いた局所機構の実験であり、網全体を学習する通常走への寄与率を直接返すものではない。後段は元のCE・残差・LayerNormをそのまま通す。

各状態で以下の2 optimizerを別々に比較する。

- **固定計量SGD**: `w←w−η D_w g_w, b←b−η D_b g_b`。η=1e−4。Dは起点のAdamのbias-corrected second momentから`1/(sqrt(vhat)+1e−8)`として一度だけ計算し固定。momentumなし。結果に応じた学習率調整はしない。これは実Adamと同じ大きさの有限変位を保証する条件ではない。
- **実Adam**: 起点の保存されたAdam状態を毎複製へ複製し、そのまま継続する。対象fc1以外のgradはNone。過去の標本履歴を持つ条件なので「雑音を一度も入れていないモデル」とは呼ばない。

各optimizerで、**32独立複製のiid標本抽出（batch128、復元抽出）と、1本のfull-batch（全250画像）**を50更新。画像とラベル、初期パラメータ、初期optimizer状態を同じにする。元走のreshuffleとは標本法が違う。これは次の勾配の条件付き期待値を全画像勾配へ一致させるためで、元走の完全再現ではない。

抽出seedは親seed・課題・起点step・対象layer・複製番号から固定hashで作る。同じ複製番号は固定計量とAdamで同じ標本列を使う。full-batchは同じ更新回数・学習率。勾配をchunk32で足し、常に画像数で正規化する。

全状態の固定計量を先に実行し、次に全状態のAdamを行う。基準走の保存状態がまだ無ければ、その状態の診断を始めない。時間切れ・エラーで中断しても完了した複製を再使用できるが、source/config一致を必須とする。結果によるseed選別、複製延長、条件変更はしない。

## 記録と評価

更新0/1/5/20/50で対象fc1のweight・biasを保存。全250画像のCLSでμ・unbiasedσ・r=μ/(σ+1e−12)、σ>1e−8のvalid、開口率をunit・複製別に再計算する。同じ時点でCE・精度を記録する。

固定した画像・tokenごとに、複製間の`c=∂L_image/∂ReLU(z)`、χの共分散を測り、`t5_measurement.md`の式によって平均場項・ゲート共分散項・全体をunit別に記録する。固定計量での次の期待Δμについて全画像autogradと照合する。実Adamにも同じ**固定計量で見た勾配診断**を適用するが、実Adamの次の変位の分解とは呼ばない。

32本を固定した前半16本・後半16本に分けた共分散源も出し、有限複製での符号の安定性を見る。恒等式用の共分散は1/R。不偏推定量を併記する場合はR/(R−1)倍。自己の活性–ゲート共分散の非負性は恒等式の確認であり、T5の優勢の証明ではない。

主要な読み方:

1. 標本抽出ありの複製平均の有限Δμ・Δrと、full-batchの有限Δμ・Δrとの差を示す。これは標本雑音を追加した総効果。
2. ゲート共分散項のunit平均が下向きか、前半・後半の複製でも符号が保たれるかを示す。5seed中の成立数を課題・起点step・layer別に全部示す。unitを独立な標本数として有意性を水増ししない。
3. 雑音の総効果が下向きでも、ゲート共分散項が上向き・微小ならT5が説明したとはしない。逆に共分散項が下向きでも、全体が相殺・上向きなら「T5が存在するが正味の沈降を支配しない」と区別する。
4. 相2の支配を支持するには、浅いblockで通常学習の沈降がある窓と対応し、固定入力の共分散の押し・雑音の総効果がともに下向き、実Adamでも同方向である必要がある。それでも局所固定実験から網全体の因果割合は断定しない。固定計量だけで成立する場合は限定的な支持。
5. source/totalの符号付き比は相殺で不安定になりうる。まずμ単位の数値を出す。比を出すなら分母・符号・相殺度も併記し、全相2の因果割合とは呼ばない。

Gate: synthetic基準走の保存checkpointで両block・両optimizer、3複製+full-batch、3更新を使う。cacheしたforwardと元forward、fc1以外の不変性、複製再読込、初期共分散0、共分散台帳と全画像autogradの一致を確認する。gateの数値をViTのT5の実測として扱わない。再開は完成済み複製を読み、未完了複製だけ同じ初期状態から再実行する。

生データは`obsidian-research-data/vit_two_block_1025/t5/`へ。最低25GiBを維持し、他の学習を止めない。一次資料は`t5_definition.md`に記録済み。相1の整列介入とunitの対応は同じ2block状態から別途測り、6blockの対応率を移用しない。
