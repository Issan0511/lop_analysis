## 0. 一行

## 2. 何を分けるか

### 2.1 片道と滑らかさ

可動度 $\phi'(z)$ で 3 つの活性化関数を並べる。

| | $z>0$ | $z\le0$ | 片道か | 滑らかか |
|---|---|---|---|---|
| ReLU | 1 | **0** | 片道（厳密な吸収） | 折れ目 |
| ELU（$\alpha=1$） | 1 | $e^{z}$ | 片道でない（深いほど遅い） | 滑らか |
| leaky ReLU（$a=0.1$） | 1 | **0.1**（定数） | 片道でない | 折れ目 |

ELU だけでは「片道でないこと」と「滑らかであること」を分けられない。leaky ReLU は折れ目を残したまま片道だけを外すので、**両方を並べて初めてゲートの性質を切り出せる**。$a=0.1$ を選ぶ理由: 負側の可動度が 10 倍遅いだけで減衰しない（ELU の $e^{z}$ と対照的）。$a=0.01$ は 100 倍遅く、5M の地平では ReLU との差が曖昧になりうるので採らない。

### 2.2 前段で消える 2 つの混入

- **第2層の自己生成 µ**（`ELU沼_spec_0830` §2.1–2.2）: 隠れ 1 層なので存在しない。入力の µ はオラクル固定で厳密に一定
- **上流の学習の混入**（`ELU沼結果_0830` §5）: 隠れ層の入力が固定なので、壁座標の増分 $\Delta\bar z_i$ は自前の勾配だけになる。**Q2（可動度スケーリング・駆動対雑音比）を汚染なしで測れる初めての配置**（§5.4）

### 2.3 3 つの帰結（どれが出ても情報になる）

| ELU（帯内） | leaky（帯内） | 読み |
|---|---|---|
| 発症せず | 発症せず | **ゲートの片道性が load-bearing**。用量はゲート条件付きの率 |
| 発症 | 発症せず | ELU の $e^{z}$ 減衰は高用量では軟らかい壁として働く。片道性でなく**可動度の減衰**が効く |
| 発症 | 発症 | 用量はゲートを経ずに効く（ノルム成長・マージン枯渇）。**柱2 の書き方を疑う** |
| 発症せず | 発症 | 滑らかさ（復元力）が効いており、片道性の除去だけでは足りない |

### 2.4 本走が答えないこと

- **無限時間の主張**。$n_{\rm onset}=0/10$ で言えるのは「5M までに観測しなかった」まで（`柱3定用量5M_spec_0830` §5.2 の強さの制限を継承。0/10 の片側 95% 上限 $p\le0.2589$）
- Adam・幅・多層・他教師（rsl_rl への接続は予測のまま）
- $\alpha$・$a$ の掃引。単一値
- 過剰パラメータ化比のスコープ条件（`過剰パラメータ化とスコープ条件_0829`）: w100 × LTU 幅 100 で測った結果。引用時に付す

## 4. 設計

### 4.1 腕（9 本）

| 腕 | 活性化 | 用量 | 目標 ‖µ‖ | 位置づけ |
|---|---|---|---|---|
| `R_off` | ReLU | 固定なし（中央 12.17） | — | `dose_const_5m_0830` `dose_off` を bit 再現（S0'） |
| `R_933` | ReLU | 9.33 | 2.333 | 同 `dose933` を bit 再現（S0'） |
| `R_1216` | ReLU | 12.16 | 3.041 | 同 `dose1216` を bit 再現（S0'） |
| `E_off` / `E_933` / `E_1216` | ELU $\alpha=1$ | 同上 | 同上 | **主対象** |
| `LR_off` / `LR_933` / `LR_1216` | leaky $a=0.1$ | 同上 | 同上 | **片道性の対照** |

用量 3 点で足りる理由: 5M では ReLU が 3 点とも 10/10 発症しており（commit 済み）、帯内の中間点を刻む意味が無い。`R_off` を残すのは無介入（$\gamma\equiv0$）の基準として。

**ReLU 3 腕を本走に含める理由**: commit 済みの値は引けるが、**全 paired 対比を同一走の腕で取る**ため。コストは §6。

### 4.2 対応づけ

活性化の変更もオラクル固定も乱数を消費しないので、9 腕は init・教師・入力列・flip 軌道が bit 一致する（S-pair）。**ただし活性化の異なる腕は step 1 以降で軌道が分岐する**（`ELU沼_spec_0830` §4.2）。ペアリングが落とすのは init・教師・入力実現の分散だけ。引用時にこの一行を落とさない。

### 4.3 実装

`VecMLPL` は `elu_swamp_0830` で `act ∈ {relu, elu}` を持つ。追加は leaky のみ。

- 前向き: `where(pre>0, pre, a*pre)`
- 後ろ向き: `where(pre>0, 1, a)`
- ELU の後ろ向きは `alpha*exp(pre)`（`ELU沼_spec_0830` §11.9。`phi+alpha` は float32 で深い負側が 0 になる）
- **ReLU 経路は 1 行も触らない**（S0' が守る）。閉形式のまま、autograd に切り替えない
- 用量固定は `dose_const_5m_0830` のオラクルモードをそのまま使う。**活性化に依存しない**（入力側の変換）

### 4.4 用語

- ReLU 腕: `strict_dead`（$\hat p_i\equiv0$）
- ELU / leaky 腕: **沈下** $\max_{x\in32}z_i(x)\le0$、`submerged_frac`（`用語と記号` に登録済みの定義）
- **どちらも verdict に使わない。** 沈下は死ではない（leaky では可動度 0.1、ELU では $e^{z}$ が残る）。§5.3 で「予測の照合」にだけ使う

## 5. 集計（事前登録）

窓・床・CI は `柱3定用量5M_spec_0830` §5 を逐語継承する。

- **5M 末尾窓** = タスク 491–500、**1M 窓** = タスク 91–100、早期窓 = タスク 2–11
- 各 seed の窓平均 未フィット率 $U_k$（床 **1e-16**・`dose_const_5m_0830` で較正済み・再較正しない）
- **発症 = $U_k\ge0.05$**（Phase 0 から継承。変更しない）
- CI: $n_{\rm onset}$ は Clopper–Pearson。差は seed クラスタ paired bootstrap、B=10000、`rng=np.random.default_rng(20260829)`、percentile を主、studentized は退化検出つきの副

### 5.1 主 endpoint — 発症数（活性化 × 用量の 9 セル）

**P1**: 各腕の $n_{\rm onset}(5\mathrm{M})$。**P2**: 各腕の $n_{\rm onset}(1\mathrm{M})$。

**主 verdict**（ELU と leaky の帯内 2 腕、`*_933` と `*_1216` で判定。`*_off` は参考）

| ELU 帯内 2 腕 | leaky 帯内 2 腕 | verdict |
|---|---|---|
| ともに $n_{\rm onset}(5\mathrm{M})=0$ | ともに 0 | **`GATE_LOAD_BEARING`** |
| いずれかで $\ge5$ | ともに 0 | **`SOFT_WALL_AT_HIGH_DOSE`** |
| いずれかで $\ge5$ | いずれかで $\ge5$ | **`DOSE_NOT_GATE_MEDIATED`** |
| ともに 0 | いずれかで $\ge5$ | **`SMOOTHNESS_REQUIRED`** |
| 上記以外（1–4 が混じる） | | **`PARTIAL`** — §5.2 の水準側で読む |

ReLU 3 腕は S0' で bit 再現されるので $n_{\rm onset}(5\mathrm{M})=10/10$ が**既知**。ReLU 側が 10/10 でなければ S0' 不合格であり結果を読まない。

**強さの制限**: `GATE_LOAD_BEARING` は「5M までに発症を観測しなかった」まで。**「用量はゲートが無ければ無限時間でも効かない」とは書かない。**

**飽和ガード**（教訓⑪）: 二値 endpoint が予測どおり 0 に揃った場合、**程度**の情報は持たない。§5.2 の水準側を同格で報告する。

### 5.2 水準（主判定と同格）

- 各腕の seed 中央値 $\log_{10}U(5\mathrm{M})$、$\log_{10}U(1\mathrm{M})$
- **P3（活性化の効果）**: 同一用量での paired Δ $\log_{10}U(5\mathrm{M})$、ELU − ReLU および leaky − ReLU（3 用量それぞれ）
- **P4（ゲート無しでの用量の効果）**: ELU 内・leaky 内で $\log_{10}U(5\mathrm{M})$ の paired Δ、`*_1216` − `*_933`。**ゲートが無くても用量が水準に効くか**を見る

| P4 | 読み |
|---|---|
| CI が 0 を含む | 用量はゲートを通してのみ効く |
| CI が 0 を上に外す | ゲートが無くても用量は学習を遅らせる（Clevert の効率経路） |

- 跳び $J$（隣接用量間の $\log_{10}U$ 差の最大）を活性化ごとに報告。verdict には使わない

### 5.3 予測の照合（沈下率・REPORT_ONLY）

§7 の予測「strict_dead 相当は 0 近傍」を照合するための凍結閾値: **5M 末尾窓の `submerged_frac` seed 中央値 < 0.05 を「0 近傍」とする。** ReLU の参照値は `dose_const_5m_0830` の 5M `strict_dead` 98–99（REPORT_ONLY）。**verdict に使わない**（§4.4）。

### 5.4 副次 — 汚染なしの Q2（REPORT_ONLY・事前登録）

`ELU沼_spec_0830` §5.2 の P2a（可動度スケーリング $\beta$）・P2b（駆動対雑音比 $\rho$）を、**隠れ 1 層で**測り直す。定義・ビン（等頻度 12 分位・自然対数・始点条件付け・タスク内隣接記録点）・閾値（$\beta$ の CI が 1 を含む → `MOBILITY_SCALING`、$|\rho|<0.1$ → `NOISE_DOMINATED`、$|\rho|\ge0.3$ → `DRIFT_DOMINATED_*`）は同 spec §5.2・§11 を逐語継承する。

- 対象は ELU 3 腕・leaky 3 腕。leaky の可動度は定数 0.1 なので **$\beta$ の期待値は 0**（ELU の 1 と対照）。leaky で $\beta$ の CI が 0 を含み ELU で 1 を含めば、可動度の絵が両方で確認される
- **沈下ユニットが seed あたり 3 未満の腕は `INSUFFICIENT_DATA`**。§7 の予測どおり沈下が起きなければ本節は空振りする。それでよい
- `logs/*.npz` に `layer1_zbar` を保存し、ビン集計を `increments.csv` に出す

### 5.5 その他の副次（REPORT_ONLY）

`strict_dead` / `submerged_frac` / `alive` / `eff_rank` / `‖w‖` / `median_M` / `median_B` / `preact_sd_median` の時系列。実測 $\gamma(k)$ と $\cos(\boldsymbol\mu,\boldsymbol\mu|_{\gamma=0})$。`eval_loss_exact` の用量反応。**`‖w‖` は主要共変量**（継続）。

`ELU沼結果_0830` で `E_none`（2 層・ELU・入力 dose ≈ 12・lr 0.01）が step 281000 に発散した。**本走の ELU 帯内腕は同じ条件に近い。** 扱いを事前登録する。

- **S-submerge**: 沈下判定が ReLU 腕で `strict_dead` と完全一致
- **S-taut**: 判定指標（未フィット率）とサニティ側の双方で、活性化の変更が定義上恒真になっていないこと
- **S1**: `OMP_NUM_THREADS=1`。**S6**: 床は継承・再較正しない（`floor_calibration.csv` を参照するだけ）
- **本走前に §5 の集計は一切しない。**
