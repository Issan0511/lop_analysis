## 1. 問い

性質 A（正斉次な整流が隠れ層に用量を作り直す）と性質 B（片道ゲート）の**多層での分離**が未測定である（[[中心主張v4.2草案_0830]] 積の構造・格）。leaky ReLU（$a=0.1$）は**正斉次なので A を持ち**（閉形式比 $g=0.585$・導出・未検証）、**負側可動度 0.1 なので B を持たない**。2 層 leaky 網の第1層だけを中心化したとき、**第2層に用量が立ち、かつ死なない**ことが観測されれば、「A は B が無ければ無害」が多層で閉じる。

## 2. 設計

- condA: `m=20`, `f=15`, teacher width 100, `T=10,000`, batch 1（[[多層Phase1結果_0829]] と同一）
- learner: **2 隠れ層 × 幅 100・leaky ReLU（negative slope $a=0.1$）**、plain SGD、`lr=0.01`
- centering: **第1層（学習器入力）のみ** `center_alpha=0.01` の EMA。教師は生入力
- seed 0–9、**5M step**（確証走は 5M 直行・[[9月運用_0901]] §3-5）、CPU、`OMP_NUM_THREADS=1`
- 新規走は 1 腕（`LR_A1`）。対照は committed 済みの `mlp2_phase1_0829/L2_A1`（ReLU 同配置）と `elu_swamp_0830/E_A1`（ELU 同配置）
- ペアリングは **init・教師・入力実現まで**（step 1 以降は軌道が分岐。「同一個体の追跡」と書かない）
- ロガー相乗り（[[9月運用_0901]] §3-2）: `M`・`B`・`denom`・`submerged`・per-layer 統計（`layer_stats` 相当）・境界スナップを既定で積む。P-3（$s_i=M_i+B_i$ 指標）の入力になる

## 5. 事前登録判定（案・凍結時に確定）

実験単位は seed。主窓は task 451–500（task-end 50 点・seed 内平均）。paired percentile bootstrap 95% CI（10,000 回・**bootstrap seed = `202609011252`**）。**既用値と重ねない**: `20260829` / `20260901` / `20260902` / `20260903` / `20260904` / **`20260906`（`channel_2x2_0901`）** ／ 今回追加: **`202609011252`（`lr_a1_0901`）**。**`generator_offset = 0`（対照 `L2_A1`・`E_A1` とのペアリング維持のため新規系列を作らない。既用の `20260830` / `20260831` / `20260905`（`channel_2x2_0901`）は使わない）**。studentized fallback と退化ガードを併記（教訓⑬）。**総和と率の両方**を endpoint に書く（教訓⑰）。**等価限界 Δ を事前登録**（「CI が 0 を含む」を判定不能と区別）。

- **P1（性質 A・閉形式が多層で立つか）**: 第2層 dose（late 窓 `late_t451_500`・10 seed 中央値）の percentile bootstrap 95% CI（seed 再抽出・B=10,000・seed `202609011252`）が、**閉形式予測 5.85 を中心とする帯 [5.35, 6.35]（= 5.85 ± Δ_dose、Δ_dose = 0.5）に収まるか**。
  - 収まる → `A_CLOSED_FORM_MATCH`
  - CI 全体が帯の外 → `A_DOSE_OFF_PREDICTION`（実測値と、λ 補正版中心 6.15（= 5.85 × 0.7183/0.6833・ReLU の実測/閉形式比を流用）での再読みを report に併記。**登録判定は 5.85 中心のみ**）
  - CI が帯の境界をまたぐ → `INCONCLUSIVE_WIDE`
  - **⚠ `L2_A1`（7.18）との生差 `LR_A1 − L2_A1` は判定に使わない。** 予測どおり（5.85）でも生差は −1.33 となり ±0.5 の等価に設計上入らない。7.18 との分離は「leaky の帯 [5.35, 6.35] が ReLU の実測 7.18 を含まない」ことの確認として報告のみ
- **P2（性質 B なしで死なないか）**: 末尾 `log10 U`（5M・`log10(mean unfit)` 側）の対 `L2_A1` paired Δ（seed 対応・percentile bootstrap・B=10,000・同 seed）。次の順で評価する。
  1. **主（符号条件・必要条件）**: Δ の 95% CI 上端 < 0（ReLU より改善・`E_A1` と同符号）
  2. **「同程度」の読み**: Δ の**点推定**が `E_A1` の登録区間 [−1.098, −0.696] に入る → `A_WITHOUT_B_HARMLESS_MULTILAYER`。**区間より下（より強い改善）も同ラベル**（改善が強い側を失敗にしない）。区間より上かつ 1 が真 → `PARTIAL_IMPROVEMENT`（片道性の除去は効くが ELU 級ではない）
  3. 1 が偽（CI 上端 ≥ 0） → `A_WITHOUT_B_NOT_CONFIRMED`
  - 注: 他走の CI を受け入れ帯に使うのは統計的には粗い（`E_A1` の CI は `E_A1` の推定不確かさであって許容幅ではない）。よって「同程度」は**記述的な**読みに格を下げ、判定の主軸は 1 の符号条件に置く
- **P3（報告のみ）**: `submerged_frac`・可動度・$s_i$ 分布。verdict に使わない
