## 1. これは事前登録ではない（格の宣言）

対象の数値は 8/22 のチャットで**既に見ている**。したがって真の事前登録は原理的に不可能である。本 spec は「再現登録」であり、二つの格を混ぜずに扱う。

- **repro tier** — 旧値があるもの。「再現の許容幅」を結果を見る前に凍結する。再現しなければ旧値を撤回する
- **prereg tier** — 旧値に無いもの（CI、等価幅判定、符号分率の区間）。**これは真の事前登録として成立する**

`verdict.csv` に `tier` 列（`repro` / `prereg` / `report`）を置き、論文引用時に格を区別できるようにする。

## 3. 標本サイズの事前確認（結果ではなく設計値）

`p̂_prev == 0` の隣接ペア総数（10 seed、境界含む）= **16,556,046**

8/22 の主張値 16,475,293 との差 = **80,753**。境界ペアは 99 境界 × 10 seed = 990 ペアなので、990 × 81.57 ≈ 80,753。すなわち **旧値は非境界ペア限定の集計**である。spec ではこの定義を明示し、境界ペアは A1-d の対照として別枠で扱う。

## 4. 定義（事前固定）

| 記号 | 定義 |
|---|---|
| `off(i,s)` | `p_hat[s,i] == 0`（厳密なゼロ。近似閾値を使わない） |
| 境界ペア | `(s, s+1)` で `step[s] % 10**4 == 0` かつ `step[s+1] - step[s] == 1` かつ `step[s] > 0` |
| 非境界ペア | 上記以外の隣接記録ペア |
| `x_i(s)` | `w_norm * mu_norm * cos_u_mu + b`（前活性の µ̂ 平行成分＝有効バイアス） |
| 復活 | `off(i,s)` かつ `not off(i,s+1)` |
| 窓 | タスク周期 T=10⁴ 単位（A5 で使用） |

**境界判定は `step[s] % T` で行う。`step[s] // T` は使わない**（8/19b の既知のオフバイワン）。

## 5. 判定基準（結果を見る前に凍結）

### A1 — 片側吸収の厳密性

| ID | tier | 内容 | 基準 |
|---|---|---|---|
| A1-a | repro | 非境界・`off_prev` ペア数 | **16,475,293 に厳密一致**。一致しなければ集計定義の食い違いなので、A1-b 以降に進む前に定義を確定させる |
| A1-b | prereg | 同ペアでの復活数 | **= 0（厳密）** |
| A1-c | prereg | 同ペアでの `max|Δcos_u_mu|` | **= 0.0（float32 厳密）** |
| A1-d | prereg・対照 | **境界**・`off_prev` ペアでの復活数 | 報告。0 より大きければ「復活は境界でのみ起きる」が示され、柱2 の天井の記述をこれに置き換えられる |

**FAIL 時**: A1-b または A1-c が破れたら「p̂=0 → 勾配恒等ゼロ → 凍結」の構造主張を撤回し、v3 柱2 の吸収の記述を作り直す。

### A2 — 撹拌はほぼ対称

| ID | tier | 内容 | 基準 |
|---|---|---|---|
| A2-a | repro | 符号比 | 49.7 : 50.1 が **±0.5pt** で再現 |
| A2-b | repro | +µ 側訪問率 | 94.9% が **±1.0pt** で再現 |
| A2-c | **prereg・主判定** | 符号分率 p₊ の seed クラスタ bootstrap 95% CI | **CI が等価幅 [0.48, 0.52] に完全に含まれる → PASS（ほぼ対称）**。CI が等価幅をはみ出すが 0.5 を含む → INCONCLUSIVE。0.5 を含まない → 「対称」を撤回 |
| A2-d | prereg | 終端（最終記録点）での復活数 | = 0 |

8/22c で「対称性は棄却」と書いて 8/22d で自ら撤回した往復がある。**同じ往復を防ぐため等価幅 [0.48, 0.52] を結果を見る前に固定する**。

### A3 — 生存者は整列していない

| ID | tier | 内容 | 基準 |
|---|---|---|---|
| A3-a | **prereg・主判定** | 生存ユニット間の符号付きペア cos の平均、seed クラスタ bootstrap 95% CI | **CI が [-0.10, 0.10] に含まれる → PASS（整列していない）** |
| A3-b | prereg・対照 | 死亡ユニット間の同量 | 生存 < 死亡 が CI で分離するか |
| A3-c | report | `eff_rank`（生存 / 死亡 / 全体） | 判定なし |

**FAIL 時**: 「生存者は整列していない」を撤回する。旧理論（整列が生存機構）の再検討は**別 spec** とし、本 spec では撤回の事実と数値のみ記録する。

### A4 — 境界あたりハザードは一定

| ID | tier | 内容 | 基準 |
|---|---|---|---|
| A4-a | repro | `analysis/q3_boundary_race.py` をそのまま実行 | レンジ 0.099–0.186 が再現 |
| A4-b | prereg | 境界あたりハザードの seed bootstrap CI | 新規に付す |

コードは既に存在し 34 秒で決定論的に回る。**実質やることは commit と 2 回実行の byte 一致確認のみ**。

### A5 — 揺れの大きさは残差に比例

| ID | tier | 内容 | 基準 |
|---|---|---|---|
| A5-a | **prereg・主判定** | 窓ごとの `median|Δx|` と `eval_loss_exact` の Spearman 相関、seed クラスタ bootstrap 95% CI | **CI 下限 > 0.5 → PASS** |

旧値「窓相関 ≈0.96」は **vault 内に出所が見つからない**ため repro tier を与えず、**新規測定として扱う**。非境界ペアのみ、窓 = T=10⁴。

### A6 — 天井＝残差依存の平衡

**判定なし（report tier のみ）。**

報告する量: 窓ごとの `|F_self| / |F_rest|` と `E[Δx]` の関係、比が 1 を跨ぐ点の分布。

判定を置かない理由:

1. 因果の向きが観察では原理的に決まらない（比が 1 を超えたから押し戻されるのか、押し戻された結果 1 に張り付くのか）
2. 比の可動域が 0.98–1.03 の 5% しかなく、`E[Δx]` が 66 倍動くのと不釣り合い（分子分母がほぼ相殺 → 測定誤差に極端に敏感）
3. `E[F_gate]` と `E[Δx]` の符号不一致（xr分解 §4 の⚠）が未解決で、F 系列を使う推論に同じ疑義が乗る

**この決定に伴い、v3 柱2 から §20 由来の記述を降ろす。** 天井の記述は A1-d（復活は境界ペアでのみ起きる）という事実に置き換える。
