## 1. 前 spec が失効した理由と、本 spec が変えるところ

### 1.1 失効理由（**committed 出力**・`results/_preflight_width5_gate_0901/`）

`onset_threshold = 0.05` が**幅 5 の到達床より下**にあった。early 窓（task 2–11）の seed 別最小 `unfit`:

| 腕      | 最小     | 中央値    | 最大     | 0.05 未満  |
| ------ | ------ | ------ | ------ | -------- |
| `R5`   | 0.0609 | 0.1632 | 0.6744 | **0/20** |
| `LIN5` | 0.1549 | 0.3183 | 0.7057 | **0/20** |

**どの緩め方をしても FAIL する**（最良 seed でも 0.061 > 0.05）ので、判定は操作化に依存しない。

### 1.2 ★ これは閾値のずれではなくスコープの発見である

**幅 5 には「フィットした状態」が存在しない。** 走り始めの最良時点ですでに 16%（ReLU）〜 32%（線形）が未フィットである。本プロジェクトが一貫して使ってきた LoP の登録概念 —— **フィット状態から絶対閾値を割り込む** —— は、**幅 5 では定義されない。**

そして **Dohare も同じ regime にいる。** 図 B.10 の縦軸は 0.45 → 1.05 で推移し Linear は 0.79–0.85 なので、原典でも一度もフィットしていない。つまり **Dohare の LoP は絶対水準の割り込みではなく、線形ベースラインに対する相対的な上昇である。** [[容量不足レジームの機構_0830]] §5.1 が「判定規則はここが残る差」と書いていた項目が、実は本質だった。

### 1.3 ★ §5.1 の分解能較正は幅 5 では成り立たない（前 spec の前提が 1 つ壊れた）

前 spec §5.1 は **幅 100 からの外挿**で「腕間ペアリングは分散を減らさない」と結論し、それを根拠に G1 を報告へ降格した。**preflight の実測はこれを否定する。**

|                      | w100（`gate_dose_0830` からの外挿） | **w5（preflight 実測）**                    |
| -------------------- | ---------------------------- | --------------------------------------- |
| 腕間の seed 相関（Pearson） | 0.087                        | **0.735**                               |
| 対応差の SD              | 1.129（各腕の SD **より大きい**）      | **0.0905**（各腕の 0.128 / 0.120 **より小さい**） |

**幅 5 ではペアリングが効く。** 幅 100 では各腕が別々の解に行けるのに対し、幅 5 では両腕が同じ教師・同じタスク実現に押さえつけられ、seed ごとの難易度が腕をまたいで共通に効くためと見られる（**機構は未検証**）。

**留保**: これは early 窓（task 2–11・約 110k step）の値である。5M 末尾では乖離が進んで相関が落ちうる。本 spec は**相関の水準に依存しない符号検定**を主判定に置くことでこの不確かさを回避する。

## 5. 事前登録判定

実験単位は seed（n=20）。**G0 は Clopper–Pearson 95%（bootstrap 不要）。** G1・G3 の水準は percentile bootstrap（B=10,000・seed `202609011921`）＋ studentized fallback と退化ガード（教訓⑬）。

### G0（**単独の主判定**・Dohare の判定規則）

腕 $A \in \{R5,\ LR5,\ E5\}$ ごとに独立に、$k_A/20$ の Clopper–Pearson 95% CI を 0.5 と比較する。

**凍結時の同値・欠測規則**: 比較は生 `unfit` の厳密な `A > LIN5` とする。同値は成功数 $k_A$ に数えないが有限な試行として $n$ には残す。どちらかが非有限の seed だけを当該腕の比較から除外し、その実効 $n$ で Clopper–Pearson を再計算する。

- CI 下限 > 0.5 → **`{A}_ABOVE_LINEAR`**（Dohare の意味で LoP あり）
- CI 上限 < 0.5 → **`{A}_BELOW_LINEAR`**
- CI が 0.5 を含み、かつ **CI ⊆ [0.20, 0.80]** → **`{A}_NOT_SEPARATED_TIGHT`**
- CI が 0.5 を含み、帯からはみ出す → **`{A}_INCONCLUSIVE_WIDE`**

**n=20 での到達可能性（事前計算・[[運用ルール]] §5 教訓⑪の連続版）**: `ABOVE` には $k \ge 15$（CP 下限 0.509）、`BELOW` には $k \le 5$（CP 上限 0.491）が要る。`NOT_SEPARATED_TIGHT` は **$k \in \{9,10,11\}$ でのみ到達可能**（$k$=9 で [0.231, 0.685]、$k$=12 で [0.361, 0.809] は帯からはみ出す）。**帯 [0.20, 0.80] はこの到達可能性から逆算した値であり、科学的な閾値ではない。**

**現象3 の主判定**: `LR5` と `E5` の少なくとも一方が `ABOVE_LINEAR` → **`PHENOMENON3_REPRODUCED`**。両方が `BELOW_LINEAR` または `NOT_SEPARATED_TIGHT` → **`PHENOMENON3_NOT_REPRODUCED`**。それ以外 → **`PHENOMENON3_INCONCLUSIVE`**。

### G0b（**登録された副判定**・図 B.10 の交差そのもの）

腕 $A$・seed $s$ について、**early 窓で `LIN5` より良く、末尾窓で `LIN5` より悪い**（＝符号が反転した）seed 数 $c_A/20$ を Clopper–Pearson で報告する。図 B.10 の曲線形状（線形ベースラインの下から始まり上で終わる）の直接の対応物である。

- **条件つき判定**: early 窓で $A$ が `LIN5` より良い seed が **15/20 以上**の腕についてのみ判定に用いる。それ未満の腕では交差の定義が空振りするので **`CROSSING_UNDEFINED`** とし、early 窓の内訳を `summary.md` に出す
- **preflight により `R5` はこの条件を満たすことが既に分かっている**（19/20）。`LR5` と `E5` の early 窓は未測定

### G1（水準・**報告のみ**）

末尾窓 $\log_{10}U$ の腕別 20 seed 中央値と、対 `LIN5` の対応差の CI。**§1.3 により前 spec の降格根拠（分散が減らない）は幅 5 では成り立たないが、early 窓の相関からの外挿にすぎないので、本 spec では昇格させない。** 実測された末尾窓の相関を `summary.md` に出し、**次の spec の設計材料にする**。

### G2（幅対比・記述のみ）

w5 腕 対 w100 腕。**非対応**（`train.make_gens` の基底に幅が入る）なので腕間の paired 統計は取らない。

### G3（機構・3 軸・報告のみ）

[[現象3指標再定義_P3_0901]] の 3 軸。軸1 `median_s`（`median_M + median_B` ではない）と生の `zbar`・`denom`／軸2 $m_i$（ReLU・leaky では $\hat p$ の関数なので恒真・ELU 腕でのみ独立）／軸3 $R_c$ と $R_c/\sum_i\tilde m_i$。**登録判定に入れない**（§8-3 の裁定を引き継ぐ）。
