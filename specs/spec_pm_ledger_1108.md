## 1 問い

PM の第 1 層で、前の課題の増分は次の課題の入力にどれだけ見えなくなるか。後の課題はその増分をどれだけ消すか。見えない質量は介入なしと L2 Init でどれだけ違うか。その違いは喪失の違いと seed 間で順位が合うか。

先行: RL-CIFAR 第 1 層の帯別帳簿（vault `測定/RL-CIFAR第1層の帯別帳簿_事後_0922.md`）。上位 10 方向の堆積は後の課題で 92〜99% 消され、侵食率は LR std で top −0.925・mid1 −0.683・mid2 −0.403・low −0.194・補空間 −0.053 と見えやすさの順に並ぶ。RL-CIFAR は入力が課題間で同じなので、当てはめの係数（1/λ）の説と切り分けられなかった。PM は並べ替えが既知なので、前の課題の増分を次の課題の帯へ厳密に移せる。

## 4 帳簿の定義

記号: 課題 t の末の第 1 層の入力の重み W_t（100×784、行 = ユニット）。W_0 は初期値。増分 D_t = W_t − W_{t−1}。過去の堆積 S_{t−1} = W_{t−1} − W_0。

課題 t の入力 X_t（その課題の順列を当てた 10,000 枚、float64）の中心化共分散 Σ_t（ddof = 1）。固有値を大きい順に λ_{t,1} ≥ λ_{t,2} ≥ …。ランク r_t は `λ > 784·ε·λ_1`（数値ランクの標準の定め）で数える。

帯は 0922 と同じ順位の切り方: top = 1〜10、mid1 = 11〜100、mid2 = 101〜439、low = 440〜r_t、comp（補空間）= r_t+1〜784（Σ_t の零空間）。r_t は課題ごとに変わる（約 650〜710）。「low 以下」= low ∪ comp。各帯の直交射影を P^t_b と書く。帯の分散の比は課題ごとに記録し、0922 の CIFAR の帯と大きさが違うことを読者が見られるようにする（順位の切り方を揃えるのを優先した。MNIST で 99% は 330 方向前後で、439 は 99.8%）。μ⊥ の帯は無い。n = 10,000 > 784 なので平均画像は中心化データの張る空間の中にある。

帯ごとの量（腕 × seed × t × 帯 b）:

| 量 | 定義 | 0922 との対応 |
|---|---|---|
| 堆積 d_b(t) | ‖D_t P^t_b‖² | 同じ（基底が課題 t の帯） |
| 課題内の侵食 e_b(t) | 2⟨W_{t−1} P^t_b, D_t P^t_b⟩ | 同じ（基底が課題 t の帯。恒等式 N_b(t) − N_b(t−1) = d_b + e_b を課題 t の基底の中で検査する） |
| 重みつき堆積 V_b(t) | Σ_{j∈b} λ_{t,j} ‖D_t u_{t,j}‖²（= tr(D_t P^t_b Σ_t P^t_b D_tᵀ)） | 新 |
| 次の課題から見た堆積 d′_b(t) | ‖D_t P^{t+1}_b‖² | 新（厳密な移送） |
| 移送の行列 T_{bb′}(t) | ‖D_t P^t_b P^{t+1}_{b′}‖² | 新（帯 b の増分が次の課題の帯 b′ へどれだけ移るか） |
| 次の課題の重みつき V′_b(t) | tr(D_t P^t_b Σ_{t+1} P^t_b D_tᵀ) | 新（帯 b の部分だけを次の課題の共分散で測る） |

### (a) 可視度

ρ(t) = tr(D_t Σ_{t+1} D_tᵀ) / tr(D_t Σ_t D_tᵀ)。窓 w では ρ_w = Σ_{t∈w} tr(D_t Σ_{t+1} D_tᵀ) / Σ_{t∈w} tr(D_t Σ_t D_tᵀ)（比の和でなく和の比）。帯 b の部分の可視度 ρ_{b,w} = ΣV′_b / ΣV_b も出す。

参照の算術（走らずに決まる）: 置換が一様乱数なら、D の 1 行 v について E_π[vᵀ P Σ Pᵀ v] = (α − β)‖v‖² + β(1ᵀv)²、α = tr Σ / 784、β = (1ᵀΣ1 − tr Σ)/(784·783)。ρ_iso(t) = [(α_{t+1} − β_{t+1})‖D_t‖²_F + β_{t+1} Σ_i (1ᵀ D_{t,i})²] / tr(D_t Σ_t D_tᵀ)。これは「次の課題の共分散と無関係な増分」の値で、実測の ρ が ρ_iso に重なることは並べ替えの性質で、機構の証拠ではない。機構の中身は ρ_iso が 1 より小さいこと、つまり D_t が自分の課題の分散の大きい向きに片寄っていることである。

### (b) 侵食率（0922 の Σe/Σd を増分の側から書く）

窓 w = [t₁, t₂] の増分 s ∈ w について L_s = W_{t₂} − W_s（窓の末までに後の課題が書いた分）。

ero_b(w) = Σ_{s∈w} 2⟨L_s, D_s P^s_b⟩ / Σ_{s∈w} d_b(s)。

基底が固定なら、これは 0922 の Σe_b/Σd_b（の窓内の対の部分）に一致する。b = 全帯なら恒等式 ero_all(w) = r_all(w) − 1、r_all(w) = ‖W_{t₂} − W_{t₁−1}‖²_F / Σ_{s∈w} ‖D_s‖²_F（0922 の累積比）。−1 は書いた分が窓の中で全部打ち消された、0 は一切触られていない。

課題内の侵食率 ero^in_b(w) = Σ_{t∈w} e_b(t) / Σ_{t∈w} d_b(t) も並べる。これは「課題 t の増分がその帯の今の在庫をどれだけ消すか」で、0922 の Σe/Σd そのものの基底だけを課題 t に置き換えた量である。「削りは見えやすさの順に効く」の直接の検査はこちらでする。

q_b(S) = Σ_s ⟨W_{s+S} − W_s, D_s P^s_b⟩ / Σ_s d_b(s)（ラグ S = 1 と 50。振幅の割合で、−1 = その増分が消えた）を別に出す。ero は q の 2 倍の位置づけである（窓内の全対で数えるため、半分は「消す側」に回る。0922 の −1 は 2q̄ = −1 に当たる）。

窓は 4 つ: w1 = [6, 50]（0922 と同じ）、w2 = [101, 150]、w3 = [251, 300]、w4 = [451, 500]（先生の後期窓）。走全体 [6, 500] の値も出す。増分 D_s の帯 b は課題 s の帯で決める。

### (c) 見えない質量

M_inv(t) = ‖S_{t−1}(P^t_low + P^t_comp)‖²_F。課題 t の時点で残っている過去の堆積 S_{t−1} = W_{t−1} − W_0 のうち、課題 t の low 以下の帯にある分。見える質量 M_vis(t) は top・mid1・mid2 の分。腕の対は同じ seed で組む。

参照の算術: 置換が一様乱数なら S_{t−1} は課題 t の基底と無関係なので、M_inv / ‖S‖² ≈（課題 t の low 以下の次元の比）= (784 − 439)/784 = 0.44。これから外れれば、在庫は並べ替えをまたいで残る構造を持つ。

### (d) 順位の一致

ΔG(seed) = G(none, seed) − G(l2init, seed)。ΔM(seed) = 課題 400・500 の平均の（M_inv(none, t) − M_inv(l2init, t)）。Spearman の順位相関 ρ_s(ΔM, ΔG)（10 seed）。

## 6 判定の線（算術から導く。固定倍率は置かない）

- **P4 の線 0.5636**: n = 10 の Spearman の厳密な帰無分布（10! の並べ替えの全数え上げ）で、片側 p ≤ 0.05 になる最小の値は ρ_s = 62/110 = 0.5636（p = 0.0481）。次の値 0.5515 は p = 0.0524。
- **侵食の雑音の床**: 無関係な 2 つのベクトルの内積は次元 d = 784·100 = 78,400 で cos の SD が 1/√d = 0.0036。増分 s の q の雑音は ‖L_s‖/‖D_s‖ · 1/√d。窓の中で Σ_s の ero の雑音の SD は 2·√(Σ_s ‖L_s‖² d_b(s) / d) / Σ_s d_b(s)。この床を帯ごとに同時に出し、|ero| が床の 2 倍以内なら「0 と区別できない」と書く。P2 の線 0.1 は親の値で、床（w1 の全帯で約 0.01）より十分大きい。
- **RL-CIFAR の帯の参照**（0922 §3、LR std の値）: top −0.925、mid1 −0.683、mid2 −0.403、low −0.194、comp −0.053、全帯 −0.607。PM の ero_all と ero^in_b を横に並べる。
- **M_inv/‖S‖² の参照** 0.44（§4(c)）。
- **箱の照合の線（S-box）**: 先生の none の差 +8.1 [+7.6, +8.6]（10 seed、t 区間）から SE = 0.5/2.262 = 0.22、seed の SD = 0.70。3 seed の平均と先生の 10 seed の平均の差の SE は √(0.70²/3 + 0.22²) = 0.46。自由度の小さい 3 seed の側で t = 4.30（df 2）を使い、許容は 8.1 ± 2.0（下の S-box）。10 seed では √(2)·0.22 = 0.31、t = 2.10（df 18）で ±0.65。
- **恒等式の残差の線**: N_b, d_b, e_b は float64 の 78,400 項の和なので、許容は 78,400·2·u·(N_b(t) + N_b(t−1) + d_b + |e_b|)、u = 2⁻⁵³ ≈ 1.1e−16。これを超えたら解析を止める。

## 7 走る前の検査（S-）

- **S-ident**: `run.py` の更新の手順が箱の `run_one` とビット単位で一致する（none と l2init の両方、seed 0、3 課題、CPU、課題末の全パラメータで `torch.equal`）。不一致なら走らない。
- **S-box**（seed 0〜2 が終わった時点で判定。先生の J.3 の値と比べる）: none の課題 1 の online（先生 83.8%）と全課題の平均 online（78.8%）、差 G の平均（+8.1）。l2init の課題 1 の online（83.6%）、全課題の平均 online（88.4%）、G の平均（−4.6）。死んだユニットの割合（J.12: none の課題 1 が第 1・第 2 層で 6.2%・11.1%、課題 500 が 15.7%・80.0%）。**G の平均が none で 8.1 ± 2.0、l2init で −4.6 ± 2.0 の外なら、残りの seed に進まず、直さずに報告して止まる。** 10 seed で ±0.65 の外なら報告する（止めるかは親が決める）。
- **S-5task**: 1 走の時間を 5 課題で測り、全部を仕込む前に時間とメモリの見積もりを出す。
- **S-sha**: 事後解析で乱数列から作り直した順列が `perm.npy` に、引いた添字が `idx_sha.json` に一致する。不一致なら解析を止める。
- **S-ledger**: 恒等式の残差が §6 の線の中。全帯の侵食の恒等式 ero_all = r_all − 1 が数値の誤差の中。
