## 0. 一行

condA（w100, T=1e4, batch=1）のタスク境界近傍を細密記録し、整流モデルの未検証の心臓部3点——(i) 駆動符号が**タスク内で安定・境界で反転**するか、(ii) 死亡直前の軌跡が**単調輸送か拡散到着か**、(iii) 凍結ユニットの変位が**境界に集中**（匍匐＝階段）するか——を、32パターン厳密期待値で判定する。

## 1. 背景と仮説の構造

整流モデル = 対称に振れる二極駆動 × 片側だけゼロの移動度。確定済みは静的部品のみ:

- 部品1（力場二極）: F_i^ungate = −2η·v_i·G、G = E[δx] 共通、符号一致率 0.993【厳密計算・確定】
- 部品2（片側移動度）: 消灯点 cos ≈ −0.15、p̂<0.05 で Δcos ≈ 0【確定】
- 部品3（駆動反転）: 隣接 ckpt（≥1周期）一致率 0.567 ≈ コイン【ckpt 粒度のみ・事後解析】

**未検証**: 機構が要求するのは「タスク内で安定 → 境界でのみ反転」。ckpt 10k = T とエイリアスしており現データでは原理的に見えない。さらに:

- **匍匐仮説**: 消灯点 −0.15 と堆積帯 −0.325 の差。候補機構は「flip_state が境界で動く → µ̂ が動く → 凍結ユニットが瞬間再露出 → 一押し → 再凍結」。正しければ変位は境界に集中し、帯深は切替回数でスケール
- **駆動分解の未分離**: posflip は v=0 始動なのに滑落した。下向き正味の正体が (a) v² 比例の自己項（符号安定・恒常）か (b) 対称駆動＋片側吸収の整流残差かが分離できていない

**キルライン**: (i) がタスク内でもコイン投げなら「境界で反転」という駆動描像は棄却（反転は境界イベントではなく連続的ゆらぎ）。(iii) で変位が時間一様なら匍匐仮説は棄却。

## 3. 設計

### 3.1 レジーム（1つのみ）

condA A_w100: m=20, f=15, T=1e4, encoding=std, width=100, batch=1, lr_main=0.01, seed 0–9。methods_sde_0813 の condA 設定を継承。**condB へは外挿しない**（スコープ）。

### 3.2 走行

トランク 0 → 1,000,000 step、介入なし、seed 10 本。probe フックで読み取り専用ロギングのみ行う（§3.4 の S2 で無擾乱を保証）。分岐アームなし。

### 3.3 ロギンググリッド（エイリアス解消の本体)

境界 = t ≡ 0 (mod 10⁴)、全 100 箇所/run。

- **境界窓**: 各境界の [−100, +100] を**毎 step** 記録（100 境界 × 201 点）
- **バルク**: それ以外を 1000 step ごと
- 計 ≈ 21,000 記録点/run

### 3.4 各記録点で計算・保存する量（全て full_support 32 パターン上の厳密値、float64 で計算し float32 で保存）

run レベル:
- G = E[δx]、E[δ]、‖E[δ]µ‖/‖Cov(δ,x)‖、s(t) = sign(G·µ̂_t)、|cos(G, µ̂_t)|
- µ̂_t = 現在の flip_state ‖ 0.5·1（make_wdir_ctx condA の定義と一致）。**flip 直後の記録点から新 µ̂ を使う**
- 駆動分解（§1 の (a)/(b) 分離用）: δ = δ_self,i + δ_rest,i、δ_self,i = v_i σ(w_iᵀx+b_i) として、ユニットごとの F_i の µ̂ 射影を self / rest に分解した2系列（下記 unit レベルに保存）

unit レベル（i = 1..100）:
- cos(u_i, µ̂_t)、p̂_i（32パターン上の厳密ゲート率）、‖w_i‖、b_i、v_i
- F_i^gate·µ̂ の self / rest 成分（上記分解）

保存: `results/ratchet_log_0819/logs/seed{k}.npz`（step 軸 + run 配列 + unit 行列）。概算 70MB/seed・計 ~700MB。

### 3.5 派生イベント定義（解析側、事前固定）

- **死亡**: p̂_i が 0.05 を下方クロスし、以後 1 周期（10⁴ step）以上回復しない最初の記録点。t_death とする
- **凍結区間**: p̂_i < 0.05 が連続する記録点区間
- **降下窓**（P3 用）: t_death から遡り、直近で cos(u_i, µ̂) > 0 だった最後の記録点を t_start とする区間 [t_start, t_death]

## 5. 主要指標（事前登録）

すべて seed 単位で集計 → paired bootstrap（run_id ソート、`rng = np.random.default_rng(fixed_seed)`、10,000 resample、95% CI）。

- **A_within**: 同一タスク内の隣接記録点ペア（バルク粒度 1000 step。境界窓内ペアは除外）での s(t) 一致率
- **A_boundary**: 各境界の「直前最後の記録点 vs 直後最初の記録点」での一致率（100 遷移/run。followup の 60 遷移から大幅増）
- **PE_i**（path efficiency）: 降下窓での |cos(t_death) − cos(t_start)| / Σ|Δcos|。死亡ユニットのみ
- **BC**（boundary concentration）: 凍結区間内の Σ|Δcos| のうち境界窓 [−100,+100] 内で生じた割合。一様帰無値 = 201/10⁴ ≈ 0.0201
- **階段回帰**: 凍結ユニットの cos 深化量を「経過 step」と「経験切替回数」で別々に回帰（seed 内で切替タイミングは決定的なので、凍結開始時刻の異なるユニット間の変動で識別）

## 6. 判定基準（事前登録・commit 前に固定）

| ID | 予測 | PASS 基準 | FAIL の帰結 |
|---|---|---|---|
| P1 | 駆動符号はタスク内で安定 | seed 中央値 A_within ≥ 0.90 | 「境界で反転」描像を棄却。整流の駆動源を連続ゆらぎ型に書き換え |
| P2 | 境界で反転（コイン化） | A_boundary の CI が [0.35, 0.65] と交差、かつ **A_within − A_boundary の CI 下端 > 0.2** | P1 と併せて解釈（両方 FAIL なら粒度問題再燃） |
| P3 | 死亡は単調輸送 | 死亡ユニットの median PE > 帰無 95 パーセンタイル（帰無 = 各降下窓内で Δcos の符号を置換した null、窓ごと 1000 回） | 拡散到着 → 部品2 の「消灯」解釈は残るが輸送物語は削除 |
| P4 | 凍結ユニットの変位は境界集中 | median BC の CI 下端 > 3 × 0.0201 | 匍匐仮説棄却。堆積帯 −0.325 の説明を再考（‖w‖ 交絡の線へ） |
| P5 | 帯深は切替回数スケール | 階段回帰で切替回数の係数が有意（CI ゼロ非含有）かつ step 係数を追加しても符号維持 | P4 と同時 FAIL なら匍匐は完全棄却 |
| E1 | 駆動分解（探索的・PASS/FAIL なし） | 推定対象のみ事前固定: 発火中の降下ユニットにおける self 成分と rest 成分の µ̂ 射影の (i) 時間平均比、(ii) 符号安定率の差。報告のみ | — |

判定は verdict.csv に P1–P5 の PASS/FAIL と E1 の推定値を記録。**dead_frac は判定に使用しない**。

## 7. サニティ（事前登録）

- **S1**: `OMP_NUM_THREADS=1` を固定（eff_rank 系は本実験では未使用だが規約として統一）
- **S2（無擾乱）**: seed 0 で probe あり/なしの 100k step を走らせ、最終 state_dict が bit 一致すること。probe 内で generator・model・env の状態に一切書き込まないこと（`torch.no_grad()` + env は `save_state` 経由の読み取りのみ）
- **S3（厳密 vs 経験）**: 記録点 3 箇所で p̂_i 厳密値と eval_batch=2000 経験値を比較、二項ゆらぎ（±3σ）内
- **S4（境界検出）**: flip イベントの発生 step が t ≡ 0 (mod 10⁴) に厳密一致することを env ログで確認

## 9. 禁止事項・留保（本文に転記すること)

- condB への外挿禁止。主張スコープは「condA・w100・T=1e4・batch=1」
- s(t) は µ̂_t 依存なので、境界での反転は「G の反転」と「µ̂ の移動」の複合。**分離しない**（本実験の主張は駆動射影 s(t) の水準まで）。分離が必要になれば µ̂ を旧値に固定した s_old(t) を追加解析（ログには G と flip_state を保存するので事後計算可能）
- P3 の帰無は増分の大きさ分布を保存する符号置換であり、真の拡散モデルの尤度比ではない
- 階段回帰（P5）は seed 内の切替タイミングが全ユニット共通のため識別力が弱い。CI が広ければ「判定保留」とし、T スイープ（T ∈ {1e4, 3e4}）の追試を Phase 2 として起案する
- followup 0.567 は事後解析。本実験の A_boundary が事前登録版の置き換えであり、以後は本実験値のみ引用
