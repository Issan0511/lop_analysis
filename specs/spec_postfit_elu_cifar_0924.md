## 0. 問い

V11 ②の鎖は二つの箱にまたがっている。
- G3（供給源）: RL-CIFAR leaky 0.1/std では、各課題を当てはめた後（hit999+500 以降）の Adam 更新を凍結か plain SGD に替えると、第 1 層の伸びの 7〜9 割と後期の遅れの全部が消える（sgd_postfit_cifar_0923、登録）。
- G6（帰結）: RL-CIFAR ELU/std では、上流平均 μ₂ の伸びが第 2 層を負側へ運び、両層の行ノルム上限で崩壊が止まる（A6 再解析・S5 cap12 RESCUED、登録）。

一つの軌道で「当てはめ後の Adam → 成長 → μ₂ → 崩壊」を同定した走は無い。**問い: S5 と同じ ELU/std の箱で、当てはめ後の Adam 更新を凍結（または SGD）に替えると、崩壊は防げるか、遅れるか。崩壊の前に積もる第 1 層の幅と μ₂ のうち、何割を当てはめ後の更新が供給しているか。**

既知の事実（S5 ref、seed 0–9、R=10）:
- 課題 1 は 10/10 seed が当てはまる（課題末の正解率 1.000、online .983）。
- 課題 2 は online .92 で、課題末に 99.9% 以上なのは 3/10 seed、99% 以上は 8/10 seed。第 2 層の平均微分 G2 は .35 → .065、‖μ₂‖ は 52.6 → 174。
- 課題 3 で全 seed が半減（T_half = 3、10/10）。課題 3 以降は 1 課題も当てはまらない。主窓 t31–50 の online は 10/10 が床。
- 主窓の床の上端 U_s は .114〜.119、cap12 の主窓 online は .84〜.87。

## 1. 箱

S5 と同じ。エンジンの `run("ELU", seeds 0–9, ["std"], R=10)` をそのまま使う。
- 乱数ラベル CIFAR-10、固定 1,200 枚、3072–100–100–10、両隠れ層 ELU(α=1)（F.elu、訓練の微分は autograd で z ≤ 0 は exp(z)、床なし）、入力 std、bias あり。
- Adam lr 1e−3（β 0.9/0.999、ε 1e−8）、WD なし、batch 16、400 epoch × 75 = 30,000 更新/課題、50 課題。m, v と時計 tc は課題をまたいで持ち越す。
- seed 0–9、R=10 で 1 本の stack、slot は seed 昇順。CUDA graph。trace は 100 更新ごと（`hit_every=100`、ce_st 付き）。課題末スナップショット（全パラメータ、float32）と `keep_ckpts`（課題末の P・m・v・tc・乱数状態）を全腕で保存する。
- 全腕が 30,000 更新を回すので、ラベルとミニバッチ順は全課題で全腕同じ（親 §1）。
- 既知の自然 seed への介入であり、未使用 seed での外部再現ではない（S5 と同じ）。

## 2. 腕

切替点は親と同じ。slot ごとに hit（更新 100 以降の trace eval で初めて正解数が閾値以上になった更新）を取り、s_sw = hit + 500。s_sw > 30,000 ならその課題では切り替えない。更新 1..s_sw は全腕 Adam。

| 腕 | 閾値 | 当てはめ後の更新 | 役割 |
|---|---|---|---|
| **A** | 1,199/1,200（99.9%） | Adam のまま（`postfit` mode adam、帳簿だけ足す） | 対照。S5 ref と bit 一致するはず（K1） |
| **F** | 1,199 | 凍結（重みも m, v も s_sw の値で止める） | **主** |
| **S** | 1,199 | plain SGD p ← p − η_S g（同じミニバッチ勾配、6 テンソル、モーメンタム・WD なし）、m, v は s_sw の値で止める | 副。凍結と違って交差エントロピーを下げ続ける |
| **F99** | 1,188（99%） | 凍結 | 副。切替の起き方への備え（下） |

**当てはまらない課題では介入が起きない。** 閾値に届かない課題は全更新が Adam（A と同じ規則）になる。A の軌道では課題 2 で 99.9% に届く seed が少なく、課題 3 以降は誰も届かない。したがって F は「当てはまっている課題の後ろだけを止める方策」で、崩壊が始まれば A と同じ更新則に戻る。これは「崩壊の前の当てはめ後の尾が崩壊を作るか」の検査としてそのまま使う。F99 は閾値を 99% に下げた同じ方策で、課題 2 のように 99% には届くが 99.9% には届かない課題でも尾を止める。F が崩壊し、しかも F の課題 2 の切替率が低いときに、「尾は効かない」と「閾値のせいで止められなかった」を分けるのが F99 の役目。

**η_S の決め方（試走、本走 S の前、予測の登録の後）**: 格子 {0.001, 0.003, 0.01, 0.03, 0.1}。各 η で S の課題 1–2 を回す（R=10、seed 0–9。本走 S の最初の 2 課題と同じ計算）。安定(η) は次を全部満たすこと。
1. 課題 1–2 の損失が全部有限。
2. 課題 1 で全 slot が切り替わる。
3. 切り替わった (課題, slot) ごとに: s_sw より後の全 eval で正解数 ≥ 1,188、ce_st ≤ 2·ce_st(s_sw)、更新 30,000 の正解数 ≥ 1,199、ce_st(30,000) < ce_st(s_sw)。

η_S = 自分とそれ以下の格子点が全部安定な最大の格子点。0.1 まで安定なら「検査範囲の最大」と書く。安定な η が無ければ S は回さず、その旨を書く。親の η_lo（課題 49 の脚）は作らない（この箱の課題 49 は崩壊した網で、切替が起きない）。

## 3. 測るもの

エンジンの行と trace（親 §3 と同じ）: online_acc、memo_acc、hit99、hit999、switch_step、pin_step、当てはめ後の変位 pf_disp_l1..l3、凍結の旗 pf_P_same・pf_mv_same、w_norm、trace の correct・ce・ce_st・n1..n3・sig_med。

スナップショットから事後に（解析 `analysis/postfit_elu_cifar_0924/analyze.py`、S5 の定義に合わせる）:
- **G2** = 第 2 層の訓練の微分（F.elu の autograd）の、全 1,200 枚 × 100 ユニットの算術平均（float64 で平均）。S5 の `G2` と同じ定義。Q2 = |g| < 1e−6 の対の割合。
- **‖μ₂‖** = 第 1 層の活性 a1 の画像平均（100 次元、float64）のノルム。S5 の `mu2_norm` と同じ。
- **V_Σ(W1)** = Σ_i Var_images(z1_i)（母分散、float64 で重みから計算し直す）= tr(W1ΣW1ᵀ)、Σ は seed の 1,200 枚の中心化共分散。‖W1‖²_F も並べる。
- 課題末から課題末への第 1 層の遷移の帳簿（Σ 計量）: Q = Σ_i Var(Δz1_i)、X = Σ_i Cov(z1_i, Δz1_i)、ρ = √(Q/V)、c = X/√(QV)、B = −2ΣX/ΣQ（窓ごと）。記述のみ。
- 床: 各 (seed, 課題) の最良の定数予測器 F_s(t) = max_c(n_{s,t,c}/1200)。ラベルは seed の `rlc_labels` 列から再生成し（エンジンの `replay_stack` と同じ規則）、S5 の `major_frac` と一致することを確かめる（K4）。

## 4. エンドポイントと判定

### 4.1 適用条件（S5 §5.1–5.3 の規則をそのまま使う）

- 完全性: 4 腕（S を回さない場合は 3 腕）× 10 seed × 50 課題が揃い、有限で、必須検査（§5）が PASS。欠落は `INCOMPLETE`、誤実装は `CHECK_FAILED`、非有限は `DIVERGED`（seed・腕・課題つき）。seed を除いて n を縮めない。
- **A が S5 ref と 50 課題全部で一致する（K1）**。一致しなければ A を ref として使い、S5 の数値は記述の参照にとどめる。
- 自然現象の条件 B: A の主窓で AT_FLOOR が 9/10 以上、かつ A の E2 の 95% 区間の上端 < 0。満たさなければ全科学ラベル `NOT_REPRODUCED`。

### 4.2 床と主量（S5 §4.1・§5.2）

- 主窓 W = t31–50。A_s,a(t) = online_acc、G_s,a(t) = G2（課題末）。
- U_s = F̄_s + t_(19,0.95)·sF_s/√20（F_s(t) の主窓の平均と標本 SD、t_(19,0.95) = 1.7291）。mean_W A_s,a ≤ U_s を AT_FLOOR。腕の床状態は 10/10 床で FLOORED、0/10 で ALIVE、それ以外 SPLIT。
- E1_s,a = mean_W A_s,a − A_s,A(1)、E2_s,a = mean_W G_s,a − G_s,A(1)（基準は A の課題 1、全腕共通。S5 の共通接頭部に当たる）。対応差 δ_j,s,a = Ej_s,a − Ej_s,A。

### 4.3 主判定 Q1（F）と副判定 Q3（S）・Q4（F99）

S5 §5.3 の表をそのまま使う。F の E1/E2 は n=10、df=9、t_(9, 1−0.05/4)（2 比較の Bonferroni、各 97.5% 両側）。S と F99 は 95% 区間の副ラベル（主の多重性の外）。

| 腕の床状態 | E1 の符号 | E2 の符号 | ラベル |
|---|---|---|---|
| FLOORED | 任意 | 任意 | COLLAPSED |
| SPLIT | 任意 | 任意 | SPLIT |
| ALIVE | + | + | RESCUED |
| ALIVE | + | 0 / − | RESCUED_FUNCTION_ONLY |
| ALIVE | 0 / − | 任意 | ALIVE_UNRESOLVED |

区間の下端 > 0 を +、上端 < 0 を −、それ以外を 0。SD = 0 は `DEGENERATE_SD` を併記。S が発散した seed は失敗込み（その seed のその後の課題は online・G2 とも発散時点で打ち切り、床とみなす）で判定し、生存者だけの値を副に出す。

### 4.4 時間 Q2（S5 §5.5）

T_half = t ≥ 2 で (A(t) − 0.1)/(A(1) − 0.1) < 1/2 となる最初の課題（A(1) は各腕自身の課題 1）。50 まで超えなければ右打切り。腕と A を seed 内で比べ、片方だけ打切りならその腕が遅い、両方打切りと同時刻は tie として除く。比較できる符号に両側正確二項検定、p < 0.05 で LATER / EARLIER、他は NO_TIMING_DIFF、比較可能 0 件は TIMING_UNDETERMINED。

### 4.5 鎖への要約 Q5（F、Q1 と Q2 から機械的に決める）

| Q1 | Q2 | 要約 | ②での読み |
|---|---|---|---|
| RESCUED / RESCUED_FUNCTION_ONLY / ALIVE_UNRESOLVED | 任意 | **BRIDGE_RESCUED** | 当てはめ後の更新が、この箱でも崩壊に必要。G3 → G6 が同じ軌道でつながる |
| SPLIT | 任意 | **BRIDGE_PARTIAL** | 一部の seed でだけ必要 |
| COLLAPSED | LATER | **BRIDGE_DELAYED** | 尾は崩壊を早めるが、無くても当てはめと切替だけで崩れる |
| COLLAPSED | それ以外 | **BRIDGE_NONE** | この箱の崩壊に尾は効かない。G3 は leaky/std の一般則として側鎖に置く |

### 4.6 機序の登録量 Q6（崩壊の前で比べる）

A の T_half は 10/10 で課題 3 なので、課題 1 と 2 の課題末は A も生きている。比較はここに置く（終端の量は崩壊した腕と生きた腕で比べられない: switch_push の教訓）。

- **M1（課題 1 の尾の分担）**: s_V = 1 − V_Σ(F, t1)/V_Σ(A, t1)、s_μ = 1 − ‖μ₂‖(F, t1)/‖μ₂‖(A, t1)、s_N = 1 − ‖W1‖²(F, t1)/‖W1‖²(A, t1)。F の課題 1 は s_sw まで A と同じ計算なので、これは A 自身の軌道で「課題 1 末の量のうち何割が当てはめ後の尾で足されたか」になる。seed の中央値と範囲。
- **M2（課題 2 末）**: 同じ比を課題 2 末で。seed 内の向き（F < A の seed 数）。
- **M3**: G2(F, t2) − G2(A, t2) の seed 内の向き。
- **M4**: 課題ごとの切替率（その課題で切り替えた slot の割合）を F・S・F99 について課題 1–10 と全体で。
- **M5（記述）**: 全腕の ‖μ₂‖、V_Σ(W1)、G2、b2 の課題別の軌跡。生き残った腕は t50 の ‖μ₂‖ を S5 の cap12（40）と ref（1,072）に並べる。
- **M6（記述）**: A と生き残った腕の第 1 層の遷移の帳簿（ρ、c、B）。ELU/std での G4 の値として。

「向き」の判定は 10 seed 中 9 以上で「一貫」（片側正確二項、P(Bin(10, 1/2) ≥ 9) = 0.0107、8 は 0.0547 で届かない。S5 §5.1 と同じ算術）。

### 4.7 判定の順序と採点

完全性 → K1（A と S5 ref）→ 条件 B → Q1–Q5 → Q6。採点できない場合（NOT_REPRODUCED・CHECK_FAILED など）はその予測を採点から外し、理由を書く。
