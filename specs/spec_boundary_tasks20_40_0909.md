# タスク20〜40の切替直後勾配と下降寄与 spec 0909
状態: 検証中 / 更新: 2026-09-09
親: [[タスク20から100の前活性分布追跡_結果_0908]] / [[初期20更新の局所勾配と実移動_再解析_0908]]
Issa依頼「20〜40でもう一度同じ解析、最小ステップの勾配と下げ幅の寄与」。既存の20タスクビンで設定点下降が大きかった区間を選んだ追加記述解析で、独立な機構確証走ではない。

## 窓と学習
対象はtask20終端→task40終端に含まれる20境界、task21..40。SNA/LR×none/L2、seed0..2。同じCPU学習器・初期値・perm/data/batch RNG・625更新/タスク・Adam lr.001・coupled L2全W/b=1e-3・Snake EMAを使う。sourceをtask1..40まで同じループで再生しtask21..40の完全境界状態、最初300更新のユニット別平均、20/300/625更新の状態を保存。元CUDAとは比較しない。
既存boundary_transport_0908の最初20更新計装を再利用・拡張する。単独step1と窓2..5、6..10、11..20、全1..20を固定。前タスク終端→置換直後の跳びと、学習step1以後を区別する。

## 最小更新の勾配
同じ学習標本・同じユニットのz、−B*dL/dz（局所下降方向）、dL/da、gate、実Δz、現在CEのみのAdam分母固定寄与、自己標本と他標本の共有パラメータ寄与を保存。正側/負側に分けて局所向きと実向き、局所上向きでも実下降する割合、平均局所方向を報告。標本自身の寄与をscalar MSEの自己項とは呼ばない。

## 下降寄与
実ΔzbarをW/b、設定点star/タスク入力整列に分解。実Adam分母を固定して、正側入力由来CEの蓄積、負側由来CEの蓄積、切替後L2の蓄積、切替前一次モーメントの残り、丸め残差に加算分解。加えて現在CE・現在L2・それ以前の履歴を分ける。履歴は切替後の前ステップ分も含む。
同じ固定512入力についてstep0正側/負側受け手を追跡。各成分の符号付き平均を主とし、実際にユニット平均が下がった更新に条件付けた下降量への符号付き寄与も補助保存（上向き成分は負の寄与率になり得る、正味が微小な全体に割合を作らない）。
平均・入力内分散・ユニット平均間分散を同じ集合で算出。20/300/625時点の平均とstarを併記し、短時間と全タスク収支を混ぜない。

## 集計・検算
境界内窓の累積→seed内20境界平均→3seed中央値/範囲。局所符号の比率は境界内で比→seed内平均。全stepとseedを保存、CI/有意差なし。
task1 checkpoint全状態を既存CPUと照合。task21..40終端のユニット別平均・star・入力内分散をtask20to100_0908の対応npzと一致確認。計装再生の平均はsource dense1と2e-5以内、勾配加算2e-6、変位加算2e-5、分散恒等式1e-9以内。追加autograd出力が勾配を変えないことを各腕seed0の最初の境界で検算。失敗は隠さず停止。
CPU1thread・最大2process、1腕seed900秒上限。specとコードを先にcommit/push。sourceと診断rawをSHA検算付きobsidian-research-dataへバックアップ。既存rawを上書きせず、CSV・図・結果ノートを保存してcommit/push。自己項の因果同定や長期下降の生成原因は、この加算分解だけでは確定しない。
