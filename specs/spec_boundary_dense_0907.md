# 沈下の収支を境界密記録で分ける（`boundary_dense_0907`）

親: [[vとwの成長_0907]] §8（候補機構「戻りの非対称」を棄却・沈下の微視的機構は未解明）／[[前活性オフセット結果_0906]] / 状態: **事前登録（走らせる前に commit・実装はこの腕表を逐語で消費する）** / 2026-09-07 / 発端: Issa「上端がラチェットの ON/OFF 面に貼りつくのはなぜ？ 上端に下向きの力がかかって見えるのはなぜ？」

## 1. 問い

沈下（`LRoff0_1216` は step 100k → 2M で z̄ が −1.16 → −3.35、**1 タスクあたり −0.0115**）を作る微視的な収支が分かっていない。末尾 20 タスクの 1000-step 記録では、

- 蹴りはタスク内で戻されない（R/K′ ≈ 0.01–0.09）＝ **「対称な蹴り × 非対称な戻り」は棄却**
- 末尾はすでに定常の鋸歯（タスク内 +0.025 ／反転 −0.027）で、**機構が動いている最中を見ていない**
- 「跨ぐ群は下へ動く」は z̄ = b + w_flip·x_flip の揺らぎへの**平均回帰**であって力ではない

ことまでしか分からなかった。**沈下中**を、**反転の直後から対数格子で**、しかも **b と w_flip·x_flip に分けて**見る必要がある。

## 2. 手段（学習は 1 bit も変えない）

**記録だけを変える。**

1. **境界密の記録格子**: 全タスク終端（10,000 step ごと）に加え、窓の中の各タスク開始 t0 から **+1, 2, 5, 10, 20, 50, 100, 200, 500, 1000, 2000, 5000 step**。窓はタスク 10〜199（step 100,000–1,990,000）。記録点は 2,481 点（標準の 201 点に対し 12 倍）。
2. **新しい列 `layer1_b`**（ユニット別バイアス）。これが無いと z̄ = b + w_flip·x_flip の分解ができない。

記録は読み取り専用（`full_support_ro` は env にも生成器にも書かない）なので、**軌道は記録格子に依らない**。これは仮定ではなく **S-null で実測する**: `BDref_1216` の `state_hash_1m` / `state_hash_final` が `offset_grid_0906` の `LRoff0_1216` と一致すること。**一致しなければ本走は全部無効**（§4 の `NOT_DETERMINED`）。

|---|---|---|---|---|
| `BDref_1216` | 0.1 | 0 | — | **本命**。S-null（`LRoff0_1216` と state_hash 一致） |

## 4. 判定（主判定 1 本・第 2 判定 1 本・どちらも効果量の床つき）

窓の各タスク k（開始行 t0 = 10,000k・**flip 前の旧支持**）について:

| 量 | 定義 | 意味 |
|---|---|---|
| **J_k** | `[z̄−b](t0+1) − [z̄−b](t0)` | 反転の**幾何の跳び**（w_flip·x_flip の入れ替え） |
| **B_k** | `b(t0+10000) − b(t0)` | **バイアスの学習** |
| **A_k** | `[z̄−b](t0+10000) − [z̄−b](t0+1)` | タスク内の **w_flip の整列** |
| **N_k** | `z̄(t0+10000) − z̄(t0)` = J+B+A | 1 タスクの正味 |

CI は **seed ブートストラップ 2000・`rng(20260907)`**（seed 単位で再標本・ユニットとタスクはプール）。

### 主判定 `SINK_CHANNEL` = f_b ≡ E[B] / E[N]

- **`BIAS_CARRIED`**: f_b ≥ 0.7
- **`GEOMETRY_CARRIED`**: f_b ≤ 0.3
- **`MIXED`**: 0.3 < f_b < 0.7
- **`NOT_DETERMINED`**: **|E[N]| < 0.005/タスク**（＝観測されている沈下 0.0115/タスク の 43%）、または E[N] の CI が 0 を含む、または S-null 失敗

### 第 2 判定 `SINK_TIMING` = τ½

b の累積プロファイル B(τ) = E[b(t0+τ) − b(t0)]（τ ∈ 記録格子）が **E[B(10000)] の半分**に達する最小の τ（格子上で線形補間しない・格子点で読む）。

- **`TRANSIENT`**: τ½ ≤ 100
- **`STEADY`**: τ½ ≥ 3000
- **`INTERMEDIATE`**: 100 < τ½ < 3000
- **`NOT_DETERMINED`**: E[B(10000)] の CI が 0 を含む、または S-null 失敗

**畳み方はどちらも 1 本で閉じている**（AND 合成をしない・[[井戸の剛性_0907]] §5-1、効果量の床を書く・[[折れ目を滑らかに_結果_0907]] §4-1）。判定は `BDref_1216` だけで読む。他の 4 腕は補助。

**補助（ラベルにしない）**: (i) 4 腕の同じ分解。(ii) 上端 zmax の同じ分解（z̄ でなく zmax で見た収支）。(iii) 跨ぎ率で条件付けた分解——**平均回帰の罠を必ず併記**（[[vとwの成長_0907]] §8-3）。(iv) B(τ) の形と ∂L/∂b = 2v[a·E[δ] + (1−a)·E[δ·1{z>0}]] の第 2 項の大きさ。(v) 窓の前半（タスク 10–99）と後半（100–199）で f_b と τ½ が動くか。

## 6. あらかじめの注意

1. **S-null が落ちたら全部無効。** 記録を変えただけで軌道が動いたなら、probe が読み取り専用でないということで、本走の解釈以前の問題。
2. 条件付き分解（跨ぎ率など）は**平均回帰の罠**を必ず併記する。今日それで 1 度誤読している。
3. 2M で止めるので 5M 走と水準比較しない。
4. `BDvf1_1216` は fit が 14 倍悪い世界。通常腕と並べない。
5. J・B・A の分解は**恒等式 N = J+B+A が数値的に成り立つこと**を検査してから読む（`test_boundary_dense_0907`）。
