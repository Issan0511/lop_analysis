## 0. 一行

**dead_frac を下げる治療（CBP）が、かえって性能を悪化させるレジームが存在する**ことを示す。成立すれば「dead unit = 可塑性喪失」という同一視への、反例より強い形の反論になる。

---

## 1. 背景

### 1.1 何が起きたか

`bias_margin_0814` で µ=0 のまま dead を誘発できたが、監査で副産物が出た。**同一残差条件の free 腕と frozen 腕で clean eval_loss を比べると、dead の機能的コストが経路で逆転する。**

| セル | dead (free) | free eval | frozen eval | free/frozen |
|---|---|---|---|---|
| n2_K10000（ノイズ σ_ξ=2） | 0.92 | 0.560 | 0.985 | **0.57**（free が良い） |
| n1_K10000（ノイズ σ_ξ=1） | 0.57 | 0.347 | 0.356 | 0.97（差なし） |
| n0_K100（高速切替） | 0.99 | 0.530 | 0.411 | **1.29**（free が悪い） |

σ_ξ=2 では alive ≈ 1.6/20 ユニットが、20 ユニット全生存の frozen ネットを 43% 上回った。

### 1.2 作業仮説

**ノイズ経路の dead は病理ではなく適応的スパース化である。** 学習器はフィット不能なノイズを拾う容量を、b の沈降によって自ら削っている。一方で高速切替経路の dead は真の症状（free が劣る）。**dead_frac が同程度（0.92 vs 0.99）でも中身が違う。**

### 1.3 なぜ CBP なのか（この実験が必要な理由）

上の free/frozen 比較には交絡がある。frozen は「死のない同一ネット」ではなく**閾値表現力ごと奪ったネット**なので、厳密な反実仮想ではない。§1.2 を検証するには、**表現力を変えずに死んだ容量だけを戻す**介入が要る。それが CBP（Dohare et al. 2024）である。

CBP は低効用ユニットを初期化に打ち直す＝**ネットが自ら削った容量を強制的に戻す**操作。§1.2 が正しければ、戻されたユニットはノイズにフィットしに行き、**clean eval は悪化する**。free 同士の比較なので §1.1 の交絡がない。

### 1.4 対照としての既知事実（再実行不要）

`methods_sde_0813` で、条件A（µ≠0、既存 LoP レジーム）では **CBP は最強アーム**だった：A_w100 rho=1e-4 で dead 0.968 → 0.034、eval_loss 0.937 → **0.005**。
**この実験は Dohare 批判ではない。** 主張は「CBP が効かない」ではなく「**CBP の適用条件が明示されていない**」であり、条件A で効くという事実は主張の一部として保持する。

## 2. 設計

条件B、**c = 0.0（µ=0 厳密）**、κ = 1、d = 21、width = 20、target_hidden = 100、lr = 0.01、batch = 1、seeds [0..4]、total_steps 1e6、`lop_every: 1000`。
`bias_margin_0814` の該当セルと同一設定にすること（rho=0 腕が bit 一致するのが S1）。

CBP のハイパラは `methods_sde_0813` と揃える：`maturity: 100, decay: 0.99`。

| 軸 | 値 |
|---|---|
| 経路N（ノイズ） | `target_noise_sd` ∈ {0, 1.0, 2.0}、K = 10⁴ |
| 経路K（高速切替） | K ∈ {10⁴, 10³, 10²}、`target_noise_sd` = 0 |
| 介入 | `rho` ∈ {0（=none）, 1e-5, 1e-4} |

経路N と経路K は (σ_ξ=0, K=10⁴) を共有するので **5 セル × 3 rho = 15 グループ**。

### 実装

新規実装はほぼ不要。`apply_method` の cbp と `target_noise_sd` を**同時に有効化できることだけ**確認する（`gens["method"]` と `gens["noise"]` が分離済みであること、`apply_method` が batch=1 前提であること）。

## 3. 事前登録予測

判定は clean eval_loss（**dead_frac ではない**。CBP は定義上 dead を下げるので、dead を判定に使うと同語反復になる）。paired seed bootstrap (n=2000) の 95%CI。

### PC-1（主判定）経路N・σ_ξ=2 で CBP は**悪化**させる
`rho=1e-4` の clean eval_loss が `rho=0` より高く、diff の CI 下端 > 0。
**反証**: 改善または差なし → §1.2 の適応的スパース化説は棄却。その場合 §1.1 の free 優位は frozen 腕の表現力ハンデで説明されるべきで、**そう明記して閉じる**。

### PC-2（本命：符号の反転）経路K・K=100 では CBP は悪化させない
`rho=1e-4` の eval が `rho=0` に対し悪化しない（改善またはニュートラル）。
**PC-1 と PC-2 が両方通ることが、この実験の目玉。** dead_frac が 0.92 と 0.99 でほぼ同じなのに治療の符号が逆になる＝ **dead_frac は治療の要否を決めない**という直接の実証。
**反証**: 両経路で同じ符号 → 「CBP は µ=0 レジーム全般で有害」という弱い主張に後退。それでも報告価値はあるが、目玉は失われる。

### PC-3（用量反応）害の大きさが rho と σ_ξ に単調
経路N で eval 悪化幅が rho（0 → 1e-5 → 1e-4）に単調増加し、σ_ξ（0 → 1 → 2）にも単調増加。

### PC-4（必須の対照）残差なしでは CBP は中立
(σ_ξ=0, K=10⁴、dead=0) で CBP の eval 差の CI がゼロを含む。
**これが FAIL＝CBP がここでも悪化させるなら、PC-1 の害は「ノイズへのフィット」ではなく汎用的な reset ダメージであり、PC-1 は交絡する。** 主張を「reset は残差の有無に関わらず有害」に修正すること。

### PC-5（機構）解離の可視化
経路N・σ_ξ=2 で、CBP により **dead_frac は下がる**（rho=0 の 0.92 から有意に低下）一方 **clean eval は上がる**。同一セル内で両者が逆向きに動くことを図で示す。
補助指標: online loss と clean eval の差（ノイズへのフィット量）が rho で増大するか。

### PC-6（アンカー、再実行不要）条件A では CBP は有効なまま
`methods_sde_0813` の既存値（A_w100: dead 0.968→0.034、eval 0.937→0.005）を summary に併記。**Dohare 批判ではないことの明示。**

## 4. サニティ

- **S1**: `rho=0` の各セルが `bias_margin_0814` の対応セル（`n2_K10000_bfree` 等）と bit 一致。**`OMP_NUM_THREADS` を揃えること**（前回 SVD の集約順序で eff_rank が 1e-5 ずれた）
- **S2**: clean eval に ξ が入っていない（`eval_batch` にノイズ加算がないことをコード引用で示す）
- **S3**: CBP の reset が実際に発火している。reset 回数の累積が理論値 `rho × width × steps` と一致（端数繰越込み）
- **S4**: reset 直後のユニットは `v=0` なので出力に寄与しない。reset がゼロ回のセル（あれば）は rho=0 と厳密一致
- **S5**: 全アームで `b` は学習可能（`freeze_bias=false`）。今回 b の凍結は使わない

---

## 5. 主張してはいけないこと

1. **「CBP は有害な手法である」とは言えない。** 言えるのは「µ=0 かつフィット不能ノイズという特定レジームで有害」まで。PC-6 を必ず併記する
2. **「Dohare の dead も無害」とは言えない。** 条件A（µ≠0）の dead は µ 経路で、`condA_freeze_0815` のとおり b とは無関係。**レジームが違う**
3. **dead_frac を判定指標に使わない。** CBP は定義上 dead を下げるので、それを効果の証拠にすると循環する
4. PC-2 が落ちた場合、「経路で符号が反転する」という一番強い形は放棄し、弱い主張で書くこと
5. §1.2 の「適応的スパース化」は**この実験で初めて検証される仮説**であり、`bias_margin_0814` の free/frozen 比較は交絡ありの示唆に過ぎない。既定事実として書かない

## 8. 通ったときの主張（先取りメモ、確定後に使う）

「**dead_frac と機能損失は解離する。µ=0・高ノイズ下の dead は容量の喪失ではなく、ノイズを拾う容量の自発的削減であり、これを CBP で戻すと性能は悪化する。同程度の dead_frac を示す高速切替レジームでは CBP は有害でない。したがって dead は病理の名前ではなく状態の名前であり、病理かどうかは何がその状態を維持しているかで決まる**」

→ 力場理論（「病理は状態ではなく力場にある」）の3例目として本筋に接続する。
