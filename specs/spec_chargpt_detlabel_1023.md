## 0. 一行

箱 M のラベルは確率的なので、課題を当てはめた後も誤差 p − y が残り、更新が止まらない。この spec は、遷移の分布を作る Dirichlet の濃度 α を 0.01 から 1e−4（主）と 1e−3（記録）に下げ、ほかはすべて C3-2 と同じにして 10 seed × 100 課題を回す。比べる相手は既存の α = 0.01 の C3-2 で、見るのは喪失（J1）、L0 の伸び（J2）、L0 の死（J3）、課題の後半の重みの動き（J4）、L1 の早期の死と後期の戻り（J5）、L1 への装填の押しの内訳（J6）である。

## 1. 問い

- Issa（1023）の問い: L0 が課題の中で育ち、凍り、死ぬ（③）の駆動は、ラベル雑音（サンプルの経路を追わせる更新）ではないか。決定的に近いラベルで同じ 2 ブロックを回し、L0 の成長・死・喪失が残るかを見たい。
- 残れば、③ はラベル雑音によらない（この箱で）。
- 消えれば、この箱の喪失はラベル雑音が重みを育てる経路だと読みたい。ただし α を下げると課題の中身も縮む（§4.4）。α の腕だけでは「消えた原因はラベル雑音」と言い切れない（§9）。
- MLP・CNN の箱はラベルが決定的なので、この問いの影響を受けない。
- 追加の問い（Issa 1023、Fable 経由）: GPT の箱で段①（装填の押しが unit を沈める向きに揃う）が後期に崩れた原因は、データ（確率的なラベル）か模型か。J6 で、決定的に近い腕の後期の L1 の押しを chargpt_loadsign_1023 と同じ恒等分解で分ける。

用語（初出で言葉を添える）:

- **超過損失**: オンラインの交差エントロピー（更新前のバッチ）から、鎖の条件付き entropy 率 H を引いた量。
- **L0・L1**: 2 ブロックの FFN。L1 が読み出しに隣接し、L0 はその一つ手前。
- **死**: 固定の一様 probe（64 系列 × 128 トークン、seed だけから作る）で、開く割合 p（z > 0 のトークンの割合）が 0.005 未満の unit。
- **up 行**: FFN の up 射影 W の行 w_i（unit i への 128 次元の入力重み）。

生きた unit は、その課題末の鎖 probe で z > 0 のトークンが一度でもある unit とした。

- 生きた L0 の unit は、後期も 1 課題に約 1.7 動く。動きの大きさは早期（1.2）から減っていない。
- 「回転が凍る」（1 − cos 0.116 → 0.001）は全 512 行の中央値である。後期は 8 割以上の行が死んでいて、死んだ行は勾配が 0 なので動かない。生きた unit に限ると 0.116 → 0.011 で、この減り方は行ノルムの伸び（2.8 → 12.6）とほぼ見合う。
- Adam の 1 歩は勾配の尺度で割られるので、雑音が支配する勾配なら 1 歩は lr 程度の乱歩になる。lr 1e−3 で 9,900 歩の乱歩の行の変位の目安は 1e−3 × √9,900 × √128 ≈ 1.1 で、上の 1.2〜1.9 と同じ桁である（読み。§3 の予測の注）。

## 4. 腕と箱

### 4.1 箱（A2 と同じ。違いは α だけ）

- 模型: `src/chargpt_cl_1019.py` の腕 `C3` を `CHARGPT_NLAYER=2` で 2 ブロックにしたもの（C3-2）。pre-LN、d 128、FFN 512、ReLU、LN は γ だけ（β・bias なし）、文脈 128、4 head、RoPE、tied embedding。
- 学習: Adam（β 0.9 / 0.999、ε 1e−8、weight decay なし）、lr 1e−3、warmup は走の最初の 300 更新だけ、batch 32、100 課題 × 10,000 更新、seed 0〜9。fresh（新品の網に同じ課題を学ばせる対照）は課題 10・25・50・100。
- 箱 M: 65 記号。課題ごとに、直前 2 記号の 65² 個の文脈それぞれで、次の記号の分布を Dirichlet(α, …, α) から引く。系列（129 記号）は最初の 2 記号を定常分布 π から引き、以後は遷移から引く。課題を当てはめた後も、ラベルは毎回この分布からのサンプルである。
- **α を指定する場所**: `src/chargpt_cl_1019_kune.py run` の引数 `--alpha`（`chargpt_cl_1019.main` の `args.alpha`）→ `task_cpu_M(seed, task, n, alpha)` → `ChainM(seed, task, alpha)` の `rng.dirichlet(alpha * np.ones(V), size=V * V)`。`rng` は `np_gen(seed, "rule", task)`（PCG64。種は sha256("chargpt_cl_1019/<seed>/rule/<task>") の先頭 8 byte）。A2 の走のコマンドは `src/chargpt_cl_1019_m2_seeds.sh` の `CHARGPT_NLAYER=2 CHARGPT_DECOMP_CKPT=1 $PY src/chargpt_cl_1019_kune.py run --box M --arm C3 --seed <k> --tasks 100 --n_per_task 10000 --alpha 0.01 --fresh_tasks 10 25 50 100 --out <dir>`。値は `provenance.json` の `alpha` に残る。
- 系列は CPU の乱数で作る（`cpu_gen(seed, "data", task)`、probe は `cpu_gen(seed, "probe", task, "chain"|"eval")`、一様 probe は `cpu_gen(seed, "probe", "uniform")`）。どの stream の種も α によらない。
- 同じ seed の腕どうしは、初期値（`init` の stream）と乱数 stream の種が同じになる。Dirichlet の引き方が α で変わるので、遷移表は別物になる。
- `--alpha` に従わない α = 0.01 の書き込みが 2 か所ある。どちらも C3 の学習には効かない。
  - `chargpt_cl_1019_kune.build_model_calibrated` は、V の較正の probe を `task_cpu_M(seed, 1, 1, 0.01)` で作る。使うのは `track_v` を持つ腕（Snake 族と cap の腕）だけである。cap の腕を足すなら、ここを腕の α にするか、0.01 のまま使うと書く。
  - 事後の解析の `analysis/chargpt_seed10_1022/load10.py` の `data()` は、鎖 probe を `ChainM(seed, t, 0.01)` で作る。J6 は腕の α を渡すように変える（§6.5）。

### 4.4 α を下げると変わる他の量（交絡）

α を 0.01 から 1e−4 に下げると、ラベル雑音は 0.29 から 0.0004 に減る。同時に、次の量も変わる。

- **課題の中身**: 最初の 500 更新に出る文脈の数が 4,169 から 176 に減る。π の有効な状態数は 2,319 から 38 に減る。
- **系列の周期性**: 決定的に近い連鎖は、最頻の写像の閉路に落ちる。π の質量の 0.99 が閉路の上にある。系列の後半の目標の 0.98 は、同じ系列の前の周期を写せば当たる（α = 0.01 では 0.03）。
- **当てはめに要る logit の幅**: 最頻遷移の確率の中央値が 0.72 から 1.0 になる。決定的な的を当てるほど logit の差を広げる押しが続く。
- **課題の難しさのばらつき**: 30 課題のうち 6 課題は、異なる文脈が 100 以下の縮退した課題になる。
- **excess の尺度**: H は 0.73 から 0.002 nats になる。T015 の閾値 0.15 nats や、追補 6 の δ = 0.025 は、課題に対して別の意味になる。

このため、A4 と A2 の違いをラベル雑音だけに帰すことはできない。A3 は中間の点（ラベル雑音 0.034、文脈 1,777、写し取り 0.32）で、交絡の向きを見る記録になる。

### 4.5 候補の腕 S2（判断待ち）: α = 0.01 のまま、目標を真の分布にする

起案者の提案。Fable と Issa の判断を待つ。走らせるなら、登録の commit の前に主・記録のどちらにするかを決める。

- **中身**: A2 と同じ連鎖・同じ系列・同じ batch・同じ初期値で、損失の目標だけを、サンプルした次の記号 y から真の条件付き分布 p(·|a, b) に替える。損失は −Σ_c p(c|a, b) log q(c) である。
- **何を分けるか**: logit の勾配は、サンプルした目標では q − y、真の分布では q − p になる。y − p はラベル雑音そのもので、条件付き期待値が 0 である。S2 は、課題の中身・入力・周期性を A2 と同じに保ったまま、ラベル雑音の項だけを勾配から除く。当てはめた後に残る勾配は、網が真の分布を表せない分（当てられない構造）だけになる。§9 の「ラベル雑音と当てられない構造の切り分け」を、α を下げずに行える。
- **記録の揃え方**: online.npz に残す損失は、A2 と同じ定義（サンプルした目標の交差エントロピー）にする。勾配に使う損失（真の分布との交差エントロピー）は別の配列に残す。これで J1 の 3 相が A2 と同じ量になる。
- **実装**: `Engine._loss` の箱 M の分岐で、文脈の番号 x[:, j−1]·65 + x[:, j] から遷移表 P を引いて目標にする。遷移表は課題ごとに GPU の静的な tensor に写す（CUDA グラフの外で copy_）。
- **Adam との関係**: 雑音の項が消えると Adam の分母 √v が小さくなり、系統的な勾配の向きの 1 歩はむしろ大きくなりうる。S2 で L0 の伸びが減らなくても、それは「雑音が駆動していない」の証拠として読める。
- 判定は A4 と同じ規則を S2 と A2 の対に当てる。データ列が同じなので、課題ごとの対の比較もできる。

## 5. 却下した代案

### (a) 最頻の記号だけを出す連鎖（argmax 連鎖）

各文脈で最頻の記号だけを出す連鎖は、65² 状態の上の写像 (a, b) → (b, f(a, b)) になる。乱写像の軌道は短い閉路に落ち、課題の中身がほとんど無くなる。

A2 の箱の遷移表（α = 0.01、seed 0〜9 × 課題 1〜100 = 1,000 写像）の最頻の写像で数えた（`analysis/chargpt_detlabel_1023/prereg/argmax_all.py`）。

| 量（1,000 写像） | 平均 | 10 / 25 / 50 / 75 / 90% | 一様な乱写像の理論（N = 4,225） |
| --- | --- | --- | --- |
| 一様な出発点から最初の繰り返しまでの状態数（ρ 長） | 81.5 | 30 / 50 / 77 / 108 / 138 | √(πN/2) = 81.5 |
| 行き着く閉路の長さ（系列の周期） | 41.2 | 6 / 15 / 32 / 61 / 88 | √(πN/8) = 40.7 |
| 閉路の上の状態の数（課題の中身の上限） | 81.8 | 28 / 49 / 78 / 109 / 139 | √(πN/2) = 81.5 |
| 閉路の数 | 4.8 | 2 / 3 / 5 / 6 / 7 | (ln 2N + γ)/2 = 4.8 |
| 学習コードの π（流域の重み）で、写し取りで当たる目標の割合 | 0.68 | 0.37 / 0.55 / 0.73 / 0.85 / 0.91（写像の間） | — |

- 依頼文の「長さ ≈ √(π·65²/2) ≈ 81」は ρ 長と閉路の上の状態の数に当たる。系列の周期そのものは平均 41 である。
- 学習コードの π は一様な出発点から遅延連鎖を回した極限なので、閉路の上に流域の大きさに比例した質量が乗る。系列は最初から周期的になり、1 課題で学ぶ遷移は平均 82 個に限られる（A2 は 500 更新で 4,169 文脈）。
- これは「当てはめ後に雑音が無い同じ課題」ではなく、「少数の閉路を覚えるか写す課題」である。

### (b) 1 課題につき 1 本の長い列を固定して記憶させる

- 文脈 128 の網に 1 本の固定列を繰り返し見せると、網は列の中の位置（と直前の数記号）から次の記号を引けばよい。
- これは 2 記号の文脈から次の記号を予測する課題ではなく、位置を手がかりにした記憶の課題で、別種である。
- A2 と比べたとき、違いがラベルの決定性なのか課題の型なのかが分けられない。

### (c) α を下げたうえで、系列を一様な状態から出発させる

- 縮退（§4.4）を避けるために π ではなく一様な出発点を使う案。
- 系列の前半は閉路に入るまでの尾（平均 40 状態）を通るので文脈は増えるが、後半は閉路に入って写し取りで当たる。
- 系列が定常でなくなり、H（π での entropy 率）が excess の基準にならない。箱の定義が A2 から離れるので採らない。

### (d) 入力を一様な乱数列にし、目標を文脈の決定的な関数にする

- 入力の分布を固定したまま雑音だけを消せるが、目標が次の入力でなくなる。言語模型ではなく系列のラベル付けの課題になる。
- A2 と比べられないので、この形で回すなら雑音のある腕も新しく要る。§4.5 の S2 のほうが A2 との対をそのまま保てる。
