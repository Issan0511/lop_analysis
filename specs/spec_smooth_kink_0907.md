# 折れ目を滑らかにする — ラチェットが効く長さスケールはどれか（`smooth_kink_0907`）

親: [[前活性オフセット結果_0906]]（ラチェットと井戸の切り分け）／[[井戸の剛性_0907]] / 状態: **事前登録（走らせる前に commit・実装はこの腕表を逐語で消費する）** / 2026-09-07 / 発案: Issa（「leaky のパラメーター実験の折れ目を滑らかにしてみて」）
関連: [[命題1-5_上端則結果_0905]]（線形は釘付け）／[[Snake の実効ゲート]]（mob = 支持平均の傾き・sinc 則）

## 1. 問い

押し下げの片側性は **折れ目（φ′ の跳び）** に由来するとされてきた（ラチェット＝一方通行弁）。ところが `act_offset` / `offset_grid` で分かったのは井戸の側だけで、**ラチェットについては「跨いでいる間だけ働く」「一次の力」「向きは折れ目のコントラスト (1−a) に単調」までしか言えていない。速度則も、効く長さスケールも測っていない。**

折れ目を幅 s で滑らかにすると、どの s から押し下げが変わるかで、**ラチェットが「何を平均した量」で決まっているか**が分かる。手元にある長さは 2 つ:

| 長さ | 値（既存ログ・a=0.1） | それが効くなら |
|---|---|---|
| 支持の半幅 **W** | 3.79（a=0.2/0.3/0.5/0.7 では 2.57/1.99/1.54/1.09） | 実効ゲートは **支持平均の傾き** mob = E_支持[φ′]。支持がすでに折れ目を幅 W で均しているので、**s ≪ W の平滑化は何も変えない** |
| 1 タスクでの z̄ の移動 **δ** | 0.05〜0.12（末尾の 1 タスクあたり） | ラチェットは**軌道の上の弁**。s ≳ δ で弁が潰れ、**s = 0.1 でもう効かなくなる** |

この 2 つは 30〜70 倍離れているので、s の梯子で分離できる。

## 2. 介入

φ_s(z) = a·z + (1−a)·s·softplus(z/s)、softplus(t) = log(1+e^t)。

- φ_s′(z) = a + (1−a)·σ(z/s) は a（z→−∞）から 1（z→+∞）へ幅 s で渡る。**s→0 で leaky に一致**。
- φ_s(z) − leaky(z) = (1−a)·s·log(1+e^{−|z|/s}) ≥ 0 は **z=0 での高さ (1−a)·s·log2 の隆起**で、|z| ≫ s では 0（＝**折れ目から遠いユニットには何もしない**）。
- φ_s″(z) = (1−a)·σ(1−σ)/s は s→0 でデルタに寄る。**支持平均 E_支持[φ″] は s ≪ W では s にほとんど依らない**（幅 W の分布に対するデルタの積分に収束する）ので、「支持平均で決まる」説はここでも s 非依存を予言する。

**曲率が入るのは避けられない**（折れ目を滑らかにする = φ″ を有限にする）。したがって本走は「ラチェットだけを消す」実験ではなく、**「折れ目の鋭さ」という 1 つのつまみを回す**実験である（§6-2）。

**発散の見積り**: 隆起は一様定数ではないが、全ユニットが折れ目付近にいれば実効的に一様シフト c ≈ (1−a)s·log2 として働き、v 空間にコヒーレント曲率 λ ≈ 2h c² を作る（`act_offset` §5 と同じ機構）。a=0.1・s=3 で c ≈ 1.87 → λ ≈ 700 → lr < 2/λ ≈ 0.003。**s=3 は lr 0.01 で落ちる可能性がある**ので、前検査（30k）で確かめ、落ちたら `NOT_RUN` として Log に記録し、追補で lr を下げて回す（`act_offset` 追補 1 と同じ手順）。

## 4. 判定（主判定は 1 本・結果を見る前に固定）

**主判定**: 押し下げの深さ d = −(末尾窓の z̄ の ALL ユニット中央値)。各 s について Δd(s) = d(s) − d(参照) を **seed ブートストラップ 2000・rng(20260907)** で CI 付きに出し、「CI が 0 を除外する最小の s」を **s\*** とする（a=0.1 の梯子で読む）。

- **`DELTA_SCALE`**: s\* ≤ 0.1（軌道の上の弁＝真のラチェット）
- **`SUPPORT_SCALE`**: s\* ≥ 1（支持平均が決める＝mob 則）
- **`INTERMEDIATE`**: s\* = 0.3
- **`SHARPNESS_IRRELEVANT`**: s=3 まで全て CI が 0 を含む
- **`NOT_DETERMINED`**: 参照が S-null に失敗、または a=0.1 の梯子で 3 本以上が発散して s\* が決まらない

**畳み方は上で閉じている**（腕横断の中央値や AND 条件は使わない・[[井戸の剛性_0907]] §5-1 の教訓）。

**補助（ラベルにしない）**: (i) a=0.5 の梯子で同じ s\* を出し、支持スケール説なら a=0.1 より小さい s で動くこと。(ii) 3 分割（上/跨/下）の割合。(iii) 幅 ‖w_free‖ の比。(iv) 実測 mob = `layer1_mob` の中央値と E_支持[φ′] の s 依存。(v) `m_dphiddphi`（曲率が入った効果）。(vi) |v| と線形化率。

**窓**: `edge_law` の tail 窓（末尾 50 記録）。settle は §6-1 の理由で**判定条件に入れない**（参考表示のみ）。

## 6. あらかじめの注意

1. **settle は判定に入れない。** 極細の CI にドリフト条件を掛けると必ず落ちる（`offset_grid` ブロック 1・`edge_law` G1 と同型の誤射が 2 回）。
2. **これは「ラチェットだけを消す」実験ではない。** 平滑化は φ″ を有限にし、折れ目付近に高さ (1−a)s·log2 の隆起も作る。結果は「折れ目の鋭さ」というつまみへの応答として書き、s が大きい腕を「ラチェットが無い腕」とは呼ばない。
3. 隆起の高さは (1−a)·s に比例するので、a=0.1 と a=0.5 を同じ s で比べるときは隆起の高さが 5 倍違うことを併記する。
4. 発散した腕は `NOT_RUN`。押し下げが「消えた」とは読まない。
5. 水準比較は同じ lr の腕どうしだけ。

## 8. 追補 1（30k 前検査の結果を受けて・本走の前に登録）

前検査で **`SKs3_1216`（a=0.1・s=3）が step 1,000 に 10/10 発散**した（§2 の見積りどおり）。初期値ではほぼ全ユニットが折れ目の近くにいるので、隆起 (1−a)·s·log2 = 1.87 が実質的に**一様シフト**として働き、v 空間にコヒーレント曲率 λ ≈ 2h·1.87² ≈ 700 が立つ（lr の上限は 2/λ ≈ 0.003）。`act_offset` の c=±2・`offset_grid` の b+2・`edge_law` の ±5/±4 と**同じ機構**で、これで 4 例目。

安定条件は s < √(1 / (h·(1−a)²·log²2·lr))。lr 0.01・h=100 で **a=0.1 なら s < 1.60、a=0.5 なら s < 2.9**。

したがって:

1. `SKs3_1216` は腕表に残したまま走らせ、**`NOT_RUN`（NUMERIC_DIVERGENCE）として記録する**。lr を下げた版は作らない（水準比較ができず、主判定に使えないため）。
2. 支持の幅を跨ぐ点（s/W > 1）は **a=0.5 側で取る**: `SKa0p5_s2_1216`（a=0.5・s=2・W ≈ 1.54 なので **s/W = 1.3**・λ ≈ 96 で安全域）。梯子 B は s/W = 0.065 / 0.19 / 0.65 / 1.3 の 4 点になり、**支持スケール説の転移点を挟む**。
3. 梯子 A（a=0.1）は s/W = 0.003 / 0.008 / 0.026 / 0.079 / 0.26 の 5 点。**s/W = 1 に届かない**ので、主判定の `SUPPORT_SCALE`（s\* ≥ 1）は「a=0.1 で s=1 まで動かない」ことしか言えない。**転移点そのものは梯子 B で読む**（§4 の主判定は梯子 A のまま・梯子 B は補助）。
