## 1. 問い

[[前活性1次元のdrift則_結果_0907]] では、`drift_law_0907` の spec に「E[Δζ | ζ] は何の関数か」と書きながら、実際に条件付けたのは**跨ぎ率 p_up** だった。結果は「p_up の drift 場は符号を変え、安定不動点 p\* ≈ a² を持つ」。

しかし**力の法則の形をしているのは、位置そのものの場 E[Δζ | ζ] のほう**である。まだ一度も測っていない。そして測れば、今まで別々に出てきた 2 つの結果が正面からぶつかる:

- **上端則**（[[命題1-5_上端則結果_0905]]）: 座る場所は「上端が折れ目」＝ **ζ ≈ −W**。W はユニットごとに違い、走の間に育つ。
- **1 次元に閉じたい**（[[issa-wants-1d-preactivation]]）: ζ だけの関数で書きたい。

上端則が正しいなら、**E[Δζ | ζ] の零点は固定された ζ には無く、W に比例して動く**。つまり

> **drift 場は ζ で閉じるのか、それとも ζ/W（＝実質 p_up）で閉じるのか。**

これを、どちらが正しくても言い切れる形で 1 回で決める。

## 2. 変数（`drift_law_0907` の定義をそのまま使う）

| 記号 | 定義 |
|---|---|
| z̄_k | タスク終端記録の前活性（step 10,000·k） |
| **N_k** | z̄_{k+1} − z̄_k（1 タスクの正味の変位・**判定量**） |
| **ζ_k** | j ∈ {k−4,…,k+5} から **k と k+1 を両方除いた** 8 タスクの z̄_j の平均 |
| **W_k** | 半幅 = 0.5·Σ&#124;w_free&#124;（step 10,000·k の `layer1_w_free` から） |
| p̂_up(k) | ζ_k と task k の w_free から作る 32 点のうち > 0 の割合 |

**両端を除く ζ は譲らない。** 片端しか除かないと揺らぎだけで +0.0247 の偽の傾きが出る（信号の 6 倍・`drift_law_0907` 追補 1）。current-task の z̄ では条件付けない。

窓は **タスク 10〜199**、判定腕は **`LRoff0_1216`**（a = 0.1・c = 0・lr 0.01）。

## 3. 測り方

`LRoff0_1216` の (タスク, ユニット, seed) を **W の三分位**に分ける。三分位ごとに:

1. ζ を**十分位ビン**に切り、各ビンで E[N] とビン中央値 ζ を出す。
2. E[N] が **正 → 負** に変わる隣り合う 2 ビンを線形内挿して**零点 ζ\***（＝安定不動点）を取る。
   - 符号の変化が無い / 複数ある場合はその三分位を `NOT_DETERMINED` にする（複数あるときは最も低い ζ の + → − を採るのではなく、**判定しない**）。
3. 同じことを p̂_up についても行い、**p\*** を取る（第 2 判定）。

## 4. 判定

CI は **seed ブートストラップ 2000・`rng(20260908)`**。

### 主判定 `ZETA_CLOSURE` — 場は ζ で閉じるか、ζ/W で閉じるか

3 つの三分位の ζ\* について、

  **A = max&#124;ζ\*&#124; / min&#124;ζ\*&#124;**,  **B = max&#124;ζ\*/W̃&#124; / min&#124;ζ\*/W̃&#124;**  （W̃ = その三分位の W 中央値）

- **`CLOSES_IN_ZETA`**: A ≤ **1.25** かつ B > **1.25**
- **`CLOSES_IN_RATIO`**: B ≤ **1.25** かつ A > **1.25**
- **`NEITHER`**: A も B も > 1.25
- **`NOT_DETERMINED`**: 有効な三分位が 3 未満／両方 ≤ 1.25（＝識別できていない）／**効果量の床**を割る

**効果量の床（2 つとも要る）**:
1. **W の広がり**: W̃ の max/min ≥ **1.5**（これが無いと A と B は同じ量になり、検査が空虚になる）
2. **drift の大きさ**: 各三分位で、最上位ビンと最下位ビンの E[N] が**逆符号**で、かつ両方の |E[N]| > **0.005/タスク**

> **`CLOSES_IN_ZETA` と `CLOSES_IN_RATIO` は排他で、どちらも積極的な結論になる。** 片方しか主張できない設計にはしない（`drift_law` の反省）。

### 第 2 判定 `PSTAR_INVARIANT` — p\* は W に依らないか

同じ三分位で p\* を取り、**C = max(p\*) / min(p\*)**。

- **`INVARIANT`**: C ≤ **1.25** → `drift_law_0907` の「不動点の位置は 1 次元」が W 横断で成り立つ
- **`VARIES`**: C > **1.25**
- **`NOT_DETERMINED`**: 有効な三分位が 3 未満／床（上と同じ 2 つ）を割る

### 補助（ラベルにしない・数値だけ）

1. 腕ごと（a = 0.1/0.2/0.3/0.5/0.7）の ζ\* と ζ\*/W̃。上端則の比 z̄/W = −1 と突き合わせる。
2. `FBLRoff0_1216`（full-batch）と `LRvf1_1216`（v 凍結）の ζ\*。
3. E[N] の**大きさ**（速さ）が ζ/W と W のどちらに追随するか（`drift_law` の κ = 0.46/0.71/1.21 の再掲）。
4. ζ\* と、同じ窓で実測した z̄/W の中央値の一致。

## 5. 予測（結果を見る前に記入）

- **Claude・主判定**: `CLOSES_IN_RATIO` **70%** / `NEITHER` **15%** / `CLOSES_IN_ZETA` **10%** / `NOT_DETERMINED` **5%**。
  理由: 上端則（z̄/W が −1.0 に固定され、490 タスク保たれる間に両方が 3.3 倍育つ）が正しければ、座る場所は W に比例する。ζ で閉じるなら上端則が偽になる。`NEITHER` を 15% 残すのは、ζ/W が p_up の代理として粗い（32 点の配置は Σ|w_free| だけでは決まらない）ため。
- **Claude・第 2 判定**: `INVARIANT` **55%** / `VARIES` **35%** / `NOT_DETERMINED` **10%**。
  理由: `drift_law` で**速さ** κ は W 三分位で 2.6 倍動いた。速さが動いて位置が動かない、が「1 次元で閉じるのは位置だけ」の主張なので、そこを直接検定することになる。ただし p\* の推定は零点の内挿なので、κ が 2.6 倍違うとビンの分解能も違い、系統差が出うる。

## 6. あらかじめの注意

1. **符号が変わる量に log–log を掛けない**（`drift_law_0907` の設計ミス）。本 spec の主判定は**零点の位置**そのもので、比は最後に取る。
2. **比を検査に使うときは分母が判定と無関係に動かないことを先に確かめる**（`wflip_split_0907` 追補 2）。ここでは分母が W そのもので、**W が動くことが検査の前提**なので、床 1 の「W̃ の max/min ≥ 1.5」で担保する。
3. ζ は N の**両端を除く** 8 タスク平均。
4. 窓は タスク 10〜199 に固定。定着後（末尾）を混ぜない。
5. 腕をまたぐ比較は**同じ lr・同じ窓**のときだけ。
6. これは**事後解析**。ここで出るラベルは既存の走のラベルを一切上書きしない。
7. 三分位は (タスク, ユニット, seed) の全組で切る。seed ごとに切り直さない（ブートストラップは seed 単位）。

## 8. 追補 1（実装中・**結果を見る前**に登録）

### 8-1. ラベルは点推定でなく**ブートストラップ CI** で切る

§4 は A・B・C の**点推定**に 1.25 の境界を当てていた。境界が 1.25 と 1 に近く、seed が 10 本しかないので、点推定は雑音で境界を跨ぐ。**CI で切る**形に厳しくする:

- **`CLOSES_IN_ZETA`**: A の CI **上端** ≤ 1.25 **かつ** B の CI **下端** > 1.25
- **`CLOSES_IN_RATIO`**: B の CI 上端 ≤ 1.25 かつ A の CI 下端 > 1.25
- **`NEITHER`**: A と B の CI **下端が両方** > 1.25
- **`NOT_DETERMINED`**: それ以外（CI が 1.25 を跨ぐ場合を含む）
- 第 2 判定 `PSTAR_INVARIANT` も同様（`INVARIANT` は C の CI 上端 ≤ 1.25、`VARIES` は下端 > 1.25）

**この変更は判定を保守側にしか動かさない**（点推定で付いたラベルが CI で外れることはあっても、その逆は起きない）。閾値 1.25・床（1.5 / 0.005）・§5 の予測は変えない。

### 8-2. 零点は **+ → −** の交差だけを採る（不安定な不動点を拾わない）

§3-2 の「正 → 負」を実装で厳密にし、− → + の交差（不安定な不動点）は**採らない**ことを検査で固定した（`test_zero_crossing_requires_exactly_one_plus_to_minus`）。+ → − が 0 本または 2 本以上ならその三分位は `NOT_DETERMINED`。

### 8-3. 検査で確かめた「識別力」

**判定器が空虚でないことを人工データで実測した**（空虚な S 検査を出さないための対照）:

| 人工の世界 | 作り方 | 出たラベル | A | B |
|---|---|---|---|---|
| ζ で閉じる | N = −0.02(ζ − ζ₀)・ζ₀ = −3 固定 | **`CLOSES_IN_ZETA`** | < 1.1 | > 1.5 |
| ζ/W で閉じる | N = −0.02(ζ + W)（＝上端則の世界） | **`CLOSES_IN_RATIO`** | > 1.5 | < 1.1 |

同じ判定器が両者を**別のラベル**に振り分ける（`test_the_two_worlds_are_not_both_accepted`）。上端則の世界では ζ\*/W̃ が三分位すべてで −1 の ±0.15 に入ることも実測。床も両方向で効く（W の広がり 1.1 倍 → `NOT_DETERMINED`、傾き 1/40 → `NOT_DETERMINED`）。
