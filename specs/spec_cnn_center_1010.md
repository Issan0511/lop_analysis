# cnn_center_1010 — 入力を中心化した leaky CNN で、入力層の沈降は止まるか

依頼: Issa（2026-10-10）「入力を中心化した leaky の CNN を 1 腕回して」。起案は Claude（会議向けに CNN をどこまで詰めるかの相談で、「機構 3（入力層の沈降は非負入力の平均パッチ方向を通る）を予言つきの主張にする最も安い一手」として提案）。
書いた時点: 実装と検査の後、本走の前。本走の値は一つも見ていない。

## 0. 既知（このノートの前に見たもの）

- **基準の腕**: `results/cnn_drive_verify_1009/LR`（leaky 0.1、seed 10–19、30 課題 × 400 epoch、Adam 1e−3、batch 16、sna の束ねエンジン）。
  - c1 の z̄（per_task の zbar_c1 = チャネル平均の中央値）: t1 −0.242（seed SD 0.178）→ t30 −2.740（0.217）、t1→t30 の変化 −2.498（0.290）。
  - 相対位置 z̄/sd（t30）: −1.921（0.168）。
  - online: t1–5 平均 0.9672、t26–30 平均 0.8899、低下 0.0773（seed SD 0.0091）。
- **c1 の分解**（10/10 未明、scratchpad、登録外、seed 10–14、課題末のチェックポイント）: z̄ = ⟨W1, m⟩ + b1。
  - 入力パッチの平均 m は |m| = 3.78 で、共分散の第 1 主成分方向とほぼ一致（cos 0.997、分散の 57%、その方向の sd 1.75）。
  - LR の c1 の沈降は W1 の負の DC 成分 a（m̂ 方向）の伸びで、a は t1 −0.11 → t30 −0.68。Δ⟨W,m⟩ = −2.15（予測 3.78 × Δa）、b はほぼ動かない（+0.05 → −0.26）。
  - Snake の腕では t10 以降、同じ沈降を b1 が担った（b −0.05 → −0.26、DC 成分は 0 に戻る）。
- cnn_drive_verify_1009 の phase 2（leaky）: c1 は切り替え直後の 10 更新で上がり（中央値 +0.13〜+0.79）、課題の当てはめの中で下がる。初期化から t30 までに沈んだ c1 チャネルは 93%、c2 は 99〜100%。
- MLP の先例（relu_doors_0919、RL-CIFAR MLP）: ReLU の生存には中間層の中心化が効き、入力の中心化と LN は無効だった（測った量は生存で、今回の量とは違う）。

## 1. 問い

**Q** 入力の平均パッチ m を 0 にすると（非負入力の DC 経路を塞ぐと）、leaky CNN の入力層 c1 の平均前活性の沈降は止まるか。それとも bias 経路が肩代わりして沈み続けるか。

- 「止まる」なら、機構 3（入力層の沈降は入力の平均方向という入力の分布の幾何を通る）が予言として当たる。
- 「沈み続ける」なら、駆動は入力の幾何に依らず、経路が DC から bias に替わるだけ（Snake の腕と同じ）。機構 3 は「経路の説明」に格下げになる。

## 2. 腕（`src/cnn_center_1010.py`）

- **LRc**: 基準の LR と同じ。違いは、全画像から CIFAR-10 訓練集合 5 万枚のチャネル平均 μ = (0.4914, 0.4822, 0.4465) を引くことだけ（標準偏差では割らない）。seed 10–19、30 課題 × 400 epoch、チェックポイントは t1・2・3・5・10・20・30。
- 中心化の効果（検査 K-center、`results/_checks_cnn_center_1010/checks.json`）:
  - 平均パッチのノルムは 3.76〜3.84 → 0.015〜0.050（各 seed の 1200 枚の平均と訓練集合の平均の差の残り）。
  - 内側のパッチ（5×5 の窓が画像の中、出力の行・列 2〜29）の共分散は相対 1e−8 で不変。
  - **開示**: 全位置で見た共分散は 16% 変わる。ゼロ埋めの 0 が、生の入力では平均（0.44）から遠く、中心化後は平均色に等しいため、縁のパッチが定数以上に動く。したがって「m だけを 0 にした」は内側のパッチについての記述で、縁の扱いも変わっている。
- その他の検査:
  - K-same: 腕 "LR" のとき、継承した束は基準の束と 2 epoch で bit 一致。
  - K-graph: グラフと eager が bit 一致。
  - K-host: 宿主の forward（中心化した画像）と 1 step の損失が完全一致、勾配の差は 1.8e−7。
  - K-repro: エンジンの run を腕 "LR" で 1 課題回すと、基準の走の課題 1 と online・memo・zbar_c1・zsd_c1・zbar_c2・w_norm_c1 がすべて bit 一致。

## 3. 量

- **主量 D1**: seed ごとに D1 = zbar_c1(t30) − zbar_c1(t0)。zbar_c1 は per_task の定義（チャネル平均の中央値）で、t0 は初期値で `evaluate` した値（LR は生の入力、LRc は中心化した入力）。腕の比 ρ = mean D1(LRc) / mean D1(LR)。
- **経路**（LRc、チェックポイントから）: Δz̄_j を Δb_j と Δ⟨W_j, m_c⟩（m_c は中心化後の平均パッチ）に分ける。後者は |m_c| ≈ 0.03 なので構成上ほぼ 0 になる。肩代わりの有無は Δb で読む。
- **副量**:
  - (i) c2 の沈降: 初期値より z̄_j が下のチャネルの割合（t30、10 seed × 16 チャネル）。
  - (ii) c1 の相対位置 r1 = zbar_c1/zsd_c1（t30）。
  - (iii) 可塑性: 低下 = online の t1–5 平均 − t26–30 平均。水準は t1–5 平均。
  - (iv) c1 の幅 zsd_c1 と、W1 の DC 成分 a（m̂ は生の入力の平均方向）。

## 4. 判定（帯は雑音から導く）

- **Q（主）**:
  - 基準の D1 の seed SD は約 0.3（t1→t30 で 0.29）なので、平均の SE は約 0.09、−2.5 に対して約 4%。LRc の SD が同程度なら ρ の SE は約 0.05。帯 0.25 / 0.75 は 0 と 1 から 5 SE 以上離れる。
  - ρ ≤ 0.25 → **C1_STOPS**（沈降の 75% 以上が消える。機構 3 が予言として当たる）。
  - ρ ≥ 0.75 → **C1_KEEPS**（bias が肩代わりする。駆動は入力の幾何に依らない）。
  - それ以外 → **C1_PARTIAL**。
  - 符号は seed ごとの D1 の符号検定で併記する。
- **副 (i)**: LRc の c2 で沈んだ割合 ≥ 0.90 → C2_SINKS。< 0.75 → C2_STOPS。間は C2_PARTIAL。
- **副 (iii)**:
  - 低下の差 δ = 低下(LRc) − 低下(LR)。基準の seed SD 0.009 から、腕の差の SE は約 0.004。帯は 2.5 SE = 0.01。
  - δ ≤ −0.01 → LESS_LOSS、δ ≥ +0.01 → MORE_LOSS、それ以外 → SAME_LOSS。

## 5. 予測（Claude、本走の前）

- Q: C1_STOPS 0.55 / C1_PARTIAL 0.30 / C1_KEEPS 0.15。
  - 基準の LR では c1 の沈降の 88% を DC 経路が運び、b はほとんど動かなかった。Adam では、1 座標の bias が平均を動かす速さは、DC 経路（75 座標 × 入力平均 0.44）の約 1/33。
  - ただし Snake では bias が肩代わりしたので、KEEPS も無視できない。
- 副 (i) C2_SINKS: 0.75（c2 の駆動は自己項で、入力の平均に依らない）。
- 副 (ii) |r1(LRc)| ≤ 0.96（基準の半分）: 0.55。
- 副 (iii) LESS_LOSS 0.35 / SAME_LOSS 0.40 / MORE_LOSS 0.25（MLP の先例では入力の中心化は ReLU を救わなかった。leaky の CNN の低下が c2・fc にあるなら変わらない）。水準（t1–5）が基準の 0.9672 より高い: 0.60。

Issa の予測は取っていない。

### 6.1 予測の採点

- Q: STOPS 0.55 ✗（PARTIAL 0.30）。
- C2_SINKS 0.75 ○。
- |r1| ≤ 0.96: 0.55 ✗。
- 可塑性: 最頻 SAME 0.40 ✗（LESS 0.35）。水準が上: 0.60 ○。

最頻の外れが 3 つで、私の予測は中心化の効きを入力層の沈降については過大に、可塑性については過小に見積もっていた。

### 6.2 読み

- **言える**:
  - 非負の入力の平均方向（DC 経路）は、leaky CNN の入力層の沈降の約 2/3 を運ぶ（ρ = 0.34）。
  - 中心化してその経路を塞いでも、平均を下げる駆動は残り、bias 経路で 1/3 の量が沈む（10/10 seed）。駆動は入力の幾何に依らず存在し、入力の幾何はそれを約 3 倍に増幅する。Adam の 1 歩あたりの効率の見積もり（bias は DC 経路の 1/33）は外れた。駆動が多くの step で持続するので、1 座標の bias でも 30 課題で −0.9 動く。
  - 深い層 c2 は入力の中心化に関わらず沈む（むしろ深い）。c2 の駆動は自己項で、入力の平均に依らない（cnn_drive_verify_1009 の c2 の谷の則・自己形と整合）。
  - 入力の中心化で、可塑性の喪失は 60% 小さくなる（10/10）。同時に c1 の沈み込み（t30 で生の入力は 99% の位置が負側、中心化は 90%）と実効ランクの崩れ（5.9 対 13.0）が防がれる。
- **言えない**:
  - 可塑性の改善が c1 の沈降の減少によるものか。中心化は、縁のパッチの埋め方（全位置の共分散の 16%）と初期の c1 のゲートの割合（t1 で z>0 が 0.29 対 0.48）も変えるので、この 1 腕では分けられない。
  - bias 経路の駆動の項。
  - Snake で同じ割合になるか（Snake では生の入力でも t10 以降 bias が担った）。

## 7. 訂正（2026-10-10 12:00、Issa の指摘「中心化でバイアス経由になるのは既知」）

§6.2 の「駆動は入力の幾何に依らず存在し、入力の幾何がそれを約 3 倍に増幅する」は、新しい発見ではない。既知の結果を CNN で言い直したものである。

- 中心化すると沈降の輸送が µ 経路から b 経路に移ることは、vault `centered_bias凍結結果_0901`（µ 経路支配の std と b 経路支配の centered が介入で分かれた）で確定している。
- 平均方向の重み勾配 = bias 勾配 × ‖µ‖²（同符号で積む）は `RL-CIFAR第1層の帯別帳簿_事後_0922` にある。
- §1 の問いの「機構 3（DC 経路）」は、この µ 経路を CNN の共有カーネルに置いたもの（平均パッチ m が µ の役）。§1 の二択のうち「沈み続ける（bias が肩代わり）」の側は、事前に既知から予想できた。予測（§5）で STOPS を本命に置いたのは、この既知を引かなかった誤り。

この走で新しく言えるのは、CNN の入力層での量だけである。
- 生の入力では c1 の沈降の 94% が µ 経路で運ばれる。中心化すると全部が b 経路に移り、量は 0.34 倍になる。
- c2 は中心化に関わらず沈む。
- 可塑性の喪失は 60% 減る（10/10）。向きは MLP の std 入力と同じ。
