## 0. 一行と問い

第1層の行 $w_i$ を、その seed の固定 1200 枚の平均画像 $\mu$ の方向 $e=\mu/\|\mu\|$ に沿って $w_i=q_ie+v_i$（$v_i\perp e$）と分けると、同じ 1200 枚の上で

$$\bar z_i=q_i\|\mu\|+b_i\quad(\text{厳密}).$$

平均前活性を動かす重みは $q_i$ だけで、$v_i$ はその周りの広がりだけを作る。**task 2 以降 $|q_i|$ と $\|v_i\|$ の成長をそれぞれ止めたとき、第1層の応答（平均 $\varphi'$）と相対位置（$d$）はどう変わるか。**

- **Q1（主）**: 両成分を止める（cap_both）と、ref より応答が残り、相対位置が浅く保たれるか。
- **Q2（成分）**: 効くのは平行成分 $q$ の上限（cap_par）か、直交成分 $v$ の上限（cap_perp）か。**cap_perp が逆に沈みを深める**可能性（広がりだけ止めて平均の経路を開けておく）を対等に検査する。
- **Q3（吸収）**: 全 1200 枚が負側（$U_i<0$）になるユニットは 150 タスクまでに現れるか。どの腕で。

## 2. 設計

### 2.1 箱（`layer_chimera_rl_0914` の EL 腕を 150 タスクへ）

- Random Label MNIST。seed ごとに MNIST 訓練集合から 1200 枚を固定（`RL.subset_idx`・role `rl_subset`）、画素/255。各タスクで 1200 枚それぞれに独立一様な 10 クラスラベル（role `rl_labels`）。
- 784–100–100–10。**第1隠れ層 ELU(α=1)（`elu_growth_0909.ELU(1.0)`）、第2隠れ層 leaky 0.1（`H.ARMS["LR"]`）**、出力線形。初期化は宿主 `H.init_params(seed)`。
- Adam lr=1e−3・β=(0.9, 0.999)・ε=1e−8、正則化なし、moment と step 数はタスクをまたいで保持。
- batch 16、80 epoch × 75 更新 = **6000 更新/タスク**、各 epoch で標本順を引き直す（role `rl_batch`）。**150 タスク**。
- seed 0–9。CPU・1 スレッド。

### 2.2 腕（4 腕 × seed 0–9 = 40 run）

| 腕 | $\|q_i\|$ | $\|v_i\|$ |
|---|---|---|
| ref | 自由 | 自由 |
| cap_par | $\le\|q_i^*\|$ | 自由 |
| cap_perp | 自由 | $\le\|v_i^*\|$ |
| cap_both | $\le\|q_i^*\|$ | $\le\|v_i^*\|$ |

$q_i^*,v_i^*$ はその run 自身の task 1 終端の第1層。第2層・第3層・bias は全腕で自由。

### 2.3 上限の定義（`src/mucap_el_0916.py`）

$e$ は seed の 1200 枚の平均画像から float64 で一度だけ計算し、ループ内では float32 に落としたものを使う（台帳と恒等式は float64 の $e$）。**各 Adam 更新の直後**、task 2 の最初の更新から:

- cap_par: $|q_i|>|q_i^*|$ の行だけ $e$ 方向に動かして $|q_i|=|q_i^*|$ にする（その時点の $q_i$ の符号を保つ。上限の内側での符号反転は許す）。$v_i$ は丸め以外動かさない。
- cap_perp: $\|v_i\|>\|v_i^*\|$ の行だけ、$q_i$ と $v_i$ の向きを保って $\|v_i\|=\|v_i^*\|$ にする。
- cap_both: 平行 → 直交の順（両順は丸めの範囲で一致・S3）。
- **上限であって等式固定ではない**: 上限以下の行は 1 bit も書かない。小さい成分を膨らませない。bias・W2・W3・Adam の moment は触らない。

これは行平均／中心化の分解（`wcap_rlmnist_0914`）とは別の基底であり、両方を記録する（§3）。

### 2.4 全腕で同一であるべきもの（S5 で検査済み）

seed ごとに init・subset・全タスクのラベル・全 epoch の標本順・task 1 終端の状態（重み・moment・step 数の sha256）。

## 3. 測る量（`src/mucap_el_run_0916.py`・すべて float64 で保存）

### 3.1 診断点

- task 1: 開始（更新 0）と終了（6000）。
- **task 2–10: 更新 0, 75, 375, 1500, 3000, 6000**。
- task 11–150: 開始（0）と終了（6000）。開始点は新しいラベルを引いた直後・重みが動く前。
- MNIST test 10000 枚での同じ幾何量: **task 1, 10, 50, 100, 150 の終了点**。訓練 1200 枚の値と混ぜない。

### 3.2 `units.npz`（診断点 × ユニット）

両隠れ層について、固定 1200 枚上で:

- 支持の幾何: $\bar z_i$、$\sigma_i$（母標準偏差）、$U_i=\max_xz_i(x)$、$p_i^+=\Pr_x[z_i>0]$、$d_i=\bar z_i/\sigma_i$、$K_i=(U_i-\bar z_i)/\sigma_i$（$\sigma_i=0$ なら $d,K$ は nan、$\bar z,U$ は残す）
- 応答: 平均 $\varphi'$、RMS $\varphi'$、$\varphi'<0.05$ の割合
- 成分（両基底）: $q_i$、$\|v_i\|$、行平均 $m_i$、$\|\widetilde w_i\|$、$\|w_i\|$、$b_i$。第2層の $q,\|v\|$ はその時点の $a_1$ の平均方向に対する記述値（第2層の $e$ は動く）
- 第2層の入力: $S_2=\sum_ja_{1,j}$ の平均・sd、$\|\mu_2\|$
- 第1層の Adam: 行ごとの $\hat m$ の RMS、$\sqrt{\hat v}+\varepsilon$ の RMS と最小、実効歩幅 $\hat m/(\sqrt{\hat v}+\varepsilon)$ の RMS、$\sqrt{\hat v}<\varepsilon$ の座標割合
- `q_cap`・`v_cap`（cap 腕の半径）

### 3.3 `ledger.npz`（タスク × ユニット・第1層・毎更新で積算）

$n\in\{q,\ \|v\|,\ m,\ \|\widetilde w\|\}$ について $\Delta(n^2)=2\langle n,dn\rangle+|dn|^2$ を、**Adam の一歩**（更新前 → 更新後）と**上限の補正**（更新後 → 射影後）に分けて積算。$q$ と $m$ の符号付き変位、各成分の traffic（$\sum|\text{増分}|$）。帳簿がタスク端点と閉じることは S6 で検査済み。

### 3.4 `per_task.csv`（run × タスク）

online 精度（各バッチの更新前の正解率の平均）、タスク終端の 1200 枚での正解率、射影の実績（書いた行数・除去量、成分別）、§3.2 の各量のユニット中央値。

## 4. endpoint（すべて seed ごとに作ってから seed 間で要約）

### 4.1 主 endpoint（第1層）

窓 $W$ の値 $X_W$ = 「画像平均 → 全 100 ユニットの算術平均 → 窓内タスク終端の算術平均」。生きているユニットだけに絞らない。

- **E1（応答）**: $X=\overline{\varphi'}$。$\Delta E1=X_{W}-X_{t1}$。
- **E2（相対位置）**: $X=d=\bar z/\sigma$。$\Delta E2=X_W-X_{t1}$。$\sigma_i=0$ のユニットは E2 の平均から除き、その数を報告する。

**主窓 $W$ = task 51–150 の終端**（100 タスク）。形成窓 task 2–10・11–50 は副報告。

腕の効果は seed 内の対応差 $\delta=\Delta_{\mathrm{arm}}-\Delta_{\mathrm{ref}}$。E1・E2 とも **正なら「ref より応答が残る／相対位置が浅い」**。

### 4.2 副 endpoint（登録・判定の代用にしない）

1. **吸収**: $U_i<0$ のユニット割合（各診断点）。ユニットごとの初回到達タスクと、5 タスク連続で $U_i<0$ に留まった初回タスク、$U_i\ge0$ への復帰回数。150 までに到達しないユニットは右打切りとし、151 に置き換えない。
2. **正側の割合**: $p^+$ の $\Delta$ と腕間差（E1 と同じ集約）。
3. **尺度と裾**: $U$、$K$、$\sigma$、$\bar z$ とその分解 $q\|\mu\|$／$b$。**$U$ の水準差は「上端が残った」の証拠にしない**（§1.2-1）。
4. **両基底の成分と収支**: §3.3 の各項のタスク和、窓和。「Adam の一歩の整列項」「射影の補正」を別に示す。
5. **Adam の分母**: $\sqrt{\hat v}<\varepsilon$ の座標割合と実効歩幅。ゲートと ε の大小だけで停止と判定しない。
6. **test 集合**での $U$・$p^+$・$d$（t1/10/50/100/150）。
7. **性能**: online 精度、適合率 $F(t)=(A(t)-0.1)/(A(1)-0.1)$（0.1 は 10 クラス一様ラベルの偶然水準で、データから選んでいない）。
8. **第2層**: E1・E2 と同じ量を第2層で。

## 5. 判定

### 5.1 帯の算術

主 2 endpoint それぞれで、10 seed の $\delta$ の平均・SD・**97.5% 対応差 t 区間**（df=9、2 量の Bonferroni）。95% 区間も併記。全 seed の $\delta$ を表で出す。SD = 0 なら区間を作らず実測の同一差を示す。

各 endpoint の符号 $s\in\{+,-,0\}$: 97.5% 区間の下端 > 0 なら +、上端 < 0 なら −、それ以外 0。

### 5.2 適用条件（満たさなければ主判定は INAPPLICABLE）

- **(A) 完全性**: 全 seed で 4 腕の task 1 終端 sha256・ラベル・標本順が一致、全 run が 150 タスク完走、非有限値なし、run の commit で S1–S7 が pass。無効 seed は黙って落とさず、有効 seed が 8 未満なら INAPPLICABLE。
- **(B) ref に現象がある**: ref 単独の $\Delta E1$ と $\Delta E2$ の 95% t 区間（seed 間）がともに 0 より下。パイロットでは t50 で −0.70 と −2.0。
- **(C) 上限がかかっている**: 各 cap 腕・各 seed で、主窓の全タスクについて、その腕が上限する成分の射影行数 > 0。一度も書かない上限は操作を試していない（閾値は「0 でない」で、値を見て決めていない）。

**読みのフラグ（判定を変えない）**: IMPAIRED — cap 腕の task 2–5 の平均 $F$ が、ref の task 2–5 の平均 $F$ から「ref 自身が task 1 から task 2–5 までに失った分」をさらに引いた値を下回る seed が過半数。パイロットの ref は $F_{2\text{–}5}\approx0.965$ なので目安は 0.93。

### 5.3 ラベル

**主（cap_both − ref）**:

| $s_{E1}, s_{E2}$ | ラベル |
|---|---|
| +, + | **BOTH_HELD** |
| +, 0 | RESPONSE_ONLY |
| 0, + | POSITION_ONLY |
| −, − | **CAP_DEEPENS** |
| −, 0 ／ 0, − | CAP_DEEPENS_PARTIAL |
| +, − ／ −, + | MIXED |
| 0, 0 | UNRESOLVED |

**成分（cap_par − ref、cap_perp − ref・95% 区間・探索的）**: 同じ表を各腕に適用。加えて交互作用 $\delta_{\mathrm{both}}-\delta_{\mathrm{par}}-\delta_{\mathrm{perp}}$ の 95% 区間。

### 5.4 読み方（登録）

- BOTH_HELD かつ cap_par が同符号で、cap_perp がそうでない → **第1層を沈めるのは平均画像方向の重みの成長**。沈みの 97% が $q\|\mu\|$ というパイロットの分解を介入で裏づける。
- cap_perp が CAP_DEEPENS → **広がりを止めて平均の経路を開けると、相対位置はかえって深くなる**。設計 §10.1 が対等に挙げた「幅を支える成分を抑えると裾の消失を早める」の実例。
- cap_both が BOTH_HELD でも IMPAIRED → 「可塑性を守った」とは書かない。学習を止めて沈みも止めた、と書く。
- 吸収（§4.2-1）が ref で出なければ、**この箱の応答喪失は吸収を経ない**と書く。どの腕でも吸収が出なければ「150 タスクの観測内で未到達」であり、不可避性の否定ではない。
- UNRESOLVED は「効果なし」ではない。単独腕が両方 0 でも「両方必要」とは書かない。
- cap_par は §1.2-4 のとおり「平均画像チャンネルを初期化の大きさに閉じ込める」操作であり、「$q$ の成長を途中で止めた」とは書かない。
- すべて「この ELU→leaky・乱数ラベル・6000 更新・task 2 開始・第1層」に限る。第2層（EE 箱）・PM・他の活性化へ移さない。

| (C) 上限がかかる | 満たす 95%（ref で $\|q\|$ 94 倍・$\|v\|$ 8.4 倍に育つ） |

**Issa の予測**（2026-09-16・登録 commit feb41ff の後、cap 腕を回す前にチャットで記入）: **Claude と同じ** — cap_par **BOTH_HELD**、cap_perp **CAP_DEEPENS**（広がりだけ止めて $q\|\mu\|$ の沈みを放置すると $d$ は −10 以下へ）、cap_both **BOTH_HELD**。発言は「同じ予想で」。ラベルの一致を記録し、Issa 自身の確率は付けない。
