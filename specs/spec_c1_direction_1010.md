# c1_direction_1010 — 隠れ層に読まれる層の押しの向き: CNN の入力層が自己形から外れる理由を帳簿で決める

状態: 登録（2026-10-10 13:15、計算前）。導出は `analysis/c1_direction_1010/derivation.md`。起案は Issa「入力層の向きが自己項から外れることには、まだ導出がありません — これ詰めたいですね」（10/10 12:30）。分業: 設計・予測・判定は Claude（Fable）、実装・計算は Claude（Opus サブエージェント）、独立の導出と批評は Codex。

## 0. 既知（このノートの前に見たもの）

- `cnn_drive_verify_1009`: c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ の沈める側の割合（LR、10 seed × 16 ch）: t1 0.50、t2 0.39、t5 0.23、t10 0.10、t20 0.11、t30 0.40。c2: 0.74、0.68、0.84、1.00、1.00、1.00。Snake 4 腕の c1: 0.51〜0.54、t30 で 0.43。中心化自己形 S1 > 0 は c1 92%・c2 90〜100%。
- 3 層 MLP（vault `3層RL-CIFARへの拡張_…_1007`）: 第 1 層の実際の押しは raw 84〜97%、std 37〜67%（自己形は 100%）。「W3 の成長 × 初期の W2 列の項」は未導出。µ₂ の担い手は raw で閉じた側（負）、std で開いた側（正）。
- 第 2 層の沈降は W2 の µ₂ 方向の反平行成分の成長が主（同ノート §4、bias 0〜5%）。
- LR の c1 の沈降は W1 の負の DC 成分（m̂ 方向）: a −0.11（t1）→ −0.68（t30）、幅 0.61 → 1.43 の大部分が DC 成分（`cnn_center_1010` §0、scratch の分解を本ノートで登録し直す）。

## 1. 問い

**Q1** c1 の切替の押しが自己形に従わないのは、下流の層へ透過する項（導出ノート §3: 接続重みの µ₂ 方向の反平行成分 × 下流の沈める押し）が自己整合項に勝つからか。c2 で従うのは自己整合項が勝つからか。
**Q2** 課題の中で c1 が沈む（切替で浮いた分を超えて正味が負になる）のは、透過の結合が切替直後に強まる非対称によるか。
**Q3** 同じ分解で、3 層 MLP の第 1 層の raw（沈める側 84〜97%）と std（37〜67%）の違いが、µ₂ の符号の違い（透過項の符号 = −sign(µ₂,i)）として出るか。

## 2. 量（定義は導出ノート §1。すべて float64、状態は課題末のチェックポイント）

### 2.1 CNN（`src/c1_direction_1010.py`、`cnn_drive_verify_1009.py` の State・forward・活性化を import）

状態 (arm, seed, t) ごと、チャネル j（c1）・k（c2）ごとに:
- G_j（c1）: (1) の Σ δ1 K1。autograd の G_full（`measure_*.npy` に保存済み）と相対 1e−8 で一致すること（検査 C1）。
- 分解 G_j = G_j⁰ + G_j^{drift} + G_j^{rest}: H1_j を W2⁰・ΔW2^{drift}・ΔW2^{rest} で作り直して (1) に入れる。和が G_j と 1e−10 で一致（検査 C2）。µ₂ = mean_{n,q′} unfold(P1)（400 次元、zero-pad 込み）。ΔW2^{drift}[k] = ⟨ΔW2[k], µ̂₂⟩ µ̂₂。
- c2 も同じ: G_k = Σ_{n,k′,q′} δ2_{k′} T_k（T_k は u_k に沿った z2 の接線。上流 W1/b1 経由の分を含む。autograd の G_full と 1e−8 で一致: 検査 C3）、H2 を W3⁰・ΔW3^{drift}（µ₃ = mean_n vec(P2) への射影）・ΔW3^{rest} で作り直す。
- 付帯量: P̄1_j = mean_{n,q} P1_j、c_k := −⟨ΔW2[k], µ̂₂⟩、D̄_k = Σ_{n,q′} δ2_k、s_kj とその init/Δ、透過の近似 T̂_j = Σ_k s_kj D̄_k（(3) の読み。G_j との Spearman）、自己形 S0_j = Σ γ K1 P1 と S1、γ̄_j、fc1 側の c_u := −⟨ΔW3[u], µ̂₃⟩、D̄3_u = Σ_n δ3_u。
- 対象: LR（seed 10–19、t ∈ {1,2,5,10,20,30}）、Snake 4 腕（SNA・SNAc3・CV06FC3・CV3FC06、seed 10–19、同じ t）、LRc（中心化、seed 10–19、t ∈ {5,10,20,30}。LRc の L_u と G はまだ計算していない）。初期値は `CN.init_params(seed)`（verify の State(task=0) と同じ。LRc は入力だけ違い初期値は同じ）。
- 検査: C1〜C3 に加え、C4: ΔW2^{drift} だけで作った z̄2 の変化 ⟨ΔW2^{drift}[k], µ₂⟩ が ⟨ΔW2[k], µ₂⟩ に等しい（射影の定義）。C5: 1 状態で (1) を autograd（b1 の勾配 × 1 + W1 の勾配 · M）と照合。

### 2.2 課題の中（Q2、`replay` の拡張）

LR の t10 → t11 と t20 → t21（seed 10–19、engine の束で再走、保存済み t11・t21 と重みが相対 1e−6 以内で一致すること: 検査 R1）。記録する step: 0, 1, 10, 75, 150, 750, 3750, 7500, 15000, 30000 で、z̄1・z̄2、W1 の DC 成分 a_j = ⟨W1[j], m̂⟩、b1、⟨W2[k], µ̂₂⟩（µ̂₂ は課題開始時の状態で固定して測る）、b2。step 75 と 750 の状態を保存し、**その課題の実ラベル**の CE の勾配で同じ分解（G^{task}_j = G^{task,0} + G^{task,drift} + G^{task,rest}）を計算する。

### 2.3 3 層 MLP（Q3、`analysis/c1_direction_1010/mlp_drift.py`）

`rlcifar_mlp_battle_0918` の LR raw・LR std、seed 0–9、t ∈ {5,10,20,50}（snap の t00 = 初期値）。第 1 層 unit i の押し G_i = Σ_n K_n φ1′(z1_in) [W2ᵀ δ2]_in（p169 の S_i と同じ量。K_n = x̄·x_n + 1、δ2 = φ2′(z2) ⊙ W3ᵀ(p_n − 1/K)）。W2 = W2⁰ + ΔW2^{drift}（行ごとに µ̂₂ = mean_n h1 へ射影）+ ΔW2^{rest} で G_i を 3 つに割る。生きた unit = p ≥ 1%。付帯: h̄1_i、c_k = −⟨ΔW2[k], µ̂₂⟩、D̄_k = Σ_n δ2_kn。

## 3. 判定の帯（雑音から導く）

率は seed ごとに出して seed 平均（LR は 16 ch × 10 seed、MLP は生きた unit × 10 seed）。偶然の率 0.5 の seed 平均の SE は約 0.04（1 seed 0.125 / √10）。**強い帯 ≥ 0.85**（0.5 から約 9 SE）、**多数の帯 ≥ 0.70**（約 5 SE）、**偶然の帯 [0.35, 0.65]**（±3.75 SE）。Snake は 64 ch × 10 seed で SE 0.02 だが同じ帯を使う。符号の一致・支配（|A| > |B|）の率も同じ帯。

- **Q1 = DRIFT_EXPLAINS**: P1 の本命（c1 の drift が浮かせる側 ≥ 0.85 かつ支配 ≥ 0.70 かつ init の項は偶然の帯）と P2（c2 の rest が沈める側 ≥ 0.85 かつ支配 ≥ 0.70）がともに立つ。
- **Q1 = DRIFT_SIGN_ONLY**: drift の符号は立つが支配が立たない（c1 の外れの符号は説明でき、大きさは別の項と分け合う）。
- **Q1 = NOT_DRIFT**: c1 の drift が浮かせる側 < 0.70、または init の項が符号を担う（> 0.70 の一致）。
- **Q2 = SWITCH_CONCENTRATED**: P9(a) が 8/10 seed 以上。**Q2 = NOT**: それ以外。P9(b) は補助。
- **Q3 = SIGN_RULE_HOLDS**: raw の drift が沈める側 ≥ 0.85 かつ std の drift が浮かせる側 ≥ 0.70。**PARTIAL**: 片方。**NOT**: どちらも立たない。

## 4. 予測（Claude、計算前。◎ 本命 ○ 対抗）

- **P1**（LR c1、t ∈ {5,10,20}、P̄1_j > 0 のチャネル）: ◎ G^{drift}_j < 0 が ≥ 0.85。G⁰_j と G_j の符号一致は偶然の帯。|G^{drift}| > |G^{rest}| が ≥ 0.70。G^{rest}_j > 0 が ≥ 0.60（弱い: rest には自己整合項のほかに AC の構造が混ざる）。○ drift の符号は立つが支配は 0.5〜0.7（DRIFT_SIGN_ONLY）。
- **P2**（LR c2、同じ t）: ◎ G^{rest}_k > 0 が ≥ 0.85、|G^{rest}| > |G^{drift}| が ≥ 0.70、G^{drift}_k < 0 が ≥ 0.60。○ G^{drift}_k > 0（fc1 の反平行漂流が無い、または D̄3 の符号が違う）— このときは §4 の読みを捨てる。
- **P3**（反平行の漂流、既知の構造の確認）: c_k > 0 が ≥ 0.85（t ≥ 5）、fc1 の c_u > 0 が ≥ 0.85、D̄_k > 0 が ≥ 0.85（t ≥ 5）。
- **P4**（時間の形）: c1 の drift の分担 |G^{drift}|/(|G⁰|+|G^{drift}|+|G^{rest}|) の seed 中央値が t1 → t20 で単調増加（8/10 seed 以上で t20 > t1）。
- **P5**（t30 の戻り）: t30 で P̄1_j ≤ 0 のチャネルでは G^{drift}_j > 0 が ≥ 0.70（符号則 −sign(P̄1_j)）。P̄1_j ≤ 0 のチャネルが 5 個未満なら判定しない。
- **P6**（Snake 4 腕の c1、t ∈ {5,10,20}）: G^{drift}_j < 0 が ≥ 0.70（P̄1_j > 0）。支配は偶然の帯（drift と rest が拮抗して全体が 0.5 になる）。
- **P7**（LRc、t ∈ {5,10,20,30}、未計算の腕への予言）: c1 の G_j > 0 が ≤ 0.40、G^{drift}_j < 0 が ≥ 0.85。c2 は G_k > 0 が ≥ 0.85。
- **P8**（MLP、Q3）: ◎ raw: h̄1_i < 0 の生きた unit で G^{drift}_i > 0 が ≥ 0.85、全体の G_i > 0 は 0.84〜0.97（既知と同じ）。std: h̄1_i > 0 の生きた unit で G^{drift}_i < 0 が ≥ 0.70、G^{rest}_i > 0 が ≥ 0.70、全体は偶然の帯。○ std で drift が偶然の帯（µ₂ 経路の漂流が弱い）。
- **P9**（Q2、LR t10→t11・t20→t21）: (a) ◎ Σ_k ⟨ΔW2[k], µ̂₂⟩ の課題内の変化の ≥ 50% が最初の 75 更新で起きる（8/10 seed）。(b) step 75・750 の実ラベル勾配で c1 の G^{task}_j > 0（沈める側）が ≥ 0.70、その drift 部分 G^{task,drift}_j > 0 が ≥ 0.70（c2 が戻る局面で透過が反転する）。○ (b) は step 75 だけ立つ。
