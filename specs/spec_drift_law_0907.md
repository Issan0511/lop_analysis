## 1. 問い

可塑性喪失の記述を**前活性 1 次元**に閉じたい。今日残った成果（着座点＝φ+c の零点・上端則 z̄/半幅 = −1・位置＝上端−半幅）はすべて 1 次元の言明であり、崩れたのは「力の法則」の側だった（[[力場が特定できない根本原因_0907]]）。そこで**ポテンシャルを仮定せず**、1 次元の

**drift 則: E[Δζ | ζ] は何の関数か**

を直接測る。これが測れれば、ラチェットの速度則（本プロジェクトで一度も測っていない量）が 1 次元の関数として書ける。

**候補の形**（勾配の帳簿から）: ∂L/∂b = 2v[a·E[δ] + (1−a)·E[δ·1{z>0}]]。出力バイアスが E[δ] をほぼ消すので、残るのは折れ目より上の点だけが効く第 2 項。したがって

  **E[Δζ] ∝ −(1−a) · p_up**,  p_up = 支持 32 点のうち折れ目より上にある割合

を検定する。**(1−a) は折れ目のコントラスト、p_up は跨ぎの量。**

## 2. 変数（ここが設計の要）

**current-task の z̄ は使わない。** z̄ = b + w_flip·x_flip の第 2 項はタスクごとに入れ替わる射影で、標準偏差 ~0.45/タスクの揺らぎを持つ。これで条件付けると平均回帰が「力」に化ける（今日 1 度誤読している・[[vとwの成長_0907]] §8-3）。

各ユニット・各 seed・各腕・タスク k（窓 §3）について:

| 記号 | 定義 |
|---|---|
| z̄_k | タスク終端記録の前活性（step 10,000·k） |
| **N_k** | z̄_{k+1} − z̄_k（**1 タスクの正味の変位**・判定量） |
| W_k | 半幅 = 0.5·Σ&#124;w_free&#124;（step 10,000·k の記録） |
| **ζ_k** | **k を除く** j ∈ {k−4,…,k+4}\\{k} の z̄_j の平均（**leave-one-out の 8 タスク移動平均**） |
| **p̂_up(k)** | ζ_k と task k の w_free から作る 32 点 ζ_k + u_j のうち **> 0 の割合** |

**leave-one-out が肝**: ζ_k は task k 自身の揺らぎを含まないので、E[N_k | ζ_k] に平均回帰の汚染が入らない。p̂_up も ζ から作る（current z̄ から作らない）。

## 4. 判定（主判定 1 本・第 2 判定 1 本・どちらも効果量の床つき）

CI は **seed ブートストラップ 2000・`rng(20260907)`**。

### 主判定 `DRIFT_SHAPE` — p̂_up への依存の指数

腕ごとに p̂_up の**十分位ビン**を作り、各ビンで E[−N] とビン中央値 p̂_up を出す。**(1−a) で割ってから**腕をプールし、log E[−N/(1−a)] を log p̂_up に回帰した傾き **s**。

- **`PROPORTIONAL`**: s の CI ⊂ **[0.8, 1.2]**
- **`SUPERLINEAR`**: CI が全部 1.2 より上
- **`SUBLINEAR`**: CI が全部 0.8 より下で、かつ 0 を含まない
- **`NO_DEPENDENCE`**: CI が 0 を含む
- **`NOT_DETERMINED`**: 有効ビンが 5 未満／p̂_up 中央値の幅が **3 倍未満**／最上位ビンの E[−N] が **0.005/タスク 未満**（＝床）

### 第 2 判定 `A_COLLAPSE` — (1−a) で畳めるか

κ_arm ≡ E[−N] / [(1−a)·p̂_up] を腕ごとに（全ビンをプールして）出し、5 腕の **max/min**。

- **`COLLAPSE`**: max/min ≤ **2**
- **`RESIDUAL`**: max/min > 2
- **`NOT_DETERMINED`**: 有効な腕が 3 未満

### 補助（ラベルにしない・数値だけ出す）

1. **p̂_up = 0 のユニットは動くか**（跨ぎが無い群の E[N]）。bang-bang の主張の要。動くなら「跨ぎは沈下の必要条件」が崩れる。
2. 同じ回帰を **W で条件付けた層別**でも出す（幅が位置に従属＝1 次元に畳めるかの検査。ζ が同じで W が違うと drift が変わるなら 2 次元が要る）。
3. c=−0.5・full-batch・v 凍結の κ。
4. `BDref_1216` と `LRoff0_1216` の κ が一致すること（S-null の再確認）。

## 6. あらかじめの注意

1. **current-task の z̄ で条件付けない。** ζ は leave-one-out で作る。ここを外すと平均回帰が「力」に化ける。
2. **窓はタスク 10〜199 に固定**。定着後（末尾）を混ぜない。
3. 腕をまたぐ κ の比較は**同じ lr・同じ窓**のときだけ。
4. p̂_up は 32 点の離散量なので、値は 0, 1/32, 2/32, … に量子化される。ビンはその量子化を跨ぐように作る。
5. これは**事後解析**。ここで出るラベルは既存の走のラベルを一切上書きしない。
6. 「drift」はポテンシャルの勾配ではなく**タスク境界のストロボ写像の期待変位**。井戸・ばね・弁の語はこの spec では使わない。

## 8. 追補 1（実装前・結果を見る前に登録）

検査 `src/test_drift_law_0907.py` が §2 の ζ の定義の欠陥を捕まえたので、**走らせる前に**直す。

**欠陥**: ζ_k を「k **だけ**除く 8 タスク平均」にすると、N = z̄_{k+1} − z̄_k の**もう一方の端 z̄_{k+1} が ζ に 1/8 残る**。純粋な揺らぎだけの系（真の drift 0）でも Cov(N, ζ) > 0 になり、
  傾き ≈ Var(揺らぎ)/(2H) / Var(ζ) = (0.45²/8)/(1+0.45²/8) = **+0.0247**
の**正の**汚染が入る。実測される drift の傾きは 0.004/単位 程度なので、**汚染は信号の約 6 倍**。

（ついでに分かったこと: k を**含める**対称窓 [k−4, k+4] は、k の負の寄与と k+1 の正の寄与が打ち消して偶然 0 になる。だから「k を除けば安全」という直感は誤りで、**除く/含めるの二択ではなく「両端を除く」が正しい**。）

**訂正した定義**: **ζ_k = j ∈ {k−4,…,k+5} から k と k+1 を除いた 8 タスクの z̄_j の平均**。N の両端を両方とも除く。検査は 3 通り（両端を除く / k だけ除く / 両方含める）を人工データで分け、両端を除く版だけが傾き 0 になることを実測する。

**もう 1 つ、検査で分かった設計の性質**: 主判定 `DRIFT_SHAPE` の log–log の傾きは、**(1−a) で割っても割らなくても変わらない**（腕ごとの x 範囲が同じなら、腕ごとの定数倍は傾きに効かない）。したがって主判定は**形だけ**を測っており、(1−a) の当否は第 2 判定 `A_COLLAPSE` の側でしか効かない。§4 のラベル定義は変えない（この性質は解釈の注意として記録する）。
