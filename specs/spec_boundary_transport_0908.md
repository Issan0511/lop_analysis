# 初期20更新の局所勾配と実移動 再解析spec 0908
親: [[切替直後の勾配と実更新_結果_0908]] / 状態: 検証中 / 更新: 2026-09-08
事後再解析。先行の20更新の結果とIssaの指摘を見て起案。以下の追加測定・集計を実行前に固定し、主張の採否は変更しない。

## 1. 問い
「正側入力では局所勾配下降、負側では上昇」は実際の入力ごとの動きと一致するか。負側入力が下がるなら、同じユニットの正側入力に由来する勾配が共有W,bを介してどれだけ寄与するか。平均の下降と分散の拡大/縮小を分離する。
source-positiveは**同じユニットの正側標本**であり、他ユニットの因果効果とは呼ばない。自己項分解も行わない。

## 2. 対象
boundary_groups_0908の保存CPU状態から全4腕（SNA/LR×none/L2）、3seed、task101..119を各20更新再生。元CPUと毎更新のzbar完全一致を目標、許容2e-5。元CUDA軌道とは異なる。初期のW,b、Adam、Snake EMA、乱数と実ミニバッチを保持。CPU1thread、同時2プロセス以内、元GPUを触らない。
独立な追加学習実験ではなく同じ保存軌道の再計装。step0は置換後学習前。

## 3. 同じ学習入力に局所勾配と実移動を対応
各stepの16入力×100ユニットについてz_before、1標本lossの局所下降方向u=-B*dL/dz、実Delta z=Delta W*x+Delta bを保存。
現在CEだけを実Adam分母に通した実効Delta zを計算。更に現在ミニバッチ中の当該標本自身と他の15標本に分ける。当該標本分は
-lr*(1-beta1)/(1-beta1^T)*(dL/dz)_si*[sum_j x_sj^2/D_Wij + 1/D_bi]。
よって（roundoffを除き）当該標本分の符号は局所下降方向と一致する。他標本分は現在CE全体との差。
z<=0かつu>1e-8を分母として、(a)実Delta z<-1e-8、(b)現在CEのDelta z<-1e-8の割合を報告。前者にはAdam履歴、後者には現在の入力間結合だけが入る。各境界の窓内標本数で割合→19境界平均→3seed中央値と範囲。空分母NA、件数も保存。全標本の局所方向/実方向不一致率も補助記述。

## 4. 全20更新の勾配由来の加算分解
切替後の一次モーメントをm_pos,m_neg,m_L2へ分けて更新する。pos/negは勾配生成時の各標本のz>0/z<=0で、その時のW,b勾配に分割。切替前mをbeta1^t*m_boundaryで別保存。各更新の実分母を共用して
Delta theta = pos_source + neg_source + post_L2 + pre_boundary + rounding
を検算。pos/negには今回の勾配と切替後の過去の蓄積が含まれる。過去の源標本の符号を後から分類し直さない。切替前m内のCE/L2は分けない。分母の状態を固定した加算帳簿であり、正側を除去する/Adamをリセットする反実仮想ではない。
固定512test probeで受け手の入力ごとの寄与を計算。主集計はstep0でz>0/z<=0の受け手マスクを固定し、その同じ標本群の累積変位を1,5,10,20更新で報告。毎stepの受け手符号による集計は補助。D/Nの旧群分けは補助、入力正負と混同しない。

## 5. 分散は別に測る
固定probeの各ユニットの入力内分散Var_x(z_i)、ユニット平均の集団分散Var_i(zbar_i)、全標本・ユニットの総分散をstep0..20で記録。全分散=入力内分散のユニット平均+ユニット平均の分散を検算。
各stepについてDelta Var=2Cov(z,Delta z)+Var(Delta z)を入力内とユニット平均の両方で計測・検算。平均下降だけから幅を推測しない。初期比は境界ごとのafter/beforeを計算してからseed平均。before<1e-12はNA。

## 6. 窓・格・検算・保存
主は1..20。局所対実移動は1..5,6..10,11..15,16..20も報告。seedを独立単位に中央値と範囲を出し、CI/有意差判定や原因確定のラベルは付けない。
主判定は記述：局所上向きでも負へ動くか、正側標本源から負側受け手への更新寄与が下向きか、どの分散が増減するか。いずれも否定/混在を許す。
検算：同CPU zbar誤差<=2e-5、更新成分の実Delta z再構成誤差<=2e-5、正負勾配の和<=2e-6、分散恒等式誤差<=1e-9（double）。局所方向と当該標本だけの方向の一致を非零点で検算。最初stepの学習勾配が追加計装なしと一致することを全4腕seed0task101で検算。失敗は調査して記録し、都合の悪いseedを除外しない。
