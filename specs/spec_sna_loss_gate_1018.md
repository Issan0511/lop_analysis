# sna_loss_gate_1018 — CNN Snake の損失による尺度適応速度の制御

状態: 実装仕様。性能の本走・科学的判定は未実施。
依頼: Issa 2026-10-18「損失が高い間は尺度適応を遅くする、CNNで実装」。

## 規則（実装・検査の前に固定）

- 箱は既存 `sna_cnn_cause_1009` の RC CNN。ネット・Adam・乱数列・画像は宿主のまま。
- 腕 `SNA`, `SNAfrz1`, `SNA_lossgate`。c=.6、beta=.01、clip [.005,3]。
- 課題1は全腕とも通常SNA。課題1末固定は宿主のfreezeを用いる。
- 各runの課題1の最後10 epoch（短いsmokeでは全epoch）の、epoch内平均の
  ミニバッチ学習CE（更新前）を求め、その中央値を Lref として永久固定。
  偶数個の中央値は中央2値の平均。Lrefの下限 epsilon=1e-4。
- 課題2以降、各runの現在のミニバッチCE L（detach、更新前）から
  g=min(1,Lref/max(L,epsilon))、beta_eff=beta*g。
  全4サイトに同じgを適用し、V<-(1-beta_eff)V+beta_eff*var(z)。
  alpha=clip(c/sqrt(V))、関数形・振幅・微分は変更しない。
- Lrefはseed/腕間で共有しない。損失を改善するための教師情報の新規導入はなく、
  もともとの学習CEのみを使う。課題境界はLrefの初期校正に使う。
- 非有限損失はg=0かつbadフラグを立て、その状態を失敗として保存して停止。
  checkpointと設定の不一致・制御状態の欠落は拒否。

## 記録と検査

epochごとの平均CE、gの平均、最後のg、Lref、課題末の宿主統計（alpha、幅、
2alpha幅、座席、logit、切替直後CE）、全制御状態を保存する。
通常腕と校正前の学習が宿主とbit一致、損失高/低で式に一致、run間独立、
capture後の有効化、CUDA graph/eager一致、gate有効時の保存再開一致を検査。
短い実データsmokeは実装検証であり性能根拠にはしない。
