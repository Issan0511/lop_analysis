# l1_push_split_0915 —— 第 1 層の押し込みを、標本の 3 群（正側・帯・谷の奥）に割る

親: `spec_perm_dial_rl_0915.md`（結果 `b0f0bdd`）・`spec_relu_gelu_silu_rl_ext150_0914.md`（結果 `fca473d`）
動機（Issa・0915）:
- 「単調増加な活性化では、押し込みは正側からの『減らせ』が負側の抵抗を上回ることで起きる（マクロな話で、ミクロでは意外と上下に動いているのかも）」
- 「谷を越えた標本自身が、谷の手前の標本と逆に、負の移動を主張する。GELU は谷の前後の勾配が同じくらい急なので、谷を少し越えた瞬間に負側の抵抗が弱まる。同じような形なのに谷越えの挙動が変わるのはそのせいでは」

前回の Claude の答えは task 末のスナップショットだけに基づく（「谷の奥は弱すぎて平均を動かさず、沈む速さは正側に残った標本が決める」）。
これは同じ深さの中で正側の占有と速さが相関するというだけで、どの標本がどちらへ押したかは測っていない。

## 0. 問い

第 1 層ユニットの平均前活性 z̄ を動かしているのは、どの標本群か。
谷の奥（φ′ < 0）の標本は z̄ を下へ押すのか、上へ押すのか。
GELU が SiLU より速く谷の直下を通り抜けるのは、正側の押しの差か、負側の抵抗の差か。

## 1. 箱と腕

箱は `relu_gelu_silu_rl_ext150_0914`・`perm_dial_rl_0915` と同一（1200 枚固定・784-100-100-10・Adam lr 1e−3・batch 16・6000 更新/タスク・**150 タスク**・seed 0–2・両層同一活性化・float32・決定的）。

| 環境 | 入力 | ラベル | 活性化 | モデル数 |
|---|---|---|---|---|
| RL | 固定 | 毎タスク乱数 | LR・ELU1・R・GELU・SILU | 15 |
| PM | 毎タスク全置換 | 真 | LR・ELU1・R・GELU・SILU | 15 |
| K784 | 毎タスク全置換（ダイヤルの k=784） | 毎タスク乱数 | LR・ELU1・GELU・SILU | 12 |
| K107 | 毎タスク 107 画素置換 | 毎タスク乱数 | GELU・SILU | 6 |

計 **48 モデル**。乱数ストリームは親の走と同じ（`env_batch_0913`・`env_perm_0913`・`env_labels_0913`・`partial_perm_0915`）。
学習は変えない。計測は読むだけで、task 末の値は RL・PM が ext150、K784・K107 が perm_dial と bit 一致するはず（G1）。

## 2. 計測（第 1 層のみ）

ユニット i・更新 t・ミニバッチの標本 x について、z = W₁ᵢ·x + bᵢ、φ′(z)、u(x) = ∂L/∂a₁ᵢ(x)（バッチ平均損失に対する上流勾配）。

**3 群**は毎更新、その更新で使う z で分ける。

- **P（正側）**: z > 0
- **B（帯）**: z_c < z ≤ 0（GELU の z_c = −0.7518、SiLU は −1.2785）
- **V（谷の奥）**: z ≤ z_c
- 谷の無い LR・ELU1・R は名目上 z_c = −1 で分ける。本来の比較は P 対 B∪V。

**(a) バイアスへの力**: F_g = −Σ_{x∈g} φ′(z)·u(x)。上向きを正とする。
u > 0（「減らせ」）の標本の分 F_g^R と、u ≤ 0（「増やせ」）の分 F_g^I に分けて記録する。

**(b) z̄ を実際に動かした量（Adam を通した厳密な分解）**: z̄ᵢ = W₁ᵢ·μ + bᵢ（μ は今のタスクの 1200 枚の平均入力）。
Adam の一次モーメントは勾配に線形なので、各群の勾配だけを積んだ一次モーメント m_g を W と b の両方で並走させる。
D_g,t = −lr·[(m^W_g/c₁)/den^W · μ + (m^b_g/c₁)/den^b]。den は実際の Adam の分母 √(v/c₂) + ε をそのまま使う。
Σ_g D_g,t は実際の Δz̄_t に丸め誤差を除いて一致する（G0・G2 で検査）。
群が分母 √v を通して他の群の歩幅を縮める効果は分解に入らず、全群に共通の尺度として残る。

**(c) その他（ユニット・チャンクごと）**: 占有 n_g、実際の Δz̄ の和、総変動 TV = Σ_t |Δz̄_t|（ミクロの上下）、Σ_t den^b、チャンク末の z̄。
タスクごとに、入力の切替直後の z̄ も記録する（切替の跳び = 蹴り）。

**チャンク**: t1–10 は 200 更新ごと（30 チャンク/タスク）。t11–150 は各タスクを [0,100)・[100,300)・[300,1000)・[1000,3000)・[3000,6000) の 5 チャンクに割る。計 1000 チャンク。

## 3. 判定（登録）

対象は **RL の GELU と SiLU**。ユニット・チャンクをチャンク開始時の d = z̄ − z_c で分ける。
**帯** = d ∈ [−3, 0)。小区間は [−1,0)・[−2,−1)・[−3,−2)。
**率** r_g = 1000 × Σ D_g ÷ Σ 更新数（そのビンのユニット・チャンクをプール）。G2 の上界を超えたユニット・チャンクは集計から除き、数を併記する。

**Q1（谷の奥の向き）**: 活性化ごと・seed ごとに、帯全体をプールした r_V を求める。
3 seed とも負 → **`V_DOWN`**。3 seed とも正 → **`V_UP`**。それ以外 → **`V_MIXED`**。

**Q2（主な沈め役）**: 活性化ごと・seed ごとに、帯全体をプールして最も負の r_g を持つ群を選ぶ。
3 seed で一致 → **`SINK_BY_P`** / **`SINK_BY_B`** / **`SINK_BY_V`**。どの群の率も負でない seed がある、または不一致 → **`SINK_MIXED`**。

**Q3（GELU が速い理由）**: 3 seed をプールし、小区間ごとの r_P・r_B・r_V を 3 小区間で単純平均する（深さの構成の差を消すため）。
抵抗比 ρ = −(r_B + r_V)/r_P、正味 net = r_P(1 − ρ)。
- 前提: 両活性化で r_P < 0 かつ net < 0、かつ net^GELU < net^SiLU。満たさなければ **`Q3_NOT_APPLICABLE`**。
- L_push = ln(r_P^GELU / r_P^SiLU)、L_res = ln((1 − ρ^GELU)/(1 − ρ^SiLU))。和は ln(net^GELU/net^SiLU) > 0。
- L_res > L_push → **`GAP_FROM_RESISTANCE`**（負側の抵抗の差）。それ以外 → **`GAP_FROM_PUSH`**（正側の押しの差。共通の歩幅の差もここに入る）。

G1 が `BIT_IDENTICAL` でなければ、全判定に `(TRAJECTORY_DIFFERS)` を付ける。

## 4. ゲート

**G0（自己検査・学習前・失敗なら止める）**
- 親の selftest（φ・φ′・逆伝播と変異対照）。
- 計測の閉包（CPU・float64・5 活性化を 1 バッチ・重み 3 倍・途中で画素を置換して μ を変える）:
  |Σ_g D_g − Δz̄| ≤ 上界_D、|Σ_g (F_g^R + F_g^I) − Σ_t(−∂L/∂b)| ≤ 上界_F、Σ_g n_g = 更新数 × 16（完全一致）。GELU と SiLU で 3 群とも占有 > 0、かつ |D_V| が上界_D を超える（V が実際に検査される）。
- 上界は丸めの算術から作る（ε は dtype の機械イプシロン、n はチャンクの更新数、A_t = lr·(Σ_j μ_j Σ_g|m^W_g,j|/c₁/den^W_j + Σ_g|m^b_g|/c₁/den^b) + |Δz̄_t|）:
  上界_D = (2000 + 4n)·ε·Σ_t A_t + ε·Σ_t(Σ_j μ_j(|W_j^前| + |W_j^後|) + |b^前| + |b^後|)。
  2000 は 784 項の和（783ε）・16 標本の和と EMA の記憶（≈10 更新）の丸め（≈90ε）・実際の ΔW·μ の和（783ε）を切り上げた値、4n は 4 本の累積和の丸め、第 2 項はパラメタ更新の丸め。
  上界_F = (8n + 128)·ε·Σ_t Σ_x |∂L/∂b の各標本項|（6 本 + 2 本の累積和と 16 標本の和）。
- 変異対照（それぞれ閉包を壊すこと）: バイアス経路を落とす／c₁ を落とす／切替前の μ を使う／分母に更新前の v を使う／V の境界を 0.1 下げて隙間を作る／力の分解で V の φ′ を |φ′| にする。
- 学習不変（CPU・float32）: 計測ありとなしで 3 ブロック後の全パラメタが bit 一致。変異対照: 計測が g1 を in-place で書き換えると一致しない。

**G1（学習が同じか・診断）**: RL・PM は `fca473d` の ext150、K784・K107 は `b0f0bdd` の perm_dial と、150 タスク全部で照合する。
- 軌道の一致は、1200 枚を一度に通す評価の bmm を通らない量で判定する。パラメタから直接計算する per-unit の `cnorm_l1`（全 48 モデル）と、rows.csv の online_acc・train_ce がすべて完全一致なら `BIT_IDENTICAL`。
- z̄・zstd・ゲート平均などの評価統計は、評価の bmm のモデル数（30・48・75）で丸めが変わる。これらは max|Δ| を報告だけする。
- （0915 修正・群分解の値を見る前）当初は per-unit の全キーの一致で判定すると書いていた。スモーク 2 タスクで、cnorm_l1 と rows は完全一致だが評価統計は最大 9.5e−7 ずれた。旧 2 走どうし（ext150 の RL と perm_dial の k=0）でも同じキーが最大 6.1e−5 ずれていたので、判定から外した。
- 閉包の比（残差 ÷ 上界）は、上界も残差も 0（動きも質量も無いユニット）なら閉じているとみなす。

**G2（本走の閉包・診断）**: チャンクごとに |Σ_g D_g − Δz̄| ≤ 上界_D と |Σ_g F_g − Σ(−∂L/∂b)| ≤ 上界_F を調べ、超えたユニット・チャンク数を報告する。

## 5. 報告のみ

- 深さ d 別の 3 群の率（D と F、F の R/I 分割、占有、ρ）: RL・PM・K784・K107 × GELU・SiLU。LR・ELU1・R は z̄ 別に P と B∪V。
- 谷越えのタスク（RL の t2）の中の時間経過。
- 戻り（チャンク内で z̄ が z_c を下から上へ跨いだ）で上へ押した群: SiLU の RL、GELU・SiLU の PM・K784。
- ミクロ: TV/|net|、上向きの総量 ÷ 下向きの総量 = (TV + net)/(TV − net)。
- 蹴り: PM・K784・K107 のタスク境界の跳び（切替直後の z̄ − 前タスク末の z̄）と、タスク内の学習の和。
- K107 の SiLU が戻りにくい理由: 帯での群の率を RL と比べる。
- 同じ判定を D の代わりに F（Adam を通さない生の力）で計算した値。

## 6. 記名予測（走行前に固定）

- **Issa**（0915 のメッセージを Claude が読んだもの。本人の確認は無い）: Q1 **`V_DOWN`**（谷を越えた標本自身が負の移動を主張する）。Q3 **`GAP_FROM_RESISTANCE`**（GELU は谷を少し越えた瞬間に負側の抵抗が弱まる）。Q2 は言及なし。
- **Claude**:
  - Q1: GELU・SiLU とも **`V_DOWN`** 55%。「減らせ」圧が活性に比例する（u ∝ a）なら、谷の奥の標本は負の a を 0 へ戻すため z を −∞ 側へ押す。
  - Q2: GELU・SiLU とも **`SINK_BY_P`** 75%。
  - Q3: **`GAP_FROM_PUSH`** 55%。u ∝ a の単純模型（z をスナップショットの z̄・zstd の正規分布とする）では、帯の力は正側が約 50 倍大きく、ρ は −0.02〜0 で、抵抗の差では速さの差を作れない。
    ただし同じ模型は、同じ d で SiLU の生の力の方が大きい（正側の占有が大きい）と言い、観測（GELU が速い）と逆になる。模型のどこかが外れている。外れているのが u ∝ a なら、抵抗側の可能性が残る。
