## 0. 一行

G の µ̂ 整列のうち、**税（self 行）が担っている分**と**それ以外（rest 行）が担っている分**を分離し、整列が税の構造的副産物でないことを確かめる。

## 1. 目的数値の出所と scope（指摘①への回答）

論点マップ／整流モデル 部品1 の 2 数値は、**部品1 が明記している集計のもとで厳密に再現する**。

| 数値 | 部品1 の記載 | 再現（`results/ratchet_log_0819/logs/*.npz`） |
|---|---|---|
| \|cos(G, µ̂)\| = 0.966–0.995 | 「E[δ] 有意な 6 seed」 | **t=500k・\|E[δ]\| 上位 6 seed（1,2,3,4,5,9）で 0.9656–0.9945** ＝ 一致 |
| ‖E[δ]µ‖/‖Cov(δ,x)‖ = 3.7–9.6 | 「有意 seed で」 | 同 6 seed で **3.70–9.57** ＝ 一致 |
| 同 median 4.3 | 「median」 | **t=500k・全 10 seed の中央値 4.252** ＝ 一致 |

したがって「4.3 は `RESULTS.md:217`（A5 の方向分散比、w=5・centered）の転記ではないか」という推測は**否定される**。両者が 4.3 なのは偶然。centered が probe で拒否される点（`ratchet_log.py` L90）は事実だが本件には無関係。

**ただし指摘①には残る正しい部分がある。** 上の再現が示すとおり、2 数値は

- **単一時点（t=500k）**かつ **seed 部分集合**の値である（部品1 の留保に既に書かれているとおり）
- **全軌道で見ると値が違う**: \|cos(G,µ̂)\| の seed 中央値 0.947–0.973（プール p50 0.962）、`ratio_mu_cov` の seed 中央値 2.90–4.16（プール p50 3.45）
- **seed 間の散らばりが大きい**: t=500k の \|cos\| は seed 6 で 0.156、seed 7 で 0.748、seed 0 で 0.873。整列は \|E[δ]\| が有意な系列でのみ成立する

→ **本 spec も現論文も、この 2 数値には必ず「t=500k・E[δ] 有意 seed」を付けて引く。** 付けずに引いている箇所は直す。

### 2 数値は独立でない（新規・要注意）

r = ‖E[δ]µ‖/‖Cov(δ,x)‖ とおくと、Cov ⊥ µ のとき cos(G, µ̂) = r/√(1+r²) が従う。実測との差は **中央値 0.0022 / p90 0.070**。つまり **2 つの目玉数値は同一量の別座標**であり、独立な 2 つの証拠として並べてはいけない。現論文ではどちらか一方に統一する。

## 2. 何が既存ログから出るか（指摘⑤の採用・初版 §2 の全面訂正）

初版の「行と列は別対象なので掛け合わせられない」は**半分誤り**だった。probe の定義（`ratchet_log.py` L119–124）で a_i·gate_i = a_i なので

```
F_self,i = −2η·v_i²·(E[a_i·x]·µ̂)      ⇒  E[a_i·x]·µ̂ = −F_self,i / (2η·v_i²)
F_rest,i = −2η·v_i·(E[δ_rest,i·gate_i·x]·µ̂)
```

が恒等的に成立する。したがって:

| 量 | 既存ログから | 備考 |
|---|---|---|
| **self 行の µ̂ 射影**（= v_i·E[a_i·x]·µ̂） | **厳密に出る** = −F_self,i/(2η·v_i) | self はゲート不変 |
| **ゲート抜き rest 行の µ̂ 射影** | **厳密に出る** = G·µ̂ − 上記 | |
| ゲート版 rest 行 | 厳密に出る = −F_rest,i/(2η·v_i) | |
| **µ/Cov の列分割（4 セル化）** | **出ない**。新規に要るのは `E[a_i]` **ただ 1 つ** | → §8 保留 |
| ノルム系（`Sax_norm`・`Scov_norm`・`Scov_cosu`） | 出ない | 初版 P3/P5 用 → §8 保留 |

**防衛に必要なのは行レベルの帰属だけ**である。交絡の主張は「税と潮流が方向として縮退している」なので、**税 vs それ以外**が割れれば足りる。よって本 spec は再走を含まない。

## 3. 判定の統計量（指摘②・B の採用）

初版の「セル/(G·µ̂)」は使わない。`G·µ̂` は記録点の **48.7–52.2%** で符号が反転し、\|G·µ̂\| < 1e-3 が **1.0–11.6%** ある。ゼロを跨ぐ分母の比はモーメントを持たない。

改訂版で採った「‖G‖ で正規化」も、**主判定には使わない**。理由（指摘B、検算で確認）:

```
self 行の µ̂ 射影 = v_i · E[a_i·(x·µ̂)]      ← δ を含まない（ユニットの活性だけで決まる）
‖G‖ = ‖E[δx]‖                              ← フィット収束で 0 へ向かう
```

したがって **‖G‖ が小さい記録点ほど \|c_self\| が大きい**。P1 は c_self + c_rest = \|cos\| より実質「c_self < \|cos\|/2」の検定なので、下限ゲートで切ると**定義上 \|c_self\| が最大の集団だけが落ちる**＝ PASS 側へ偏る。除外率は層A 8.09% / 層B 10.29% とどちらの層にも同程度かかるので、層間比較では見えない。

### 3.1 主判定は ‖G‖ を含まない形にする

`c_rest > c_self` は両辺が同じ正数 ‖G‖ で割られているだけなので、**per-record の比較は正規化に依らない**:

```
c_rest,i > c_self,i   ⟺   σ·(rest 行の射影) > σ·(self 行の射影)      σ = sign(G·µ̂)
                      ⟺   σ·(G·µ̂) > 2·σ·(self 行の射影)
```

右辺には ‖G‖ が現れない。**主判定はこの対応比較の符号のみを使う**（下限ゲート不要）。

> **P1 の意味の言い換え（誤読防止）**: rest 行は G からの差で定義されるので独立な測定ではない。P1 は実質
> **「典型的な alive ユニットの自己寄与が G·µ̂ の半分未満か」**の検定である。alive が中央値 9 個しかない系で、
> 各 alive ユニットが出力の相当部分を担っている以上、これは自明に成立する命題ではない。

### 3.2 正規化版は頑健性としてのみ使う

解釈用（「0.96 のうち何割を誰が担ったか」）には ‖G‖ 正規化版

```
c_self,i = σ·(self 行の射影)/‖G‖ ,  c_rest,i = σ·(rest 行の射影)/‖G‖ ,  c_self,i + c_rest,i = |cos(G,µ̂)|
```

を使うが、**下限 floor ∈ {1e-3, 1e-2, 1e-1} の 3 点すべてで対応差の符号が保たれること**を事前登録の条件にする（指摘B の最小の直し）。保たれなければ P1 は「判定保留」へ落とす。追加コストはゼロ。

**Phase 0（器の健全性・実測済み）**

| 量 | 実測 | 事前登録するゲート |
|---|---|---|
| ‖G‖ | p50 = 0.380、< 1e-2 が **10.19%**、< 1e-3 が 4.52%、min 2.9e-8 | **主判定では使わない**。§3.2 の 3 点感度でのみ使用 |
| \|v_i\|（alive のみ） | p50 = 0.688、< 1e-2 が **0.67%** | **\|v_i\| ≥ 1e-2**（self 射影が −F_self/(2η·v_i) なので除算の増幅を回避）。主判定でも適用 |
| alive 数（p̂ ≥ 0.05） | p50 = 9、≤5 が 33.4%、**= 0 が 1.65%** | alive = 0 の記録点は除外 |

除外率は `verdict.csv` に必ず記載する。

## 4. 層別（必須・指摘A を反映）

既存の記録グリッドは **95.7% が境界窓**。層別せずに 1 つの中央値へ潰すと、答えているのは境界窓の問いだけになる。

- **層A: バルク点**（`step % 1000 == 0` かつ境界窓外）… **主判定はここ**
- **層B: 境界窓**（境界 ±100）
- **層C: seed 単位の固定集合** … §1 の scope の再現。t=500k の \|E[δ]\| 上位 6 seed **{1,2,3,4,5,9}** と、残り 4 seed **{0,6,7,8}**

> **改訂版の層C（`ratio_mu_cov > 1`）は撤回**（指摘A）。§1 が cos = r/√(1+r²) を示した以上、`ratio > 1` は
> \|cos(G,µ̂)\| > 0.7071 と同値であり（実測の一致率 **0.9775**）、§3 の恒等式 c_self + c_rest = \|cos(G,µ̂)\| により
> **分解しようとしている量の和そのもので条件付ける**ことになる。加えて §1 の scope も切り出せていない
> （t=500k で `ratio>1` は 9 seed {0,1,2,3,4,5,7,8,9} であり §1 の 6 seed と一致しない。全記録点では 83/17 の偏った分割）。
> 差し替えた層C は **seed 単位で事前に固定**され、記録点ごとの outcome では条件付けない。

フィット段階での違いは、**判定なしの診断**として `eval_loss_exact` の seed 内四分位別に併記する（regime を見るためであり、条件付き判定はしない）。層間で結論が割れたら「判定保留」とし、割れ方を報告する。

## 5. 判定基準（事前登録・commit 前に固定）

**集計順序を明記する**（指摘・軽微1）: 記録点 × alive ユニットごとに対応量を作り → **run 単位で中央値** → seed bootstrap（B=10000、`np.random.default_rng(20260821)`）。
`c_rest,i − c_self,i = |cos|_i − 2·c_self,i` なので `median(c_rest − c_self)` と `median(c_rest) − median(c_self)` は一致しない。**前者（記録点ごとの差を先に取る）を採る。**

10 seed の中央値ブートストラップは順序統計量に載って階段状になるので、**対応差が正だった seed の数（符号検定）を必ず併記する**（10/10 なら p≈0.001、9/10 で p≈0.011）。

| ID | 予測 | 統計量 | 基準 |
|---|---|---|---|
| **P0** | 前提ゲート | §9 の S1–S4 | 全 PASS。FAIL なら中止 |
| **P1** | **主判定**: µ̂ 整列は税の副産物ではない | §3.1 の対応比較。run ごとに σ·(rest 射影) > σ·(self 射影) となる (記録点 × alive) の割合 → seed 中央値 | seed 中央値 > 0.5 **かつ** 対応差の bootstrap CI 下端 > 0 **かつ** 符号数 ≥ 9/10 で **PASS** → 目玉数値は §1 の scope 付きで現行の読みのまま引ける。**FAIL なら §6 の限定文を書く** |
| **P1b** | 頑健性（事前登録） | §3.2 の正規化版の対応差を floor ∈ {1e-3, 1e-2, 1e-1} で | 3 点すべてで符号が一致。**一致しなければ P1 を「判定保留」へ落とす** |
| **P2** | ゲート版でも同じ | −F_rest/(2ηv) と −F_self/(2ηv) で §3.1 と同じ比較 | P1 と同基準。P1・P2 が割れたら両方「判定保留」とし、ゲートの効果として別項目で報告 |

| **P4** | 中和との整合（報告のみ） | 総寄与シェア \|self\|/(\|self\| + \|rest\|)（有界・‖G‖ 非依存） | 判定なし。**シェアを主判定にしない**（Q2b が示すとおり「大きく寄与して正味ゼロ」は両立するため） |

## 6. P1 FAIL のときの処置（先に決めておく）

**新規アームは起案しない。** condA の中では µ 列の 2 セルは定義上コリニアで、self 行は非負性で µ̂ に張り付くため、原理的にこれ以上分離できない。異方 Σ は 8/21 の線引きの外。

処置は現論文への限定文の追加のみとする。文案:

> condA は入力が非負であるため、自己項（税）と潮流は方向として縮退する。\|cos(G, µ̂)\| は両者の和を測っており、潮流が輸送を担っていることの証拠としては読めない。

**この限定文の前半（方向の縮退が構造由来であること）は、P1 の結果によらず既に正当化されている** → §7。

## 7. 確定事項（再走不要・判定から外す）

初版の P4「縮退は構造由来か」は **t=0（ランダム初期化・学習ゼロ）で決着している**。`kaiming_mlp_params` の分布から独立に再現した結果:

| 量 | t=0 実測（独立再現） | 初版の閾値 | 帰趨 |
|---|---|---|---|
| cos(E[a_i·x], µ̂) | min 0.898 / **中央値 0.989** / > 0.9 が 99.9% | 「t=0 で > 0.9」 | **満たす → 構造由来で確定** |
| cos(Cov(a_i,x), ŵ_i) | 中央値 **0.496** | 「> 0.5 で支持」 | **閾値が null と同値 → 指標として無効** |
| ‖Cov‖/‖E[a·x]‖ | 中央値 **0.151** | 「< 0.1」 | 閾値近傍 → 同上 |

「t=0 で低く学習で上がる → 交絡の懸念が弱まる」という初版の分岐は**起こり得ない**。学習前から成立している以上、これは非負入力が強制する構造である。
