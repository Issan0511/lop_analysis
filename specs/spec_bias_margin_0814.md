## 0. 一行

ゲート margin を動かすノブは µ だけではなく **b** もある。b は入力中心化で消えないので、µ=0 でも Path A（dead unit）を走らせられるはずだ、という仮説の判定。

---

## 1. 理論（判定の前提。導出は手検算前）

学習器のゲートは `1{wᵀx + b > 0}`。ガウス入力なら発火確率は

    p_i = Φ(β_i),   β_i = (w_iᵀµ + b_i) / √(w_iᵀΣ w_i)

**条件B・c=0・κ=1 では µ=0, Σ=I なので β_i = b_i/‖w_i‖ ちょうど。** 本実験の主変数はこの1スカラー。

### T1（定理）µ=0 かつ b≡0 では死は不可能

中心化ガウスで b=0 なら wᵀx ~ N(0, ‖w‖²) が原点対称。w をどう動かしても p ≡ 1/2。
→ `center_selfcov_0814` アーム3 の dead=0.00 は null 結果ではなく**必然**。設計ジレンマの正体は「β のノブを µ 一本と誤認したまま、その一本を抜いていた」こと。

### T2（恒等式）b のドリフトは中心化をすり抜ける

実装の勾配は `g_b = 2δ·v·1`（`src/nets.py`）。w と同型に分解できて

    E[δ·1_i] = E[δ]·p_i + Cov(δ, 1_i)

w の式 `E[δx] = E[δ]µ + Cov(δ,x)` で µ が座っていた席に、b の式では **p_i = E[1_i]** が座る。µ は中心化で 0 にできるが p_i は生きている限り正。

### T3（導出）自己項は無条件に b を下へ押す

δ に自分の寄与 v_iσ_i が入るため Cov(δ,1_i) の自己成分は v_i·E[σ_i](1−p_i) ≥ 0、b への寄与は

    −2η · v_i² · E[σ_i] · (1 − p_i)  ≤ 0

**v_i の符号にも µ にも依存しない下向きの力。** C_self の b 空間版。(1−p_i) 因子により p→1 側では消えるので、同じ式から dead(p→0) と linearized(p→1) の二峰が出る。

### T4（導出）ただし平衡では相殺する ＝ 死の必要条件

各タスクの最適点では ∂L/∂b_i = 2E[δ1_i] = 0 なので T3 の力は打ち消される。**b が沈むには「フィットし切れない残差の持続」が必要。** 本実験がこれを2経路で与える（§3）。

### T5（導出）β は真の吸収境界

b の勾配もそのノイズも因子 1_i を持つため、p→0 で**ドリフトと拡散が同時に消える**。w 空間の錐条件と違い1次元で閉じた吸収過程になる。復活率ゼロが厳密に予測される（PB-5）。

## 2. 実装変更（3点）

いずれも **既定値で既存 run と bit 一致**すること（S1）。

### 2.1 `condB.target_noise_sd`（既定 `0.0`）

学習ループの教師出力にのみ加法ノイズを乗せる：

```python
# src/train.py 学習ループ、y = teacher(x_raw) の直後
if noise_sd > 0:
    y = y + noise_sd * torch.randn(y.shape, generator=gens["noise"], device=device)
```

**必須要件**
- 専用ジェネレータ `gens["noise"]` を新設する。既存ストリームを消費しないこと
- `noise_sd == 0` のときはサンプリング自体をスキップする（bit 一致の担保）
- **`eval_batch()` には絶対に加えない。** eval は clean teacher に対する誤差でなければ LoP 判定が不可能になる（ノイズ込みだと eval_loss の床が σ² だけ持ち上がり、「悪化」と「既約ノイズ」が分離できない）

### 2.2 `condB.freeze_bias` / `condA.freeze_bias`（既定 `false`）

`true` のとき b を初期値 0 に固定する。`VecMLP.sgd_step` で `gb` をゼロ化する実装が最も安全（勾配計算自体は残し、更新だけ止める）。乱数消費は不変。

### 2.3 `lop_metrics.py` に b 系カラムを追加

`lop_every` ごと。全てコスト無視できる。

| カラム | 定義 |
|---|---|
| `b_mean_alive` / `b_mean_dead` | alive / dead ユニットの b 平均。dead が無ければ NaN |
| `b_std` | 全ユニットの b の標準偏差（**拡散とドリフトの分離用、PB-3 の主材料**） |
| `b_min` | 最小 b |
| `beta_mean` / `beta_p10` / `beta_min` | β_i = (w_iᵀµ + b_i)/√(w_iᵀΣw_i) の alive 平均・10%点・最小。µ, Σ は**解析値**（条件B）。条件A は eval バッチからの経験推定 |
| `p_min` / `p_mean` | 経験発火率（既存 `open_frac` を流用）の最小・平均 |
| `dead_b_dominant_frac` | dead ユニットのうち、負性を b が担っているものの割合。条件B・µ=0 では定義上ほぼ 1 になるので**主に条件A（Phase 0）用の指標** |
| `dead_persist_frac` | 直前の lop step で dead だったユニットのうち、今も dead な割合（PB-5） |

## 4. 事前登録予測と判定基準

判定は seed 間 bootstrap (n=2000) の 95%CI。

### PB-1（対照 ＝ 実装検証を兼ねる）
`freeze_bias=true` の全セルで dead_frac = 0.000（全 checkpoint）。
→ T1 より数学的に保証される。**ゼロでなければ発見ではなくバグ**。この扱いを summary に明記すること。

### PB-2（主判定）
`freeze_bias=false` かつ残差経路を入れたセルで、dead_frac 最終値の CI 下端 > 0。
**反証**: dead_frac が全セルでゼロのまま。→ b 経路は棄却、次手2の探索は別の場所へ。

### PB-3（機構：ドリフトか拡散か）
dead が出たセルで
- (a) `b_mean_alive` の傾き CI が**ゼロ未満**（系統的沈降＝ドリフト）
- (b) |b_mean| が `b_std` を**上回る**区間が存在（単なるランダムウォークではない）

**反証**: b_mean ≈ 0 のまま b_std だけ増大 → 死は b の拡散によるものであり T3 の自己項ドリフトは支持されない。この場合「Path A は µ=0 下では拡散駆動」と報告する（これも報告価値のある結果）。

### PB-4（用量反応）
dead_frac が残差強度（σ_ξ もしくは 1/K）に対して単調増加。

### PB-5（吸収性 ＝ T5 の直接検証）
`dead_persist_frac` = 1.000（復活ゼロ）が全区間で成立。
→ 成立すれば **w 空間の「実質的な凍結」より強い、厳密な吸収の実証**になる。
**反証**: 復活が観測される → §1 T5 の「拡散も同時に消える」が破れている。実装（dead 判定の tol）を疑ってから理論を疑うこと。

### PB-6（ラベルノイズ非依存性 ＝ 位置づけの要）
経路2（K 短縮＝タスク切替がフィットより速い）でも PB-2 が成立する。
→ 成立すれば「人工ラベルノイズ専用の現象」ではなく継続学習の設定に接続する。**不成立なら、この機構の論文上の価値は大きく下がる**（§6 参照）。

### PB-7（LoP 症状との接続）
dead が出たセルで clean-teacher eval_loss が上昇する。
**反証**: dead だけ増えて eval が悪化しない → 「予算アーティファクト」（幅が余っているだけ）の疑い。dead_frac と eval_loss の対応を図で示すこと。

## 6. 主張してはいけないこと（事前に固定）

過去に adjacent-pair chaining と過大主張で2度躓いているので明示する。

1. **b 経路が既存の LoP 結果を説明するとは言えない。** Phase 0 のとおり µ≠0 の条件A では死は µ 経路が支配（b 主導は 5.3%）。本実験が示すのは「**欠けていたレジームへの到達手段**」であって既存現象の再解釈ではない
2. **「µ は不要」とは言えない。** 示せるのは「β を動かす別のノブがある」までで、実際の継続学習で b 経路が支配的だという主張には別の証拠が要る
3. **PB-6 が落ちた場合の位置づけリスク**: 「フィット不能な残差」を人工ラベルノイズでしか作れないなら、それは破棄した v1 の外生誤差モデル（e ⊥ x）と実質同じ設定に戻ることを意味する。この場合は正直に「機構としては成立するが継続学習設定への接続は未確立」と書くこと
4. §1 の T2–T5 は**単一パスの導出のみで手検算前**。外部資料に出す前に再導出すること（task_080 と同じ扱い）

## 8. スコープ外（「後で考えるリスト」行き）

- 条件A での b 介入（b 凍結して µ 経路だけの死を測る）→ Phase 0 の分解で必要性を判断してから
- κ>1 との組み合わせ（Path A と Path B の結合）→ 本実験は Path A 単独に絞る

- ノルム固定アーム（β = b/‖w‖ の分母側の統制）
- b を持つ層が複数ある場合の層間伝播

## 9. 先生への確認事項（返信に載せる候補）

1. **理論ノートは σ(wᵀx) と書いて b を落としているが、実装（および Dohare 準拠の標準的な MLP）には b が常にある。** 統一 SDE に b を明示的に入れるか確認したい。入れる利点は、Path A が β = (wᵀµ+b)/‖w‖_Σ という**1次元の真の吸収過程**として閉じること（ドリフトも拡散も p→0 で同時に消える）
2. **先行研究**: Cornacchia et al. 2021 (arXiv:2111.02154) が µ=0 ガウス＋純ラベルノイズで「bias 無し→死ねない／bias 有り→b の単調負ドリフトで全ユニット死」を示している。b と LoP を結ぶ既知の唯一の論文で、引用と差分の明示が要る（先方は分類・p=1 極限のみ、継続学習ではない）
