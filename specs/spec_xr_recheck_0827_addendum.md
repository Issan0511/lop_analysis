## 1. A2 / A5 / A6 の母集団（最重要）

### 1.1 穴

親 spec §5 A2-a は「符号比 49.7 : 50.1 が ±0.5pt で再現」を repro 対象に挙げているが、
**その符号比がどのペア集合の上で計算されたかを書いていない**。§4 の定義表にあるのは
「非境界ペア = 境界ペア以外の隣接記録ペア」だけである。

この母集団では判定が必ず壊れる。非境界ペアは全体で 2,080 万件あり、その約 79% は
`p̂ = 0`（消灯）のユニットのペアで、A1 が示すとおり **Δx が厳密に 0** である。
したがって「非境界ペア」で符号比を取ると `Δx = 0` が 8 割を占め、`p₊` は 0.497 ではなく
0.1 未満の別物になる。A2-a は**定義の食い違いだけで FAIL する**。

### 1.2 復元

[[xr分解と生存機構_0822]] §19 に母集団が書いてある:

> タスク内・**発火中**限定・Δstep=1000、n = 149,492

したがって A2 の母集団は以下で確定する。**A5・A6 も同じ母集団を使う**（A5 の
`median|Δx|` はゲートを外すと全窓で 0 になり、相関が定義できない）。

| 条件 | 内容 |
|---|---|
| 境界 | 非境界ペアのみ（`flip_state` の差分で判定。ハードコードしない） |
| 粒度 | **`Δstep == 1000` のみ**（境界窓内の 1 step ペアは除く） |
| ゲート | **ペア始点で `p̂ > 0`**（発火中。§3 の母集団） |

**`p̂ > 0` は閾値ではなく離散の非ゼロである。** `p̂` は 32 パターン上の割合なので
`1/32 = 0.03125` 刻みであり、`p̂ > 0` ⟺ `p̂ >= 1/32` ⟺ 「1 パターン以上で発火する」。
`p̂ >= 0.05`（= `TAU`、k >= 2）とは**別物**で、母集団が 30,446 件ずれる。

```
Δstep=1000・タスク内ペアの母集団サイズ（10 seed）
  p̂ > 0        149,492   ← §19 の n=149,492 と厳密一致
  p̂ >= 0.05    119,046   ← 30,446 ずれる
  全体          801,000
```

実装では `--pair-population on_bulk`（既定）。`alive_bulk` / `any_bulk` / `on_all` /
`any_all` は逸脱確認用で、**既定値のみが判定に使う正**である。

### 1.3 S6（母集団定義の加法恒等式・ゼロ許容）

上の分割は加法的に閉じる。

```
801,000（Δstep=1000・タスク内 全ペア）
  = 149,492（始点 p̂>0  → §19/§3 の母集団）
  + 651,508（始点 p̂=0  → §14 の「1000 step ペア、復活 0」）
```

右辺の 2 項は vault が**別々の文脈で報告している値**であり、加法的に一致することが
母集団定義の検算になる。**S6 として置き、ゼロ許容（1 件でも外れたら中止）とする。**

### 1.4 A1 の母集団は変えない

A1-a の目標値 16,475,293 は **Δstep を問わない全非境界ペア**の集計である
（Δstep=1000 に絞ると seed あたり 1000 ペア程度にしかならず 2 桁合わない）。
親 spec §4 の字義どおりでよい。A2 と A1 で母集団が違うことをここで明示する。

## 2. A2-b の分母

「+µ 側訪問率 94.9%」の分母は**ユニット 1000 本**（10 seed × 100 unit）であり、
ペアではない。[[xr分解と生存機構_0822]] §19「生涯の最高到達点」表の

> `x_max > 0` … 0.9490（10 seed × 100 unit、記録点ベース）

を正とする。`x_max` は各ユニットの全記録点にわたる `x` の最大値。

## 3. A2-d の定義

親 spec の「終端（最終記録点）での復活数 = 0」を、
**最終隣接ペア `(n-2, n-1)` で `p̂ = 0` から `p̂ > 0` になったユニット数**と読む。
10 seed 合算で 0 であれば PASS。

## 4. A5 の窓ごとの残差

窓（タスク）は `task_id(step) = (step − 1) // T`（`step = 0` は task 0）で切る。
境界 B の flip は記録点 B と B+1 の**間**で起きるため、`step // T` を使うと境界ペアが
タスク内に混入する（[[xr分解と生存機構_0822]] §18 で自己検出されたバグ。親 spec §4 の
「`step[s] // T` は使わない」はこれを指す）。

窓の残差は **窓内記録点の `eval_loss_exact` の平均**（実装の `loss_mean`）。
`--a5-loss-agg loss_first`（窓頭の値）は逸脱確認用。

## 5. bootstrap の変種 — 推定量は項目ごとに分ける

親 spec §7 の「seed クラスタ（seed をリサンプルし、ユニットはプール）」には 2 つの読みが
あり、seed ごとのペア数が違うため一致しない。

| 版 | 手続き |
|---|---|
| **pooled** | seed を復元抽出し、選ばれた seed の**分子・分母を合算してから比を作り直す** |
| **mean** | seed ごとの値を作ってから平均（`figures_ratchet_log.boot_ci` と同じ） |

**どちらか一方に決めるのではなく、項目ごとに割り当てる。**

| ID | 推定量 | 理由 |
|---|---|---|
| A2-a（repro） | **pooled** | 旧値 0.4971 / 0.5008 が pooled。**同じ推定量でなければ再現の検定にならない** |
| A2-c（prereg・主判定） | **mean** | seed が独立実現＝推論の単位。pooled は「発火中ユニット数」というノイズ変数で seed を重み付けてしまう |
| A4-b（prereg・判定なし） | mean を主に置き pooled を併記 | 同上（推論の単位は seed） |
| A2-c'（report） | 両者の乖離 `pooled − mean` | 必ず出す。大きければ「seed 間で対称性が揃っていない」という別の所見 |

`B = 10000` ではなく親 spec §7 の **`B = 20000`**、`default_rng(20260827)`。

比ではない量（A3-a の符号付き cos、A5-a の ρ）は seed ごとの値しか無いので mean 版のみ。

この割り当ては**実データを一度も走らせずに固定した**（合成データでの不均衡デモにより
両者が食い違いうることだけを確認した）。実データでの乖離幅は結果として出るものであり、
それを見てから推定量を選び直すことはしない。

## 6. A4 の実装

親 spec A4-a は「`analysis/q3_boundary_race.py` をそのまま実行」だが、`OUTDIR` が
`~/q3_out/race`（リポジトリ外）に固定されており、CLI で差し替えられない。本走では

  `results/xr_recheck_0827/verdict.csv` とする

## 7. A3 の生死判定と eff_rank

- **alive/dead は snapshot 自身から再計算する。** `A_w100_cont_step500000.pt` には
  `p_hat` が保存されていないため、`net/W`・`net/b`・`env/flip_state` と condA の入力
  サポート 32 パターン（自由 5 bit ∈ {0,1}）から `p̂ = mean(pre > 0)` を厳密に作り、
  **`alive = p̂ > 0`** とする（§1 と同じ「発火中」のゲート）。式は
  `src/ratchet_log.py` の `exact_record` と同一（std なので centering 補正なし）。
  **logs 側の `p̂` は使わない**（S5）

### 7.1 S0 に追加する前提ゲート（ゼロ許容・外れたら中止）

[[xr分解と生存機構_0822]] §9 の閉形式

```
dead(flip) ⟺ flip·w[1:15] + b + Σ_{j∈rnd} max(w_j, 0) ≤ 0
```

を計算し、(i) 32 パターン列挙の `max(pre)` と一致すること、(ii) 総数が

```
alive (p̂ > 0) = 120     dead (p̂ = 0) = 880
```

であることを確認する。§7 の seed あたり平均 12.0 / 88.0、§17 の n=120 / 880 と一致する
はずの値である。**外れたら A3 の母集団定義が違うので中止する。**

> 実装後に S0 を単体で実行して確認済み（2026-08-27）: 閉形式と列挙の
> `max abs err = 0.000e+00`、alive 120 / dead 880 で一致。**なお `p̂ >= 0.05` で切ると
> 85 にしかならず、A3 でも `p̂ > 0` が正しいゲートであることが裏付けられた。**
> これは母集団の同定であって A3 の統計量ではない（ペア cos も eff_rank も未計算）。
- ペア cos は重み行ベクトル `W[r, i, :]` の正規化内積。群内の全ペア `i < j` の
  符号付き平均が A3-a、`|cos|` の平均は report
- `eff_rank` は `src/lop_metrics.py` と同式 `exp(−Σ p log p), p = s/Σs`。
  **活性側**は 32 パターンの `relu(pre)` を群の列に絞った行列、**重み側**は `W` を群の行に
  絞った行列の特異値。いずれも A3-c（report・判定なし）

## 8. 親 spec §2.3 の前提の訂正

親 spec §2.3 は

> 8/22 の §7 が n=12・1 seed だったのは seed 0 しか見ていなかったためで、標本は 10 seed 分ある

と書いているが、[[xr分解と生存機構_0822]] §7 は見出しに「10 seed」と明記しており、表の
**12.0 / 88.0 / 100.0 は seed あたりの平均本数**である（ランダム基準の CI が alive 側だけ
広いのも本数 12 対 88 と整合する）。したがって §7 は最初から 10 seed で、
**「1 seed だった」という前提は誤り**である。

10 seed で回して seed クラスタ CI を付けるという**方針は変わらない**（§7 には CI が無く、
A3-a はそこを埋めるのが目的なので、prereg tier の成立も変わらない）。訂正するのは
理由の記述だけである。

## 9. A1-d を prereg から **repro** に格下げする

親 spec は A1-d を prereg・対照（報告）として置いているが、[[命題リスト]] Q3 と
[[研究索引]] に

> 対照の境界ペアは 80,753 件中 **9,318 件（11.54%）** が復活

が記録されている。そして**親 spec の執筆時に [[xr分解と生存機構_0822]] §14 を読んで
おり、11.54% が文脈に入っていた**。

**見た数値を prereg と名乗ることはできない。** 格を落とす。

```
A1-d  tier: repro
      基準: 境界・off_prev ペア 80,753 件、復活 9,318 件（11.54%）に厳密一致
```

格は落ちるが、判定は**厳密一致**になるので検定としては強くなる。実装が `flip_state`
差分から独立に導く境界ペア数と §14 の 80,753 が一致する見込みは高い。
