## 0. 一行

per-unit の self/rest 帰属を捨て、G を **学習器の出力項 G_out** と **教師項 G_teach** に全体レベルで割り、\|cos(G, µ̂)\| をどちらが担っているかを符号ランダム化 null 付きで測る。

## 1. 本体 P1 がなぜ無効か（Q2 の系）

本体 P1 は「σ·(rest 行の射影) > σ·(self 行の射影) となる割合」を主判定にした。これは**測るべきものを測っていない**。

1. **Q2（定理）**: condA で F_self,i ≤ 0 が点毎に成立（[[自己項の恒等式]]。実測でも全 10 seed × 全記録点で成立）
2. self 行の射影 = −F_self,i/(2η·v_i) ⟹ **sign(self 射影) = sign(v_i)**
3. よって σ·(self 射影) = sign(σ·v_i)·\|self 射影\| であり、**v_i の符号が σ と逆のユニットは無条件に「勝つ」**
4. v の符号はユニット間でほぼ対称（層A・alive・\|v\|≥1e-2 で正の割合 **0.502**）。これは「v 符号二極説は棄却（sign(v) と極の一致率 0.527）」として既知

したがって signal がゼロでも勝率は 0.5 を超える。符号ランダム化 null の期待勝率は解析的に

```
E[勝率] = 0.5 + 0.5·P( 2|self 射影| < |G·µ̂| )
```

**実測（本体の走行および独立再計算）**

| 量 | 値 |
|---|---|
| 層A 勝率 | 0.5896–0.5911（seed 幅 0.570–0.608） |
| 上式の null | 0.5907–0.5929 |
| 観測 − null | −0.0011 〜 −0.0027（CI がゼロを含む） |
| 観測 > null の seed 数 | **4/10** |

**P2 も同じ理由で無効**（self はゲート不変 a·gate = a なので、ゲート版でも符号の釘付けは変わらない）。**P1b の 3 点一致も無効を救わない**（間違った量を頑健に測っただけ）。

> **教訓（[[論点マップ]] §9 に追加すべき項目）**: 指標が測定対象の一部で恒真になっていないかの事前確認（8/19b 教訓②）は、
> **「定理から符号が決まっている量を、符号比較の指標に入れない」**という形でも適用される。
> 材料（Q2 の定理・v 符号の対称性）は両方とも台帳にあったのに、指標設計時に接続されなかった。

## 2. 何が壊れていたのか（設計上の診断）

G は**全ユニット共通の 1 本のベクトル**である。それをユニットごとに self_i + rest_i へ割ると、

- rest_i は G からの差で定義されるので**独立な測定ではない**
- self_i の符号は Q2 により v_i に釘付けされる

の二重の理由で、母集団統計が v の符号対称性へ潰れる。**per-unit の行帰属は原理的にこの問いに答えられない。**

一方、縮退の懸念（`blindspot_0820` §3）が実際に指しているのは「非負性のせいで E[a_j·x] が µ̂ に張り付く」という**集合的な**事実であり、これは全体レベルで書ける。

## 3. amended 指標: 全体レベルの分割

δ = Σ_j v_j·a_j + c − y より、恒等的に

```
G = E[δx] = Σ_j v_j·E[a_j·x]  +  ( c·µ − E[y·x] )
            └──── G_out ────┘     └─── G_teach ───┘
```

- **G_out**（学習器の出力項）: 各項 v_j·E[a_j·x] は「非負象限 × sign(v_j)」。**縮退の懸念が指している集合そのもの**。v の符号は和の内部にあるので、外から釘付けされない
- **G_teach**（教師項）: µ̂ 方向性は非負性から強制されない。課題の性質

### 既存ログからの計算（厳密）

probe の定義（`ratchet_log.py` L119–124）で a_j·gate_j = a_j なので F_self,j = −2η·v_j²·(E[a_j·x]·µ̂)。よって

```
G_out·µ̂   = Σ_j v_j·(E[a_j·x]·µ̂) = −(1/2η)·Σ_j F_self,j / v_j        （j は全 100 ユニット）
G_teach·µ̂ = G·µ̂ − G_out·µ̂
```

**\|v\| の下限ゲートは不要**（本体 §3 との違い）: F_self,j ∝ v_j² なので F_self,j/v_j ∝ v_j → 0 で発散しない。dead ユニットは a_j = 0 より F_self,j = 0 で厳密に寄与ゼロ。（実測: `v` に厳密ゼロは 0 個、min\|v\| = 6.53e-7。`p̂=0` の 16,556,972 要素すべてで F_self が厳密に 0。）

正規化版（解釈用）は本体と同じく σ = sign(G·µ̂) と ‖G‖ を使い、

```
k_out = σ·(G_out·µ̂)/‖G‖ ,  k_teach = σ·(G_teach·µ̂)/‖G‖ ,  k_out + k_teach = |cos(G, µ̂)|
```

**主判定は ‖G‖ を含まない形**（σ·G_out·µ̂ と σ·G_teach·µ̂ の直接比較）にする。理由は本体 §3 と同じ（‖G‖ はフィット収束でゼロへ向かい、分子は δ 非依存な項を含むため、下限ゲートが片側に効く）。

## 4. null（**事前に固定する** — 同じ失敗を三度繰り返さないため）

**符号ランダム化 null**: 各記録点で \|v_j\| と E[a_j·x]·µ̂（= −F_self,j/(2η·v_j²)、いずれも非負）を保ったまま、**v_j の符号を i.i.d. ±1 で引き直して** G_out·µ̂ を作り直す。G_teach·µ̂ は G·µ̂ − G_out^null·µ̂ として整合的に再計算する。

- 壊れるのは「v の符号と活性の大きさの対応」だけで、大きさの分布・ユニット数・µ̂・‖µ‖ は保たれる
- 置換回数 1000、`np.random.default_rng(20260821)`
- **σ = sign(G·µ̂) は null の下でも固定**（修正2）。G·µ̂ を観測値に固定する設計なので σ は変化しない。
  b_j := v_j·(E[a_j·x]·µ̂) と置くと \|b_j\| = \|v_j\|·(E[a_j·x]·µ̂) で、null は G_out^null·µ̂ = Σ_j ε_j·\|b_j\|。
  したがって E[σ·G_out^null·µ̂] = 0、**null の統計量の期待値は −\|G·µ̂\|** になる

**この null を置く理由**: G_out·µ̂ = Σ_j v_j·A_j（A_j ≥ 0）は、v の符号が揃っていれば大きく、対称なら √N のスケールに縮む。null がないと「和が大きい」を「協調がある」と読み違える。

### null 設計の自己点検（事前登録の一部）

本追補の指標が恒真でないことを、実行前に次の形で確認する:

- σ は G·µ̂ = G_out·µ̂ + G_teach·µ̂ の符号なので、G_out が支配するなら σ·G_out·µ̂ > 0 は**自動的に成立する**。したがって「σ·G_out·µ̂ > 0」を判定に使わない。判定は **G_out と G_teach の大小比較**と **null との差**のみで行う
- 上記 null の下でも σ は固定なので、観測と null は同一の σ の下で比較される（修正2）
