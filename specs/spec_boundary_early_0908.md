# 初期タスクの形成過程と正負更新収支 spec 0908
親: [[初期20更新の局所勾配と実移動_再解析_0908]] / 状態: 検証中 / 更新: 2026-09-08
Issaの指摘に基づく追加検証。タスク101..119を「釣り合い成立後」と断定せず、後半窓と呼ぶ。新しい初期窓を実行前に固定する。主張の採否は変更しない。

## 1. 対象と窓
同じCPU実装、同じ初期値、data/perm/batch RNG、SNA/LR×none/L2、seed0..2でタスク1..20を再生して状態を保存する。学習器・625更新/タスク・lr.001・Adam・L2(全W/b)・Snake EMAは既存通り。
切替の主対象は最初の境界からtask2..20の19境界。各境界の最初20更新で、既存boundary_transport_0908の同一入力局所勾配/実移動・正負入力源のAdamモーメント・固定probeの平均/分散を同じコードで測る。
新旧の比較はCPU対CPUのみ（後半task101..119）。元CUDAとは別。
task1には切替がないので混ぜないが、初期・20更新・625更新の状態を参考保存し、task1から既に動いた分を隠さない。

## 2. 形成過程の指標
毎taskの切替直後・20更新・終端625更新で、zbar・star=global_pixel_mean*row_sum(W1)+b1・入力内分散・ユニット平均の分散・W1ノルム・b1を記録/再計算。
task2..20の全軌跡を図示し、初期2..6、7..11、12..20の固定ビンで補助集計。後半101..105、106..110、111..119は同じ位置ビン。主比較は全19境界とtaskごとの推移、ビンを結果に合わせて変えない。
正負入力源の更新収支、初期負側受け手の平均変位、局所上向きでも実下降する割合、分散比を初期/後半で同じ定義で比べる。初期19境界をプールした表だけで形成過程の説明を済ませない。

## 3. 釣り合いの読み
平均の位置が不変か、源別勾配の相殺か、分布幅が不変か、タスク内の戻りかを分ける。特にstarのtask2直前→task20終端の変位とtaskごとの傾向を示す。後半についても同じ量を示す。
明確な定常性検定を設計していないので、初期を自動的に「非平衡」、後半を「平衡」とラベルしない。結果から言えるのは測った窓で何が変化/相殺しているかまで。
源別分解は共有パラメータへの標本別寄与で、他ユニットの因果効果や自己項帰属ではない。実Adam分母を固定した帳簿であり、介入効果ではない。

## 4. 集計と検算
境界ごとの値→seedごとの窓平均→3seed中央値・範囲。CI/有意差判定なし。task曲線はseedを重ねる。初期・後半の同じseedの対応差も保存する。
元CPU実装との短走(task1..3)の全4腕一致を先に検算。新しいsource再生のtask1終端パラメータ・Snake状態・Adam・RNGを、以前保存したtask1 checkpointと全12走で照合する。
20更新の計装再生は新しいsourceログと一致<=2e-5、勾配加算/実変位/分散の検算は前specを継承。失敗を記録し、恣意的seed除外をしない。
CPU1thread、同時高々2プロセス、元GPUを触らない。1腕seed900秒上限。初期source・診断rawをチェックサム付きでobsidian-research-dataへ退避し、コード/spec/データhashと出所を保存。
specは実行前commit/push、結果はノート・CSV・図に保存してcommit/push。後半の既存結果は書き換えず、対象窓の解釈を追記する。
