## 0. 一行

RL-CIFAR × MLP で ReLU は raw でも std でも崩壊する。崩壊は「前活性の中心が自分の広がりの 1.6 倍ぶん負へ行ってゲートが厳密に 0 になる」ことで起きる。
中心を押し下げる道は **(C) 入力の直流成分、(H) 中間層の入力の直流成分、(B) bias** の 3 本ある。**扉を 1 枚ずつ足す梯子（`ref` → `C` → `CH` → `CHB` → `CHB1`）で、ReLU が生き残るのに何枚要るかを決める。**

## 1. 出所（`rlcifar_mlp_battle_0918` §8。すべて事後・登録外だが、この spec の設計根拠）

- 沈みはほぼ全部 **W·(その層の入力の平均)** で、bias の取り分は第 1 層 3–13%、第 2 層 **0.03%**。
- ランダムな重みでは |z̄ᵢ|/sdᵢ ≈ r（r = ‖平均‖/rms‖偏差‖）なので、**初期化時の片側ユニットの割合 = 2Φ(−2.33/r)**。raw は r = 1.911±0.016 で実測 25.3%±2.5%（予測 22.3%）、std は r = 0.121 で 0.0%。10 seed で一致。膝は r ≈ 1。
- **raw の ReLU**: タスク 1 で第 1 層が全滅（死亡率 1.000）、online 0.109、‖w‖ は初期値から 1.00 倍＝1 ミリも動かない。
- **std の ReLU**: タスク 1 を 0.982 で覚えきってから、タスク 2 のラベル切り替えで第 2 層が落ちる（死亡率は 0.000 のまま、z̄₂/sd₂ が −0.59 → −1.33 → −1.57、ゲートが厳密 0 の割合 72% → 95% → 100%）。以後は勾配が厳密 0 で凍結。
- **第 2 層の入力 ā₁ の r は 0.49–0.68**（膝の下）。第 2 層の沈みは初期化でなく、**学習が W₂ を ā₁ の逆向きに揃える**結果。
- leaky が生き残るのは φ′ に 0.1 の床があるからで、**ゲートが厳密 0 になる割合は 50 タスク通して 0%**。

## 2. 箱

宿主 `src/pmnist_rlcifar_0907.py` を**無改変で import**する。3072-100-100-10、seed ごとに CIFAR-10 の 1200 枚を固定、タスクごとに一様乱数ラベル、50 タスク × 400 epoch × 75 step（batch 16）、Adam lr 1e−3（moment 持ち越し）、WD なし、正規化層なし、float32。
**入力は raw（u8/255）に固定**する。`rlcifar_mlp_battle_0918` の std 条件は「中心化と尺度を同時に変える」ので、ここでは尺度を動かさず中心化だけを扉にする。
エンジンは `rlcifar_mlp_battle_0918` の束ねエンジン（`baddbmm` + autograd + 要素ごと Adam + CUDA グラフ）を流用し、**1 プロセス = 1 腕 × seed 0–9（R = 10）**。

### 2.1 三つの扉

| 扉 | 定義 |
|---|---|
| **C** | 入力の中心化。x ← x − x̄、x̄ は**その seed の 1200 枚の平均**（走る前に一度だけ計算し、学習も評価も同じ x を使う）。**割らない**（尺度は raw のまま）。これで r が 1.911 → 0.121 になる。 |
| **H** | 中間層の中心化。a₁ ← a₁ − m₁、a₂ ← a₂ − m₂。mₗ はユニットごとの **EMA 走行平均**、mₗ ← (1−β)mₗ + β·mean_batch(aₗ)、**β = 0.01**（適応 α と同じ）、初期値 0。**mₗ は定数扱いで勾配を通さない。訓練と評価で同じ値を使う**（訓練/評価のずれを作らない）。更新は前向きの計算のあと、Adam の更新と同じ位置で行う。 |
| **B** | bias の封鎖。**b₁ を持たない**（第 1 層の bias を除去し、恒等的に 0。勾配も更新も無い）＋ **b₂ に decoupled WD**（Adam の更新のあとに b₂ ← b₂ − lr·λ·b₂ を毎 step）。**b₃ は自由**。Issa の指定。λ は §2.2 で導出する。<br>扉 C と併せると x̄ = 0 なので **z̄₁ᵢ = w_i·x̄ + b₁ᵢ = 0 が全ユニット・全タスクで厳密に成り立つ**。 |

### 2.2 λ の導出（固定値を置かない）

decoupled WD の平衡は「Adam の 1 step の歩幅 ≈ lr」と「減衰 lr·λ·b」の釣り合いで **|b|_eq ≈ 1/λ**。
崩壊の閾値は §1 の実測から **z̄₂/sd₂ = −1.6**。bias が単独でそこへ届かないよう **8 倍の余裕**を取り、目標を |b₂|_eq = 0.2·sd(z₂) と置く。

sd(z₂) は走る前に**未使用 seed 100–102 で `CH` 腕を 3 タスクだけ回して実測**し（`--probe`）、その 3 seed の t1–t3 の sd(z₂) の中央値 S を使って

$$\lambda = \frac{1}{0.2\,S}$$

と定める。得られた S と λ は走る前に spec の追補と `provenance.json` に記録する。**λ を決めたあとに動かさない。**

**実測（2026-09-19 01:17、seed 100–102 × `CH` × 3 タスク、`results/_probe_relu_doors_0919/`）**:
sd(z₂) は 9 点で 7.06–43.46、**中央値 S = 29.1923**。したがって

$$\lambda = \frac{1}{0.2 \times 29.1923} = \mathbf{0.1713}$$

|b₂| の平衡は 5.84（= 0.2·sd(z₂)）、1 step の減衰率 lr·λ = 1.7e−4 で 1 タスク（30,000 step）あたり e⁻⁵。
sd(z₂) はタスクとともに育つ（t1 8.4 → t3 29.2 → 0918 の類似条件では t50 に 200 超）ので、
早いタスクで決めたこの λ は後半ほど**余裕が大きくなる側**に外れる。**これ以降 λ は動かさない。**

## 4. 登録する読み出し

タスクごとに宿主の `evaluate_rl` の列に加えて:

- `online_acc`（更新前 argmax の平均）、`memo_acc`
- 両層の `zbar`・`zsd`・`dead_frac`、**`gate_zero_frac`**（φ′ が厳密に 0 の要素の割合）
- **`sink_ratio_l` = z̄ₗ / sd(zₗ)**（中心がどれだけ沈んだか）
- **`p_pos_l` = ユニットごとの P(zₗ > 0) の中央値**、**`onesided_frac_l` = min(p, 1−p) < 0.01 のユニットの割合**、**`fold_mean_l` = min(p, 1−p) の平均**<br>（**z̄ を 0 に釘付けにしても、分布を歪ませればユニットは片側に寄れる**。平均 0・中央値が大きく負・正側に少数の外れ値、という形。崩壊の直接の指標はこちらで、`sink_ratio` はその原因の 1 つに過ぎない）
- **`skew_l`** = ユニットごとの zₗ の歪度の中央値（上の逃げ道が使われたかを見る）
- **`bias_share_l` = |b̄ₗ| / |z̄ₗ|** と **`bias_over_sd_l` = |b̄ₗ| / sd(zₗ)**（扉が bias に移ったかを見る。**b₁ 側を必ず取る**）
- `w_norm_l1..3`、`r_a1`（第 2 層の入力の平均/偏差）

窓 = t31–50 の `online_acc` の平均、低下 = (t1–10) − (t41–50)、**崩壊 = 窓 < 0.5**、崩壊時刻 = `gate_zero_frac_l2` が初めて 0.9 を超えるタスク（0918 では `sink_ratio_l2` < −1.6 と同時に起きたが、扉を塞ぐと歪みの道が残るので**ゲートそのもの**で定義する）。
腕対腕は seed 対応の**厳密二項符号検定**、「勝ち」= 相手が勝つ seed が 1 以下かつ p < 0.05（0918 と同じ規則）。
