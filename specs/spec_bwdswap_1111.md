## 0. 問い

V13 の段 ④ は「活性化の微分を失ったユニットは、新しい課題への適応を遅らせる」である。証拠は付録 E.1 の介入で、第 2 隠れ層の活動を

  ã = φ(z⁰) + [φ(z + d) − φ(z⁰ + d)]（d = 供与側の前活性 − 受け手の前活性・画像ごとに固定）

に置き換えた（腕 X）。分岐の時点では活動と予測が一致し、学習に使う微分は φ′(z + d) になる。ただし分岐の後は、順伝播の応答も φ(z + d) の傾きで動く。だから E.1 は、微分の二つの役（**逆伝播で学習の信号を通す役**と、**順伝播で入力に応答する役**）を分けていない。

この走は、逆伝播の微分だけを替える腕 B を足す。

  a = φ(z)（順伝播は自然な網そのもの）、∂a/∂z = φ′(z + d)（逆伝播だけ供与側の位置の微分）

**問い**: E.1 の効き（戻す向きで適応が上がり、渡す向きで下がる）のうち、どれだけが逆伝播の微分だけで再現されるか。

## 1. 設定・腕・予算（付録 E.1 と同じ。実装の特定は `results/bwdswap_1111/checks.json` と実装者の報告）

| 設定 | 活性化 | 戻す（受け手 ← 供与側） | 渡す | 次の課題・予算 | 集計 |
|---|---|---|---|---|---|
| RC（乱数ラベル CIFAR・MLP） | ELU・std | 10 ← 1（Adam 継続、次は課題 11） | 1 ← 10（Adam は N・X・B とも初期化、次は課題 2） | 30,000 更新 | 次の 1 課題の online 精度・10 seed |
| RM（乱数ラベル MNIST・2 隠れ層 MLP） | ELU | 10 ← 2（継続、次は 11・12） | 2 ← 10（初期化、次は 3・4） | 6,000 更新 × 2 課題 | 1 課題目の online 精度・10 seed |
| 5+1（実ラベル CIFAR-100 の 5+1・MLP） | ReLU・std | 28 ← 2（継続、次は hard 29） | 2 ← 28（初期化、次は 3） | 780 更新 | 次の hard 課題の online 精度・10 seed |

腕: N（対照・自然な網）、X（E.1 の入れ替え）、B（逆伝播の微分だけ）。B の d・分岐の状態・Adam の扱い・ラベル・ミニバッチは X と同じで、違うのは順伝播の 1 か所だけである。seed は 0〜9。RC と 5+1 は GPU（CUDA graph・R = 10 で束ねる）、RM は CPU。

**登録の前の検査**（`checks.json` は all_pass）: B の順伝播は毎歩、自然な網と bit で一致した（RC 150・RM 378・5+1 780 回の照合で差 0）。B の局所微分は native の φ′(z + d) と bit で一致した。更新 0 の N・X・B の出力と損失は bit で一致した。N と X は、この起動の中で E.1 の記録を bit で再現した（RC の課題 1 の末の状態、RM の seed 0・1 の全記録、5+1 の t02・t28・t29 の状態）。

## 2. 比べと区間（符号は「腕 − 対照」。渡す向きの悪化は負。付録 E.1 の表と同じ）

- 主の比べ（設定ごとに 2 つ）: 戻す向きの B − N と、渡す向きの B − N。対応差の 97.5% t 区間（10 seed。E.1 と同じく設定ごとの主 2 比較）。
- X − N は E.1 の再現で、E.1 と同じ数になるはず（RM は bit 一致）。
- 副の比べ: B − X（97.5% t 区間）と、比 β = (B − N)/(X − N)（seed の bootstrap・10,000 回・百分位の 95%）。β は「X の効きのうち、逆伝播の微分だけで再現される割合」。

## 3. 判定（設定 × 向きごと）

- **JB1（向き）**: B − N の 97.5% 区間が 0 を含まず、X − N と同じ符号なら B_SAME_DIRECTION。0 を含めば B_NO_EFFECT。逆の符号なら B_OPPOSITE。
- **JB2（割合）**: β の 95% 区間の下端 > 0.5 なら BACKWARD_CARRIES_MOST、上端 < 0.5 なら FORWARD_NEEDED（逆伝播の微分だけでは X の効きの半分に届かない）、それ以外 MIXED。0.5 は「効きの半分」という比の定義から来る。X − N の区間が 0 を含む設定・向きでは JB2 を判定しない。

## 4. 予測（Claude・本走の前。smoke の B の数は見ていない）

考え方: 渡す向きでは、供与側（劣化した網）の微分がほぼ 0 なので、X でも B でも体はほとんど学ばず、出力層だけが分岐の時点の健康な特徴の上で学ぶ。X は順伝播の傾きも 0 なので活動は分岐の時点の値に凍り、B は体が動かないので φ(z) も動かない。だから B ≈ X。戻す向きでは、X は活動が健康な傾きで応答するが、B の順伝播は飽和したまま（ELU の z が深い負）なので、逆伝播で健康な信号が来ても、前活性が飽和を抜けない限り出力に効かない。ReLU（5+1）は閉じたユニットの前活性が信号で 0 を越えれば応答が戻るので、ELU より戻りやすい。

| 番号 | 予測 | 確信 |
|---|---|---|
| PB1 | 渡す向き: 3 設定とも JB1 は B_SAME_DIRECTION、β の点推定は 0.7 以上 | 60% |
| PB2 | 戻す向きの RC と RM（ELU）: β の点推定は 0.3 未満 | 55% |
| PB3 | 戻す向きの 5+1（ReLU）: β の点推定は 0.2〜0.7 | 40% |
| PB4 | 戻す向きの 5+1 は B_SAME_DIRECTION | 60% |
| PB5 | 戻す向きの RC と RM は、JB2 が FORWARD_NEEDED | 50% |
| PB6 | X − N は E.1 と同じ数（RM は bit 一致、RC・5+1 は付録の値と小数 1 桁まで一致） | 85% |

**外れたときの読み（本走の前に書く）**

- PB2・PB5 が外れて、ELU の戻す向きでも B が X の効きの大半を出すなら、劣化した網に欠けているのは逆伝播の学習の信号で、順伝播の応答は信号が戻れば自分で戻る。V13 の段 ④（微分の喪失が適応を削る）は、学習の信号の側として言える。
- 当たって B が戻す向きで効かないなら、段 ④ の介入の効きは順伝播の応答（飽和した活動が入力に応えないこと）を通っている。V13 §4.4 は「微分の場を入れ替える」と書かず、「応答と微分を一緒に入れ替える」と書くべきで、学習の信号だけを戻しても治らない。
- PB1 が外れて渡す向きの B が N に近いなら、劣化した網の微分を渡しても、順伝播が健康なら適応は保たれる。適応を削るのは応答の側である。
