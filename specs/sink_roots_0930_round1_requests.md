## 組 sign: 押しの向き（部分残差）と、活性化をまたぐ式

### replay_adam_gap_2layer
- 目的: 2 層の第 2 層で実変位が 99〜100% 下向きになる成分を分ける（1 次の Adam の式は 0.80〜0.94 まで）。自分の重み・上流・その相互作用（交差項と勾配の時間変化）のどれが残りを作るかを決める
- 設計: final/ で `bash run_gated_final.sh`（または `python3 replay.py <state>`）。入力は derive/states の L2_{ELU,LR,SILU}_K10_s{0,1}_t00{2,3,4,6}.npz（24 状態）と L1 ELU・leaky の 6 状態。保存状態から同じバッチ順（env_batch_0913 の流れを課題 t まで進める）・同じ新ラベル（y_new と一致を assert）で最初の 200 更新を float32 で再生。腕: full（全部、保存した dm との一致を確認）、own（最終隠れ層の W・b だけ更新）、up（第 1 層だけ）、head（読み出しだけ固定）、sgd（1 歩目の平均の歩幅を Adam に合わせた SGD）。記録: 第 2 層の m の変位（50・200 更新）、相互作用 = full − own − up。1 状態 1〜2 秒、1 スレッド
- 予言: full の再生は dm と相対誤差 1e−4 未満。own は下向き 0.95 以上（切替 2〜4・3 腕）。up は 0.6〜0.85。相互作用は ELU で 7 割以上の unit が負で、1 次の 0.80〜0.94 を 0.98〜1.00 に押し上げる。leaky・SiLU の切替 2〜3 では平均場の Q>0 なので相互作用は正に出やすく、それでも下向きが保たれるなら own の非線形（勾配の時間変化）が主。head は full 以上。sgd は full より低い（0.7〜0.9）

### tau_eff_vs_fit_speed
- 目的: 記憶のフィルタの実効 τ が旧課題の当てはめの速さで決まるかを確かめる（1 層で τλ1≈10〜30、2 層で ≈0.3、K=2 で過小評価の理由）
- 設計: 1 層 784-100-10（ELU・leaky・GELU）、K∈{2,10}、3 seed、12 課題、1 課題の更新数 500・1,000・4,000・16,000。切替 2・3・5・8・12 の状態を保存（derive/dump_states.py に --steps を足す）。各状態で final/filter_real.py の誤差最小 τλ1 と、旧課題の acc が 0.9 に達した更新数 t_fit を記録
- 予言: 誤差最小の τ は η·t_fit/N にほぼ比例し、t_fit で割ると腕・K によらずそろう。t_fit で決めた τ を使うと K=2 の過小評価が ±0.08 以内に縮む。更新数を増やしても当てはめ後の更新は τ を伸ばさない

### leaky_C2_intervention
- 目的: leaky の上向きの unit が「反平行 × 漏れ × 閉じた量」の C2≈a²ΣK·Cov(K,z)/K̄ から来るかを、漏れを変える介入で確かめる
- 設計: 1 層 leaky（a=0.1）の保存状態（切替 8・12、2 seed）から、特徴を固定し、閉じた入力の出力だけ a′∈{0.02, 0.1, 0.3} に置き換えた網で旧ラベルに読み出しだけを Adam で 4,000 更新学習し直す。乱数ラベル 16 組。記録: 押し S の上向きの割合、上向きの unit の Cov_n(K,φ) の符号、π⁺
- 予言: 上向きの割合は a′ とともに単調に増える（0.02 で 0.1 以下、0.1 で 0.2〜0.3、0.3 で 0.35 以上）。上向きの unit は全部が反平行。上向きの unit の π⁺ は a′² に比例して上がる

### condA_balance_check
- 目的: condA（SGD・二乗誤差）の p*≈a² が、生の記憶の零点（odds=a²d̄₋/h̄₊）と中心化した記憶の零点（π⁺*≈a²|Cov(K,z)|/(K̄(1−a)(h̄₊+a d̄₋))）のどちらから来るかを決める
- 設計: 既存の condA の走（位置のdrift場_0908 の箱）の切替時点の状態を a∈{0.1,0.3,0.5} で保存し、final/centered.py と filter_real.py を当てる。unit ごとに両方の零点の予言と実際の釣り合いの p⁺ を比べる
- 予言: condA は SGD で当てはめが遅いので実効 τ が大きく、中心化の側の式のほうが unit ごとの p⁺ と順位で合う（順位相関 0.5 以上）。生の記憶の式は平均だけ合う

### df_test_self_influence（導出役から引き継ぎ）
- 目的: 読み出しの記憶と門の記憶（z 経路）を介入で分け、開閉の内訳が模型と合わない理由を見る
- 設計: derive/df_test.py（derive/run_pending.sh に含む）。状態 L1_ELU t005・t012、LR t008、GELU t008、SILU t008 から独立な乱数ラベル 12 組で 1 課題学習し直し、腕 full・vc（読み出しと c だけ）・wb（第 1 層だけ）。課題末の S・S^oh と開閉の内訳を記録
- 予言: 導出役の予言（derivation.md §2.5）に加えて: vc の腕の |S_閉|/|S_開| は中心化した記憶の値（leaky 0.37・ELU 0.05）に近く、full と wb の腕で実際の値（0.87・0.24）に近づく（閉じた入力の大きい票は z 経路から来る）

## 組 return: 戻りが押しより小さい理由と、切替直後と課題の残りを 1 つの式で書くこと

### Q1_replacement_branch
- 目的: Adam の帳簿の下向きの偏り b（戻りの窓で約 −0.6e-3/更新）の正体を分ける。候補は 3 つ。非復元抽出の偏り、R_mem の grid の位相の産物、軌道の揺らぎを通して R_mem 自身に移った偏り
- 設計: refute/rho_test.py をそのまま使う（1 本 2 分弱）。1 層の箱・ELU・seed 0。課題 6/8/10/12/14 の +400 更新で状態を複製し、2,000 更新まで進める。4 変種 = {同じ並べ替え, 復元抽出} × {β₁ 0.9, 0}。20 更新ごとに全データ勾配 ÷ √v̂ を記録する（エポックの中の位置を一巡する）。粗い grid（0・300・600・1,000・1,600）でも積分する。続けて --act LR --w0 500。記録: 開いた unit の実際の Δm、∫R_mem（細かい・粗い）、b の平均
- 予言: (a) 復元抽出の 2 変種で |b の平均| < 0.15e-3/更新。B1 からほぼ確実で、外れたら R_mem の計算か v̂ の相関を疑う。(b) 同じ並べ替えで、細かい R_mem の ρ≈1、粗い R_mem の ρ≈0.5 なら、grid の位相の産物。(c) 本題: 同じ並べ替えを復元抽出に替えると、2,000 更新までの実際の Δm が +0.8 以上増える（≈ |∫b| 1.1 の 7 割）→ 並べ替えの偏りが戻りを削っている。±0.3 以内なら、偏りは R_mem に移っただけ。(d) β₁ 0.9 と 0 で b は ±20% の中

- 予言: a_P が ELU 0.12〜0.13 → 0.05 以下（今の網で入力だけをそろえた見積もりは −0.03〜−0.04、checks/a4）。ELU の生き残りの比が 0.78〜0.82 → 0.88 以上、κΔs_task/|P| が 0.20〜0.25 → 0.12 以下。外れの条件: 比が 0.82 以下のまま → 押しの墨の偏りは不足の担い手でなく、戻りの窓の幅が主

## 組 valley: 谷（GELU・SiLU）: p⁺ → 0 と上端の有界性

### R_eps_wall
- 目的: 閉じた unit を止める壁が Adam の ε で決まるか（ε 則）を、介入で確かめる。谷の全閉の増加のうち、どれだけが ε の壁によるかも見る。
- 設計: 箱は elu_alpha_ladder_1layer_0925/alpha_ladder_1layer.py（v4、既に --eps1 で第 1 層だけの ε を変えられる）。GELU・SiLU × eps1 ∈ {1e−6, 1e−12}（1e−8 は既存の v4）× seed 0・1 × 200 課題。記録は既存の v4 と同じ（課題末の unit ごとの task_zmax・task_pplus・task_s、z の snapshot）。判定は次の 4 つ。(1) 閉じた unit の |Δ上端|/課題 の中央値が 0.01（GELU）・0.1（SiLU）になる深さ（0.25 刻みの帯で内挿）。(2) 軌道ごとの閉じた上端の最小。(3) 課題 151〜200 の全閉の割合と μ₋。(4) 生きた unit の k と上端の中央値。
- 予言: 式の定数のずれを避けるため、ε 1e−8 の既存の位置からのずれで書く（ずれは |φ′| の比だけで決まる）。(a) GELU の閉じた上端の最小（1e−8 で −6.95〜−7.03）と、動きが 0.01/課題になる深さ（1e−8 で約 −6.83）は、1e−6 で +0.71、1e−12 で −1.24 ずれる（最小は約 −6.3・約 −8.2 へ）。±0.3 以内、確信 70%。(b) SiLU の 0.1/課題の深さ（1e−8 で約 −22.6）は 1e−6 で +4.8（約 −17.8）ずれる。±1.5 以内、確信 60%。1e−12 では −25 より下へ行く閉じた unit-課題が 0.5% 未満、確信 65%。(c) GELU の課題 200 の全閉は 1e−6≥1e−8≥1e−12 の順で、両端の差 ≥0.05。確信 55%。(d) SiLU の 1e−6 は 1e−8 より課題 151〜200 の全閉が 0.05 以上高い。確信 50%。(e) 生きた unit の k の中央値（1〜2）と上端の中央値（3〜4.5）は ±20% 以内。確信 70%。(a)(b) が外れたら、止めているのは ε ではない。

### R2_valley_long
- 目的: 全閉→1（μ₋→0）か、μ₋ に下限があるかを決める。壁の向こうが吸収的か（F1）も見る。
- 設計: v4 の箱で GELU・SiLU × seed 0・1 × 1,000 課題。課題末の unit ごとの上端・k・s を毎課題、z の snapshot を 100 課題ごとに記録する。判定: 200 課題ごとの μ₊・μ₋、深さの帯の人口、上端 ≤−6.75（GELU）・≤−22（SiLU）の占有と、そこから開き直った数、閉じた上端の最小。
- 予言: (a) GELU の課題 801〜1000 の全閉は 0.80〜0.95、μ₋≤0.07。確信 60%。(b) GELU の上端 ≤−6.5 の占有は課題 1000 で ≥0.25。確信 60%。(c) SiLU の全閉は 0.40〜0.60、≤−20 の占有 <0.10。確信 70%。(d) 生きた unit の上端の中央値は 2〜6、k の中央値は 1〜2。確信 80%。(e) GELU で上端 ≤−6.9 に入った unit が後で開く割合 <5%。閉じた上端の最小は −7.3 より浅いまま。確信 65%。

### R1_valley_N_ladder
- 目的: k=O(1) が N によらないか（p⁺∝1/N か）を確かめる。(K2) の漂流が N で保たれるかと、ε の壁の 1/N 依存も見る。
- 設計: nksweep の箱（push_lift_ladder_1layer_0928/nksweep/nk_sweep.py に act=gelu/silu を足す）。GELU・SiLU × N 300/600/2400 × seed 0・1 × 200 課題（N 1,200 は既存）。記録: 課題ごとの切替時・+500・課題末の unit ごとの上端・k・s、課題 50/100/200 の z の snapshot。判定: 課題 151〜200 の生きた unit の k の中央値と、N への log-log 傾き。k≥k₀ の部分履歴の漂流。閉じた上端の最小。
- 予言: (a) 課題 151〜200 の生きた unit の k の中央値は、全ての N で 1〜2。N への傾きの絶対値 <0.2。確信 70%。(b) 漂流は GELU k≥2・SiLU k≥3 で、全ての N で ≤−0.2。確信 65%。(c) GELU の壁（閉じた上端の最小）は、N 2400 が N 300 より約 0.3 浅い（ε 則の 1/N、ln8/6.9）。±0.2、確信 55%。

### R3_readout_scale_clamp
- 目的: GGN で上端の記憶 ρ が伸びた原因が、読み出しの小ささか、ブレーキの揺らぎそのものかを分ける。
- 設計: GELU/GELU の 1 層の箱。課題 50 までは通常。課題 51 から毎更新後に、W2 の各列からクラス平均を引いた部分のノルムを r に戻す（ゲージ成分は触らない）。r ∈ {1.8, 14} × seed 0・1 × 150 課題。判定: 生きた unit の上端の OLS の傾き（1 課題の記憶）、年齢別の上端の中央値、閉じる確率、μ₊・μ₋。
- 予言: r=1.8: 傾き ≥0.5、年齢 12 以上の上端の中央値が年齢 1 の 2 倍以上。r=14: 傾き ≤0.3、上端は年齢によらず平ら。確信 60%。外れたら、記憶を伸ばしているのはブレーキの揺らぎそのもの。
