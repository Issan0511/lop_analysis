# spec: depth_silu_rlmnist_1020 — 深さを変えた SiLU MLP で、層ごとの沈みと担い手を測る

状態: **登録（予測を固定、検査と本走の前）** / 2026-10-20 / 起案・実装・計算: Claude（Opus 5.5）
依頼: Issa「多層にしたらするほど沈みにくいのか」。V13 の親セッション（Fable）経由。Issa の指示「Opus にやらせて」。
背景: 文字 GPT（4 ブロック pre-LN）の下見（1020、1 seed）で、SiLU・GELU の読み出しに隣接する FFN が課題 5 に μ/σ −2.8 まで沈んだあと、課題 10〜15 に正側へ戻った。戻りを運んだのは上流の共通ベクトル ȳ の動きだった。1 隠れ層 RL-MNIST では SiLU は戻らない（kappa_reload_1020、戻り 0/200）。

## 1 問い

- **Issa の問い**: 隠れ層を増やすほど、unit は沈みにくくなるか。
- **親（Fable）の読み**: 効くのは深さではない。その層の担い手（入力平均 h̄_{ℓ−1}）を上流が作って動かすかどうかが効く。第 1 層の担い手（画素平均）は固定なので、1 層の網と同じに沈んで戻らない。第 2 層以降の担い手は上流の活性化の平均なので、上流が沈むと縮み、上流が動けば戻りも起きる。学び直しは固定の担い手を持つ第 1 層が決めるので、深さでは救われない。
- **この走で分けるもの**: 深さそのものの効果と、担い手が固定でないことの効果。分け目は二つある。A4 の第 1 層（担い手は固定、上に 3 層ある）と A1 の隠れ層の比較。A4C（第 1 層の担い手を消した 4 層）と A4 の比較。

## 3 箱

`obsidian-research-data/push_direction_proof_0930/gen_states.py`（sha256 `4571091d…0fec3f30`）の箱を、隠れ層の数 L だけ変えて使う。

- 784-(100 × L)-10。隠れ層の幅は全部 100。
- MNIST raw/255、seed ごとに固定の 1,200 枚（乱数列 `rl_subset`）。
- 乱数ラベル K = 10、画像ごとに独立、課題ごとに引き直す（`env_labels_0913`）。batch 16 の並び（`env_batch_0913`）。
- 初期値は U(±1/√fan_in)（重みも bias も）。乱数列 `init` から、第 1 層の重み・bias、第 2 層の重み・bias…読み出しの順に引く。L = 1 なら gen_states と同じ値、L = 2 なら drive_recon_0930 の 2 層の箱と同じ値になる。
- Adam（`torch.optim.Adam`、lr 1e-3、β 0.9・0.999、eps 1e-8）。状態は課題をまたいで引き継ぐ。4,000 更新/課題。
- float32、CPU 1 スレッド（BLAS も 1 スレッド）。SiLU は `z * sigmoid(z)`、ReLU は `relu`、微分は autograd。
- 実装: `src/depth_silu_rlmnist_1020.py`（新規。既存の src は触らない）。

**扉 C（A4C だけ）**: x ← x − x̄。x̄ はその seed の 1,200 枚の平均（float32、引くだけで割らない）。訓練の前に一度だけ作り、全 batch・全診断に同じ x を使う。doors_rlmnist_1007 の C と同じ定義。第 1 層の担い手（画素平均）が消え、第 1 層の位置を動かす道は bias だけになる。第 2 層以降の担い手は残る。

## 5 測る量（float64、保存した重みから。x は訓練と同じもの）

記号: 層 ℓ の前活性 z_ℓ = h_{ℓ−1}W_ℓᵀ + b_ℓ、出力 h_ℓ = φ(z_ℓ)、h₀ = x。unit i、画像 n（1,200 枚）。

**位置（課題末ごと・層ごと）**
- 絶対の位置 μ_i = mean_n z_in、幅 s_i = sd_n z_in、位置 r_i = μ_i/s_i（s_i > 0 の unit だけ）。
- 開く割合 p_i = mean_n 1[z_in > 0]。死 = p_i = 0。
- φ′ の平均 mean_n φ′(z_in) と、|φ′| の平均。
- n_eff_i = (mean_n |φ′(z_in)|)² / mean_n φ′(z_in)² ∈ [1/N, 1]（勾配を運ぶ実効画像の割合。φ′ が全部 0 なら 0。ReLU では p_i に等しい）。
- 層の要約: r・μ・s の中央値、p・φ′・|φ′|・n_eff の平均、死の割合。

**担い手（課題末ごと・層ごと）**
- h̄_{ℓ−1} = mean_n h_{ℓ−1,n} と ‖h̄_{ℓ−1}‖。
- K_n = h̄_{ℓ−1}·h_{ℓ−1,n} + 1、壁 c_ℓ = mean(K)/sd(K)（重みが h̄ に反平行なとき r ≥ −c_ℓ）。sd(K) = 0 なら ∞。
- 入力の総分散 v_ℓ = tr Cov_n(h_{ℓ−1})。
- 第 1 層は画素平均で固定なので、‖h̄₀‖・c₁・v₁ は全課題で同じ値（検査に使う）。

**Δμ の分解（課題ごと・層ごと・窓ごと）**
- 窓: 切替窓 = 課題 k−1 の末（k = 1 は初期値）→ 課題 k の +200 更新。残りの窓 = +200 更新 → 課題 k の末。
- 窓の始まり a・終わり b で、Δμ_i = (Δw_i·h̄_a + Δb_i) ＋ w_{a,i}·Δh̄ ＋ Δw_i·Δh̄。順に「自分の重み」「上流」「交差」。恒等式で、残差を記録する。第 1 層は Δh̄ = 0 なので上流と交差は恒等的に 0。
- 各項を窓の始まりの幅 s_{a,i} で割る（s_a > 0 の unit）。層ごとに unit の平均と、Δμ/s の中央値を出す。
- 上流の割合（絶対）U = Σ_i |上流 + 交差| / (Σ_i |自分| + Σ_i |上流 + 交差|)。上流の割合（符号つき、文字 GPT と同じ）= mean(上流 + 交差) / mean(Δμ)。|上流 + 交差| > |自分| の unit の割合。
- 切替窓では「自分の重み」をさらに自己形の向きへの射影とその残りに割る（文字 GPT の decomp と同じ。d_i = Σ_n K_n φ(z_in)φ′(z_in)[h_n; 1]、自己項 = (Δθ_i·d̂_i)(d̂_i·[h̄_a; 1])）。副の量。
- 切替窓で位置が下がった（Δμ < 0）生きた unit の割合。

**戻り（層ごと）**
- 素の戻り（親の定義）: ある課題末に p < 1/2、それより後の課題末に p ≥ 1/2 になった unit の数。あわせて、隣り合う課題末で p < 1/2 → p ≥ 1/2 になった回数の総和。
- 深い戻り: ある課題末に p ≤ 0.1、それより後の課題末に p ≥ 1/2 になった unit の数。境の近くを行き来するだけの unit（1 層の ELU の 4 個は p 0.45〜0.48 から）を分けるため。
- 課題 30 までと課題 50 までで数える。分母は層ごとに 3 seed × 100 = 300 unit。

**学び直し（腕ごと・課題ごと）**
- オンライン精度 A(k) = 課題 k の 4,000 更新の、更新前の batch 正答率の平均。
- 頭 200 更新の学び直し H(k) = 課題 k の最初の 200 更新の平均。
- 床 F(k) = 課題 k のラベルの最多クラスの割合。
- 可塑性の喪失（fresh gap）G30 = A(1) − mean A(21..30)、G50 = A(1) − mean A(41..50)。RL-MNIST の課題は交換可能なので、課題 1 がその腕の新品の学習そのもの（wcap_rlmnist_0914 と同じ定義）。
- 床に落ちた = 窓の A の平均 ≤ 窓の F の平均 + 3·sd(F)/√10（layer_chimera_rl_0914 と同じ規則）。

**表**: 腕 × 層 × 課題末（1・5・10・20・30・50）。値は seed ごとの層の要約を 3 seed で平均し、seed の範囲を添える。

## 6 検査（本走の前に通す。閾値は算術から）

- **S-repro1（深さ 1 の再現）**: L = 1 の SiLU と ReLU、seed 0、30 課題を回し、保存状態の `end*`・`mid*`・`y`・`acc` と比べる。基準は完全一致（max |差| = 0）。同じ CPU・同じ乱数列・同じ演算順なので、ずれは実装の違いからしか来ない。本走の後に seed 1 と seed 0 の本走の課題 1〜30 も同じ基準で照合する。変異対照: Adam の eps を 1e-7 にした 1 課題は一致しない（max |差| > 0）。
- **S-repro2（深さ 2 の再現）**: L = 2 の SiLU、6,000 更新/課題、seed 0・1 を 5 課題回し、`sink_roots_0930/round1/sign_states/L2_SILU_K10_s{0,1}_t00{2,3,4,6}.npz` のパラメータ p0〜p5 と Adam の m・v と比べる。基準は完全一致。初期値の引く順と順伝播の多層化を確かめる。変異対照: 層の初期値を読み出しから逆順に引くと一致しない。開示: 起案中に scratchpad の使い捨てのスクリプト（engine ではない）で seed 0 の課題 1〜2 が完全一致することを確かめてから、この検査を登録した。
- **S-ident（分解の恒等式）**: 試走（A4 と A4C の seed 0、3 課題）の全窓・全層・全 unit で、|残差| ≤ 4γ_{d+2}·(Σ|w_a||h̄_a| + Σ|w_b||h̄_b| + Σ|Δw||h̄_a| + Σ|w_a||Δh̄| + Σ|Δw||Δh̄| + |b_a| + |b_b| + |Δb|)（γ_n = n·u/(1 − n·u)、u = 2⁻⁵³、d は入力の次元）。第 1 層の上流と交差は厳密に 0。変異対照: 交差の項を落とすと、第 2 層以降の unit の大半で残差が上の上界を超える。
- **S-doorC（扉 C の定義）**: A4C の x の画素ごとの平均が、float32 の平均と引き算の丸めの上界（doors_rlmnist_1007 の `c_bound` と同じ式）以内。全 batch と診断が同じ x（sha256 を記録して照合）。第 1 層の sd(K) は 0 に近い（‖x̄_c‖·(Σ_n‖x_n‖²/N)^{1/2} 以下）。変異対照: 中心化を外した x はこの上界を超える。
- **S-count（戻りの数え方）**: 答えの分かっている合成の p の列（境の 1/2 ちょうど、何度も行き来する列、深い戻り）で、2 種類の戻りの数が正しい。
- **S-neff・S-wall**: ReLU で n_eff = p（float64 で完全一致）。合成の入力で c_ℓ が mean/sd の直接計算と一致し、K が定数なら ∞。
- **S-online**: 記録した最初の更新の batch 正答数が、初期値で同じ batch を順伝播し直した正答数と一致する。

ずれたら値を記録して止める。閾値は決め直さない。

## 8 判定（課題 30 の値、3 seed）

**Q1（Issa の問い）**: 網全体の位置 r_net = その網の全隠れ unit をまとめた r の中央値（課題 30）。
- `DEEPER_SINKS_LESS`: 3 seed の平均で r_net(A1) < r_net(A2) < r_net(A4)、かつ r_net(A4) − r_net(A1) ≥ +0.5 が 3 seed とも。
- `DEEPER_SINKS_MORE`: 同じ規則で逆向き（A4 − A1 ≤ −0.5 が 3 seed とも、平均で単調に下がる）。
- `NO_DEPTH_TREND`: それ以外。
- 0.5 は P2 の許容幅と揃えた（A1 の seed 間の差は 0.06）。
- 可塑性の向き（G30 が深さとともに下がるか）は同じ表に並べて報告する。

**深さか担い手か（判定文）**
- J1（固定の担い手の層への深さの効果）: Δ₁ = r₁(A4) − r₁(A1)。+0.5 以上なら「深さが固定の担い手の層も浅くする」。
- J2（動く担い手の層）: 第 2〜4 層の r と第 1 層の r の差（A4）。+0.5 以上の層を「浅い」とする。ただし課題 30 の幅 s の中央値が 1 未満の層は「細い（入力が細い）」として別に数え、「沈みにくい」に入れない。
- J3（固定の担い手を消す効果）: r₁(A4C) − r₁(A4) ≥ +0.5 かつ G30(A4C) ≤ 0.5·G30(A4)。
- 判定文の規則:
  - 「担い手」: J1 が ±0.5 以内、J2 で太い浅い層が 1 つ以上あり深い戻り ≥ 5%、J3 が成り立つ。
  - 「深さ」: J1 が +0.5 以上。
  - 「どちらでもない」: J2 で太い層が第 1 層より 0.5 以上深い、または Q1 が `DEEPER_SINKS_MORE`。
  - どれにも当たらなければ、表の値をそのまま書き、どの部品が欠けたかを書く。
- 判定文は「沈みにくさが深さから来るのか、担い手が固定でないことから来るのか」の形で書く。
