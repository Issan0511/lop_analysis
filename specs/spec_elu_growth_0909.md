# ELU の第1層ノルム成長と沈下 spec 0909
状態: 検証中 / 更新: 2026-09-09

## 0. 何を問うか
0909 夜の事後解析で、素leaky の第1層中心化重みは **‖W̃‖ ~ t^0.46–0.48（√t）**、各タスクの増分は累積と直交（cos −0.05）、z̄ = −0.33 − 0.36√t（R² 0.98）だった。その機構として**尺度方向が損失の厳密な平坦方向であること**を同定した。leaky は正斉次なので (W1,b1)→κ(W1,b1)・W2→W2/κ で損失が不変で、オイラーの定理から
$$E \;=\; \langle\nabla_{W_1}L,W_1\rangle+\langle\nabla_{b_1}L,b_1\rangle-\langle\nabla_{W_2}L,W_2\rangle \;=\; \sum_{s,i}\frac{\partial L}{\partial a_{1,si}}\,h(z_{si}),\qquad h(z)=z\varphi'(z)-\varphi(z)$$
が成り立つ。**h が活性化のすべてを決める。** leaky は h≡0（実測で相対 1e−8、変異対照は 1e−3〜3 で外れる）、Snake は h が振動して深部で負、**ELU は h(z)=α[e^z(z-1)+1] ≥ 0 で深さに単調・α で飽和**。
**問い: h≢0 の ELU では第1層ノルムはどう伸び、沈下はどうなるか。** 本走は新規学習（120 タスク）だが CPU で 1 腕seed 約 44 秒。

## 1. 腕と学習
Permuted MNIST 784→100→100→10、CE、batch16、**625 更新/タスク × 120 タスク**、Adam lr=.001 β=(.9,.999) eps=1e−8（タスクを跨いで状態維持）、coupled L2 は `g += 2*.001*param` を全 W/b に。既存腕と同じ `H.init_params(seed,·)`（S-init: 腕は RNG に入らない）と `H.stream('perm'|'data'|'batch',seed)` を使うので、**同じ seed の全腕が同一の初期値・置換列・層化抽出・バッチ順を共有する（対応のある設計）**。
| 腕 | 活性化 | iv | 役割 |
|---|---|---|---|
| `LR` | leaky a=0.1 | none | **G1 参照**（既存 committed checkpoint を厳密再現しなければならない） |
| `SNA` | 適応Snake α=.6/√EMA, β=.01, clamp .05–3 | none | G1 参照 2・非斉次の既知例 |
| `ELU1` | ELU α=1.0 | none | 主腕 |
| `ELU03` | ELU α=0.3 | none | α 依存（飽和閾値 z<ln(0.05/α) が −3.0 → −1.79 と浅くなる） |
| `ELU1` | ELU α=1.0 | l2 | WD 対照 |
seed 0..2、計 15 走。ELU は**新モジュール内の duck-typed クラス**として実装し、`pmnist_boundary_host_0908.py` は編集しない（既存 provenance の host sha256 を動かさないため）。ELU は第1層・第2層の両方に掛かる（他腕と同じ）。

## 2. 測定
各タスクについて**置換直後（更新0）**と**タスク終端（更新625）**で記録する。
- `params` から厳密に: ユニット別 ‖W̃_i‖（中心化行ノルム）、行平均 m_i、bias_i、‖W2col_i‖
- 固定 probe（seed ごと test512）を**現タスク perm** で: z̄_cur、σ_cur、ユニット平均間分散、正の割合
- 同じ probe を**固定参照 perm 8 本**（`torch.Generator().manual_seed(20260909)`、`width_depth_intervention_0909` と同一）で: z̄_inv、σ_inv（8 本平均）。**幅の指数はこちらで測る**（現 perm の σ は整列で 30% 膨らみ置換で戻る成分を含む）
- ゲート: φ′ の平均、**φ′<0.05 の (標本,ユニット) 割合 `sat`**、全 probe 標本で φ′<0.05 のユニット数
- 固定の訓練 4096 標本（`manual_seed(20260909+seed)` で毎タスク同一の抽選、学習ストリームとは独立）で: `⟨∇W1,W1⟩`・`⟨∇b1,b1⟩`・`⟨∇W2,W2⟩`・`E`・`Σ(∂L/∂a1)h(z)`・loss
- 全 test set（現 perm）の精度
**勾配を作る集合（訓練 4096）と z̄ を測る probe（test512）は別物として常に書き分ける。σ_cur と σ_inv も別物。**

## 3. 判定（事前登録）
seed ごとに算出し、**3/3 一致のときだけラベルを付ける**。CI・有意差は出さない。窓は固定で、極値を選ぶ操作はしない。

**V1 幅の指数**（`ln‖W̃‖` を `ln t` に回帰）。`p_early` = t5–30、`p_late` = t60–120。
- `EXPONENT_HALF`: `p_late` が 3 seed とも [0.44, 0.52]
- `EXPONENT_SUB`: 3 seed とも < 0.40 ／ `EXPONENT_SUPER`: 3 seed とも > 0.56 ／ 他は `EXPONENT_MIXED`
- 併せて **減速** `DECELERATES`: `p_late < p_early − 0.10` が 3 seed とも

**V2 ユニット別の分岐**（100 ユニットそれぞれで t20–120 の指数を回帰）
- `UNIT_UNIMODAL`: 四分位範囲 IQR < 0.10 が 3 seed とも（leaky の実測は [0.43,0.48]＝IQR 0.05）
- `UNIT_SPLIT`: IQR > 0.20 が 3 seed とも ／ 他は `UNIT_PARTIAL`
- 補助（ラベル無し）: 指数 < 0.10 のユニット数

**V3 飽和**（`sat` = φ′<0.05 の割合、タスク終端）
- `SATURATION_GROWS`: `sat(t120) ≥ 0.20` かつ `sat(t120) > 2·sat(t20)` が 3 seed とも
- `SATURATION_FLAT`: `|sat(t120) − sat(t20)| < 0.05` が 3 seed とも ／ 他は `SATURATION_PARTIAL`

**V4 沈下則**（z̄_inv、タスク終端、t20–120）
- 傾き比 `r = slope(t80–120)/slope(t20–60)`。√t 則の予言は r = √(40/100) = 0.63
- `SINK_SQRT_LIKE`: √t 当てはめ R² > 0.90 かつ r ∈ [0.4, 0.9] が 3 seed とも
- `SINK_SATURATES`: r < 0.25 が 3 seed とも ／ 他は `SINK_PARTIAL`
- 併せて幅–深さの比 `k` = z̄_inv を σ_inv に回帰した傾き（t20–120）と R² を報告（leaky の既測は −1.70/−1.73/−1.72、R² 0.96）

**V5 欠損項の符号**（タスク終端 t20,40,60,80,100,120 × 3 seed = 18 点）
- `DEFECT_OUTWARD`: E<0 が 15/18 以上 ／ `DEFECT_RESTORING`: E>0 が 15/18 以上 ／ 他は `DEFECT_MIXED`
- E は `⟨∇W2,W2⟩`（斉次・確信度圧）と分けて報告する

**V6 WD 対照**: `ELU1/l2` の `p_late` が 3 seed とも [−0.05, +0.05] なら `WD_PINS_ELU`

**進捗ゲート G1**: `LR` と `SNA` の全 seed が既存 committed checkpoint を **params・maxabs 0** で再現すること。対象は `boundary_groups_0908/{arm}_none_s{seed}_task1.pt`・同 `_task100.pt`・`boundary_tasks20_40_0909/source` の task21..40 終端・`boundary_groups_0908` の task101..120 終端。**1 つでも外れたら全腕を無効として停止する。** さらに `LR` の E が全点で相対 <1e−6（h≡0 の帰結）でなければ停止。

## 4. 事前予測（記名・参考値）

> **起草時の予測を撤回して差し替えた（実行前・結果ゼロの時点）。** 初稿の Claude 予測は「ELU は leaky の動作点に到達できず手前で止まる（`EXPONENT_SUB`・`UNIT_SPLIT`・`SINK_SATURATES`）」だったが、Issa の指摘で**内部矛盾**が判明した: 同じ初稿が「欠損項 E<0＝外向きで leaky より速く伸びる」とも予測しており、W が leaky より大きくなれば σ も大きく、沈下が少しでもあれば分布は**より深く**なる。「手前で止まる」と両立しない。
> さらに、その根拠にした「飽和して凍結する」も自分の探針で否定されている。leaky の t100 到達点（z̄=−3.9, sd 4.4）に ELU のゲートを当てると飽和は (標本,ユニット) 対の 57–59% だが、**全標本で飽和したユニットは 0〜1/100**。ユニットは死なず、どれも正側の標本から勾配を受け取り続ける。**集団の成長を止める機構は同定できていない。**

**Claude（差し替え後）**: `EXPONENT_HALF` または `EXPONENT_SUPER`（`EXPONENT_SUB` ではない）／`SATURATION_GROWS`（σ が伸びれば閾値 z<ln(0.05/α) の下の質量は必ず増えるので、これが最も堅い）かつ **ELU03 > ELU1**（閾値が −3.0 → −1.79 と浅い）／`SINK_SQRT_LIKE`（leaky と同じかそれ以上に沈む）／`DEFECT_OUTWARD`／`UNIT_UNIMODAL`（凍結ユニットが出ないので leaky と同じく一峰）／`WD_PINS_ELU`。
一行で言えば **「ELU は leaky と同型か、やや外向きに強い」**。

- **各予測の強さ**: `SATURATION_GROWS` は幾何だけで出るので強い。`DEFECT_OUTWARD` は leaky 学習状態上の探針が根拠で、**本物の ELU 学習網では定数寄与 −α が b2 に吸収され得るため最も弱い**（ただし飽和するユニットの集合は置換ごとに変わるので b2 は追随しきれず、ゼロにはならないはず）。`EXPONENT_HALF/SUPER` はその E の符号に依存するので中間。
- **反証の形**: `EXPONENT_SUB` かつ `SINK_SATURATES` が出れば、私が同定できていない集団レベルの停止機構が存在する（撤回した初稿の予測が結果的に当たることになる。その場合も初稿の根拠＝凍結は 0/100 で否定済みなので、別の機構を探すこと）。`EXPONENT_HALF` かつ `DEFECT_MIXED` なら、h≢0 でも実効的には平坦方向のままという読みになる。
- `UNIT_SPLIT` が出たら凍結が実在するので、そのとき初めて「飽和による凍結」を機構として使ってよい。
- Claude のこれまでの的中は通算 2.5/9、Issa は 8.5/9。**重みは Issa 側に置く。** 上の差し替え自体が Issa の指摘によるもので、Claude 単独の予測としては初稿が外れたと数える。
- 既存の [[ELU沼結果_0830]] は ELU＋第1層中心化（`E_A1`）で LoP がほぼ消え第2層 dose が減少した別系の結果で、そこでは Issa・Claude 双方の機構予測が外れている。**本走の予測はそれとは独立に立てており、整合しなくても後から読み替えない。**

## 5. 検算と変異対照
すべての検査に変異対照を付け、対照が実際に検査を落とすことをアサートする（空虚な S 検査を 6 回作った履歴があるため）。
1. **G1 の厳密再現**（§3）。対照: 初期値 W1[0,0] に +1e−3 を足した学習で maxabs > 1e−4。
2. **恒等式 E = Σ(∂L/∂a1)h(z)**（全腕）。相対化の分母は内積の自然なスケール `‖∇W1‖‖W1‖+‖∇b1‖‖b1‖+‖∇W2‖‖W2‖`（r1・r2 自身は零交差するので分母に使わない）。許容 **1e−6**。対照: 別の活性化の h を使うと同じ分母で最大 > 1e−4（全腕）。
3. **leaky で E ≡ 0**（同じ分母で相対 <1e−6）。対照: 別の活性化の h（検査 2 の対照）と b1 項の脱落。
4. **ELU の phi/dphi が autograd と一致**（1e−6）。対照: α を 1.01 倍した dphi で > 1e−3。
5. **測定が学習を変えない**（測定込みと測定無しで task120 の params が差 0）。対照: 測定側でパラメータに +1e−9。
失敗は隠さず停止する。

## 追補 1: Issa の事前予測（2026-09-09・**結果を読む前**）

**登録時点の状態**: 本走は起動済みで 15 走中 1 走が完走。**判定値は一つも読んでいない**（`*_rows.csv` を一度も開いていない。ログで見たのは検算値 `ck` のみ）。本追補は §3 の判定規則・腕・測定を一切変えない。

**Issa の予測**: 「**外向きに弱い**」。Claude の §4「leaky と同型か、**やや外向きに強い**」に対する反対。

判定ラベルへの割り当て（Claude による読み替え。§4 の Claude 予測との相違点だけを書く）:
- **V5 は `DEFECT_OUTWARD`**（符号は Claude と同じ）だが、その**相対的な大きさが小さい**。
- **V1 は `EXPONENT_HALF`**（`EXPONENT_SUPER` ではない）。外向きの押しが弱いので指数は 1/2 から目立って外れない。
- Claude の予測との実質的な分岐点は **V1 が HALF か SUPER か**。V5 の符号では分岐しない。

考えられる根拠（Claude による補足であって Issa の言葉ではない）: ELU の h(z) は α で**飽和する**ので欠損項の 1 対あたりの寄与は上限を持つ一方、斉次項（確信度圧）はネットワークの成長とともに伸びる。したがって E の**相対的な**重みは学習が進むほど小さくなる。実際 leaky 学習状態での κ 探針でも、|E| は斉次項の 46%（κ=1）から 5%（κ=5）へ落ちていた。加えて定数寄与 −α は b2 に吸収され得る（Claude 自身が §4 で V5 を最も弱い予測とした理由と同じ）。

**別読みの可能性（未確定）**: 「外向きに弱い」を「leaky より内向き＝復元がある」と読めば **V5 は `DEFECT_RESTORING`** になる。Issa の確認が結果読み取り前に取れれば、本追補をその読みへ差し替える。取れなければ上の割り当て（`DEFECT_OUTWARD` かつ `EXPONENT_HALF`）を Issa の登録予測として扱い、`DEFECT_RESTORING` が出た場合は「別読みなら的中」と両論併記する。

**通算**: Issa 8.5/9、Claude 2.5/9。本件は V1 で真っ向から分岐するので、どちらが当たったかが明確に決まる。
