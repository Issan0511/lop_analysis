## 0. 一行

`BL` は「幻の残差項」で、µ の壁の力が壁の向こうでも同じ向きに続くため発散した。壁の力を止める幻の作り方は 3 つ: 負側ゲートの**符号を反転**（`BLR`）、反転を**深さ比例**に（`BLQ`）、幻の勾配から **µ 射影だけ抜く**（`BLP`）。**幻はどれも $\lVert w\rVert$ のバネを持たない**ので、w-WD を掛けた対を置き、幻とバネのどちらが何を担うかを分ける。

## 2. 何を分けるか（未登録の推論。verdict には使わない）

沈下パターン（$z_p\le0$）での幻ゲート $\gamma_p$:

| 腕 | 負側ゲート $\gamma(z)$ | $\bar g$ の係数（釣り合い時） | 揺らぎの係数 | $\lVert w\rVert$ のバネ | 予言される型 |
| --- | --- | --- | --- | --- | --- |
| `BL`（済） | $+a$ | $\lvert F\rvert+a\lvert S\rvert>0$ | $1-a$ | なし | **発散**（実測） |
| `BLR` | $-a$ | $\lvert F\rvert-a\lvert S\rvert=0$ | $1+a$ | なし | 反射壁・聞こえない |
| `BLQ` | $a_Q z$（$a_Q=0.01$） | 深さ加重で 0 になる点あり | 深さ加重 | なし | 硬い反射壁・聞こえない |
| `BLP` | $+a$、$w$ は $\hat\mu$ 直交射影・$b$ は 0 | µ 成分 0・呼び戻しは残る | $1-a$ | なし（$\sqrt t$） | 信号は残る・ノルムは伸びる |
| `*w` | 同上 | 同上 | 同上 | $\lambda_w$ | バネの代替 |
| `RWw` | 0 | — | — | $\lambda_w$ | **w-WD 単独の対照** |

**本走が答えないこと**: $a$・$\lambda_w$ の掃引、b-WD との組合せ、多層、Adam。

## 10. 実装段の決定と追補

**登録済みの判定基準と事前予測は 1 つも変えていない。以下はすべて記録の追加と、実装上どうしても必要な操作化である。**

### 10.1 §1 の恒等式についての実測（**予測は変えない・結果を見てから議論する**）

本走前に恒等式の出所と含意を検算した。3 点が出た。**いずれも §7.1・§7.2 を書き換えずに記録だけする**（9/2 Issa 裁定: 「代数はずっと分かっていないところなので、結果を見て議論したい」）。

**追補 1（出所）。** 恒等式は vault `主張/自己項の実在_力場_0902.md` に**存在しない**。同ノートを grep した結果は `gamma` 0 件・`a_p` 0 件・`nabla` 0 件・`|F|` 0 件・**「反転」0 件**。ノート §3 の見出しは「税とバネは同じ項である（Claude の読み・未登録）」で、**自己項／残差項**という別の切り方を扱う。本 spec の分解は**平均／偏差**で、vault 全体でこの式が出るのは本 spec の 1 行だけ。したがって:

- §1 の材料表の格「Claude の代数・未登録」は正しい。**出所欄を「本 spec の代数（初出）」に直した**（vault 側の正本は未修正・§8 に注記を置いた）
- vault spec §2・§5.1 行 2・§7.3 (iv) の「§3 の恒等式が間違っている」は、**存在しない主張を反証対象に設定している**。反証対象は「本 spec の代数」と読む
- 代数そのものは正しい（$g_p=\bar g+a_p$、$\sum_{\rm all}a_p=0$、$\sum_S a_p=-\sum_F a_p$ から導出を確認した）

**追補 2（釣り合い点は存在しない）。** 厳密支持は 32 点なので $\lvert F\rvert$ は整数。$\lvert F\rvert=a\lvert S\rvert$ は $\lvert F\rvert=32a/(1+a)=2.909$ で**達成不可能**。`BLR` の係数 $\lvert F\rvert-0.1(32-\lvert F\rvert)$ は

| $\lvert F\rvert$ | 0 | 1 | 2 | 3 | 4 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 係数 | −3.200 | −2.100 | **−1.000** | **+0.100** | +1.200 |

$-1.0 \to +0.1$ と飛び越して**ゼロを通らない**。「係数を 0 にする」は連続近似の産物。$\hat p\approx a/(1+a)=0.0909$ という §5.3 の予言は、$\lvert F\rvert$ が 2 と 3 の間を行き来する位置としては妥当（$2/32=0.0625$, $3/32=0.094$）。

**追補 3（$\lvert F\rvert=0$ では揺らぎ項が消える）。** 揺らぎ項の係数 $(1-\gamma)$ が掛かる相手は $\sum_{p\in F}a_p$ ＝ **発火集合上の和**である。$\hat p_i=0$ のユニットでは $\lvert F\rvert=0$ なので $\sum_F a_p=0$（空和）、したがって

$$\nabla_{w_i} = \gamma\lvert S\rvert\,\bar g = \gamma\cdot32\,\bar g$$

| | $\gamma$ | $\lvert F\rvert=0$ での勾配 |
| --- | --- | --- |
| `BL`（実測発散） | $+a$ | $+3.2\,\bar g$（壁の力と同じ向き） |
| `BLR` | $-a$ | $\mathbf{-3.2\,\bar g}$（**逆向き＝復元ドリフト**） |

**すなわち本 spec の代数は、完全に沈んだユニットに対する `BLR` を「復元バネ」と予言しており、これは `PHANTOM_RESCUES` / `PHANTOM_NEEDS_SPRING` の機構（Issa 側）であって `PHANTOM_DEAF`（Claude §7.2）ではない。** 「揺らぎを $(1+a)$ 倍する」は、まさに救いたいユニットで恒等的に 0 になる。§5.3 が `BLR` について「$\hat p\approx0.09$ に山・沈下率 ≈0」＝ユニットは生きている、と予言しているのも同じ向きで、§7.2 の「10/10 発症」とは整合しない。

**この不整合は解消せずに凍結する。** 結果が出たら、`BLR` の実測がどちら側に落ちたかで代数のどこが効いているかを議論する（作業表 #5）。**予測が外れたときにどこを疑うかは §7.3 (iv) に既に書いてある。**

**追補 4（`BLQ` の交差深度）。** $\lvert\gamma_{BLQ}\rvert=a_Q\lvert z\rvert$ が $\lvert\gamma_{BLR}\rvert=a$ と一致するのは **$z=-10$**、$\lvert\gamma\rvert=1$ に達するのは $z=-100$。親走の診断走の深さ $\bar z\approx-30$ では `BLQ` は `BLR` の **3 倍強い**。§7.2 は「浅い側で弱い」しか書いていないので、深い側で強いことを `summary.md` に定数として出す。また **P8 は 3 型で第 2 項（`RWw`−`R`）が同一**なので、P8 どうしを引くと登録していない `BLR`−`BLQ` 対比になる。`p8_cross_type_difference_registered: false` を config に置き、summary では型ごとに独立の行として出して差は出さない。

### 10.2 実装上の操作化

**追補 5（判定表の全列挙）。** §5.1 の順序つき表をワイルドカードのまま順序で解くと、`mid` と `diverged` を含むセルが上の行に吸われる。4 値 × 3 腕 = **64 セルを config に全列挙して凍結**し、解析コードは順序を再実装せず写像を引く。表の側を独立に実装した検算を `validate_config` に入れる（`bwd_leak` 追補 7 と同型）。生の 3 つ組と、条件を満たしていた行の全列挙（`co_satisfied_labels`）も `verdict.csv` に残す。

**追補 6（飽和ガード）。** §5.1 は `PHANTOM_NEEDS_SPRING` と `PHANTOM_DEAF` が 64 セル中**各 1 セル**で、どちらも `RWw ≥ 5` を厳密に要求する。**`RWw` が 0/10 に出ると 3 型とも `WD_W_SUFFICIENT_ALONE` に潰れ、幻の型の弁別がゼロになる**（§4.1 が $\lambda_w$ を賭けた先の受け皿が spec に無い）。`bwd_leak` §5.1 の飽和ガードに相当するものを置く: **`RWw` が present でないときは §5.2 の水準（P3'・P8）を主読みへ繰り上げる**。

**追補 7（S-proj の精度）。** 射影残差は float32 では $\varepsilon\lvert g\rvert$ が下限で、実測 $3\times10^{-8}$〜$1.4\times10^{-7}$。**登録の $10^{-12}$ は原理的に到達不能**（`lin0_base_0902` の S_lin0 と同じ）。**float64 の解析経路で gate し、float32 の実現値を併記する。許容値は緩めていない。** なお float32 の丸めが 5M ステップ蓄積しても µ 方向のドリフトは $\sim10^{-9}$ 級で、$s\sim-3$ に対して無害である。

**追補 8（`BLP` の µ 不変量は $s$ ではなく $\bar z$）。** §5.3 は「沈下ユニットの $s_i$ が末尾窓で変化しない（$\lvert\Delta s_i\rvert<10^{-6}$）」と書くが、**これは成り立たない**。$s_i=(w_i\cdot\mu+b_i)/\mathrm{denom}_i$ の $\mathrm{denom}_i=\sqrt{w_i^\top\Sigma w_i}$ は **$w$ 全体**に依存し、`BLP` は直交成分を $\sqrt t$ で伸ばすのが設計そのもの（§2）。したがって分子が厳密に凍っていても $s$ は動く。親走の実測（**登録外の診断**）で `denom` の中央値は 1M 窓 → 5M 窓で **×1.27**（`R_1216`）／**×1.25**（`LR_1216`）動いている。

**不変量は生の $\bar z_i = w_i\cdot\mu + b_i$**（`layer1_zbar` に既存）。主判定を $\lvert\Delta\bar z_i\rvert<10^{-6}$ に置き、$\Delta s_i$ と `denom` の成長比を**併記**して「動いたぶんは denom 経由であって µ 方向の移動ではない」と明記する。`bwd_leak` §6.2 追補 5（正規化量だけで力学を書かない・現象3指標再定義 D-5・引用禁止 C）が、今度は登録した判定式そのものに入り込んでいた。

**追補 9（符号付きゼロ）。** 反転ゲートを `torch.full_like(pre, -self.act_alpha)` と書くと $a=0$ で **$-0.0$** を返す。ReLU 分岐は $+0.0$ を返し、`torch.equal` は符号盲なので **S-limit がバイトの違いを見逃して PASS する**。`0.0 - self.act_alpha` と書いて $a=0$ で真の $+0.0$ を出し、`signbit` も明示的に検査する（`s_limit_check_signbit`）。同じ罠が `bwd_quad` の $a_Q\cdot\mathrm{pre}$（$a_Q=0$ かつ $\mathrm{pre}<0$ で $-0.0$）にもある。

**追補 10（`act_fn` / `act_grad` のフォールスルー）。** どちらの関数も末尾が**無条件の ELU return** になっている。`ACTIVATIONS` に名前を足して分岐を片方だけ書くと、黙って ELU の前向き／導関数になる。3 型とも**両方**に分岐を足し、S-cross で `relu` の前向きと bit 一致することを検査する。

**追補 11（`BLQ` の `act_alpha` は傾きではない）。** `set_activation` の $[0,1]$ ガードは `bwd_leaky` / `fwd_leaky` の凍結済み契約なので緩めない。`bwd_reflect` は **$+a$ を格納して符号は `act_grad` の中で付ける**（負の値を渡さない）。`bwd_quad` の $a_Q$ は $1/z$ の次元で**傾きではない**ので、$[0,1]$ は傾きの上限ではないことを docstring に書く。

### 10.3 S-refl の降格（9/2 Issa 裁定 A・**登録の変更**）

**追補 13。** §6 の **S-refl は登録時「必須」だったが、REPORT_ONLY へ降格した。** これは本 §10 で唯一、**登録済みの基準そのものを変えた**箇所である（他の追補はすべて記録の追加か操作化）。

**降格の理由は 2 つある。**

1. **S-refl は実装の検査ではなく、本走の主 endpoint と同じ物理の主張を検査するゲートである。** 「`BLR` の沈下ユニットの $\bar z$ が `BL` と逆向きに動く」は、まさに §5.1 が発症数で判定しようとしている「反転が壁の力を止めるか」そのものである。仮説を検査する sanity gate は、仮説が面白いときにちょうど走を止める。実装の正しさは**他の 11 ゲートが保証している**（S-cross・S-limit ×4・S-bwd・S-proj・S-wd-w・S-pair・S-dose・S-taut・S-ref はすべて PASS）
2. **30k では登録された署名が観測できない。** 実測（**登録外の診断・転記対象ではない**）:

| 窓 | `BL` の平均 $\Delta\bar z$ | `BLR` の平均 $\Delta\bar z$ | 符号 |
| --- | ---: | ---: | --- |
| [0, 30k] | −0.00262 | −0.00709 | 同じ |
| [30k, 60k] | +0.01280 | −0.01419 | 逆 |
| [60k, 100k] | −0.11265 | −0.15049 | 同じ |
| [0, 100k] | +0.16163 | +0.13717 | 同じ |

「沈下ユニット」の定義を 3 通り（step 0 で沈下／全記録点で沈下／末尾で沈下）試しても 30k では反転しない。**見当**: µ の**向きがタスク境界ごとに回る**（`mu_cos_off` が 0.894–1.0）ので、$\bar g$ の µ 成分に固定符号が無く、複数タスクにまたがる窓では $\bar z$ のドリフト符号が安定しない。これは §1 の恒等式の「壁の力が同じ向きに続く」という前提にも触る観測である。

**降格の中身**: 測定は**すべて残す**。`registered_expectation_met`（登録された「逆向き」を満たしたか）を実測値と一緒に `preflight.json` と `summary.md` に出し、**gate としては使わない**。config に `s_refl_report_only: true` / `s_refl_is_required_gate: false` を置き、`validate_config` がこの 2 つを要求する（降格を config から消すと落ちる）。

**この降格は本走前に行った。** 結果は 1 つも見ていない。

**追補 12（`BLP` の射影の書き方）。** $g_{W_i} = g_{b_i}\otimes x_{\rm in}$ なので、$g_W$ を $\hat\mu$ 直交へ射影することは **$x_{\rm in}$ を射影すること**と厳密に同値。$b$ を 0 にするのは $g_W$ を作った**後**（spec §4.3 の順序）。$\hat\mu$ は `env.flip_state` だけの関数（$\mu = [\mathrm{flip}, 0.5\cdot\mathbf 1_5] - 0.5\gamma\mathbf 1$）なので毎ステップ $O(m)$ で取れ、厳密支持の列挙は要らない。
