## 2. tau_eff_vs_fit_speed（記憶のフィルタの実効 τ は旧課題の当てはめの速さで決まるか）

- 走: 本体の `derive/dump_states.py` に `--steps` と、25 更新ごとの全 1,200 枚の正答率（その課題のラベル）の記録を足したもの。ELU・leaky 0.1・GELU × K ∈ {2, 10} × seed 0〜2 × 1 課題の更新数 T ∈ {500, 1,000, 4,000, 16,000}、12 課題、切替 2・3・5・8・12 の状態を保存（72 本・360 状態）。T ごとに別のフォルダ（ファイル名が T を含まないため）。df_test 用に SiLU K10 seed 0 T 4,000 を 1 本足す。
- t_fit（登録）: 旧課題（切替 t の直前の課題 t−1）で、25 更新ごとの正答率が初めて 0.9 以上になった更新数。届かなければ未定義。副（記述）: t_fit90 = 正答率が初めてその課題の最終正答率の 0.9 倍以上になった更新数。
- フィルタ: 本体の `final/filter_real.py`。変えたのは 2 点: τ_nat = ηT/N の T を状態自身の課題の長さに（元は 4,000 固定。4,000 の状態では同じ値）、t_fit の τ（ηt_fit/N とその 1/K）を別の行に足す（標準の行の並びは変えない）。核は plain（読み出し + 出力 bias の NTK）を主、full を副。
- 集計（登録）: 群 = (活性化, K, T)。群の誤差曲線 = 状態で平均した |予言の平均 P(τλ₁) − 観測 S^oh>0| を τλ₁ の格子（1e−4〜1e6、41 点）で。誤差最小の τλ₁ を群の λ₁ の中央値で割って τ_best。比 r = τ_best / (η·t_fit の中央値 / N)（t_fit が群の状態の半分以上で定義された群だけ）。
  - (a)「t_fit で割るとそろう」: r の群の間の散らばり（最大 / 最小）が 3 倍以内で、かつ T で割った比 τ_best/(ηT/N) の散らばりより小さい → SUPPORTED。どちらか外れ → NOT_SUPPORTED。
  - (b) K = 2 の過小評価: τ = c·ηt_fit/N（c = K10 の群の r の中央値、K ごとの自由パラメタなし）での K = 2 の状態の予言と観測 S^oh>0 の差の平均。|平均| ≤ 0.08 → SUPPORTED。
  - (c)「当てはめ後の更新は τ を伸ばさない」: 同じ (活性化, K) で τ_best(T 16,000) / τ_best(T 4,000) ≤ 1.5（T に比例なら 4）→ SUPPORTED。
  - 格子の 1 点の τ_best は粗い（格子は 1/4 桁刻み）ので、比は格子の刻みの分（×1.78）を誤差として書く。

## 11. 予言（依頼の原文のまま）

- R3prime_bwrelu: 登録の中央値の比が SiLU 0.32〜0.37 → 0.55 以上、GELU 0.14〜0.15 → 0.40 以上。どちらも bwabs（0.86・0.68〜0.71）よりは低い。生き残りの f_top は 0.85 以上。外れの条件: bwabs 並みに上がる → 谷の下の入力を拾えることが要る。上昇が 0.1 以下 → φ′<0 の符号でなく、φ′ の小ささが効いている
- tau_eff_vs_fit_speed: 誤差最小の τ は η·t_fit/N にほぼ比例し、t_fit で割ると腕・K によらずそろう。t_fit で決めた τ を使うと K=2 の過小評価が ±0.08 以内に縮む。更新数を増やしても当てはめ後の更新は τ を伸ばさない
- leaky_C2_intervention: 上向きの割合は a′ とともに単調に増える（0.02 で 0.1 以下、0.1 で 0.2〜0.3、0.3 で 0.35 以上）。上向きの unit は全部が反平行。上向きの unit の π⁺ は a′² に比例して上がる
- df_test_self_influence: 導出役の予言（derivation.md §2.5）に加えて: vc の腕の |S_閉|/|S_開| は中心化した記憶の値（leaky 0.37・ELU 0.05）に近く、full と wb の腕で実際の値（0.87・0.24）に近づく（閉じた入力の大きい票は z 経路から来る）
  - 導出役の予言（derivation.md §2.5、走の前に固定）: ELU は vc・wb とも E[S] > 0 の unit が 9 割以上。leaky は vc で 4 割以下（c0 = 0 のラベル記憶は上向き）、wb で 7 割以上（折れ目をまたぐ入力の門の跳び 1 − a が正に効く）、full は 6〜8 割。GELU は vc が 9 割以上、wb は 5〜9 割。
- F2_branch_scale: PS-a: 読み出しが学習する腕で、×2 の深さが 1.15〜2.0 倍、×0.5 が 0.5〜0.87 倍（賭け 0.45）。PS-b: 転回点も同じ向き（0.50）。PS-c: 凍結した腕では、深さは c によらず 0.8〜1.25 倍（0.55）。PS-d: 転回点は、旧ラベルの余裕が 2 割に落ちる時刻の 0.67〜1.5 倍（0.35）
- R5_rf_probe: 共分散の割合は、前半 16 回と後半 16 回で同じ符号、大きさは 2 倍以内。旧モーメントを除いた 1 歩目のラベル平均の符号は、座標ごとに U2 と 9 割以上一致する
- R2_valley_long: (a) GELU の課題 801〜1000 の全閉は 0.80〜0.95、μ₋≤0.07。確信 60%。(b) GELU の上端 ≤−6.5 の占有は課題 1000 で ≥0.25。確信 60%。(c) SiLU の全閉は 0.40〜0.60、≤−20 の占有 <0.10。確信 70%。(d) 生きた unit の上端の中央値は 2〜6、k の中央値は 1〜2。確信 80%。(e) GELU で上端 ≤−6.9 に入った unit が後で開く割合 <5%。閉じた上端の最小は −7.3 より浅いまま。確信 65%。
