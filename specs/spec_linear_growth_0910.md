# ゲートなし線形網の幅成長と沈下 spec 0910
状態: 検証中 / 更新: 2026-09-10
親: [[W増大メカニズム_0909]] §F（3 腕共通の説明）／§D-①（直交の理由）／§D-⑤（σ/‖W̃‖ の腕差）
run id: `linear_growth_0910`

## 0. 問い
Issa の記憶「ゲートなしの線形網でも重みが爆発した」を、pmnist 系の現在の計装で測り直す。線形網は (a) 厳密に正斉次（h≡0）で W2 が尺度を吸収できる、(b) ゲート非対称がゼロ、(c) φ″≡0。したがって §F の説明が正しければ:
- **幅は leaky と同じように伸びる**（直交堆積＋Adam の注入は活性化に依らない）
- **深さは沈まない**（沈める力は正負のゲート非対称が担うので、非対称ゼロなら零）
- **σ は ‖W̃‖ に厳密に比例する**（行平均が流れず、ランダム perm 下の σ² = W̃ᵀΣW̃ + 定数）
これに加えて、**尺度を吸収する層が無い単層 `LIN0`** を置く。`LIN0` では確信度圧が唯一の重みに直接かかるので、「尺度方向が平坦」が成り立たない対照になる。

## 1. 腕と学習
`elu_growth_0909`／`gate_scale_invariance_0909` と同一の枠組み: Permuted MNIST、CE、batch16、625 更新/タスク × **120 タスク**、Adam lr=.001 β=(.9,.999) eps=1e−8、正則化なし、seed 0..2。
| 腕 | 構成 | 役割 |
|---|---|---|
| `LIN` | 784→100→100→10、活性化は恒等（`H.ARMS['LIN']`） | 主腕。3 層線形＝非凸な因子分解。init は他の 3 層腕と**同一**（S-init） |
| `LIN0` | 784→10 の単層アフィン（`H.ARMS['LIN0']`、`init_params(seed, dims=(784,10))`） | 尺度を吸収する層が無い対照。**init のドローが違う**（次元が違う）ので初期値は他腕と非共有。perm/data/batch のストリームは共有 |
| `LR` | leaky a=0.1 | G1 参照（既存 42 checkpoint を maxabs 0 で再現） |
計 9 走。実装は新モジュールに置き、`pmnist_boundary_host_0908.py` は編集しない。`H.forward` は `len(params)==2` で `LIN0` を分岐し `(z,z,z,z,z)` を返す——**`LIN0` の「第1層」は 10×784 の出力重みそのもので、ユニット数は 10、前活性は logit**。

## 2. 測定
各タスク終端で `params` から厳密に: ユニット別 ‖W̃_i‖（行平均を引いた行ノルム）、N=平均、N²、注入 ‖ΔW̃‖²、侵食 2⟨W̃,ΔW̃⟩、cos、行平均、bias。10 タスクごと（t20,30,…,120）に: タスク内 625 歩の Σ‖step‖²（持続因子）、固定 probe（seed ごと test512）を**固定参照 perm 8 本**（seed 20260909）で評価した z̄_inv・σ_inv、現 perm での z̄_cur・σ_cur、test 精度。
`E_TASKS = 20,40,…,120` の終端で固定訓練 4096 標本の勾配から:
- `LIN`: ⟨∇W1,W1⟩+⟨∇b1,b1⟩−⟨∇W2,W2⟩（=E、恒等式で 0）と Σ(∂L/∂a1)h(z)（h≡0 で 0）
- `LIN0`: ⟨∇W,W⟩+⟨∇b,b⟩ と Σ_{s,k}(∂L/∂logit_{sk})·logit_{sk}（**単層のオイラー恒等式**。こちらは W2 が無いので「確信度圧そのもの」。恒等式として両辺が一致することを検算する）
**勾配を作る集合（訓練 4096）と z̄ を測る probe（test512）は別。σ_cur と σ_inv も別。**

## 3. 判定（事前登録）
seed ごとに算出、**3/3 一致のときだけラベル**。窓は固定。leaky の既測（`gate_scale_invariance_0909` の LR）: p_late 0.465/0.471/0.476、z̄_inv(120) −4.26、cos(t101–120) −0.045。

**V1 `LIN` の幅** — p_late（ln‖W̃‖ を ln t に回帰、t60–120）
- `LIN_GROWS_LIKE_LEAKY`: 3 seed とも [0.44, 0.52]
- `LIN_SLOWER`: 3 seed とも < 0.40 ／ `LIN_FASTER`: 3 seed とも > 0.56 ／ 他は `V1_PARTIAL`

**V2 `LIN` の深さ** — z̄_inv(t120) と Δz̄ = z̄_inv(120) − z̄_inv(20)
- `NO_SINK`: 3 seed とも |z̄_inv(120)| < 0.5 かつ |Δz̄| < 0.3
- `SINKS`: 3 seed とも z̄_inv(120) < −1.0 ／ 他は `V2_PARTIAL`

**V3 `LIN` の σ と幅の比例** — ln σ_inv を ln N に回帰（t20–120 の tracked 点）
- `SIGMA_TRACKS_WIDTH`: 傾き ∈ [0.9, 1.1] かつ R² > 0.95 が 3 seed とも ／ 他は `V3_PARTIAL`
- 併せて σ²_inv/N² の t20 と t120 の比を報告（leaky では σ²/E‖W̃‖² の「幅由来係数」が腕で 2.7 倍違った。線形網でこれが一定なら、腕差は活性化効果）

**V4 `LIN0` の尺度方向** — cos（t60–120 のタスク終端平均）と p_late
- `LIN0_OUTWARD`: 3 seed とも cos > 0 ／ `LIN0_INWARD`: 3 seed とも cos < −0.02 ／ 他は `V4_PARTIAL`
- p_late は報告（`LIN` との大小を併記。**予測は §4**）

**V5 恒等式** — `LIN` の |E|/スケール < 1e−6、`LIN0` の単層恒等式の相対誤差 < 1e−6（分母は内積の自然スケール）。落ちれば実装エラーとして停止。

**進捗ゲート G1**: `LR` が既存 42 checkpoint を params maxabs 0 で再現。外れたら全腕を無効として停止。

## 4. 事前予測（記名・参考値）
- **Claude**: `LIN_GROWS_LIKE_LEAKY`・`NO_SINK`・`SIGMA_TRACKS_WIDTH`。`LIN0` は `LIN0_INWARD`（切替ショックの侵食が W2 の緩衝なしに直接かかるため、平均すると内向き）で、**p_late は `LIN` より小さい**。
- **反証の形**: `LIN` が沈めば「沈下にはゲート非対称が要る」が崩れ、§F6 の説明が落ちる。`LIN` の p_late が leaky の帯から外れれば「幅の成長は活性化に依らない」が崩れる。`LIN0` が `LIN` より速く伸びれば、W2 の吸収は成長を**抑えて**いたことになり、§F1 の「尺度に無関心」の読みが逆転する。
- Claude の的中は通算 2.5/11。Issa の予測が入れば結果読み取り前に追補で併記する。

## 5. 検算と変異対照
1. **G1**（対照: 初期値 W1[0,0] に +1e−3 で > 1e−4）
2. **恒等式**（`LIN`: E と Σ(∂L/∂a1)h の一致、h≡0 なので両方 0。`LIN0`: 単層恒等式）。対照: `LIN` に ELU の h を当てると > 1e−4、`LIN0` の右辺を logit の代わりに入力 x で計算すると > 1e−2。
3. **Δ‖W̃‖² の分解恒等式**（1e−10。対照: 符号反転）
4. **測定の非侵襲**（task120 の params 差 0。対照: 測定側で +1e−9）
5. **`LIN0` の forward が `len(params)==2` 分岐を通ること**（`H.forward(params,x,act)[4]` が `x@W.T+b` と一致、1e−12）
失敗は隠さず停止する。
