# 幅と沈下の介入 spec 0909
状態: 検証中 / 更新: 2026-09-09
親: [[現在CE符号反転の要因交換_結果_0909]] / [[Leak距離補償仮説_説明と検証方針_0908]]
Issa 仮説「沈下は W の幅と対応している。前活性の幅が増えれば、釣り合う場所は沈下側に絞られる」。事後解析（0909 夜・未登録）で素LR のタスク終端は z̄_end = −1.7·σ_end + c（81 タスク・3 seed・R² 0.96）、素SNA は k≈−1.0、l2 腕は幅も沈下も無し、を確認した。ただし観測だけでは「幅→沈下」と共通駆動を分けられず、ユニット単位では不成立、SNA seed0 は幅が同じだけ伸びて沈まない。**本 spec は向きを決める介入**。新規学習軌道は作るが、保存済み状態からの決定的再生のみで GPU 走はしない。

## 介入と継続
開始状態は task20 終端 = `boundary_tasks20_40_0909/source/{ARM}_{iv}_s{seed}_states.pt` の boundaries[0] の `before`（params・`adam_before`・SNA は V）。ここで W1 に介入し、task21..40 を各境界の保存 `perm`・`rng_after_perm` で **625 更新×20 タスク**継続する（同じ層化抽出・バッチ順・coupled L2・Snake EMA 順序）。`after_625`(j) = `before`(j+1) が params・Adam・V とも差 0 で連鎖することを確認済みなので、無介入の継続は保存状態 20 個を厳密に再現しなければならない。
W1 の行 i を W_i = m_i·1 + W̃_i（行平均＋中心化）と書く。5 腕:
- **幅腕 κ ∈ {0.7, 1.0, 1.4}**: W̃_i ← κ W̃_i、m_i・b_i は不変。行和と設定点 star は不変、置換平均の z̄ は不変、置換不変 σ² は off + κ·cross + κ²·wid に変わる（off=行平均由来、cross=行平均×中心化の交差項、wid=中心化 W 由来）。
- **深さ腕 Δb = ±0.3·σ_inv(20⁺)**: 全ユニットの b_i に同じ Δb を足す。z̄ は正確に Δb ずれ、σ は不変。
Adam の m・v・t と Snake の V は介入で触らない（V は EMA で追随する。記録する）。κ=1.0 が参照腕。
腕: LR/SNA × none/l2 × seed0..2 × 5 介入 = 60 継続。優先解釈は素LR。l2 腕は「幅が戻る」の陽性対照。

## 測定
20⁺（介入直後・学習前）と各タスクの更新 20/100/300/625 で:
- 固定 probe（seed ごとの test512）を**現タスクの perm** で: z̄_cur・σ_cur（入力内分散のユニット平均の平方根）・ユニット平均間分散。
- 同じ probe を**固定参照 perm 8 本**（`torch.Generator().manual_seed(20260909)` で引く。学習の乱数系列とは無関係な定数）で: z̄_inv・σ_inv（8 本平均）。これが「W の幅」の測り方。現 perm の σ はタスク内で整列により +30% 膨らんで置換で戻る成分を含むので、判定には使わない。
- W の統計: 行平均の平均、中心化行ノルムの平均、bias 平均、star 平均、参照 perm 下の分散のオフセット部／幅部。
- タスク終端の test 精度（全 test set・現 perm）。
- ユニット別の z̄_i（inv）・σ_i（inv）をタスク終端で保存（事後用）。
**勾配を作る集合（訓練ストリーム）と z̄ を測る probe は別物。σ_cur と σ_inv も別物として書き分ける。**

## 判定（事前登録）
seed ごとに、同 seed の参照腕（κ=1）との差で定義する。t は task21..40 の終端（20 点）、20⁺ は介入直後。
- Δσ_X(t) = σ_inv,X(t) − σ_inv,ref(t)
- Δz_X(t) = [z̄_inv,X(t) − z̄_inv,X(20⁺)] − [z̄_inv,ref(t) − z̄_inv,ref(20⁺)]（参照の自然な漂流と初期のわずかなずれを差し引いた、介入が生んだ追加の深さ変化）
- k_inv = 参照腕の 20 点で z̄_inv,ref(t) を σ_inv,ref(t) に回帰した傾き（自然な漂流の dz̄/dσ。81 点の σ_cur 版 k は参考として併記）

**幅腕**（κ=0.7 と 1.4 の両方で同じラベルになったときだけ付ける。違えば `ASYMMETRIC`）
- 持続 P = Δσ_X(40)/Δσ_X(20⁺)。3 seed とも |P|<0.25 → `WIDTH_RESTORED`／|P|>0.75 → `WIDTH_PERSISTS`／それ以外 `WIDTH_PARTIAL`
- 結合 C = Σ_t Δz_X(t)Δσ_X(t) / Σ_t Δσ_X(t)²（20 点の原点回帰）。
  3 seed とも sign(C)=sign(k_inv) かつ |C|≥0.5|k_inv| → `DEPTH_FOLLOWS_WIDTH`／|C|≤0.25|k_inv| → `DEPTH_IGNORES_WIDTH`／それ以外 `DEPTH_PARTIAL`
  `WIDTH_RESTORED` の腕では結合ラベルを `NOT_TESTABLE_WIDTH_RESTORED` とし、|Δσ| が初期の 0.25 を下回った最初のタスクを併記する。
**深さ腕**（±両方で同じラベル）
- 復元 Q = [z̄_inv,X(40) − z̄_inv,ref(40)] / Δb。3 seed とも |Q|<0.25 → `DEPTH_RESTORED`／|Q|>0.75 → `DEPTH_FREE`／それ以外 `DEPTH_PARTIAL`
- 副測定: 幅の応答 S = Σ_t Δσ_X(t)·δz_X(t) / Σ_t δz_X(t)²（δz は参照との生の差）。1/k_inv と併記、ラベル無し。

**組み合わせの読み**（結果を見る前に固定）
| 幅腕 | 深さ腕 | 読み |
|---|---|---|
| FOLLOWS | RESTORED | 深さと幅の間に双方向の拘束。仮説の最も強い形 |
| FOLLOWS | FREE | 幅が深さを一方向に決める。深さ自身に復元力は無い |
| IGNORES | FREE | 結合無し。z̄=−1.7σ は共通駆動か偶然。「W が伸びる理由」と「行平均が流れる理由」は別の問い |
| IGNORES | RESTORED | 深さは規制されるが幅は規制していない。規制者は別（出力・読み出し側）|
| WIDTH_RESTORED（素腕） | — | WD 無しで幅が規制されている。それ自体が発見。結合はこの方法では検定できない |
| WIDTH_RESTORED（l2 腕） | — | 期待どおりの陽性対照 |

進捗ゲート G1: 参照腕が保存 20 状態を厳密再現しなければ全腕を無効とし停止する。
副次: κ 腕の test 精度が参照より 2 pt 以上落ちた seed は「介入が学習を壊した」として結合ラベルに★を付ける。

## 事前予測（記名・参考値）
- Issa: `DEPTH_FOLLOWS_WIDTH`（幅が釣り合い点を決める）。
- Claude: 素LR で `WIDTH_PERSISTS` かつ `DEPTH_IGNORES_WIDTH`、深さ腕は `DEPTH_FREE`。根拠はユニット単位の非結合と SNA seed0。l2 腕は両者とも `WIDTH_RESTORED`。Claude の的中は通算 2/7。
- 反証の形: κ=1.4 で z̄ が参照より k_inv·Δσ だけ深くなれば Claude が外れ。Δσ が 20 タスク持続して z̄ が動かなければ Issa の一方向形が外れ。

## 検算と変異対照
全検査に変異対照を付け、対照が検査を落とすことをアサートする。
1. κ=1 の継続が保存 `after_625` 20 個を params・Adam・V とも差 0 で再現。対照: W1[0,0] に +1e−3 で > 1e−4。
2. 幅介入直後の σ_inv² = off + κ·cross + κ²·wid（参照 perm 下の分解。介入は double で計算して float32 に戻すので相対 1e−5）。対照: κ を 1/κ に替えると外れる。
3. 幅介入で bias は差 0、行和・star は float32 丸め以内（相対 1e−5）、‖W̃_new − κW̃_old‖ は float32 丸め以内、‖W̃_new − W̃_old‖ > 0。κ=1.0 は介入コードを通さない no-op（double 往復の丸めで参照腕の厳密再現を壊さないため）。
4. 深さ介入で z̄_inv・z̄_cur が Δb ずれ（float32 加算なので絶対 1e−6）、σ_inv・σ_cur は差 0（W に触れない）。対照: 0.99Δb と照合すると外れる。
5. 測定が学習を変えない。参照腕は測定込みで走らせて検査 1 を通すので、これが測定の非侵襲性の証明を兼ねる。対照: 測定側で act.update（SNA）／W1 に +1e−9（LR）を入れた変異で検査 1 が落ちること。
失敗は隠さず停止する。

## 集計・保存・運用
seed 内は時系列（20 点）、seed 間は 3 本並記。ラベルは 3/3 一致のみ。CI・有意差なし。
CPU 1 thread・最大 2 process。1 継続 120 秒上限（実測 0.4 秒/タスク + 測定）。全体 ~10 分。
spec とコードを実行前に commit/push。CSV・verdict・summary・図を commit、ユニット別 npz は SHA 照合付きで `obsidian-research-data/width_depth_intervention_0909` へ。既存 run の出力は上書きしない。
限界: 一時点（t20）の一回限りの介入で、自然な漂流の駆動を同定するものではない。leaky は正斉次なので W2 が層 1 の尺度を機能的に打ち消せる（打ち消して z̄ が動かないなら、それが `IGNORES` の中身）。Snake は非斉次で V が追随するため同じ読みはできない。元 GPU 軌道ではなく CPU 再生軌道。
