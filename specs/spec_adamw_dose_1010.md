## 0. 一行と問い

AdamW（Loshchilov & Hutter 2019）は、勾配に何も足さず、各更新で重みを (1 − ηλ) 倍してから Adam の 1 歩を引く: θ ← (1 − ηλ)θ − η·m̂/(√v̂ + ε)。重みの成長を止める働きを、行ノルム上限のような硬い射影ではなく、最適化器の側で連続的に行う。その時間定数は τ = 1/(ηλ) 更新である。

- **Q1（主・箱 1）**: τ が走の 1/10 以下になる λ（3×10⁻²・10⁻¹）で、AdamW は ELU→ELU の崩壊を防ぐか（doors_rlmnist_1007 の規則で `RESCUED`）。
- **Q2（箱 1）**: 主窓の online は λ とともに単調に上がるか（`DOSE_*`）。τ が走より長い 10⁻³ と、中間の 10⁻² も入れる。
- **Q3（箱 1・機構）**: 隠れ層の行ノルムは回転平衡 √(ηd/2λ) に落ち着くか（`EQUILIBRIUM_*`）。幅は止まるか（`WIDTH_*`）。第 2 層は訓練の微分の零点から離れているか（`DEPTH_*`）。
- **Q4（箱 2・否定対照）**: 5+1 CIFAR × ReLU で、τ が走の 1/10 以下の λ（5・10）の AdamW は、R と L2 Init の中点に届かないか（`NO_RESCUE`）。

### 1.3 RL-MNIST の coupled L2（l2split_rlmnist_0914、登録・報告のみ）

Adam を通る L2（λ 1e−3、lr 1e−3、784–100–100–10、30,000 更新/課題、50 課題）は、ReLU の腕 R_l2 で時間劣化の 98.9% を除いた（A(31–50) 94.0 対 ref 12.6）。coupled L2 は、勾配が 0 の座標でも λθ を Adam が正規化するので、v に残った過去の勾配が抜けた後は（β₂ = 0.999 で数千歩）、1 歩およそ η ずつ 0 へ動かす。死んだ unit の重みは、走の中で 0 の近くに戻る。decoupled はその座標を (1 − ηλ) 倍するだけで、符号を変えない。**箱 2 の結果は decoupled WD についてのものであり、「WD 一般」や coupled L2 には広げない**（§10）。

## 2. 設計

### 2.1 AdamW の入れ方（両箱で共通）

- 各更新で、宿主どおりに順伝播と勾配を計算する。その後、6 テンソル（W1・b1・W2・b2・W3・b3）のそれぞれに、λ_p ≠ 0 なら **p ← fl₃₂(p·c)、c = fl₃₂(1 − ηλ_p)** を掛ける（`p.mul_(1 - lr * lam)`。torch.optim.AdamW の `param.mul_(1 - lr * weight_decay)` と同じ演算で、丸めも同じ）。続けて宿主の Adam の更新（m・v の更新と `p -= lr * (m / c1) / ((v / c2).sqrt() + eps)`）を 1 文字も変えずに行う。結果は θ_{t+1} = c·θ_t − η·m̂_t/(√v̂_t + ε) で、torch.optim.AdamW の 1 歩と同じ式になる（減衰は勾配の計算に使った θ_t に掛かり、Adam の項より前に入る）。
- **勾配には何も足さない**（decoupled）。m と v は損失の勾配だけを見る。
- λ = 0 では減衰の演算を 1 つも入れない（torch の `if weight_decay != 0` と同じ）。λ = 0 の経路は宿主と bit 一致しなければならない（§6 の S0・S-nochange）。
- **torch.optim.AdamW そのものは使わない**（§11 の 2）。宿主の Adam は手書きで、torch の Adam とは演算の順序が違う（torch は m を lerp で更新し、分母は √v/√c₂ + ε を先に作る）。そのため weight_decay = 0 でも宿主と bit 一致しない（§1.5）。torch.optim.AdamW と同じ式であることは、S-torch（§6）で丸めの帯の中の一致として示す。
- 実効の減衰率は 1 − c である。float32 の丸めで ηλ から最大 1.3% ずれる（λ = 10⁻³ で +1.33%）。釣り合いと時間定数はこの値で計算する（§2.2・2.3 の表）。
- **WD の対象は 6 テンソル全部**（両隠れ層と読み出しの、重みと bias）。λ は全テンソルで同じ。唯一の例外は検査 S-ctrl の「読み出しだけ」の腕（W3・b3 だけ）で、本走には入らない。
- 減衰は **task 1 の最初の更新から**入れる。最適化器は学習者の一部だからである。doors の扉と同じく、E1・E2 は各腕自身の task 1 から測る。Adam の moment と更新番号は課題をまたいで保持する（宿主どおり）。

### 2.4 箱 1 の釣り合いの見積もり（算術。§7 の予測の根拠）

### 5.2 DOSE（用量反応）

- 水準の順序は L0 = ref（λ = 0）< 10⁻³ < 10⁻² < 3×10⁻² < 10⁻¹。seed ごとの**主窓の online の水準**（窓内の課題平均。E1 ではない）を使う。
- 隣り合う 4 段のそれぞれで、seed 内の差 D_k = online(L_k) − online(L_{k−1}) に正確な両側の符号検定（同値は除く。全部同値なら p = 1）を当て、4 段で Holm（α = 0.05）。段ごとに UP（Holm で有意かつ + が多数）、DOWN（Holm で有意かつ − が多数）、FLAT（それ以外）。
- ラベル: **DOSE_MONOTONE**（DOWN が無く、UP が 1 つ以上）、**DOSE_PEAKED**（ある UP の段より上の段に DOWN がある）、**DOSE_FLAT**（全段 FLAT）、**DOSE_OTHER**（それ以外。DOWN が UP より下の段にだけある、など）。互いに排他で網羅的。段ごとの中央値と勝ち数も報告する。
- 「単調」を非減少で定義した理由: ref と 10⁻³ はどちらも床に落ちる予測なので、厳密な単調増加は設計上ほぼ届かない（§11 の 6）。

### 5.3 EQUILIBRIUM（効く水準。第 1・2 層。第 3 層は報告のみ）

- seed ごとに、主窓の課題終端の `row_norm` の unit 中央値を窓で平均し、‖w‖* = η·√(d/(2(1 − c)))（第 1 層は d = その seed の d_eff、第 2 層は d = 100）との比 ρ を取る。log₂ρ の seed 平均の 95% t 区間で、**MATCH**（区間が [−1, +1] の中 = ×1/2〜×2）、**OFF_HIGH**（下端 > +1）、**OFF_LOW**（上端 < −1）、**UNRESOLVED**（それ以外）。d = 784 での比も報告する。
- 水準のラベル: 両層とも MATCH なら **EQUILIBRIUM_MATCH**、そうでなければ **EQUILIBRIUM_OFF**（層ごとのラベルと倍率を記録）。
- 帯 ×1/2〜×2 の算術: (i) 更新の向きがすべて揃った極限の釣り合いは η√d/(1 − c) で、乱歩の値の √(2/(1 − c)) 倍 = 141（10⁻¹）〜258（3×10⁻²）倍。×2 よりはるかに外にある。(ii) ref の生きている間の増分から作った INC の見積もりは ×1.51〜2.01（第 1 層）・×1.44〜1.87（第 2 層）で、帯のほぼ中に入る（第 1 層の上端は縁）。(iii) ×1/2 を下回るのは、大半の座標で損失の勾配が消えて減衰だけが働く場合（崩壊の署名）。したがって帯は「勾配が細った（< 1/2）」「乱歩と課題ごとの押し（1/2〜2）」「揃った押しが支配（> 2）」を分ける。

### 5.4 WIDTH（効く水準。層ごと）

- s = 課題終端の `sigma` の unit 中央値。seed ごとに、主窓（t51–100）の s の最小二乗の傾き b_λ,s を、**同じ seed の ref の生きている間（t1–10）の傾き g_ref,s** で割った κ_s を取る（記録で g_ref は σ1 +0.464〜+0.523、σ2 +1.57〜+2.77/課題）。
- 腕の床の状態が ALIVE のときだけ評価する。FLOORED なら **WIDTH_FROZEN**（死んで凍った幅は止まって見えるので、WD の働きとは読めない）、SPLIT なら **WIDTH_SPLIT**（評価しない）。
- ALIVE のとき、層ごとに κ の seed 平均の 95% t 区間で: **STOPPED**（区間が (−1/10, +1/10) の中）、**GROWING**（下端 > 1/10）、**SHRINKING**（上端 < −1/10）、**UNRESOLVED**（それ以外）。両層とも STOPPED なら **WIDTH_STOPPED**、そうでなければ **WIDTH_NOT_STOPPED**。
- 1/10 の算術: 効く水準の ‖w‖² の緩和の時間定数は τ/2 ≤ 2.8 課題なので、t51 までに残る緩和は e^{−50/2.8} ≈ 2×10⁻⁸ で、釣り合いでの期待の傾きは 0。止まっていなければ、傾きは生きている間の成長率（κ ~ 1）の桁になる。釣り合いの揺らぎによる傾きの誤差は、課題ごとの揺らぎを σ_s として ≈ σ_s·√12/50^{3/2} ≈ 0.01·σ_s である。σ_s が g_ref（σ1 で 0.5/課題、σ2 で 2/課題）の数倍以下なら、κ の誤差は 1/10 よりずっと小さい。親の原案（主窓の ref の傾きの 1/10）は、ref の主窓の傾きが 9/10 seed で 0 なので使えない（§1.1 (b)、§11 の 3）。

### 5.5 DEPTH（RESCUED の水準）

- Z_λ,s = 主窓の課題終端の `z2_zero_pairs`（第 2 層の（画像, unit）の対のうち、訓練の微分が厳密に 0 の割合）の窓平均。ζ_s = Z_λ,s / Z_ref,s（ref は ≈ 1.000）。
- ζ の seed 平均の 95% t 区間で: **DEPTH_ABOVE_FLOOR**（上端 < 1/10）、**DEPTH_AT_FLOOR**（下端 > 1/10）、**DEPTH_UNRESOLVED**（それ以外）。Z_ref,s = 0 の seed は除く（(B) の下では起きない見込み）。
- 1/10 は親の指定。厳密 0 の対からは勾配が 1 つも出ないので、Z < 0.1 は「対の 9 割以上が勾配を運ぶ」状態を意味する。ref は ≈ 0 割。

### 5.6 箱 2

- seed s ごとに、後期窓で a_s = W_s − R_s、c_s = W_s − M_s、M_s = (R_s + L_s)/2 を取る（W は AdamW の腕、L は L2 Init λ 1e−2。R と L は committed の記録で、再利用の照合は §2.3）。
- 正確な両側の符号検定。2 水準（λ = 5・10）で、a の族と c の族のそれぞれに Holm（α = 0.05）。
  - **RESCUED**: c が有意に正（R と L2 Init の中点より上の seed が有意に多い）。
  - **PARTIAL**: RESCUED でなく、a が有意に正。
  - **NO_RESCUE**: それ以外。そのうち a が有意に負なら、副フラグ **WORSE**。
- 中点の算術: 中点は 2 つの既知の錨（介入なしの R と、この箱で最良の既知の正則化である L2 Init）から等距離の点で、RESCUED は「R より L2 Init に近い」を意味する。L − R は 10/10 seed で正なので、seed ごとに W − R > W − M であり、RESCUED なら a も seed ごとに正の側にある。報告: 中央値、順序統計の区間 [v(2), v(9)]（97.9%）、戻りの割合 ρ_s = a_s/(L_s − R_s)。
- **IMPAIRED**（読みのフラグ）: 早期窓の W − R の 95% t 区間の上端 < 0（cap_cifar5p1_1007 と同じ定義）。
- **適用条件**: **(A)** 2 腕 × 10 seed × 30 課題の行と fresh_self の行が揃い、有限で、発散 0。§2.3 の再利用の照合 (a)(b)(c) がすべて成立し、t29 のバッチ列の sha256 が全腕で一致する。欠けは INCOMPLETE、照合の破れは CHECK_FAILED（科学ラベルを出さない。seed を落として n を縮めない）。**(B)** R の fresh gap（10 個）の 95% t 区間の下端 > 0（既知で成り立つ）。満たさなければ NOT_REPRODUCED。**(C)** 各腕・各 seed・各課題で、6 テンソルとも `wd_steps` = 780。満たさない腕は INAPPLICABLE。
- **箱 2 のまとめ**: 2 水準とも NO_RESCUE なら **WD_NO_RESCUE_RELU**（親の予想）。どちらかが RESCUED なら **WD_RESCUES_RELU**。それ以外は **WD_PARTIAL_RELU**。
- 報告のみ: 死 l2・mob l2・p2・relpos l2・eff_rank l2・w_norm l1–l3・bias のノルムの、後期窓の seed 中央値と R との対応差。fresh gap（2 種）。**C-snp**（本走の後に adamw10 を較正 seed 100–109 で走らせ、S&P ε 1e−3・σ 1e−4 のセルと seed で対にした後期窓の差の中央値と [v(2), v(9)]。S&P の縮めだけのセルを AdamW の近い代わりとして引けるかを見る）。

### 5.7 読み方（登録）

- **箱 1 が WD_RESCUES_BOTH、箱 2 が WD_NO_RESCUE_RELU** → V12 の一文の WD の部分を、AdamW の形で書ける: 「decoupled WD（全パラメータ、τ ≤ 走/10）は、乱数ラベル MNIST の ELU→ELU を 100 課題、床に落とさなかった。5+1 CIFAR の ReLU では、τ ≤ 走/10 の 2 水準とも R と L2 Init の中点に届かなかった」。EQUILIBRIUM・WIDTH・DEPTH が立てば、機構（釣り合いの幅で第 2 層が零点から離れた）を併記する。
- 効く水準が RESCUED で EQUILIBRIUM_OFF（OFF_HIGH）→ 「WD は幅を止めたが、回転平衡の値ではなく、揃った押しで決まる値で止めた」と書く。
- RESCUED で DEPTH が ABOVE でない → 「零点から離れたことで救った」とは書かない。
- 箱 2 が NO_RESCUE でゲートが開いた（死 l2 が下がる・relpos が上がる）→ 「WD は ReLU の閉じたゲートを開けられない」とは書かない。「原点への縮めはゲートを動かしたが、水準は戻らなかった」と書き、階数と IMPAIRED を併記する。
- 箱 2 が RESCUED → V12 の一文の ReLU の半分は、AdamW では成り立たない。書き直す。
- wd1e-2 に「戻り」の事象がある → 「decoupled WD の下では ELU の死は吸収的でない」と書ける（報告のみの格）。RESCUED でも、主窓で床にいた課題の割合を併記し、「崩れなかった」ではなく「床に居続けなかった」と書く。
- IMPAIRED・T1_LOWER の腕では「可塑性を守った」と書かない。
- RESCUED は「この箱の 100 課題で床に落ちなかった」の意味で、無限時間の非崩壊を意味しない。

### 7.3 採点の規則（登録）

- ラベルの項目は、実現したラベルに付けた確率、最頻ラベルの的中、多クラスの Brier 得点 Σ_k(p_k − 1[k = 実現])² を報告する。「他」は 1 つの桶。名前を書かれていないラベルの確率は 0 とする。
- 二値の項目は、真偽と binary Brier (p − o)² を報告する。
- 評価できない項目（DEPTH は RESCUED の水準だけ、WIDTH は ALIVE のときだけ、など）は「未採点（理由）」とする。
- S1・S2 のように ref だけで決まり、記録から答えがほぼ分かっている項目も採点するが、独立な予測の成功としては数えない。箱 2 の項目も同じ（§1.2）。

## 10. 言わないこと・読みの上限

- **AdamW が可塑性の喪失全体を防ぐとは言わない。** 言えるのは、この 2 箱・この λ・この予算の範囲である（箱 1: 乱数ラベル MNIST の ELU→ELU・6000 更新/課題・100 課題。箱 2: 5+1 CIFAR の ReLU/std・lr 1e−4・30 課題）。
- **SiLU・GELU（と leaky など）は測っていない。** 箱 1 は ELU→ELU だけ、箱 2 は ReLU だけである。「深さで応答を失う活性化」を ELU 以外に広げない。
- **online は学ぶ速さである**（課題の中の更新前の当たり率の平均）。到達点でも、記憶の容量でもない。窓の online は速さの積分である（cifar5p1_mlp_0920 §17 の教訓）。
- RESCUED は相対の規則（自分の task 1 からの低下の差）なので、窓の水準が ref の task 1 より低くても立ちうる。水準と T1_LOWER を必ず併記する。
- 箱 2 の NO_RESCUE は decoupled WD・λ ∈ {5, 10} の結果であり、「WD 一般が ReLU に効かない」とは言わない（RL-MNIST の ReLU は coupled L2 で救われている。§1.3）。λ < 4.27 は走っていない（S&P の近いセルは較正 seed の報告のみ）。
- 中心化（扉 C・H）との比較は本 spec の範囲外で、「中心化が要る」は本 spec からは言えない（V12 の一文の後半は doors 系の登録に依る）。
- 媒介の割合や因果の全体は言わない。釣り合いの式は既知（Kosson 2024）で、新規性を主張しない。
- 箱 1 の wd1e-2 の「戻り」は報告のみの格で、登録の主張にしない。
