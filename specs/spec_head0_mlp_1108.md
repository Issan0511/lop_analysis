## 1 問い

MLP の継続学習で、課題が進むほど新しい課題を学べなくなる。その遅れのうち、どれだけが**体（第 1 層）の状態**で、どれだけが**切替の事件（装填した head をほどく費用と、その切替の押し）**か。

ViT 箱では課題 30 までの遅れが全部 head の側だった（head を 0 に戻すと新品より速い、5/5 seed）。V13 §3 の段④→⑤「沈んだ unit は応答を失い、学び直しが削れる」は、読み出しへの経路がその層だけのとき（MLP・CNN）の主張として残せるか。残せるかどうかは、MLP で head を 0 に戻しても遅れが残るかで決まる。MLP・CNN には、切替で head を 0 に戻す対照が一本も無い（spec/ と results/ を grep した限り）。

## 3 腕（切替 t−1 → t ごと。t = 2〜30）

課題 t の頭で、継続網の θ と Adam 状態（m・v・step）を複製してから枝を回す。本線 S は最後に回し、枝は本線に触らない。

| 腕 | 体 θ | 体の Adam | head W₂・b₂ | head の Adam | 初期値 | ミニバッチ順 | 回す課題 |
|---|---|---|---|---|---|---|---|
| S | 引き継ぐ | 引き継ぐ | 引き継ぐ | 引き継ぐ | — | engine の順 | 1〜30（本線） |
| Sb | 引き継ぐ | 引き継ぐ | 引き継ぐ | 引き継ぐ | — | 別の順 | 21〜30 |
| H0 | 引き継ぐ | 引き継ぐ | **0** | **0（m・v・step）** | — | engine の順 | 2〜30 |
| H0b | 引き継ぐ | 引き継ぐ | 0 | 0 | — | 別の順 | 21〜30 |
| H0k | 引き継ぐ | 引き継ぐ | 0 | **引き継ぐ**（ViT の R0 と同じ） | — | engine の順 | 21〜30 |
| H0A | 引き継ぐ | **0** | 0 | 0 | — | engine の順 | 2〜30 |
| fa | 新品 | 新品 | 新品 | 新品 | 乱数列 a | engine の順 | 1〜30 |
| fb | 新品 | 新品 | 新品 | 新品 | 乱数列 b | engine の順 | 21〜30 |

- H0 の約束: head の重みと bias を 0 にし、head の Adam 状態（m・v・step）も 0 にする。体の θ と体の Adam 状態はそのまま。head が厳密に 0 なので最初の 1 更新は体の勾配が厳密に 0 で、体は前の課題から持ち越した Adam の運動量だけで動く。head が育ってから体が動く。最初の数更新だけで読まない。
- H0k は ViT の R0/R0L と同じ約束（重みだけ 0、Adam 状態は残す。`analysis/vit_long_1024/run.py` は `reset_head` で重みだけ 0 にし、optimizer は走の頭で一度作ったまま）。H0 との差を記録する。
- fa・fb の新品の初期値は engine と同じ分布（一様 ±1/√d_in）、乱数列は `head0_mlp_1108|fresh_init|{a|b}|{task}|{seed}`。ラベルは課題 t のもの、ミニバッチ順は engine の順。
- 「別の順」は `head0_mlp_1108|batch_b|{task}|{seed}` から引く。Sb・H0b は同じ出発状態からの取り直しで、S・H0 の量のばらつきを測るためにある。
- 課題 1 は S と fa だけ（切替が無い）。

## 4 測るもの（走ごと）

- 更新ごとのミニバッチの CE 損失（更新の前の値）。4,000 個。
- 10 更新ごとに 1,200 枚全部の訓練精度と CE 損失（更新 0・10・…・4,000 の 401 点）。
- 課題の頭と末で、unit ごとの位置 m_i = w_i·x̄ + b_i（float64）、開いた割合 p⁺_i（z > 0 の入力の割合）、前活性の幅 σ_i（1,200 枚の SD）。head の Frobenius ノルム。

集計（judge.py、float64）は 3 相で、新品の同じ相と並べる（[[plasticity-loss-three-phases-1020]]）。

| 相 | 量 | 定義 |
|---|---|---|
| (1) スパイク | spk | 更新 0〜4 のミニバッチ損失の平均 |
| (2) 速さ | A100・A1000 | 更新 100・1,000 の訓練精度 |
| (2) 速さ | T20・T50・T90 | 訓練精度が初めて 0.2・0.5・0.9 以上になった更新。届かなければ 4,010 と置く（打ち切り） |
| (3) 漸近 | A_end・L_end | 更新 3,510〜4,000 の 50 点の訓練精度・損失の平均 |

**主量** ρ_A（課題 t ごと）:

ρ_A = (A_end[f] − A_end[H0]) / (A_end[f] − A_end[S])

- ρ_A ≈ 1: head を替えても漸近が戻らない。遅れは体の側。
- ρ_A ≈ 0: head を替えると新品に並ぶ。遅れは切替の事件（装填の費用と、その切替の押し）の側。
- 課題 21〜30 では A_end[S] は S と Sb の平均、A_end[H0] は H0 と H0b の平均、A_end[f] は fa と fb の平均。
- 同じ式で ρ_1000（A1000）も出す。T90 は打ち切りが多いので比にしない。

## 5 判定（課題 21〜30 の 10 切替、活性化 × seed ごと）

閾値は固定値を置かず、取り直しのばらつきから導く（[[threshold-derivation-rule]]）。

- ばらつきの推定: 対にした取り直しの差から、σ_f² = mean((A_fa − A_fb)²)/2、σ_H² = mean((A_H0 − A_H0b)²)/2、σ_S² = mean((A_S − A_Sb)²)/2（課題 21〜30 の 10 対）。
- 1 切替の ρ_A の標準誤差（デルタ法、各腕は 2 本の平均なので分散は半分）: s_ρ² = [σ_H²/2 + σ_f²/2 + ρ̃²(σ_S²/2 + σ_f²/2)] / D̄²。D̄ は分母 A_end[f] − A_end[S] の 10 切替の平均、ρ̃ は 10 切替の中央値。
- 10 切替の中央値の標準誤差: SE = 1.25 s_ρ / √10。帯は ρ̃ ± 2 SE。
- 可検定性の床: D̄ > 10 · max(σ_S, σ_f)。満たさなければ NOT_TESTABLE（S に遅れが無い）。

| 判定 | 量 | ラベル |
|---|---|---|
| J1 漸近 | ρ_A の中央値と帯 | 帯の下端 > 1/2 → **BODY_SIDE**。帯の上端 < 1/2 → **LOADING_SIDE**。それ以外 → MIXED。帯が 1 を含むか ρ̃ > 1 なら **FULL_BODY** を併記（head を替えても漸近は 1 点も戻らない） |
| J2 速さ | ρ_1000 の中央値と帯（同じ算術、A1000 で） | 同じラベルに _SPEED を付ける |
| J3 スパイク | H0 の spk − fa の spk の中央値 | |中央値| ≤ 2 σ_spk（σ_spk² = mean((spk_fa − spk_fb)²)/2）→ **SPIKE_GONE**。それ以外 → SPIKE_REMAINS。S の spk − fa の spk も並べる |
| J4 H0A | A_end[H0A] − A_end[H0]、A1000 の差 | 記録。|中央値| ≤ 2 σ_H なら「Adam の記憶の分は見えない」 |
| J5 H0k | A_end[H0k] − A_end[H0]、A1000 の差 | 記録。ViT の約束との差 |

主判定は J1。活性化の判定は seed 0・1 が同じラベルのときだけ確定、割れたら「割れ」と書く。

## 9 やらないこと

- H0 を手法として語らない。head を 0 に戻すのは診断の対照で、ViT の R0 と同じ役。
- この箱の ρ を CNN・ViT・深い MLP へ一般化しない。箱 2（RL-CIFAR MLP、GPU）は別の段で、GPU が空いてから Issa に聞いて決める。
- ρ_A < 1 の分を「装填の費用」と「その切替の押し」に分けない。この走ではどちらも H0 で同時に消えるので分けられない。分けるなら別の腕が要る。
- 課題 2〜20 の ρ は図と表に出すが、判定に使わない（取り直しが無いので帯が出せない）。
- 更新 0〜4 のスパイクだけ、更新 100 だけで「救われた」と言わない。
