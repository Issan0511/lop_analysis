## 1. 問い

位置の drift 場の零点（安定不動点）ζ\* は W にどう依存するか。

  **ζ\*(W) = α + β·W**

- **β ≈ 0** なら場は **ζ で閉じる**（1 次元の力の法則がある）
- **α ≈ 0 かつ β ≈ −1** なら **上端則**（座る場所は上端が折れ目 ＝ ζ = −W）
- どちらでもなければ **affine**（W に追随するが比例ではない）

## 4. 測り方（`zeta_field_0908` からの 3 つの訂正）

腕ごとに、(タスク, ユニット, seed) を **W の六分位**（三分位でなく）に分ける。六分位ごとに:

1. ζ を**十分位ビン**に切り、各ビンで E[N] とビン中央値 ζ を出す（1 ビン 20 点未満は捨てる）。
2. **訂正 A: プロファイルに単調（非増加）回帰（PAVA）を掛けてから**零点を取る。
   W を固定すれば drift は ζ について減少するはず、という制約を課す。これで零点が一意に決まり、`zeta_field_0908` の「1 本のビンが揺れると交差が 2 本になって nan」（誤り 2）が消える。
3. **訂正 B: 床は「両端のビン」でなく「プロファイルの振れ幅」に掛ける。**
   単調化した後の **max E[N] − min E[N] > 0.02/タスク**、かつ **max > 0 かつ min < 0**（＝両符号を跨ぐ）。
4. **訂正 C: 床は六分位ごとに評価し、腕の判定には 6 本中 4 本以上あればよい**（全部の AND にしない。複合 AND は 3 回落ちている）。
5. 有効な六分位の (W̃, ζ\*) に**重み付き最小二乗**（重み = その六分位の点数）で直線を当て、**β** と **α** を得る。無次元の切片を **α̂ ≡ α / W̃_all**（W̃_all = その腕の窓内 W の中央値）とする。

同じことを p̂_up についても行い **p\*** を取る（第 2 判定）。

## 9. 追補 1（実装中・**持ち出し腕を 1 度も読まずに**登録）

検査が §4 の**訂正 A（単調回帰）そのものを否定した**ので、走らせる前に取り下げる。

### 9-1. 単調回帰（PAVA）は棄却する — **物理が単調でない**

`zeta_field_0908` で見た実プロファイル（`LRoff0` 第 1 三分位）に単調（非増加）当てはめを掛けると:

```
生      : +0.0154 +0.0282 +0.0236 +0.0162 +0.0148 +0.0026 -0.0020 -0.0018 +0.0064 +0.0024
単調化後: +0.0224 +0.0224 +0.0224 +0.0162 +0.0148 +0.0026 +0.0013 +0.0013 +0.0013 +0.0013
```

**全域が正になり、零点が消える。**

理由は物理のほう: **折れ目の上下に線形域が 2 つあり、どちらも釘付け**（[[命題1-5_上端則結果_0905]]「線形は釘付け」・[[前活性1次元のdrift則_結果_0907]]「跨ぎゼロ群は full-batch で −0.0004」）。したがって E[N|ζ] は

  低い ζ（全部折れ目の下・線形）→ **上がる** → 跨ぎ帯 → **沈む** → 高い ζ（全部上・線形）→ **0 へ戻る**

で**単調ではない**。単調制約は沈下の谷を上側の平坦域に吸収してしまう。**制約を課すなら物理を先に確かめる。**

PAVA の実装と検査は「棄却した推定量」として残し、診断としてだけ出力する。

### 9-2. 訂正 A を差し替える — 六分位が有効な条件を 3 つにする

六分位が有効なのは、**生のプロファイルが**次を**すべて**満たすとき:

1. **`+ → −` の交差がちょうど 1 本**（＝安定不動点が定義できる。`− → +` は不安定側なので数えない）
2. **振れ幅 max − min > 0.03/タスク**（§4 の 0.02 から**引き上げる**）
3. **Spearman ρ(ζ, E[N]) ≤ −0.6**（＝そもそも右下がりである）

**2 を 0.02 → 0.03 に上げた理由**: 六分位だと 1 ビンあたり ~5,300 点で E[N] の標準誤差は 0.45/√5300 ≈ 0.006。10 ビンの純雑音でも振れ幅は ~0.019 出るので、**0.02 では雑音を弾けない**。0.03（雑音の 1.6 倍）に上げ、さらに条件 3 で「右下がりであること」を要求して二重に締める。

**この 3 つは六分位の中の AND** であって、腕の判定は 6 本中 4 本・11 本中 5 本のまま（訂正 C は維持）。

### 9-3. 検査で確かめたこと

- PAVA を採用していたら実プロファイルの零点が消えていた（`test_pava_would_have_destroyed_the_crossing`）

- 振れ幅だけ大きくて右下がりでない列は条件 3 で落ちる（`test_spearman_floor_rejects_a_flat_but_wide_profile`）
