## 0. 何を決めるか

[[幅クランプはドリフトを上げるか_結果_0912]] で、幅クランプは**一歩の大きさも向きも第 2 層のノルムも変えずに**目減りを 2.28 → 0.60 pt にし、絶対精度を +1.6 pt 上げた。射影が消した量のうち勾配方向は **0.5%**、つまり**勾配はユニットの長さを押さず、向きを押している**。

**1 次元の候補（回る速さ説）**: leaky は $\varphi(cz)=c\varphi(z)$ なので、ユニット $i$ の働きを決めるのは $\tilde W_i$ の**向き**で、長さは下流が吸収できる。Adam の一歩は $\lVert\Delta\tilde W_i\rVert \approx \mathrm{lr}\sqrt{784}$ と**長さに依らずほぼ一定**。したがって 1 更新あたりの向きの変化は

$$\omega \;=\; \lvert\Delta\theta_i\rvert \;\approx\; \frac{\lVert\Delta\tilde W_i\rVert_{\perp}}{\lVert\tilde W_i\rVert} \;\propto\; \frac{\mathrm{lr}}{\lVert\tilde W_i\rVert}$$

**長いユニットは同じ一歩で回る角度が小さい。** 1 タスクは 625 更新しかないので、長いほど回りきれずにタスクが終わる。**幅の害の正体はこれ（1 次元のスカラー $\omega$）だ、というのが本走の説。**

**決着のさせ方**: クランプの高さ $\kappa$ と lr を**逆向きに同じ倍率で**動かす。$\omega \propto \mathrm{lr}/\kappa$ なので、$(\kappa, \mathrm{lr})$ と $(2\kappa, 2\mathrm{lr})$ は**長さが 2 倍違うのに $\omega$ が同じ**。回る速さ説が正しければ、**この対は目減りも一致する**。

## 1. 走

箱 B（Permuted MNIST・784–100–100–10・leaky a=0.1・Adam・batch 16・625 更新/タスク・正則化なし・CPU 1 スレッド）。t1–120・seed 0–2。クランプは t21 から、`wclamp`（$\lVert\tilde W_i\rVert$ を t20 の値の $\kappa$ 倍へ毎更新射影）。

| 腕 | κ | lr | ω ∝ lr/κ | 役割 |
|---|---:|---:|---:|---|
| `N0` | — | 1e−3 | — | 参照・**G1 錨**（`elu_growth_0909/LR`） |
| `W1` | 1.0 | 1e−3 | **1.0** | 既知のクランプ腕・**G1 錨**（`grad_coherence_0911/N0w` と bit 一致） |
| `W1h` | 1.0 | 0.5e−3 | **0.5** | 遅い対の片方（短い） |
| `W2` | **2.0** | 1e−3 | **0.5** | 遅い対の片方（**長い**） |
| `W1d` | 1.0 | 2e−3 | **2.0** | 速い対の片方（短い） |
| `W05` | **0.5** | 1e−3 | **2.0** | 速い対の片方（**もっと短い**） |

6 腕 × 3 seed = **18 走**。

**分岐点の設計（実装時に修正・走る前）**: **t1–20 は全腕が参照の lr = 1e−3 で走り**、そこから枝分かれする。クランプの高さは**全腕共通**の $\kappa\cdot c_{\rm ref}$（$c_{\rm ref}$ は参照腕の t20 ノルム）で、lr は t21 から腕ごとの値になる。当初は各腕が自分の t20 ノルムを基準にする設計だったが、**lr を下げると t20 のノルムも小さくなり κ と lr が独立でなくなる**（スモークで `W1h` の ω 比が 0.50 でなく 0.76 になって露見）。この修正で $\omega\propto \mathrm{lr}/\kappa$ が設計どおりになり、**全腕の t1–20 が参照を bit 再現する**ので G1 も強くなる。

**決定的な対**: 遅い対 `W1h` 対 `W2`（長さ 2 倍違い・ω 同じ）、速い対 `W1d` 対 `W05`（長さ 2 倍違い・ω 同じ）。

**新しい測定**（late 窓 t61–120・毎更新・ユニット別）:
- **ω_step**: 1 更新での $\tilde W_i$ の向きの変化角 $\lvert\Delta\theta_i\rvert$（射影後の正味）の平均 [rad/更新]
- **Θ_task**: タスク開始から終端までの $\tilde W_i$ の**正味の回転角** [rad]
- **turn_eff** = Θ_task / (625·ω_step)（角度版の経路持続。記述のみ）
- 既存の量（精度・CE@0/20・drift2_net・κ2・S²・ρ・graw²・‖W̃ᵢ‖・ゲート・‖W2‖）も同じ窓で取る

## 3. 判定（事前登録・seed 3/3 一致でラベル、混在は `MIXED`）

すべて満たせば `MANIPULATION_OK`。**ゲートの適用範囲（実装時に明示・走る前・データ無し）**: K0.1–K0.3（クランプの実効性・ノルムが κ に比例・ω が設計どおり反応）は **K1–K4 すべて**を塞ぐ。**K0.4（対の内部で ω が一致）は K1 だけを塞ぐ。** K4 は「対の ω 一致が厳密でなくても答えが出る形」として足したものなので、K0.4 で塞ぐと趣旨が失われる。K2・K3・K4 は実測の ω を使うので K0.4 に依存しない。`verdict.csv` には厳しい読み（K0.4 も全部を塞ぐ）での結果も `K0_strict` として併記する。
**可検定性**（K0 とは独立に記録し、外れても K1–K3 は判定する）: L(`N0`) − L(`W1`) ≥ 1.0 pt（前走の実測は 1.57/1.68/1.66）。

**K1 決定的 — 回る速さが長さを代替するか**: 遅い対 $d_{\rm s}$ = L(`W1h`) − L(`W2`)、速い対 $d_{\rm f}$ = L(`W1d`) − L(`W05`)。
- |d_s| < 0.3 かつ |d_f| < 0.3 pt → **`OMEGA_EXPLAINS_WIDTH`**（長さは ω を通してのみ効く）
- |d_s| ≥ 0.7 または |d_f| ≥ 0.7 pt → **`OMEGA_FAILS`**（長さそのものが効いている）
- 他 → `K1_PARTIAL`

**K2 ω は腕を並べるか**（5 つのクランプ腕）: Spearman(ω_step, L)。
- ≤ −0.8 → **`OMEGA_ORDERS`**／≥ −0.2 → `OMEGA_DOES_NOT_ORDER`／他 `K2_PARTIAL`

**K3 正味の回転角のほうが良い指標か**: Spearman(Θ_task, L) を K2 と併記。|Spearman(Θ_task)| が |Spearman(ω_step)| より 0.2 以上大きい → `NET_TURN_BETTER`／0.2 以上小さい → `STEP_RATE_BETTER`／他 `K3_TIE`。

**K4 ω を効かせた後に長さは残るか**（**実装時に追加・走る前・データ無し**。K0.4 の対の ω 一致が厳密でなくても答えが出る形）:
5 つのクランプ腕 × 3 seed = 15 点で、**実測の** $\log_2\omega$ に L を最小二乗で当てはめ、その残差と $\log_2\lVert\tilde W_i\rVert$ の Spearman を取る。
- |Spearman| ≤ 0.3 → **`LENGTH_ADDS_NOTHING`**（長さは ω を通してしか効かない）
- ≥ 0.6 → **`LENGTH_ADDS_BEYOND_OMEGA`**（長さそのものが残る）
- 他 → `K4_PARTIAL`

**可検定性**: 発散した腕seed は `DIVERGED`。late 窓のタスク内 CE 改善が 90% 未満なら `LEARNING_BROKEN` として判定から外す（`W1d` は lr 2 倍、`W05` は κ 0.5 なので要注意）。

## 4. 進捗ゲートと変異対照

- **G1**: **全腕の t1–20 が `elu_growth_0909/LR` と maxabs ≤ 1e−10**（共通の分岐点）。`N0` は t1–120 の全体で、**`W1` は `grad_coherence_0911/N0w` と per-unit で 0.0**（κ と lr を可変にしても既定値の腕が動いていない証拠）。件数ガード付き。変異対照は初期値 +1e−3 で 1e−8 超。
- **G2 角度の検査**（実装時に形を変更・走る前）: $\cos\Delta\theta_i \in [-1,1]$ を厳密に満たす。**報告する角度そのものを 2 通りで突き合わせる**: 内積経由 $\theta^{\rm dot}=\arccos$ と、小角で数値的に安定な弦経由 $\theta^{\rm chord}=2\arcsin\!\big(\lVert\hat a-\hat b\rVert/2\big)$（**先に正規化する**ので、ノルムが育つ無クランプ腕でも成り立つ） が相対 **1e−6** で一致。（当初は弦の恒等式 $\lVert\Delta\tilde W\rVert^2=2\lVert\tilde W\rVert^2(1-\cos)$ を相対 1e−8 で課したが、$\theta\sim3\times10^{-3}$ rad では $\lVert\Delta\tilde W\rVert^2$ の計算に桁落ちが入り、相対誤差が $\varepsilon_{64}/\theta^2$ のオーダーで出る。スモークの実測 1.12e−8 はこの下界どおりで、**装置ではなく私の許容値が誤っていた**。角度同士の突き合わせは桁落ちを含まない。）Θ_task ≤ Σ|Δθ| の球面三角不等式を 1e−8 で満たす。

- **G4 lr**: 各腕の lr が設計値に相対 1e−12 で一致。κ は `base['c']` の定数倍として作り、**committed の `apply_clamp` は編集しない**。

## 7. 限界（結果前に明記）

- t120・3 seed・leaky のみ・κ は 3 水準（0.5/1/2）・lr は 3 水準。
- **κ≠1 は t21 で ‖W̃ᵢ‖ を不連続に κ 倍する。** leaky は正斉次なので下流が吸収しうるが、過渡は残る。late 窓は t101–120 なので 80 タスク後だが、`acc(t21–25)` を副測定で記録して過渡の大きさを開示する。
- lr を動かすと ω 以外（Adam の実効温度・$\hat v$ の時定数との関係）も動く。**対は κ と lr を逆向きに動かすので、ω 以外の効果は対の内部で打ち消されない。** これは本走の主要な交絡で、K1 が `OMEGA_FAILS` でも「lr の副作用」で説明がつく可能性を排除できない。
- ω は行平均の量。ユニット別の分布は副測定。
