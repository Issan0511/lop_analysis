## 0. 何を決めるか

[[勾配の揃いを直接動かす_結果_0911]] で、第 1 層の勾配に不偏ノイズを注ぐと **‖W̃‖ は縮むのに損失は増えた**（N2 対 N0: 幅 7.38 対 8.08、目減り 3.03 対 2.28 pt）。lr を下げた腕は幅も損失も減る。同じ「幅が縮む」で結果が逆になる。

**Issa の仮説**: ノイズは学習を阻害することで W が大きくなることを防ぎ、しかしノイズのせいで**せっかく作った学習が壊される**から駄目。

**走る前に手元のデータで分かったこと**（[[勾配の揃いを直接動かす_結果_0911]] の再集計・事後）:
1. N2 − N0 の精度差は t1–5 で −0.81 pt、t101–120 で −1.54 pt と**倍に開く**。lr 対照は −1.54 → −0.35 と**追いつく**。ノイズの害には「即時の下げ」と「積もる成分」の両方がある。
2. Adam の一歩を**ドリフト**（揃った成分）と**拡散**（ランダム成分）に分けると、c=2 では拡散が **77%**（解析式 0.0546 対 実測 0.0541）。歩幅は同じで中身が入れ替わっている。
3. 拡散はタスクあたりの正味移動 D² の **3%** しか占めない。**W が縮むのはドリフトが薄まったから**（D² 1.40 → 0.75）。これは Issa の「学習阻害で W が育たない」そのもの。ただし lr 対照もドリフトを薄めて幅を縮め、そちらは可塑性が**良く**なるので、**ドリフトの薄まりは害でなく、害は拡散の側**にある。

**両者が一致する点**: W が縮むのはドリフトの薄まり（学習の阻害）。損失が増えるのはランダム成分（拡散）。

**分かれる点**: **拡散が壊すのは何か。**
- **Issa**: 蓄積された構造（タスクをまたいで持ち越すもの）。害は**持続**し、ノイズを止めても戻らない。
- **Claude**: 読み出し層（W2・W3）が、毎歩ジッタする第 1 層の表現を追い切れないこと。害は**追随の失敗**で、ノイズを止めれば数タスクで回復する。ただし §0-1 の「差が積もる」は Claude に不利な観測で、その場合は「積もるが早く戻るもの」（Adam の状態・読み出しの較正）を候補にする。
- **V9 の幅説（対照）**: 幅が縮めば良くなるはず → すでに反証済み（N2 が悪い）。

## 2. 量（登録）

- gap(t) = acc_X(t) − acc_N0(t)（seed 対・タスク終端・pt）。窓は 5 タスク中央値。
- **onset**: g_imm = gap(t61–65)、g_late = gap(t101–120)（`N2on`）。
- **offset**: 回復時間 τ = t61 以降で最初に |gap(t..t+4)| ≤ 0.3 pt になる t − 60（`N2off`）。end = gap(t101–120)。
- **損傷** D_X = L(X) − L(N0)、L = acc(t16–20) − acc(t101–120)。
- **拡散の割合** f_diff = late 窓の直交成分二乗和 ÷ 全二乗和（`N2`）。
- **持ち越し** Δce0 = CE@0(X) − CE@0(N0)（late 窓中央値・seed 対）。

## 3. 判定（事前登録・すべて seed 対・3/3 で一致したときだけラベル、混在は `MIXED`）

**F0 操作チェック**: `N2` の f_diff ∈ [0.60, 0.90] かつ `N2post`・`N2step` の拡散エネルギーが `N2` の ±30% → `MANIPULATION_OK`。外れたら該当腕の判定は `NOT_TESTABLE`。可検定性: D_N2 ≥ 0.5 pt（前走では 0.50–1.09）。

**F1 onset（害は即時か積もるか・`N2on`）**: g_imm と g_late の比 r = g_late / g_imm（両方 < 0 のとき）。
- r ≤ 1.3 → `DAMAGE_IMMEDIATE_ONLY`
- r ≥ 1.8 → `DAMAGE_ACCUMULATES`
- 他 → `DAMAGE_BOTH`
（参考: 前走の `N2` は 1.54/0.81 = 1.9）

**F2 offset（止めたら戻るか・`N2off`）**:
- τ ≤ 10 → `RECOVERS_FAST`
- 10 < τ ≤ 40 → `RECOVERS_SLOW`
- 60 タスク以内に |gap| ≤ 0.3 に達しない → `DAMAGE_PERSISTS`
- 加えて end ≥ +0.3 pt（N0 を**上回る**）→ `OVERSHOOTS`（幅を低く保ったぶん得をした）を併記

**F3 拡散の形（`N2post` 対 `N2step`）**: D_post と D_step。
- D_post ≥ 0.7·D_N2 かつ D_step ≤ 0.4·D_N2 → `QUIET_COORD_KICKS`（静かな座標を蹴ることが害）
- 両方 ≥ 0.7·D_N2 → `ANY_DIFFUSION_HURTS`
- 両方 ≤ 0.4·D_N2 → `DILUTION_ALSO_NEEDED`（拡散だけでは害にならず、ドリフトの薄まりと組んで初めて害）
- 他 → `F3_PARTIAL`

**F4 持ち越し（何が壊れるか）**: `N2` の Δce0 が late 窓で ≥ +0.05 nat、かつ t21–40 より t101–120 が大きい → `CARRYOVER_DAMAGED`（置換不変な状態が壊れている）／|Δce0| < 0.02 → `CARRYOVER_INTACT`／他 `F4_PARTIAL`。

**F5 タスク内の形**: `N2` − `N0` の CE 差を @0・@20・@100・@300・@625 で並べ、差が @0 で最大で減っていく → `STARTS_WORSE_CATCHES_UP`／差が @300–@625 で最大 → `ERODES_LATE`（当てはまった後に削られる）／他 `F5_FLAT`。

## 4. 進捗ゲートと変異対照

- **G1**: `N0` は `elu_growth_0909` LR と maxabs ≤ 1e−10（`cnorm_i` は 0.0）。**`N2` は `grad_coherence_0911/N2` の per-unit 6 配列 × t1–120 と 0.0**（同じ系列を同じ回数引くので bit 一致するはず。計装が軌道を動かしていないことの証明）。変異対照は初期値 +1e−3。
- **G2**: 前走の G2（不偏性・分散・対照）を継承。`N2post` の加法ノイズは RMS が 0.205·lr の ±1%、`N2step` の乗法ノイズは E[(c′ξ)²] が 0.82² の ±1%（各 2000 回の標本で）。
- **G3**: ドリフト＋拡散の二乗和が実現した一歩の二乗和と 1e−10 で一致（射影の恒等式）。`N2post`・`N2step` では注入後の一歩と注入前の一歩の差の RMS が設計値に一致。
- **G4**: スケジュール腕で c=0 の区間に `gradnoise` が一度も引かれていない（生成器の状態が区間の前後で同一）。`N2off` の t1–60 は `N2` と bit 一致（同じことをしている）、`N2on` の t1–60 は `N0` と bit 一致。
- **G5**: 帳簿（ρ の Cauchy–Schwarz・望遠鏡和）継承。発散 0、CE 改善率 ≥ 0.9。
