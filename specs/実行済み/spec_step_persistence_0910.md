# spec_step_persistence_0910 — タスク内の経路持続 ρ はどのスケールで作られるか

## 0. 位置づけ

`gate_scale_invariance_0909` §6 の未登録仮説「Snake はゲートの振動で座標ごとの勾配の符号が揃わず、Adam の m̂/√v̂ が小さい＝正規化後の歩幅が短い」を、既登録データ（同走の `steps2`・`persist` 列）で判定した。**棄却。** 歩幅 S² の腕間の変動係数は 5.1% しかない。

D² の腕差と時間成長は、ほぼ全部が **ρ = D²/S²（タスク内 625 歩の経路持続）** にある。本 spec は ρ の作られ方を測る。仮説の中身（ゲートで向きが揃わない）は死んでおらず、効くスケールが Adam のモーメンタム窓（≈10 歩）ではなくタスク全体（625 歩）に移った、という可能性が残る。

## 1. 動機となる事後観測（既登録データの再集計。**判定には使わない**）

t60–120 平均、3 seed:

| 腕 | D² | S² | ρ = D²/S² | N |
|---|---:|---:|---:|---:|
| LR | 1.303 | 0.0267 | 48.8 | 7.35 |
| LR001 | 1.187 | 0.0247 | 48.1 | 7.19 |
| LR03 | 1.071 | 0.0268 | 39.9 | 6.93 |
| ELU1 | 1.116 | 0.0237 | 47.2 | 7.40 |
| LIN | 0.826 | 0.0257 | 32.1 | 6.30 |
| SN02 | 0.820 | 0.0241 | 34.1 | 6.33 |
| SN06 | 0.676 | 0.0238 | 28.4 | 5.27 |
| SN15 | 0.720 | 0.0241 | 29.8 | 6.12 |

- 腕間 CV: D² 24.2% / **S² 5.1%** / ρ 22.2%。D² の腕間 log 差のうち ρ が担う割合の中央値 **0.83**。
- 時間方向（LR、t20→120）: S² +11%、ρ +45%、D² +60%。ρ が担う割合 **0.79**。
- ρ は 625 歩の**相互整列**そのもの: 平均ペア cos = (ρ−1)/624。LR 0.0766、SN06 0.0439、LIN 0.0499。
- ρ は N（Spearman +0.64）より σ（+0.885）・z̄（−0.913）に並ぶが、**どの変数でも 1 本に崩れない**（log ρ の残差 sd: N で 0.339、σ で 0.246）。腕内の傾きと腕間の傾きが一致しない（σ で 0.16 対 0.54、N で 0.27 対 1.89）。

## 2. 問い

625 歩の経路は、どのラグで整列を失うか。腕差はその**記憶の長さ**に出るのか、**全ラグに一様な整列の振幅**に出るのか。

## 3. 測定量

TRACK タスク（20, 30, …, 120）で、第 1 層 W1 の**中心化された適用済み更新** ũ_s ∈ R^{100×784}（s = 1…625, ũ_s = (θ_{s+1}−θ_s) の行平均除去）について。既存の D² と同じく **(·).sum(1) してから 100 ユニット平均**の規約を使う。

- **S² = Σ_s ‖ũ_s‖²** — 一歩の予算（既存 `steps2` と一致すべき）
- **D² = ‖Σ_s ũ_s‖²** — タスク増分（既存 `D2` と一致すべき）
- **ρ = D²/S²** ∈ [0, 625]（1 = 拡散、625 = 弾道）
- **ブロック因子 G(b)** = ⟨‖Σ_{s∈block} ũ_s‖²⟩_blocks / (b · S²/625)、b ∈ {1, 5, 25, 125, 625}。G(1) ≡ 1、G(625) ≡ ρ は恒等。
- **ラグ相関 A(τ)** = ⟨cos(ũ_s, ũ_{s+τ})⟩_s。短ラグ τ ∈ {1,2,3,4} は逐次累積、長ラグは 5 歩ごとに保存した 125 本の総当たり行列から τ ∈ {5,10,…,620}。
- **交差項の分配**: X = D² − S²（= 全ペア内積の和）。X_short = τ < 50 の寄与、X_long = τ ≥ 50 の寄与。X = X_short + X_long は恒等。
- **κ1 = ⟨|m̂|/(√v̂+ε)⟩、κ2 = ⟨(m̂/(√v̂+ε))²⟩**（W1 の全座標・全ステップ）— §6 仮説の直接量
- **graw = ⟨‖∇W1 の行‖⟩**（Adam 前の生勾配）
- **ゲート相関 gcorr** = corr(φ′(z_start), φ′(z_end))（同じ 512 プローブ・同じ置換、タスク開始時と終了時）
- 参考: N, D², σ, z̄, acc（既存と同じ定義）

## 4. 腕・seed・走

`LR`(leaky .1)・`LR001`(.01)・`LR03`(.3)・`SN02`(snake .2)・`SN06`(.6)・`SN15`(1.5)・`ELU1`(elu 1)・`LIN`(linear) × seed 0,1,2 = **24 走 × 120 タスク**。

`R`(ReLU) は 11/100 ユニット凍結で平均が 2 集団の混合になるため除外（`gate_scale_invariance_0909` §2）。同 seed の全腕は初期値・置換列・抽出・バッチ順を共有（`H.init_params(seed)` / `H.stream(role,seed)` は腕を取らない）。host は編集しない。

## 5. 事前登録の予測と判定

判定はすべて **t = 100, 120 の 2 タスク × 3 seed** の平均で行う。

### V1 `MEMORY_LENGTH` — 整列はどのラグに住むか
X_long/X（τ ≥ 50 の寄与割合）を全腕で見る。
- `LONG_MEMORY` … 中央値 ≥ 0.60
- `SHORT_MEMORY` … 中央値 ≤ 0.35
- `MIXED` … その他

**予測: `LONG_MEMORY`。** 根拠: Adam のモーメンタムは β₁ = 0.9 で実効 10 歩、これだけなら ρ ≲ 20。実測 ρ = 28–55 はそれを超える。全ラグに一様な平均ペア cos 0.077 は ρ = 1 + 0.077×624 = 49 を厳密に再現し、LR の実測 48.8 と一致する。よって「タスク中ずっと同じ向きに降りるコヒーレントな漂流」が主成分のはず。

### V2 `ARM_LOCUS` — 腕差はどこから来るか
LR と SN06 の X の差を短ラグ／長ラグに分解: f_long = (X_long^LR − X_long^SN06)/(X^LR − X^SN06)。
- `LONG` … f_long ≥ 0.65
- `SHORT` … f_long ≤ 0.35
- `BOTH` … その他

**予測: `LONG`。** 根拠: 短ラグの整列は Adam のモーメンタムが作り、S² が腕間で 5% しか違わない以上、モーメンタム窓内の挙動も腕間で近いはず。差は漂流の振幅に出る。

### V3 `STEP_BUDGET_INVARIANT` — §6 仮説を新測定で正式に閉じる
κ2 の腕間 CV。
- `CONFIRMED` … CV ≤ 10%
- `REOPENED` … CV ≥ 25%

**予測: `CONFIRMED`。** あわせて S² が既登録 `steps2` を ≤1e−6 で再現すること（外部整合）。

### V4 `GATE_ROTATION` — 残ったゲート説の検定
gcorr と ρ の腕間 Spearman（8 腕）。
- `GATE_EXPLAINS` … |Spearman| ≥ 0.7 かつ符号が負（ゲートが動く腕ほど ρ が小さい）
- `GATE_FAILS` … |Spearman| < 0.5

**予測: `GATE_FAILS`。** 根拠: LIN はゲートが存在せず gcorr = 1.0（回転ゼロ）なのに ρ = 32.1 と低い。SN06 は gcorr が最も低いはずで ρ も最低（28.4）だが、LIN の存在で単調性は既に破れている。**§6 仮説のゲート部分は 625 歩スケールでも落ちると予想する。**

### V5 `SCALE_KILLED` — Adam は生勾配の尺度を殺すか（機構の確認）
腕間の変動係数比 CV(graw)/CV(S²)。
- `SCALE_KILLED` … ≥ 2.0
- `SCALE_SURVIVES` … < 1.2

**予測: `SCALE_KILLED`。**

## 6. 検査（すべて変異対照つき）

| # | 検査 | 合格 | 変異対照 |
|---|---|---|---|
| G1 | `LR` が既存 committed checkpoint 42 点を再現 | params maxabs **0.0** | init に +1e−3 → ≥1e−4 |
| C1 | Σ_s ũ_s == W̃_end − W̃_start | ≤1e−10 | 1 歩落とす → ≥1e−5 |
| C2 | G(1) = 1、G(625) = D²/S² | ≤1e−12 | b を取り違える → ≥1e−2 |
| C3 | Cauchy–Schwarz: G(b) ≤ b（全 b） | 成立 | — |
| C4 | X_short + X_long == X | ≤1e−10 | ラグ境界をずらす → ≥1e−4 |
| C5 | S²(uncentered) == lr²·Σ_s Σ_j (m̂/(√v̂+ε))²（Adam の一歩の形） | ≤1e−12 | ε を 1e−6 に → ≥1e−6 |
| C6 | S²・D² が既登録 `gate_scale_invariance_0909` と一致（同 seed・同腕） | ≤1e−6 | 別 seed と比較 → ≥1e−3 |
| C7 | 測定の非侵襲（logging on/off で終端 params） | **0.0** | measure 時に +1e−9 → >0 |
| C8 | φ′ が autograd と一致（全腕） | ≤1e−15 | 別腕の φ′ → ≥0.9 |

## 7. 限界（事前に宣言）

- 判定は t = 100, 120 のみ。ρ の時間発展の形は報告のみ。
- ラグ相関の長ラグは 5 歩間隔の粗視化。τ < 5 は別扱いなので、τ = 5 の前後で定義が変わる。
- SGD 対照が無いので「Adam だから」は言えない。κ2 の腕間不変性が Adam の構成に由来するか経験的事実かは分離できない。
- β₁ を振っていないので、短ラグ整列がモーメンタム由来であることは直接示せない（V1 で ρ ≲ 20 という上限見積りを使うのみ）。
- 腕内と腕間で ρ の N・σ 依存の傾きが一致しない件（§1 末）は本 spec では解けない。ラグ構造がその手がかりを出すかは事後の読みとして扱う。
- 120 タスクは推定天井の手前。
