## 0. 何を決めるか

[[回転を買い戻せるか_結果_0912]] の事後解析で、**「t20 と同じ精度を出すのに要る更新数」は t120 で 3.6 倍**（‖W̃ᵢ‖ は 2.32 倍）と出た。625 更新はそもそも学習しきっておらず（2 周で +1.5〜1.8 pt）、この箱の「可塑性の喪失」のかなりの部分は**同じ学習に要る手数が増えること**として現れる。

**問い**: では毎タスクに十分な手数を与えたら、劣化はどれだけ残るか。**手数で消える劣化（ハンディキャップ）と、手数では消えない劣化（本当の喪失）を分ける。**

**既存データが示す兆候**: 予算 625 の参照は t21–30 → t111–120 で **−1.82 pt**、予算 1250 の `FLAT`（t21 分岐）は **−2.12 pt**。**予算を 2 倍にしても減衰は縮まず、むしろ広がっている。** 予算は精度の水準を持ち上げるが減衰を平らにはしない可能性がある。

## 1. 走

箱 B（Permuted MNIST・784–100–100–10・leaky a=0.1・Adam lr=1e−3・batch 16・正則化なし・CPU 1 スレッド）。**t1 から一貫して**固定予算。seed 0–2。データ予算は全腕同一（1 タスク 1 万枚のプールを `reshuffle` 系列で周回）。

| 腕 | 1 タスクの更新数 | 周回 | 役割 |
|---|---:|---:|---|
| `B1` | 625 | 1 | 参照・**G1 錨**（`elu_growth_0909/LR`・t1–120） |
| `B2` | 1250 | 2 | |
| `B4` | 2500 | 4 | |
| `B8` | 5000 | 8 | 最大 |

4 腕 × 3 seed = **12 走**。**同じ腕の中で序盤と終盤を同じ予算で比べる**のが要で、t21 分岐ではなく t1 から分ける。計装は [[回転を買い戻せるか_spec_0912]] と同じ。

## 2. 量（登録）

**早い窓 = t21–30**、**遅い窓 = t101–120**、窓内は平均、seed 中央値。
- **減衰** $D(B)$ = acc(早い窓, B) − acc(遅い窓, B) [pt]。**両窓とも同じ予算 B。**
- **水準** $A_{\rm late}(B)$ = acc(遅い窓, B)。
- **残る劣化** $D(5000)$。

## 3. 判定（事前登録・seed 3/3 一致でラベル、混在は `MIXED`）

**U0 操作チェック**: `B1` の G1（`elu_growth_0909/LR` と maxabs ≤ 1e−10・360 配列）。全腕で実更新数 = 設計値（厳密）。`reshuffle` 系列が perm/data/batch を汚さない。角度の 2 式突合・三角不等式。発散 0・late のタスク内 CE 改善 90% 以上。
可検定性（独立に記録）: D(625) ≥ 1.0 pt（実測 1.82）。

**U1 決定的 — 予算で減衰は縮むか**: $D(5000)/D(625)$。
- ≤ 0.5 → **`DECLINE_SHRINKS`**（劣化の半分以上は手数で消える）
- ≥ 1.3 → **`DECLINE_GROWS`**（予算を増やすほど減衰が広がる＝複利）
- 他 → `DECLINE_FLAT`

**U2 残る劣化**: $D(5000)$。
- ≤ 0.5 pt → **`COMPUTE_REMOVES_DECLINE`**
- ≥ 1.5 pt → **`DECLINE_SURVIVES_COMPUTE`**
- 他 → `U2_PARTIAL`

**U3 水準は買えるか**: $A_{\rm late}(5000)$ − acc(早い窓, 625)。≥ 0 → `LEVEL_BUYABLE`（8 倍の予算があれば t120 は t20 の参照に届く）／< 0 → `LEVEL_NOT_BUYABLE`。

**U4 複利**: ‖W̃ᵢ‖(遅い窓, 5000) / ‖W̃ᵢ‖(遅い窓, 625)。記述（≥ 1.5 で `COMPOUNDING`）。

**U5 単調性**: D(625) ≤ D(1250) ≤ D(2500) ≤ D(5000) か、その逆か（記述）。

## 5. 事前予測（記名・走る前・各 1 点）

**Claude**:

| 判定 | 予測 | 根拠 |
|---|---|---|
| U0 | `MANIPULATION_OK` | 既存の計装 |
| **U1** | **`DECLINE_GROWS`**（比 1.3〜1.6） | `FLAT` が既に参照より減衰が大きい（2.12 対 1.82）。予算を増やすと W が速く育ち、手数あたりの回転が落ちる |
