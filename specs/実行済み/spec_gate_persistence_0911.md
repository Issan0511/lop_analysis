## 0. 何を決めるか

「負側にいる」と「そこで動けずにくすぶっている」は別である。腕ごとに、低ゲート集団が**固定メンバー**か**交代**かを決め、その滞留の度合いが腕間の損失を並べるかを見る。Snake については、低ゲートの個体が「位相」（2αz̄ᵢ）で決まっているかを見る。

事後の材料（未登録・9/10 夜・Gaussian 近似の E[φ′]・`elu_growth_0909`・t41–120・3 seed 中央値）: ゲート下位 10% の 20 タスク後残留率は leaky 0.50・ELU1 0.90（帰無 0.10）、80 タスクで下位を通過した個体数は 48 対 19、90 タスク以上連続の個体は 0 対 8、z̄ が −20 を割った個体は 0 対 9 で戻り 0。**leaky は交代し、ELU には固定の芯がある。それでも損失は ELU ≤ leaky。** 本 spec は近似ではなく実測の φ′ で、13 腕について登録して決める。

## 1. データ

`gate_shape_0911` の毎タスク終端の per-unit ゲート ḡᵢ(t)（固定プローブ 512 枚・現置換・φ′ の入力平均）、zcurᵢ(t)・sdcurᵢ(t)、腕の損失 L（[[ゲート被覆か非線形性か_spec_0911]] §2）。13 腕 × seed 0–2、t1–120。追加の走は無い。

## 2. 量の定義（登録）

下位集団 B(t) = ḡᵢ(t) の小さい 10 ユニット（順位・同順位は安定ソートで先のユニット）。GELU・SiLU も符号付き ḡᵢ で取る（負のゲート＝最も「逆向き」の個体が下位に来る。|ḡᵢ| 版は副測定）。

- **残留率 O_k** = mean_{t∈[41, 120−k]} |B(t) ∩ B(t+k)| / 10、k ∈ {1, 5, 20, 40}。帰無（完全交代）= 0.10、固定 = 1.0。**主判定は O_20。**
- **通過個体数 Ndistinct** = |∪_{t=41..120} B(t)|（固定 → 10、完全交代 → 100 に近づく）。
- **長期滞留数 Nrun60** = t21–120 で B に 60 タスク以上連続で入っていたユニット数。
- **chronic**（[[ゲート被覆か非線形性か_spec_0911]] と共通）= t101–120 のすべてで B に入っていたユニット。
- **Snake の位相**（固定 α の SN02 / SN06 / SN15）: θᵢ(t) = 2α·zcurᵢ(t)、位相の広がり αWᵢ = α·sdcurᵢ。late 窓（t101–120）で B(t) のメンバーのうち sin θᵢ < −0.5 の割合 = **phase_frac**。SNA は α(t) がユニット別なので、実測 ḡᵢ の順位だけを使う。
- **縮退**: late 窓で Var_i ḡᵢ < 1e−10（LIN のように全ユニット同一ゲート）なら B(t) は定義されず、その腕は `DEGENERATE`。

## 3. 判定（事前登録）

**C1 腕ごとの滞留**（3 seed が同じ帯 → そのラベル、混在 → `MIXED`）

| O_20 | ラベル |
|---|---|
| ≥ 0.75 | `FIXED_MEMBERS` |
| ≤ 0.55 | `ROTATING` |
| 0.55 < O_20 < 0.75 | `PARTIAL` |

**C2 滞留は損失を並べるか**（13 腕・`DEGENERATE` を除く・seed 中央値の Spearman(O_20, L)）: ≥ +0.6 `PERSISTENCE_ORDERS_LOSS` / 0.2 < ρ < 0.6 `PERSISTENCE_PARTIAL` / ‖ρ‖ ≤ 0.2 `PERSISTENCE_FAILS` / −0.6 < ρ < −0.2 `PERSISTENCE_PARTIAL_INVERTED` / ≤ −0.6 `PERSISTENCE_INVERTED`。

**C3 Snake の位相**（SN02 / SN06 / SN15 それぞれ・3 seed 一致）: phase_frac ≥ 0.8 → `LOW_GATE_IS_PHASE`；≤ 0.4 → `LOW_GATE_NOT_PHASE`；他 `PHASE_PARTIAL`。加えて late 窓の max_i |ḡᵢ − 1| ≤ 0.15 なら `NO_GATE_STRUCTURE`（全ユニットが実効的に線形で、下位集団は雑音）。

**C4 ELU 対 leaky の既知の対比の登録版**: ELU1 と LR の O_20 の差（seed 対）が 3/3 で +0.2 以上 → `ELU_FIXED_LEAKY_ROTATES`。同時に L_ELU1 ≤ L_LR + 0.5 pt（3/3）なら `FIXED_CORE_WITHOUT_EXTRA_LOSS`。

## 4. 検算と変異対照

- **帰無対照（走中に計算）**: 各タスクでユニットのラベルを独立に置換して O_20 を計算 → 0.10 ± 0.1 に入ること（統計量が交代を交代と読む）。**固定対照**: B(t) を t41 の集合に固定した合成列で O_20 = 1.0。両方が出なければ C1 は無効。
- **順位の一意性**: B(t) の要素数が毎タスク 10（同順位の処理を含めて）。
- **G1**: 親走の G1 を継承（`gate_shape_0911` が G1 を通らなければ本 spec も無効）。
