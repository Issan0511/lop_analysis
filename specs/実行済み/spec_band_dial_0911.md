## 0. 何を決めるか

候補 (a)（低ゲート被覆）を相関でなく**介入**で見る。ELU の負側 φ′ = e^{z} の「高ゲート帯」の幅を温度 τ で直接動かし、被覆だけを変えて損失が追随するかを決める。あわせて「深部の弱さ」を床で消した ELU（leaky の床 0.1 を持つ ELU）で、Issa の「浅い帯が深部の弱さを補う」と「深部の弱さは元々効いていない」を分ける。

9/10 夜の私の提案では「1 で (a) が並んだ場合だけ回す」としたが、**走のコストが小さく、(a) が並ばなくても帯幅の介入は c_act の候補を 1 つ消す情報になる**ので、無条件に回す（条件付き実行は撤回）。ただし §3 の読み方は (a) の帰趨で変わる（§3 末尾）。

## 3. 判定（事前登録）

- **D0 操作チェック**: Cov(CELU3) < Cov(CELU1) < Cov(CELU03) が 3/3 seed で成り立てば `MANIPULATION_OK`。成り立たなければ D1 は `NOT_TESTABLE_NO_COVERAGE_CHANGE`。
- **D1 帯幅の用量反応**（seed 対）: L(CELU03) > L(CELU1) > L(CELU3) が 3/3 → `WIDER_BAND_LESS_LOSS`；逆順が 3/3 → `WIDER_BAND_MORE_LOSS`；他 → `BAND_NO_MONOTONE`。加えて効果量: |L(CELU3) − L(CELU03)| の seed 中央値 < 1.0 pt → `BAND_WEAK`、≥ 1.0 → `BAND_STRONG`。
- **D2 床**（seed 対 ELUF − CELU1）: ≤ −0.5 pt が 3/3 → `FLOOR_HELPS`；≥ +0.5 pt が 3/3 → `FLOOR_HURTS`；他 → `FLOOR_NEUTRAL`。
- **D3 幅の追随**（副）: N(late) の腕差を併記。帯幅で N が 10% 以上動いたら D1 の差には幅の差が混ざる（そのときは「c_act の介入」でなく「幅経由」と読む）。
- 発散した腕seed は `DIVERGED`（落とす）。
- **読み方**: 親 spec の (a) が `Cov_ORDERS_L` で、かつ D1 が `WIDER_BAND_LESS_LOSS`・`BAND_STRONG` のとき、(a) は相関と介入の両方で立つ。(a) が `FAILS` で D1 が `BAND_NO_MONOTONE` か `BAND_WEAK` なら、(a) は候補から外す。食い違えばそれ自体を記録する。

## 4. 進捗ゲートと変異対照

- **G1**: `CELU1` の per-unit 3 配列 × t1–120 が `elu_growth_0909` の ELU1 と maxabs ≤ 1e−10（τ=1 の実装は ELU1 の式と同じ演算順序: z/1.0 と 1.0·expm1 は厳密）。変異対照: 初期値 +1e−3 で外れる。`CELU03`・`CELU3`・`ELUF` は錨無し（新規）。
