# spec_perm_overlap_0912 — 置換の重なりで c を連続に引き、c がタスク側の変数であることを決める

## 0. 位置づけ

帳簿 $\Delta\lVert\widetilde W\rVert^2 = D^2 - 2cDN$、天井 $N^*=D/2c$ のうち、$D$ 側は誤差の強さ $e2$ が並べることが分かった（[[勾配の因子分解と斉次性の破れ_結果_0912]]、観測 8 腕・介入 4 腕・斉次性 6 腕で符号一致）。残るのが $c$。

**$c$ は活性化では動かない。** 3 層・WD なしの 19 腕（線形〜Snake α=1.5、ゲート 385 倍、斉次性の破れ h=εz²）で **0.0242–0.0499** の 1.6 倍帯に収まる。

**一方、活性化以外では大きく動く。**

| 変えたもの | c | 出典 |
|---|---:|---|
| 同じ置換の反復（CYCLE1） | **−0.047**（符号反転） | `perm_cycle_0909` |
| 新しい置換（FRESH・標準） | +0.049 | 同 |
| W2 を外す（LIN0） | +0.139 | `linear_growth_0910` |
| WD あり | +0.45 | `boundary_*` l2 腕 |

事後の読み（[[なぜ下がるか_活性化誤差の分解_事後_0910]] §6）は「侵食の正体は**切替直後の誤答標本が既存パターンを縮めること**」（既存方向への射影は誤答から +0.16/task、正答から −0.013）。切替直後の CE は LR 4.03・ELU03 4.00・ELU1 4.36・SNA 4.24 と**活性化によらずほぼ同じ**（一様予測 ln10 = 2.30 を大きく超える）。**$c$ が腕で揃うのは、誰でも同じだけ間違えるから**という読みになる。

**未検証**: この読みは事後で、介入していない。CYCLE1 の符号反転が唯一の傍証。

## 1. 介入 — 置換の重なりダイヤル

タスク境界で、**784 画素のうち割合 $k$ だけを入れ替え直す**。

$$\text{perm}_t = \text{perm}_{t-1}\ \text{の位置部分集合 } S\ (|S|=\lfloor k\cdot784\rceil)\ \text{上の値だけをシャッフル}$$

$k=1$ が標準の Permuted MNIST、$k=0$ が「同じ置換を 120 回」（データ抽出とバッチ順は毎タスク新しいまま）。**固定率** $f=\frac1{784}\#\{j:\text{perm}_t[j]=\text{perm}_{t-1}[j]\}$ を毎タスク実測する。

### 乱数ストリームの整合（G1 を保つための設計）

全腕・全タスクで `torch.randperm(784, generator=gp)` を**必ず 1 回引く**。

- $k=1$: その値をそのまま使う → **宿主と完全に同じ経路**（G1 が効く）
- $k<1$: その値は捨て、部分入れ替えは別生成器 `stream('overlap', seed)` で行う

これで `gp` の消費が全腕で同一になり、`gd`（データ抽出）・`gb`（バッチ順）も同一に保たれる。**タスク 1 の置換は全腕で同一**（$k$ に依らず fresh）。

## 2. 腕・seed・走

$k \in \{0,\ 0.1,\ 0.25,\ 0.5,\ 1.0\}$ × 活性化 $\{$ `LR`(leaky .1), `SN06`(snake .6) $\}$ = **10 セル × 3 seed = 30 走 × 120 タスク**。

`SN06` を入れるのは **§0 の読み「$c$ はタスク側」の直接検定**のため。タスク側なら $c(k)$ の曲線が 2 活性化で重なる。

## 3. 測定量

`gradient_factors_0910` の機構をそのまま使う（c・D²・S²・ρ・N・e2・g2・ξ・R・graw・σ・z̄・acc、TRACK = 20,30,…,120）。追加:

- **f**（固定率、毎タスク実測）
- **切替 CE / 切替 acc** — 新しい置換の最初のバッチで、**1 回も更新する前に**測る（ショックの大きさ。4096 標本の固定プローブを使い、学習バッチは消費しない）
- **N\* = D/2c**、指数 **p_late**（t60→120 の log-log）

判定は t = 100, 120 × 3 seed（p_late と指数系は t60–120）。

## 4. 事前登録の予測と判定

### V1 `C_DIAL` — c は k で動き、符号が反転するか
`LR` の c(k=0) と c(k=1)。
- `SIGN_FLIPS` … c(k=0) ≤ −0.01 かつ c(k=1) ≥ +0.03
- `MONOTONE_NO_FLIP` … Spearman(k, c) ≥ 0.8 だが符号反転なし
- `NO_RESPONSE` … |c(1) − c(0)| < 0.01
- `PARTIAL` … その他

**予測: `SIGN_FLIPS`。** 根拠: `perm_cycle_0909` の CYCLE1 で cos +0.047（c = −0.047）、FRESH で cos −0.049。ただしあちらは t20 からの 20 タスク再走で、本走は 120 タスク新規学習なので値は一致しなくてよい。

### V2 `TASK_NOT_ACTIVATION` — 2 活性化で同じ曲線か（**§0 の読みの本体**）
各 k で |c(`LR`) − c(`SN06`)|。
- `SAME_CURVE` … 全 5 水準で ≤ 0.010
- `DIFFERENT` … いずれかで ≥ 0.020
- `PARTIAL` … その他

**予測: `SAME_CURVE`。** 根拠: k=1 では既に 0.042 対 0.045（差 0.003）。19 腕の全幅が 0.026 しかない。

### V3 `SHOCK_MEDIATES` — 切替ショックが媒介か
10 セルでの Spearman(切替 CE, c)。
- `MEDIATES` … ≥ +0.8
- `NO` … < +0.5
- `WEAK` … その他

**予測: `MEDIATES`。** これが §0 の事後読みの初めての介入検定。

### V4 `RUNAWAY` — c<0 で成長則は変わるか
`LR` k=0 の p_late（t60–120）。
- `SUPER_SQRT` … ≥ 0.55
- `SUB_SQRT` … ≤ 0.45
- `SQRT` … その間

**予測: `SUPER_SQRT`。** 根拠: c<0 なら $dN^2/dt = D^2 + 2|c|DN$ で両項が正、固定点が消える。ただし `perm_cycle_0909` の CYCLE1 は注入が 0.159（FRESH の 1.005 の 1/6）まで落ちたので、**絶対値としては k=0 の N120 が k=1 より小さくてよい**（指数と絶対値を混同しない）。

### V5 `LEDGER` — 帳簿は N120 を予言するか
10 セルで実測 (D, c) から $dN^2/dt=D^2-2cDN$ を t20 → 120 で積分し、N120 と比較。
- `HOLDS` … 全セルで相対誤差 ≤ 10% かつ Spearman(模型, 実測) ≥ 0.9
- `FAILS` … その他

**予測: `HOLDS`。** 根拠: `gate_scale_invariance_0909` §5 で 8 腕とも 2–4%。ただし c<0 のセルは外挿になる。

### V6 `LOP_FOLLOWS_WIDTH` — この軸でも幅が LoP を並べるか
10 セルの精度低下（t20 → t120、pt）と N120 の Spearman。
- `WIDTH_TRACKS` … ≤ −0.7（幅が大きいほど低下が大きい）
- `NO` … > −0.4

**予測: `WIDTH_TRACKS`。** **交絡を明示**: k が小さいほどタスクが似ていて精度低下は自明に小さい。k と幅が同方向に動くなら本判定は k の効果と区別できない。**判定値と一緒に Spearman(k, 精度低下) を必ず併記し、両者が同程度なら `CONFOUNDED` と読む。**

## 6. 限界（事前に宣言）

- **k は c だけを動かさない。** タスクが似れば新しく積むものも減るので D も e2 も同時に動く。天井 $N^*=D/2c$ を D 側と c 側に分けて報告するのが精一杯で、「c だけの効果」は取り出せない。
- **k<1 は Permuted MNIST の定義を緩める。** V9 の主張（毎回まったく新しい置換）の外側に出るので、本走の結果を LoP の設計指針として読んではいけない。目的は $c$ の帰属（タスク側か活性化側か）の決着のみ。
- V6 は k と幅が同方向に動くため原理的に交絡する。`CONFOUNDED` で終わる可能性が高い。
- k=0 は「同じ置換の 120 回反復」で、継続学習ではない。指数・帳簿の外挿として読む。
- 切替 CE は 4096 標本の固定プローブ。学習バッチそのものではない。
- 活性化は 2 種のみ。`SAME_CURVE` が出ても 2 点である。
- SGD 対照なし。120 タスクは天井の手前。
