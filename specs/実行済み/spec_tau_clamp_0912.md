## 0. 何を決めるか

**前提の訂正**: 「ELU の飽和は無害」は誤り。幅をほぼ一定に保って負側の帯 τ だけを振ると、目減りは **2.68 / 1.86 / 0.65 pt**（τ = 0.3 / 1 / 3・‖W̃ᵢ‖ は 7.00 / 7.97 / 8.06）。**ELU の中で飽和は 2.0 pt の害である。**

**本当に特異なのは「幅を止めた後に残る損失」** $R_c$。[[ゲート被覆か非線形性か_結果_0911]] の 13 腕で、**滑らかに 0 へ減衰する負側**（ELU 0.08・Snake −0.25〜0.24）は $R_c\approx0$、**一定値で止まる負側**（leaky 0.3/0.1/0.01 で 0.20/0.49/0.91・ReLU 0.69）と**符号が反転する負側**（GELU 1.12・SiLU 0.85）は 0.5 以上残る。今日の走でも幅を止めた ELU は目減り **0.00 pt**、leaky は **0.60 pt**。

**思いつく説明はデータに潰れる**: 「φ′ が 0 へ減衰するほど良い」なら leaky は負側を平らにするほど良くなるはずだが、実測は逆（0.3→0.01 で $R_c$ 0.20→0.91）。ReLU は φ′ ≡ 0 で 0.69 残る。**φ′ の大小では説明できない。**

**決定的に欠けている 1 点**: **τ = 0.3 の ELU に幅クランプをかけたときの損失**。

- ほぼ 0 になる → **ELU では飽和の害も幅を通っている**（τ ダイヤルの 2.0 pt は幅経由の効果を幅一定と誤認していたことになる。その場合 $R_c$ が活性化族で分かれる事実は「幅を止めれば全部消える族と消えない族がある」という、より強い形になる）
- 2 pt 残る → **飽和の害と幅の害は独立で、ELU はたまたま τ=1 で飽和の取り分が小さいだけ**（`CELU1` の $R_c$ ≈ 0 は τ=1 固有の偶然で、族の性質ではない）

**どちらでも、私が 9/11 から 2 度立てた「ELU の飽和は無害／飽和は ω を通す」の残りが決まる。**

## 2. 量（登録）

窓: **base = t16–20**（クランプ分岐の前なので同じ τ の 2 腕で厳密に同一）、**late = t101–120**、seed 中央値。
L = acc(base) − acc(late) [pt]、level = acc(late)。
**$R_c(\tau)$ = L(無クランプ) − L(wclamp)**（幅を止めて消える分）、**$S(\tau)$ = L(wclamp)**（幅を止めても残る分）。

## 3. 判定（事前登録・seed 3/3 一致でラベル、混在は `MIXED`）

**N0 操作チェック**: 全腕の G1（maxabs ≤ 1e−10・件数ガード）、`wclamp` の検査（`c3_cnorm_rel` ≤ 1e−6・`c3_m_absdiff` ≤ float32 の証明可能床・`clamp_tail_absdiff` = 0）と変異対照 3 本（合格幅＝検査の許容の 10 倍・[[threshold-derivation-rule]]）、角度の 2 式突合（θ > 1e−4 の行のみ・1e−6）、球面三角不等式 ≤ 1e−8、実測 ‖W̃ᵢ‖(wclamp) / ‖W̃ᵢ‖(t20) が 1 ± 1e−6。すべて満たせば `MANIPULATION_OK`。**外れたら N1–N3 は `NOT_TESTABLE`。**
可検定性（N0 と独立に記録）: L(`T03`) − L(`T3`) ≥ 1.0 pt（前走 2.03）。

**N1 決定的 — 深い飽和の害は幅を通るか**: $S(0.3)$ = L(`T03w`)。
- $S(0.3)$ ≤ 0.5 pt → **`SATURATION_VIA_WIDTH`**（幅を止めれば深い飽和でも損失が消える）
- $S(0.3)$ ≥ 1.5 pt → **`SATURATION_INDEPENDENT`**（飽和の害は幅の外に独立に立つ）
- 他 → `N1_PARTIAL`

**N2 幅を止めた後に τ は効くか**: $\Delta S$ = $S(0.3)$ − $S(3)$（クランプ 3 腕、`CELU1w` の $S(1)$ = 0.00 を併記）。
- |ΔS| < 0.3 pt → **`TAU_GONE_UNDER_CLAMP`**（τ の 2.0 pt はすべて幅経由）
- ΔS ≥ 1.0 pt → **`TAU_SURVIVES_CLAMP`**
- 他 → `N2_PARTIAL`

**N3 $R_c$ は τ とともに動くか**: $R_c(0.3)$・$R_c(1)$（=1.86・持ち込み）・$R_c(3)$ が τ に対して単調か（3/3 seed）。単調増加 → `RC_RISES_WITH_BAND`／単調減少 → `RC_FALLS_WITH_BAND`／他 `RC_FLAT_OR_MIXED`。**記述的だが、$R_c$ が族の性質か τ 固有かを分ける。**

**可検定性**: 発散は `DIVERGED`。late 窓のタスク内 CE 改善が 90% 未満なら `LEARNING_BROKEN`（`T03` は hard-dead 14 個なので要注意）。
