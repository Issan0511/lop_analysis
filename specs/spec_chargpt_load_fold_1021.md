## 2. (A) 装填（部品 0）— seed 1000、保存済みの checkpoint

対象（`results/chargpt_cl_1019/quicklook/`）:
- 4 ブロック `M/C3`・`M/SiLU`・`M/GELU`: init と課題 1〜10・25・39〜50 の課題末（＋更新 100、Adam）。
- 4 ブロック `M/ReLUcap`・`M/SiLUcap`・`M/GELUcap`: init と課題 1・10・25・50。
- 2 ブロック `M2/C3`・`M2/SiLU`: init と課題 1〜10・25・39〜50・89〜100。

定義（kappa_reload_cnn_1020 の `src/kappa_reload_cnn_1020.py`・`results/kappa_reload_cnn_1020/summary.md` に揃える。違うところだけ書く）:
- 特徴 h_n は最終 LN の出力（d = 512、token ごと）、読み出しは head（V × d、bias なし、埋め込みと共有）。課題 k の F_k = Σ_n (y_n − 1/V) h_nᵀ を課題 k の鎖の probe で作る。κ_k・cos²(v^c, F)・Q = κ‖F‖・帰無（クラス置換）の分位点・補題 A = ⟨v^c, F⟩ の恒等式と κ ≥ [N(log V − L)]/‖F‖²（bias なしで B = 0）の破れの数と κ/κ_lb。
- 読み出しに隣接する FFN 層（4 ブロックは L3、2 ブロックは L1）の unit j の位置 m_j = 課題の probe での前活性の token 平均（bias なしなので m_j = w_j·ȳ）。切替の期待の勾配は、新しい鎖の事前分布が対称なので、一様の目標を一様 probe に当てた損失 L_u = mean_n[logsumexp f_n − mean_c f_nc] の勾配で代える（近似。§4 で実際の次の課題の 1 実現と比べる）。自分の重みの押し G_own,j = ȳ_j·∇_{w_j} L_u（後ろ向き 1 回）、全体の押し G_full,j = ⟨∇_θ m_j, ∇_θ L_u⟩（m(θ) の JVP 1 回）。G > 0 が沈める側（SGD で Δm = −ηG）。生きた unit = probe で z > 0 の token がある unit。
- 初期化の押し: init の状態での |G_own| の中央値 ÷ 課題 1 末での |G_own| の中央値。
- 自己形の符号: d_j = Σ_n K_n φ(z_jn) φ′(z_jn) y_n（K_n = ȳ·y_n、下見の decomp_dmu と同じ）の向きと G_own の符号の一致。

予測（計算前・Opus 5.5 が記名。Issa は記名なし）:
- P0-1: head の κ_k > 0 が全腕・全課題末で成り立ち、補題の破れは 0（定理の数値の確認）。
- P0-2: 課題末の cos²(v^c, F) は CNN の f2（0.63〜0.75）より低く 0.1〜0.6（埋め込みとの共有、残差 512 次元）。
- P0-3: C3 の κ_k/κ₁ ≥ 0.8 が課題末の 8 割以上で成り立つ。SiLU・GELU は残差の尺度が伸びて κ 比は崩れうるが cos² は保たれる（CNN の Snake と同じ形）。
- P0-4: L3（2 ブロックは L1）の生きた unit のうち G_own が沈める側の割合は、C3 の課題 1〜10 で 0.8 以上、SiLU・GELU の課題 1〜10 で 0.7 以上。SiLU・GELU の課題 39〜50（L3 が正側へ逃げた後）では 0.6 未満に落ちる。
- P0-5: G_full と G_own の符号の一致は 0.75 以下（押しの大きさの大半が上流の経路を通る）。
- P0-6: 初期化の押し ÷ 課題 1 末の切替の押し（|G_own| の中央値）は 1/30 以下。
- P0-7: 一様 probe の期待と、実際の次の課題の鎖の 1 実現で計算した押しの、沈める側の割合の差は ±0.1 以内。

## 3. (B) 折れ目の喪失（部品 5）— 本走 10 seed
