## 1. 問い

`act_offset_0906` / `offset_grid_0906` で確定したのは **不動点の位置**（着座点 = φ+c の零点 −c/a、a=0.2〜0.7 で 4/4・±0.02、ELU でも同型）だけである。底の位置は E[(φ+c)²] でも E[|φ+c|] でも E[(φ+c)⁴] でも同じなので、**現在のデータは復元力の形（指数 p）を区別していない。**「活性化に比例して強い」「単調に強い」はどちらも未証明。

本解析は、ポテンシャル U ∝ E_支持[|φ+c|^p] のうち **p=2（変位に比例する復元力）** が正しいかを、既存ログの中の**緩和そのもの**から測る。

## 2. 測る量

**窓**: 各腕の末尾 20 タスク（`logs_tail` の 1000-step 密記録・`step > total − 200,000`）。
**増分**: 隣接する密記録行の対のみ（Δstep = 1000）。**`flip_state` が両行で一致する対だけ**を使う（タスク境界を跨ぐ増分は支持そのものが変わるので除外）。
**速度** u ≡ `layer1_dzbar`（float64 の z̄ 差・1000 step あたり）。行差ではなくロガーの列を使う（[[proj-004-drift-experiment]] の罠）。
**変位** x ≡ z̄ − z\*。z\* は群ごとに解析的に決まる:

| 群 | 条件（増分の両端で成立を要求） | φ+c | 井戸の底 z\* | p=2 の曲率 d²E[(φ+c)²]/dz̄² |
|---|---|---|---|---|
| 下 | `zmax < 0` | a z + c | **−c/a** | 2a² |
| 上 | `zmin > 0` | z + c | **−c** | 2 |
| 跨 | それ以外 | — | 定義しない | — |

（下群では E[(a(z̄+u)+c)²] = (a z̄+c)² + a²E[u²] なので、支持の幅に依らず底は厳密に z̄ = −c/a。上群も同様。）
**跨ぎ群はラチェットが乗るので主判定から除外**し、参考として別掲する。
**ALL ユニットで読む**（ALIVE 規則は潰れたユニット＝見たい対象を落とす・格子の教訓 3）。ALIVE 部分集合は参考値として併記。
**CI**: seed ブートストラップ 2000・`rng(20260907)`（seed 単位で再標本）。

## 3. 判定（結果を見る前に固定）

各腕 × 群で、10 seed をプールして:

- **T1 線形性（主判定）**: |x| の十分位ビンごとに中央値 (|x|, |u|) を取り、log–log の傾き **q** を回帰。U ∝ |φ+c|^p なら力 ∝ |x|^{p−1} すなわち **q = p−1**。
  - `LINEAR`（p=2 と整合）: q の CI が **[0.7, 1.3]** に含まれる。
  - `CONSTANT_FORCE`（p=1 型）: q の CI が **[−0.3, 0.3]** に含まれる。
  - `OTHER`: どちらにも入らない。
  - ビンが 5 未満、または |x| の中央値の幅が **3 倍未満**の腕は T1 を `NOT_DETERMINED` とする（変位のレンジが無いと指数は読めない）。
- **T2 復元性**: 原点通過回帰 u = −k·x の傾き k と、`sign(u) = −sign(x)` の割合 r。**k > 0 かつ CI が 0 を除外**しなければその腕は「復元が読めない」として T3–T6 から落とす。k はタスク内位相 j=1..9 ごとにも出す（位相で 2〜3 桁減衰することが既知なので、腕間比較は**同じ位相**で行う）。
- **T3 a 依存**: c=+0.5 の下群 4 腕（a=0.2/0.3/0.5/0.7）で log k を log a に回帰した傾き **α**。p=2 は曲率 2a² なので **α = 2** を予言。
  - `A_SQUARED`: α の CI が **[1.5, 2.5]**。`A_LINEAR`: **[0.5, 1.5]**。`A_FLAT`: CI が 0 を含む。ほかは `OTHER`。
- **T4 枝コントラスト**: 同じ a で k_up（c=−0.5 の上群）/ k_dn（c=+0.5 の下群）。p=2 は **1/a²** を予言（a=0.2 で 25、0.5 で 4、0.7 で 2）。
  - `BRANCH_P2`: 観測比が予言比の **[1/3, 3]** に入る。`BRANCH_FLAT`: 観測比が **[1/2, 2]**（枝に依らない ＝ p=2 棄却）。ほかは `OTHER`。
- **T5 v 依存**: 腕内でユニットを |v| の四分位に分け、log k を log |v| に回帰した傾き **β**。p=2（力 ∝ v²）は **β = 2**。判定は **v 凍結腕**（`LRvf1_1216` / `LRoffm0p5_vf1_1216` / `LRoffp0p5_vf1_1216`）を主とする（v が状態と相関しないため）。`V_SQUARED`: CI が [1.5, 2.5]。`V_FLAT`: CI が 0 を含む。
- **T6 η 依存（健全性）**: lr 0.00125 の腕（`*_lr0p00125_1216`）の k は lr 0.01 の対応腕の **1/8**。観測比が **[1/16, 1/4]** なら整合。外れたら「k は 1 ステップあたりの力ではない何かを含む」ことになるので、T3–T5 の解釈に注記を付ける。
- **T7 予言子（補助）**: u を **−|v|²·`m_phidphi`** に回帰する。この量は p=2 の井戸が予言する力の形を、実際の支持の上の実際の φ+c から計算したもの（`m_phidphi` = E_支持[(φ+c)·φ′]）。腕をまたいで係数が **3 倍以内**に収まれば「一つの定数で書ける」と読む。
  - **注**: これは自己項／残余項の分解を根拠にした導出ではない（[[force-field-self-rest-decomposition-caution]]）。**p=2 が予言する力の形を予測子として当てるだけ**であり、当たっても「勾配の自己項が支配する」とは読まない。

**総合ラベル**:
- `WELL_P2`: T1 が `LINEAR` かつ T4 が `BRANCH_P2` かつ（T3 が `A_SQUARED` または T5 が `V_SQUARED`）。
- `WELL_LINEAR_SCALING_OFF`: T1 が `LINEAR` だが T3 / T4 / T5 のいずれかが予言から外れる。
- `NOT_P2`: T1 が `CONSTANT_FORCE`、または T4 が `BRANCH_FLAT`。
- `NOT_DETERMINED`: 有効増分が 1 腕あたり 1,000 未満、または上の条件のどれにも当てはまらない。

## 5. 引用上の注意（あらかじめ）

1. 本解析は**末尾 20 タスクの局所的な緩和**を測る。着座に至る過程全体の力則ではない。
2. 腕をまたいで k の水準を比べるのは**同じ lr・同じ位相**のときだけ（T6 が通った場合に限り lr 換算を許す）。
3. 跨ぎ群の値は参考。ラチェットと井戸が混ざっているので、そこから p を読まない。
4. T7 が当たっても外れても、力場の分解については何も主張しない。
