## 0. 先生の指定と、実装に落とす際の論点

原文の指定は3項目。

## 1. 設計上の決定と根拠

### 1.1 項目3は条件A（SCR）では原理的に測定不能 → **条件Bで行う**

条件A の入力は {0,1}^m（m=20、うち f=15 が flipping bits、残り5が毎ステップ U{0,1}）。

- **タスク内**: flipping bits は定数（分散 0）、ランダムビットは分散 1/4 → Σ_within = (1/4)·I₅ ⊕ 0₁₅。固有値 1/4 が**重複度5**で縮退
- **周辺**: 全ビットが周辺 Bernoulli(1/2) 独立 → Σ = (1/4)·I₂₀。**完全等方**

いずれにせよ e₁^Σ は一意に定まらず、cos(e₁^W, e₁^Σ) は測定量として定義されない。中心化条件では µµᵀ も消えるので E[xxᵀ] でも同じ。

→ **項目3は条件B（ガウス入力）でスパイク型 Σ = I + (κ−1)uuᵀ を入れて行う。** κ>1 で e₁^Σ = u が一意に定まる。κ=1 は「縮退した対照」として並走させ、判別力がゼロであることを実データで示す（先生の元設計が等方前提だったことへの説明材料になる）。

### 1.2 µ=0 は条件Bの **c=0** で厳密に実現する

条件A の中心化は EMA（`center_alpha=0.01`）による走行平均の減算で、**厳密な µ=0 ではない**。条件B は µ = (c/√d)·1 なので c=0 で厳密に µ=0。項目3の「µ=0 でも残存する」という主張は厳密ゼロで示すのが強い。

条件A の std/centered 対比は**項目2（増幅因子）専用**とする。

### 1.3 Σ の定義：先生は E[xxᵀ]（二次モーメント）と書いている

µ=0 の腕では Cov(x) と一致するので問題ない。std 腕では E[xxᵀ] = Σ + µµᵀ となり、‖µ‖ が大きければ e₁^{E[xxᵀ]} ≈ µ̂ になる（条件A std では µ = (1/2)·1 なので実際そうなる）。

→ **両方を計算して別カラムで保存**する。主判定は µ=0 腕（両者一致）を使う。

### 1.4 e₁^W の定義：「PCA」はユニット方向の中心化を意味しうる

W は [h, d]。行 wᵢ をサンプルと見た PCA は **ユニット平均 w̄ を引く**。ところが我々が測りたい「全ユニットの共通方向」は、まさにその w̄ 成分に乗っている。中心化 PCA は共通成分を除去した**残差**の構造を測ることになり、意図と逆になりうる。

→ **両方を必ず出す。**

- `cos_e1W_raw`: 中心化なしの W の第1**右**特異ベクトル（＝ E[wwᵀ] の最大固有ベクトル）。**主判定はこちら**
- `cos_e1W_pca`: 行方向を中心化した W の第1右特異ベクトル

この2つが乖離した場合、そのこと自体を先生への確認事項として返信に載せる。

### 1.5 dead 行はゼロ化する

`stable_rank_W_alive` と同じ規約。dead 行を残すと「死んだユニットの初期値が主方向を決める」アーティファクトが混入する。alive 行が1本以下の run は NaN。

### 1.6 主統計は |cos|

aniso_perp_0812 の符号付き解析で、Σ スパイクへの引力は **± 対称の軸吸引**（run 内でも符号が割れる）と確定している。第1特異ベクトルも符号任意。signed も保存するが判定には使わない。

> **注意**: 先生の「1.0 に収束」という書き方は暗に符号付きの向きを含むが、軸吸引である以上 |cos| → 1 が正しい形。返信で1行触れること。

### 1.7 レジーム問題：既存の条件B設定では LoP も低ランク化も起きない

`aniso_perp_0812`（c=2, κ∈{1,4,16}, lr∈{0.003,0.001}, 1M step）の実測は **dead_frac = 0.0、eval_loss 0.086–0.126、srank(W_alive) 11.0 → 12.0（微増）**。W がほぼ動いていないので、W の主方向を測っても判別にならない。

原因は `src/train.py` で条件B教師の隠れ幅が**学習器と同一に固定**されていること（`MLPTeacher(R, width, d, ...)`）。容量ギャップがないため学習器が教師をほぼ完全に追従し、構造的近似誤差 Cov(e,x) が育たない。

→ **教師幅を config で分離する**（§2.1）。条件A が Dohare 準拠で学習器5・教師100 の容量ギャップを持つのと同じ構造を条件Bに与える。

## 2. 実装変更（3点）

### 2.1 条件B教師幅のデカップリング

`configs` に `condB.target_hidden`（既定 = `null` → 従来どおり学習器幅）を追加。

```python

```

**要件**: `target_hidden` 未指定時は乱数消費を含めて既存 run と **bit 一致**すること（S1 で確認）。

### 2.2 `lop_metrics.py` に W 方向指標を追加

`lop_every` ごとの密な時系列が要る（項目3は「学習が進むにつれて収束」という時間発展の主張なので、チェックポイント6点では足りない）。1回あたり [h,d] の SVD 1本なのでコストは無視できる。

追加カラム:

| カラム | 定義 |
|---|---|
| `cos_e1W_e1Sig` | \|cos(e₁^W_raw, e₁^Σ)\|。W は dead 行ゼロ化。Σ は Cov(x) |
| `cos_e1W_e1M2` | 同上、ただし Σ を E[xxᵀ] = Cov + µµᵀ に置換 |
| `cos_e1W_e1Sig_pca` | 行中心化版 W での同指標（§1.4） |
| `cos_e1W_mu` | \|cos(e₁^W_raw, µ̂)\|（µ=0 なら NaN） |
| `cos_e1W_e1Sig_signed` | 符号付き（参考） |
| `top1_frac_alive` | s₁²/Σs² （alive 行）。主方向への集中度 |
| `w_norm_mean` | alive 行の ‖wᵢ‖ 平均。§7 の交絡統制に必須 |
| `e1_stability` | 直前の lop step の e₁^W との \|cos\|。方向が定常か暴れているかの診断 |

**Σ と µ は解析値を使う**（サンプル推定しない）。

- 条件B: µ = (c/√d)·1、Σ = I + (κ−1)uuᵀ、u は `spike_dir` から決定的に定まる。κ=1 のとき Σ は等方なので **e₁^Σ を NaN にして全指標を NaN で埋める**（縮退の明示。無理に第1固有ベクトルを取らないこと）
- 条件A: Σ = (1/4)I → **同様に全て NaN**（§1.1）。std 腕でも E[xxᵀ] 側だけは µµᵀ が支配して一意なので `cos_e1W_e1M2` のみ計算してよい

**ランダム床**は d 次元独立ベクトル対の E|cos| ≈ √(2/(πd))。d=21 で **0.174**。全図に点線で描く。

### 2.3 傾き推定ユーティリティ

`analysis/center_selfcov/slopes.py` を新規作成。指標系列 y(t) に対し:

- 前半区間 [0, t_half] の OLS 傾き（t_half は §5 で固定）
- 到達時刻 t50: y が (初期値 + 最終値)/2 を最初に超える step の線形内挿
- run 単位で算出 → seed 間 bootstrap (n=2000) で 95%CI

## 6. 事前登録予測と判定基準

判定は seed 間 bootstrap (n=2000) の 95%CI で行う。

### P3-1（増幅因子・dead_frac）
条件A w100 で、centered の dead_frac 最終値が std より低い。差の CI がゼロを含まない。
- 参考: 既存の drift 系実験で std 0.96 → centered 0.28
- **反証**: 差なし、または符号が逆

### P3-2（増幅因子・整列速度）
centered の `wcos_mean` の前半傾きが std より小さい。差の CI がゼロを含まない。

> **事前に明記しておく留保**: 勾配場レベルの類似量（pairwise cos(E[g_i], E[g_j]) = A1）は **中心化しても 0.61–0.68 から落ちなかった**という既報がある。重みレベルの `wcos_mean` は別量だが、**P3-2 が null に出る可能性は事前に高いと見積もっている**。null の場合は「µ は dead_frac 経路（Path A）には効くが整列経路（Path B）には効かない」という分離結果として報告する。後付けの言い訳にしないため、ここに書いておく。

### P3-3（交絡統制）
P3-1 / P3-2 に差が出た場合、`w_norm_mean` の時系列を共変量として同じ比較を行う。‖w‖ を揃えても差が残るか。
- 理論 v2 §3(d) より、ノイズは ‖w‖⁻²、ドリフトは ‖w‖⁻¹ でスケールする。**µ を一切変えなくても ‖w‖ が伸びれば整列は進む**ので、統制しないと µ の効果と分離できない
- 差が ‖w‖ で説明し尽くされる場合、「µ の効果はノルム媒介」と報告する

### P3-4（C_self 残存・**主判定**）
アーム3、κ=16 で `cos_e1W_e1Sig` が
- (a) 学習に伴い**単調増加**し、
- (b) 最終値の CI 下端が**ランダム床 0.174 を上回る**。

**反証**: 床付近に留まる、または減少。

### P3-5（κ 単調性）
最終値が κ ∈ {1, 4, 16} で単調増加。κ=1 は定義上 NaN なので、実質 κ=4 < κ=16 の比較。

### P3-6（先生の予言そのもの）
`cos_e1W_e1Sig` → 1.0 に収束。**判定は 0.9 到達の有無**。
- 到達しない場合、到達した水準（例: 0.4）を「部分整列」として報告し、**1.0 収束は成立しないと明記する**。srank(W_alive) と併記し、「そもそも rank-1 に落ちていなければ e₁ が支配的でないのは当然」という但し書きを付ける

### P3-7（勾配場と重みの乖離）
同一 checkpoint で `|cos(E[g], u)|` と `cos_e1W_e1Sig` を比較。前者が後者を有意に上回る場合、**「drift は Σ 軸を向いているが、重みはそこに蓄積していない」**という乖離が本レジームでも成立する。
- これは理論 v2 §5(b)「1/‖w‖ による操舵切断」および rank_int_0814 の「病理は状態ではなく力場」と同方向の材料になる
- Phase 0 では乖離が出ている（0.71 vs 0.10）。Phase 2 で消えるか残るかを見る

## 10. 先生への確認事項（返信に載せる）
