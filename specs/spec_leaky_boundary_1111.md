# leaky_boundary_1111: what changes at the adaptation cliff?

Registered 2026-11-11 before the new runs. User clarification: the question is the change AT the boundary, after tolerating sparsity, not whether a late failed state can eventually recover. Recovery with more time and an abrupt dynamical change can coexist. The remembered CondA observation remains unidentified. This is a focused NEW random-label MNIST experiment, motivated by leaky_cliff_1111 discovery a=.003, whose largest online drop was task3→4 in seeds0–2. No phase-transition claim is presupposed.

## Setting and selection
Same host/data/init/Adam arithmetic as leaky_cliff_1111: fixed1200 images,784–100–100–10, batch16, lr=.001, eps=1e-8, float32, one CPU thread, no decay. a=.003 in both layers. NEW seeds3–7 for this a (they were not in the previous a=.003 discovery). Six tasks of6000 updates, natural optimizer history retained. Save native states at age0 and each quarter-task (1500 updates); dense full-bank measurements every75 updates, plus first update. Save params, m/v/tc, label and batch RNG states. Labels/orders must reproduce the old runner for any identical seed/a/horizon.

For EACH seed select j in{1,..,5} maximizing online_acc(task j)−online_acc(task j+1), ties smaller j. Report whether the drop is >=.15; no excluding seeds if it is smaller. The two SOURCE states are ages j−1 and j, i.e. immediately before the two tasks being compared. This distinction avoids pairing end-of-task geometry with the wrong performance. If j=1, age0 is valid. Call the sources pre and post only as event-relative labels.

## Identical probe task at every source state
The same independently generated1200 random labels (dedicated boundary_probe_labels stream) and same independent batch stream are used for every source/arm within each seed. Never reuse a training label sequence to define the probe. Every age0,1,..,6 is probed. Also probe the quarter points j−.75,j−.5,j−.25 along the ACTUAL training path between the selected source endpoints; do not interpolate weights or moments.

Native probes at selected pre/post sources run96000 updates on that ONE fixed task. Other native probes run24000. Thus50 native probes total. From each selected pre/post source run two additional controls for96000 updates: G fixes each input's source activation gates in both layers while parameters still train; L fixes the source full Jacobian and trains the exact linearized model f0+J0*delta using the same Adam state and initial delta0. Each of G/L has10 probes. Total5 prefixes +70 probes. No parameter/head/moment reset in these comparisons. No label change at6000/24000. No other sweep is part of this spec.

G initially has the same forward and Jacobian as N, but uses its original per-input slope masks even when z later changes sign. It retains multiplicative weight interactions. L initially has the same forward and Jacobian, then fixes the full response matrix; its parameter deltas use the source Adam moments. These are diagnostic surrogate models, not claims of attainable functions or capacity of the natural network. Log source masks separately from current preactivation signs; do not call G/L's current z-sign their actual derivative. Verify identical initial parameter update for N/G/L.

## Outcomes and clocks
Full-bank accuracy and CE every75 updates; record exact6000,12000,24000,48000,96000 where present. Online pre-update minibatch means separately. T90 first crossing, sustained-T90 four consecutive evaluations>=.9, CE first-passage thresholds{2,1.5,1,.5,.2,.1}. Unreached is right-censored, never infinity. Also record margins(y−max other logit), distribution/quantiles and near-boundary fraction |margin|<.1; save all logits at0 and registered budgets.

Separate initial old-function removal (T_CE<=2) from further learning time (T_CE<=.5−T_CE<=2). Compare paired pre/post T90 and this learning time, including censoring. Inspect whether the continuous CE and margin distributions change more smoothly than accuracy.

A single-clock check aligns each native CE curve at its first CE<=2 and scales time by the interval to CE<=.5. Compare pre/post CE on51 points between those two times by linear interpolation; report RMSE and first-passage interval ratios for thresholds1.5,1,.5. Approximate single-clock consistency is operationally RMSE<=.10 and max/min finite interval ratio<=2. Report each seed; classify majority consistency only if>=4/5 pass. This is a descriptive test, not a proof of identical dynamics, and cannot be computed if required thresholds are censored. No cherry-picked successful window.

Along the five source positions (pre, three quarters, post), report log T90 and log learning time without averaging seeds before event alignment. Operational sharp slowing requires at least one adjacent-quarter ratio>=2 AND post/pre>=3 in>=4/5 seeds; explicitly label this as a finite-resolution criterion, not a physical phase-transition theorem. Censoring produces bounds and inconclusive comparisons, not automatic positive verdicts.

## Response structure and dynamics
At each dense point per layer record positive branch input fraction, per-unit fraction distribution, mean true derivative, within-input derivative variance, near-one-branch fraction min(p,1−p)<.01, input fraction with zero positive units, m/s/r summaries, and actual used-mask turnover from the previous evaluation. At every750 updates and checkpoint also record centered gate-covariance participation/eigenvalues, centered hidden-feature covariance participation, and unique input gate patterns. These characterize sign-pattern diversity, NOT rank/capacity of the full network.

At the first update and every750 record gradient norms, intended/actual floating-point parameter steps, actual centered-logit displacement, error alignment and realized full-bank CE decrease. Preserve the distinction between individual-step response and whole-curve speed. No scalar mean derivative or gate count alone is a phase classifier.

At source ages{0,pre,quarters,post,6} (deduplicate), characterize the full1200×10 centered-output tangent operator K=J J^T/N with matrix-free products. Use the SAME independent centered one-hot probe demand vector across sources, rather than a changing task residual. Separately use K_D=J D J^T/N with D=(sqrt(vhat)+eps)^−1 frozen at the source; skip this Adam-history diagnostic at age0, whose moments are all zero. Neither operator includes subsequent momentum evolution or CE curvature.

Compute the trace analytically, normalize by trace/(9N), and run128-step fully reorthogonalized float64 Lanczos from the fixed demand. Compare64/128 quadrature estimates of remaining normalized demand at virtual kernel times{1,10,100,1000,10000} and ridge residual factors alpha={1e−2,1e−4,1e−6}. Report absolute convergence differences; do not use a tail statistic for conclusions if64/128 differ by>.03. These are demand-weighted spectral diagnostics, NOT full spectra, minimum-eigenvalue or exact-rank estimates; kernel virtual time is not Adam update time. Also report the unnormalized scale to separate amplitude from relative conditioning. Verify the operator and analytic trace against an explicit small-network Jacobian before use.

## Interpretation tests
1. Budget crossing: both selected native states reach90%, their common-task learning curves approximately obey one-clock rescaling, time grows smoothly across source quarters, and the apparent failure moves with measurement budget. Supports mainly a finite-clock crossing in this window. Recovery alone is insufficient.
2. Structural/kinetic change: native source-time curve has registered sharp slowing and/or single-clock failure, accompanied by a localized change in demand-weighted response or gate-pattern diversity; G/L differ from N across the same source pair. This motivates a concrete bottleneck, not a thermodynamic transition. Correlation alone does not establish mediation.
3. Need to reorganize: if native post-source reaches90% while G or L remains below80% at96000 (paired mean gap>=.15), with pre-source controls less impaired, fixed response/gating is inadequate for recovery in this budget. If G/L fit faster than N, ongoing response changes impose a cost. Quantify endpoint differences and paired95% t intervals; secondary intervals descriptive/unadjusted.
4. Metric amplification: inspect common-task margins and CE at6k across source quarters. A sharp accuracy loss with smoother CE/margins can reflect many margins crossing zero; no fixed numeric verdict will substitute for the distributions.
5. Persistent failure at96k remains censored; no proof of impossibility. No width scaling, hysteresis, basin stability, asymptotic capacity or true critical exponent claim is allowed by this design. Cases may combine slowing and structural change; do not force a binary answer.
