## 0. 問い

V13 の段 ① は「課題を学ぶと読み出しが前のラベルに整列し、ラベルが替わると、その読み出しが前活性を下げる勾配を作る」である。査読（Opus 3 体 × 4 巡）は 3 人とも、この段の証拠が弱いと書いた（2 seed・一隠れ層・事後・段 ① だけを消す介入が無い・Adam の状態と切り分けていない・SGD で照らしていない）。

保存状態の事後の計算（V13 の査読ループ・`obsidian-research-data/v13_review_risk_1110/kari4_1/readout/`・点検 `rv6/`）では、次が分かった（一歩の期待の勾配・2 seed）。

- 課題の末の状態で、読み出しの成分をクラスの間で入れ替えても（ノルムは同じ・前のラベルとの対応だけ消える）、式 2 の期待の勾配の和は 0.77〜1.56 倍だった。
- 課題 1 の途中（reload_dial_1020 の checkpoint）では、同じ入れ替えで和は 0.08〜0.44 倍だった（点検役の計算）。
- 実の 200 更新の沈みとの順位相関は、整列の無い読み出しの平均の勾配のほうが高かった（点検役の計算）。

この走は、同じことを**学習の動き**で確かめる。問いは五つ。

- **Q1（整列）**: 課題の末で読み出しの整列だけを壊すと（ノルムは保つ）、切替の後 200 更新の沈みと、課題の末の精度の不足は変わるか。
- **Q2（大きさ）**: 整列を保ったまま読み出しを初期化の時点のノルムへ縮めると、沈みは消えるか。
- **Q3（最適化器の状態）**: 隠れ層の Adam の状態だけを捨てると、沈みと不足はどうなるか（V13 §4.1 の H0A は出力層も 0 にしていた）。
- **Q4（SGD）**: 命題が扱う SGD でも、切替の後の沈みと課題を重ねた喪失は起きるか。Lyle ら 2023 の Adam（β2 = 0.9・内側の ε = 1e-3）ではどうか。
- **Q5（毎回の介入）**: 全ての切替で整列を壊す・出力層を 0 にする（Dohare らの作法）・隠れ層の Adam を捨てる軌道で、沈みと喪失は課題を重ねて積もるか。

## 1. 箱

**C1（engine との一致）**: Adam・lr 1e-3 の本線 S は、seed 0・1 で保存済みの状態（`push_direction_proof_0930/states`）と、全 30 課題の末と +200 更新で bit 一致すること（走の中で assert）。登録の前に LR seed 0 と SiLU seed 1 で回して確かめた（§9）。

## 2. 走

### B1 分岐の腕（Adam・lr 1e-3・5 活性化 × seed 0〜9）

本線 S を 30 課題回す。課題 t ≥ 2 の頭（課題 t−1 の末の重みと Adam の状態）を複製し、腕ごとに一度だけ介入して、課題 t を 4,000 更新回す（ラベル・順は S と同じ）。腕は次の課題へは進まない。

| 腕 | 介入 | 何を見るため |
|---|---|---|
| S | なし（本線） | 基準 |
| P0 | 全ユニットで同じクラスの並べ替え π。読み出しの行・出力の bias・それらの Adam の状態を同じ π で並べ替える | ラベルの付け替えと厳密に同じ網。S と統計的に同じはずの帰無 |
| P0m | P0 と同じ並べ替えを読み出しにだけ施し、bias は P の規則で直す | P の bias の規則の帰無 |
| P | ユニットごとに独立なクラスの並べ替え（各ユニットの読み出しの値の集合とノルムは同じ）。読み出しの Adam の状態も同じ並べ替え。bias は標本で平均した logit を保つ（b ← b + (V − V′)ā） | 整列だけを壊す（Q1） |
| Q | 各ユニットの読み出しの中心化した成分を、その seed の初期化の時点のノルムへ縮める（向きは保つ）。bias は P と同じ規則。Adam の状態は保つ | 整列を保って大きさだけ縮める（Q2） |
| R | 出力層を初期化と同じ分布から引き直し、出力層の Adam の状態を捨てる | 初期化の時点の乱数の読み出し（Li・Shvetsov の領域）。出力層の初期化し直し |
| H0 | 出力層を 0 にし、出力層の Adam の状態を捨てる | 読み出しの寄与が無い基準（V13 の D.6 の H0） |
| H0A | 出力層を 0 にし、全ての Adam の状態を捨てる | V13 の D.6 の H0A |
| A0 | 隠れ層の Adam の状態だけを捨てる | Q3 |
| F200 | 最初の 200 更新は隠れ層の勾配を捨てる（隠れ層の重み・bias・Adam の状態は動かない） | 切替の直後の押しを体に届けない |
| fa | 新品の網（専用の乱数列の初期値・新品の最適化器） | 不足の基準 |

### B2 分岐の腕（SGD・5 活性化 × seed 0〜9）

最適化器を SGD（運動量なし。engine の `--opt sgd` と同じ）にして B1 と同じことをする。腕は S・P0・P0m・P・Q・R・H0・F200・fa（Adam の状態の腕は無い）。学習率は C-SGD で決める。

**C-SGD（学習率の較正）**: 格子 {0.01, 0.03, 0.1, 0.3, 1.0}、較正の seed 100〜102、本線だけ 30 課題。活性化ごとに、30 課題の末の訓練精度の平均（3 seed の平均）が最大の学習率を選ぶ。発散（損失が非有限）した学習率は除く。同点（差 0.005 以内）なら小さい方。

### B3 分岐の腕（Lyle ら 2023 の Adam・5 活性化 × seed 0〜9）

β1 = 0.9・β2 = 0.9・平方根の内側の ε = 1e-3（外側 1e-8）、lr 1e-3。腕は S・P・H0・A0・fa。

### T 毎回の介入の軌道（Adam・lr 1e-3・5 活性化 × seed 0〜9）

腕 X ∈ {P, Q, R, H0, A0, F200} の介入を、全ての切替（t ≥ 2）で施しながら 30 課題を回す（Pall・Qall・Rall・H0all・A0all・F200all）。ラベルと順は S と同じ。新品の基準は B1 の fa を使う。

### D 課題 1 の途中からの切替（Adam・5 活性化 × seed 0・1）

`obsidian-research-data/reload_dial_1020/raw/ckpt` の checkpoint（初期値・訓練精度 20・50・80・95%・課題 1 の末。重みと Adam の状態）から、新しい乱数ラベル 5 通りへ、読み出し S・P0・P・Q で切り替え、200 更新回す。

## 3. 測る量

課題 t の腕 X について（更新 0 は介入の後）。

- **数えるユニット**: 更新 0 で、少なくとも一つの入力で前活性が正のユニット（V13 付録 D.1 と同じ）。
- **D200**: 数えるユニットのうち、前活性の平均 m が更新 0 から 200 で下がったものの割合。
- **sink200**: 数えるユニットの −(m(200) − m(0))/σ(0) の中央値（σ は更新 0 の前活性の標準偏差）。
- **Σpush**: 更新 0 の式 2 の期待の勾配 S_i の、数えるユニットでの和（正が下げる向き）。
- **acc_end**: 課題の末（4,000 更新）の、1,200 枚での訓練精度。
- **不足** def_X = acc_end(fa) − acc_end(X)（同じ課題・同じラベル・同じ順）。
- **閉じた割合**: 更新 4,000 で、全ての入力で前活性が負のユニットの割合。

帯: 課題 2〜3・4〜8・9〜19・20〜30（V13 付録 D.1 と同じ）。各 seed で帯の中の課題の平均を取り、10 seed で比べる。ReLU は、S の数えるユニットが 3 個以上の課題までを数える。

## 4. 比

読み出しの寄与を 0 にした腕（H0）を基準にした比で読む。Y は D200 か sink200。

- ρ_align = (Y_S − Y_P)/(Y_S − Y_H0): 読み出しの効きのうち、整列が要る割合。0 なら大きさだけで足り、1 なら整列が無いと全部消える。
- ρ_norm = (Y_S − Y_Q)/(Y_S − Y_H0): 整列を保って大きさを縮めたときに消える割合。
- ρ_null = (Y_S − Y_P0)/(Y_S − Y_H0)、ρ_nullm = (Y_S − Y_P0m)/(Y_S − Y_H0): 帰無（0 のはず）。
- 不足の除去率 rem_X = (def_S − def_X)/def_S: 腕 X が S の不足のどれだけを除いたか。

区間: 10 seed の帯の平均を seed で再標本化する bootstrap（10,000 回・百分位の 95%）。比は再標本ごとに計算する。

## 5. 判定（帯 × 活性化ごと）

閾値の 0.5 は「読み出しの効きの半分」という比の定義から来る。

- **J0（帰無）**: Y_S − Y_H0 の 95% 区間の下端が 0 より大きいこと（READOUT_EFFECT）。そうでなければ NO_READOUT_EFFECT で、その帯の J1・J2 は判定しない。ρ_null と ρ_nullm の 95% 区間が 0 を含むこと。含まなければ NULL_FAILS と書き、その帯の J1 は INCONCLUSIVE とする。
- **J1（Q1・整列）**: ρ_align の 95% 区間の上端 < 0.5 なら ALIGN_NOT_NEEDED、下端 > 0.5 なら ALIGN_NEEDED、それ以外 MIXED。D200 と sink200 で別々に判定し、主は D200。
- **J2（Q2・大きさ）**: ρ_norm の区間の下端 > 0.5 なら NORM_NEEDED、上端 < 0.5 なら NORM_NOT_NEEDED、それ以外 MIXED。
- **J3（Q3・Adam の状態）**: (a) D200_A0 − D200_S の 95% 区間（seed の bootstrap）が 0 を含めば SINK_SAME、下端 > 0 なら SINK_MORE、上端 < 0 なら SINK_LESS。(b) 課題 21〜30 の rem_A0 の区間の下端 > 0.5 なら LATE_LOSS_MOSTLY_ADAM、上端 < 0.5 なら LATE_LOSS_NOT_ADAM、それ以外 MIXED（def_S の区間の下端 > 0 のときだけ）。
- **J4（Q4・SGD と Lyle の Adam）**: B2・B3 の S で、D200_S − D200_H0 の区間の下端 > 0 なら SINK_PRESENT、上端 < 0.05 なら SINK_ABSENT（0.05 は 1,000 ユニット中の数え方の分解能の 50 倍。D200 は 0〜1 の割合）。課題 21〜30 の def_S の区間の下端 > 0 なら LOSS_PRESENT、上端 < 0.02 なら LOSS_ABSENT（0.02 は 1,200 枚で 24 枚）。B2 の J1 も B1 と同じ規則で判定する。
- **J5（Q5・毎回の介入）**: 課題 21〜30 の不足の比 def_Xall/def_S（seed の bootstrap）。区間の上端 < 0.5 なら LOSS_REMOVED、下端 > 0.5 なら LOSS_KEPT、それ以外 PARTIAL。前活性の平均の積もり: 各ユニットの m の、課題 2 の頭から課題 30 の末までの変化の中央値（数えるユニット）で、Xall と S を同じ規則で比べる（SINK_REMOVED / SINK_KEPT / PARTIAL）。
- **J6（D・課題 1 の途中）**: checkpoint ごとに、Σpush_P/Σpush_S と D200_P − D200_S（5 draw × 2 seed の平均）を記述する（2 seed なので区間は書かない）。
