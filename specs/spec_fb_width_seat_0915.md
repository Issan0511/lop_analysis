## 0. 一行

condA で第 1 層の幅（各ユニットの自由 5 ビットへの重みのノルム ‖w_free‖₂）を t20 の値で止め、同じ t20 状態から SGD（batch 1）と full-batch GD（32 パターン厳密勾配）に分岐させる。**幅を止めると沈みは止まるか（Q2）**と、**止まった上端 zmax が雑音の有無で違うか（Q1）**を測る。

## 1. 何を分けるか

- condA では自由 5 ビットの 32 パターンが z̄ の周りで対称なので、**z̄ ≡ zmax − ½‖w_free‖₁**（恒等式）。‖w_free‖₂ を止めると、z̄ が動ける経路は上端 zmax と形 κ = ‖w_free‖₁/‖w_free‖₂（1〜√5）の 2 本に限られる。
- Issa の観察「full-batch でも沈む」（[[駆動源問題_0909]] §2.1）は、幅が育つ腕での観察である。
- 先生の 5 項式は、同じ 5M 状態から 1 タスク回した SGD と full-batch GD の差を「雑音」と定義した（格 C・蹴りを除く）。k_on（flip 直前に z > 0 となる支持点の数・32 点中）で群に分けると、雑音は**跨ぐ群を下げ**（k_on ≥ 3 で −0.219、主に第 5 項 T_5）、**全点負の群を上げる**（k_on = 0 で +0.032、主に第 4 項 T_4＝雑音の浮力）。
- 長い地平線でこの 2 つの向きのどちらが勝つかは、幅が育つ腕では幅の違いと混ざって読めない（`offset_grid_0906` の summary も full-batch 腕と lr 0.01 腕の水準比較を禁じている）。本走は**幅と t20 までの履歴を揃えて**、雑音の有無だけを変える。

閉じる穴: [[駆動源問題_0909]] §5.1 のうち「full-batch でも残る成分」を、幅の成長と切り分けて測る。先生の (F9)（Issa 側 full-batch 腕の沈む速さとの照合）は既存 `FBLRoff0_1216` のログで走なしで行うので範囲外。

## 2. 箱と腕

箱は `offset_grid_0906` の `LRoff0_1216` と同一: condA（15 flip ビット＋自由 5 ビット）・幅 100・深さ 1・leaky a = 0.1（`leaky_off_0`・dial 0.1）・MSE・lr 0.01・T = 10⁴ step/タスク・centered_layers [1]・用量 12.16・seed 0–9・5M step（500 タスク）。

| ブロック | 腕                 | t1–20     | t21–500 の学習   | t21–500 の幅       | 役割                       |
| ---- | ----------------- | --------- | ------------- | ---------------- | ------------------------ |
| 親    | `LRoff0_1216`     | SGD       | SGD           | 自由               | G1（既存ログと byte 一致）・SGD 自由 |
| 主    | `LRwf21_1216`     | SGD（親と同一） | SGD           | w_free 固定        | SGD 幅固定                  |
| 主    | `FB21LRoff0_1216` | SGD（親と同一） | full-batch GD | 自由               | GD 自由                    |
| 主    | `FB21LRwf21_1216` | SGD（親と同一） | full-batch GD | w_free 固定        | GD 幅固定                   |
| 診断   | `LRwi21_1216`     | SGD（親と同一） | SGD           | w_free・w_flip 固定 | 入力重み全体を固定（判定なし）          |
| 診断   | `FB21LRwi21_1216` | SGD（親と同一） | full-batch GD | w_free・w_flip 固定 | 同上                       |

- 分岐腕も step 0 から走らせる。step 200,000（t20 終端）までは親と同じ演算・同じ乱数で進む（G2 で検算）。
- full-batch に切り替えた後も `env.step()` は毎 step 呼び、flip の時刻と乱数消費を親と揃える（`train_arm_full_batch` と同じ規則）。
- **分岐にする理由**: SGD 腕と GD 腕を step 0 から別々に走らせると、t20 の幅（基準ノルム）が腕ごとに違い、着座点の比較に幅の違いが混ざる。分岐なら固定 2 腕は n_i と履歴が同一で、違いは t21 以降の雑音の有無だけになる。

## 3. 介入の定義

- **基準ノルム**: step 200,000 の記録時点（t20 終端・flip 前・200,000 回更新後）で、各 seed・各ユニット i について n_i = ‖W1[i, 15:20]‖₂。診断ブロックは f_i = ‖W1[i, 0:15]‖₂ も取る。
- **射影**: step 200,000 以降のすべての更新（`sgd_step_layers` の直後）で W1[i, 15:20] ← W1[i, 15:20] · n_i / ‖W1[i, 15:20]‖₂。ノルム 0 のときは射影せず回数を記録する。主ブロックでは b1・W1[:, 0:15]（w_flip）・v・c・中心化の running mean に触らない。診断ブロックは w_flip も同じ規則で f_i へ射影する。
- **full-batch 切替**: step 200,000 以降の更新を 32 パターン厳密勾配（`full_support_ro`・`forward_gate_batch`・`grads_centered_elu_batch`）で行う。lr は 0.01 のまま（SGD の平均流と同じ）。
- **実装**: 新しいフック `branch`（`{switch_step: 200000, full_batch: bool, clamp: none | free | free_flip}`）と、`train_arm_edge` の逐語の写しに挿入行を足した学習関数で行う。フックの無い腕は宿主の関数そのものを通る（既存の S-hook-noop の規則）。

## 4. 検査

- **G0 自己検査（スモーク・切替を step 20,000 に置いた 4 タスク）**
  - S-noop: フックなしの腕が宿主の関数と bit 一致。
  - S-prefix: 分岐腕の切替前の記録が親と byte 一致。
  - S-clamp: 射影直後の ‖W1[i, 15:20]‖₂ と n_i の相対差 ≤ 1e−6。主ブロックでは射影の前後で W1[:, 0:15]・b1・v・c が bit 一致。
  - S-flip: 分岐腕の flip 時刻と `flip_state` が親と一致。
  - 変異対照（どれも検出されること）: (m1) w_flip を射影する、(m2) 基準ノルムを毎 step 現在値で更新する（射影が恒等になる）、(m3) 切替を 1 タスクずらす。
- **G1**: 親 `LRoff0_1216` の全ログが `results/act_offset_0906/logs/LRoff0_1216_seed*.npz` と byte 一致（同じマシン）。別マシンなら `ENV_CHANGED` を記録し、判定は走内の比較だけで行う。
- **G2**: 分岐 5 腕の t1–20 の記録（1000 step ごとの記録とタスク終端）が親と byte 一致。
- **M1（操作チェック）**: 固定腕の t21–500 の全タスク終端で max |‖w_free‖₂ / n_i − 1| ≤ 1e−5（診断ブロックは w_flip も）。
- **M2（成長の実在）**: 自由腕（親・`FB21LRoff0_1216`）で、‖w_free‖₂ のユニット中央値の t451–500 平均 ÷ t20 値 ≥ 1.5。満たさない腕を含む比較は Q2 を `NOT_DETERMINED_NO_GROWTH` とする。
- **発散**: `NUMERIC_DIVERGENCE` の seed は除く。主ブロックのどれかで 3/10 超なら全判定 `NOT_DETERMINED`。

## 5. 登録判定

**集約（全判定共通）**: タスク終端（flip 前）の記録を使う。各 seed・各タスクでユニット 100 個（ALL。ALIVE 規則は使わない）の中央値 → 窓内のタスク平均 → seed ごとの値。腕の比較は seed 対応の差（同じ seed は t20 状態と flip 列を共有する）。CI は seed bootstrap 2000・`numpy.random.default_rng(20260915)`・95% 百分位。

### Q2 幅を止めると沈みは止まるか（先に判定する）

量: Δz̄_late = z̄(t451–500) − z̄(t251–300)。

- **`STOPS_WITHOUT_GROWTH`**: 固定 2 腕（`LRwf21`・`FB21LRwf21`）とも Δz̄_late の CI ⊂ [−0.1, +0.1]、かつ対応する自由腕（親・`FB21LRoff0`）の CI 上端 < −0.1。
- **`KEEPS_SINKING`**: 固定腕のどちらかで CI 上端 < −0.1。
- **`NOT_DETERMINED`**: それ以外（自由腕が沈み続けていない場合・M2 不成立を含む）。

報告: 腕ごとの判定、κ のユニット中央値の t20 → t451–500 の変化（z̄ が κ 経由で動いた分の上界 ½·Δκ·n_i）。

### Q1 止まった上端 zmax は雑音で違うか（主判定）

前提: Q2 で固定 2 腕とも Δz̄_late の CI ⊂ [−0.1, +0.1]。満たさなければ `NOT_DETERMINED_MOVING`。

量: Δzmax = zmax(`LRwf21`) − zmax(`FB21LRwf21`)、窓 t451–500。

- **`SEAT_SAME`**: CI ⊂ [−0.15, +0.15]（最初に評価する）。
- **`NOISE_LIFTS_SEAT`**: CI 下端 > 0（SGD の方が高い＝雑音の浮力が勝つ）。
- **`NOISE_SINKS_SEAT`**: CI 上端 < 0（GD の方が高い＝跨ぐ群を沈める T_5 が勝つ）。
- **`NOT_DETERMINED_WIDE`**: CI が 0 をまたぎ、かつ ±0.15 に収まらない。

±0.15 は T_5 の帯（|z| < 0.3）の半分として置いた。

## 6. 報告のみ（判定しない）

## 8. 引用制限・範囲外

- condA・leaky a = 0.1・lr 0.01・幅 100・深さ 1 に限る。Adam 系や RL-MNIST（[[第1層の押し込みを正側・帯・谷の奥に割る_結果_0915]] §12 の箱）へ外挿しない。
- 分岐腕の t1–20 は SGD。最初から full-batch の腕（`FBLRoff0_1216`）とは履歴が違うので水準を並べない。
- 幅固定は人工的な射影であって、学習手法ではない。
- Q1 は幅を揃えた条件での雑音の**正味**の向きであり、T_4 と T_5 の寄与率ではない（診断効果を足し合わせて寄与率にしない）。
- 先生の (F9) は範囲外（既存 `FBLRoff0_1216` のログで走なしで行う）。
