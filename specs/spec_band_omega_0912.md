## 0. 何を決めるか

**Issa の観察**: ELU は 0 のすぐ下、ゲートが 0.25〜1 に残っている**浅い帯**に前活性がたくさんいる。実測（late t101–120・seed 中央値・(ユニット, 入力) の割合）:

| | 正側 | **浅い帯** | 深い側 φ′<0.25 | ω | L |
|---|---:|---:|---:|---:|---:|
| leaky | 0.158 | **0.000** | 0.842 | 6.49e−4 | 2.28 |
| ELU τ=1 | 0.194 | **0.094** | 0.712 | 5.34e−4 | 1.86 |
| ELU τ=3 | 0.285 | **0.433** | 0.282 | 6.65e−4 | 0.65 |

**leaky の浅い帯は構造的にゼロ**（負側が一律 0.1 なので 0.25〜1 の領域が存在しない）。正側の割合は両者ほぼ同じで、**違うのは負側の使い方だけ**。ELU 6 腕で浅い帯は損失を −0.89 で並べ、ユニット内でも「ゲートが開いている入力の割合」が回転速度を **+0.87**（3 seed）で並べる。

**私の仮説（本走で試す）**: **ELU では幅クランプが「長さを縮める」と「浅い帯を広げる」を同時にやっている。** 実測で浅い帯は 0.094 → 0.145（τ=1）、0.433 → 0.592（τ=3）と**クランプで増える**。leaky は 0.000 のまま。だから ELU は ω 1 オクターブあたりの利得が大きく見え、傾きが **−1.59**（leaky は −1.06 pt/octave）になっている。

**決着のさせ方**: [[回る速さが幅の正体か_結果_0912]] の設計（クランプの高さ κ と lr を**逆向きに同じ倍率**で動かし、長さが 2 倍違うのに ω が同じ対を作る）を **ELU τ=1 でそのまま回す**。
- leaky ではこの対の目減りが **+0.09 / −0.10 / +0.39 pt** と一致した（`K1` の遅い対）。
- **浅い帯が ω と独立のレバーなら、ELU では同じ対が割れる**。κ=1 の腕（短い・帯が広い）が κ=2 の腕（長い・帯が狭い）より良くなるはず。
- 割れなければ、浅い帯は ω を通してしか効いておらず、傾きの差は別の理由になる。

可検定性（独立に記録）: L(`E0`) − L(`E1`) ≥ 1.0 pt（実測 1.86）。

**Q1 決定的 — ω を揃えた対は ELU でも一致するか**: 遅い対 $d_{\rm s}$ = L(`E1h`) − L(`E2`)、速い対 $d_{\rm f}$ = L(`E1d`) − L(`E05`)。
- |d_s| < 0.3 かつ |d_f| < 0.3 pt → **`OMEGA_SUFFICES_IN_ELU`**（leaky と同じ。浅い帯は ω 経由でしか効かない）
- **d_s ≤ −0.5 pt（κ=1 が良い）** → **`BAND_SPLITS_THE_PAIR`**（浅い帯が独立のレバー）
- d_s ≥ +0.5 pt → `BAND_SPLITS_INVERTED`
- 他 → `Q1_PARTIAL`

**Q2 ELU の傾きは leaky と同じか**（同じ設計で測り直す）: 5 腕 × 3 seed の $\log_2\omega$ に L を当てはめた傾き $b_{\rm ELU}$。
- |$b_{\rm ELU}$ − (−1.06)| < 0.3 → **`SAME_SLOPE_AS_LEAKY`**（τ ダイヤルで出た −1.59 は、帯と ω が束になっていた見かけ）
- ≥ 0.6 → **`ELU_SLOPE_STEEPER`**
- 他 → `Q2_PARTIAL`

**Q3 κ と lr は浅い帯を動かすか**: $B$(`E2`)/$B$(`E1`)、$B$(`E05`)/$B$(`E1`)、$B$(`E1h`)/$B$(`E1`)、$B$(`E1d`)/$B$(`E1`)。
- κ で 1.2 倍以上動き lr で 1.2 倍未満 → **`BAND_MOVES_WITH_KAPPA_ONLY`**（帯は長さの従属変数）
- どちらでも 1.2 倍未満 → `BAND_STATIC`／lr でも動く → `BAND_MOVES_WITH_BOTH`

**Q4 ω を効かせた後に帯は残るか**（5 腕 × 3 seed = 15 点）: $\log_2\omega$ に L を当てはめた残差と $\log B$ の Spearman。
- |Spearman| ≤ 0.3 → **`BAND_ADDS_NOTHING`**／≥ 0.6 → **`BAND_ADDS_BEYOND_OMEGA`**／他 `Q4_PARTIAL`

**可検定性**: 発散は `DIVERGED`。late のタスク内 CE 改善が 90% 未満なら `LEARNING_BROKEN`（`E1d` は lr 2 倍、`E05` は κ 0.5 なので要注意）。

## 7. 限界（結果前に明記）

- t120・3 seed・τ=1 のみ・κ 3 水準・lr 3 水準。
- **κ≠1 は t21 で ‖W̃ᵢ‖ を不連続に κ 倍する。** `acc(t21–25)` を副測定で記録して過渡を開示する。
- lr を動かすと ω 以外（Adam の実効温度）も動く。対は κ と lr を逆向きに動かすので、**lr の副作用は対の内部で打ち消されない**（[[回る速さが幅の正体か_spec_0912]] §7 と同じ交絡）。
- **浅い帯 B と長さは物理的に結びついている**（短い → 前活性の散らばりが小さい → 0 付近に集まる）。Q1 が割れても「帯が効いた」と「長さが ω 以外の経路で効いた」は分離できない。分離には帯を長さと独立に動かす手（τ とクランプの同時操作）が要る。**本走では分離しない。**
- `E1`・`E0` は `elu_turn_0912` からの持ち込み。同設計・同計装だが同一走ではない。
