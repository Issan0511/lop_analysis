# オラクル中心化 spec 追補1 — 境界マスクから初期過渡を外す

> 本追補は `center_oracle_0831` の結果を見る前に commit された。親 spec の P1 は endpoint の定義を `centered死因分解_posthoc_spec_0831` §2 E3 から継承していたが、その定義に欠陥が見つかったので継承先を差し替える。判定閾値（0.2 / 0.8）は変更しない。

## 1. 直す欠陥

E3 の境界窓マスクは `step % 10000 == 1000` で定義され、500 個の遷移を拾う。しかし `flip_state` の変化は seed あたり 499 回しかない。差の1個は step 0 → 1000 の遷移で、タスク切替ではなく EMA の初期収束過渡である。

オラクル腕は支持平均を step 0 から厳密に引くので EMA の初期収束過渡が構成上存在せず、500点版は分母 A1 だけへ非対称な初期過渡を混入させる。このため閾値を動かさず定義を直す。

## 2. 差し替える定義

- **境界窓**: `step % 10000 == 1000` かつ当該遷移で `flip_state` が実際に変化した遷移。499個。
- **内部**: `step % 10000 != 1000` の遷移。4500個。
- **初期過渡**: step 0 → 1000 の遷移。1個。どちらにも入れず単独報告。

追加サニティ S9: 境界窓マスクの要素数が `flip_state` の変化回数と seed ごとに一致し、499 = 499 であること。不一致なら走は破棄しないが endpoint を出さない。

## 3. 報告の形

`verdict.csv` に腕ごとに以下を出す。

1. `dbeta_boundary_499`（P1 の判定に使用）
2. `dbeta_internal_4500`
3. `dbeta_startup_0to1000`（REPORT_ONLY）

登録定義（500）版の R も REPORT_ONLY で併記する。両者で判定が割れた場合はその事実を記録し、P1 は499版を採る。
