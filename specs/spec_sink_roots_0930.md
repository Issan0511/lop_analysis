### 1.1 全走で記録するもの（本体の依頼 1・2 を含む）

- **時間の格子**: 切替（更新 0）から 500 更新まで 25 刻み、以降 250 刻み、課題末を必ず含む。
- **unit ごと（各隠れ層）**: m = 入力平均の前活性（全 1,200 枚の z の平均）、k = 開いた入力（z > 0）の数、上端 = z の最大値、幅 s = z の標準偏差。
- **Adam の一歩**（各層）: u = m̂/(√v̂ + ε)（更新は −lr·u）の unit 平均・|u| の平均・入力平均方向の成分 u·μ + u_b・符号の揃い Σ_j μ_j sign(u_ij)/Σ_j |μ_j|。読み出しは unit ごとに |u| の平均と |Σ_k u_ik|/Σ_k |u_ik|。
- **全データの誤差**: CE、正答率、平均 |p − y|₁、p_old（旧ラベルの確率）の平均、1 − p_new の平均、その他の確率、最大確率の平均、余裕（正解 − 次点の logit）の中央値を新ラベル・旧ラベルそれぞれで、logit の中心化後の RMS。
- **期待の押しの場**（最後の隠れ層）: S_cancel_i = ⟨K_n φ′(z_in) v_i^c·p_n⟩、A_new_i = ⟨K_n φ′ v^c_{i,y_new(n)}⟩、A_old_i = ⟨K_n φ′ v^c_{i,y_old(n)}⟩（⟨⟩ は全 1,200 枚の平均、K_n = 層入力·μ + 1、v^c はクラス平均を引いた読み出し）。
- **谷**（GELU・SiLU、各層）: 谷底 z_c（GELU −0.75179、SiLU −1.27846）より下の (入力, unit) の数、その要求 u_in = ∂ℓ_n/∂a_in が負（出力を上げたい＝φ′ < 0 のもとで z を下げる向き）の割合、要求の打ち消し部（v^c·p）と正解部（−v^c_y）それぞれが負の割合、次の格子点までに z が上がった割合・z の変化の平均・z_c より上に出た割合。閉じた対（z ≤ 0）と開いた対の要求が負の割合（全活性化）。
- **2 層**: 第 2 層の入力の対の核 a₁(x)·a₁(x′) + 1 の最小値と負の割合（本体の依頼）。
- **課題ごと**: online 正答率、課題末の正答率、入力ごとの被覆（最後の隠れ層で開いている unit の数、切替時と課題末）と課題末の正誤。

**登録前に決めたこと（下調べ、ELU seed 0、課題 1–3 だけ）**:
- 本体が依頼した「切替で v̂ だけ初期化（m は残す）」は、最初の一歩が |m|/|g| の大きさになり網が壊れる（GELU で課題 3 の正答率 0.10）。v だけの初期化は Adam の一歩の上限（|m̂/√v̂| ≲ 1）を外す操作なので、adamreset（m も初期化）に替えた。
- logit の上限 f → 2·tanh(f/2) は、課題 2 から学習が止まった（ELU で課題 2・3 の正答率 0.27・0.12。飽和で勾配が消える）。自信を下げる 2 本目の操作は logit の締め付けにし、λ を {0.003, 0.01, 0.03} から、課題 1–3 の正答率を落とさず（≥ 0.95）最大確率を最も下げる 0.03 にした（課題 3 末の最大確率の平均 0.68、基準 0.89、ls01 0.85）。

### 2.2 量

- 押し P_{i,t} = m_i(t, 200) − m_i(t, 0)、戻り R_{i,t} = m_i(t, T) − m_i(t, 200)（T16k では T = 16,000、加えて 4,000 での R も）。課題 t = 5〜30（26 の切替）。
- 集計する unit: (a) 切替時に開いた入力を持つ unit（k_i(t, 0) > 0）、(b) 全 unit（本体の依頼 4）。
- **ρ_med**（中央値どうしの比）= −median_t(median_i R_{i,t}) / median_t(median_i P_{i,t})。
- **ρ_unit**（unit ごとの比の中央値）= median over (i, t) with P_{i,t} < 0 of (−R_{i,t}/P_{i,t})。
- **主量は (a) の ρ_med**。seed ごとに出す。

### 2.3 判定

腕と base の差 Δ = ρ_med(腕) − ρ_med(base)（同じ活性化・同じ seed）。
- **UP**: 3/3 seed で Δ > 0、かつ Δ の中央値 ≥ 0.10。**DOWN**: その逆。**FLAT**: |Δ の中央値| < 0.05。**MIXED**: それ以外。
- 閾値 0.10 は、下調べ（drive_recon_0930 の runs_ref）で base の ρ_med の seed 間の幅が最大 0.11（LR 0.73〜0.84）、ELU 0.08・SiLU 0.05・GELU 0.01 だったことから、「seed 間の違いより大きい」の下限として置いた。
- **TIMEOUT**（T16k の中で）: ρ_med(16,000) − ρ_med(4,000) が 3/3 seed で ≥ 0.10。
- 機構の読み（活性化ごと、上のラベルの組から機械的に）:
  - 記憶（分母に切替の記憶が残る）: b2_09 と vrestore がともに UP。
  - 記憶でない: b2_09 と vrestore がともに FLAT。
  - 自信（Issa の読み）: ls01 と sq003 がともに UP。
  - 門: bwfloor が UP。
  - 谷: bwabs が UP。
  - 時間切れ: TIMEOUT。
- 記述（D）: 押しの大きさ、課題あたりの正味の変位 m(T) − m(0)、p⁺・k・上端・全閉の割合の 30 課題の軌跡、adamreset と T1k の ρ、切替時の p_old と余裕、時間の形（§1.1）。

## 6. R11 — 範囲

### 6.1 R11a: ラベルの保持率 τ（M1、ELU・GELU・SiLU・LR、seed 0–2、30 課題）

- 課題 2 以降、各入力について独立に確率 τ で旧ラベルを保ち、残りは base と同じ一様の抽選（保持の抽選は別の乱数列 "tau_keep_0930"。τ = 0 は base と同じ計算）。τ ∈ {0.25, 0.5, 0.75, 0.9}（0 は R3 の base）。16 腕 × 3 seed = 48 走。
- 式（0925 ノート §1.2 の相関ラベルの行、SGD の期待値）: E[新ラベル | 状態] = τ·onehot(y_old) + (1 − τ)·一様、予測を p ≈ γ·onehot(y_old) + (1 − γ)·一様 と書くと、期待の押しは −(γ − τ)·A_old_i に比例する（A_old は旧ラベルとの整列。下調べで大半の unit で正）。
- 量: 課題 t の γ̂_t = (切替時の p_old の平均 − 1/K)/(1 − 1/K)。押し P̃_t = 切替時に開いた unit の P_{i,t} の中央値。
- **Q11a**: (τ, t)（t = 5〜30）のうち |γ̂_t − τ| > 0.1 の組で、sign(P̃_t) = sign(τ − γ̂_t) となる割合を活性化・seed ごとに。3/3 seed で ≥ 0.9 なら **SIGN_FOLLOWS_GAMMA_MINUS_TAU**、3/3 seed で ≤ 0.6 なら **SIGN_NOT_EXPLAINED**、それ以外 **PARTIAL**。記述: P̃ と (γ̂ − τ)·median(A_old) の順位相関。

### 6.2 R11b: 5+1 CIFAR（ELU・GELU・SiLU・LR・R・KKT1、seed 0–2）

- **CIFAR-100 がこのマシンに無い**（cifar5p1_mlp_0920 の worktree とともに消えている）。取得には Issa の許可が要るので、許可が出たら本節の走を回す。取得した archive の sha256 を `cifar5p1_mlp_0920` の provenance の値と照合してから使う。
- 量: 切替時と格子点 {0, 10, 25, 50, 78, 150, 300, 500, 780} で、層 1・2 の unit ごとの m・p⁺・上端を、その課題の訓練画像と固定の検査画像（CIFAR-100 の test から seed ごとに固定の 2,000 枚）の両方で。切替の蹴り = 旧重みのまま画像だけ新課題に替えたときの m の差。第 2 層の期待の押しを、実際の新ラベルで打ち消し部 ⟨K φ′ v^c·p⟩ と新クラス部 −⟨K φ′ v^c_{i,y_new}⟩ に分ける。
- **Q11b**: 押し（格子点 78 の m の変位、その課題の画像、切替時に開いた unit）の中央値が負の課題の割合を層・活性化ごとに。記述が主（この箱の押しの式は乱数ラベルの期待値の式とは違う）。予測は §9.1。

### 9.2 本体（「ELUが沈降しない事件」、0930 のメッセージの写し。導出の前の見立て）

- Issa の読み「戻りが小さいのは、自信があるときの残差が小さいから」が効いているなら: ラベル平滑化と logit の上限で 戻り ÷ 押し が全活性化で上がる。押しそのものも小さくなる。
- Adam の下では、残差が小さいだけでは一歩は縮まない（分母も一緒に小さくなれば一歩は戻る）。一歩が縮む道は 2 つで、分母に切替の記憶が残る道と、平均が揺らぎに埋もれる道。
  - 記憶の道なら: β₂ 0.9 と「+200 で v̂ を切替前に戻す」で 戻り ÷ 押し が大きく上がる（ELU で 0.85 以上）。課題長 16,000 でも上がる。
  - 揺らぎの道なら: その 2 腕でも 戻り ÷ 押し はほとんど変わらない（ELU で 0.75 未満）。課題長を 4 倍にしても戻りは対数程度しか伸びない。
- 門が閉じる道なら: 戻りの窓で負側の微分を 0.1 に底上げした腕で、ELU の 戻り ÷ 押し が leaky 並み（0.73 以上）になる。GELU・SiLU は |φ′| の腕で上がる。
- 本体の見立て（外れる前提で記録）: ELU は揺らぎと記憶の両方が効き、β₂ 0.9 で 0.75〜0.9。GELU・SiLU は谷が主で、β₂ を変えても 0.5 未満のまま、|φ′| の腕で 0.6 以上に上がる。平滑化は全活性化で比を上げる。
- 注: 本体の「logit の上限」の腕は §2.1 のとおり logit の締め付け（sq003）に替えた。
