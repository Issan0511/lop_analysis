## 0. 何を決めるか

**レバーが 2 本あって、共通の下流量が見つかっていない。**

- **幅クランプ**: ‖W̃₁ᵢ‖ を t20 の値へ毎更新射影すると、目減りが 2.28 → 0.60 pt、**絶対水準も 0.9002 → 0.9159 と上がる**（[[勾配の揃いを直接動かす_結果_0911]] の `N0w`）。今夜の全腕で絶対水準を上げたのはこれと `N2off` だけ。
- **勾配ノイズ**: Adam 前に注ぐと目減りが増える。害の大きさは一歩の揃い（drift2）に従い、9 腕で重なりなく分かれる（[[勾配の床か揃いか_結果_0911]] §3-3）。

**しかし ρ（タスク内の経路持続）は 2 本を繋がない。**

| 腕 | ρ | L |
|---|---:|---:|
| ノイズ c=1（`N1`） | 38.1 | 2.62 pt |
| 参照＋幅クランプ（`N0w`） | 38.4 | **0.60 pt** |

**ρ がほぼ同じで L が 2 pt 違う。** 幅クランプは ρ を 51.9 → 38.4 と**下げながら**可塑性を良くする。

**欠けている測定**: drift2（一歩のうち注入前の生勾配方向に揃った成分・lr² 単位）は 9/11 の 2 走で導入した量で、**幅クランプ腕では測っていない**。これを測れば、2 本のレバーが 1 つの量に繋がるかが決まる。

## 1. 走

箱 B（Permuted MNIST・784–100–100–10・leaky a=0.1・Adam lr=1e−3・batch 16・625 更新/タスク・正則化なし・CPU 1 スレッド）。t1–120、seed 0–2。クランプは t21 から（自分の t20 状態が基準）。

| 腕 | ノイズ | クランプ | G1 錨（bit 一致を要求） |
|---|---|---|---|
| `N0` | 無し | 無し | `elu_growth_0909/LR`（3 配列 × t1–120） |
| `N0w` | 無し | wclamp | `grad_coherence_0911/N0w`（6 配列 × t1–120） |
| `N1` | Adam 前・行一律 c=1 | 無し | `grad_coherence_0911/N1` |
| `N1w` | Adam 前・行一律 c=1 | wclamp | `grad_coherence_0911/N1w` |

4 腕 × 3 seed = **12 走**。1 走 ≈ 3 分（6 並列）。**注入も学習もクランプも既存の committed 実装をそのまま使い、足すのは読み出しだけ。** 既存 4 腕の軌道が bit で不変であることが G1。

**新しい測定**（late 窓 t61–120・毎更新）: 行 i ごとに、注入前の生勾配 $g_i$ の単位ベクトル $\hat g_i$ への射影で、実現した重み変化を分ける。
- **drift2_adam**: Adam の一歩 $\Delta^{\rm A}_i$（射影する**前**）の $\hat g_i$ 成分の二乗和 ÷ 625 ÷ lr²
- **drift2_net**: クランプ射影まで含めた正味の変化 $\Delta^{\rm net}_i$ の $\hat g_i$ 成分（**重みを実際に動かした量**）
- **diff2_adam / diff2_net**: それぞれの直交成分
- **f_diff_net** = diff2_net / (drift2_net + diff2_net)
- **clamp_removed**: $\lVert\Delta^{\rm A}_i-\Delta^{\rm net}_i\rVert^2$ の二乗和（射影が消した量）と、そのうち $\hat g_i$ 方向の分 **clamp_removed_drift**

既存の測定（精度・ρ・κ2・S²・graw²・‖W̃ᵢ‖・ゲート・CE）も同じ窓で取る。

## 2. 量（登録）

窓: **base = t16–20**、**late = t101–120**、seed 中央値。L = acc(base) − acc(late) [pt]、level = acc(late)。

## 3. 判定（事前登録・seed 3/3 一致でラベル、混在は `MIXED`）

**J0 G1**: 4 腕とも錨と per-unit maxabs ≤ 1e−10（件数ガード付き）。変異対照は初期値 +1e−3 で 1e−8 超。外れたら全判定 `NOT_TESTABLE`。
**可検定性**（J0 とは独立に記録し、外れても J1–J3 は判定する。9/11 に連言の読みで詰まった反省）: L(`N0`) − L(`N0w`) ≥ 1.0 pt。

**J1 決定的 — 幅クランプはドリフトを上げるか**: r = drift2_net(`N0w`) / drift2_net(`N0`)。
- r ≥ 1.3 → **`CLAMP_RAISES_DRIFT`**（2 本のレバーは drift2 で繋がる）
- r ≤ 0.9 → **`CLAMP_LOWERS_DRIFT`**（drift2 も共通量ではない）
- 他 → `CLAMP_DRIFT_FLAT`

**J2 決定的な対 — drift2 は ρ が分けられなかった対を分けるか**: `N0w`（L 0.60）と `N1`（L 2.62）は ρ がほぼ同じ（38.4 対 38.1）。
- drift2_net(`N0w`) ≥ 1.5 × drift2_net(`N1`) → **`DRIFT_SEPARATES_THE_PAIR`**
- 比が [0.8, 1.2] → **`DRIFT_FAILS_THE_PAIR`**
- 他 → `J2_PARTIAL`

**J3 射影は何を消しているか**: clamp_removed_drift / clamp_removed（`N0w`・late 窓）。
- ≥ 0.3 → `CLAMP_CUTS_SIGNAL`（射影は勾配方向の成分をかなり削っている）
- ≤ 0.1 → `CLAMP_CUTS_ONLY_RADIAL`（削っているのはほぼ勾配と無関係な成分）
- 他 → `J3_PARTIAL`

**J4 4 腕の順序**（記述・n=4 なのでラベルは付けるが弱い）: drift2_net と L の Spearman、‖W̃ᵢ‖ と L の Spearman を併記。

## 4. 進捗ゲートと変異対照

- **G1**（上記 J0）。**計装は読み出しのみ**なので bit 一致が計装の非侵襲性の証明になる。
- **G2 射影の恒等式**: drift2 + diff2 = 全エネルギー が相対 1e−10（adam 版・net 版とも）。$\Delta^{\rm A}-\Delta^{\rm net}$ がクランプ射影と厳密に一致（クランプ無し腕では 0）。
- **G3 クランプの実効性**: committed の `c3_cnorm_rel` ≤ 1e−6・`c3_m_absdiff` ≤ float32 の証明可能床・`clamp_tail_absdiff` = 0 と、skip / rowscale / tail の変異対照が各 100 倍で発火。
- **G4 注入**: 実測の平均 ‖Δg‖/‖g‖ ∈ [0.98c, 1.02c]（9/11 追補 1 の形）。最小最大と sd は記録のみ。`gradnoise` 系列が perm/data/batch を汚さない。
- 時間上限 1800 s / 走。
