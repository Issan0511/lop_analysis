## 2. 何を測るか — 分解を使わない設計原理

総勾配は $\partial L/\partial b_i = v_i\,\mathbb E[\varphi'(z_i)\,\varepsilon]$（$\varepsilon$ は**総残差**）。$\varepsilon$ を自己項と rest に割らなければ、ゲート $\varphi'$ は総力の乗法因子である。分解なしで出るのは次の 3 つだけで、**向き**は出ない。

- **(a) 大きさの上界。** $T$ step の変位は $\eta T\sup|\varphi'|\cdot K$ で抑えられる（$K:=|v_i|\,\mathbb E|\varepsilon|$ の上界）。**設計上は $K=1$ を約束事にする**（保証ではない。§5.4 で実測 $|v_i|$・残差水準と併記する）。5M では $\eta T=5\times10^4$ なので、$|\varphi'|<10^{-6}$ の深さでは 5M かけても変位の上界が 0.05 を割る。これを**凍結深さ $u_{\rm fr}$**（$u=-z$）と呼ぶ。「それより深いユニットは 5M の間に表層まで戻れない」という保証であって、「届く範囲のユニットは戻る」とは言わない
- **(b) 零点（障壁）。** SiLU・GELU は負側に $\varphi'=0$ の点（谷底）を持ち、そこでは向きに関係なく速度が 0 になる。谷より深いユニットが勾配だけで表層へ戻る経路は無く、越えるのは境界での $w\cdot\Delta\mu$ の跳びだけ。谷底の位置は視野 $T$ に依らない
- **(c) 符号反転。** 谷より深いと $\varphi'<0$ だが残差の向きに定符号は無い。**「押し下げ」とは書かない**

| 族 | 負側 $\varphi'(u)$ | 谷底 $u^\ast$ | 凍結深さ $u_{\rm fr}$（$K$=1・5M） | ダイヤルの効き方 |
| --- | --- | --- | --- | --- |
| leaky$_a$ | $a$（定数） | なし | **なし**（$a>0$ なら有限時間で任意の深さへ届く） | 上界は $a$ に線形（冪） |
| ELU$_\alpha$ | $\alpha e^{-u}$ | なし | $\ln(10^6\alpha)$ ＝ 13.82 / 11.51 / 9.21 / 6.91（$\alpha$=1 / 0.1 / 0.01 / 0.001） | **対数** |
| SiLU$_\beta$ | $\sigma(-\beta u)\,[1-\beta u\,\sigma(\beta u)]$ | $1.2785/\beta$ | $16.56/\beta$ | $1/\beta$ |
| GELU$_\beta$ | $\Phi(-\beta u)-\beta u\,\phi(\beta u)$ | $0.7518/\beta$ | $5.394/\beta$ | $1/\beta$ |

（谷底は $c\,\sigma(c)=1$・$\Phi(-c)=c\,\phi(c)$ の根。**表の数値は閉形式と $K$=1 の代入で、実験出力ではない。引用不可。** 実装は同じ量を数値で解き直して照合する = S-dial。vault §2 の 2 桁丸め「16.5 / 5.5」に対する 4 桁値がここ。）

**同じ「標準点」で硬さの 2 つの候補が食い違う例**: $\beta$=1 の SiLU は $u_{\rm fr}$=16.6 で ELU（13.8）より**深部の裾は軟らかい**が、谷底 1.28 より深いと勾配では戻れないので**復帰の意味では硬い**。どちらの「硬さ」が発症を決めるかは本走が答える。

**「いつ」の作業仮説（登録しない・設計の見当）**: 発症は「凍結域（$u>u_{\rm fr}$、または谷より深い）に到達したユニット時間の割合」が容量を割る点で起きる。**到達側（どの深さまで、どの率で沈むか）の理論は持たない。測る。**

**本走が答えないこと**: 視野 $T$ のダイヤル、谷を埋める活性化、順伝播と逆伝播の分離（`bwd_leak_0902`）、用量 9.33、多層、Adam、幅、無限時間の主張。

### 4.2 対応づけ

活性化の選択は乱数を消費しない（`nets.py` の契約）ので、新規腕は `gate_dose_0830` の各腕と init・教師・入力列・flip 軌道が bit 一致する（S-pair）。**step 1 以降は軌道が分岐する。** paired 対比・族内の隣接対比はすべてこのペアリングの上で取る。引用時に「対照は別走の committed 値」と書く。

### 4.3 実装

- `VecMLPL.ACTIVATIONS` に `silu`・`gelu` を追加。閉形式のまま（autograd に切り替えない）。**ReLU・leaky・ELU・代替勾配の経路は 1 行も触らない**。ダイヤルは既存の `act_alpha` に載せる
  - `silu`: 前向き $z\,\sigma(\beta z)$、後ろ向き $\sigma(\beta z)\,[1+\beta z\,(1-\sigma(\beta z))]$。`torch.sigmoid` の安定形で書く
  - `gelu`: **exact（erf）**。tanh 近似は使わない。前向き $z\,\Phi(\beta z)$、$\Phi(x)=\tfrac12(1+\mathrm{erf}(x/\sqrt2))$。後ろ向き $\Phi(\beta z)+\beta z\,\phi(\beta z)$
  - leaky $a\in\{10^{-2},10^{-3},10^{-4},10^{-5}\}$・ELU $\alpha\in\{0.1,0.01,0.001\}$ は既存分岐のパラメータ変更のみ
- 用量固定は `dose_const_5m_0830` のオラクルモードそのまま（入力側・活性化非依存）
- **新規ロガー（軌道中立・追加のみ・既存列は変えない）**。記録点ごと・ユニット別 `(5001, 100)` float32:
  - `layer1_mob` $=\mathbb E_x[\varphi'(z_i(x))]$。ReLU では `p_hat` と、leaky では $a+(1-a)\hat p$ と恒等に一致する（S-mob）。**独立な量になるのは ELU・SiLU・GELU 腕だけ**
  - `layer1_absmob` $=\mathbb E_x|\varphi'|$（SiLU・GELU は符号が混じる）
  - `layer1_zmax` $=\max_x z_i(x)$、`layer1_zmean` $=\mathbb E_x z_i(x)$（$(M+B)\cdot\mathrm{denom}$ と一致するはず）
  - `layer1_v_unit` $=v_i$（読み出し重み・ユニット別）
- **float32 の飽和**: GELU は erf が float32 で飽和するため $\beta z<-5.5$ で前向きが**厳密 0** になる。数学的な $|\varphi'|$ はその領域で $6\times10^{-7}$ 以下＝5M の変位上界 0.03 未満なので**力学上の差は無い**（$u_{\rm fr}\approx5.4/\beta$ と同じ位置）。**飽和深さは S-num で測って `provenance.json` に書く。** float64 化はしない

### 4.4 用語

- `submerged` := $\max_x z_i\le0$（$\hat p_i=0$ と恒真同値）。全腕で定義
- `beyond_valley` := $\max_x z_i\le-u^\ast$（SiLU・GELU のみ。leaky・ELU は空欄）
- `frozen` := $\bar z_i\le-u_{\rm fr}$（$K$=1 の約束事つき。leaky は常に偽）
- **$m^-$** := seed 内で `submerged` ユニットの `layer1_mob` の中央値（末尾窓）。**新しい指標ではなく既存軸の制限**
- **復活** := `submerged` → 非 `submerged` の遷移（境界／非境界で別に数える）
- いずれも verdict には使わない

### 5.2 E2 — 水準（主判定と同格）

paired $\Delta\log_{10}U(5\mathrm{M})$:

- **P3'**: 各新規腕 − `R_1216`
- **P5'（軟らかい端との距離）**: leaky 系は − `LR_1216`、ELU 系は − `E_1216`、SiLU・GELU 系は − `E_1216` と − `LR_1216` の両方。**等価限界 $\Delta=0.15$ dex**（`spec_bwd_leak_0902` §7.1 の Issa 裁定を継承。据え置き = §7.1）。`EQUIV` は $n=10$ ではほぼ到達不能なので、較正定数の要らない **seed 別符号検定を REPORT_ONLY で併記**する。CI が $[-\Delta,+\Delta]$ に収まれば **`EQUIV_SOFT_*`**、0 を上に外せば **`SHORT_OF_SOFT_*`**、どちらでもなければ **`INCONCLUSIVE_WIDE`**
- **位置比 $\rho$（REPORT）**: $\rho=(\log U_{\rm arm}-\log U_{\rm soft})/(\log U_{R}-\log U_{\rm soft})$

### 5.3 E3 — 発症時刻（「速度」の endpoint）

$U^{(10)}_k$ := タスク $k-9$〜$k$ の記録点の `unfit` 平均（宿主の `_window` と同じ集約）。**$k^\ast:=\min\{k\ge10: U^{(10)}_k\ge0.05\}$**、無ければ **500 で打ち切り**。seed 別に出し、腕ごとに中央値・範囲・打ち切り数を書く。「未発症＝生存」の Kaplan–Meier 曲線（**率**）を $n_{\rm onset}$（**総和**）と並べる（教訓⑰）。

**V2（族ごとの単調性）**: 族内を軟らかい側から硬い側へ並べ（committed の両端を含む）、隣接対比 $\Delta_j:=\log_{10}U(\text{硬い側})-\log_{10}U(\text{軟らかい側})$（5M・paired）を全部出す。

| 条件 | V2（族ごと） |
| --- | --- |
| どの隣接対比も CI が丸ごと $-\Delta$ の下に落ちず、かつ $n_{\rm onset}$ が硬い側へ向けて非減少 | **`MONOTONE_TOWARD_RELU`** |
| いずれかの隣接対比の CI が丸ごと $-\Delta$ の下、または $n_{\rm onset}$ が硬い側で 3 以上減る | **`REVERSAL`** |
| 新規腕の隣接対比がすべて $[-\Delta,+\Delta]$ に収まり、新規腕の $n_{\rm onset}$ がすべて 0 | **`FLAT_IN_RANGE`**（遷移は測った範囲より ReLU 側にある） |
| 上記以外 | **`PARTIAL`** |

判定順は §6.3 追補 3。$k^\ast$ の中央値は V2 に**添える**だけで判定式には入れない。

### 6.3 実装段の決定と追補

> **登録済みの判定基準は緩めていない。** 追補 1 は vault 字義が宿主実装と矛盾する 1 箇所の解決、追補 2–8 は guard と分岐の明示である。

1. **★ 窓の記録点数（vault §5.3 の S-mask 字義の訂正）。** vault は「$U^{(10)}_k$ の記録点数が各 $k$ で 100」と書くが、宿主の `mlp2_phase0b._window_indices` は `step % task_period == 0` だけを拾う = **タスク終端 10 点**。vault 自身が要求する「$U^{(10)}_{100}$・$U^{(10)}_{500}$ が 1M・5M の $U_k$ に一致」は終端のみの定義でしか成り立たず、committed 対照の $U_k$ もその定義で作られている。よって**逐語継承（終端のみ・10 点）が正**とし、S-mask は「10 点であること」＋「宿主 $U_k$ と一致すること」を検査する。字義との差は `sanity.S_mask` と `summary.md` に残す。**vault 側に追補が要る。**
2. **S-fd の情報量ガード。** 登録した GELU の $\Phi=\tfrac12(1+\mathrm{erf})$ は $\beta z\lesssim-8$ で桁落ちし（float64 で $\Phi$ が 0 に潰れる）、**中心差分の照合が成立しなくなる**。潰れた分の絶対誤差は $\varepsilon/2\approx10^{-16}$ で、凍結閾値 $10^{-6}$ の 10 桁下だから力学には効かない。実装は `gate_dose._s_grad_check` の先例に倣い、(i) 差分が情報を持つ点は中心差分で相対照合、(ii) 情報を持たない深い裾は桁落ちしない `erfc` 形との照合（絶対許容 $8\varepsilon$）、の 2 経路にする。**登録された算術は変えない。** 実測では差分が無情報になるのは $\beta z\lesssim-5$ から、すなわち $u_{\rm fr}$ とほぼ同じ深さ
3. **V2 の判定順（vault の表に順序が無い）。** `REVERSAL` → `FLAT_IN_RANGE` → `MONOTONE_TOWARD_RELU` → `PARTIAL`。理由: REVERSAL は単調性の破れなので隠してはならず、FLAT は MONOTONE の特殊形（新規腕が全部 0 で動いていない）なので先に見る。`spec_bwd_leak_0902` 追補 7 に倣い、**当たっていた行も全部 `verdict.csv` に残す**（`V2_co_satisfied`）。MONOTONE / REVERSAL は対照を含む梯子の全隣接対、FLAT は新規腕どうしの対だけを見る
4. **対照の $m^-$（committed logs にユニット別 `mob` が無い）。** これは P-3 の指摘そのもの。対照の $m^-$ だけは **5M チェックポイントから 1 点で復元**し、窓ラベルを `final_step5000000` として出す。**末尾窓 491–500 の量ではない**（教訓⑫。引用時に窓を添える）。復元できなければ `INSUFFICIENT_DATA`
5. **S-ref の列単位照合。** 親走の `verdict.csv` は provenance 記録後に N5 修正（非 ReLU 腕の `strict_dead` 列を空にする）で再生成されている。ファイルのハッシュ不一致自体は事故ではないが、**本走が転記する列**が動いていたら事故。`provenance.output_sha256` に一致する版を git 履歴から探し、その blob と列単位で突き合わせる（`spec_bwd_leak_0902` と同じ手続き、対照の顔ぶれだけが違う）。実測では変化した列は `median_strict_dead_frac_5m` の 1 本だけで、転記列は不変
6. **段の裁定（vault §9 #0）。** 2026-09-02 Issa: **全 14 腕（段 3 の錨込み）を投入**。腕プロセス並列は S-par 通過後に使う
7. **S-dial（$u^\ast$・$u_{\rm fr}$ の数値解との照合）。** config に凍結した表は閉形式の代入値なので、実装は同じ量を数値で解き直して相対許容 6%（vault の 2 桁丸めを吸収する幅）で照合する。**表は実験出力ではない**ことを `summary.md` にも書く
8. **対照の $k^\ast$。** `verdict.csv` に発症時刻は無いので、対照の $k^\ast$ だけは committed `logs` の `unfit` 系列から作る（§4.2 の carve-out）。主 endpoint（$U_k$）は転記のまま。$k^\ast$ は V2 の式に入らない「添えるだけ」の量なので、この経路差は判定に影響しない
