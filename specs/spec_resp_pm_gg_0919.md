### 2.2 PM の床と健康点（自然軌道だけで選び、介入の E を見ない）

`E_s(t)` はタスク t の online 正解率、`A_s(t)` は終端の同じ1200枚の正解率。`F_s=max_c n_sc/1200` は最良の定数予測器。PM では F_s がタスク間で一定なので、そのタスク間 SD を使わない。

**床の帯**は画像数から定める。N=1200、K=10、α_F=0.05、`q=Φ⁻¹(1−α_F/K)` として、二項 score 不等式

$$N(F_s-p)^2\le q^2p(1-p)$$

の上側の解を

$$U_s=\frac{F_s+q^2/(2N)+q\sqrt{F_s(1-F_s)/N+q^2/(4N^2)}}{1+q^2/N}$$

と置く。K は最多クラス選択の参照補正。`AT_FLOOR(s,t)` ⇔ `E_s(t)≤U_s` かつ `A_s(t)≤U_s`。**これは有限画像数の尺度を持つ操作的な床であり、固定ラベルを再利用して学習する PM の online 成績に二項独立性や家族誤り率を保証する検定ではない。** 96000回の提示を独立標本数にせず、1200枚を尺度にする。α は事前の名目水準であり、固定の正解率差や「SDの3倍」を置いたものではない。

健康の境界は、完全適合1と定数床 F_s から等距離になる点 `H_s=(1+F_s)/2`。これは二つの参照水準への二乗距離が等しい解。`HEALTHY(s,t)` ⇔ `E_s(t)>H_s` かつ `A_s(t)>H_s`。床と健康の間は中間状態として残す。

1. `t_h(s)` = t=2,…,148 のうち、t−1 と t が連続して HEALTHY となる最初の t。最も成績のよい時刻を選ばない。
2. `t_c(s)` = t_h+2,…,150 のうち、t−1 と t が連続して AT_FLOOR となる最初の t。二つの異なる置換で確認する最小の反復数が2であり、独立な二回の有意検定とは読まない。
3. t_h が無ければ `NO_HEALTHY_BRANCH`、t_c が無ければ `RIGHT_CENSORED_150`。延長・代替 seed・第1層への主判定変更はしない。欠測と右打切りを区別する。
4. 次タスクの成績によって分岐点を選び直さない。N_h が次の置換で落ちる、N_c が復活する場合も保存し、§5 の現象確認で扱う。

分岐 checkpoint は p、m、v、**各 seed の Adam 時刻**、画像・ラベル・現在の置換、次の置換/標本順の RNG 状態、状態 hash を含む。t_h・t_c の決定根拠の2行を `branches.csv` に残す。

### 2.3 画像 id 上の固定場（PM 固有の主・副）

同じ seed の donor の時刻を u、recipient の時刻を r、置換を P とする。`z_l(p,P,x_id)` はその画像を P で並べたときの層 l の前活性。ユニットは同じ初期化の index i で対応し、並べ替えてよく合う相手を探索しない。

**主 R（recipient-next）**:

$$d_{l,i}(id)=z_{l,i}(p_u,P_{r+1},x_{id})-z_{l,i}(p_r,P_{r+1},x_{id}).$$

donor も受け手の次タスクの置換で読む。同じ入力条件における応答の差を渡す。donor の「当時健康/崩壊」は自然軌道での資格であって、新しい P 上の応答の良し悪しを保証しない。

**副 D（donor-own）**:

$$d_{l,i}^{D}(id)=z_{l,i}(p_u,P_u,x_{id})-z_{l,i}(p_r,P_{r+1},x_{id}).$$

donor の当時の置換で記録した場を、元画像 id の対応で渡す。受け手の入力・ラベル・学習用置換は主腕と同じ P_{r+1}。画素位置やミニバッチ内の位置で field を引かない。

両定義とも d は最初の継続タスク前に作って凍結し、2タスク目でも **画像 id に張った同じ d** を使う。2タスク目の置換は P_{r+2} へ自然に変わるため、そこで donor の場と一致し続けるとは言わない。動く場への変更やタスクごとの d の貼り直しは本走の外。

### 2.4 初期出力を揃える式と手書き逆伝播

受け手の分岐パラメータ `p_r=p_0` を別メモリに凍結し、**現在の入力置換・現在のミニバッチ形状**で凍結網の z_l^0 を再計算する。対象層だけ

$$a_l=\phi(z_l^0)+[\phi(z_l+d_l)-\phi(z_l^0+d_l)]$$

とする。補正の z_l^0 と d_l を更新しない。分岐時には括弧が厳密に0で、特徴・logit・CEは自然 forward と bit 一致する。全1200枚評価用キャッシュをミニバッチの凍結 forward の代用にしない（行列積の形状で丸めが違い得る）。

GELU は `−0.0` を返す。`a0+0` による符号 bit の消失を防ぐため、括弧が厳密0の要素では **a0 自体の bit を返す**。これは符号つきゼロの保存であり、逆伝播を0にする分岐ではない。手書き逆伝播は対象層で必ず `g_l=gate(z_l+d_l)` を掛け、非対象層はその腕自身の z の `gate(z)`、W3 はその腕自身の a2 で計算する。前向きだけ自然の φ(z) にして backward だけ差し替える別の straight-through 介入にはしない。

主は **第2層のみ**。第1層のみの交換を副に2腕置く。両層同時交換、層を事後に選ぶ最小 n_eff 規則、一様シフト梯子、動的 donor、W cap は含めない。各腕で両層を測る。

### 4.3 副 endpoint — 健康な PM seed で較正する相対 n_eff

`g` は統計用の別微分でなく、backward が実際に使う `gate(z+d)`（自然腕は d=0）。

$$n_{{\rm eff},i}=\begin{cases}(\sum_{id}|g_i|)^2/(N\sum_{id}g_i^2),&\sum g_i^2>0,\\0,&\text{全画像で }g_i=0,\end{cases}\qquad x=\frac1{100}\sum_i n_{{\rm eff},i}.$$

float32 の g を **二乗する前に** float64 化する。負の微分を符号相殺で失わない。主の x は第2層。第1層、min、符号つき分子、mean|g|、ゼロ割合は副の記述量で、勝った指標へ差し替えない。

**較正手順（本走 seed の値に触れる前に固定し commit）**:

1. C=100–109 の自然51タスクを走らせる。各 seed の t1–3 が HEALTHY、`x_s(2)>0`、`G_s=E_s(3)−F_s>0` を要求する。ここで `x_s(t)` は重み p_t を **次タスク P_{t+1} 上**で読んだ開始値。欠ければ `CALIBRATION_NOT_TESTABLE` とし、seed を替えない。
2. t=3,…,50 のうち、それまでの t1,…,t+1 がすべて HEALTHY の点だけを使う。最初の非健康の後の復活点は使わない。各 seed に少なくとも2点かつ全体で2つ以上の異なる x が必要。これは「健康な軌道の応答低下と成績の関係」を学ぶ較正で、崩壊点の E は曲線へ入れない。採用・除外点の一覧と全較正ログは保存する。
3. `r_s(t)=x_s(t)/x_s(2)`、`f_s(t)=(E_s(t+1)−F_s)/G_s`。t=2 は f=1 の恒等点なので fit と採点から外す。seed 内の各点に重み1/採用点数を置き、seed の総重みを等しくした **非減少 isotonic 最小二乗（PAVA）**を当てる。同一 r は重みつき平均にまとめる。
4. 得た節点間は線形補間。最小の正 r より下は **(0,0) へ直線**で結び、最大 r より上は最後の値。r=0 の値は0に固定し、もし健康なのにr=0の点があればその誤差も較正残差へ入れる（除外しない）。正の節点が無ければ較正不能。f は非負、Eに戻した後だけ[0,1]に clip。この低応答側の直線は、健康なデータから実証されない**登録した外挿仮説**。滑らかさ・knot・指数の探索をしない。
5. 正規化の定数は較正 seed の `G_C=mean_s G_s`。本走では自分の健康な分岐の次課題開始値 `x_s(t_h)` で割り、`Ehat_s(t)=clip(F_s+G_C*f_C(x_s(t)/x_s(t_h)),0,1)`。**本走の E は較正に使わない**。x_s(t_h)=0 なら副判定は `CALIBRATION_NOT_TESTABLE`。
6. 帯は seed を一つずつ抜き、残る9 seedで曲線とG_Cを作って、抜いた seed の健康な採用点の E を予測する。各 seed の最大絶対誤差を e_s とし、`Q=max(q_E,e_(k))`、`k=ceil((10+1)×0.90)=10`（昇順）を半幅とする。seed を交換単位とした最大残差の帯であり、タスク行を独立と数えない。LOSOの学習集合は重なるので厳密な split-conformal 保証とは言わない。90% は登録した名目被覆。較正不能・帯の空虚さは §5.4 で別ラベルにする。

**外部採点**: 本走20–29の自然軌道、分岐 t=`5,10,20,50,100,149` の x(t) と E(t+1)。偶然 t=t_h と一致する点は恒等参照なので除外し、残りをすべて採点する（各 seed 少なくとも5点）。t_h・t_c で選んだ二点だけを当てて「予測成功」としない。移植腕の開始 x→E の予測も全腕出すが、固定補正による分布の違いがあるため **報告のみ**。課題中平均 n_eff は E と同時に生じる量なので先行予測子にしない。

## 5. 登録する判定（ラベル・帯・適用条件）

### 5.1 適用条件を主ラベルの前に判定する

1. コード・spec・入力 hash、段階に対応する登録 manifest、全必要記録、数値の有限性、S0–S9 を確認する。主には自然10×152行と V の各 seed の分岐12×2行、副には較正10×51行も要求する。資格のない分岐を欠測行にせず理由付きで記録する。主データの技術的欠測、NaN、変異の見逃しは `INVALID`。出力を保存してから停止し、正常な seed だけ黙って採用しない。副の較正不能だけでは主を止めず、registration に曲線なしと理由を記録する。
2. 自然軌道10本をすべて報告する。t_h と t_c の両方を持つ seed を V とする。**主効果の母集団は150タスク以内に登録規則で崩壊した seed に条件づく**。右打切りを効果0や NEITHER に代入しない。
3. `n=|V|` が6未満なら `INAPPLICABLE_TOO_FEW_COLLAPSES`。6は、二つの片側方向に α/2=0.025 を割り当てた厳密符号検定で、全一致でも `2^(−n)≤0.025` を満たす最小 n。t 区間に加え符号の離散的解像度も確保するための下限であり「8割残ればよい」とは置かない。
4. V で `D_s=E(N_h)−E(N_c)` の95%対応 t 区間の下端>0、かつ平均 E(N_h)>平均 H_s、平均 E(N_c)≤平均 U_s を要求する。不成立は `NOT_REPRODUCED_AT_NEXT_TASK`。枝の選び直しはしない。
5. 主2腕の開始時に、recipient と donor の gate 場の差のRMSが、それらの計算・field再構成の丸め誤差上界のRMSより大きいことを要求する。両場が算術精度で分離していない場合は `FIELD_NOT_SEPARATED`（該当 seed/方向を列挙）。n_eff の大小関係や第2層の平均位置を成立条件にはしない。固定場を正しく渡して結果が悪いことは検査不合格ではない。

### 5.2 自然腕の散らばりから効果の帯を作る

**自然4腕だけを先に完了**し、V、F/U/H、branches、較正曲線、以下の帯を `registration.json` に書いて hash とともに commit する。それまで移植腕を起動しない。これは事前に固定したアルゴリズムによる較正で、自然成績を見て式や枝を変える手続きではない。

P1 の参照列 `C1_s=E(N_c)`、P2 の参照列 `C2_s=E(N_hr)`。主比較数m=2、家族名目水準α=0.05、`c_n=t_(1−α/(2m),n−1)` とし、

$$b_j=\max\{q_E,\ c_n\,\operatorname{SD}(Cj_s)\sqrt{2/n}\}.$$

導出: 同じ自然腕分布から n seed 平均を二つ作ったとき、独立な平均の差の分散は `2 SD²/n`。この自然な平均差の幅を検出したい効果の基準とする。√2 はこの分散の加算から出る。対応を無視した保守的な参照尺度であり、**b_j 自体を有意差の信頼区間とは呼ばない**。SD=0でも1正解ぶんの q_E を残す。

各 seed の P1/P2 の**差を先に作り**、その平均と不偏SDから97.5%対応 t 区間

$$I_j=\bar P_j\pm c_n\operatorname{SD}(Pj_s)/\sqrt n$$

を求める。差のSD=0なら同一差を点区間として報告し、`degenerate=true` を付ける。境界の等号は不支持側。支持 `J_j` は **`lower(I_j)>b_j` かつ片側厳密符号検定 p≤α/2**。符号検定の0差は除き有効符号数を明記、すべて0なら p=1。95%区間と自然帯のみ/区間のみの当否も報告する。

この二段の基準は親より厳しい。p と t 区間の前提、自然帯の推定の不確かさは開示し、効果の大きさ・全 seed の差をラベルと併記する。

### 5.3 主ラベル（4値）

| J1（戻す） | J2（奪う） | 主ラベル |
|---|---|---|
| true | true | **RESPONSE_BOTH_WAYS** |
| true | false | **ONE_WAY_RESTORE** |
| false | true | **ONE_WAY_REMOVE** |
| false | false | **NEITHER** |

逆向きで `upper(I_j)<−b_j` なら、4値ラベルに加えて `direction_Pj=REVERSED` を必ず出す。未判定の前提不成立は4値に押し込まない。NEITHER はこの規則で効果を示せなかった意味で、同等性の証明ではない。

RESPONSE_BOTH_WAYS は「この PM 箱で固定補正つき第2層の場が再学習を両方向に動かした」。完全回復・完全死亡・全媒介は別。報告する回復率は `ρ1=mean(P1)/mean(E(N_h)−E(N_c))`、除去率は `ρ2=mean(P2)/mean(E(N_hr)−E(N_cr))`。各分母の95%区間の下端が0以下なら `UNRESOLVED_DENOMINATOR`。個々の比を平均せず、1を超えた比もclipしない。§2.2のHEALTHYまで戻った割合、AT_FLOORに入った割合も別記する。

Adam 対照、D方式、第1層、継続2タスク目は対応差と95%区間の**副報告**。主2方向の成否や層を置き換えるラベルには使わない。

### 5.4 相対 n_eff の副ラベル

較正10 seed と自然本走10 seed が完全な場合だけ採点する。欠測は `INVALID_SECONDARY`。健康な較正点の不足・分母0は `CALIBRATION_NOT_TESTABLE`。

- **帯の非空虚性**: `2Q<G_C` が必要。床と健康の中心が G_C 離れ、双方の半幅Qの帯が重ならない条件から出る。不成立なら `CALIBRATION_UNINFORMATIVE`。帯を後から狭めない。
- **被覆**: 各 seed の全登録採点点が帯 `Ehat±Q` に入れば1、それ以外0。下側二項尾 `Pr{Bin(10,0.90)≤k}` が0.05を下回らないこと。k=6では0.012795、k=7では0.070191なので **7/10以上**が条件。名目90%を健康外にも検証する操作的な採点で、LOSO/外挿に厳密な被覆保証を付けない。
- **予測の情報量**: 各 seed で予測RMSE、常時床 `F_s` のRMSE、常時健康 `clip(F_s+G_C,0,1)` のRMSEを同じ点で計算する。`min(二つの定数RMSE)−予測RMSE` の片側符号検定 p≤0.05。10本・tie無しでは9本以上の勝ちが必要（8本は0.0546875、9本は0.0107422）。tieは除いて再計算。広い帯に入るだけでは通さない。

3条件とも満たせば **RELATIVE_NEFF_PREDICTS**、採点可能だが一つでも満たさなければ **RELATIVE_NEFF_FAILS**。外れの上下・各 seed/時刻の予測・誤差を全て出す。不支持から「あらゆる PM 較正が不可能」、支持から「n_eff が普遍的十分統計量・因果量」とは書かない。

**許容の算術**: 同じ実行グラフ・RNG・dtypeには許容0。別の和の順序で計算する独立oracleには、unit roundoff `u=eps/2`、`γ_k=ku/(1−ku)`、長さkの内積の `γ_k Σ|a_i b_i|` を基本に、入力丸めと演算グラフの各辺の誤差を伝播する。subnormalの絶対丸めも演算回数ぶん加える。相対誤差一律1e−6や許容の100倍は使わない。

field の `d=fl(z_src−z_r)`、`q=fl(z_r+d)` は、減算と加算それぞれの絶対丸め誤差を加え、別形状評価の実測Δzも加えた上界内で z_src と照合する。**qとz_srcのbit一致までは要求しない**。GELU の滑らかな導関数に対しては `sup|φ''|=2/√(2π)` を使え、float32 gate自体の丸め・underflow差は別にoracle誤差へ加える。gの符号やゼロの不連続な記述量は、引数の誤差区間が境界にかかる要素数から許容を出す。

独立oracleが同じ宿主gateを呼ぶ部分は**配線の検証**であり、gateの解析式自体の検証はS4bの別計算で行う。変異が丸め内に埋もれた場合は倍率を盛らず、負微分・非零場差を含む合成fixtureを使う。それでも落ちない検査はPASSにしない。t/正規/二項分位とPAVAは独立計算で照合する。実検査の all_pass と変異検出数を後の commit で記録し、未実施の今は合格宣言しない。
