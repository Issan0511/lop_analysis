## 5. S の機構（保存状態 38 個の事後解析）

### 5.1 1 層目は CLS の位置でだけ沈む

- CLS の位置の r は −2.5〜−2.2 です。unit の半分前後（0.49〜0.64）は、CLS の位置では probe のどの画像でも開きません。
- 全 token（CLS 1 個とパッチ 64 個）で測った r は −0.1〜0 です。典型的な unit は token の約半分で開くので、死は 0 です。
- 1 層目の FFN の入力（埋め込み＋1 層目の注意）では、共通成分（token 平均）はエネルギーの 1〜1.4% しかありません。2 層目の入力では 53〜63% です。
- bias は両層とも中央値が約 −0.01 で、幅に比べてほぼ動きません。全 token をまとめて沈める向きが 1 層目には無く、CLS（どの画像でもほぼ同じベクトル）だけが沈みます。

### 5.2 2 層目の死が課題 85〜100 で戻った担い手

1. 2 層目の死が 0.85 → 0.63 に減ったのは、2 層目の入力の共通成分 ‖m‖ が 339 → 226 に縮んだからです。
   - 課題 100 の重みのまま ‖m‖ だけ 1.5 倍に戻すと、死は 0.79 に戻ります。0.67 倍にすると、どの保存状態でも死は 0 です（`posthoc/split_more_S.txt`）。
   - 行と共通成分の cos は −0.16 → −0.15 で、ほぼ変わりません。
2. 2 層目の共通成分の 98〜100% は 1 層目の FFN（ReLU）の平均出力が書いています（`posthoc/common_mode_S.json`）。
3. FFN1 が書く量は、FFN1 の入力の token ごとの広がり（token 平均を引いた残りの rms）に比例します。
   - 比は課題 40〜100 で 9〜10 です（`posthoc/spread_S.json`）。ReLU は正の斉次で、bias ≈ 0 だからです。
   - 課題 70 → 100 で、広がりは 33.7 → 22.1、書く量は 336 → 226 でした。
   - 入れ替えで割ると、入力の token ごとの部分が −184、入力の平均が +35（逆向き）です。FFN1 自身の重みは fc1 が +19、W2 が −10 でした（`posthoc/ffn1_mean_S.txt`）。
4. 広がりが細ったのは主に 1 層目の注意の出力です。広がり² のうち注意の分が 832 → 292、埋め込みの分が 219 → 158 でした。注意 1 が細った理由は測っていません。
