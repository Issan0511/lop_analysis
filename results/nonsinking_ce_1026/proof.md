# 通常の誤差逆伝播で、学習中ずっと沈まない反例

2026-10-26。ここにあるのは本走のための直接の導出。既存論文の定理として引用しない。
有限回の数値走は実装の確認であり、永続性の根拠は以下の不変領域と無限時間の証明である。

## 1. 主張の範囲と沈降の定義

固定データの前活性 z_i(x)=w_i^T x+b_i について、μ_i=E_x z_i、母標準偏差 σ_i、r_i=μ_i/σ_i を測る。
反例は **全隠れ unit の μ と r が増え続け、正側率が減らず、通常の CE が 0 に近づく**。
読み出しだけの学習、損失・逆伝播の変更、明示的なゲート固定は用いない。

これは「通常学習なら必ず沈む」「沈まない状態は必ず一時的」という一般命題への反例である。
ViT の通常学習で下向きが典型的になる理由、課題切替の効果、T5 の大きさや符号については結論しない。
期待値・典型性の主張は、分布と適用条件を指定して別に検討する必要がある。

## 2. 固定学習率の通常 GD による二値分類の永久反例

入力は x=-a,+a、ラベルはそれぞれ 0,1。a=2 を主例とする。

\[
f(x)=v_- [w_- x+b_-]_+ + v_+[w_+x+b_+]_+ +c,\qquad
L=\tfrac12\{\log(1+e^{f(-a)})+\log(1+e^{-f(a)})\}.
\]

初期値は w_-=−0.75、w_+=0.75、b_-=b_+=−0.25、
v_-=−0.5、v_+=0.5、c=0。全てのパラメータを同じ正の学習率 η で更新する。
各 unit の active 前活性は s=1.25、inactive 前活性は B=−1.75。
初期 μ=−0.25、σ=1.5、r=−1/6。初期 accuracy は既に 1 であり、
この主例での学習進展は CE と分類 margin の改善である。初期誤分類がある別の走も併記する。

対称性 w_-=−w_+、b_-=b_+、v_-=−v_+、c=0 は、全パラメータの通常 GD によって保たれる。
c の勾配は対称な残差が相殺して 0 になるのであって、c を固定しているのではない。
w=w_+>0、b=b_+、u=v_+>0、s=aw+b、q=1/(1+e^{us}) と書くと、

\[
\begin{aligned}
w'&=w+\tfrac{\eta}{2}a u q,& b'&=b+\tfrac{\eta}{2}u q,\\
s'&=s+\tfrac{\eta}{2}(a^2+1)u q,& u'&=u+\tfrac{\eta}{2}s q,\\
B'&=B+\tfrac{\eta}{2}(1-a^2)u q .
\end{aligned}
\]

a≥1 なら B<0 は保たれ、s>0、u>0 は増える。従って gate は更新の結果として保たれる。
この式は小さい η の近似ではなく、各 GD step の厳密な式である。

### 学習が止まらず、L→0

各有限 step で q>0 なので s,u は厳密に増え、margin us も増える。L=log(1+exp(−us)) は厳密に減る。
もし us が有界なら、s,u は正の初期値から増えるので共に有界であり、q は正の下限を持つ。
すると Δu≥η s_0 q_min/2>0 が続いて矛盾する。従って us→∞、L→0。
さらに Δs/Δu=(a²+1)u/s より、一方だけが有界で他方が発散することもできず、s,u は共に発散する。

### μ と r がずっと上がる

対称入力なので μ=b、σ=a w。d=w−ab は厳密な不変量で、主例では d=1.25>0。
t=ηu q/2>0 と置くと、

\[
\Delta\mu=t>0,\qquad
\Delta r=\frac{t(w-ab)}{a w(w+at)}>0.
\]

従って全 unit の μ と r は全ての有限 step で上がる。b→∞、w→∞ であり、

\[
r\longrightarrow 1/a^2=1/4.
\]

各 unit の正側率は 1/2 のまま。負側の入力での前活性 B はさらに負になるが、
unit 全体の平均と標準化位置は上がる。「全入力で z が上がる」とは主張していない。

## 3. 正確な対称性がなくても保たれる構造

任意の二入力 x_0,x_1（等確率、ラベル 0,1）を考える。
拡張入力 ξ_n=(x_n,1)、K_nm=ξ_n^T ξ_m とする。
ある unit がクラス a のみで開き、A=z(x_a)>0、B=z(x_{1-a})<0 とする。
読み出し v は a=1 なら正、a=0 なら負。出力 bias や他の unit の値は任意でよい。

二値 CE では p−y の符号がラベルだけで決まる。従ってこの unit への非零信号は必ず

\[
\frac{\partial L}{\partial z(x_a)}=-\tfrac12 |v|q_a<0,
\quad q_1=1-p_1,\quad q_0=p_0.
\]

λ=η|v|q_a/2>0 と置けば、通常の GD で

\[
A'=A+\lambda K_{aa},\qquad B'=B+\lambda K_{a,1-a}.
\]

同時に |v| は η A q_a/2 だけ増える。この関係は任意の output bias と他 unit があっても成り立つ。
単一標本 SGD でも、そのクラスが選ばれた step に正の λ を使い、他の step は λ=0 とすればよい。

**十分条件**:

1. K_ab≤0（a≠b）：正しいクラスの活動を増やす更新が、他クラスの gate を開かない。
2. K_aa+K_ab>0：その更新は前活性の平均も上げる。
3. I=A K_ab−B K_aa>0：標準化位置 r も上げる。

このとき gate と読み出しの符号は保たれ、I'=I。

\[
\Delta\mu=\tfrac{\lambda}{2}(K_{aa}+K_{ab})>0,\qquad
\Delta r=\frac{2\lambda I}{(A-B)\{A-B+\lambda(K_{aa}-K_{ab})\}}>0.
\]

したがって任意の step 数にわたり非沈降が保たれる。K_ab<0 とした全ての条件は厳密な不等式であり、
入力・初期パラメータの摂動を許す開集合を定義する。反例の非沈降性は左右対称性の一点に依存しない。
ただし、この段落だけから任意の大きな固定学習率で CE も毎 step 減るとは主張しない。

### 開集合全体での学習進展：gradient flow では L→0

両クラスを支える unit が少なくとも一つずつあるとする。各 unit の |v_i| は正の初期値以上である。
勾配の w_i,b_i 成分だけでも

\[
\|\nabla L\|^2 \ \ge\
\tfrac14 K_{00}|v_{i_0}(0)|^2 q_0^2
+\tfrac14 K_{11}|v_{i_1}(0)|^2 q_1^2.
\]

gradient flow では dL/dt=−||∇L||²。もし L の極限が正なら、
少なくとも一つの標本の CE が正の下限を持ち、その q も正の下限を持つ。
上式から dL/dt に負の定数上限が生じ、L≥0 に矛盾する。よって L→0。
有限データのこのモデルは残差が有界で勾配の成長がパラメータに対して高々線形なので、
有限時刻にパラメータが発散することもない。
固定学習率の非対称 GD は数値でも別に検証する。flow の証明を、そのまま離散 GD の証明とは呼ばない。

### 初期値としてどの程度特殊か

固定 x=±a、a≥1 では、正クラスを支える unit の十分条件は
w>0、−aw<b<w/a、v>0。w,b が等分散・独立の零平均 Gaussian の場合、
(w,b) の角領域は atan(a)+atan(1/a)=π/2 なので、読み出しの符号まで含む確率は 1/8。
二つの unit が両クラスを一つずつ支える確率は 2(1/8)²=1/32。
b=0 初期化で w,v の符号が独立・対称なら同じ確率は 1/8。
これは **指定した小モデル・初期化における不変領域への所属確率** であり、
ViT や一般的な広いネットワークが沈まない確率ではない。
対称な主例の固定 GD の証明とは区別し、この開集合の学習収束は上記 flow の保証と数値走で扱う。

## 4. 10 クラスの標準 softmax CE にも同じ永久反例がある

C=10、x_n=√(2C)(e_n−1/C)、ラベル n とする。N=H=C、
W_i=0.1 x_i、b_i=−0.25、読み出し V_ik=0.5 if i=k else 0、出力 bias=0。
全パラメータを通常の mean softmax CE の GD で更新する。
拡張入力の Gram は K_ii=2C−1、K_ij=−1（i≠j）。
各 unit は自分のクラスだけで開く。active 前活性 A=1.55、その他 B=−0.45。

対称性により、読み出しの自クラス値と各他クラス値との差は共通の d>0 で表せる。
q=1−p_y=(C−1)/(exp(Ad)+C−1) とすると、各 step は

\[
A'=A+\eta(2C-1)qd/C,\quad
B'=B-\eta qd/C,\quad
d'=d+\eta A q/(C-1).
\]

A,d は厳密に増え、B は減る。二値の場合と同じ有界性の矛盾により Ad→∞、
L=log(1+(C−1)exp(−Ad))→0。A と d も共に発散する。
このとき λ=ηqd/C>0、I=A(−1)−B(2C−1)=7 は不変であり、

\[
\mu=\frac{A+(C-1)B}{C},\quad
\sigma=\frac{\sqrt{C-1}}{C}(A-B),\quad
\Delta\mu=\lambda>0,
\]
\[
\Delta r=
\frac{C\lambda I}{\sqrt{C-1}(A-B)\{A-B+\lambda(2C)\}}>0,\qquad
r\longrightarrow\frac1{2\sqrt{C-1}}=\frac16.
\]

初期 r=−5/12、正側率は常に 1/10。初期 accuracy は 1 だが CE は非零から 0 へ下がる。
これは固定学習率の離散 GD の厳密な反例であり、二値 loss に特有ではない。

さらに、ある unit がクラス y だけで開き V_iy>V_ik が全 k≠y で成り立てば、
\[
\frac{\partial L}{\partial h_i}
=\sum_{k\ne y}p_k(V_{ik}-V_{iy})<0.
\]
通常の読み出し更新は V_iy を上げ、全 V_ik を下げるので、この順位も補強される。
適切な入力 Gram による gate 保持と合わせ、活動を上げる向きそのものは対称性に依存しない。
一般の非対称多点データで r が上がるには、分散の変化も別に確かめる必要がある。

## 5. 条件を壊すと何が起きるか

### 読み出しの向きを反転する

二値の対称モデルで、正クラス用の signed readout を u<0 とする。
gate が変わるまでは s'=s+(ηK/2)u q、u'=u+(η/2)s q、K=a²+1。
従って

\[
J=u^2-s^2/K,\qquad J'=(1-K\eta^2q^2/4)J.
\]

η<2/√K なら J の符号は保たれる。
α=s/√K とすると α+u は (1+√Kηq/2) 倍、α−u は (1−√Kηq/2) 倍になる。
J<0（α>|u|）なら u は有限 step で正へ戻る。J>0（|u|>α）なら s が先に閉じる。
主例の s=1.25、K=5 に対して、反転 |u|=0.5 は前者、0.75 は後者である。
実行した |u|=0.75、η=0.05 の走では両入力で gate が閉じる。
その後は対称な出力 bias の勾配も 0 で学習が止まるので、この走を有効な非沈降反例には数えない。

### 入力幾何と位置・幅

- K_ab>0 なら、正しいクラスへの更新が別クラスの gate を開く可能性がある。
  純度を失えば信号に競合が生じる。ただし条件を外しただけで沈降が必ず起きるとは言えない。
- K_aa+K_ab<0 なら、正しいクラスでの活動を増やす更新でも μ は下がる。
  これは入力平均を経由する幾何学的効果であり、class 純度だけでは防げない。
- I<0 なら r は下がる。例えば x=±2、w=0.75、b=1 では
  μ は上がるのに r は 2/3 から 1/4 へ下がる。σ の増え方が相対的に大きいためであり、
  r の低下をそのまま μ の低下と呼んではいけない。

### 正味の押しに関して、何を絞れたか

入力平均 0 の二値モデルで v_i>0 の unit について、通常の更新は

\[
\dot\mu_i=\dot b_i
=v_i\{\mathbb E[1_{y=1}g_i(1-p)]-\mathbb E[1_{y=0}g_i p]\}.
\]

右辺第一項は、その unit の読み出しが正しい方向である入力からの押し上げ、
第二項は逆のクラスで活動してしまうことへの押し下げである。
反例では第二項が 0 で、第一項が正であり、その関係を通常学習自身が保つ。
この条件では「下向きの自己項がある」ことから正味の沈降を結論できない。

この式は条件の識別であり、一般の学習で第二項が優勢になる理由の導出ではない。
「沈むのが自然」を次に主張するなら、少なくとも
誤差で重み付けした活動の競合、入力の幾何、分散成長のどれが下向きを作り、
どの学習状態の分布でそれが優勢になるかを示す必要がある。
この反例を「精密な相殺なので実際にはすぐ崩れる」として除外することはできない。
