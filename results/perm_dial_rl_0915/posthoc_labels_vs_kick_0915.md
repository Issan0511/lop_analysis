床はどの列も ≈0.11–0.12。

## 読み

- **ELU・ReLU の PM での生存は蹴りではなくラベルによる。** 蹴りを全開にしても乱数ラベルなら死ぬ（k=784 で 0.100 / 0.114）。蹴りは死を遅らせるだけ（最初に床を割るタスク: ELU t11–16 → t20–30、ReLU t5 → t8–38）。
- **GELU の PM での死は蹴りによる。** 乱数ラベルのまま蹴りだけ入れると死ぬ（k=0 の 0.171 → k=784 の 0.114）。ラベルを正しくしても救われない（PM 0.116）。
- ReLU の復活率は蹴りとともに増える（第 1 層 0 → 2.6%/タスク、第 2 層 0 → 8.9%）が、乱数ラベルの圧に負けて t141–150 では全 k で床。PM（正ラベル）の第 1 層復活率は 12–16%。
- ダイヤルは単調ではない: GELU の生存数 3/2/3/0/0、SiLU 1/0/2/3/0。3 seed の数えなので中間水準は荒い。SiLU の k=270 が 3/3 生存（late 0.21・第 2 層は反転域 0.98 に居るが凍結 0.00）は外れ値として扱い、主張に使わない。
- G2 の蹴りの間隔は算術の目標（0.25/0.5/0.75/1）に対して 0.23/0.29/0.61/1.00。k=107 が弱く、ダイヤルの中間は均等ではなかった。単調性は満たしている。
