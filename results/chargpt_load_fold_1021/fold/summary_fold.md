## 0. 一行

LN のある ReLU の網では、読み出しに隣接する FFN（L3）の応答の喪失はすべて死で（正側の片側化は 0）、その死は課題を通して波のように増えたり戻ったりし、学び直しの速さはその死に連れて動く（課題ごとの相関の中央値 C3 +0.63・C4 +0.86、10/10 seed で正）。lr 1e−3 の C3 では 7/10 seed で L3 が生き返り、速さも戻る。登録した予測は 4 つ中 1 つ（P5-1）が規則の上で当たり、その 1 つも C3・B3 では空に近い検査だった。

## 1. 定義

- 応答の状態は一様 probe（seed だけから作る固定の入力、全課題で同じ）で、各課題の末。`q` は z < 0 の token の割合（閉じた割合）。死 = 記録の `dead`（z > 0 の token が無い）、正側片側化 = q ≤ 0.01 かつ死でない、応答しない = 死 ∪ 正側片側化。ReLU では入力間の傾きの分散 Var_x(φ′) = q(1 − q) が厳密。
- 学ぶ力の 3 相（課題ごとの online の損失、excess = 損失 − 鎖のエントロピー）: スパイク = 更新 0〜4、T015 = 50 更新の移動平均が 0.15 以下に初めて届く更新数（届かなければ 10,000）、e1k = 更新 950〜1050、eend = 最後の 1000 更新。
- 先行の判定: onset_resp = L3 の応答しない割合が課題 1 より 0.10 増えた最初の課題。onset_T = T015 の 5 課題の移動平均が課題 2〜10 の平均を δ_T 以上上回った最初の課題（課題 11 以降）。δ_T = 3 × 課題 2〜10 の T015 の平均の seed 間 SE（C3 29、B3 32、C4 22、N4 215 更新）。

- C3 の L3 の死は波になる。例: seed 1 は課題 40 に 0.84 → 課題 50 に 0.00、同じ時期の T015 は 2655 → 1109 更新。seed 6〜9 は課題 10〜20 に死に、課題 25 までに生き返り、T015 も 700 台に戻る。seed 0・5 は課題 25 以降に死が積み上がり（課題 50 で 0.83・0.82）、T015 は 1738・2026 まで伸びる。
- C4 は死が積み上がるだけで戻らない。B3 は死が少なく、速さとの連動も弱い。
- 読み: LN のある Transformer では、読み出しに隣接する FFN の死は可逆で、学び直しの速さは課題ごとにその死に連れて動く。生き返りは lr 1e−3 の網でだけ起きた。生き返りの経路（上流の担い手の動きか、probe に出ない token での開きか）は測っていない。
- 相関は固定状態の記録の共変で、因果ではない。

## 6. 部品の表への含意（Transformer × 5）

- 応答の喪失＝死（ReLU、正側片側化は 0）。死と学び直しの速さは課題ごとに連動する（C3 +0.63・C4 +0.86、10/10）。
- 「戻らない」は LN のある lr 1e−3 の網では成り立たない（C3 7/10 で生き返り、速さも戻る）。lr 1e−4 では戻らない。
- 喪失の主張は 3 相で書く。3 相のうち速さ（T015・e1k）が死と最もよく連動し、課題末（eend）の変化は小さい（C3 0.041 → 0.048）。
