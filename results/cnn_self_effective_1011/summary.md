# CNN c1：自己成分による上昇と、入力方向別の重み増減

2026-10-11、事後解析。結論は **自己成分が上向きを助ける例は多いが、収縮と上昇の同時性だけで自己項と判定できない。重みノルムの増加は、前活性に弱く効く方向への蓄積と両立する**。

## 1. 実際の上昇に自己成分は寄与したか

他チャネルを削除せず、元の網の勾配を加法的に分けた。各画像のlogitsをf、c1の活性化チャネルをa_j、poolを含む下流JacobianをA_j=df/da_jとし、

\[
Q(f)=\int_0^1\bigl[\operatorname{diag}p(tf)-p(tf)p(tf)^T\bigr]\,dt,
\quad v_j=A_j a_j,
\]

と置く。p(f)−uniform=Q(f)fにより、CEのcotangentは

\[
A_j^TQv_j\; +\; A_j^TQ(f-v_j)\; +\; A_j^T(u-y)
\]

に分かれる。最初を **局所線形CEの対角チャネル自己成分**、次を他チャネルと下流のaffine残差、最後をラベル成分と定義した。これは一意な因果分解ではなく、明示した操作的定義。QとA自体は元の全ネットに依存する。他チャネルを削除してforward・勾配を再計算する比較網の勾配、自己形への回帰、定数モードの残りとは別物。

実Adamの一次モーメントを成分ごとに積算し、二次モーメントと分母は実際の全勾配が作った同一のものを使用した。開始前のmomentumは持越し履歴、丸め・求積の残差は独立成分にした。c1では平均がW,bに線形なので、各成分の平均変化は有限更新でも加算できる。

### 切替直後、課題31の最初75更新

160チャネル中80で「前活性分散が縮む」と「平均が上がる」が同時に起きた。その **61/80では自己成分も上向き、19/80では自己成分は下向き**。後者は他成分が上昇を作っており、同時性が自己項の識別条件にならない反例。

上昇＋収縮した80チャネルの平均変化の帳簿：

| 成分 | 平均変化への寄与 |
|---|---:|
| 自己成分 | +3.561110 |
| 他チャネル・下流affine残差 | −3.121325 |
| ラベル成分 | −0.051315 |
| 持越し履歴 | −0.000137 |
| 数値残差 | +0.000086 |
| 実際の平均変化 | **+0.388419** |

大きな自己成分と残りが相殺する。61/80はチャネル数の記述であり、「上昇の76%を説明した」という寄与率ではない。独立反復単位は10seedで、80チャネルを独立標本として検定していない。

全160チャネルでの自己成分の平均上昇+1.362763は、μ経路+1.412286とbias経路−0.049523に分かれた。自己成分が上向きでも、その主経路はbiasとは限らない。

実更新を固定入力PCAへ射影すると、自己成分は全4方向帯で重み二乗ノルムを減らす規約上の寄与を持ち、分散を減らす寄与の大部分はPC1だった。ただし二乗量の成分配賦には交差項の規約が必要で、ここでは対称的な端点配賦を使う。平均寄与にはこの曖昧さはない。詳細は `replay_direction_notes.md`。

### 同じ課題の最後75更新

通常の学習とのパラメータ差はここでも完全に0だった。ただし成分の打ち消しが極端で、チャネル別の `Σ|平均寄与|/|実平均変化|` の中央値は約 **4.0×10^8**。数値残差を実際の小さな移動に対して無視できない。

この窓では63チャネルが上昇＋収縮し、計算上56で自己成分が正だったが、**終盤の寄与率・原因の証拠には採用しない**。大きな各勾配を、相殺後の小さな全勾配に基づくAdam分母で割るため、個別成分が巨大になる。足し戻せる代数分解と、安定した因果的説明は同じではない。

最初の固定絶対閾値1e−8による分散閉合チェックは1.0056e−8で失敗した。ログを保存し、事後の浮動小数点スケール監査を別ファイル `replay_late/scale_audit.json` に記録した。相対演算誤差としては小さいが、この監査をもって寄与率の不安定さが解消したとは扱わない。

## 2. 重みはどの入力方向で増減したか

元のseed0、課題20→50。固定1200画像の全パッチ共分散で方向を分けた。表の「重み量」は16チャネル平均の二乗ノルムで、以前のL2ノルム中央値とは異なる。

| 入力方向 | 入力分散の分担 | 重み量20→50 | 前活性分散への寄与20→50 |
|---|---:|---:|---:|
| PC1 | 56.71% | 0.490→0.124 | 1.513→0.383 |
| PC2–5 | 29.84% | 2.413→0.182 | 0.843→0.055 |
| PC6–20 | 12.34% | 5.721→4.760 | 0.422→0.144 |
| PC21–75 | 1.11% | **0.638→8.378** | 0.00161→0.02410 |

大きな入力変動を拾う方向が弱まり、小さな変動の方向に大きな重みが積まれるため、ノルム増加と前活性収縮が同時に起きる。10seedでは上位5方向の重み量減少が152/160、下位55方向の増加が160/160だった。この低分散方向を「無意味な重み」「損失に一切効かない」とは呼ばない。

### 元のseed0で平均を上げた経路

課題40→50では

\[
\Delta\bar z=\mu^T\Delta W+\Delta b
=\mathbf{+1.019609}-0.598908=+0.420702.
\]

PC1だけで+1.024900、残りの74方向は−0.005291。PC1と平均パッチのcosineは0.99744で、このデータではほぼ同じ方向だった。負のPC1寄与が弱まると、画像の明るさ変動への反応が弱まり、平均もゼロ側へ戻る。**この区間ではbiasの正味寄与は沈める側で、重み経路が浮かせた**。

例外のチャネル10は、課題20→50でPC1側が増えて分散を+1.69082増やし、他方向の減少を上回った。そのためノルムが減っても分散は増えた。チャネル差も同じ方向別帳簿で説明できる。

### 活性化とmax-poolを含む実効入力

生入力のPCAとは別に、poolで選ばれるパッチへ活性化の傾きを掛けた `Ψ=φ'(z_winner)(x_winner,1)` のGramを、seed0の固定128画像で測った。各区間の開始時点の基底を固定。

課題20→50では、その下位56方向にbias込み重み二乗量が平均+8.349増えたが、開始点での局所出力変化の二乗平均に占める割合は0.118%だった。実効入力でも「出力変化に弱く効く方向にノルムが増える」という像は残った。

ただし長区間ではwinnerが64.2%変わり、線形近似の余りが大きい。これは開始点での感度に関する解析であり、全区間の厳密な因果分解ではない。詳細・全チャネル値は `analysis/cnn_self_effective_1011/directions_notes.md` と `directions_seed*.json`。

## 3. 低分散方向の増加は、いつ積まれたか

実状態から継続したseed10–19、課題31の下位55方向の正味二乗ノルム変化（160チャネル平均）：

| 局面 | 下位55方向の変化 |
|---|---:|
| 最初75更新 | −0.00447360 |
| 途中29850更新 | **+0.1345557** |
| 最後75更新 | +0.00004201 |
| 課題全体 | +0.1301241 |

増加は切替直後の窓ではなく、課題への当てはめを進める途中に積まれた。途中区間の各勾配成分を積分してはいないので、ラベル項とAdamの再重み付けのどちらが作ったかまでは未同定。全体の重みノルム変化はこの1課題ではほぼ0で、長期20→50の水準と混ぜない。

いま支持される像は、**強く変動する入力を読む成分を削りながら、弱く変動する方向には重みが蓄積する**というもの。削る側には自己成分が関わる例が多いが、自己項だけで上昇・収縮・ノルム増加の全てを説明したとは言えない。
