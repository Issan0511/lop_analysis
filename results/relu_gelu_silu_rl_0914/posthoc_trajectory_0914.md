## 読み（事後・登録の外）

- **登録判定は `UNRESOLVED`**（SiLU が 2 AT_FLOOR / 1 ABOVE で割れた）。腕ごとには R `AT_FLOOR`・GELU `ABOVE_FLOOR`・SILU `DISAGREEMENT`。
- **死に方が 3 通りある。**
  - ReLU は **t5 で床**（最速）。第 2 層は z̄₂ ≈ 0 の水面で φ′ が厳密に 0 になり、旅をしないまま死ぬ。
  - ELU は t11–16 で床。第 2 層が −150 まで旅をして Adam の ε で凍る（親の走と同じ）。
  - SiLU の 2 seed は **t10 の時点で第 2 層の標本の 99% が反転域**（z̄₂ −10）にいて、−50 まで沈んで t31–34 で床。
    反転域は RL では復元にならなかった（箱 B の PM では復元域だった）。
- **生き残った側は第 2 層が水面から動かない。** GELU 3 seed と SiLU seed 2 は z̄₂ ≈ 0・反転域 ≤ 3%・|φ′|<ε が 0%。
  ただし GELU は late 0.22 で LR（0.49）の半分以下、傾き −0.009〜−0.013/10 タスクで落ち続けている。SiLU seed 2 は 0.35 で傾き −0.029 と最も急。
  「50 タスクの窓の中で床に届いていない」までが言えることで、「死なない」とは言えない。
- **運命は t10 までに決まっている**: SiLU の分岐（反転域 99% か 0% か）は t10 で既に完全に分かれている。
