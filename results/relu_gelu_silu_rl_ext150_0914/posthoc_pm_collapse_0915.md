## 注記

- PM の床規則は縮退する: PM はラベルが毎タスク同じ（1200 枚の正ラベル）なので s = 0 で閾値 = F そのもの。GELU s1 は late 0.114 が F をわずかに上回って `ABOVE_FLOOR` と出たが、軌道は t117 以降 0.114 で 3 seed とも偶然水準。
- **RL と PM で死ぬ活性化が逆になる**: ELU1 は RL で死に PM で生きる（0.96）。GELU は RL で床の上に残り（0.17）PM で死ぬ（0.115）。
- PM の GELU は **反転域に入ってから死ぬ**: t50 で第 2 層の φ′<0 が 0.43–0.73、その後 −64〜−76 まで沈んで |φ′|<ε が 1.00、第 1 層も t150 で φ′<0 が 0.65–0.81。
  spec §5 の Claude の機構予測（「死ぬ seed では z̄₂ が谷底を割るのが床より先」）と同じ順序だが、予測は RL についてのもので、PM は登録外。
- 箱 B（pmnist・625 更新/タスク）では GELU の谷の向こうは復元域で釣り合いが −7 だった。この箱（1200 枚・6000 更新/タスク）の PM では −75 まで沈んで凍る。**復元になるかは箱に依る**。
