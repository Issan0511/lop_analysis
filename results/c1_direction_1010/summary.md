## 0. 一行

隠れ層に読まれる層（CNN の c1、3 層 MLP の第 1 層）の切替の押しは、**定数モード（下流の余接の平均水準が接続作用素を通って戻る項）＋ 中心化した残り** に厳密に割れる [恒等式・固定状態]。残りは自己整合成分を含みうるが同定していない（H ∝ P の R² は MLP 0.01〜0.07・CNN ≤ 0.01）。どの腕でも定数モードは浮かせる側が多数（0.62〜0.99）、残りは沈める側が多数（0.86〜1.00）で、全体の符号は両者の大きさの競合に対応した: LR の c1 では定数モードが支配（t5〜t20 で浮かせる側 0.86〜0.95、符号一致 0.89〜0.95、分担の中央値 0.70〜0.73）、学習で付いた接続カーネルの DC 和の変化だけでも全体と 0.88〜0.95 で符号一致し、初期値の分は偶然（0.51〜0.59）。固定 α = 3 の Snake では定数モードが非支配（|定数| > |残り| 0.12〜0.27）になり c1 は沈む（0.84〜0.89）。3 層 MLP では、現在の µ₂ 方向の成分（drift）が −µ̂₂,i·Cpl_i と厳密に因数分解され、Cpl > 0 のもとで符号は上流の平均出力の逆: raw（h̄1 < 0）で沈める側 1.00、std（h̄1 > 0）で浮かせる側 0.84〜0.94。定数モード全体は raw で弱く沈める側・std で浮かせる側 0.71〜0.79（分担 0.30〜0.41）で、raw 0.86〜0.93 対 std 0.37〜0.56 の差は競合と整合する。「W3 の成長 × 初期の W2 列」は分担 0.03〜0.15・符号一致は偶然へ落ち、主要項を支持しなかった。

## 1. 問いと穴

`cnn_drive_verify_1009` で c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ は自己形 S_j（92% 正）に従わない（LR: 沈める側 0.50 → 0.10（t10）→ 0.40（t30）、c2 は 1.00）。3 層 MLP の第 1 層も std で 37〜67%（vault 3 層ノート §8、V12 §11 の 7 [未導出]）。V12 §4 の主張（期待値での必然）は 2 層で閉じているので、隠れ層に読まれる層で何が加わるかを導く。

## 2. 恒等式と定理の形（格つき）

- G_j = Σ_{n,q} γ_j K1_j H1_j [恒等式]（γ = 勝者のゲート、K1 = 平均パッチ方向の接線 ≈ 15.3、H1 = ∂L_u/∂P1_j）。自己形 S_j = Σ γ K1 P1_j は H1 → P1 の理想化で、差は H1 と P1 の差だけ。H1 ∝ P1 の R² は conv 層で ≤ 0.01 [実測]。
- H1_j は接続カーネル W2[:, j] に線形（δ2 固定）→ W2 の任意の割り方で G も同じ和に割れる [恒等式]。割り方 3 つ: (i) W2⁰ + ΔW2^drift（現在の µ̂₂ への射影）+ ΔW2^rest、(ii) ΔW2 = DC バケット（(k, j) ごとの DC 和）+ AC、(iii) 定数モード κ_j H̄1_j + 中心化した残り（Codex (25)）。
- DC バケット: G_DC_j = Σ_k Δs_kj Ã_kj、Ã_kj = (1/25) Σ_{n,q} γK1 (1₅ₓ₅ ⋆ᵀ δ2_k)（境界込み）[恒等式]。Ã_kj = Q̄_j D̄_k + Cov（D̄_k = c2 チャネル k の bias の押し）。Ã と D̄ の符号一致は 0.93〜0.96 [実測]。
- drift の符号の定理 [厳密・仮定つき]: G^drift_j = −(P̄1_j/‖µ₂‖) Z_j − E_ac,j、c_k ≥ 0・Z_j > 0（Σ_k c_k D̄_k > 0 ＋ ゲートの残りの有界）・|E_ac| < |主項| のとき sign G^drift = −sign P̄1_j。MLP では G^drift_i = −µ̂₂,i·Cpl_i が厳密（1e−15）。実測: Z > 0 は LR で t10 以降 1.00、|E_ac| < |主項| 0.94〜1.00。
- 2 層の箱にも定数モードはあるが、読み出しの δ の画像和 D = p̄ − 1/K は当てはめ済み iid 有限標本で O_p(N^{−1/2})（成分 sd 0.0087）[仮定つき]。「2 層には無い」は言い過ぎ（Codex）。
- 反例（構成、頻度は不明）: ゲート相関・AC カーネル × ゲート・境界集中で drift の符号は逆転しうる（Codex 第 1 ラウンド）。

## 5. 言える／言えない

**言える**: (1) 隠れ層に読まれる層の押しは定数モード＋中心化した残りに厳密に割れ（固定状態の帳簿）、残りは MLP・CNN とも沈める側が多数（MLP raw 0.98〜1.00・std 0.64〜0.71、CNN c1 全腕 0.86〜1.00）、定数モードは浮かせる側が多数（CNN 全腕 0.62〜0.99、MLP std 0.71〜0.79）。(2) LR・LRc・SNA の c1 では定数モードが支配（0.76〜0.95）して全体と符号が一致し（LR 0.89〜0.95）、学習で付いた接続カーネルの DC 和の変化だけでも全体の符号を強く追跡した（0.88〜0.95）。初期値の分は偶然。(3) MLP では drift の符号則 −sign(h̄1) が Cpl > 0 のもとで厳密な因数分解（raw 1.00、std 0.84〜0.94）。CNN では Z_j > 0 と残りの非支配を仮定した条件つき（P̄1 > 0 で 0.75〜0.98、≤ 0 で 0.69〜1.00、LR）。(4) MLP の raw/std の差は定数モードと残りの競合と整合する（読み）。(5) 「W3 の成長 × 初期の W2 列」は分担 0.03〜0.15 で主要項ではない。(6) 中心化した LRc でも c1 は浮く（計算前の予言 3/3。LR/LRc・seed 10〜19・観測した t）。(7) 固定 α = 3 の Snake の c1 は定数モードが非支配（0.12〜0.27）になって沈む。(8) LR の c2 の押しは上流ブロックの分担の中央値が 0.77〜0.96（t10 以降 0.96）。
**言えない**: 定数モードの分担（CNN 0.63〜0.75、MLP std 0.30〜0.41）を決める式。Δs_kj の負の蓄積が P̄1_j の反転後も残る機構の分離（履歴・箱和・Adam。Codex (20) の分解は未測定）。CNN で AC・上流が c2 を支配する理由。正味の沈降の大きさ（切替の浮き対課題の中の沈み）。反例（ゲート相関・AC × ゲート・境界）の実軌道での頻度。定数モードと DC バケットは別の分解（zero-pad の境界では AC も平均水準に寄与する）で、「透過 = DC 和」とは書かない。「決まる・運ぶ・消える」は固定状態の帳簿の対応で、学習の履歴の因果ではない（Codex 審査）。Snake の c1 は P̄1 > 0 のチャネルの比率が異なり、drift の率は腕で 0.00〜0.96 と割れる。
