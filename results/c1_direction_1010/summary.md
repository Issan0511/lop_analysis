# c1_direction_1010 — 隠れ層に読まれる層の押しの向き: CNN の入力層が自己形から外れる理由

状態: 計算完了（2026-10-10 15:15）。spec と予測は `specs/spec_c1_direction_1010.md`（登録 e4268ad2、13:08、計算前。結果は §6.1〜6.5）。導出は `analysis/c1_direction_1010/derivation.md`（§5′・§5″ は計算前の追記と Codex の批評を受けた訂正）、Codex の独立導出・批評は `codex_derivation.md`（第 1）・`codex_derivation2.md`（第 2、DC バケットの盲検予測つき）。実装・計算・表は Opus（`src/c1_direction_1010.py`・`analysis/c1_direction_1010/mlp_drift.py`・`cnn_tables.py`・`q2_tables.py`）、採点は `analysis/c1_direction_1010/verdict.py` → `verdict.json`・`verdict_tables.md`。この要約は親（Fable）。符号の約束: **G > 0 = 沈める側**（期待の SGD の 1 歩が平均を下げる）。帯は seed 平均の SE 0.04 から（強 ≥ 0.85、多数 ≥ 0.70、偶然 [0.35, 0.65]）。

## 0. 一行

隠れ層に読まれる層（CNN の c1、3 層 MLP の第 1 層）の切替の押しは、**定数モード（下流の層の bias の押しが接続重みの DC 和を通して上流の平均へ透過する項）＋ 中心化した残り（自己整合側、沈める側）** に厳密に割れる。CNN の c1 では定数モードが浮かせる側で支配し（LR t5〜t20 で 0.86〜0.95、分担 0.7）、その符号は学習で付いた接続カーネルの DC 和の負の蓄積（下流 c2 の µ₂ 経路の沈降の裏側）が決める。符号は固定ではなく下流の状態で決まり、固定 α = 3 の Snake では c2 の W2 が µ₂ に反平行に育たないので透過が消え、c1 は自己形どおり沈む（0.84〜0.89）。3 層 MLP では同じ透過項の符号が上流の平均出力 h̄1 の符号の逆で、raw（h̄1 < 0）は沈める側に足し、std（h̄1 > 0）は浮かせる側で自己整合側と拮抗する — raw 84〜97% 対 std 37〜67% の中身。3 層ノート §8 の「W3 の成長 × 初期の W2 列」は分担 0.03〜0.15 で効いていない。

## 1. 問いと穴

`cnn_drive_verify_1009` で c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ は自己形 S_j（92% 正）に従わない（LR: 沈める側 0.50 → 0.10（t10）→ 0.40（t30）、c2 は 1.00）。3 層 MLP の第 1 層も std で 37〜67%（vault 3 層ノート §8、V12 §11 の 7 [未導出]）。V12 §4 の主張（期待値での必然）は 2 層で閉じているので、隠れ層に読まれる層で何が加わるかを導く。

## 2. 恒等式と定理の形（格つき）

- G_j = Σ_{n,q} γ_j K1_j H1_j [恒等式]（γ = 勝者のゲート、K1 = 平均パッチ方向の接線 ≈ 15.3、H1 = ∂L_u/∂P1_j）。自己形 S_j = Σ γ K1 P1_j は H1 → P1 の理想化で、差は H1 と P1 の差だけ。H1 ∝ P1 の R² は conv 層で ≤ 0.01 [実測]。
- H1_j は接続カーネル W2[:, j] に線形（δ2 固定）→ W2 の任意の割り方で G も同じ和に割れる [恒等式]。割り方 3 つ: (i) W2⁰ + ΔW2^drift（現在の µ̂₂ への射影）+ ΔW2^rest、(ii) ΔW2 = DC バケット（(k, j) ごとの DC 和）+ AC、(iii) 定数モード κ_j H̄1_j + 中心化した残り（Codex (25)）。
- DC バケット: G_DC_j = Σ_k Δs_kj Ã_kj、Ã_kj = (1/25) Σ_{n,q} γK1 (1₅ₓ₅ ⋆ᵀ δ2_k)（境界込み）[恒等式]。Ã_kj = Q̄_j D̄_k + Cov（D̄_k = c2 チャネル k の bias の押し）。Ã と D̄ の符号一致は 0.93〜0.96 [実測]。
- drift の符号の定理 [厳密・仮定つき]: G^drift_j = −(P̄1_j/‖µ₂‖) Z_j − E_ac,j、c_k ≥ 0・Z_j > 0（Σ_k c_k D̄_k > 0 ＋ ゲートの残りの有界）・|E_ac| < |主項| のとき sign G^drift = −sign P̄1_j。MLP では G^drift_i = −µ̂₂,i·Cpl_i が厳密（1e−15）。実測: Z > 0 は LR で t10 以降 1.00、|E_ac| < |主項| 0.94〜1.00。
- 2 層の箱にも定数モードはあるが、読み出しの δ の画像和 D = p̄ − 1/K は当てはめ済み iid 有限標本で O_p(N^{−1/2})（成分 sd 0.0087）[仮定つき]。「2 層には無い」は言い過ぎ（Codex）。
- 反例（構成、頻度は不明）: ゲート相関・AC カーネル × ゲート・境界集中で drift の符号は逆転しうる（Codex 第 1 ラウンド）。

### 3.3 CNN LR の c2

G > 0 は t10 以降 1.00。t ≥ 10 で P̄2 ≤ 0 が全チャネルになり、drift（W3 の µ̂₃ 成分）は沈める側に反転（分担 0.42〜0.63）、rest も沈める側（1.00）。**c2 の押しの 77〜96% は上流ブロック**（u_k の W1/b1 成分: c1 の重みが動いて P1 が変わり z̄2 が下がる。sign(G_up) = sign(G) 0.94〜1.00）で、own は 0.53〜0.89。H2 ∝ P2 の R² ≈ 0.01。「c2 は自己形に従う」の中身は、上流が運ぶことと、平均出力が負になった層では透過も沈める側になること。

### 3.5 課題の中（Q2 = NOT、P9。LR t10→t11・t20→t21、再走は元の走と bit 一致）

結合 Σ_k⟨W2[k], µ̂₂⟩ は切替で落ち（75 更新で −1.73 / −0.79）、課題の中で大半が戻る（正味 −0.35 / −0.28）。「変化の ≥ 50% が最初の 75 更新」の seed は 7/10・6/10 で帯 8/10 に届かず NOT だが、分母（正味）が小さく比は不良設定。c1 の平均は切替で上がり（+0.08 / +0.12）、750 更新で下がり（−0.31 / −0.35）、正味 −0.09 / −0.07。課題の初め（step 75、実ラベルの勾配）の c1 の押しは沈める側 0.72 / 0.71 だが、それを運ぶのは AC 部分（0.86 / 0.78）で DC 部分は半々（0.41 / 0.51）。課題末（step 30000）の実ラベル勾配では DC が沈める側 0.83 / 0.84（c2 の戻りの押しと負の Δs の積）、AC は 0.07 / 0.22。c1 の平均の動きは W1 の DC 成分 a_j‖M‖ がほぼ全部運ぶ（0.92〜1.03、既知の µ 経路）。正味の沈降の大きさの式は無い [未導出]。

## 5. 言える／言えない

**言える**: (1) 隠れ層に読まれる層の押しは定数モード（透過）＋中心化した残りに厳密に割れ、残りは MLP・CNN とも沈める側が多数（MLP raw 0.98〜1.00・std 0.64〜0.71、CNN c1 0.88〜0.99）。(2) CNN の c1 では透過が浮かせる側で支配（LR・LRc・SNA・CV06FC3）、その符号は学習で付いた接続カーネルの DC 和の変化が決め、初期値の分は偶然。(3) 現在の µ₂ 方向の成分の符号則 −sign(P̄1) は Cpl > 0 のもとで厳密な因数分解で、CNN・MLP とも 0.88〜1.00。(4) MLP の raw/std の差は透過の符号（h̄1 の符号の逆）で読める。(5) 「W3 の成長 × 初期の W2 列」は無視できる項。(6) 中心化しても c1 の押しの向きは変わらない（P7）。(7) 固定 α = 3 の Snake の c1 は透過が消えて沈む。(8) c2 の押しの 77〜96% は上流が運ぶ。
**言えない**: 透過の分担（CNN 0.7、MLP std 0.3〜0.4）を決める式。Δs_kj の負の蓄積が P̄1_j の反転後も残る機構の分離（履歴・箱和・Adam。Codex (20) の分解は未測定）。CNN で AC・上流が c2 を支配する理由。正味の沈降の大きさ（切替の浮き対課題の中の沈み）。反例（ゲート相関・AC × ゲート・境界）の実軌道での頻度。Snake の c1 は P̄1 > 0 のチャネルの比率が異なり、drift の率は腕で 0.00〜0.96 と割れる。
