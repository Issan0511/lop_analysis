## 0. 一行

隠れ層に読まれる層（CNN の c1、3 層 MLP の第 1 層）の切替の押しは、**定数モード（下流の層の押しが接続重みの DC 和を通して上流の平均へ透過する項）＋ 中心化した残り（自己整合側）** に厳密に割れる。CNN の c1 では定数モードが浮かせる側で支配し（t5〜t20 で 0.86〜0.95、分担 0.7）、残りは沈める側だが小さい。定数モードの符号は学習で付いた接続カーネルの DC 和の負の蓄積（下流 c2 の µ₂ 経路の沈降の裏側）が決める。3 層 MLP では同じ透過項の符号が上流の平均出力 h̄1 の符号の逆になり、raw（閉じた側、h̄1 < 0）では沈める側に足し、std（h̄1 > 0）では浮かせる側に働いて自己整合側と拮抗する — これが raw 84〜97% 対 std 37〜67% の中身。

## 1. 問いと穴

`cnn_drive_verify_1009` で、c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ は自己形 S_j（92% 正）に従わない（LR: 沈める側 0.50 → 0.10（t10）→ 0.40（t30）、c2 は 1.00）。3 層 MLP の第 1 層も std で 37〜67%（vault 3 層ノート §8「W3 の成長 × 初期の W2 列」[未導出]）。V12 §4 の主張（期待値での必然）は 2 層で閉じているので、隠れ層に読まれる層で何が加わるかを導く。

## 2. 恒等式（厳密）

- G_j = Σ_{n,q} γ_j K1_j H1_j（γ = 勝者のゲート、K1 = 平均パッチ方向の接線 ≈ 15.3、H1 = ∂L_u/∂P1_j）。自己形 S_j = Σ γ K1 P1_j は H1 → P1 の理想化。差は H1 と P1 の差だけ。
- H1_j は接続カーネル W2[:, j] に線形（δ2 固定）→ W2 = W2⁰ + ΔW2^drift（現在の µ̂₂ への射影）+ ΔW2^rest、または ΔW2 = DC バケット（(k,j) ごとの DC 和）+ AC で、G も同じ和に割れる。
- DC バケット: G_DC_j = Σ_k Δs_kj Ã_kj、Ã_kj = (1/25) Σ_{n,q} γK1 (1₅ₓ₅ ⋆ᵀ δ2_k)（境界込み、Codex (2)〜(4)）。Ã_kj = Q̄_j D̄_k + Cov（D̄_k = c2 チャネル k の bias の押し）。
- 定数モード: G_j = κ_j H̄1_j + Σ (γK1 − κ_j/M)(H1 − H̄1)（Codex (25)）。2 層でも定数モードはあるが、読み出しの δ の画像和 D = p̄ − 1/K が当てはめ済み iid 有限標本で O_p(N^{−1/2})（成分 sd 0.0087）なので小さい。隠れ層の D̄_k は unit 自身の沈める押しで、全 unit が同符号。
- MLP: G^drift_i = −µ̂₂,i · Cpl_i（Cpl_i = Σ_k c_k A_ki）が厳密（1e−15）。

### 3.2 CNN LR の c1（Q1 = DRIFT_SIGN_ONLY、事後で機構は確定）

## 5. 言える／言えない

**言える**: (1) 隠れ層に読まれる層の押しは定数モード＋中心化した残りに厳密に割れ、CNN の c1 では定数モード（下流の押しの透過）が浮かせる側で支配する。(2) 定数モードの符号は学習で付いた接続カーネルの DC 和の変化（Δs_kj < 0 が 76〜82%）が決め、初期値の分は偶然。(3) 現在の µ₂ 方向への射影の符号則 −sign(P̄1) は CNN・MLP とも 0.88〜1.00 で立つ（Cpl > 0 のもとで厳密な因数分解）。(4) MLP の raw/std の差は透過項の符号（h̄1 の符号の逆）で読める。(5) 3 層ノートの「W3 の成長 × 初期の W2 列」は無視できる項。
**言えない**: Δs_kj の負の蓄積が P̄1_j の反転後も残る機構の分離（履歴・箱和・Adam。Codex (20) の分解は未測定）。c2 で AC・上流が支配する理由。Snake での成立率（計算中）。長期の正味（課題の中の戻り）は Q2 で測る。
