## 1. §4.7 G13 の段落の末尾に足す（本文。Codex の案を土台にした）

隠れ層に読まれる unit i の押しを G_i = Σ_r a_ir H_ir（r は MLP では画像、CNN では画像 × 位置。a = K φ′、H = その unit の出力への逆伝播）、κ_i = Σ_r a_ir、H̄_i = 平均と書けば、G_i = κ_i H̄_i + Σ_r (a_ir − κ_i/|r|)(H_ir − H̄_i) と、**下流の余接の平均水準が接続作用素を通って戻る定数モード**と**中心化した残り**に分かれる [恒等式・固定状態]。残りは自己整合成分を含みうるが、それ全体を自己整合項とは同定しない（H を出力に回帰した R² は MLP 0.01〜0.07、CNN ≤ 0.01）[実測]。背骨の 3 層 MLP（LR raw／std、seed 0〜9、`c1_direction_1010`）の事後分解では、中心化した残りが沈める側なのは raw 0.98〜1.00・std 0.64〜0.71、std の定数モードが浮かせる側なのは 0.71〜0.79（分担 0.30〜0.41）で、raw の全体 0.86〜0.93 と std の 0.37〜0.56 の差は両者の競合と整合する [実測 ＋ 読み]。さらに接続重みの変化のうち現在の µ₂ 方向の成分（drift）に限れば G_i^drift = −µ̂₂,i·Cpl_i が厳密に成り立ち（Cpl_i = Σ_k c_k A_ki、c_k = −⟨ΔW₂[k], µ̂₂⟩、A_ki = unit i のゲートで重みづけた第 2 層の押し）、Cpl_i > 0 の unit でのみ符号は −sign h̄1_i になる [厳密・条件つき]（raw は課題 2 以降 Cpl > 0 が 100% で drift は沈める側 1.00、std は 84〜94% で浮かせる側 0.84〜0.94 [実測]）。この符号則は定数モード全体や CNN の蓄積した DC 成分へは一般化しない。第 1 層の押しの戻りを運ぶ項として読んでいた「W₃ の成長 × 初期の W₂ 列」（初期 W₂ × 育った W₃ の項）は、分担の中央値 0.03〜0.15・符号一致は課題とともに偶然へ（raw 0.78 → 0.52、std 0.80 → 0.54）で、主要項を支持しなかった [実測]。2 層の箱にも同じ定数モードはあるが、読み出しの δ の画像和 D = p̄ − 1/K は、当てはめ済み・iid 標本・出力 bias 停留・有界な読み出しのもとで O_p(N^{−1/2}) である [仮定つき]。

## 4. 付録 L　CNN の箱（RL-CIFAR × Kumar らの CNN）— 一般性の確認

**L.1 設定と現象。** conv5×5 3→16 → φ → maxpool2 → conv5×5 16→16 → φ → maxpool2 → fc 1024→100 → φ → fc 100→100 → φ → fc 100→10。1,200 枚・乱数ラベル・400 epoch/課題・batch 16・Adam 1e−3。活性化は leaky 0.1（LR）と適応 Snake（SNA ほか 3 腕）。R 本を束ねるエンジン（grouped conv ＋ CUDA graph、宿主と 1 step の損失が完全一致）で seed 10〜19 × 30〜50 課題（`sna_cnn_cause_1009`・`cnn_drive_verify_1009`）。喪失: LR の online 0.965（t1）→ 0.889（t30）。沈降: t30 で初期より下のチャネルは c1 85〜93%・c2 99〜100%。leaky では沈降は切替の押しでなく課題の中の当てはめで起き、c1 の初期値からの沈降の内訳は重みの平均パッチ方向の成分（µ 経路）が中央値 94%、bias が 6% [実測]。
**L.2 柱 1（入力の幾何）。** 入力からチャネル平均を引く（平均パッチ 3.78 → 0.03。zero-pad の意味が変わるので全位置の共分散は 16% 変わる）と、c1 の沈降は 0.34 倍になり全部が bias 経路へ移る（既知の µ → b の移り）、可塑性の喪失（online の低下）は 0.077 → 0.031（10/10）[登録・実測]（`cnn_center_1010`）。
**L.3 押しの向き。** c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ は自己形（92% 正）に従わない（LR: 沈める側 t1 0.50 → t10 0.10 → t30 0.40、SNA 0.47 → 0.11）[実測]。押しは G_j = κ_j H̄1_j + Σ (γK1 − κ_j/M)(H1_j − H̄1_j)（定数モード ＋ 中心化した残り）に割れ [恒等式]、学習で付いた接続カーネルの変化は (k, j) ごとの DC 和と チャネル内 AC に割れる（G_DC_j = Σ_k Δs_kj Ã_kj [恒等式]。zero-pad の境界では AC も平均水準に寄与するので、定数モードと DC バケットは別の分解）。LR の c1 では定数モードが浮かせる側 0.86〜0.95、全体との符号一致 0.89〜0.95、分担の中央値 0.70〜0.73（t5〜t20）、中心化した残りは沈める側 0.93〜0.99 [実測]。学習で付いた DC 和の変化だけの定数モードも全体と 0.88〜0.95 で符号一致し、初期値の分は 0.51〜0.59 [実測]。現在の µ₂ 方向の成分（drift）の符号則 −sign(P̄1_j) は P̄1 > 0 で 0.75〜0.98、P̄1 ≤ 0 で 0.69〜1.00 で立つが、P̄1_j は課題を追って符号を変える（≤ 0 のチャネルが 61 → 146/160）ので蓄積の基底としては狭い [実測]。c2 の押しは t10 以降 1.00 が沈める側で、その内訳は上流ブロック（c1 の重みが動いて P1 が変わる項。W1 と b1 の成分）が分担の中央値 0.77〜0.96（t10 以降 0.96）[実測]。腕をまたぐと、定数モードはどの腕でも浮かせる側が多数（0.62〜0.99）・中心化した残りは沈める側が多数（0.86〜1.00）で、全体の符号は両者の大きさの競合に対応した: LR・中心化 LRc・SNA では定数モードが支配（|定数| > |残り| 0.76〜0.95）し c1 は浮き、固定 α = 3 の SNAc3 では定数モードが非支配（0.12〜0.27、分担 0.20〜0.37）になって c1 は沈み（0.84〜0.89）、conv と fc の片方だけ適応の 2 腕は 0.5〜0.8 で半々 [実測]。中心化 LRc への計算前の予言（c1 浮く・drift 浮かせる側・c2 沈む）は 3/3 当たった [登録]。
**L.4 課題の中。** LR の t10→11・t20→21 を bit 一致で再走すると、接続重みの µ₂ 方向の結合は新課題の最初の 75 更新で −1.73 / −0.79 動き、課題末の正味は −0.35 [−0.75, 0.05] / −0.28 [−0.67, 0.12]。c1 の平均は最初の 75 更新で +0.08 / +0.12、750 更新までに −0.31 / −0.35、正味 −0.09 [−0.23, 0.04] / −0.07 [−0.19, 0.04]（点推定は負、区間は 0 を含む）。安定な区間では動きの 0.92〜1.03 を W1 の平均パッチ方向の成分が占める（§3.4 の µ 経路）。課題の初め（step 75、実ラベルの勾配）の押しは沈める側 0.72 / 0.71 で、接続カーネルの AC 部分が沈める側に揃い（0.86 / 0.78）、DC 部分は半々（0.41 / 0.51）。課題末では DC 部分が沈める側 0.83 / 0.84、AC 0.07 / 0.22 [実測]。正味の沈降の大きさの式は無い [未導出]。
**L.5 Adam と十分条件。** 最初の 1 歩で SGD の期待方向と有意に逆になるチャネルは c1 0〜1.7%（LR の t1 だけ 4.4%）・c2 3〜4%（LR の t1 だけ 10%）、凍結参照は −G に 92〜96% 従う。付録 K の十分条件 (3)(5)(8) は CNN の実状態（Snake 240・leaky 60 状態）で一度も成り立たない [実測]（`cnn_drive_verify_1009`）。
**L.6 適応 Snake の CNN での劣化。** 固定 α = 3 に負ける（t21〜30 で −0.7 pt）。30 課題・この構造では、入力層の α を 3 に固定する（尺度の錨）か課題 1 末で α を凍結すると固定 α = 3 を上回り（+0.5 pt、10/10）、錨の上で fc の平らな点を持ち上げると +0.7 pt（10/10）[登録・実測]（`sna_cnn_cause_1009`）。
