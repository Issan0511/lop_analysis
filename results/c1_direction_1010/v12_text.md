## 1. §4.7 G13 の段落の末尾に足す（第 1 層の押しそのもの）

第 1 層の押しそのものを、接続重み W₂ の初期値 W₂⁰・現在の平均入力 µ₂ の方向の成分（drift）・残りに分けると、押しも同じ三つの和に割れる [恒等式]。drift の項は G^drift_i = −µ̂₂,i · Cpl_i（Cpl_i = Σ_k c_k A_ki、c_k = −⟨ΔW₂[k], µ̂₂⟩ ≥ 0 は第 2 層の µ₂ 経路の沈降そのもの、A_ki は unit i のゲートで重みづけた第 2 層の押し）と厳密に因数分解され [恒等式]、Cpl_i > 0（raw で課題 2 以降 100%、std で 84〜94%）のもとで、符号は上流の平均出力 h̄1_i の符号の逆になる [厳密・条件つき ＋ 実測]。raw の生きた第 1 層は閉じた側で h̄1 < 0 なので drift は沈める側（1.00）、std は全 unit が h̄1 > 0 で浮かせる側（0.84〜0.94）である [実測]（`c1_direction_1010`、seed 0〜9）。押しを定数モード κ_i H̄_i（H̄_i は unit i への逆伝播の画像平均。第 2 層の bias の押し D̄_k が W₂ を通して上流へ透過する項）と中心化した残りに割ると [恒等式]、残りは raw でほぼ全 unit（0.98〜1.00）・std で 0.64〜0.71 が沈める側、定数モードは raw で弱く沈める側（h̄1 < 0 の unit で 0.70〜0.87）・std で 0.71〜0.79 が浮かせる側（分担 0.3〜0.4）である [実測]。std の 37〜67% は、浮かせる側の透過と沈める側の残りの拮抗で読める [実測 ＋ 読み]。「W₃ の成長 × 初期の W₂ 列」を通る項（初期 W₂ × 育った W₃）は、符号の一致が課題とともに偶然へ落ち（0.78 → 0.52）、分担 0.03〜0.15 で効いていない [実測]。2 層の箱にも同じ定数モードはあるが、読み出しの δ の画像和 D = p̄ − 1/K が当てはめ済みの iid 有限標本で O_p(N^{−1/2})（成分 sd 0.0087）なので小さい [仮定つき]。

## 3. §11 範囲の段落に足す（CNN）

「標準の CNN（Kumar らの conv 2 層 + fc 3 層、RL-CIFAR、leaky と適応 Snake）でも可塑性の喪失と沈降は起き、深い conv 層の押しは沈める側に揃う（leaky で t10 以降 1.00。その 77〜96% は上流の c1 の重みが動くことで運ばれる）が、入力 conv 層の押しは自己形に従わない（leaky で沈める側 0.10〜0.23、t5〜t20）。その理由は §4.7 の透過項と同じで、入力層の押しの 0.7 を接続カーネルの DC 和を通る下流の押しの透過（定数モード）が運び、浮かせる側に働く（符号一致 0.89〜0.95）。理論の十分条件（付録 K）は CNN の実状態で一度も成り立たないので、CNN は定理の対象でなく測定の対象として付録 L に置く。」

## 4. 付録 L　CNN の箱（RL-CIFAR × Kumar らの CNN）— 一般性の確認

**L.1 設定と現象。** conv5×5 3→16 → φ → maxpool2 → conv5×5 16→16 → φ → maxpool2 → fc 1024→100 → φ → fc 100→100 → φ → fc 100→10。1,200 枚・乱数ラベル・400 epoch/課題・batch 16・Adam 1e−3。活性化は leaky 0.1（LR）と適応 Snake（SNA ほか 3 腕）。R 本を束ねるエンジン（grouped conv ＋ CUDA graph、宿主と 1 step の損失が完全一致）で seed 10〜19 × 30〜50 課題（`sna_cnn_cause_1009`・`cnn_drive_verify_1009`）。喪失: LR の online 0.965（t1）→ 0.889（t30）。沈降: t30 で初期より下のチャネルは c1 85〜93%・c2 99〜100%。沈降は切替の押しでなく課題の中の当てはめで起き（leaky は切替で上がる）、c1 の沈降の 94% は重みの平均パッチ方向の成分（µ 経路）が運ぶ [実測]。
**L.2 柱 1（入力の幾何）。** 入力からチャネル平均を引く（平均パッチ 3.78 → 0.03）と、c1 の沈降は 0.34 倍になり全部が bias 経路へ移る（既知の µ → b の移り）、可塑性の喪失（online の低下）は 0.077 → 0.031（10/10）[登録・実測]（`cnn_center_1010`）。
**L.3 押しの向き。** c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ は自己形（92% 正）に従わない（LR: 沈める側 t1 0.50 → t10 0.10 → t30 0.40、Snake 0.51 → 0.43）[実測]。押しは G_j = κ_j H̄1_j + Σ (γK1 − κ_j/M)(H1_j − H̄1_j)（定数モード ＋ 中心化した残り）に割れ [恒等式]、定数モードは接続カーネル W₂ の (k, j) ごとの DC 和を通る c2 の押しの透過で、G_DC_j = Σ_k Δs_kj Ã_kj [恒等式]。LR の c1 では定数モードが浮かせる側で支配し（t5〜t20 で 0.86〜0.95、分担 0.7、|定数| > |残り| 0.88〜0.93）、残りは沈める側（0.88〜0.99）だが小さい。定数モードの符号を決めるのは学習で付いた DC 和の変化（Δs_kj < 0 が 76〜82%。初期値の DC 和の分は偶然 0.51〜0.59）[実測]。自己形の理想化 H1 ∝ P1 は R² ≤ 0.01 で conv 層には実質ない [実測]。現在の µ₂ 方向の成分（drift）の符号則 −sign(P̄1_j) は c1・c2 とも 0.88〜1.00 で立つが、P̄1_j が課題を追って符号を変える（≤ 0 のチャネルが 61 → 146/160）ので、蓄積した DC 和の基底としては狭い [実測]。c2 の押しの 77〜96% は上流ブロック（c1 の重みが動いて P1 が変わり z̄2 が下がる項）で、t ≥ 10 では P̄2 ≤ 0 となって透過項も沈める側に反転する [実測]。符号は固定でなく下流の状態で決まる: 入力を中心化した LRc でも c1 は浮き（沈める側 0.16〜0.26、計算前の予言 3/3 が当たり）、適応 Snake（SNA）と conv だけ適応の腕でも浮く（drift 浮かせる側 0.77〜0.96）が、固定 α = 3 の Snake では c2 の W2 が µ₂ に反平行に育たず（c_k > 0 が 0.21 → 0.01）透過が消えて c1 は自己形どおり沈み（0.84〜0.89）、conv 固定・fc 適応の腕では c2 の押しが揃わず（D̄_k > 0 が 0.16〜0.50）半々になる [実測]。
