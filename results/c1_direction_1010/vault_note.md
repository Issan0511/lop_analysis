## 0. 何を測ったか

- **穴**: CNN の入力 conv 層 c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ が自己形 S_j = Σ γ K1 P1_j（92% 正）に従わない（leaky: 沈める側 0.50（t1）→ 0.10（t10）→ 0.40（t30）、c2 は 1.00）。3 層 MLP の第 1 層も std で揃わない。V12 §4 の「期待値での必然」は 2 層で閉じているので、隠れ層に読まれる層で何が加わるかを導く。
- **恒等式**: G_j = Σ_{n,q} γ K1 H1_j（H1 = P1 への逆伝播）で、G と S の差は H1 と P1 の差だけ。H1 は接続カーネル W2[:, j] に線形なので、W2 の割り方ごとに G が厳密に割れる。割り方 3 つ: (i) 初期値 W2⁰ ＋ 現在の µ̂₂ への射影（drift）＋ 残り、(ii) 学習で付いた ΔW2 を (k, j) ごとの DC 和（DC バケット）＋ チャネル内 AC、(iii) **定数モード** κ_j H̄1_j（H1 の全 (n,q) 平均 × ゲート重みの和。全 W2 と境界を含む）＋ **中心化した残り**（Codex (25)）。DC バケットの押しは G_DC_j = Σ_k Δs_kj Ã_kj（Ã_kj = ゲート × K1 で重みづけた c2 の押し）[恒等式]。(ii) と (iii) は別の分解（zero-pad の境界では AC も平均水準に寄与する）。drift の項は MLP で G^drift_i = −µ̂₂,i·Cpl_i と厳密に因数分解（1e−15）、CNN では −(P̄1_j/‖µ₂‖) Z_j − E_ac,j。
- **データ**: CNN は保存済みチェックポイント（LR 60・Snake 4 腕 240・中心化 LRc 60 状態、seed 10〜19、t = 1/2/5/10/20/30）を float64 で解析（新しい学習なし。再走は Q2 の LR 2 課題だけ、元の走と bit 一致）。MLP は `rlcifar_mlp_battle_0918` の LR raw/std・seed 0〜9 の snap（t00 = 初期値）。検査: CNN は保存済みの G と 2.3e−12、分解の和 1.4e−12、全 360 状態 all_pass。MLP は autograd と 5.9e−15、p169 の既知の率と 36/36 状態で完全一致。

## 4. 言える／言えない

**言える**: (1) 隠れ層に読まれる層の押しは定数モード＋中心化した残りに厳密に割れ（固定状態の帳簿）、残りは沈める側が多数、定数モードは浮かせる側が多数。(2) LR・LRc・SNA の c1 では定数モードが支配して全体と符号が一致し、学習で付いた接続カーネルの DC 和の変化だけでも全体の符号を強く追跡した。初期値の分は偶然。(3) MLP では drift の符号則 −sign(h̄1) が Cpl > 0 のもとで厳密（raw 1.00、std 0.84〜0.94）。CNN では条件つき（Z_j > 0・残りの非支配）。(4) MLP の raw/std の差は定数モードと残りの競合と整合する（読み）。(5) 「W3 の成長 × 初期の W2 列」は分担 0.03〜0.15 で主要項ではない。(6) 中心化した LRc でも c1 は浮く（計算前の予言 3/3）。(7) 固定 α = 3 の Snake の c1 は定数モードが非支配になって沈む。(8) LR の c2 の押しは上流ブロックの分担の中央値 0.77〜0.96。
**言えない**: 定数モードの分担（CNN 0.63〜0.75、MLP std 0.30〜0.41）を決める式。Δs_kj の負の変化が P̄1_j の反転後も残る機構の分離（履歴・箱和・Adam。Codex (20) の分解は未測定）。CNN で残り・上流が c2 を支配する理由。正味の沈降の大きさ（区間は 0 を含む）。反例（ゲート相関・AC × ゲート・境界、Codex 第 1）の実軌道での頻度。2 層の定数モードは O_p(N^{−1/2})（当てはめ済み・iid・出力 bias 停留・有界な読み出しのもとで）で、「2 層には無い」とは書かない。定数モードと DC バケットは別の分解で、「透過 = DC 和」とは書かない。「決まる・運ぶ・消える」は固定状態の帳簿の対応で、学習の履歴の因果ではない。
