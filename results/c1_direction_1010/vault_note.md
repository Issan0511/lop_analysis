## 0. 何を測ったか

- **穴**: CNN の入力 conv 層 c1 の切替の押し G_j = E_new⟨∇m_j, ∇L⟩ が自己形 S_j = Σ γ K1 P1_j（92% 正）に従わない（leaky: 沈める側 0.50（t1）→ 0.10（t10）→ 0.40（t30）、c2 は 1.00）。3 層 MLP の第 1 層も std で 37〜67%。V12 §4 の「期待値での必然」は 2 層で閉じているので、隠れ層に読まれる層で何が加わるかを導く。
- **恒等式**: G_j = Σ_{n,q} γ K1 H1_j（H1 = P1 への逆伝播）で、G と S の差は H1 と P1 の差だけ。H1 は接続カーネル W2[:, j] に線形なので、W2 の割り方ごとに G が厳密に割れる。割り方 3 つ: (i) 初期値 W2⁰ ＋ 現在の µ̂₂ への射影（drift）＋ 残り、(ii) ΔW2 = (k, j) ごとの DC 和（DC バケット）＋ チャネル内 AC、(iii) 定数モード κ_j H̄1_j ＋ 中心化した残り（Codex (25)）。DC バケットの押しは G_DC_j = Σ_k Δs_kj Ã_kj（Ã_kj = c1 チャネル j のゲート × K1 で重みづけた c2 の押し、境界込み）[恒等式]。drift の項は MLP で G^drift_i = −µ̂₂,i·Cpl_i と厳密に因数分解（1e−15）、CNN では −(P̄1_j/‖µ₂‖) Z_j − E_ac,j。
- **データ**: CNN は保存済みチェックポイント（LR 60・Snake 4 腕 240・中心化 LRc 60 状態、seed 10〜19、t = 1/2/5/10/20/30）を float64 で解析（新しい学習なし。再走は Q2 の LR 2 課題だけ、元の走と bit 一致）。MLP は `rlcifar_mlp_battle_0918` の LR raw/std・seed 0〜9 の snap（t00 = 初期値）。検査: CNN は保存済みの G と 2.3e−12、分解の和 1.4e−12、全 360 状態 all_pass。MLP は autograd と 5.9e−15、p169 の既知の率と 36/36 状態で完全一致。

### 2.5 課題の中（LR t10→11・t20→21、再走は元の走と bit 一致）

結合 Σ_k⟨W2[k], µ̂₂⟩ は切替で落ち（75 更新で −1.73 / −0.79）課題の中で大半が戻る（正味 −0.35 / −0.28）。c1 の平均は切替で上がり（+0.08 / +0.12）、750 更新で下がり（−0.31 / −0.35）、正味 −0.09 / −0.07。動きは W1 の平均パッチ方向の成分がほぼ全部運ぶ（0.92〜1.03、既知の µ 経路）。課題の初め（step 75、実ラベルの勾配）の沈める押し 0.72 / 0.71 は AC 部分（0.86 / 0.78）が運び、課題末では DC 部分が沈める側 0.83 / 0.84（c2 の戻りの押し × 負の DC 和）。順番は「切替の浮き（透過）→ 課題初めの沈み（自己整合側）→ 課題後半の沈み（透過の反転）」で、正味の大きさの式は無い。

## 4. 言える／言えない

**言える**: (1) 隠れ層に読まれる層の押しは定数モード（透過）＋中心化した残りに厳密に割れ、残りは MLP・CNN とも沈める側が多数。(2) CNN の c1 では透過が浮かせる側で支配し（LR・LRc・SNA・CV06FC3）、符号は学習で付いた接続カーネルの DC 和の変化が決め、初期値の分は偶然。(3) 現在の µ₂ 方向の成分の符号則 −sign(P̄1)（−sign(h̄1)）は Cpl > 0 のもとで厳密な因数分解で、CNN・MLP とも 0.88〜1.00。(4) MLP の raw/std の差は透過の符号（上流の平均出力の符号の逆）で読める。(5) 「W3 の成長 × 初期の W2 列」は効いていない。(6) 中心化しても c1 の押しの向きは変わらない。(7) 固定 α = 3 の Snake の c1 は透過が消えて沈む。(8) c2 の押しの 77〜96% は上流が運ぶ。
**言えない**: 透過の分担（CNN 0.7、MLP std 0.3〜0.4）を決める式。Δs_kj の負の蓄積が P̄1_j の反転後も残る機構の分離（履歴・箱和・Adam。Codex (20) の分解は未測定）。CNN で AC・上流が c2 を支配する理由。正味の沈降の大きさ。反例（ゲート相関・AC × ゲート・境界、Codex 第 1）の実軌道での頻度。2 層の定数モードは O_p(N^{−1/2}) で小さいが厳密 0 ではない（「2 層には無い」とは書かない）。
