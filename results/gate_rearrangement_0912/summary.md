## 4. 読み

### 4.1 零交差「密度」説は棄却、「1 本か周期か」の二値は完全に残る

V1（組み換え量が飽和を並べる）は Spearman **−0.36** で `FAILS`。V2（Snake 内で α に単調）も `NOT`（S = 0.23 / 0.95 / 0.83 で SN06 > SN15）。**量的な読みは死んだ。**

一方 V3・V4 は的中し、**飽和比 S が族で完全に分離する**:

| 群 | 活性化 | S = c(k=0.1)/c(k=1) |
|---|---|---|
| **1 交差** | LR001・LR・LR03・ELU1 | **−0.20 / −0.24 / −0.06 / −0.18**（全部負） |
| **周期** | SN02・SN06・SN15 | **+0.23 / +0.95 / +0.83**（全部正） |

leak を 100 倍（0.01→0.3）振っても、折れ目を平滑（ELU）にしても、1 交差なら S ≈ −0.2 に揃う。周期族は 3 本とも正。**7 腕が例外なく二分される。**

### 4.2 k=0 が決定的 — 組み換えでは説明できない

**k=0 では境界で置換が変わらない（`gate_corr` ≡ 1.0、`gate_l1` ≡ 0）。組み換えはゼロである。** それでも:

| 活性化 | c(k=0) |
|---|---:|
| ELU1 / LR03 / LR001 / LR | **−0.042 / −0.036 / −0.033 / −0.029** |
| SN02 / SN06 / SN15 | **−0.001 / +0.004 / +0.012** |

1 交差の 4 本は自己膨張（c<0）、周期族は 0 以上で **α に単調増**。**境界で何も組み変わっていないのに差が出る以上、機構は「境界での組み換え」ではない。** タスク内でゲートが動くこと自体に由来する。§0 の事後読みは、二分の部分だけ正しく、機構の帰属を誤っていた。

### 4.3 切替ショックは依然として最良の単一予測子（V5 `TIE`）
21 セルで Spearman(切替CE, c) = **+0.84** 対 Spearman(gate_corr, c) = **−0.73**。組み換えはショックに勝てない（差 0.11 < 0.15 で `TIE`）。

### 4.4 gate_corr が何を測っていたか
k=1 では Snake の `gate_corr` が 0.003〜0.06 まで落ちる（LR001 0.50・ELU1 0.39 に対し）ので、**大きな摂動では確かに Snake のゲートが激しく組み変わる**。しかし飽和が起きる k=0.1 では SN02 が 0.916 と最も組み換えが小さいのに S は正。`gate_corr` は φ′ の**値の分布**に支配され（leaky は 2 値、Snake は [0,2] 連続）、**どのユニットが応答するかの配置**を測る指標として不適切だった可能性が高い。

## 5. 結論と限界

- **活性化形状の検定 5 回目も、量的な予測としては外れた**（φ″・gcorr・RMS φ′・h・零交差密度）。
- ただし**二値の分離（ゲートが単調か周期か）は 7 腕で例外なし**で、これは新しい確定事実。侵食の符号が k=0 で族により分かれることは、**ゲートの単調性が c の符号を決める**という形で残る。
- 機構は「境界での組み換え」ではない（4.2）。次に測るなら**タスク内でのゲートの動き**（学習中に φ′ がどれだけ入れ替わるか）。
- V2 は n=3。S は比なので c(k=1) が小さい `SN15`（0.031）で不安定。生値も §2 に併記した。
- k<1 は Permuted MNIST の外側。LoP の設計指針としては読まない。
- 初回本走は `p4` の許容 1e−12 が厳しすぎ 63/63 が最後の検査で落ちた（追補 2）。検査を訓練の後ろに置いた設計の失敗で、28 分を失った。
