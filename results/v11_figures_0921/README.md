## 0922 の訂正（Issa 指摘）

本文から正規化量を外した。図 2 の (b) 沈下比 `z̄₂/sd₂` と (d) `|b₂|/sd₂`、図 3 の (b) `|b₂|/sd₂` は、
分母がゼロに落ちるだけで発散する量だった。`ref` は t50 で `zsd_l2` = 0・`zbar_l2` = −0.037 なので、
比の −3.7e10 と 1.5e11 は分母の写しでしかなく、生の量は動いていない（[[引用禁止]] C
「正規化量で力学を書かない。生の x で測る」）。

- 図 2 のパネル: (a) online・(b) 生の `zbar_l2`・(c) 生の `zsd_l2`・(d) `dead_frac_l2`
- 図 3 の (b): 生の `bias_absmean_l2`

読みも変わる。`ref` は沈んで死ぬのではなく目盛が潰れて死ぬ（`sd₂` → 0）。沈んで死ぬのは `C`
（`z̄₂` −168・`sd₂` 78）。`H` は `ref` 型（`sd₂` 0.079）。登録列 R2（沈下比の t50 中央値 −0.191）は
キャプションの数値として引く。

## 0922 の読みやすさの直し

値が両端に張り付いて位置から読めなくなっていた 5 枚を直した。軸の規約（§2.5-3 の
online accuracy は 0–1.02 固定）は動かさず、**数値を点のそばに添える**か、**軸線に余白を入れる**
ことで解いた。

| 図 | 何が起きていたか | どう直したか |
|---|---|---|
| 2 | `dead_frac` の 0 と 1 が軸線に重なり、`sd₂` = 0 の `ref` が底の枠線に隠れていた | 両端に余白（`style.breathe`）。`ref` は太めに敷いて上の腕の隙間から見えるように |
| 3 | CH と CHB が同じ青の族で、10 本ずつ重なると見分けられなかった | CHB を破線に（`seeds_lines` が線種を取るように） |
| 4 | (c) で 4 腕が 0 に重なり、上の 1 本しか見えなかった | 余白＋「H・CH・KKT1・L2 Init は 0 のまま」と注記 |
| 5 | (b) の境界の自己 S が軸の底に張り付き、格のラベルが点に被っていた | `ylim` を明示、格を移動 |
| 7 | (b) で 4 腕が 0.10–0.12、8 腕が 0.85–0.99 に固まり、上の 8 腕の順位が読めなかった | 数値を添える（`style.value_labels`） |
| 8 | (a) で 6 腕が 0.92–0.97 に固まっていた | 同上 |
| 9 | (a) で 13 腕が 0.58–0.67 に、fresh gap は 13 腕が 0 の近くに固まっていた。(c) は 7 腕ぶんの帯が濁っていた | (a) は数値を添える。(c) は中央値の線だけにし、seed の散らばりは (a) が担う |

`style.py` に 2 つ足した。`value_labels(ax, y, values)` は水平の順位図で点のそばに数値を置き、
`breathe(ax)` は端の値が軸線に張り付かないよう両端に余白を入れる。格のラベルは
`center right` / `center left` にも置けるようにした。
