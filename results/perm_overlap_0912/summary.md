## 3. 読み

### 3.1 「c はタスク側の変数」は棄却（V2 `DIFFERENT`）

| k | 切替 CE (LR/SN06) | c (LR) | c (SN06) | 差 |
|---:|---|---:|---:|---:|
| 0 | 0.015 / 0.053 | **−0.0285** | +0.0036 | +0.0321 |
| 0.1 | 0.198 / 0.228 | −0.0099 | **+0.0423** | **+0.0522** |
| 0.25 | 0.635 / 0.594 | +0.0137 | +0.0472 | +0.0336 |
| 0.5 | 1.716 / 1.574 | +0.0295 | +0.0466 | +0.0171 |
| 1 | 3.949 / 4.597 | +0.0421 | +0.0445 | **+0.0025** |

**2 つの活性化が一致するのは k=1 だけ。** そこから離れると最大 0.052 開く——19 腕の全幅（0.026）の 2 倍。

**つまり「活性化 19 腕で c が 0.024–0.050 に揃う」は、k=1 でしか測っていなかったことの産物だった。**

### 3.2 leaky と Snake で機構が違う

- **leaky**: 切替ショックが c を完全に媒介する（Spearman(切替CE, c) = **+1.000**）。k を下げると c は単調に下がり、k=0.25 と 0.1 の間で**符号が反転**して自己膨張側に入る。§0 の事後読み（誤答標本が既存パターンを縮める）はこちらでは支持された。
- **Snake**: **飽和する。** c(k=0.1)/c(k=1) = **0.95**。切替 CE 0.23（k=1 の 1/20）で既に満額の侵食が立つ。Spearman は +0.600 で、k=0 の 1 点を除けばほぼ平坦。**Snake は完全に同じ置換でない限り、常に最大の侵食を受ける。**

読み（事後・未検定）: Snake のゲート 1+sin(2αz) は z の零交差が周期的に並ぶので、**画素を 1 割入れ替えるだけで応答するユニットの集合が大きく入れ替わる**。leaky のゲートは sign(z) しか見ないので 1 割では反転が起きにくい。これは[[勾配の因子分解と斉次性の破れ_結果_0912]]の「ゲートは Adam に消される」と矛盾しない——消えるのはユニットごとの**定数倍** $g2$ であって、**どのユニットが応答するかという配置**は消えない。

### 3.3 c<0 でも暴走しない（V4 `SUB_SQRT`）
`K000_LR` は c = −0.0285 で固定点が消えるのに p_late = **0.435** と √t を下回る。D が 1.165 → 0.374 と 1/3 に落ちるため。**指数と絶対値を混同するなという §4 の但し書きが効いた形。** 帳簿はこのセルで 17.1% 過小（V5 `FAILS`、順序は Spearman +0.94 で保存）。

### 3.4 この軸では幅が LoP を並べない（V6 `NO`）
Spearman(N120, 精度低下) = **+0.15** に対し (k, 精度低下) = **+0.74**。`K000_LR` は幅 6.98 で精度が **改善**（−0.52 pt）、`K000_SN06` は幅 4.57 で +0.82 pt 低下。**幅が小さい方が悪い。** §6 で宣言した交絡どおり k が支配しており、`CONFOUNDED` ではなく素直に `NO`。**ただし k<1 は Permuted MNIST の外側なので、V9 の「幹は幅」への反証としては読めない。**

### 3.5 e2 は生き残った
10 セルで Spearman(e2, ρ) = **+0.915**（D² とは +0.939）。自然 8 腕・BL 4 腕・H 6 腕に続き 4 データ目で符号一致。

## 4. 限界

- 3.2 の機構（ゲートの零交差配置）は事後・未検定。α を振れば検定できるが本走には無い。
- 活性化 2 種、k 5 水準。`DIFFERENT` は 2 点間の主張。
