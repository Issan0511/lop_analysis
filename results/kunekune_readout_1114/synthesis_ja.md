# kunekune族の同条件読み出し対照 — kunekune_readout_1114

実施日：2026-11-14。事前登録：fc83776f。実行コード：1cb597e3。全60履歴・1,440分岐完走、保存した終状態1,440個の再検査済み。

**今回の一隠れ層・乱数ラベルMNISTでは、KKA・KKA23・KKT1の読み出しを0.1倍にすると学び直しが悪化した。並べ替えた後でも同じで、課題1・10・30のすべて、各10 seedで悪化した。ELUの課題10・30では逆に縮小が改善をもたらす。** kunekune族を「ELUと同じ読み出し障害を、微分の温存だけで耐えている」とする説明は、この介入では支持されない。学習した読み出しを残す方が有利だった。

## 比較条件と指標

先行の `elu_specificity_1112` / `readout_separation_1111` のLNなしMLPと同じ。MNIST 1,200例、784–100–10、batch 16、Adam 0.001、1課題4,000更新、自然履歴30課題。seed 0〜9の入力・初期パラメータ・ラベル・batch列を対応させた。活性化ごとの学習済み特徴や読み出しノルムを等しくした実験ではない。KKA・KKA23・KKT1・適応Snake（SNA）は既存SnakeFamilyの式と分散EMAによるα適応を使用。

課題1・10・30の末から次のラベルへ切り替え、次の8条件を各4,000更新走らせた。全条件で介入後も全パラメータと活性化のEMAを学習する。

| 記号 | 切替時の操作 |
| --- | --- |
| N | 読み出し・Adamとも自然状態 |
| S1 | 読み出しはそのまま、読み出しのAdamだけ消す |
| S01 | クラス中心化した読み出しを0.1倍、平均logitを保つbias補正、読み出しのAdamを消す |
| P1 | 読み出しの各列を独立にクラス並べ替え、同じbias補正、読み出しのAdamを消す |
| P01 | P1と同じ並べ替えの後に0.1倍、同じbias補正 |
| Z_keep | 読み出し重み・biasをゼロ、本体のAdamは残す |
| Z_clear | 読み出し重み・biasをゼロ、全Adamを消す |
| F0 | 同じseedの新品本体・初期EMA、ゼロ読み出し、新品Adam |

Uは切替後0〜4,000更新の訓練精度不足（1−accuracy）の台形積分を4,000で割った値。小さいほど速い。以下の「利益」は介入前U−介入後Uを百分率ポイント（pp）で示す。**正は改善、負は悪化**。括弧は10 seedの対応を保った10,000回bootstrapの記述的95%区間（多重性補正なし）。主比較は課題10末。課題1・30は副次比較。

## この結果で言うこと

**同じ入力・学習条件・読み出し介入でも、その損益は活性化と学習履歴で逆転する。kunekune族では、負側への位置の移動の下でも微分と学習が保たれ、読み出しの縮小は適応を妨げた。ELUでは後期に縮小が適応を回復させた。** これは「読み出しの大きさ」単独で善悪を決めず、活性化の形・尺度・本体状態との組合せを見る必要があるという結果。

事前に競合させた「応答は残るがB_P/Z_Pも正」というE1はkunekune3種では支持されなかった。E2の「低U・リセット本体が新品以上」の側には合うが、縮小利益が0付近というより明確な介入損だった。E3の「本体の制約で救えない」も課題10のkunekuneには当たらない。登録した期待の文言を結果に合わせて変更しない。

この結果から、装填（学習が次の切替の押しを作ること）自体が無い、読み出しがいつでも無害、微分だけが性能差を媒介する、とは結論しない。Pは列内の値とノルムを保つが読み出し全体の幾何と予測も変え、純粋な整列除去ではない。S01/P01は平均logitを保つbias補正を含み、Z系はbiasもゼロにするため単なる同じ尺度操作の終点ではない。αの適応履歴も活性化条件の一部。一時点の0.1倍介入であり、旧Qallの各列初期ノルム制約や継続的予防、ViT・CNNの結果へはそのまま拡張しない。
