# 事前予測 — `LR+l2`（leaky に WD）: Q1 の +0.0233 は Snake 固有か

書いた時刻: 2026-09-07 01:1x（**走らせる前**）。Claude。[[RandomLabelMNIST結果_0906]] §引用制限で自ら挙げた穴。

## なぜ
Q1 = `ACTIVATION_MATTERS_UNDER_WD`（`SNA+l2` − `R+l2` = +0.0233・10/10）は「正則化の下でも活性化が効く」を
示すが、**比較相手が ReLU だけ**なので「Snake が特別」か「ReLU が特別に悪い」かを分けられない。
素の腕では `SNA` 0.986 対 `LR` 0.808（+18.0 pt）だが、WD を入れると `R` が 0.114 → 0.941 と +82.7 pt 回復した。
**同じ回復が leaky にも起きるなら、`SNA+l2` の優位は縮む。**

## 設計
`LR --iv l2:1e-3`・seed 0–9・50 タスク・400 epoch・Adam lr=0.001。他は本走と同一（同 seed・同 init・同ラベル列）。
既存 6 腕の数値をそのまま使い、窓 31–50 の `online_acc` で対応差を取る。**未登録の追加腕・REPORT_ONLY。**

## 予測
1. **`LR+l2` は `R+l2`（0.9412）より上、`SNA+l2`（0.9644）より下。** 0.950–0.962 に入る。確信 中。
   非ゼロ床は WD と組むと ReLU より有利だが、開いたゲート（mob 0.82）には届かない
2. **`SNA+l2` − `LR+l2` は +0.005〜+0.015 で 9/10 以上。** 確信 低〜中。
   **これが有意でなければ Q1 の +0.0233 は「ReLU が特別に悪い」の話に縮む** — その場合 §引用制限に
   「Q1 を『Snake 固有』と読まない」を追加する
3. **`LR+l2` の mob は 0.11 前後**（素の `LR` と同じ・床が決めるので WD で変わらない）。`SNA+l2` の 0.824 と桁が違う。確信 高
4. **`LR+l2` の ‖w‖ 比は 1.0 前後**（素の `LR` は 16.9 倍だった。WD がノルムを抑えるのが leaky で最も効く）。確信 中〜高
5. **外れたときに第一に疑うもの**: λ=1e−3 が leaky にとって最適でない（腕ごとに最適 λ が違う可能性）。
   その場合 `LR+l2` の不利は λ の不利であって活性化の不利ではない

**起草側の予測であり独立の予言ではない。**
