## 3. 読み
1. **幅の成長は活性化に依らない（ほぼ）。** ゲートも φ″も無い LIN が leaky の 85% の幅（7.14 対 8.40）まで、指数 0.437（対 0.471）で伸びる。cos −0.039（対 −0.046）。直交堆積＋Adam 注入の機構は線形網で成立。指数のわずかな差（0.03）は未説明。
2. **沈下にはゲート非対称が要る。** LIN の z̄ は 120 タスクで ±0.14 に留まる。§F6 の説明（正負のゲート非対称が釣り合い点を σ に比例して沈める）は、非対称ゼロで沈下ゼロという形で支持された。
3. **σ は ‖W̃‖ に厳密比例し、純粋な幅係数は 0.071。** LIN の σ²/‖W̃‖² は t20–120 で 0.071 一定。**leaky の 0.101 から行平均オフセット（約 28%）を除いた 0.073–0.075 と一致する**。よって §D-⑤ の「σ/‖W̃‖ の腕差」は **leaky については解消**（オフセット項で全部説明できる）。残る異常は ELU1 の 0.206 だけ。
4. **W2 が無いと幅は止まり、平均 logit が別の対称性で流れる。** LIN0 は cos −0.137（3 層腕の 3 倍）で t60 に頭打ち（p 0.03）——確信度圧の切替ショックが緩衝なしに直接かかる。一方 **平均 logit は −13.4 → −50.7 と t に厳密線形**（−0.373/task）。softmax は全 logit の共通シフトに不変で、その方向の勾配は Σ_k(p_k−y_k)=0 で**厳密にゼロ**。ゼロ勾配の方向を Adam の座標正規化が非対称に押して、等速で流している。**これはゲートの沈下とは別の機構**（完全な平坦方向＋Adam）。σ が ‖W̃‖ と無関係に伸びる（傾き 5.8）のは、このオフセット m²·1ᵀΣ1 が σ² を支配するため。
5. **幅が伸びても沈まなければ LoP は小さい。** LIN は leaky の 85% の幅で精度低下 −0.6 pt（leaky −2.9）。ただし線形網は容量が低く（0.889）落ち代が少ない可能性があり、決定的ではない。
