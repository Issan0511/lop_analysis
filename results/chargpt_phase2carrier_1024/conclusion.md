# C3の相2：全経路の合計と、その押しを運ぶ担い手

2026-10-24 / Issaの依頼 / Codex。登録spec `b71fa304`。新しい学習なし。

**課題100末のC3 L0では、上流を含む実CE切替期待の合計が、SGDで10/10 seed、保存Adam分母固定で9/10 seed、沈める向きだった。最大の担い手は注意0（その前LNを含む）で、相2予測もその担い手と合計の符号を捉えた。** 一方、測定した早期のL0は全seedで浮かせる向きであり、自unit行の方向対応が課題5–6頃から強まったことを、L0全体の沈降開始と読むことはできない。

## 測ったもの

C3-2、seed0–9、課題末1・4・5・6・9・39・50・89・100の90状態。L0主、L1も測定。位置は固定一様probe、勾配は現課題の鎖probeで計算し、全512unitを主集計した。閉じたunitも上流が変われば位置が動くため除かない。これは指定端点の比較で、未測定の課題を含む窓中央値ではない。

切替実測は、現入力を固定して独立一様の新ラベルへ切り替えたCE期待勾配（誤差p−1/V）。次課題の入力や100更新の再生ではない。現課題の真の確率Qへの勾配p−Qも別に保存した。

相2は、最終LN特徴H上で自由headを共同最小二乗fitした旧ラベル平均の予測 `g2 = J_H^T[H(H^T H)^+]`。実CEの符号を使わずに計算し、係数のfitはしない。共通の正の係数を除くので、実測と絶対量の一致を主張しない。文脈共有共分散の予測P2ctxも記録した。

それぞれの勾配gを同じ排他的parameter群に分け、各群の独立JVPで

`S_r,a = dmu_a/s − mu*ds_a/s²`, `Δr = −η Σ_a S_r,a`

を計算した。以下はS>0が沈める側。表の「沈むseed」は全512unitのSの平均が正のseed数であり、沈むunit割合とは別である。SGDとAdam分母固定を比較する。後者は保存二次モーメントのbias補正済み分母を使い、momentum込みの実Adam更新ではない。

経路は共有token埋め込み、注意0＋前LN、FFN0前LN、up0、down0、注意1＋前LN、FFN1前LN、up1、その他後段。全parameterを重複なく被覆し、head共有重みの直接微分も含む。FFN upのbiasは存在しない。対象前活性より後段のparameterの直接JVPは0だが、それらを通って上流へ戻る誤差信号は残している。

課題100末のL1は実CE合計が3/10 seedで沈め、7/10で浮かせる。相2は5/10で沈め、合計平均の符号を2seedで外した（SGD seed0・4、Adam seed0・1）。Adam seed0はunitのBAが1でも、実CE平均−69.895に対し相2平均+83.681である。**unit符号の高い一致から合計平均の向きを推定してはいけない。** unit間の大きさの重み付けまで合計に影響する。

## 今回言えることと残ること

後期L0については、「上流が動く」という状態の記述から進んで、旧ラベル平均の相2式を全経路に戻すと、実CE合計の沈む向きと、注意0が主にそれを運ぶことが対応した。これは相2の方向説明を支持する保存状態の証拠である。自unit up行を動かす経路と、自己出力だけの誤差成分を混同していない。

ただし、実網は共有head・CEで、相2は自由head・LS・旧ラベル平均の模型である。相2平均の仮定が実網でなぜ成立するか、何がこの配置を形成したか、長期の実沈降をどれだけ生むかは、この方向対応だけでは確定しない。切替だけでなく課題の胴を説明したとも言えない。現課題fitのL0合計は課題100末・Adam固定で6/10 seedが沈める側、P2対fitのBAは.074–.563で、今回の切替モデルはこの向きを一律には説明しない。
