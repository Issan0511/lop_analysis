## 2. 3仮説の生死

- **H-cov（共通力は Cov(δ,x)）— 生存。本再解析で最も強く支持された。**
  v̂ との一致は条件B で \|cos\| = 0.99、条件A で 0.88。これは偶然一致ではありえない
  （床 0.17）。ただし仕様書 §4 が定義した **教師側の c_t = Cov(f_t(x), x) では説明できない**
  （\|cos\| = 0.37、しきい値 0.4 未満）。効いているのは**凍結学習器自身の**
  Cov(ŷ, x) を主成分とする残差共分散である（§4 に機構）。
- **H-Σ（µ⊥ 内の共通方向は Σ の最小固有ベクトル）— 死亡。**
  条件B は設計上 Σ = I なので検定不能、条件A では有意水準にまったく届かない
  （最小 p = 0.226）。それどころか centered 条件では v̂ が最小固有値部分空間を
  ほぼ完全に**避ける**（‖P_S v̂‖² = 0.000 に対し帰無期待値 0.750）。
  自律場 −(I−uuᵀ)[s(u)µ + p(u)Σu] の予測は的中していない。
- **H-sign（揃っているのは象限だけ）— 部分支持、単独では不十分。**
  符号だけを保存したヌルが A1 の **71–75%** を再現する。しかし残差は
  bootstrap CI で 0 と明確に分離しており（例: B c=0 で +0.169、CI [+0.167, +0.171]）、
  大きさレベルの整列も確かに存在する。「cos は符号の派生統計にすぎない」という
  強い主張は**成立しない**が、「cos の値の大半は符号構造で決まる」という弱い主張は成立する。

**総合すると、A1 整列の正体は「H-cov が作った 1 本の共通方向 E[δ·x] に、
全ニューロンの勾配が構造的に平行になっていること」であり、その cos 値の大半は
符号一致として現れている。** µ も Σ も主役ではない。

## 4. 機構（B2 から読み取れたこと）

`src/nets.py:44-52` の厳密な恒等式

> **E[g_{W_i}] = 2·v_i·E[δ·1[pre_i>0]·x]**

を再測定で数値的に確認した（相対誤差 1.5e-6、`measure.py`）。ゲート 1[pre_i>0] が
無ければ全ニューロンの期待勾配は **1 本のベクトル E[δ·x] の v_i 倍**に厳密に一致する。
つまり A1 整列は「学習で獲得された整列」ではなく、**アーキテクチャに内在する構造**であり、
1 から下がる分だけがゲートの非一様性で説明される。

さらにその E[δ·x] の中身は、条件B で

- \|cos(E[δ·x], Cov(ŷ,x))\| = 0.98–0.99（**凍結学習器自身の出力共分散**が主成分）
- \|cos(Cov(ŷ,x), c_teacher@ckpt)\| = 0.994–0.996（学習器は直前の教師に適合済み）
- ‖Cov(y,x)‖ / ‖Cov(ŷ,x)‖ = **0.16**（測定窓では教師が 50 回再サンプルされ、
  教師側の寄与は方向が平均化されて消える）

したがって「共通力」の正体は **凍結された学習器が直前に適合した教師の共分散構造**であり、
教師の瞬時 c_t ではない。period 間の c_t⊥ の pairwise \|cos\| が 0.18–0.55 と
低いこと（B2 図 `fig_b2_period_consistency_*.png`）もこれと整合する
— **c_t 自体は静的でないが、学習器に焼き付いた成分が静的な共通方向を作る。**

## 6. 注意・限界

1. **width=5 と最終 ckpt の条件A は alive ニューロンが枯渇している**
   （A_w5 @1e6 は中央値 1）。ペア統計が作れないため主判定はすべて **width=100**。
   条件B の K=100 も alive ≤ 2 で v̂ が構成できず、B3 で NaN になっている（データの限界であり不具合ではない）。
2. **経験 Σ の縮退判定は窓長に依存する。** K=100 の測定窓は M=5000 しかなく、
   Σ の固有値が Wishart 雑音で [0.88, 1.14] に散る（1±2√(d/M) と一致）。
   異方性ではないので、B3 は仕様書 §5-1 の指示どおり**解析値 Σ を主**にした
   （経験値は図に破線で併記）。
3. **中心化系列では µ̂ の取り方が結果を変える。** E[g] は `x_in = x_raw − running_mean`
   から作られるのに、npz の `mu_inter` は生入力 x_raw の平均である。
   B2/B3 では x_in 基準の µ に統一した（`measure.py` の `mu_in`）。
   B1 は仕様書の文面どおり `mu_inter` を使っている（両者は std 系列では同一）。
4. **B4 の置換ヌルの前提は完全には満たされていない。** \|w\| の座標間プロファイルは
   ユニット間で相関しており（mean \|corr\| = 0.33–0.72）、座標ごとの平均 \|w\| も
   一様でない（CV = 0.35–1.74）。したがって「絶対値は交換可能」という仮定は近似である。
   ただしこの相関は「大きさレベルの共有構造」そのものなので、検出された excess
   （27%）を弱める方向には働かない。
5. すべての cos について **signed と \|cos\| の両方**を JSON に保存してある
   （`*_signed_mean` / `*_abs_mean`）。本文の主統計は表中に明記した。
