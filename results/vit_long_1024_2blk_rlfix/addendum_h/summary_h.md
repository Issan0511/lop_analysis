# 追補 H の結果: 課題 60 の末の体から枝を切って学び直す（1109）

**結論。** 課題 60 の末の体は、head を 0 にして Adam を新しくしても、5,000 更新で 4/5 seed が課題 61 を覚えられない。block 1 の attention を定数（平均）に置き換えると 5/5 seed が覚え、新品の全体より 4/5 seed で速い（同じ枝を切った新品より 5/5 で速い）。遅れの担い手は block 1 の attention（またはそこを通る信号）で、残りの attn0・FFN0・FFN1 は容量不足ではなく、新品より良い初期値として働く。

箱と腕は spec の追補 H（H.2〜H.3）。S（LN なし・共有 head、追補 F の箱）の seed 5 本の model_t60 / model_t30 を、head 0・Adam 新品で次の課題に 5,000 更新。切除は forward hook で枝の出力を定数に置き換え（B60・B30 は切除前の網で取った token 位置ごとの平均、新品 F61・F31 は 0）、切った枝の重みは凍結。T90 は訓練精度 0.9 に届く更新（届かなければ 5,025）、A_end は最後の 500 更新の訓練精度の平均。判定の物差しは新品 none の 5 seed の SD（t60 側 s_T 144、t30 側 41）。判定表の全体は `judge_h.md`。

## 読み

1. t60 の学び直しの遅れは「残りの容量が課題を下回る」形ではない。切除なしの体はどの薄い新品よりも遅く（J H2 BELOW_ALL）、attention 1 を定数にした体は新品の全体より速い。残っている部分の容量は足りている。
2. 担い手は block 1 の attention を通る信号。FFN1 は担い手ではなく、切ると悪くなる（DEGRADES 5/5）。追補 F で「head と最終 FFN 側のどの介入でも救えない」と出た体の側の喪失は、attention 1 の側にあった。
3. t30 では attention 1 は無くても学べ（切ると速い）、t60 では学び直しを止める側に回る。t30 から t60 の間に attention 1 の役が変わる。
4. attention 1 の何が学び直しを止めるか（出力の大きさ、token 間の揃い、勾配の通り方）はこの追補では測っていない。読みはここまで。
