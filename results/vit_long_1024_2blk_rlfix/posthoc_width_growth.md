# 追補 D の事後解析：幅（fc1 の行ノルム）はいつ、どう伸びるか（2026-10-26、seed 10252010、1 seed）

問い（Issa）: head を共有した SL で、なぜ幅が伸びるのか。head を戻す R0L との違いは何か。

材料は保存した課題末の重み（`posthoc_2blk` の行ノルムの差分）と、保存状態（重み＋Adam）から課題 11・61・101 を 5,000 更新回し直して更新ごとに測った量（`analysis/vit_long_1024/posthoc_2blk/body_replay.py`、生の出力は `~/Projects/obsidian-research-data/vit_long_1024_2blk_rlfix/posthoc_body/`、図は `body_replay_L1.png`・`body_replay_L2.png`、表は `body_replay_table.md`）。LN が FFN の入力のノルムを固定するので、前活性の幅は fc1 の行ノルム ‖w_j‖ に比例する。

- **当てはめた後の歩幅は、どちらの腕でもほぼ 0 である。** 2,001 更新以降は coh 0.002〜0.03、歩幅 ≤ 0.001 lr²d。Adam の分母 v̂ は約 1,000 更新前の大きな勾配を覚えているので、損失が 1e−4 まで落ちると 1 歩は lr の 1〜3% に縮む。「Adam は歩幅が一定」はこの箱の当てはめ後には成り立たない。
- **伸びは、切替の直後（1〜100 更新）と当てはめの最中に入る。** 最初の 100 更新は、R0L では head の学び直し（体への勾配は 2 歩目から）、SL では切替の押しで、1 歩が lr の 0.4〜1.3 倍と大きく、向きがそろっている。そろった歩が続くので、変位はその和（‖Σ Δw‖²）になり、1 歩ごとの二乗和の数十倍になる。課題末の差分で「w と直交な足し算」と見えたのは、この 1 本の変位が課題の始めの w と直交だからである。
- **SL が R0L より伸びるのは、当てはめの尾が長いからである。** R0L は 500 更新までに損失が 1e−2 を切り、以後は動かない。SL は課題 61・101 で 501〜2,000 更新のあいだ損失が 0.25〜0.5 に居座り、coh 0.13〜0.18・歩幅 0.03〜0.04 lr²d の、そろった歩が 1,500 更新続く。R0L の同じ窓（0.003・0.000）の 40〜100 倍である。
- 2 層目の勾配には、当てはめ後に w を伸ばす向きの成分が残る（rad_g = Σ g·ŵ ÷ Σ‖g‖ が SL 課題 11 で −0.028、61 で −0.006、101 で −0.002。負は勾配降下が ‖w‖ を増やす向き）。歩幅のうち w 方向の割合 frac_d は 0.37 → 0.28 → 0.06 と課題を重ねて減る。歩幅そのものがほぼ 0 なので、この分の伸びは 1 課題あたり ‖w‖² の 0.2〜0.7% にとどまる。1 層目にはこの成分は無い。

## 3. 答え

1. **幅は「当てはめ後の拡散」では伸びない。** 伸びは、切替直後の大きくそろった歩（R0L は head の学び直し、SL は切替の押し）と、当てはめの最中のそろった歩の、課題ごとの変位の二乗が足し上がったものである。変位は課題の始めの w とほぼ直交なので、‖w‖² は課題ごとに ‖δ‖² ずつ増える。
2. **R0L では毎課題の変位がほぼ同じ大きさ**（損失が 500 更新で 1e−2 を切る）なので、‖w‖² は累積更新に線形に伸びる（lr²d の 0.8 倍/更新）。
3. **SL では、当てはめが遅いほど変位が大きくなる。** 課題 60 以降、損失が 0.25〜0.5 のまま 1,500 更新続き、その間のそろった歩が R0L の 40〜100 倍の変位を作る。1 課題の伸びは 0.016 → 0.053 になり、加速する。
4. 当てはめ後に残る w 向きの成分は SL にだけあるが、小さい（1 課題で ‖w‖² の 1% 未満）。

**残る問い**: SL の当てはめが遅くなる理由そのものは、ここでは決まらない。遅い当てはめ → 大きな変位 → 幅の伸び、という向きは測れたが、幅の伸びが当てはめを遅くするか（輪が閉じるか）は、この測定では分からない。R0L は ‖w‖² が 10 倍になっても速くなり続けるので、幅の伸びだけでは当てはめは遅くならない。

## 4. 訂正

同日の途中の報告で「R0L の 1 課題の伸びの 25% は当てはめ後の拡散」と書いたが、課題末と 100 更新目の差分を更新数で割った値を歩幅と取り違えていた。回し直しで測った当てはめ後の歩幅は 0 に近く、伸びは当てはめの最中に入る。
