# MLP の共有 head の解き直しの費用（ch_chb_200_0919 の課題末 snapshot からの回し直し、1029）

Fable、2026-10-29。Issa「MLP の CHB が生きてたのを見ると MLP では起こってなかったのかな」への答え。ViT（LN あり・共有 head）で見つかった「学び直しの遅れは全部 head の装填費用」が、MLP の箱（RC/raw/ReLU、3072-100-100-10、1,200 枚、Adam 1e-3、30,000 更新/課題、200 課題、seed 0〜9）でも起きているかを、`ch_chb_200_0919` の課題末 snapshot（W・b・door H の EMA）から次の課題の最初の 3,000 更新を回し直して測った。script は `analysis/vit_long_1024/posthoc_2blk/mlp_unload_1029.py`、生データは `~/Projects/obsidian-research-data/vit_long_1024_2blk_rlfix/posthoc_mlp_unload/`（mlp_unload.json・run.log）。

## 答え

解き直しの費用は MLP にもある。CHB でも CH でも、共有 head の T90 は head を 0 に戻した回し直しより 200〜850 更新長く、10 seed すべてで正である。損失が一様（ln 10）まで戻るのに 420〜730 更新かかる（戻す腕は 20〜70）。
ただし 1 課題は 30,000 更新なので、この費用は 1〜3% で、online 精度（CHB 99.0%）には見えない。「MLP では起きていなかった」のではなく「起きていたが評価の窓に入らなかった」。
私の前の見積もり「数十更新」は外れで、数百更新である。head の 1 歩の logit の歩幅 η Σ|a2| は 0.4〜2.8 と大きいのに、解き直しはそれより 1〜2 桁遅い。sign 歩の上界では解き直しの速さは当たらない。
費用は課題とともに伸びない。CHB の L0（旧 head の自信）は 22〜33 でほぼ一定で、‖W3‖ が 3 → 11 に伸びる間に特徴のノルム Σ|a2| が 2,800 → 790 に縮むので、積が変わらない。LN が ‖h‖ を固定して自信が ‖W‖ とともに伸びる ViT とは、ここが違う。
体は課題をまたいで速くなる（head を戻した T90 920 → 570）。これは ViT の R0L（新品の 7.7 倍速い）と同じ向き。

## 方法

- 課題 t の末の snapshot（`{arm}_raw_seed{s}/t{t}.npz`: W1 b1 W2 b2 W3 b3 と EMA m1 m2）から課題 t+1 を回す。ラベルと batch の順は本走と同じ生成器（`H.stream('rlc_labels', s)` を t+1 回、`'rlc_batch'` を t×400 回進める）。
- 腕: 共有（snapshot のまま）と戻す（W3・b3 を 0）。door C・H・B は本走どおり（CHB は b1 を毎更新 0、b2 を (1−ηλ) 倍、λ 0.1713）。
- Adam のモーメントは snapshot に無いので 0 から始める（bias 補正つき）。t200 の ckpt.pt（実モーメント付き）で t201 を回して近似の差を見た（下）。
- 量: 全 1,200 枚で 10 更新ごとに損失と精度。L0 = 更新 0 の損失、n_chance = 損失 ≤ ln 10 の最初の更新、T50・T90 = 精度 ≥ 0.5・0.9 の最初の更新（上限 3,000、未到達は 3,010）。10 seed の中央値。

## ViT との対応

| | MLP CHB（この測定） | ViT SL（LN あり・共有 head） |
| --- | --- | --- |
| 旧 head の自信 L0 | 22〜33、課題で一定 | 11 → 20、‖W‖ とともに伸びる |
| 解き直しの費用（T90 の差） | 200〜850 更新、課題で縮む | 約 550 更新、課題で伸びる |
| 1 課題の長さに対する割合 | 1〜3%（30,000 更新） | 100%（新品の T90 と同じ） |
| 体の速さ | 課題をまたいで速くなる（920 → 570） | 早期は新品の 2.6 倍速く、後期は新品並み |

費用が課題とともに伸びるかは、特徴の尺度が固定されるかで決まる。LN は ‖h‖ を固定するので自信 ∝ ‖W‖ で伸び、MLP は ‖W3‖ が伸びると特徴が縮んで積が一定になる。
本稿への含意: 装填費用は共有 head の普遍的な費用で、Transformer の性質ではない。見えるかどうかは、課題の長さと評価の窓（online 精度の平均か、T90 か）と、尺度の固定の有無で決まる。

## 限界

- 1 課題の回し直しは eager で Adam のモーメントを 0 から始める近似（上の表のとおり約 2 倍の過大評価）。
- 10 seed・2 腕・10 課題末。T90 の上限 3,000 更新。
- η Σ|a2| は head の 1 歩の logit の歩幅の上界で、解き直しの速さの予測には使えない（1〜2 桁外れる）。
