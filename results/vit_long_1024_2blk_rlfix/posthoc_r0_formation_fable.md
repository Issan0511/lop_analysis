# R0 の patch 側の尺度の形成則（LN なし・head を毎課題 0 に戻す腕、依頼 4 の A）

Fable エージェント A、2026-10-28〜29。箱は vit_long_1024 追補 D（2 ブロック ViT、rlfix、seed 10252010）。依頼書は `analysis/vit_long_1024/posthoc_2blk/fable_r0_1028_brief.md`。生データと表は `~/Projects/obsidian-research-data/vit_long_1024_2blk_rlfix/posthoc_r0_form/`。

## 答え

R0 の patch 側の尺度の形成は三つの段に分かれる。
第 1 段（課題 1〜27）は当てはめ後の穏やかな漂いで、全画像が当たった後に損失が尺度を上げる側に押す（符号は導出、課題 1→2 で +0.29 のうち +0.23 が当てはめ後）。
第 2 段（課題 28〜40）は崩れの跳ね上がりで、課題の中で暗記率が崩れる窓で尺度が跳び、穏やかな窓では育たない（課題 30→31 の +0.97 のうち +0.66 が 16 の崩れ窓）。
崩れは head と体の結合した当てはめの不安定（依頼 3 の T90 崩れの機構）で、本走では課題 28 から崩れ窓が 0〜5 個から 15〜38 個に跳び、共通成分 m2 の課題あたりの log 増分が +0.5 に跳ぶ。形成と T90 の崩れは別の過程ではなく同じ輪である。
第 3 段（課題 40 以降）は釣り合いで、崩れで育ち穏やかな窓と成功した課題で縮む。
崩れ窓の押しは m2 に沿った半径方向で、損失の尺度微分 ∂L/∂α の符号とは独立であり、前の課題から残る Adam の v の下で崩れ時の歩が η を超えることが成長を運ぶ（v を消すと同じ数の崩れで成長が消える。崩れの大きな歩は R0 では FFN0 を開いて育て、S では閉じて縮める）。
切替相は主因ではない。R0 の切替では体の勾配が厳密に 0 で体は Adam の残りだけで動き、S の切替では装填の押しが head 特徴を 25 更新で 1/3 に縮め最終 FFN の死を 0.50 から 0.86 にするが、patch 側の尺度は跳ねて戻る。
R0 と S の差は切替相の縮みではなく崩れの有無で、S は崩れ窓が 0〜5 個のままで崩れでは縮み、装填の押しは切替相の体の動きを通して当てはめ相の縮みとして遅れて効く（体を 200 更新止めると S の 1 課題は −0.36 から −0.04 に、R0 は +0.97 から +1.18 になる）。
成長の担い手は FFN0 の開いた値の大きさ（‖ā‖ 63 倍）で、重みのノルム（1.2 倍）や利得（1.8 倍）ではなく、課題 10〜40 の増分は向きを保って積む。
閉じて導けたのは尺度微分の符号・切替での体の勾配と Adam の残り・v の遅れ・増分の半径と直交の分解までで、崩れの間の押しが R0 で m2 に沿って正になり S で負になる理由は未導出である（崩れで予測が偏って共通の押しが生じるという仮説は、同じ軌跡の記録で外れた）。

## 1. 方法

- 回し直し: 保存状態（model_tK + adam_tK）から次の課題を eager で 5,000 更新。batch 列・ラベル・損失の 10 クラスは本走と同じ。R0 は head を 0 に戻し head の Adam のモーメントは本走どおり残す。script は `fable_r0form_replay.py`。
- 記録: 25 更新ごと（列 1 の 3 走目以降は切替直後の 1,2,3,5,10,15,20 も）に固定 probe（val 64 枚）で各段の patch rms・CLS rms（token ベクトルのノルムの二乗平均の平方根、依頼 3 と同じ定義）、m2、FFN0 の平均 patch 出力、最終 FFN の死、head のノルム、訓練 2,500 枚の暗記率。50 更新ごとに FFN0 の patch 出力の倍率 α の ∂L/∂α を forward-mode の JVP で画像ごとに出し、当たり・外れで分けた。最初の 200 更新は毎更新、体の 1 歩のノルムと勾配のノルム。
- 相の切り方: 切替相 = 暗記率が初めて 0.2 以上になる記録まで、当てはめ相 = T90 まで、当てはめ後 = 残り。窓の種類: 崩れ窓 = 50 更新で暗記率が 0.1 以上落ちた窓、上昇窓 = 0.1 以上上がった窓、平ら = それ以外。
- 保存状態の一貫性（A-4）: `fable_r0form_coherence.py`。本走の課題ごとの記録（per_task.csv・layer_stats.csv・intask.npz）: `fable_r0form_mainrun.py`。増分の半径・直交の分解: `fable_r0form_windows.py`。表: `fable_r0form_summary.py`。
- 回し直しは eager で、本走（compile）と軌跡は一致しない。batch の分け方だけで T90 が 75 動く。1 seed。

## 3. A-2 切替相

### 3.1 R0: 体の勾配は厳密に 0、体は Adam の残りで動く

head を 0 に戻した直後の 1 更新目は、logit が全画像で 0 なので体の勾配が厳密に 0 である（実測 0）。
体はそれでも動く。Adam の 1 歩は −η m̂/(√v̂ + ε) で、勾配 0 のあいだ m は β1 = 0.9 倍、v は β2 = 0.999 倍に減るだけなので、歩幅は 0.9005 倍ずつ減りながら前の課題の押しをそのまま続ける（実測 R0 30→31: 0.080, 0.072, 0.065, 0.058, 0.053 と 0.9 倍ずつ）。
残りの大きさは前の課題の終わり方で決まる。

| 保存状態 | 前の課題の末 | median \|m\| | median √v | 残りの 1 歩 / η（rms） | \|歩/η\| > 0.5 の座標 |
|---|---|---|---|---|---|
| R0 t10 | 収束（損失 1e-4） | 3.4e-8 | 1.2e-4 | 0.001 | 0.000 |
| R0 t30 | 未当てはめ（暗記率 0.48） | 6.6e-4 | 4.6e-3 | 0.36 | 0.14 |
| R0 t60 | 未当てはめ（0.46） | 9.6e-5 | 1.7e-2 | 0.06 | 0.002 |
| S t10 | 収束 | 8.8e-10 | 5.0e-5 | 0.008 | 0.000 |
| S t30 | 収束 | 1.8e-19 | 3.7e-4 | 0.010 | 0.000 |

収束した課題の後はもう一つの効果がある。v が小さいので、新しい小さな勾配が最初から全幅の歩になる。
状態を 0 から始めた Adam の最初の歩は η(1−β1)/√(1−β2) = 3.16η で、通常の歩 η の 3 倍である。
R0 10→11 では head が 1 更新で育った直後の 2〜10 更新目に体の 1 歩が 0.0003 から 0.23（全座標が η 動くときの 0.25 に近い）に跳ね、S 10→11 では 1 更新目から 0.50（3.16η × 0.25 × 0.65）である。
この全幅の歩で R0 10→11 の最初の 25 更新に m2 が +0.23、注意 1 の出力が +0.5、最終 FFN の死が 0.06 → 0.80（その後 0.08 まで戻る）と過渡が出る。
ただしこの過渡は patch 側の尺度を課題をまたいで積まない（課題 10→11 の正味 +0.15、S と同じ）。

### 3.2 S: 装填の押しは head 特徴を縮め最終 FFN を殺すが、patch 側は縮まない

S の切替時の ∂L/∂α_h（head 特徴の倍率）は +32.6（10→11）、+21.3（30→31）で、尺度を上げると損失が上がる側である。
LN なしでは半径成分がそのまま残るので、head 特徴（最終 FFN 後の CLS）は 25 更新で 65 → 25（10→11、log −0.97）、200 更新で 110 → 67（30→31、−0.50）に縮む。
同時に最終 FFN の死は 0.50 → 0.86（10→11）、0.91 → 0.95（30→31）に増える。これが「装填の押しが最終 FFN を沈める」の切替相の姿である。
patch 側（FFN0 出力）の ∂L/∂α は切替時 +2.7（10→11）、−0.009（30→31）で、尺度は縮まず、むしろ 15〜25 更新目に +0.10（10→11）・+0.28（30→31）・+0.32（60→61）跳ねて 100〜250 更新で戻る。
最初の切替（1→2）だけは patch 側も縮む（最初の 25 更新で −0.42、切替相 300 更新で −0.38）。head 特徴は 300 更新で 247 → 16（−2.8）に落ち、網が若いうちは半径の縮みが patch 側まで届く。
予測 A1 の「S の切替相で FFN0 出力と CLS が縮む」は、CLS（head 特徴）は当たり、FFN0 出力は課題 1 だけ当たりで課題 10 以降は外れである。

### 3.3 反実仮想: 最初の 200 更新は体を止める

切替相の体の動きを除いて（最初の 200 更新は体の lr を 0 にして head だけ動かす）、1 課題の成長が変わるかを見た。

| R0 30→31 keep | −0.00 | 2,300 | 0.56 | 16 | +0.041 | +0.97 | +0.77 |

R0 では切替相の体の動きを消しても成長は消えず、むしろ大きい。成長の源が切替相に無いことは、帳簿だけでなく反実仮想でも支持される。
S では逆に、切替相の体の動きを消すと当てはめ相の縮み（keep で −0.32）が消えて +0.02 になり、1 課題の正味が −0.36 から −0.04 に変わる。
S の切替の跳ねは体を解放した直後にも出る（+0.16）ので跳ね自体は head の学び直しに伴う体の最初の歩で、当てはめ相の縮みは切替相の体の動き（装填の押しを受けた最終 FFN の死と head 特徴の縮み）の後に遅れて現れる。
つまり S の 1 課題の正味を押し下げるのは装填の押しだが、その効き方は切替相の直接の縮みではなく当てはめ相の漂いである。1 軌跡ずつの比較なので大きさは参考値である。

R0 30→31 で、体の Adam の状態を変えて回し直した。zero_m は m だけ 0（v は前の課題のまま）、zero_mv は m・v・step も 0（体だけ新品の Adam）。

前の課題の v は大きい（R0 t30 の median √v は 4.6e-3 で、収束した課題の 40 倍）。v の記憶は 1,000 更新、m は 10 更新なので、崩れで勾配が急に大きくなると m は先に追いつき v は遅れ、1 歩が η を超える。
古い v のもとでの崩れ時の大きな歩が成長を運ぶ、という読みがこの差に合う。これは 1 seed・1 課題の軌跡の比較で、軌跡自体が分かれている（T90 2,300・1,450・1,025）ことに注意する。
同じ keep の軌跡で窓ごとの体の歩幅を記録し直すと（§8 の表）、崩れ窓の体の歩幅の和は平らな窓の 1.6 倍で、m2 の増分と Spearman +0.24（p 0.02）である。

## 5. A-4 課題をまたぐ一貫性

直交する増分（乱歩）なら C = 1、同じ向きに積むなら C = 区間数、行って戻るなら C < 1。増分の大きさが偏ると C は最大の増分に支配されるので、半径成分の cos と始点・終点の cos を併記する。

## 6. A-5 力の符号

∂L/∂α = E[(p−y)ᵀ W ∂h/∂α] は恒等式で、当たっている画像では負（尺度を上げると損失が下がる）、外れている画像では正になりやすい（依頼 3 の導出）。実測もそのとおりで、当てはめ相の当たり画像の平均は −0.3〜−0.4、外れ画像は +0.4〜+0.7 である。
しかし成長は符号に従わない。

## 8. A-7 どこまで式で言えるか

導出できる段:

1. ∂L/∂α の符号の恒等式（当たり画像で負・外れ画像で正になりやすい）。実測と一致し、崩れの無い早い課題では当てはめ後の穏やかな漂いの向きと大きさの順序を決める（第 1 段）。崩れがある課題では成長を決めていない。
2. R0 の切替で体の勾配は厳密に 0。体の動きは Adam の残りで、歩幅は (β1/√β2)^t = 0.9005^t で減る。残りの大きさは前の課題の終わり方で決まる（表 3.1）。
3. 収束した課題の後は v が小さく、新しい勾配に対する最初の歩が通常の 3.16 倍 = (1−β1)/√(1−β2) 倍まで大きくなる。R0・S の切替直後の過渡（m2 の跳ね、最終 FFN の一時的な死）はこれで起きるが、課題をまたいで積まない。
4. S の切替の半径成分: ∂L/∂α_h > 0 なので、LN なしでは降下が head 特徴を縮める。実測 −0.97（25 更新）。
5. ‖a + Δa‖² − ‖a‖² = 2⟨a, Δa⟩ + ‖Δa‖² の分解。R0 の崩れ窓の m2 は半径項 +3.1、直交項 +2.0 で、向きを持つ押しが主で直交の足し算は従。
6. Adam の v の遅れ。m の記憶は 1/(1−β1) = 10 更新、v は 1/(1−β2) = 1,000 更新なので、崩れで勾配が急に大きくなると 1 歩 η m̂/√v̂ は η を超える（上限は (1−β1)/√(1−β2) = 3.16 倍）。前の課題の v が残っている keep 走は崩れ 1 つで +0.041 育ち、v を 0 から作り直した走は同じ数の崩れで +0.009 しか育たない（§4）。

導けない段（測った事実）:

7. 崩れ窓で R0 の m2 と FFN0 出力が m2 に沿って育ち、S では縮む理由。
8. 1 課題の正味の成長 = 崩れ窓の数 × 崩れ 1 つの増分（R0 で +0.04〜+0.09）− 穏やかな窓の漂い（−0.005/50 更新）。崩れの数が尺度とともに増える（本走で課題 28 から）ので正の帰還になり、課題 40 以降は失敗と成功の釣り合いで止まる。これは帳簿で、崩れ 1 つの増分の式は無い。

検証して外れた仮説:

9. 「崩れでは予測が少数のクラスに集中し Σ_i(p_i − y_i) ≠ 0 になるので、head 特徴への勾配の和 Σ Wᵀ(p−y) が画像に依らない共通の押しになり、R0 では m2 の向きに育てる」。R0 30→31 を同じ軌跡で記録し直す（_pbar 走、T90・暗記率・尺度が keep と一致）と、崩れ窓の予測の最大割合は 0.13（平らな窓 0.13）で集中せず、‖p̄−ȳ‖ は 0.038（平ら 0.042）、共通の押しのノルムは 0.003、m2 との cos は −0.01 である。共通の押しは無く、外れ。

崩れ窓で違うのは体の歩幅である。
