# 大きく育ったpeak Snake個体の行き先（追加事後集計 0914）

SN_peak_q0、10seed×100unit、task500終点。群分けは最終結果を見た事後記述。自由重み=変動する5入力方向。元の動画ではない。

初期より自由重みが育った292/1000個の終点平均前活性は−4.035〜+3.599。266/292個では32入力の前活性の範囲が0をまたぐ。群の自由重み二乗和は全体の99.9703%（seed内比率のseed平均）。これは性能寄与率ではない。

各seedの最終自由重みノルム上位10個を固定して追跡（計100個）:
- 自由重みノルム平均: task0 .8210 → task20 1.6960 → task100 2.1015 → task500 2.6161。
- 前活性標準偏差平均: .4105 → .8480 → 1.0508 → 1.3081。CondAの独立一様5bit入力ではsigma=自由重みノルム/2。
- 終点で93/100個は入力によって正負両側に前活性を持つ。
- 終点平均前活性が±.1にいる個体も10/100個。平均の中心化と幅の収縮を同一視しない。
- 終点平均abs(v)=.3246、初期.0831。vが残ることだけから機能的重要性や原因は判定しない。
- 上位10個の終点自由重み二乗和の占有率は平均51.93%。

最大の個体（seed1/unit19）: 自由重み.76845→3.73551（4.861倍）。task500で平均前活性−1.07430、標準偏差1.86775、32入力の最小−4.95814・最大+2.80954、v=−.43168。

結論: 大きく育った群は、集団として負側へ一方向に飛んだ群ではなく、正負に広い前活性を持つ群として残る。平均が中心の近くにあっても、幅を広げている個体がある。縮小群との分岐原因は未同定。

入力SHAは親ディレクトリverification.jsonのSN_peak_q0各seedを参照。groups.csvはseed内集計、units.csvはID付き終点。標本ごとの前活性範囲は平均±sum(abs(u))/2で厳密に計算。有限の全32入力支持集合の範囲であり、時間を通した同じ入力の軌道を意味しない。
