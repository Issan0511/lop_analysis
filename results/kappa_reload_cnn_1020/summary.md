## 0. 一行

RL-CIFAR CNN（leaky 0.1）の最終隠れ層 f2 でも、課題末の読み出しは毎課題、現課題のラベル構造 F に整列し直す（κ_k/κ₁ は 1.4〜7.0 で 10/10 seed、帰無分位点 1.000、補題の破れ 0/484）[実測]。f2 の自分の重みを通る期待の押しは全境界で 99〜100% の unit で沈める側、実際の 200 更新で 84〜100% が沈み、初期化の押しは切替の 1e−4 倍 [実測]。MLP と違うのは三つ。(i) f2 の一次応答の大きさは上流の重みが運ぶ分が 97〜100% を占める。(ii) 30,000 更新の課題の中で切替の沈みは t10 以降ほぼ全部戻り、f2 の集団は r ≈ −0.6 で止まる（f1・c2・c1 は沈み続ける）。(iii) 適応 Snake の 4 腕では κ 比の予測は外れ（特徴の尺度が膨らみ κ が縮む）、fc のゲートが鋭い 2 腕（c = 3）では f2 に沈める押しが無い。

## 1. 箱と定義（spec §2〜3）

- 網: conv 3→16 → φ → pool → conv 16→16 → φ → pool → fc 1024→100 → φ → fc 100→100 → φ → head 100→10。1,200 枚、課題ごとに一様乱数ラベル、batch 16、30,000 更新/課題、Adam 1e−3。最終隠れ層 f2 = fc 100→100 の出力 a4、読み出し = head。
- 腕と状態: LR（leaky 0.1、seed 10〜19、t ∈ {1,2,3,5,10,20,30}）、適応 Snake 4 腕 SNA（c = 0.6 全層）・SNAc3（c = 3 全層）・CV06FC3（conv 0.6・fc 3）・CV3FC06（conv 3・fc 0.6）（seed 10〜19、t ∈ {1,2,3,5,10,20,30,40,50}）、R（ReLU、seed 10、t ∈ {1,2,3}、課題 3 で死ぬ参照）。計 433 状態 ＋ 初期値 51 状態。
- 定義は MLP（`analysis/kappa_reload_1020/measure.py`）のまま: x = f1 の出力、K_n = x̄·x_n + 1、m_i = mean_n z4_in、g = φ′(z4)、v^c = head をクラスで中心化、F = Σ_n (y_n − 1/K) ⊗ a4_n（旧ラベル）、**κ = ⟨v^c, F⟩/‖F‖²**（v^c の F 方向への原点を通る最小二乗射影係数）、S_exact_i = Σ_n K_n g_in ⟨v_i^c, π_n⟩（自分の重みを通る期待の押し）、S_self = κ(1 − 1/K)Σ K_n g φ（自己形）。CNN で足した量: **G_own = S_exact/N**（自分の重みの一次応答）、**G_full**（α を固定した全パラメータの一次応答、JVP）、**G_up = G_full − G_own**（上流の重みが x̄ を動かす分、ブロック内積から独立に算出）。生きた unit = 正側の入力が 1 つ以上。
- κ は尺度の非不変量（F を a 倍・head を 1/a 倍で 1/a² 倍）なので、射影ノルム Q = κ‖F‖ と射影割合 cos² = ⟨v^c,F⟩²/(‖v^c‖²‖F‖²) を常に並べる（Astra の指摘）。

## 5. 言える／言えない

**言える** [実測・恒等式]
1. 課題末の head は毎課題、現課題の F に整列し直す（LR: κ 比 1.4〜7.0・cos² 0.63〜0.75、Snake: cos² 0.5〜0.9、全腕で帰無分位点 1.000）。補題 κ ≥ [N(log K − L) − B]/‖F‖² は 484 状態で破れ 0 で、線形 head と CE だけから成り立つ。
2. LR の f2 では、自分の重みを通る期待の押しは全境界で 99〜100% の unit で沈める側、実際の最初の 1 歩で 80〜95%、200 更新で 84〜100% が沈む。初期化の押しは切替の 1e−4 倍。
3. 自分の重みを通る押しの向きは、own 方向の感度の旧ラベルへの整列 κ_R の符号と恒等的に一致し（学習後は ε ≈ 0）、f2 ではほぼ全部正、c1 では多くが負。
4. f2 の位置の一次応答の大きさは上流の重みが x̄ を動かす分が 97〜100% を占める（固定状態の帳簿）。
5. 30,000 更新の課題の中で、f2 の切替の沈みは t10 以降 100〜125% 戻り、f2 の集団は r ≈ −0.6 で止まる。f1・c2・c1 は沈み続ける。
6. f2 の unit は境界ごとに p⁺ < 1/2 と ≥ 1/2 を行き来する（LR で 1,000 中 653）。
7. fc のゲートが鋭い Snake（c = 3）では f2 に沈める押しが無く、f2 は沈まない。

**言えない**
- 押しが沈める側に揃う「原因」が学んだ整列であること（head を替えた参照は固定状態の比較で、学習の履歴の因果ではない）。
- f2 の集団が r ≈ −0.6 で止まる機構（当てはめに要る活性の床か、上流の沈降との釣り合いか）。課題あたりの更新数（4,000 対 30,000）が戻りの差の原因かどうか（箱が二つ違う）。
- 上流項 G_up の符号が沈める側に出る理由（Astra の導出ノート §5: 先験的には定まらない）。
- Snake の κ 比が落ちることと可塑性の喪失の関係（SNAc3・CV06FC3 は幅の暴走で知られた腕で、押しの向きが無いことと尺度の膨張は同じ状態の記述）。
- 実ラベルの CNN（5+1）で同じ装填が起きるか（一様ラベルの期待が使えないので対象外）。

## 6. V13 の部品の表「CNN × 装填」の欄（提案）[提案]

> **理論の格**（MLP から持ち込める部分）: κ の下界は線形 head ＋ CE の恒等式と Jensen で、構造によらない。自分の重みを通る押し G_own = (1 − 1/K)κ_R + ε は恒等式。
> **CNN の実測**（RL-CIFAR、leaky）: head は毎課題、現課題の F に整列し直す（κ 比 1.4〜7、cos² 0.63〜0.75、帰無分位点 1.000、補題の破れ 0/484）。最終隠れ層の自分の重みを通る期待の押しは全境界で 99〜100% が沈める側、実際の 200 更新で 84〜100% が沈む。初期化の押しは切替の 1e−4 倍。ただし一次応答の大きさは上流項が 97〜100%、切替の沈みは 30,000 更新の課題の中で t10 以降戻り切り、最終隠れ層の集団は r ≈ −0.6 で止まる（f1・conv は沈み続ける）。unit 単位の戻りは多い（1,000 中 653）。適応 Snake は fc のゲートが緩い腕で t1〜t3 だけ同じ印、鋭い腕（c = 3）では押しに向きが無い。
> **介入**: 未（head を替えた固定状態の参照のみ: 乱数 head では沈める側 0.63〜0.65）。

H1 の文言への含意 [提案]: 「読み出し κ > 0 が切替ごとに押しを装填する」は CNN の最終隠れ層でも実測で立つが、「沈み続ける」の担い手は最終隠れ層ではなく上流（f1・conv）で、最終隠れ層は切替で深く沈んで課題の中で戻る。V13 の「Keep」は層で分けて書く。

## 7. 提案（回していない）

- **(h) ダイヤル**（spec §4 (h)）: LR の課題 1 の精度 20/50/80/95% の checkpoint が無いので、課題 1 を 1〜2 seed 回し直して checkpoint を取り、5 通りの新ラベルへ 200 更新。新しい GPU の走（1 seed で約 5 分 ＋ 5 × 200 更新）。Issa の了承で回す。
