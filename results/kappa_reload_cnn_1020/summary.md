## 0. 一行

RL-CIFAR CNN（leaky 0.1）の最終隠れ層 f2 でも、観測した保存境界で読み出しは現課題のラベル構造 F に整列し直していた（κ_k/κ₁ は 1.4〜7.0 で 10/10 seed、クラス置換の帰無分位点 1.000、補題の破れ 0/484）[実測]。f2 の自分の重みを通る期待の押しは全境界で正符号（沈める側）が 99〜100% を占め、再生した 200 更新で 84〜100% が沈んだ [実測]。MLP と違う点は三つ [実測]。(i) f2 の位置の一次応答のうち、上流の重みのブロックの絶対値分担が 97〜100% を占める。(ii) 課題の中で切替の沈みの合計は t10 以降 1 倍以上戻り、元の位置まで戻る unit は半数から 6 割で、保存境界の f2 の集団中央値は t10・t20・t30 で約 −0.6 だった（f1・c2・c1 の中央値は下がり続ける）。(iii) 適応 Snake 4 腕では κ 比の登録基準を満たさず（特徴の尺度 ‖F‖ の増大と射影ノルム Q の変化が併存）、fc のゲートが鋭い 2 腕（c = 3）では f2 の押しに LR のような正符号優勢が無かった。

## 1. 箱と定義（spec §2〜3）

- 網: conv 3→16 → φ → pool → conv 16→16 → φ → pool → fc 1024→100 → φ → fc 100→100 → φ → head 100→10。1,200 枚、課題ごとに一様乱数ラベル、batch 16、30,000 更新/課題、Adam 1e−3。最終隠れ層 f2 = fc 100→100 の出力 a4、読み出し = head。
- 腕と状態: LR（leaky 0.1、seed 10〜19、t ∈ {1,2,3,5,10,20,30}）、適応 Snake 4 腕 SNA（c = 0.6 全層）・SNAc3（c = 3 全層）・CV06FC3（conv 0.6・fc 3）・CV3FC06（conv 3・fc 0.6）（seed 10〜19、t ∈ {1,2,3,5,10,20,30,40,50}）、R（ReLU、seed 10、t ∈ {1,2,3}、課題 3 で死ぬ参照）。計 433 状態 ＋ 初期値 51 状態。
- 言葉: 位置 m は画像間で平均した前活性。幅 s は画像間の標準偏差（母標準偏差）。r = m/s は幅で測った位置。p⁺ は前活性が正の入力の割合。生きた unit は正側の入力が 1 つ以上ある unit。
- 定義は MLP（`analysis/kappa_reload_1020/measure.py`）のまま: x = f1 の出力、明るさ K_n = x̄·x_n + 1、傾き g = φ′(z4)、v^c = head をクラスで中心化したもの、F = Σ_n (y_n − 1/K) ⊗ a4_n（y は旧ラベル）、**κ = ⟨v^c, F⟩/‖F‖²**（v^c の F 方向への原点を通る最小二乗射影係数）、S_exact_i = Σ_n K_n g_in ⟨v_i^c, π_n⟩（自分の重みを通る期待の押し）、S_self = κ(1 − 1/K)Σ K_n g φ（自己形）。
- CNN で足した量: **G_own = S_exact/N**（自分の重み W4[i]・b4[i] だけの一次応答）、**G_full**（checkpoint の α を固定した全パラメータの Euclid 計量による一次応答、JVP）、**G_up**（上流の重み・bias のブロックの応答、ブロック内積から独立に算出。G_full = G_own + G_up [恒等式]）。
- κ は尺度の非不変量（F を a 倍・head を 1/a 倍にすると 1/a² 倍）なので、射影ノルム Q = κ‖F‖ と、中心化 head の二乗ノルムに対する射影の割合 cos² = ⟨v^c,F⟩²/(‖v^c‖²‖F‖²) を κ と並べる（Astra の計算前批評）。Q 比と cos² を P1 の代替として読むのは事後の補助評価で、登録した κ 比の判定を変えない。

- **head を替えた参照（T3c、事後）**: 特徴を固定して head の中心化行をクラス置換すると S_exact は厳密に不変（b5 がクラス一様なら π′ = Ππ の対称性）で、対照にならない [恒等式]。固定した特徴の下で学習済みノルムの乱数 head に替えると f2 の正符号割合は 0.63〜0.65（平均の自信 0.85）、初期化尺度の乱数 head で 0.63〜0.65（自信 0.62〜0.69）、実際の head で 0.99〜1.00 [実測]。この比較では整列だけでなく予測の確信度も変わる。

## 5. 言える／言えない

**言える** [実測・恒等式]
1. 観測した保存境界で、課題末の head は現課題の F に整列していた（LR: κ 比 1.4〜7.0・cos² 0.63〜0.75、Snake: cos² 0.5〜0.9、主対象 5 腕で帰無分位点 1.000）。補題 κ ≥ [N(log K − L) − B]/‖F‖² は 484 状態で破れ 0 で、線形 head と CE だけから成り立つ。
2. LR の f2 では、自分の重みを通る期待の押しは全境界で正符号が 99〜100%、実際の最初の 1 歩で 80〜95%、200 更新で 84〜100% が沈んだ。初期化の押しは切替の 1e−4 倍。
3. 自分の重みを通る押しは G_own = (1 − 1/K)κ_R + ε に割れ、学習後の状態では sign(κ_R) = sign(G_own) が 1.00、κ_R > 0 は f2 でほぼ全部、c1 では多くが負。
4. f2 の位置の一次応答の絶対値は上流ブロックの分担が 97〜100%（固定状態の帳簿。符号の一致や因果の寄与ではない）。
5. LR の t10・t20・t30 からの再生では、沈んだ f2 unit の変位の合計で見た戻り比が 1 を超え、元の位置まで戻った unit は 50〜60%、保存境界の f2 の集団中央値 r は約 −0.6 だった。f1・c2・c1 の集団中央値は下がり続けた。
6. 境界列で数えると f2 の unit は p⁺ < 1/2 と ≥ 1/2 を行き来した（LR で 1,000 中 653）。
7. fc のゲートが鋭い Snake（c = 3）では、f2 の G_own の正符号は半々で、LR のような正符号優勢は無かった。

**言えない**
- 押しの正符号が学んだ整列の「原因」で揃うこと（head を替えた参照は固定状態の比較で、整列と確信度が同時に変わる。学習履歴の因果ではない）。κ > 0 だけから押しの符号は導けない（gate・明るさ・非対角項・head 残差・予測誤差の条件が要る: Astra 導出ノート §3a）。
- f2 の集団中央値が約 −0.6 に留まる機構と、以後の停止・定常。
- 課題あたりの更新数（4,000 対 30,000）が戻りの差の原因かどうか（箱が二つ違う）。
- 上流ブロックの応答の符号が沈める側に出る理由（先験的には定まらない: Astra 導出ノート §5）。
- Snake の κ 比が落ちることと可塑性の喪失の関係（SNAc3・CV06FC3 は幅の暴走で知られた腕で、押しに正符号優勢が無いことと尺度の膨張は同じ状態の記述）。活性化だけを変えた因果効果。
- 実ラベルの CNN（5+1）で同じ装填が起きるか（一様ラベルの期待が使えないので対象外）。
- 範囲の限界: 結果は観測した保存境界とこの箱に限る。R は 1 seed の参照。span > 1 の帳簿は各課題の寄与を識別しない。最終境界からの更新は元の走の外への継続で、全再生区間の bit 一致を確認したわけではない。Q 比と cos² による P1 の代替的な読みは事後の補助評価で、登録した κ 比の不支持を変えない。head のクラス置換は κ の帰無には使えるが、π も置換される対称性の下では押しを壊す対照にならない。Euclid GD の固定状態の一次応答を、Adam の有限更新や適応 α を含む変位と同一視しない。疎な境界列の戻りの計数は境界間の往復を全部は捕捉せず、集団の中央値や合計の戻り量から unit ごとの不可逆・完全回復は結論しない。

## 6. V13 の部品の表「CNN × 装填」の欄（提案）[提案]

> **理論の格 [恒等式・不等式]**: 線形 head と交差エントロピーから κ の下界 κ ≥ [N(log K − L) − B]/‖F‖² が成り立つ（構造によらない）。自分の重みを通る押しは G_own = (1 − 1/K)κ_R + ε と分解できる。どちらも CNN の沈降や再装填の因果機構を証明しない。
>
> **CNN の実測 [実測]**: RL-CIFAR の LR では、観測した保存境界で κ 比の登録基準を満たした（1.4〜7.0、10/10 seed）。f2 の自分の重みを通る期待の押しは正符号が 99〜100%。再生した 200 更新で f2 の 84〜100% が沈んだ。初期化の押しは切替の 1e−4 倍。上流ブロックの絶対値分担は 97〜100%（T3）。課題の中の集団の戻り量（t10 以降 1 倍超）と unit ごとの完全回復率（50〜60%）は g2 に分けて示す。保存境界の f2 の集団中央値 r は後半の 3 点で約 −0.6、f1・conv は下がり続けた。境界列での unit の戻りは f2 で 1,000 中 653（T7）。Snake 4 腕の κ 比は登録基準を満たさず、cos² は 0.5〜0.9。fc のゲートが鋭い 2 腕では f2 の押しに正符号優勢が無かった。
>
> **介入 [実施範囲]**: 固定状態で head を替えた参照比較は実施した（乱数 head で正符号 0.63〜0.65 対 実際 0.99〜1.00）。学習履歴を通じて機構を同定する介入とダイヤル実験は未実施。
