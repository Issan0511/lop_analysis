## 結論

1. **観測した保存境界で、読み出しは CNN でも現課題のラベル構造に整列していた。** leaky（LR）では κ_k/κ₁ が 1.4〜7.0 で全境界 10/10 seed、head と F の cos² は 0.63〜0.75、クラス置換の帰無分位点は 1.000、補題 κ ≥ [N(log K − L) − B]/‖F‖² の破れは 484 状態で 0 [実測・恒等式]。適応 Snake 4 腕では κ 比の登録基準を満たさない（‖F‖ の増大と射影ノルム Q の変化が併存。CV06FC3 は ‖F‖ が 4.5e3 → 1.6e6）が、cos² は 0.5〜0.9 に留まった [実測]。
2. **最終隠れ層 f2 の自分の重みを通る押しは LR で全境界 99〜100% が正符号（沈める側）、再生した 200 更新で 84〜100% が沈み、初期化の押しは切替の 1e−4 倍** [実測]。自分の重みを通る押しは G_own = (1 − 1/K)κ_R + ε（κ_R = own 方向の感度の旧ラベルへの整列）に割れ、学習後の状態では sign(κ_R) = sign(G_own) が 1.00 [恒等式・実測]。
3. **MLP と違う点が三つ** [実測]。(i) f2 の位置の一次応答のうち上流の重みのブロックの絶対値分担が 97〜100%（固定状態の帳簿、符号や因果の分担ではない）。(ii) 30,000 更新の課題の中で、切替の沈みの合計は t10 以降 1 倍以上戻り、元の位置まで戻る unit は 50〜60%、保存境界の f2 の集団中央値 r は t10・t20・t30 で約 −0.6（f1・c2・c1 の中央値は下がり続ける）。境界列で数えると f2 の unit は p⁺ < 1/2 と ≥ 1/2 を行き来する（LR で 1,000 中 653、MLP は 4）。(iii) fc のゲートが鋭い Snake（c = 3 の SNAc3・CV06FC3）では f2 の G_own の正符号は半々で、LR のような正符号優勢は無い。

## 1 何を測ったか

- 箱: RL-CIFAR CNN（conv 3→16 → φ → pool → conv 16→16 → φ → pool → fc 1024→100 → φ → fc 100→100 → φ → head）、1,200 枚、課題ごとに一様乱数ラベル、batch 16、30,000 更新/課題、Adam 1e−3。腕: LR（seed 10〜19、t ∈ {1,2,3,5,10,20,30}）、適応 Snake SNA・SNAc3・CV06FC3・CV3FC06（seed 10〜19、t ≤ 50）、R（seed 10、t ≤ 3、課題 3 で死ぬ参照）。433 状態 ＋ 初期値 51。
- 定義は MLP のまま: x = f1 の出力、K_n = x̄·x_n + 1、κ = ⟨v^c, F⟩/‖F‖²（head の F 方向への射影係数）、S_exact = Σ K_n g ⟨v^c, π⟩（自分の重みを通る期待の押し）、S_self = κ(1 − 1/K)Σ K_n g φ。CNN で足したもの: G_own = S_exact/N、G_full（α 固定の全パラメータの一次応答）、G_up（上流ブロックの応答、G_full = G_own + G_up）。κ は尺度の非不変量（F を a 倍・head を 1/a 倍で 1/a² 倍）なので Q = κ‖F‖ と cos² を並べる（Astra）。
- 検査: 58 件中、必須 54 件 PASS（閉じた式 = autograd 1e−15、JVP の G_full = 既存の保存値、A の恒等式 2e−16、再生 t1→t2 は LR 10 seed・Snake 40 束・R で保存済み t02 と bit 一致、LR の t2→t3 も全課題の再生で bit 一致）。Snake は 10 束では一致しない（非必須の検査が FAIL）。K6 は登録の有限ステップ基準では SNA が 1.2〜4.3e−3 で未達、Richardson の極限は 1.3e−5 で一致（追加の検算）。Astra のコード監査: 符号・式・配線に結果を反転させる誤りなし。

## 6 言える／言えない

**言える**: §結論 1〜3。
**言えない**: 押しの正符号が学んだ整列の原因で揃うこと（head を替えた参照は固定状態の比較）。κ > 0 だけから押しの符号は導けない。f2 の集団中央値が約 −0.6 に留まる機構と以後の停止。課題あたりの更新数（4,000 対 30,000）が戻りの差の原因かどうか（箱が二つ違う）。上流ブロックの応答の符号が沈める側に出る理由（先験的には定まらない: Astra 導出ノート §5）。活性化だけを変えた因果効果。実ラベル CNN で同じか。範囲の限界: 観測した保存境界とこの箱に限る。span > 1 の帳簿は各課題の寄与を識別しない。最終境界からの更新は元の走の外への継続。Q 比と cos² による読みは事後の補助評価で登録の判定を変えない。疎な境界列の戻りの計数は往復を全部は捕捉しない。

## 7 V13 への含意 [提案]

- 部品 0（装填）の「CNN」欄: 理論の格 = κ の下界は線形 head ＋ CE の恒等式と Jensen で構造によらず、G_own = (1 − 1/K)κ_R + ε は恒等式（どちらも因果機構の証明ではない）。実測 = 結論 1〜3（LR の数は repo の summary.md §6 の文案）。介入 = 固定状態で head を替えた参照比較のみ、学習履歴を通じた介入とダイヤルは未実施。
- H1 の文言: LR の観測境界では κ の再整列と f2 の自分の重みを通る押しの正符号優勢が併存した。H1 の十分条件や因果機構の立証とは区別して載せる。「沈み続ける」の集団の記述は層で分ける: 最終隠れ層は切替で深く沈んで課題の中で集団として戻り、f1・conv の集団中央値は下がり続けた。
- κ 比ではなく cos² と Q で箱をまたいで比べる（κ は尺度の非不変量）。
