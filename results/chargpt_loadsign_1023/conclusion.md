# 装填成分の押しが後期に半々になる経路

2026-10-23 / Issa の依頼 / Codex 01a1676a

## 結論

C3-2 の L1 では、装填読み出しが作る自己項の正方向の押しに、他の FFN unit の出力から戻る逆向きの項が重なるようになる。最終 LayerNorm の分散微分も符号に効く。後期の半々を「最終 LN だけ」「v が小さくなって消えた」「入力係数の負の符号だけ」では説明できなかった。

自己項を含む分解は成立する。成立しなくなるのは自己項の符号だけから合計の符号を予測する読み。全て、自分の up 重み W_i に届く勾配の内訳であり、他の重みや上流パラメータの更新を入れた計算ではない。以下の第二段階の「自己項」は予測を作る出力源の自己項であり、補題1の自己形ΣKφφ′と同じ量ではない。

## 対象と主な数値

保存 checkpoint のみ。2 腕 × 10 seed × 35 課題末 = 700 状態。早期は課題末 1–9、後期は課題末 89–100。タスク内の後半ではなく、継続学習列の後ろの課題である。表は seed 内の窓中央値を取り、その10 seedの範囲を示す。S>0 が沈める側。

| C3-2 L1 の量 | 早期 | 後期 |
|---|---|---|
| 自己項が沈める割合 | 0.9975–1.0000 | 0.7500–1.0000 |
| 他 unit 由来の項が沈める割合 | 0.7553–0.8951 | 0.0059–0.5121 |
| 最終 LN の分散微分を入れる前の合計 | 0.9864–0.9956 | 0.4932–0.7489 |
| 分散微分も含めた元の s_load | 0.7188–0.7979 | 0.4603–0.5194 |
| 他 unit 由来の項の絶対値の分担 | 0.1690–0.2021 | 0.3949–0.5896 |

最後の分担は unit ごとの |other|/(|self|+|other|+|residual|) の中央値。最終 LN の分散微分を含める前の帳簿であり、因果的な寄与率ではない。他 unit 項の分担は10/10 seedで増え、その正の割合は10/10 seedで下がった。

自分の出力＋固定残差までの信号が正だった unit を、他 unit 項を足すと非正にする割合は、早期 0–0.0059 → 後期 0.1340–0.5068。

## 保存状態での診断

- 最終 LN の分散微分だけを除く: C3 後期 0.4932–0.7489。事前の回復基準（s≥0.75 かつ元より≥0.20増）0/10。
- 位置係数 K を abs(K) にするだけ: 後期 0.4603–0.5263。0/10。一定の正係数にしても 0.4531–0.5180。
- softmax の誤差を装填 logit だけで作る: 後期 0.4080–0.4980。0/10。head の残余成分を誤差側から除くだけでも回復しない。
- 探索的な再合成で他 unit 項と LN の分散微分を両方除く: 後期 0.6754–1.0000。上と同じ数値基準では8/10。元の事前判定の変更ではない。

自己項だけの後期の正の割合は7 seedで0.9955以上。seed2,3,8では0.8335,0.7500,0.8936。自己項のKをabs(K)にすると0.9928,0.9609,1.0000になる。従って一部seedでは、unitが活性になる位置とKの符号の結び付きも効いている。Kが全tokenの大半で正でも、この条件付きの効果は無視できない。

vの縮小の説明も合わない。中心化headのノルムは21.37–23.26 → 84.50–93.57、装填読み出しのノルムは16.51–19.85 → 34.10–48.12。v/W のノルム比は0.364–0.383 → 0.285–0.444。上流の更新はこの計算に含まれない。

## ReLUcap-2 との違い

ReLUcap-2 の後期は、他 unit 由来の項も0.9902–1.0000の割合で沈める側を保ち、分散微分前の合計も0.9980–1.0000。最終 LN の分散微分を入れると0.4463–0.5137になる。その項だけを除くと10/10 seedが事前の回復基準を満たす。最終的に半々という同じ見かけでも、C3とReLUcapで内訳が違う。

## 分解と読みの限界

最後のFFN出力後、最終LN前を t=r+Ua、q=(t-mean(t))/sigma、b=gamma*(e@vL) とすると、LNの逆向きの信号は

    [b - mean(b) - q*mean(q*b)] / sigma

である。最後の項を分散微分の項と呼ぶ。自己項・他unit項・固定残差項は、残るdirectの信号をさらに分けたもの。

softmax について f を logit、alpha=logmeanexp(f)、d_i=(p_i-1/V)/(f_i-alpha) と置く。H=diag(d)-dd^T/sum(d) は半正定値で、p-u=Hf が厳密に成立する。このHを用いてfを自unit・他unit・残差のforward出力に分けた。非線形softmaxの出力源の帰属には唯一の分け方があるわけではない。ここで報告した値は、この測定前に固定した恒等分解におけるもの。

第一段階は事前登録。第二段階の自己項等の分解は、第一段階でC3の原因が特定できなかった結果を見てからspec§7をcommitして測定した探索的追補。再合成も探索的。保存状態でどの信号が符号を変えるかを示すが、どの学習更新がこの配置を作ったかを証明しない。

## 補題1との対応についての訂正・区別

### 装填側を直接分けた第三段階の結果

T=Gamma P U、G=T^T Tとし、現課題probeでB=(Y-u)^T(a/sigma)、F_r=(Y-u)^T(Gamma P r/sigma)を作ると、F=B T^T+F_rである。unit iの分散微分前の装填読み出しは

    κF T_i = κG_ii B_i + κΣ_{j≠i}G_ji B_j + κF_r T_i。

| C3の装填側の項が沈める割合 | 早期 | 後期 |
|---|---|---|
| 自unit成分・分散微分前 | 0.9780–0.9949 | 0.7223–1.0000 |
| 他unit成分・分散微分前 | 0.9482–0.9746 | 0.0157–0.5138 |
| 自unit成分・分散微分込み | 0.9756–0.9935 | 0.7223–1.0000 |
| 他unit成分・分散微分込み | 0.5527–0.6121 | 0.0205–0.4625 |
| 自unit成分・Kをabs(K)・分散微分込み | 0.9756–0.9935 | 0.9595–1.0000 |

全700状態で元のdirect/exactの押しを再現し、最大相対誤差9.48e-15、符号割合は完全一致。Fの恒等再現も5.74e-15。ReLUcapの装填自己成分は後期、分散微分前・込みの両方で1.0000。装填の他unit成分は分散微分前0.9814–0.9971、込み0.2705–0.3340。

headのv⊥を取り除いても、FFN unitごとの読み出しには他unitのB_jや残差入力からの装填が残る。この残りも同じ旧ラベルから作られており、unitごとのv_i^0が旧ラベルと無相関であるとは自動的に置けない。同じラベル由来というだけで相関の非零を証明したわけではなく、旧ラベルを振り直した期待は今回測っていない。測れたのは、固定状態の押しにおいてその残りが小さくなく、逆向きに効くこと。

この結果は、FFN出力方向の内積による混合と、活性・誤差との結び付きが重要であることを示す。ただしGだけの変化をB・誤差・gateの変化から分離していないので、「配置のどのパラメータが原因だったか」を一意に同定したとは言わない。

### H1の仮定と今回測ったものの違い

原文を確認した（V13付録_最小限_1023 C.1–C.2、V12通し稿_1007 C.3、V12補題1パッチ_幅のひずみと越えの条件_1019）。ReLUのφφ′=z_+≥0は破れていない。今回成立を確認できないのは、実際の押しを正の係数×自己形に置き換えるところである。

H1の導出は、旧ラベル平均の中で特徴・微分・K・κを固定し、旧ラベルの入力間独立と予測π→yを用いて、E[〈y_m-u,y_n-u〉]=0（m≠n）と対角項だけを残す。今回の測定は、学習済みの状態を固定した新課題期待であり、この旧ラベル平均ではない。また勾配probeは独立一様入力、装填Fのprobeは現課題の鎖で、単純に同一入力の対角消去を当てられない。

GPTではFは最終LN後の128次元特徴についての量であり、対象は手前の512 FFN unit。間のdown射影とLNを通した実効読み出しを、κFの正の射影係数だけからunitごとのκφ_iと同一視できない。κ>0のCE下界、自己形のReLU正値性、実際のunit押しの正値性は別の文である。

第二段階の予測側の他unit項と、H1で平均消去する入力間の非対角項は別物。その大きさをもってH1のどの仮定がどれだけ破れたかを測ったとは言わない。補題との接続を近づけるため、第三段階ではF自体をunit別に分けた（loading_sources_summary.md）。

整列の下界からκ>0が出ても、v=v0+κFのv0が旧ラベルと無相関とは限らない。射影による〈v0,F〉=0は、H1が要する旧ラベルとの期待相関の消失と同じ条件ではない。今回vLだけへ差し替えても、特徴固定の旧ラベル平均・正答極限・FFNからheadへの構造という残りの条件は復元しない。

本文・付録へ移すときは「自己形が破れた」「κ>0でも自己形の符号が揃わない」とは書かず、「実際の装填成分の押しS_loadが、正の自己形に従うとは限らない」と区別する。本解析の自己成分は、補題の自己形そのものを測った量ではない。

10/19に指摘済みの「K一定なら幅は不変」という補題1の反復の旧証明の誤りは別件。今回はその手前の、一歩の実際の押しと自己形との対応を調べている。

## 検証・保存

### 入力probeと旧課題の誤差の対照（第四段階）

旧課題で正答すればp-y_oldは消えるが、新課題の独立一様ラベルに平均すると誤差はp-uである。p≈y_oldでもp-u≈y_old-uは残る。実装は「旧課題で誤差が残った例だけを抽出してランダムラベルへ読み替える」手順ではなく、固定モデルの新ラベル期待を全probe位置で計算する。

箱Mは65文字の直前2文字ごとにDirichlet(alpha=.01)で次文字の分布を作り、毎回そこから次文字をサンプルする。決定的なラベルの暗記ではない。C3の現課題probeの正答率は早期0.6914–0.7046、後期0.5660–0.6904。正解文字への平均確率は早期0.5972–0.6072、後期0.4291–0.5840。連鎖自体の条件付きentropyは早後とも約0.72–0.73。H1のπ→one-hot正答は早期から成立しておらず、この事実だけで早後の差を説明してはいけない。

Fと同じ現課題文字列に勾配probeを揃え、新ラベル期待p-uは保つ対照を全700状態で実施した。C3の後期s_loadは元の一様入力0.4603–0.5194に対し、同じ入力で0.4512–0.5256。回復基準0/10。ReLUcapも0.4395–0.5029、0/10。入力分布の違いだけでは後期の半々を説明しない。入力次元の因果効果は測っていない。

旧課題CE自身の押しの絶対値中央値/切替期待の押しの絶対値中央値はC3早期0.1768–0.2324、後期0.1540–0.6917。これは単位ごとの比の中央値ではなく、各状態の二つの中央値の比。旧課題の更新が全て消えている状態とも言えない。課題のBayes最適に近づいたときの条件付き期待勾配と、有限probeの実現値は区別する。
