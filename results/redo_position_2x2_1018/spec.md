## 1. ReDo × 生存ユニットの位置回復

**run id:** `redo_position_2x2_1018`  
**推奨ファイル:** `specs/spec_redo_position_2x2_1018.md`  
**継承:** `cifar5p1_mlp_0920`、`resp_cifar5p1_1007`、`controls_cifar5p1_1008`、`baselines_cifar5p1_1008`。

### 1.1 問い・箱・分岐

F51/ReLU/std。seed0–9。t1〜29 の自然な接頭部を再現し、**t28 末を介入点、t29 を採点する hard 1 課題**に固定する。t1 末の網を早期位置の参照にする。t1/t28/t29 の P・Adam・RNG を保存。無介入分岐が接頭部の t29 と一致することを介入値の開封前に確認する。

### 1.2 四腕（4×10 seed、共通接頭部）

| 腕 | t28 末の一回操作 |
|---|---|
| `none` | なし |
| `redo` | 既存 ReDo の採用閾値 τ=0.1 による再初期化を一回 |
| `shift` | 下記の第2隠れ層 bias の一様シフトを一回 |
| `both` | 同じ ReDo → 同じ定義の shift の順で一回ずつ |

**ReDo の細部。** t28 の最後の2学習バッチの64枚、介入前の同じ forward で両隠れ層のスコア `s_i=mean|h_i|/(mean_j mean|h_j|+1e−9)` と対象集合 D_l={s_i≤0.1} を固定する。入力行は既存 `b5_redo_reinit` stream の初回 draw と初期化分布、bias は0、続いて出力列は0。入力行と出力列の Adam m/v は0、**bias の m/v と大域時刻は保持**。両層の入力側→両層の出力側という元の順序を継ぐ。`redo` と `both` は mask と新しい値も同一。一回介入なので period=1560 は以後の起動条件に使わず、t29 中は再初期化しない。

**shift の対象と目標。** 画像集合 X は t29 の訓練2500枚（ラベルは不使用）。介入前の自然網で、第2隠れ層に **max_x z_i(x)>0** を持つunitをLとする。これは現稿§4の「生きたユニット」の定義に合わせる。**bothもこの介入前のLを使う。** 開いたpairの目標と達成値はnative訓練微分で記録し、宿主の `clamp(min=0)` のゼロ点の微分と、論文のz>0を区別する。両方の個数も残す。

早期 t1 網を同じ X に通し、L 上の開いた (画像,unit) pair 数 K* を求める。各 shift 腕の直前状態について、`b2[i]←b2[i]+c_s (i∈L)`、他の bias は不変とし、実際の native 訓練ゲート数が K* に最も近くなる **非負 float32 の c_s** を選ぶ。同点は小さい c。既に K* 以上なら c=0 とし `TARGET_ALREADY_MET`。ソートした前活性の閾値を候補とし、丸めを含む実 forward の単調な探索で確認する。全体で同じ c、unit 別最適化はしない。到達不能な同値ブロックは最小の達成誤差とその区間を記録する。

シフトは重み・moment・RNG を変えず、第2層の生存 unit の bias だけを変える。`shift` と `both` は同じ目標へ合わせる **方策としての介入**であり、ReDo 後の分布が違うため c の数値は別になり得る。

**先に開示する限界。** 既存 A.2 系の `R_match` は anchored な応答引数のシフトであり、物理 bias シフトではない。本走は依頼どおり物理 bias を変えるので初期 logits も変わる。初期 logits/CE/精度の変化を必ず記録する。τ=0.1 では D と L が重なり得るため、`|D2∩L|` を保存する。ReDo と shift の操作効果を切る走であり、「死亡した unit だけ」と「生存 unit だけ」の互いに素な分解ではない。死亡だけの主張には τ=0 の別登録が要る。

### 1.3 指標・判定（m=7）

E[a,s]=t29 online。`R=E[redo]−E[none]`、`S=E[shift]−E[none]`、`B=E[both]−E[none]`。

判定用7区間は R、S、B、B−S、B−R、S−R、`I=B−R−S`。逆向きの区間は符号反転で得る。

| 主ラベル | 必要十分な登録条件 |
|---|---|
| `POSITION_CARRIES` | POS(S)、NI(shift,both)、POS(S−R) |
| `DEAD_CARRIES` | POS(R)、NI(redo,both)、POS(R−S) |
| `ADDITIVE` | POS(R)、POS(S)、EQ(I) |
| `MIXED` | 上のどれも成立しない |

`DEAD_CARRIES` は依頼の名前を保持するが、本文では「この閾値の ReDo が運ぶ」と記す。文字どおりの死亡だけの帰属をしない。B が二単独腕を上回っても I の EQ が示せなければ ADDITIVE としない。各腕−none、I、全10対応差を必ず表にする。

副: t29 memo/CE、介入直前直後と更新0/1/10/100/390/780の m/s/r・native 微分平均/分散・死亡/休眠率・開いた数、D/L/重なり、c、目標誤差、初期 logits 差。t29 の同一バッチ列を学ぶ fresh は「課題が難しいだけ」を調べる参照で、主ラベルには混ぜない。
