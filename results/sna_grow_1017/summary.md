## 2. CNN（Q1）

- 窓 t21–30 の online は SNA 0.9536、SNA+grow1 0.9610。窓 t11–20 でも差は +0.0077（9/10）。
- 差は課題 4 から開き、課題 5〜30 は +0.005〜+0.011 で続く。
- 覚え直しは速くなる。99% に届く epoch（中央値）は課題 30 で SNA 49、grow 41。
- 対応差の seed 間 SD は 0.0088 で、spec の見積もり 0.0037 の 2.4 倍だった。帯の 0.0055 は 0 から約 2 SE で、設計（4.6 SE）より余裕は薄い。
- 1 seed を抜いた D は 0.0059〜0.0095 で、どれも帯の上に残る。

**予想した経路は通っていない。** 機構の再走（課題 20 → 21、run の順で bit 再現）では、grow の α は覚え直しの 10 epoch の間まったく動かない。それでも f2 の傾きの平均は SNA より低い。

| f2 の傾きの平均（seed 10–19） | 75 更新 | 3 epoch | 5 epoch | 10 epoch |
|---|---:|---:|---:|---:|
| SNA | 0.084 | 0.164 | 0.266 | 0.394 |
| SNA+grow1 | 0.138 | 0.158 | 0.177 | 0.233 |

grow は切替の時点ですでに傾きが低い（0 更新で 0.580、SNA 0.689）。据え置きの反実仮想（SNA の軌道で α を固定）は軌道の変化を含まないので、実際の grow の軌道とは別物だった。

**幅が全層で伸び続ける。** SNA は幅が頭打ちになるが、grow は伸び続ける。

| 課題 30 の中央値 | SNA | SNA+grow1 |
|---|---:|---:|
| c1 の幅（α） | 0.150（3.000、上限） | 0.627（0.643） |
| c2 の幅 | 0.91 | 5.62 |
| f1 の幅 | 6.57 | 33.87 |
| f2 の幅 | 17.14 | 57.00 |
| f2 の 2α·幅（単位ごとの中央値） | 1.241 | 0.932 |
| f2 の座席 / 谷を越えた割合 | −1.164 / 0.285 | −0.887 / 0.090 |
| logit の sd | 16.48 | 25.13 |
| 切替直後の損失 | 32.45 | 57.70 |

- c1 の α は上限から外れ、課題 1 末の値に近いまま下がる（実質、c1 は課題 1 末の凍結に近い）。
- 切替直後の損失は伸び続けている。seed 12 で切替直後の損失 > 100 が 2 回（t24 115.98、t27 111.08）あり、暴走の定義に当たる。seed 12 は唯一の負の seed（−0.011）。
- 30 課題より先で利得が保たれるか、暴走が増えるかは測っていない。

## 5. 読み（親）

- CNN では、縮みを追わない規則で SNA の劣化が減った。登録の帯では「救う」。
- ただし、登録時に置いた「切替直後の縮みに α が追従して fc を谷に留める」という経路はこの走で支持されない。何が効いたかは特定していない。
- MLP では、全期間の最大を幅の代わりに使う規則そのものが壊れた。一時的な山が α を恒久的に下げる。
- 両方の箱で、課題 1 末で凍結する腕のほうが grow より良い。MLP は同じ記録との直接比較（−0.029）。CNN は 1009 の束 A で凍結 +0.012（10/10）、今回の grow +0.0075 で、束が違うので参考値。
- したがって「伸びだけ追う α」を主張にはできない。「縮みは追わなくてよい」も、この走だけでは言えない（MLP の失敗は最大の取り方の失敗で、縮みを追わないこと自体の検定になっていない）。

## 6. 登録からのずれ

- K-cnn-grow・K-mlp-grow の 1e−7 は、同じ演算順の float32 の参照との bit 一致と 4u（2.38e−7）の上界で通した。float64 の参照との相対 1e−7 は宿主の SNA の α でも届かない（1.774e−7）。結果には影響しない。
- 機構の再走は spec の R = 6 でなく run の全 20 slot を run の順で読み込み、本走と bit 再現させた（1080 値で不一致 0）。
- CNN の SNA の W21 は束 A（1009）の 0.9576 に対し今回 0.9536。同じ構成でも束の大きさ R が違うと軌道が分かれる（エンジンの R 依存）。D は同じ束の中の対応差なので影響は雑音として入る。
- MLP の本走は実装の commit を要求するので、commit 40d696a7 の後に回した（検査と同じ sha b615cbcd）。
