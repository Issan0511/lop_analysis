# cnn_drive_verify_1009 — Codex の CNN 駆動源理論を実軌道で数値検証（Snake の CNN）

状態: phase 1 完了（2026-10-10 03:50）。計算・表は Opus（サブエージェント）、この要約は親（Fable）が報告から書き起こした。表は `tables/`（a・b1）、`tables_b2/`（凍結参照）、`tables_c/`（長期と帳簿）、`tables_extra/`（自己形と Adam の分解）、`tables_misc/`（容量と c2 の厳密値）。spec と予測（計算前に登録）は `specs/spec_cnn_drive_verify_1009.md`。コードは `src/cnn_drive_verify_1009.py`・`analysis/cnn_drive_verify_1009/`。

対象: `sna_cnn_cause_1009/A` のチェックポイント（4 腕 SNA・SNAc3・CV06FC3・CV3FC06 × seed 10–19 × t ∈ {1,2,5,10,20,30}、課題末の重み・Adam の m/v・α の状態）。(a)(b1) は 240 状態・7,680 チャネル。活性化は **Snake（適応 α）** で、Codex の定理が仮定する ReLU ではない。以下はすべて、活性化によらず定義できる量を Snake の実軌道で測った値。

## 0. 一行

実軌道では、Codex の固定状態の量（期待勾配 G・凍結した Adam の応答・容量の傾き）は最初の 1 歩の向きをよく与え、Adam はそれをほとんど逆にしない（c1 ≤ 0.2〜1.7%、c2 3〜4%）。しかし Codex の十分条件（証明書）は実状態で一度も成り立たず、入力層 c1 では full の押しの向きが自己形にも literal self にも従わない（一致は偶然並み）。長期の沈降（t30 で c1 の 85%・c2 の 99% が初期より下）は、課題ごとの単調低下ではなく、切り替え直後の約 10 更新の沈み（t1 で中央値 −0.17）が課題の残りでほぼ戻ったあとのわずかな偏り（1 課題で下がる割合 0.51〜0.56）の蓄積として現れる。

## 1. 定義の対応（Codex の記号 → 我々のテンソル。曖昧な点は Codex の verify*.py の実装を正とした）

| Codex | ここでの計算 |
|---|---|
| m_c（第一 Conv の平均前活性） | z̄¹_j = 1200 枚 × 32×32 位置の平均（zero-pad 込み） |
| u = ∇m | autograd（c1 では平均 augmented patch と 1） |
| G = E_new⟨∇m, ∇L_new⟩（G > 0 が沈める側） | ラベル iid 一様なので期待は厳密。(1/N)ΣR·(p − 1/C) と照合 |
| literal self（第一 Conv） | W1[j]・b1[j]・W2[:, j] に切り出して forward し直す（Codex の selfpars と同じ。「他チャネルを 0」と一致、K4） |
| literal self（第二 Conv） | 私たちの延長（W2[j]・b2[j]・fc1 の 64 列） |
| 自己形 S = ⟨R_c, H_c⟩ | pool 後の特徴とその前向き接線の内積（K8）。画像で中心化した S1 も |
| 十分条件 (3)(5)(8) | 画像 × チャネルごとに判定 |
| Adam の 1 歩とその分解 | 宿主の式（bias 補正込み）。ラベルと batch の期待は MC 65,536 標本 |
| 凍結参照（proof §21） | J_conv を固定し、ラベル再利用・毎 epoch の randperm で m/v だけ進める |
| 容量の方向微分 ½tr((λ+K)⁻¹K′) | 全 raw パラメータ、32 枚 × 10 出力、λ ∈ {0.01, 1, 100} |

検査 K0–K8 は全部 PASS（方向微分は pool の勝者を固定した差分と 1e−9〜4e−7、G の 3 式は 1.7e−15、再走 t1→t2 は保存済み t02 と 40 走すべて bit 一致）。計算は float64（訓練の cuDNN conv2 は z2 で相対 5e−4〜2e−3 ずれる）。

### (a) 押しの向き（full と literal self）

| 課題 | c1 沈める側（full） | c1（self） | c1 一致 | c2 沈める側（full） | c2（self） | c2 一致 |
|---|---|---|---|---|---|---|
| 1 | 0.51 [0.49, 0.53] | 0.78 | 0.58 | 0.87 [0.83, 0.91] | 0.91 | 0.91 |
| 5 | 0.54 | 0.67 | 0.63 | 0.73 | 0.83 | 0.77 |
| 10 | 0.52 | 0.59 | 0.66 | 0.56 | 0.78 | 0.74 |
| 20 | 0.51 | 0.55 | 0.62 | 0.53 | 0.70 | 0.74 |
| 30 | 0.43 [0.40, 0.47] | 0.55 | 0.56 | 0.54 | 0.71 | 0.74 |

- 一致 − 偶然 = c1 +0.106 [0.084, 0.129]、c2 +0.186 [0.171, 0.200]。Spearman(G_full, G_self) は c1 0.33・c2 0.74。
- 「self は沈めるが full は浮かせる」が c1 26%・c2 16%（逆は 13%・5%）。Codex の反例は実軌道では例外ではない。
- 腕で分かれる（t30 の c1 の沈める側）: SNA 0.11・CV06FC3 0.24・CV3FC06 0.54・SNAc3 0.84。c2: CV06FC3 1.00・SNA 0.96・SNAc3 0.12・CV3FC06 0.08。
- **c2 は Snake の谷の則に従う**（谷の上で沈める側 0.97、下で 0.38、seat の AUC 0.94）。**c1 は従わない**（AUC 0.53）。
- 自己形 S1（中心化）は Snake でも c1 92%・c2 90% で正。self の押しとの一致は 0.68・0.88 だが、**c1 では full の押しとの一致が偶然並み（0.55、ρ −0.09）**。c2 では 0.74（ρ 0.83）。
- 十分条件 (5)/(8) が 1200 枚全部で成り立つチャネル × 状態: **0**（画像ごとの割合の中央値 0.13・0.19）。順位条件 (3): 0。

### (b) Adam の反転（Bonferroni z = 4.51）

- 最初の 1 歩の有意な反転: c1 0〜0.2%（t30 だけ 1.7%）、c2 3〜4.4%（CV3FC06 8.0%・SNAc3 3.8%・SNA 3.3%・CV06FC3 0.1%）。古い m を 0 にしても同じ。
- 反転の出どころ（Codex の分解）: c2 の反転の 98% は座標ごとの倍率の項で既に逆。分母との共分散で符号が変わるのは 1%。古い m は 0。
- 1 歩の大きさ |Δθ|/(3.16·lr) の中央値 0.73〜0.91（古い v は無視できない）。
- 凍結参照（Codex の定常応答）: S ≥ 75 で −G と有意に同じ向きが 92〜93%。有意な反転は c1 0%・c2 3.1%。
- **同じ実ラベル・同じ batch で凍結と実軌道を比べる**: 凍結は −G に 86%（10 更新）〜97%（75 更新以降）従い下がるのは約 50%。実軌道は −G に 59〜62% しか従わず 65〜73% が下がる。→ 最初の 1 epoch で固定状態の向きからずれるのは、Adam のモーメントではなく**パラメータが動くこと**による。

## 4. Codex の主張の判定（Snake の実軌道で）

**支持**: 1（G の恒等式）。「他チャネルが向きを逆にしうる」反例（c1 で 26%、常態）。8（Adam が逆にしうる — 存在のみ、c2 3〜4%・c1 ≲ 1.7%）。9・12・24 の定常反転（凍結参照で c2 約 3%・c1 0%、稀）。11・17 の「CE は容量の向きを逆にしない」（92〜97% 一致。ただし十分条件 K′ ≻ 0 は 0 件で、実測として）。10・18〜23 の「最終 mean は初期より下」（結論は c1 85%・c2 99% で観測。前提は満たさない）。

**支持されない**: 7（十分条件は全画像で 0 件。G > 0 も c1 では約半数）。3・11・17 の full と self の容量の同符号（c1 0.55）。「自己形が正なら押しは沈める側」（c1 で自己形 92% 正なのに full との一致は偶然並み）。

**測れない**: 2・4・5・6・14・15（模型が実訓練と違う）。12・13・16・19〜23・24 の構成と定数。

## 5. Snake の影響と ReLU/leaky で測るなら

- Snake 特有: c2 の符号を決める谷（ReLU に谷はない）。ReLU では自己形は構成上 S ≥ 0（Snake では c1 8%・c2 10% が負）。
- Snake のせいとは言えない: c1 で full が自己形にも self にも従わないのは、自己形が正のチャネルでも起きる。ReLU で同じかは未測定。
- 要るもの: 宿主の LR 腕（leaky 0.1、生きる）と R 腕（課題 3 で死ぬ）、seed 10–19、課題末に P・m・v・tc を保存。φ・φ′ を差し替えれば今回のコードは使える（ReLU では K1 で gate も固定する）。

## 6. 言える／言えない

**言える**: 実際に学習した Snake の CNN では、固定状態の量は最初の 1 歩の向きを高い精度で与え、Adam はそれをほとんど逆にしない。実際の課題では最初の約 10 更新でパラメータが動いて c1 の平均が大きく下がり、その後ほぼ戻る。課題の正味は押しの向きと弱くしか結びつかない（ρ 0.18）。それでも 30 課題で積もると c1 の 85% は初期より下。
**言えない**: 最初の約 10 更新で下がる機構。ReLU の網で同じになるか。容量と c2 の厳密値は部分集合だけ。
