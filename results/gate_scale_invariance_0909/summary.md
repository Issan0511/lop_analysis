## 4. 二つの族は Δ‖W̃‖² = D² − 2cDN の**別の項**で動いている

- leaky 族: c ≈ 一定、**β が a で動く**
- Snake 族: β は乱れ、**c が α で動く**
- ELU1: β 0.33、c 0.034、指数 0.43。Δ‖W̃‖² は 0.67 → 0.52 と単調減衰

**単一の「h → 指数」の写像は存在しない。** 問いは「何が β を決めるか」と「何が c を決めるか」の 2 つに割れる。

## 6. 次の仮説（未登録・事後の読み）
- **β は勾配の一貫性**: leak が弱いほど負側（入力の 84%）が勾配に寄与せず、正側の 16% だけの**きれいな信号**になる → Adam の m̂/√v̂ が 1 に近づき正規化後の歩幅が大きい → 沈んで正側が減るほど歩幅が伸びる（β>0）。検定: 座標ごとの m̂/√v̂ の分布と、a の対応。
- **c は実効ゲートの線形性**: α が大きい Snake は sinc 平均で実効ゲートが 1 に近づき、更新方向の累積 W との相関（cos）が弱まる。検定: mob=1+sin(2αz̄)sinc(αW) の実測値と c の対応。
