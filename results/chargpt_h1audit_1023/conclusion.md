# H1の自己項と残りを初期・後期で点検した結果

2026-10-23 / Issaの依頼 / Codex 01a1676a / chargpt_h1audit_1023

## 結論

**「初期は残りが旧ラベルと無相関で自己項だけが残り、後期にその条件が破れた」という説明にはならなかった。初期から残りは大きく、自己項と同じ沈める向きに働いていた。C3では後期に他unit装填が逆向きに働くunitが増える。**

旧課題の更新が小さいことから残りの旧ラベル相関が消えるとは言えない。保存状態の実測でも、unit側の残りは初期から正負半々ではなかった。誤差信号を旧正解に置き換えてもこの結果は保たれるため、単に後期の正答への自信が低いことだけでは説明できない。

ここで測れたのは固定状態の重み付き旧ラベル内積。学習し直した網を含む旧ラベルensembleの無相関性を直接検定したわけではない。H1の自己形の正値性と、その形だけで実際の押しを説明できることを区別する。

## 比較条件

新しい学習0、2腕×10 seed×35課題末=700状態。初期は課題末1–9、中期39–50、後期89–100。タスク内の後半ではなく、継続学習列の後ろの課題である。

数値は各seedの窓中央値を取り、その10 seedの範囲。Fを作る入力と勾配probeを同じ現課題文字列に揃えた。元の独立一様入力で測ったsと混ぜない。生きたunitの集合、κ、F、位置係数Kは元の定義を保持した。S>0が沈める向き。

oracleは誤差信号だけをp-uからy_old-uへ置き換える計算。forward・重み・Fは変更しない。truthは同じ位置の真の次文字確率q-uへ置き換える。directは最終LNの分散微分だけを外し、exactはそれも含める。

## 1. unit側の残りは初期から消えていなかった

最終FFNのdown重みをU、最終LNをΓ、中心化射影をPとし、T=ΓPU、G=T^T Tと置く。
F=B T^T+F_r、B_i=Σ_m(y_m-u)a_im/σ_mなので、direct経路のunit iの読み出しは

    V^c T_i = κG_ii B_i + R_i
    R_i = κΣ_{j≠i}B_jG_ji + κF_rT_i + V^perp T_i

となる。R_iが、自己unitの装填を取り除いた残りである。head全体のV^perpだけとは異なる。
R_iの旧ラベルとの内積をK_n gate_ni/σ_nで重み付けした押しを測った。

| C3 L1、旧正解の誤差信号・direct | 初期 | 後期 |
|---|---:|---:|
| 自unit装填が沈める割合 | 1.0000–1.0000 | 0.7394–1.0000 |
| 他unit装填が沈める割合 | 0.9046–0.9518 | 0.0049–0.5045 |
| 固定残差からの装填が沈める割合 | 0.9124–0.9621 | 0.4530–0.5809 |
| head射影残りが沈める割合 | 0.6204–0.7550 | 0.4673–0.7450 |
| R_i全体が沈める割合 | 0.9447–0.9848 | 0.0039–0.7645 |
| R_iと自己装填の絶対値のうちR_iの分担 | 0.7698–0.8157 | 0.5034–0.9675 |

分担はunitごとの|S_R|/(|S_R|+|S_self|)の中央値。因果の寄与率ではない。
R_iの正の割合が0.4–0.6に入るseedは初期0/10、後期3/10で、「後期は全seedで単にランダム」とも言えない。
他unit装填の正の割合は全10 seedで0.20以上低下した。
自己装填と固定残差の和が正だったunitを、他unit項を足すと非正にする割合は初期0.0020–0.0061、後期0.1015–0.5039。

R_iはH1のv_i^0に最も近いdirect経路の残りだが、σの位置依存と最終LNがあるため、そのままH1の定数読み出しと同一視しない。

## 2. 補題が消す入力間の項も初期から大きかった

補題の旧ラベル平均が消すのは入力index m≠nであり、上のunit index j≠iとは別。
旧正解の誤差信号では

    S_load,i = κ/N Σ_{m,n} K_n gate_ni <ξ_m,ξ_n> h_m^T J_n U_i

と書ける。m=nの対角Dとm≠nのOへ厳密に分けた。
独立一様旧ラベルを、特徴・微分・κ・K固定で平均した模型ならOの期待は0。
同じ計算で自己unitのdirect対角は

    D_self,i = κ(1-1/C)G_ii mean_n[K_n gate_ni a_ni/σ_n²]

となり、ReLUでK≥0なら正である。

| C3 L1、direct自己unitの入力対角/非対角 | 初期 | 後期 |
|---|---:|---:|
| 対角D_selfが沈める割合 | 1.0000–1.0000 | 0.7500–1.0000 |
| Kをabs(K)にしたD_selfが沈める割合 | 1.0000–1.0000 | 1.0000–1.0000 |
| 非対角O_selfの絶対値の分担 | 0.7686–0.7981 | 0.6755–0.7875 |
| 非対角O_selfが沈める割合 | 0.9493–0.9762 | 0.8194–1.0000 |

初期から非対角が対角より大きいseedは10/10。自己unitの正値は、実測で対角だけが残ったためではない。初期には大きな非対角も同方向に押していた。
全loadingの非対角分担はdirectで初期0.9504–0.9555、後期0.8814–0.9443、exactでは初期0.9892–0.9935、後期0.8986–0.9608。
単一の学習済み状態に、旧ラベル平均の非対角消去を数値近似として直接当てる根拠は初期からなかった。

後期D_selfの正の割合≥.95は8/10 seed、abs(K)なら10/10。
Kが負の入力は全体では少なくても、特定unitがそこだけで開けばそのunitの符号に効く。
ReLUのφφ′=z_+そのものは破れていない。

## 3. 自信ある正答に置き換えても後期は回復しない

固定読み出しに対してS(V,p-u)=S(V,y_old-u)+S(V,p-y_old)が厳密に成立する。

| C3 L1、最終LN込みのloadingが沈める割合 | 初期 | 後期 |
|---|---:|---:|
| 実際の予測p-u | 0.6221–0.7031 | 0.4512–0.5256 |
| 旧正解one-hotによるy_old-u | 0.6267–0.6816 | 0.4456–0.5178 |
| 真の次文字確率q-u | 0.6313–0.6973 | 0.4428–0.5293 |

後期s≥.75かつ元より≥.20増の復元基準は、旧正解・真の条件付き分布の両方で0/10。
directでも、実予測の後期0.4907–0.7550に対し、旧正解0.4941–0.7566である。
自信ある正答の仮定は実モデルでは早期から厳密には満たされないが、それだけが早後差の説明ではない。

箱Mは65文字の直前2文字ごとにDirichlet(.01)で次文字確率を作り、そこから文字を抽選する。固定した独立ランダムラベルを暗記する実装ではない。
真の条件付き分布に対するprobe KL(q||p)は初期0.0923–0.1022、後期0.2173–0.9333なので後期の当てはまりも悪くなるが、上記の誤差信号対照では押しの符号は回復しない。
KLは解析probeの全128位置。学習損失は最初の位置を除く。解析の最初の位置には定常分布からの真の条件付き確率を使った。

## 4. 入力次元と配置

入力次元128、FFN512は早後で同じ。次元を変える介入はしていない。

| C3 L1の配置の指標 | 初期 | 後期 |
|---|---:|---:|
| 中心化したFFN入力の実効ランク | 73.99–82.19 | 4.97–34.07 |
| 未中心化second momentの実効ランク | 11.37–16.42 | 1.38–8.89 |
| TのGramの実効ランク | 63.13–67.76 | 34.22–61.98 |
| Tの異なる列の平均cos² | 0.01268–0.01376 | 0.01334–0.02662 |
| 生きたunit数 | 442–482 | 109–512 |

実効ランクは(tr C)^2/tr(C^2)。特徴が使う方向の広がりは全10 seedで縮小した。
したがって「128次元という設定が変わった」のではなく、同じ次元の中の配置が変わっている。
この比較だけでは配置の変化が符号を変えた因果効果、あるいはGとBのどちらの変化が主因かは分離していない。

## 5. ReLUcap-2では内訳が違う

旧正解のdirect他unit装填が沈める割合は初期0.9336–0.9805、後期0.9404–0.9854。C3の低下は再現せず、0.20以上低下は0/10。
R_i全体は後期0.9980–1.0000、自unit装填は1.0000。旧正解のdirect合計も0.9961–1.0000。
最終LNの分散微分を含めると、旧正解の合計は0.4395–0.5039となる。
中心化FFN入力の実効ランクは78.54–84.70→92.09–95.25で、C3のような縮小もない。
後期の見かけが半々でも、C3とReLUcapの経路は異なる。

## 6. H1との対応表

| 条件・推論 | 初期 | 後期 | 今回言えること |
|---|---|---|---|
| CEからκ>0 | 成立 | 成立 | 元の整列下界は破れていない |
| ReLUの自己形の正値性 | K≥0なら成立 | K≥0なら成立 | abs(K)対照は全seedで正 |
| 旧ラベルが入力間で独立一様 | 実課題とは異なる | 同左 | Markov文脈依存・確率的出力 |
| 旧ラベル平均で特徴・微分・κを固定 | 仮想計算として実施 | 同左 | 実学習ensembleの仮定としては確認していない |
| 実状態で入力非対角を無視できる | できない | できない | 初期から大きく、初期は同方向を支える |
| unit側残りを実測押しで無視できる | できない | できない | 初期は強く同方向、C3後期は他unitが逆方向化 |
| one-hotへの自信ある正答 | 厳密には不成立 | 厳密には不成立 | 正答信号へ置換しても後期は回復しない |
| 自己項の符号だけから合計を予測 | 初期に符号の傾向は合う | C3では崩れる | 初期の一致を残りゼロの証拠にできない |

「更新が止まるなら残りはランダム」について、通常のuntied読み出しでも停留条件はmean[(p-y)φ]=0であり、残りのmean[<v_i^0,y-u>]が0である条件ではない。正解を支える成分は、正解できて勾配が小さくなっても相関したまま残れる。本実装はheadとembeddingも共有する。
また、実装は所定回数のAdam更新を行う。正解したunitだけを停止・除外したり、残りをランダム化する処理はない。
