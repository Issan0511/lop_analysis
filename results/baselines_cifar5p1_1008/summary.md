### S&P は第 2 層の相対位置をどれだけ動かしたか

後期窓の relpos l2（unit ごとの z̄/sd の中央値）の対応差 S&P − R = **+0.198** [+0.144, +0.242]（19/20、p 4e−5）。中央値の比 z̄/zsd では +0.177 [+0.145, +0.232]（20/20）。**向きは 0 に近づく側で有意だが、大きさは 0.3 未満**（R −1.58 → S&P −1.38）。選ばれた S&P は縮めが小さく（ε 1e−5）雑音が大きい（σ 1e−2）設定で、W2 の行ノルムは R より大きい（t29 の ‖W2‖_F 9.7 対 7.1）。死 l2 は .336 → .132 と 6 割減るが、mob l2 は .016 で閉じたまま。前の走（行ノルムの上限）と同じく、相対位置はわずかしか戻らず、成績も R → SNA の差の 36% しか戻らない。

### ReDo: 死んだ unit を戻すと成績はどこまで戻るか（登録した言い方 §6.3）

- **死はほぼ消えた**: 死 l2（後期窓・hard の課題終端・再初期化の前）R .336 → ReDo **.002**（Δ −.332 [−.348, −.306]、20/20）。hard 課題の終端の死は t9 以降すべての課題で中央値 0。z̄ l2 −8.53 → −0.94、relpos −1.58 → −0.24、mob .003 → .409、eff_rank 9.4 → 17.7、‖W3‖ 3.14 → 0.89。
- **しかし成績は SNA・L2 Init の水準に届かない**: J2-REDO・J4-REDO とも `B_WINS`（−.123・−.124、0/20）。**戻りの割合**（中央値の対応差の比）は R → SNA の差の **43%**、R → L2 Init の差の 44%。→ 登録した読み **`DEATH_REMOVAL_NOT_ENOUGH`**（死を戻すだけでは戻らない。残りは死以外）。
- **死は毎回作り直されている**: F 1560 の検査は偶数（easy）課題の終端に当たり、各検査で第 2 層の 22.5〜39.5 unit（seed 中央値）、第 1 層の 4.5〜25 unit を再初期化する（`redo_checks.csv`）。この量は走の最初から最後までほとんど減らない（課題 2: 39.5、課題 30: 32.5）。再初期化の直後の死 l2 は 0（`dead_post_l2`）。**1 クラスの easy 課題のたびに第 2 層の約 3 割がそのクラスに対して黙り、ReDo はそれを出力の重み 0 で作り直す**ので、次の hard 課題は第 2 層の約 3 割が白紙の状態で始まる。
- ReDo の hard 課題の成績は t9 以降 .51–.53 で横ばい（R は .58 → .41 と下がり続ける）。**下がり続けるのは止めたが、水準が低い**。早期窓は R より低い（.5905 対 .6117、記述）。死を消しても mob（.41 対 SNA .80）と eff_rank（17.7 対 49.3）は戻っていない。
- 用量反応（較正 9 セル、seed 100–109、記述）: どのセルも死を .014 以下に消すが、点数は .469〜.559 で、再初期化の数が多いセル（F 100）ほど低い。seed ごとの「第 2 層の再初期化数」と後期窓の相関は +0.31（20 seed、記述）。
- 読みの限定: これは「この ReDo（τ 0.1・F 1560・直近 64 枚の標本）で死を戻したとき」の結果。死を戻す別の介入（扉 H・L2 Init）とは介入が違う。

## 範囲と限定

- **lr は 1e−4 に固定**（比較腕と同じ）。Kumar は 3 手法とも lr 1e−3 を選んでいる（CNN）。手法ごとに lr を選んだ比較ではない。
- **3 手法とも格子の端で選ばれた**（S&P は ε の下端・σ の上端、CBP は ρ の下端、ReDo は τ・F の上端）。格子は小さく（9・3・9）。事後に端の外へ 1 歩ずつ測ると、どれも選ばれたセルより低かった（上の事後の節）。それでも lr と他の次元は動かしていないので「調整し尽くしても負ける」とは言わない。言えるのは「文献の既定値を中心にした格子と、その端の 1 歩外の範囲では、SNA・KKT1・L2 Init に 12〜17 ポイント届かない」まで。
- 較正は 10 seed で、選択の雑音は残る。評価 seed 0–19 は選択に使っていない（held-out）。
- 手法の実装の選択（spec §2・§12）: S&P の雑音はプロセスに 1 つの CUDA generator（束ねに依存）、CBP は contribution utility・`accumulate=True`・bias を 0・要素ごとの Adam 更新番号（AdamGnT）・宿主の Adam 式、ReDo のスコアは直近 64 枚の訓練画像・bias の moment と更新番号は保持（Dopamine の実装どおり）。
- 死 l2 は課題の画像で測るので hard と easy で揺れる。ReDo の F 1560 の再初期化は easy の終端に当たるので、後期窓（hard）の死はその間の hard 1 課題の間に生じた分。
- 同じ箱の 1 セル（R/std/30 課題）の結果で、原典の CNN の箱や他の箱へは一般化しない。
