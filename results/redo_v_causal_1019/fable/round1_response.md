### 1. 何が確立していて、何が仮説を反証しうるか

**確立している(記述的事実)**
- リサイクル層2コホートは task3 末に 95% が p≥.99、85% が全開。平均 z は −0.01 → 7.96。
- その上昇の端点分解で 6.72/7.97 が ΔW·mean(h1) 項、bias 寄与はほぼゼロ。cos(W2, mean h1) 0 → .36。つまり「開く」経路は bias ではなく、**incoming W が h1 の平均方向(ReLU 出力なので非負・非中心)に揃う**こと。
- リセット直後は v=0 なので incoming 勾配はゼロ、v が先に成長する。コホートの v は小さく(.121 vs .596)、活性は大きく(8.85 vs 2.36)、入力中心化後のロジット寄与は小さい(.458 vs .959)。

**確立していない**
- (a) v=0 が全開化の原因であること(矢印1)。(b) 全開化が適応不良を媒介すること(矢印2)。(c) そもそも「ReDo の適応不良」が何に対する差分なのか(no-reset 基準との gap がこの窓で存在するか)。
- CE 分解(課題項 O(v) と制動項 O(v²))は軌跡上で未計測。
- 端点分解は因果経路の帰属ではない(ご指摘どおり)。

**仮説を反証しうる観察**
1. **v≠0 でも同じく全開化する**:v=0 は必要条件ではない。既存ログで無料に確認できる最重要コントロールがあります——**task1 でゼロから学習した層2ユニット**(初期化時 p≈.5、v はランダム非ゼロ)が task1/2 末に何%全開か。これが ~90% なら「非中心入力 + ReLU + Adam の一般的性質」であり、v=0 固有ではない(ただし h1 の統計量と訓練段階が異なる点は留保)。
2. **全開化を防いでも適応が改善しない**(矢印2の否定)。
3. **全開性を保ったまま (v, a) のスケールだけ変えると適応が変わる**:原因は「全開性」ではなく Adam 下の有効学習率/制動の弱さ(直接経路)。
4. **ラチェット説**:ReLU は閉側で勾配が止まり開側で流れ続けるため、平均 z の揺らぎは正側に吸収されやすい。これは v の値と無関係な機構で、矢印1と区別が必要(norm ladder に用量反応がなければラチェット/入力非中心性が主因)。

**全開性は良性でありうるか** — ありえます。全開ユニットは h1 のアフィン関数で、h1 自体が x の非線形特徴なので、x に対しては依然非線形な特徴です。死んだユニットと異なり全入力で勾配が流れ、後で閉じ直すことも可能(吸収状態ではない)。失うのは層2のゲーティング(区分線形領域数)だけで、定数オフセット ~8 は readout bias が吸収できます。したがって「全開=有害」を自明視してはいけない。害があるとすれば候補は (i) コホート全員が mean(h1) 方向を共有し出力が冗長(有効ランク低下)、(ii) 大活性 × 小 v の Adam 幾何(readout のステップ lr が活性 8.85 倍でロジットを動かし、制動 O(v²) が効かない)。(i)(ii) は全開性と相関するが同一ではなく、下の設計で分離します。

### 2. 最小で決定的な介入設計

**共通条件**:同一データ順・同一初期化・**第1リセットのマスクと新 W2 を原実行から強制**(以降のリセットは各 arm でネイティブに計算し、その旨を記録)。ランダム方向は seed ごとに固定し、norm ladder 間で共有。20 seed 対応化、seed 内差分の平均と 95% CI、符号検定を併記。各 arm で必ず記録:コホート p・全開率・mean z・cos(W2, mean h1)・活性 RMS・v ノルム・コホート活性行列の有効ランク・CE 分解の2項の軌跡。

**窓**:主評価は **task3 末の操作チェック + tasks 3–8 の適応指標**(次のリセットで新コホートが混入しマスクが分岐する前)。全30タスクは副次。適応指標は 5クラスタスクの (a) タスク末現タスク精度、(b) タスク内学習曲線 AUC(速度)。1クラスタスクは精度が自明なので損失のみ。前提として **A0 vs no-reset の gap がこの窓に存在するか**を先に確認(なければ媒介の問いは空虚)。

**P0(無料・既存ログ)**
- task1/2 のゼロからの層2ユニット全開率。A0 と no-reset の tasks 3–8 の差。

**P1 矢印1:outgoing 初期化の norm ladder(4 arm)**
- A0: v=0(原 ReDo)
- A2-s: v = s·u(u は seed 固定ランダム方向、s ∈ {0.05, 0.15, 0.6}; 0.6 ≈ 生存ユニットの典型ノルム)
- (任意) A2-old: 旧 v 保持(ReDo 既知変種として参考、意味不整合は承知の上)
- 即時のロジット撹乱を各 arm で定量(リセット直後の損失ジャンプ)。s=0.6 では ~0.6×1.65×√39 ≈ 6 のロジット変化が起きうるので、小さい s を含めるのが重要。
- 推定量:s に対する全開率・cos(W2, mean h1) の用量反応(矢印1)、同時に適応指標。

**P2 矢印2:全開化の予防(v=0 のまま)(2 arm)**
- A1: リセール時にコホートの incoming を **z = w·(h1 − μ) + b'** に再パラメータ化(μ はリセット時点の h1 平均をバッファから固定、b' = b + w·μ で順伝播は厳密に同一)。平均方向の移動は b' に集約され、Adam の lr 上限(1e-4×1560 ≈ 0.16)で事実上封じられる。これは分解の主項 ΔW·mean(h1) を直接標的にした、**順伝播保存・最適化幾何のみ変更**の介入で、恣意的クランプではない。
- A1-sham: μ を同ノルムのランダムベクトルに置換(再パラメータ化の副作用を統制、mean 経路は残る)。
- 操作チェック:A1 でコホート p が .5 付近に留まること。分布の歪みで w·(h1−μ) 経由で開く可能性はあるので必ず確認。

**P3 ゲージ試験:全開性固定で (v, a) スケールのみ変更(1–2 arm)**
- A3: task3 末にコホート j の (W2_j, b_j) を 1/c_j、readout 列 v_j を c_j 倍(c_j は活性 RMS が生存者中央値に一致するよう ~3.7)。ロジット・p・全開性は完全不変。Adam モーメントは整合的に変換(m_W/c, v_W/c²; m_v·c, v_v·c²)。A3-sham: c=1 で同じ操作を実行(実装統制)。c<1 の方向試験も有用。
- **意味**:Adam はゲージ不変でないため、「小さい v が原因」という主張は (v, a) の組としてしか定義できません。A3 が改善すれば、原因は全開性ではなく最適化幾何(直接経路)。改善しなければ、直接経路は棄却され矢印2が残る。v と a を別々に動かせないのは confound ではなく、この主張の正しい定式化です。

合計 ~8–10 arm × 20 seed、各実行は小 MLP の 23k 更新なので安価です。

### 3. 全開性の「応答保存」因果試験について

原理的な注意:全開性はデータ台上の**関数の性質**(アフィン性)なので、それを除去しつつ全入力で応答を保存することは定義上不可能です。だから「保存」は二通りにしか定式化できません。

- **予防時の順伝播保存**(推奨、= A1):介入時点で関数は同一、変えるのは勾配の経路のみ。これが最も恣意性が低い。
- **事後の予測保存(開いたままの入力集合上で)**:ユニット j の bias を分位 q の z だけ下げ(m_j)、同時に出力バイアスに m_j·v_j を加える。すると z>m の入力では予測が厳密に不変、q 割合の入力だけがクリップされる(= ゲーティングの導入そのもの)。単純な再中心化(補償なし)は、全入力で −m v_j のロジット定数シフトを与え、学習済み関数を壊し、bias の Adam 状態も陳腐化する——全開性ではなく「損傷」を測ってしまうので不可。
- 必要な統制:**損傷整合 sham**——mean(h1) に直交するランダム方向に W2_j を摂動し、即時損失増加を q 条件と一致させる(z 平均は不変なので全開のまま)。q ∈ {0.1, 0.3, 0.5} の ladder で、sham との差が q に伴って拡大するなら全開性除去の効果と言える。

### 4. 結論テンプレート

**支持パターン**:(i) P1 で s に対し全開率・cos が単調減少(矢印1)、(ii) A1 が A0・A1-sham より tasks 3–8 で改善し、操作チェックが通る、(iii) A3 が改善しない(直接経路棄却)。→「この設定では、outgoing ゼロ化が mean(h1) 方向への incoming 移動を通じて全開化を引き起こし、全開化の予防が適応を改善した。小 v/大活性の最適化幾何単独では説明できない。」ただし媒介の割合は seed 間の相関からは主張せず、A1 の効果量として報告。

**反証パターン**:
- P0 でゼロからのユニットも全開 → 「全開化は非中心 h1 + ReLU + Adam の一般現象で v=0 固有ではない」。
- A1 が全開化を防いでも性能不変 → 「全開性は良性(層1の非線形性により x に対しては有効特徴)。適応不良は別経路」。
- A3 が改善 → 「原因は Adam 下での (小 v, 大 a) ゲージ。処方は再スケール/制動であり、ゲーティング回復ではない」。
- gap 自体が無い → 「媒介の問いは成立しない」。

**優先順**:P0(即日)→ P1 → P2 → P3 → P4(任意)。現観察だけでは仮説は「もっともらしい機構記述」に留まり、因果主張は P1–P3 の結果を待つべきです。
