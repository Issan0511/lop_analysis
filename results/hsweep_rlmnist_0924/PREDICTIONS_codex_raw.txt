spec を読んだ上での独立した事前予測です。確率は主観確率、数値は各腕の **seed 中央値の点予測**です。小幅で削りは増えるものの、幅の停止までは起きにくいと予測します。

| 判定 | 確率 |
|---|---:|
| CAPACITY | 10% |
| LOSS_SET | 32% |
| PARTIAL | 30% |
| OTHER | 28% |

OTHER には、残留はほぼ一定でも B が指定範囲を外れる場合や、単調性だけ崩れる場合を含めます。

数値予測は当てはまり合格を条件としていません。h=8 の直交補はゼロなので、その f₁ は定義できません。

| 二値事象 | 確率 |
|---|---:|
| (a) h=8 が当てはまる | 25% |
| (b) h=16 が当てはまる | 80% |
| (c) 当てはまる腕のどれかで P2 通過 | 13% |
| (d) 最小の当てはまる h で f₁₀ ≤ .3 | 23% |
| (e) f₁₀ が h に対して単調非増加 | 1% |
| (f) 当てはまる全腕で、読まれる f₁ < 読まれない f₁ − .1 | 58%※ |
| (g) 当てはまる全腕で VΣ の傾き ≥ .5 | 70% |
| (h) 当てはまる全腕で VΣ(t50)/h ∈ [30,90] | 59% |
| (i) h=300 の f₁₀ > h=100 の f₁₀ | 70% |
| (j) 最小の当てはまる h の B > h=100 の B | 82% |

(e) は文面どおり「**h が増えるほど f₁₀ が下がる**」と解釈しました。逆方向、つまり spec の CAPACITY が要求する当てはまる腕での単調性なら **55%**。

※(f) は厳密には二値になりません。**成立58%、不成立17%、h=8 が当てはまるため未定義25%**。定義できる場合に条件づけた成立確率は約77%です。

理由は以下です。

- 残留は
  \[
  f_k=1+\sum_{j=1}^{k}
  \frac{\langle D_{s+j},D_s\rangle_\Sigma}{Q_s}
  \]
  です。小幅では負のラグ相関が強まると予想しますが、f₁₀≤.3 には累積で .7 以上の相殺が必要で、かなり強い変化です。
- \(W_3W_2\) の直交補は、一般には損失の零空間ではありません。実際の局所読み出しは活性化の傾きを含む \(W_3A_2(x)W_2A_1(x)\) で、入力ごとに異なります。したがって **h−9 だけで残留を決める説明には弱気**です。
- 厳密に
  \[
  V_{50}-V_{40}=(1-B)\sum_{t=40}^{49}Q_t
  \]
  なので、B が .98 付近でも Q が大きければ幅は増えます。B の上昇より、P2 通過には低い確率を置きます。
- 最も強い削りが出そうな h=8 は、当てはまりの門で除外されやすい。この選別も CAPACITY の確率を下げます。
