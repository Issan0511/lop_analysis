## 1. 結論

**一部のユニットを大きく動かして固定すると、触っていないユニットも動く。出力への影響は大きく補償される。ただし自己項の集団的な釣り合いを取り戻すとは限らない。**

主判定は leaky 幅100・少数固定・上下キックの対称平均で **INCONCLUSIVE**。自己項補償率の中央値 −0.200、seed bootstrap 95% CI [−0.274,+0.091]。正の補償を支持する結果ではないが、登録基準ではゼロを跨ぐため「補償がない」と確定もしない。

別の操作である全体への小キックでは、全4モデル・上下とも介入直後の全更新に戻す向きがあった。2000更新ではSnakeの平均前活性のずれは約98–99%解消した一方、leaky/ELUは約86–93%が残った。**集団の一様な移動への復元と、少数を固定したときの集団補償は別の応答。** モデル間の幅・中心化・lrが違い、活性化だけの効果とは判定しない。

## 2. 実施条件

既存5M checkpointから独立コピーを作った。
- leaky .1 / ELU: 幅100、各10 seed、中心化あり、lr=.01。
- Snake α=.75 / 1: 幅5、各20 seed、中心化なし、lr=.0036/.0037。
- 32入力を全列挙し、**タスク・入力支持・中心化平均・教師を固定**。full-batch二乗損失GD、float64、2000更新。
- 元のonline学習やタスク切替の再現ではない。元ログ・元重みには書き込んでいない。

各seedの代表標準偏差 σ を「各ユニットの入力に関する前活性標準偏差の中央値」と定義。
- 全体キック: 全ユニットの b を ±.25σ。
- 少数キック: 幅100では無作為な5ユニット、幅5では1ユニットの b を **±4σ**。対象選択の乱数を事前固定し、結果による選び直しなし。
- 幅100の5%と幅5の20%は異なる介入割合。

少数キックは3通りを測った。
1. **pulse:** 動かした本人も含め全員が学習。
2. **hold:** 動かした対象の W,b,v を固定し、他ユニットの W,b,v と出力バイアス c を学習。
3. **readout:** 全員の W,b と対象の v を固定し、他ユニットの v と c だけ学習。

各々に、**同じ固定マスクでキックだけしない対照（sham）**を置いた。全体キックは全員が学習する対照と比較。計11条件×4モデル、660 seed×条件。計算部分の壁時計は約30秒、CPU1thread。

## 3. 何を「補う」と測ったか

自己項は、同じネットワークの中だけで

$$S=\sum_i v_i^2 M_i,\qquad M_i=\mathbb E_x[\phi_i\phi_i'].$$

対象Tを固定すると、その自己項のキックによる変化 D_T は一定になる。他ユニットの対照との差 ΔS_other を使い、

$$C_S=-\frac{\Delta S_{\rm other}}{D_T}.$$

- C_S=1: 他ユニットが自己項のずれを全補償。
- C_S=0: 自己項の補償なし。
- C_S<0: 同じ方向に変わり、キックによるずれを増幅。

これは**元の対照軌道に対するずれの補償**。絶対的な S=0 への収束を示す指標ではない。絶対不均衡 ρ=|S|/Σv²E|φφ′| も併記する。

出力については初期キックの予測差 d0(x) に対する、他ユニット＋cの予測差の反対向きへの射影 C_out を使った。C_outが1に近くても直交方向の差が残り得るので、**全32入力上の予測差RMS／初期RMS**を別に評価した。以下の「出力差が何%残る」はこのRMS比であり、損失の改善率ではない。

## 4. 少数を固定したとき — 他のユニットは動いた

2000更新、各seedで計算してから中央値。前活性の応答は非Tユニットの対照との差のRMSをσで割ったもの。介入対象には変化を戻す自由度がない。

| モデル          | キック | 他ユニットの前活性変化 RMS/σ | 出力差が残る割合 | 自己項補償 C_S |
| ------------ | --- | ----------------: | -------: | --------: |
| leaky 幅100   | 上   |              .192 |     .78% |     −.326 |
| leaky 幅100   | 下   |              .041 |    1.37% |     +.137 |
| ELU 幅100     | 上   |              .154 |     .89% |     −.299 |
| ELU 幅100     | 下   |              .028 |    7.79% |     +.162 |
| Snake .75 幅5 | 上   |              .484 |    3.88% |     −.331 |
| Snake .75 幅5 | 下   |              .473 |    3.56% |     −.288 |
| Snake 1 幅5   | 上   |              .446 |    3.96% |     +.045 |
| Snake 1 幅5   | 下   |              .345 |    4.33% |     −.207 |

**「他の奴らも動く」は観測された。だが「自己項の釣り合いを取りに行く」はこの表と同じ意味ではない。**

例えば leaky の上キックでは、出力差は元の0.78%まで縮んだのに、他ユニットの自己項は初期のずれを32.6%増幅する側に動いた。絶対不均衡ρの中央値も、無介入対照 .174 に対して介入後 .776。出力がほぼ直ることと自己項が釣り合うことは分離している。

補償率はseed間に幅がある。特にELU下キックは対象の自己モーメント変化が小さくなり得て比が広がる。表の中央値だけから全seedが同じ動きと読まない。全seedの値とIQRはCSV・図に保存。

## 5. 主判定

事前登録した主endpointは **leaky、hold±、2000更新**。上下をまず各seed内で平均し、その10 seed中央値を取る。全10 seedで両方向の操作成立・有限完走を確認。

$$\operatorname{median}_s
\frac{C_{S,s}^{+}+C_{S,s}^{-}}2
=-0.2003,\qquad
95\%\ \mathrm{CI}=[-0.2739,\ 0.0910].$$

登録判定: **INCONCLUSIVE**。CIは0を跨ぎ、自己項を補うという正の効果を支持しなかった。「厳密な補償なし」や長期での不在の証明ではない。

上下の中央値 −.326/+ .137 を平均した値とは異なる。**seed内平均→seed間中央値**の順番が登録統計量。

## 6. 読み出しだけでも多くの出力差を補える

全ユニットの前活性を固定し、他ユニットの v と出力 c だけを更新した対照でも、2000更新で出力差RMSの残りは以下だった。

| モデル          | 上キックの残り | 下キックの残り |
| ------------ | ------: | ------: |
| leaky 幅100   |   5.81% |  13.64% |
| ELU 幅100     |   5.98% |  17.90% |
| Snake .75 幅5 |  10.57% |   9.84% |
| Snake 1 幅5   |   8.87% |   8.79% |

他ユニットの前活性も動けると、表§4のとおりさらに差が小さくなる。しかし**出力の帳尻を合わせるために、前活性だけが動く必要はない**。

自己項の対応差も、同時刻の対照読み出しを基準に「前活性分布の変更」と「vの変更」に代数的に分けて保存した。成分の中央値を足して全体の中央値を作らない。leaky上キックでは両成分の中央値とも補償と逆向きだった（幾何 −.116、読み出し −.214）。

c単独の出力補償射影は、他ユニットも動ける腕の中央値では多くが数%程度。今回の応答全体を「出力biasだけが直した」とは読めない。

## 7. 全体を少しずらすとどうなるか

全体±.25σのキックでは、介入直後の **全勾配による平均前活性の対応差**が、全4モデル・両方向・全seedでキックを打ち消す向きだった。自己項だけを測った判定ではない。

2000更新後に、無介入対照に対するずれが初期の何倍残ったか:

| モデル          | 平均前活性のずれ残存 上/下 | Sのずれ残存 上/下      |
| ------------ | -------------- | --------------- |
| leaky 幅100   | .863 / .860    | .469 / .375     |
| ELU 幅100     | .926 / .868    | .591 / .420     |
| Snake .75 幅5 | .0218 / .0206  | .0061 / .0082   |
| Snake 1 幅5   | .0091 / .0078  | −.0049 / −.0017 |

各seedで残存比を取ってから中央値。負の残存比は対照を少し越えたことを表す。

**今回のSnakeでは一様な集団移動への復元が強く、平均位置は元の軌道近くへ戻った。** しかし、Sの差がほぼ消えても、対照そのものの絶対ρは .34/.41 程度で0ではない。これは「自己項ゼロの平衡へ戻る」の証拠ではなく、「元の適応軌道へ戻る」観測。

幅・中心化・lr・元の学習状態も違うので、「Snakeという関数だけがこの違いを生んだ」「これがLoP耐性の原因」とはまだ言わない。

## 8. 解釈 — 集団応答の経路は何か

他のユニットへ初めて影響が伝わる経路は共有する出力残差である。介入直後、非Tユニット j の状態は同一だから、bias更新の差は

$$\Delta\dot b_j=-2v_j\mathbb E_x[d_0(x)\phi'_j(x)].$$

この関係とW版は実測勾配との差が検算を通った。**本人の自己項が変わったという情報が、独立した信号として他ユニットへ送られるわけではない。** ただし、この恒等式だけで長期的な集団配置が決まるわけではない。

今回の観測からは、「一部の配置が変わる→出力残差が変わる→他のユニットと読み出しが応答する」は確認できた。応答の結果として自己項が釣り合うかは別で、固定した少数への応答では普遍的な補償は観測されなかった。

これは距離補償という広い仮説をすべて否定しない。**出力を共同で補うことと、自己項の集団的な和をゼロへ戻すことを区別すべき**という結果。
