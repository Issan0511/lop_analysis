## 恒等式
z_i = W_i·Px + b_i、W_i = m_i·1 + W̃_i（ΣW̃_i = 0）とすると、置換 P の期待値で
  **σ²_i = κ‖W̃_i‖² + Var(S)·m_i²**、  κ = v̄ − c̄、 S(x) = Σ_j x_j（総インク）
v̄ = 画素分散の平均、c̄ = 画素間共分散の平均。cross 項 2m·Cov(S, W̃·Px) は ΣW̃=0 で消える。**自由パラメータなし**（データ定数のみ）。

## 読み
1. **W → σ の写像は活性化に依らない**。κ は 5 腕すべて 0.065–0.069（データ定数 0.0656）。活性化が変えるのは W の成分（‖W̃‖ と m）であって、写像ではない。
2. **§D-⑤「σ/‖W̃‖ の腕差」は全腕で解消**。ELU1 の 0.29 は幅ではなくオフセット項（沈下 m² × 総インク分散）が 89% を占めるため。
3. **σ は「幅」と「沈下の副産物」の和**。ゲートが関わる幅の項 σ_w は LIN 1.83 / LR 2.15 / ELU 2.1–2.2 / SNA 1.58 と腕差が小さい。深さ z̄/σ_w は LR −2.0、ELU1 −3.2、SNA −0.9、LIN 0。
4. 「z̄ = −1.7σ の直線」の σ にはオフセット項が混入していた。z̄ = m·E[S]、σ_off = |m|·sd(S) なので z̄/σ_off = −3.03 は機械的に決まる。幅→深さの主張は σ_w で言い直す必要がある（介入結果 width_depth_intervention は W̃ だけを掛けたので影響なし）。
