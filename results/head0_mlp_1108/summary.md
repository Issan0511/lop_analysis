1 隠れ層の乱数ラベル MNIST（784-100-10、Adam 1e-3・batch 16・4,000 更新/課題・30 課題、engine は push_direction_proof_0930）。切替ごとに、継続 S・head を 0 に戻す H0（重みと bias と head の Adam を 0、体はそのまま）・H0A（H0 に加えて体の Adam も 0）・新品 fresh を、同じラベル・同じミニバッチ順で 4,000 更新回した。判定は課題 21〜30、取り直しのばらつきから帯を出した。全行は `rows.csv`、判定の表は `judge.md`、早い切替は `early_switches.md`、図は `fig_head0_mlp_1108.png`。検査（S の再生は保存済みの課題末と max|差| = 0、10 走 × 30 課題）は全部通過。

## 1 結論（3 行）

1. head だけ 0 に戻しても、課題 21〜30 の漸近（更新 3,510〜4,000 の訓練精度）の遅れは leaky・SiLU・GELU で 7〜9 割、ReLU で全部残る（ρ_A 0.73〜1.00、BODY_SIDE）。ELU だけ 6 割が戻る（ρ_A 0.38〜0.39、LOADING_SIDE）。
2. head に加えて体の Adam 状態も 0 にすると（H0A、登録済みの副腕）、leaky は新品と同じ漸近に着く（ρ_A 0.01）。ELU は 8 割、SiLU は 3 割、GELU は 2 割が戻り、ReLU は戻らない。J1 の「体の側」は、leaky・ELU では体の重みでなく、体の optimizer 状態と閉じた unit が開き直す時間の側だった。
3. 早い課題（3〜10）では 5 活性化とも遅れはほぼ全部切替の事件で（ρ_A ≈ 0〜0.3）、前の課題への装填 log K − L が強いほど ρ_A は 0 に近い。課題が進むと体の側へ移る。ViT 箱の「課題 30 は head 側、課題 60 は体の側」と同じ順。

## 7 読み（事後。判定ではない）

- J1 の「体の側」には体の重みと体の Adam 状態の両方が入っている。H0A がそれを分けた。leaky では体の重みだけなら新品と同じ漸近に着き、ELU では 8 割、SiLU で 3 割、GELU で 2 割、ReLU で 0。
- この順位は、閉じた unit が勾配を通すかの順位と同じ。leaky 0.1 は閉じていても 0.1 倍の勾配を通す。ELU は float32 で z < −16.64 の unit だけが厳密に 0 になる。SiLU・GELU は z ≈ −20〜−25 で φ′ がほぼ 0。ReLU は 0。
- H0 が更新 1,000 で S より遅い理由は、体の Adam の v にある（`posthoc/bodystep.md`、課題 25、seed 0、4 活性化）。更新 1〜100 で体の勾配のノルムは H0 と H0A でほぼ同じ（leaky 0.013 と 0.018、S は 1.56）なのに、体の 1 更新の変位は H0 が H0A の 0.07 倍（leaky 0.006 と 0.083）・ELU 0.31 倍・SiLU 0.11 倍・GELU 0.15 倍。H0 の v は前の課題の値のまま（更新 100 で H0A の 100〜250 倍）で、更新 1,000 でもその 6 割が残る。head の変位は 3 腕で同じ。

| 活性化 | 体の変位 1〜100: S / H0 / H0A | 101〜1,000: S / H0 / H0A | 体の勾配 1〜100: S / H0 / H0A | 精度 4,000: S / H0 / H0A |
|---|---|---|---|---|
| leaky 0.1 | 0.101 / 0.006 / 0.083 | 0.061 / 0.013 / 0.091 | 1.56 / 0.013 / 0.018 | 0.62 / 0.71 / 0.99 |
| ELU | 0.149 / 0.017 / 0.056 | 0.041 / 0.045 / 0.083 | 1.53 / 0.014 / 0.015 | 0.42 / 0.75 / 0.87 |
| SiLU | 0.129 / 0.006 / 0.053 | 0.040 / 0.024 / 0.077 | 2.77 / 0.006 / 0.006 | 0.36 / 0.49 / 0.58 |
| GELU | 0.086 / 0.006 / 0.037 | 0.033 / 0.022 / 0.062 | 1.99 / 0.003 / 0.004 | 0.22 / 0.31 / 0.41 |

- V13 の段⑤への材料: MLP では head を 0 に戻しても遅れは 4/5 の活性化で残る（ViT では残らなかった）。残る遅れの担い手は、SiLU・GELU・ReLU では φ′ ≈ 0 の unit（体の重み）、leaky・ELU では体の optimizer 状態と閉じた unit が開き直す時間で、体の重みそのものは新品並みに戻せる。⑤の文の置き方は Issa の判断。
