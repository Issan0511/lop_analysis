## 読み（Issa: 「実は寄与しているのは負のほう」）
1. 全腕で z > 0 は恒等なので、腕の差は定義上すべて負側から来る。
2. **負側の中でも、効いているのは φ′（逆向きのゲート）で、前向きの値 φ ではない。**
3. 箱 B では近傍帯（z_c < z < 0）と深部（z < z_c）の片方だけでは効かず（小キメラ SMINH ≈ ELU1・`SMALL_EQUALS_ELU1`）、
   **負側のゲートが「0 付近で 1・深部で 0.1」の両方を持つときだけ**効く（`SUPERADDITIVE`）。

- GN = 前向き φ_LR・逆向き φ′_SMAXH、FN = 前向き φ_SMAXH・逆向き φ′_LR、GD = 前向き φ_ELU1・逆向き φ′_SMAXH、FD = 前向き φ_SMAXH・逆向き φ′_ELU1（spec §1.5）。
- 近傍の効果は**ゲートだけでほぼ全量**再現され、前向きだけでは逆に悪化する。深部の効果はゲートだけで約半分、前向きだけでは late 精度で ≈ 0。
- RL-MNIST でも、深部のゲートが飽和する ELU1・SMINH だけが 3/3 で床（online 10%）に落ち、深部 0.1 の LR・SMAXH は約 80%（`verdict.csv` の AT_FLOOR 行）。負側深部の φ′ が生死を分けている。

## 限界（この読みを引用するときに付ける）
- **事後・未登録。** D5a の登録規則は「前向きだけの腕が起点に留まる（|Y_F − Y_A| ≤ 2m）」を要し、FN が悪化したので満たさない。
- **FN の悪化は 2 通りに読める**: 前向きの値 φ_SMAXH が害なのか、前向きと逆向きの食い違い（勾配流でない学習）が害なのかを、この実験は分けない。GN も食い違っているのに改善したので「利点はゲート側」は頑健だが、「前向きの値は害」とは言えない。
- 分離腕は箱 B と SCR にしか無い（RL は段 2・未実行）。SCR の分離腕は向きだけの登録で、FD は 1 系列が発散して打ち切り。
- seed は 3。深部のゲートだけの効果（+0.19〜+0.39）は小さく、σ_traj を含めた m での分解は判定器の D5a 行を見ること。
