You are checking a short derivation for errors. Be adversarial: find any step that is wrong, any hidden assumption, any sign error. Answer in Japanese, concise, numbered to match the claims. For each claim give: 正しい / 条件付きで正しい（条件を明記）/ 誤り（理由と正しい形）.

Setting. MLP 3072-100-100-10: a1 = W1 x + b1, h1 = phi(a1), a2 = W2 h1 + b2, h2 = phi(a2), z = W3 h2 + b3, phi = leaky ReLU with slope 0.1 (phi(a) = phi'(a) a). Loss per sample: cross entropy L = -z_y + log sum_k exp(z_k), p = softmax(z). Minibatch loss = mean over a batch of 16. No weight decay.

Claim 1 (rescaling identity). For l = 1, 2 and any differentiable loss of z:
  <W_l, dL/dW_l> + <b_l, dL/db_l> = <W_{l+1}, dL/dW_{l+1}>,
and for the last layer <W3, dL/dW3> + <b3, dL/db3> = sum_k (p_k - y_k) z_k. Hence, ignoring biases, <W_l, -dL/dW_l> = sum_k p_k (z_y - z_k) for every layer l, which is > 0 whenever z_y is the strict maximum (sample correctly classified) and < 0 when the margin-weighted average is negative (e.g., right after a label switch when the new label's logit is far below the old label's).

Claim 2 (SGD conservation). With plain SGD, theta <- theta - eta g on the same minibatch loss, per step exactly:
  Delta(||W_l||^2 + ||b_l||^2 - ||W_{l+1}||^2) = eta^2 (||g_{W_l}||^2 + ||g_{b_l}||^2 - ||g_{W_{l+1}}||^2).
So first-order changes of the squared norms are equal across layers (up to bias terms), and only the second-order (squared step) terms can make ||W1||^2 grow relative to ||W3||^2. Consequence: over a sequence of tasks, if ||W3||^2 and the bias norms stay bounded, then the growth of ||W1||^2 per task equals the accumulated second-order terms eta^2 sum_steps (||g_{W1}||^2 - ||g_{W3}||^2) (plus bias terms). Observed in our runs: after the fit, SGD adds the same amount to all three layers (e.g., +2.8/+2.82/+2.82, +20.2/+20.07/+20.05 per task), and over whole tasks pure SGD grows ||W1||^2 by +16/task (IID) and +2.9/task (two alternating label sets) while ||W3||^2 changes by -0.25 and +0.25.

Claim 3 (Adam breaks it at first order). With Adam, u = eta * mhat / (sqrt(vhat) + eps) elementwise, the first-order term of Delta||W_l||^2 is -2 <W_l, u_l> = -2 eta <W_l ./ (sqrt(vhat_l)+eps), mhat_l>, which is not tied across layers by Claim 1, because the elementwise preconditioner reweights coordinates differently in each layer. Its sign is positive if the momentum is a positive combination of past minibatch gradients that each point outward (Claim 1, all samples correct, W changing slowly) AND the diagonal preconditioner does not rotate the vector much (e.g., sufficient: ||(D - cI) W|| * ||m|| < c <W, -m> for D = diag(1/(sqrt(vhat)+eps)), some c > 0). Observed: after the fit every Adam update had a positive outward component (cos(-u, W1) ~ 0.04, no negative ones), cos(G, G/sqrt(vhat)) = 0.988, and the post-fit growth per task was W1 +2634, W2 +115, W3 +3.9 (parameter counts 307,200 / 10,000 / 1,000).

Claim 4 (Adam's step does not shrink after the fit). Model: after the fit, the new squared gradients are negligible in vhat, so vhat(t) ~ vhat0 * beta2^t (beta2 = 0.999), sqrt(vhat) decays with time constant 2/(1-beta2) = 2000 updates. Let ||G|| ~ c L (cross entropy at large margins). Then dL/dt = -<G,u> ~ -eta c^2 L^2 / sqrt(vhat(t)), whose solution for large t is L ~ exp(-t/2000)/(const), and ||u|| = eta ||G|| / sqrt(vhat) tends to a constant. So the loss falls ~1 e-fold per 2000 updates (about 12 e-folds in 24,000 updates) with a constant step size. For plain SGD, dL/dt = -eta c^2 L^2 gives L ~ 1/(eta c^2 t), only logarithmically many e-folds. Observed: sqrt(vhat) time constant 1999-2002, loss time constant 1785-2002, Adam reaches ~12.4 e-folds per task, SGD 0.9-3.4 e-folds. When sqrt(vhat) << eps = 1e-8, u ~ (eta/eps) mhat = 1e5 * mhat, i.e., SGD with learning rate 1e5 (vs 0.001-0.03 in our SGD arms).

If vhat has decayed to ~0 and a gradient g arrives, then m = (1-beta1) g, v = (1-beta2) g^2, so (with bias corrections ~1 at large t) |u| = eta (1-beta1)/sqrt(1-beta2) = 0.1/0.0316 eta = 3.16 eta on every coordinate with g != 0, independent of |g| (as long as |g| >> eps/0.0316).
