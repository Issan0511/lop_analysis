# 中心主張 B の独立レビュー（2026-09-23）

## 1. 結論

**中心文（`author_memo.md` §「一番伝えたいこと」）は、そのままでは支持できない。ただし、四つの独立した部分に分けると、それぞれに定理級・介入級の強い版がある。**

- 「入力平均がある限り沈下は不可避」は定理として偽で、有限軌道でも反例がある。真の版は「ラベル切替時に、直前まで自信をもって正解していた個体は、自分の更新で下向きに押される」という条件付き定理と、その押しが戻りに勝つという箱ごとの経験的収支である。
- 「W 増大で幅が増えるから −∞ で勾配 0 の活性化は悪化する」は、幅の増大と負側輸送を分ければ半分正しい。幅の増大は活性化に依らず起き、それだけでは正規化した位置は沈まない。絶対深さが増すのは、第 2 層では上流が生成する平均 μ₂ が幅に比例して伸びるからで、その符号は切替が決める。
- 「幅で性質が変わらない kunekune」は厳密な恒等式として成り立つ。ただし追随するのは幅だけで、平行移動には追随しない。これは論文の主定理にできる。
- 「解決する」は、乱数ラベル CIFAR の 50 課題と 5+1 CIFAR の順位としては支持される。ただし 5+1 では kunekune の劣化量と fresh gap は ELU より大きく、「可塑性喪失を解決」ではなく「この箱で最上位群」が正確な言い方。

論文を担げる骨格は「経路（平均）・源（切替）・応答（尺度）」の三分離である。決定的に欠けている実験は一つで、**尺度だけを固定した kunekune（`--beta 0`）と、尺度だけを適応させた ELU** の対照である。これがないと「尺度の適応が機構」という中心文の最後の一手が観察止まりになる。

## 3. 証明と反例

**3.1 命題 A（符号の盲目性）。** 個体 i の自己更新による平均前活性の変位は、SGD で Δz̄_i = −η E[φ′(z_i) u_i (x·μ + 1)]、u_i = J_iᵀ(p − e_y)、J_i は下流の局所 Jacobian である。状態を固定して下流の列を J_i → −J_i に置き換えると、u_i → −u_i、勾配 → −勾配となり、Adam は m → −m、v → v で更新も符号反転する。μ も φ′ も変わらない。したがって μ ≠ 0 と φ′ の任意の性質だけでは Δz̄_i の符号は決まらず、符号は残差と下流感度の相関、つまり「損失がこの個体の応答する入力でその活性を減らしたいか」に住む。`drive.md` §12.2 の γ_i がまさにこの量である。

**3.2 有用な十分条件（切替一回・自己更新）。** 次の四条件で SGD の自己変位は負になる。(i) 全標本で x·μ + 1 > 0、非負入力なら自動。第 2 層でも第 1 層が ReLU か leaky なら a₁ ≥ 0 で自動、ELU なら a₁ ≥ −1 で崩れ得る。(ii) 標本上で φ′ ≥ 0、GELU・SiLU の谷（`drive.md` §12.3 の V 枝）は逆向きに寄与する。(iii) 切替前の確信 ε_o が小さく、旧 logit への局所寄与が残差上界を超える、T_i > R_i。(iv) Adam なら履歴条件 Q_i^D > 0。これは `drive.md` §12.4–12.5 と同じ内容で、私の検算でも成立する。ここで非対称性は使っていない点に注意されたい。符号に要るのは φ′ ≥ 0 であり、非対称性が効くのは次の戻りの段階である。

**3.3 整流の位置。** 押しは個体が正側にいる間、φ′ = 1 の重みで起きる。戻りは負側で要求され、φ′(−D) の重みで起きる。固定尺度なら φ′(−D) → 0 なので戻りだけが消える。これが「非対称微分」の正しい役割で、沈下の源ではなく戻りの弁である。ただし Adam は個体の勾配を定数倍しても更新を変えないので、この弁は部分的にしか効かない。`drive.md` §2.5c の閾値 odds ∝ a^0.47、押し上げ枝 ∝ a^0.3 がその実測である。

**3.4 反例 1（構成・証明可）。** 非負入力 x₁ = (1,0)、x₂ = (0,1)、μ = (½,½) ≠ 0、隠れ 1 個体、読み出し v > 0。課題 A で y(x₁) = 1、y(x₂) = 0 を学ぶと w₁ > 0、w₂ < 0 となり x₂ は負側に座る。課題 B で x₂ のラベルだけ 1 に変える。x₁ では確信して正解のままなので押しは小さく、x₂ では leaky・ELU なら φ′ = a > 0 で u < 0、Δw₂ > 0 となり z̄ は上がる。前提は満たすが沈まない。ReLU では φ′ = 0 で x₂ から w₂ への経路が無く、bias 経由でしか戻れない。つまり吸収性は ReLU 固有で、非対称性一般の帰結ではない。一般化すると、変わるラベルが個体の負側入力に集中し、読み出しの符号が新要求と合えば自己変位は上向きになる。乱数ラベルではこの寄与は平均ゼロで、正側の押しが勝つ。

**3.5 反例 2（有限軌道・記録済み）。** PM 箱の Adam・leaky/ELU/Snake は `drive.md` §10 表で p⁺ が 100 課題間 0.12–0.39 に留まり、ELU の死は t400 で 3–9/100 で頭打ちである。層別キメラの `LL` は第 1 層が d₁ = −2.13 まで沈んでも 0.728 を保つ（`results/layer_chimera_cifar_0921/summary.md` 読み 2）。前提が成立しても「低勾配側へ全入力が運ばれる」は起きていない。

**3.6 定理 1（尺度の恒等式・厳密）。** コードの四種すべてについて、任意の s > 0 で φ_{α/s}(sz) = s φ_α(z)、φ′_{α/s}(sz) = φ′_α(z)。証明は z + sin²(αz)/α が (z, α) → (sz, α/s) で 1 次斉次であること、帯の境界が θ = 2αz で書かれていること、KKT1 の右側 z + 1/α も同様に斉次であることから直ちに従う。EMA が幅を正確に追い clip が効かなければ α_t σ_t = 0.6 が保たれ、微分の分布は正規化前活性 ζ = z/σ の関数 1 + sin(1.2 ζ) だけで決まる。

**3.7 定理 2（固定尺度の退化）。** ReLU・ELU・SiLU・厳密 GELU について、ζ ≠ 0 で φ′(σζ) → 1{ζ > 0}、φ(σζ)/σ → max(0, ζ)。裾は `fixed_scale.md` §3.3 の表のとおりで、私の検算では SiLU′(−D) ≈ −(D−1)e^{−D}、GELU′(−D) ≈ −Dϕ_N(D) を確認した。点ごとの零点は ELU′ > 0 で無し、SiLU′ は z ≈ −1.28 で符号反転、GELU′ は z ≈ −0.75 で符号反転、KKT1′ = 1 + sin θ ≥ 0 は θ = −π/2 で接する零点一つで負にならず、帯外では 1。

**3.8 系。** 正規化座席 z̄/σ を固定して σ → ∞ とすると、|φ′| > ε の (個体, 入力) 割合は固定尺度クラスで P(ζ > 0) へ収束し、KKT1 では不変。これが中心文の「幅によって性質が変わらない」の最強の数学的な形である。

**3.9 定理 1 の限界（本文に必須）。** (a) 平行移動: θ̄ = 1.2 z̄/σ で、z̄/σ が −5.2 を下回るか 2.6 を上回ると分布は帯外の傾き 1 へ出る。勾配は失わないが入力依存の非線形性を失い、片側化した leaky と同じ状態になる。観測された座席は −1.1〜−1.4 で帯内。median θ ≈ −1.0〜−1.4 は微分の零点 θ = −π/2 の近くに座っており、mob ≈ 0.55 は θ の広がり 1.2 での 1 + E[sin θ] と整合する。(b) EMA: 時定数約 100 更新で、30,000 更新の課題に対して無視できる。ただし t1 の最初は V₀ = 1 から出発する。(c) clip: α ∈ [0.005, 3] は幅 [0.2, 120] に対応し、中央値 5–63 では効かないが裾の頻度は summary に無い。(d) Adam は尺度不変でない。KKA23 の K2 が両条件で有意差を出したのがその証拠で、「応答場が尺度不変」と「学習が尺度不変」を混ぜてはいけない。(e) 適応 Snake も E[φ(z)] は幅に比例して伸びる。μ₂ の生成は kunekune でも起きており、違いは絶対深さへの応答だけである。

**3.10 格の区別。** 定理: 3.1、3.2、3.6–3.8、`fixed_scale.md` §3.3。観測: 13 腕、キメラ、A6 帳簿、switch_push 時間表、quiet drift。介入: relu_doors、cap_cifar、resp_cifar S4、switch_push Q1、neffdir。機能: 低応答 ≠ LoP は A6 の t2 対 t3、LN の全開ゲートでの崩壊、LK001 の床付き崩壊が示す。

## 5. 論文の骨組み案 3 つ

**A. 機構論文: 経路・源・応答の三分離**

主張: 負側飽和は、平均という経路、切替という源、固定尺度という応答弁の積である。図 1 は恒等式と初期片側率、図 2 は切替直後の押し（A2 境界集中と switch_push の時間表）、図 3 は帳簿と cap12、図 4 は定理 1 と 2 の微分質量曲線、図 5 は 13 腕、図 6 は S4 両方向。risk: A2 の頻度が上向き優勢で、駆動の記述が事後に寄る。cap2 の自己項が上向きになる理由が未説明。活性化が輸送速度を変える交絡。

**B. 設計論文: 尺度適応で応答場を不変に保つ**

主張: 定理 1 が保証する不変性が可塑性を保つ。図 1 は σ を変えたときの微分プロファイル、図 2 は 13 腕、図 3 は固定尺度 kunekune 対 適応 ELU の対照、図 4 は 5+1 と L2 Init、図 5 は帯外流出と平行移動の限界。risk: 対照が未実施で、それなしでは観察論文になる。K2 が示すとおり Adam は尺度不変でなく、KKA23 の差を説明できない。5+1 での劣化は残る。

**C. 幾何論文: 平均の幾何を介入設計に使う**

主張: 外部の平均も生成された平均も同じ経路で、層ごとに塞ぐ必要がある。図 1 は A5 の初期片側率予測、図 2 は C/CH/CS/LN の梯子、図 3 は 200 課題の CHB、図 4 は 5+1 の H と予算 ×10 の逆転、図 5 は平均を許容する側の解として kunekune。risk: 中心化の効用自体は先行研究にあり、新規性は層別対照に限られる。LN の解釈 G1 は撤回済み。予算依存で結論が動く。

三案とも、著者の「機構から設計へ」の順序に合う。担ぎやすさは B が最も高いが、必要 3 の対照が前提になる。A は現在の証拠だけで書けるが、中心文をかなり弱めることになる。
