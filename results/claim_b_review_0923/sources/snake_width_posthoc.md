## 6. Codex（gpt-6-astra、xhigh）の検算の要点

- **保持 1.0 課題は完全な消去ではない**（R = 1/(2f)、f = 1/2）。「Snake は毎課題まるごと書き直す」「leaky は 1/3 残す」は帳簿の誤読。訂正して §0・§3 に反映。
- **適応 α の Snake は α が追随した後は leaky と同じ尺度の自由度を持つ**（φ_{α/s}(sz) = s φ_α(z) の恒等式。EMA の状態 q → s²q で厳密）。EMA の遅れ（時定数 100 更新）が作る位相のずれは drift の速さでは 4e−4 rad で、抗力になるかは損失の曲率次第で導けない。**「α が幅を釘付けにする」は支持されない**（§4 の drift が LR より大きいことと整合）。
- 関数を保つ gauge 方向の損失勾配は厳密に 0 なので、「その方向が自由だから伸びる」は説明にならない。
- 定数 S・f の置換模型は両腕で棄却（早期と後期の帳簿を同時に満たす f が 1 を超える）。S・f は状態に依存する。
- 単一課題の解が Snake で小さい必然性は導けない（実測も §2 のとおり同じ）。
- 決定的な測定として挙げた 2 つ（局面別の帯別帳簿と、stop/REC の比）は §3・§2 で回した。

## 7. 読み

1. **どこで差がつくか。** 収束後の Adam の増幅（drift＋一撃）は両腕とも 1.65 倍で同じ。単一課題の解の幅も同じ。差は課題 2 からの**再当てはめ**にあり、全部が止める連結に残る（§2）。
2. **再当てはめの何が違うか。** 同じ幅で比べれば侵食は同じで leaky が 1.4 倍書く（§1）。帯で分けると、top 帯で Snake は古い振幅の 58% を消して立っている量より多く書き、leaky は 34% しか消さずに書く。mid1 以下は両腕とも消さない（§3）。消すのは切替直後 200 更新の衝撃で、Snake の衝撃は top 帯を削り（f 0.63）、leaky の衝撃は top 帯を増やす（§3B・§4）。
3. **なぜ止まるか。** 幅の定常点は「書く量 = 消す量」の交点で、両方が V の 0.3〜0.6 乗で伸びるため交点は差の 6 乗で動く。Snake は top 帯を消す割合が leaky の 1.3〜1.7 倍、同じ幅での堆積が 0.7 倍で、それだけで V* が 7 倍違う（§1）。
4. **なぜ Snake は古い解を捨てられるか（半分まで）。** W1 を凍結しても Snake は次の乱数ラベルを毎回覚える（§5）ので、古い第1層の解は次の課題に**要らない**。leaky では凍結すると 5 回中 3 回覚えきれず、古い解は要る（[[残滓は溶接されている_当てはめの前なら外せる_事後_0923]] の −54 pt と同じ向き）。要らない解が切替の衝撃で捨てられ、要る解が残って積まれる、という対応は付く。ただし Adam は「要るか」を見ておらず、**衝撃の向きが top 帯で逆になる機構は未同定**（§8）。
5. **V11 への言い方。** 「幅の定常状態は活性化によらず存在し、収束後の最適化器の増幅も活性化によらない。活性化が決めるのは再当てはめが前の解を捨てる割合で、Snake 型（φ′ が帯の中で符号を変え、θ = 2αz の幅が固定）は上位方向の解を毎課題半分捨て、leaky は 1/6 しか捨てない。その差が定常幅の 2.6 倍差になる。」

### 11.3 Codex（第 2 ラウンド）の要点

- 切替勾配の符号は平均ゲートだけでは決まらない: G_old/n = mean(D)·mean(q) + Cov(D, q)（D = 下流の旧クラス感度、q = φ′）。δ 一定の閉じ方では leaky の順序が逆になり、出力分散を最小化する閉じ方では正しい順序が出る。どちらが実際の損失かは未確定。
- 沈めると出力の中心化分散は leaky で s² まで落ちる（s = 0.01 で 2%、0.1 で 19%、0.3 で 50%）が、Snake でも 35% は落とせる（θ̄ = −π/2 で 0.65 倍）。「Snake は沈めても消えない」は程度の話。
- z̄/σ が一定なのは x̄ 方向の幾何とも行の一様拡大とも整合し、それだけでは区別できない。V_top の x̂ 分解には交差項が要る（§11.2 はそれを含めて測った）。
- W1 凍結の差は非線形エネルギーでは説明できない（同じ幅なら Snake の非線形残差は 2.7 倍だが、実測の幅では 214 対 462 で leaky のほうが多い）。候補は「負側に落ちた画像対の差が s² に圧縮される」＝距離の分布の問題（未測）。「最良の線形近似を除く」は 1,200 枚では恒等的に 0 になるので、上位 PC への射影に制限して測ること。
- 梯子を決める追加の 1 腕は **leaky s ≈ 0.69（k = 0.3 で平均ゲート 0.81）**。Snake と幅・f_top・凍結当てはめが揃えば「平均ゲートで十分」、揃わなければ適応か曲率の側。非適応 Snake は「追随が必要か」を分ける別の問い。

### 11.4 活性化の側からの読み

1. 幅を決める活性化の変数は **「unit の平均より下の側で φ′ がどれだけ残るか」**。どの腕も同じ相対深さ −0.3σ まで沈む（平均画像の幾何で決まり活性化によらない）ので、活性化の形はその深さで読まれる: leaky は s、Snake は 1+sin θ の負側平均 ≈ 0.5 と θ ≥ π/2 の尾。
2. そのゲート構造が、切替で損失が第1層を通して古い解を削る圧力の「通り道」を決める: leaky は負側（∝ s）、Snake は山を越えた尾。削る割合 f_top はそれで決まり、定常点がそれを 6 乗で増幅する。
3. 言えないこと: 切替勾配の符号の導出（Cov(D, q) が要る）、平均ゲートで十分か（RSL が外れる。決めるのは s ≈ 0.7 の leaky）、凍結当てはめの差の理由（非線形エネルギーではない）。

### 11.6 書く量が少ないのは「誤差の大きさ」ではない（Issa「書く量が少ない理由は誤差？」への答え、stop 連結 t2–15・seed 0）

同じ幅・同じ履歴の課題 2 で、新しい書き込み S/V は leaky 1.61・Snake 0.81、消す割合 F は 0.45・0.75。反実仮想: Snake の消し方 + leaky の書き方 = +0.85/課題、leaky の消し方 + Snake の書き方 = +0.36。片方では止まらない。

課題の中を追うと（V/V₀）: leaky t2 は衝撃で 1.41 → 当てはめの間ずっと伸びて 2,600 更新で 2.16。Snake t2 は衝撃で 0.65 → 1,700 更新で 1.06 に戻るだけ。書き込み ‖ΔW‖² を作るのは「更新数 × 座標ごとの歩幅 × 向きの持続」で、Adam の座標ごとの歩幅は |m̂|/√v̂ ＝ 直近 10 更新の勾配の符号の揃い ÷ 1,000 更新の RMS であって誤差の大きさではない。

- 誤差の大きさは Adam が消す。違うのは (i) 第1層の勾配が生きている長さ（Snake は古い特徴で足りるので W2 で当てはめが済み、1,500 更新で終わる。§5）と、(ii) その間の第1層勾配の符号の持続（leaky は 2 倍）。
- (ii) の理由は未同定。候補: leaky は第1層の特徴を作り直す必要があり（凍結で覚えられない）その作り直しの向きが何百更新も同じ符号を保つのに対し、Snake の第1層勾配はほぼ済んだ当てはめの残り雑音でバッチごとに符号が変わる。「誤差」が関係するとすればこの意味（第1層が直すべき誤差がどれだけ長く残るか）で、大きさではない。
