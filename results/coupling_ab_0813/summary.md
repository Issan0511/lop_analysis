# coupling_ab_0813: Path B → Path A 結合ダイナミクス — 結果サマリ

2026-08-13 実行。実験(5)。4指標同時計測: ①srank(W) (stable_rank_W) ②切替直後誤差
E[e²] (postswitch_err, 境界後10step) ③tr C(w) (trC_W) ④dead_frac。
condA/B × width {5,100}、T=K=1e4 (100 タスク境界)、1M step、seed 5本。
順序統計は各指標の半立ち上がり時刻 t50 の seed ブートストラップ (stats_summary.md)。

## 判定: 因果連鎖 ①→②→③→④ は「部分支持 + 重要な修正」

### 支持された部分

**(a) ① srank 低下が連鎖の先頭 — 強く支持。**
srank_drop < post_err は発現した全セルで P ≥ 0.99 (A_w5 +127k step /
A_w100 +198k / B_w5 c0 +118k / B_w5 c2 +134k / B_w100 c2 +236k)。
Path B (低ランク化) が他の全指標に 10⁵ step オーダーで先行する。

**(b) 切替イベントが diffusion を即時注入し (③)、dead を階段状に増やす (④) —
ミクロレベルの ③→④ は明確。**
イベント整列図 (fig_cp_event_*) で、全セルとも境界直後 ~100 step で trC が
ジャンプ (Δlog₁₀ 0.4–3.2) し、同じ窓で dead が増える
(A_w100 早期: +0.022/切替が 300 step 以内に完成、B_w100 c=2: +0.003/切替)。
Path A は連続的でなく**境界イベントでパルス的に進行**する。

**(c) Path B の進行が切替ノイズ応答を増幅する — A_w5 で観測 (結合の直接証拠)。**
A_w5 の切替後 trC ジャンプは 学習後期 (Δlog₁₀ ≈ 1.6) ≫ 早期 (≈ 0.4)。
同じタスク切替でも、低ランク化が進んだネットほど大きな diffusion を受ける。
これは「Path B が表現力を奪う → 同じ非定常性がより大きなノイズになる」という
先生の結合仮説そのもの。ただし A_w100 では逆転 (早期 3.2 ≫ 後期 1.1) —
後期は 97% dead でネットがほぼ無反応になるため (飽和による頭打ち)。
condB では位相依存なし (early/mid/late が重なる)。

### 支持されなかった部分

**(d) マクロな媒介順序 ② post_err ↑ → ③ trC ↑ は不支持 (逆転)。**
A_w100 (P=0.0007, trC が 274k step 先行)・B_w5 両 c (P<0.004, ~120k 先行) で
trC の立ち上がりが post_err より早い。A_w5 のみ仕様の順 (P=1.0)。
trC のマクロな上昇は「表現力低下の帰結」ではなく主に**境界応答の直接和**であり、
切替の瞬間に発生する (媒介変数を挟まない)。

**(e) マクロな ③ trC → ④ dead の順序は方向は正だが有意でない。**
A_w5 P=0.74 / A_w100 P=0.90、CI が 0 を跨ぐ (seed 5本では検出力不足)。
ミクロレベル (b) がこのリンクの実質的な証拠。

## 修正された機構像

タスク切替 →(即時)→ trC スパイク →(数百 step)→ dead 増分パルス、の**イベント駆動連鎖**が
Path A の実体。Path B (srank 低下) は最初から静かに進行して全体に先行し、
(A_w5 では) 切替あたりのノイズ注入量を増幅する「地盤沈下」として効く。
「①→②→③→④ が順にピークを迎える単線カスケード」ではなく、
「遅い ① が イベント駆動の ③→④ パルス列の振幅を変調し、② は ① の帰結として遅れて現れる」
という二時間スケール構造が正確な描像。

## 補足

- B_w5 は dead が発生せず (trC→dead は n=0)、B_w100 c=0 は srank/post_err とも
  発現が弱く順序判定不能 (P=0.39)。連鎖全体が観測できるのは condA と B_w100 c=2。
- dead_frac と srank_drop は A_w100 でほぼ同時進行 (トレンド図で重なる)。dead 化した
  ユニットの行が W の実効次元を直接下げるため、④→① の逆向き寄与も混在している点に注意
  (この分離は今後の課題: dead 行を除いた srank の再計算で切り分け可能)。
