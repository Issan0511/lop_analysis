2026-08-13 実行、同日 v2 改訂。v1 の見出し「srank 低下が全指標に先行」は
**隣接ペア検定の連鎖推論による過大主張**だったため、(i) 全ペア順序検定への変更、
(ii) dead 行除外 srank (`stable_rank_W_alive`) の追加計測 (全 4 グループ再実行) で再計算した。

4指標: ①srank(W)=stable_rank_W (+dead行除外版) ②切替直後誤差 E[e²] (境界後10step)
③tr C(w)=trC_W ④dead_frac。condA/B × width {5,100}、T=K=1e4、1M step、seed 5本。

## 主結果: 結合の向きは条件依存 — 「B→A」と「A→B」の両レジームが存在する

t50 (半立ち上がり時刻、seed 平均):

| セル | 順序 (t50) | 判定 |
|---|---|---|
| A_w5 | **srank(19k)** → dead(111k) → trC(128k) → post_err(146k) | **B → A** (仕様の向き) |
| B_w100 c=2 | **srank(12k)** → post_err(248k) → dead(304k) | **B → A** (仕様の向き) |
| A_w100 | **trC(44k) → dead(70k) → srank_alive(80k)** → srank(120k) → post_err(318k) | **A → B** (逆向き) |
| B_w5 両c | srank ≈ trC (~20-60k) → post_err、dead 不発 | B のみ発現 |
| B_w100 c=0 | 全指標弱発現、順序判定不能 (P≈0.42) | 判定不能 |

### A_w100 の逆順は ④→① アーティファクトでは説明しきれない (本実験 v2 の主発見)

dead 行が srank を機械的に下げる逆流を除くため、dead 行をゼロ化した
`stable_rank_W_alive` で再計算した結果:

- 除外により srank の t50 は 120k → **80k** に前倒し (機械的寄与はギャップ 50k のうち
  約 40k を説明)。
- しかし **dead(70k) は alive-srank(80k) にまだ先行**する。全 5 seed で同順、
  P(dead 先行)=1.000、ラグ −9.7k step、95%CI [−14.9k, −4.8k]。
- つまり A_w100 では「生き残りユニットのランク崩壊」より先に dead 化が進む。
  ノイズ増大 (trC 44k) → dead パルス蓄積 (70k) → 生存者の整列・低ランク化 (80k)
  という **Path A 主導**の系列が正しい。

**condA は width で結合の向きが反転する**: w5 は srank が dead に ~92k 先行 (B→A)、
w100 は dead が srank に ~10k 先行 (A→B)。狭いネットは表現力の底が浅く先に
ランクが崩れ、広いネットは吸収壁への到達 (dead) が先に進む。

### 一般に成立するのは「srank → post_err」のみ

srank_drop < post_err は発現した全セルで P ≥ 0.99 (ラグ +118k〜+236k)。
v1 の「全指標に先行」はこの限定された主張に訂正する。

## イベントレベルの所見

**(a) 切替は trC を即時ジャンプさせ (Δlog₁₀ 0.4–3.2、~100 step 以内)、dead を
階段状に増やす** (A_w100 早期 +0.022/切替、B_w100 c2 +0.003/切替)。Path A の進行は
連続ではなく境界イベント駆動のパルス列。

**帰属の留保**: trC_W は eval バッチの per-sample 勾配分散 (診断量) であり、訓練は
batch=1。境界の dead パルスが diffusion 由来か、drift の過渡的押し込み由来かは
本実験では区別できない (fullbatch_0812 で w100 full-batch でも dead=0.58 が出る事実は
drift 経路の実在を示す)。判別には **full-batch 訓練 + 本実験の coupling 窓**で
イベント整列 dead パルスが残るかを見る実験が必要 (batch: full は実装済みで即実行可)。

**(b) A_w5: ノイズ注入は後期ほど増幅されるが、dead への変換ゲインは減衰する。**
切替後 trC ジャンプは後期 (Δlog₁₀≈1.6) ≫ 早期 (≈0.4) で、低ランク化が進んだネット
ほど同じ切替から大きな diffusion を受ける (Path B → ノイズ増幅の直接証拠)。
ただし dead のイベント応答は早期 +0.01、中期・後期は ≈0〜微負 (復活気味) で、
「後期ほど dead も増える」わけではない。③→④ のゲインは一定でなく、生存ユニットの
壁からの距離とともに減衰する。A_w100 では逆に trC 応答が早期 3.2 ≫ 後期 1.1
(97% dead による飽和)。

**(c) µ が切替イベントの性質を反転させる (B_w100、新規)。**
srank のイベント応答は c=0 で切替直後 **+0.42 の多様化キック**の後に減衰、
c=2 では即時に**単調圧縮** (後期 −0.25 まで)。共通ドリフト µ の有無が
「切替＝ランク回復の機会」を「切替＝圧縮の加速」に反転させる。
先生の「µ = 両 Path の増幅因子」仮説のイベントレベルの直接証拠。
(w5 では両 c ともキック正 → 反転は w100 で顕著)。

## 検定手法の教訓 (v1 からの修正)

- **隣接ペアのみの順序検定は非単調指標を挟むと連鎖推論が壊れる**。v2 は全ペア行列。
- post_err は非単調 (A_w100 で 0.55M 頂点後に下降) で t50 が脆い。
- そもそもイベント時間スケールでは C(w) ≈ σ_e²·E[xxᵀ ⊙ gate v²] の恒等により
  ②誤差と③勾配分散は同一量の二つの読み出しであり、マクロ t50 での ②→③ 因果検定は
  概念的に不適切だった。②→③ は「検定対象」から「定義的連動」に格下げする。

## 修正された機構像

タスク切替 →(即時)→ trC スパイク →(数百 step)→ dead 増分パルス、のイベント駆動連鎖が
Path A の実体 (diffusion / drift の帰属は未決)。遅い srank 低下は (i) post_err には
常に先行するが、(ii) dead との先後は条件依存で、w5/条件B では B→A、A_w100 では
A→B (dead が生存者ランク崩壊に先行)。「単線カスケード」でも「常に B が先」でもなく、
**幅と入力統計 (µ) がどちらの Path が先に走るかを決める二方向結合**が正確な描像。
