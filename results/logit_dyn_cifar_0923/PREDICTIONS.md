# logit_dyn_cifar_0923 — Claude の予測（計算の前）

書いた: Claude (Opus 5.5), 2026-09-23 夜。格: 事後（既存のスナップショットの再計算）。Codex の予測は取っていない。
依頼: Issa「3 層目のソフトマックス関数に通す前がどう変化してるのか調査してください」。
対象: 第 3 層の前活性 z = W3 a2 + b3（logit）を、保存した重みと各 seed の 1,200 枚から float64 で計算し直す。
データ: sgd_postfit_cifar_0923（A = LR_iid と bit 一致、F、S_hi、A_ce、SA_iid、SA_abab、交差 fork の切替時点）と altlabels_cifar_0923（LR_abab）。
中心化した logit zc = z − mean_k z、広がり s = 画像平均の std_k(z)、余白 m = z_y − max_{k≠y} z_k、M = Σ_k p_k (z_y − z_k)。

| # | 予測 | 確率 |
|---|---|---|
| L1 | A の課題末の広がり s の比 t41–50 / t5–14 が 1.1〜1.8（同じ期間の ‖W1‖ の比は約 2 より小さい） | 0.70 |
| L2 | t41–50 の課題末の広がり s の順が A > S_hi > F | 0.60 |
| L3 | 押し（W_sw → W_end、同じラベル）は logit をほぼ一様に拡大するだけ: cos(zc_end, zc_sw) ≥ 0.95（50 組の中央値） | 0.70 |
| L3b | その拡大率 c = ⟨zc_end, zc_sw⟩/‖zc_sw‖² が 1.5〜3 | 0.60 |
| L4 | 次の課題の最初（W_end、新ラベル）の M の平均は、押しの前（W_sw、新ラベル）の 1.5〜3 倍負 | 0.60 |
| L5 | logit の空間では、次の当てはめが押しの変化の 6 割以上を打ち消す: −⟨Δz_ret, Δz_push⟩/‖Δz_push‖² ≥ 0.6（重みの空間では 0.22） | 0.65 |
| L6 | 当てはめ後、押しは関数に跡を残さない: 旧ラベルが 2 位になる割合の差（押しあり − なし）が ±3 pt 以内 | 0.60 |
| L7 | ABAB の Adam: logit の空間の往復 cos(Δz_AB, Δz_BA) ≤ −0.8（重みの空間の −0.40 よりずっと逆向き） | 0.65 |
| L7b | ABAB の全部 SGD: logit の空間の往復 cos ≤ −0.9 | 0.80 |

根拠（短く）: 収束後の Adam の押しは外向き（W の向きの拡大）が一次の主で、logit は各層について 1 次同次なので、同じラベルの間は logit の拡大として見えるはず。次の当てはめは新ラベルの余白を作るために旧ラベルの自信を消す必要があるので、関数の空間では押しの効果をほぼ消す。重みの空間で 8 割残るのは、その残りが 1,200 枚の logit にほとんど効かない向き（関数的に静かな向き）にあるから、という読み。
