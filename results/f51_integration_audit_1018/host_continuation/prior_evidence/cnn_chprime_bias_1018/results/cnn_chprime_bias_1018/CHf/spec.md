## 6. CNN の全特徴中心化 CH′ にチャネル幅に合わせた bias 抑制

**run id:** `cnn_chprime_bias_1018`  
**推奨ファイル:** `specs/spec_cnn_chprime_bias_1018.md`  
**継承:** P181 `cnn_center_relu_1011`、P183 `cnn_center_feat_1011`。原稿の対応先は現稿付録H.2。

### 6.1 問いと、層共通WDを採らない理由

CNN/RC/raw/ReLU、30課題、seed10–19。CH′にbiasへの操作を足したとき、付録H.2と同じ救済判定を満たすかを調べる。

Issaの追加観測は「チャネルによって幅が大きく違い、小幅のチャネルでbiasが支配的」である。一定λのWDについての近似 `|b|_eq≈1/λ` はチャネル幅を含まないため、`|b_c|_eq/s_c≈1/(λs_c)` は小幅のチャネルほど大きくなる。層の中央値の幅からλを一つ決めても、この点を解決しない。初期幅からチャネル別λを決めるだけでも、その後s_cが縮むと問題が再発する。なおこの平衡式はAdamの歩幅を一定とする目安であり、実更新に対する厳密な上界ではない。

したがって、本specは**現在のチャネル幅に応じたbiasの直接射影**を一つのBとして採る。元案の「c1ゼロ化＋層共通λのWD」からの変更であり、実施後に両者を同じ処方だったと書かない。r目標の持ち上げもこの本走に同時追加しない。

### 6.2 CH′と主腕

| 部位 | 固定する操作 |
|---|---|
| 入力C | CIFAR-10 train5万枚の色のチャネル平均を引く。subset別平均画像は引かない |
| c1/c2後のH′ | pool後の各チャネル×位置のEMA平均を引く。c1は16×16×16、c2は16×8×8。画像軸だけ平均、β_H=0.01、初期0、勾配なし、課題境界で保持、宿主のAdam/EMAの更新順を維持 |
| f1/f2後のH′ | unit別EMA、同じ規則 |
| c1/c2/f1/f2のbias | 毎Adam更新後、下記のチャネル/unit別の幅に対する上限へ射影 |
| W全層・出力f3のbias | 元のAdamのみ、WD/射影なし |

主腕 `CHf_B`（表示 `CH′+B_width`）×10seed、task1から30課題を新規実行。参照 `CHf`（CH′）はP183のseed10–19を資格確認して再利用。ref/CHは文脈としてのみ併記する。

### 6.3 B_width の演算と尺度

係数 **κ=0.2** に固定する。これは旧relu_doorsの「biasの大きさを幅の0.2倍に抑える」という設計目標の継承であり、性能の成功閾値ではない。今回λへ近似変換せず、その比を直接制御する。κの探索はしない。

各更新で宿主のforward/backward→Adam→所定のEMA更新を終えた後、**同じ学習ミニバッチの画像をもう一度、no_gradで前向き**に通す。この測定ではEMA/RNGを更新しない。c1→c2→f1→f2の順に、その層までの補正を反映した入力を使って次を行う。

1. biasを加える前の `q_l=W_l*h_in,l` を計算する。幅はbiasに支配されたzからbを差し引いて作らず、このbiasなし演算から得る。qの統計だけfloat64で集約する。
2. convでは各チャネルc・位置pについて、ミニバッチ画像軸の母分散 `v_c,p=Var_batch(q_c,p)`（correction=0）を計算する。**チャネルの尺度は `s_c=sqrt(mean_p v_c,p)`**、すなわち位置ごとの画像方向の幅のRMSとする。位置ごとの平均の違いを幅に加算しない。fcはunitごとの画像軸SD（correction=0）。
3. Adam後の候補biasを `b_c←clip(b_c, −κs_c, +κs_c)` とする。候補・s・射影後biasを保存する。s=0ならb=0。NaN/Infなら数値発散として止め、小さな分母や任意の下限幅へ置換しない。上限内ならbitを書き換えない。
4. 補正済みbiasで活性化・pool・現在のH′を適用し、次層の尺度計算へ進む。最終f3にBは掛けない。

最初の学習forwardでは元の初期化biasを使い、最初のAdam更新後からBを入れる。Bで勾配を作らず、W・Adam m/v/tcを変更しない。通常の訓練forwardとReLUのnative微分はそのまま。追加測定forwardの実装による丸めと通常forwardの差は独立checkerで記録する。

この操作は**当該ミニバッチ上のチャネル尺度に対するbiasの比**を制御する。真の全入力分布や全位置で同じ上界が成り立つとは主張しない。固定1200枚での全画像尺度、位置別のs、min/中央値/max、bias/幅を課題末に測り、バッチ尺度とのずれを示す。

実数ではbiasの変更はそのunitの幅を変えず、mを同じ量だけ動かす。中心化残りを `a_c=E[q_c]` とすれば `r_c=(a_c+b_c)/s_c`。Bはb_c/s_cを抑えるが、a_c/s_cやs_c自身を保つ操作ではない。**bias支配を抑えたこととr/応答の保持を同一視しない。** 位置別の全幅を保証する操作でもない。

係数probeは不要。seed100–102の短縮走は実装検査・比の実現と追加forwardの計時だけに使い、κを選ぶ較正にはしない。追加forwardの費用と1step当たりの演算順を本走前に固定する。

### 6.4 主判定と副比較（論文付録H.2/P181を継承）

各seedの `W_s=mean_{t=21..30}(online)`。全10seedの有限な完走を要求する。

| 主ラベル | 字義 |
|---|---|
| `RESCUED` | W_s≥0.5 が9/10以上 |
| `FAIL` | W_s≥0.5 が1/10以下 |
| `PARTIAL` | 2〜8/10 |

9/10は帰無p=.5の両側正確二項でp=.021484375に対応する元P181の基準。nを8/9へ縮めて別閾値に替えない。欠測/発散は共通の完全性ラベルを先に出し、観測値は報告する。

副: `D_s=W_CHf_B−W_CHf` の平均/95%t区間・中央値・全差・正確符号検定（1比較）。改善が有意でもW≥0.5が1/10なら主判定はFAILのまま。主窓で保つことを、200課題/無期限の治癒へ拡張しない。

### 6.5 必須の痕跡と操作確認

全4隠れ層について、次を保存する。

- 各課題始端/終端と切替後更新1/10/100/1000で、固定probe画像のunit別m/s/r、native E[φ′]・Var_x[φ′]、厳密0率、死亡率、正側固定率、bias、W/フィルタノルム。**全unit配列を残し、幅の二極化を中央値で消さない。**
- convは位置p別の `m[c,p]=E_x z`、`s[c,p]`、r、Var_x[φ′]を画像軸で算出。Bに使うRMS幅と、画像×位置を混ぜたSDを別列にする。後者をVar_xと呼ばない。fcは画像軸。
- `b_c/s_c`、`a_c/s_c`、`m_c/s_c` の分解。小幅側・大幅側を**当該時点のチャネル幅の順位**で可視化する。帯の取り方は記述であり、性能の主ラベルを変えない。
- 各更新の射影発火数、除去量、射影前後の最大比、s=0の個数、各課題の全画像幅に対するbias比。丸め上界を越える実装違反と、バッチ外で上界を越える標本差を区別する。
- 実際の入力平均とEMA、`m=<W,μ_in>+b` の分解、t0からの変化。Cは色だけの中心化なので、c1のμ経路が厳密0とはしない。sが縮んだ場合とmが動いた場合を分ける。
- P183のonline/memo/CE、t0、curves、units、checkpoint t1/2/3/5/10/20/30を継承。再開用P/Adam/EMA/RNGを含む。旧参照から再構成できない新指標はNOT_AVAILABLEとし、都合のよい値で埋めない。

### 6.6 FAIL の場合に弱まる主張（走る前に固定する段落）

> CH′+B_widthがFAILなら、「CNNで残るbiasの相対寄与を抑えれば、同じCNN箱の再学習を保てる」という今回の介入仮説は支持されない。単に層共通のλが弱すぎたという説明は採れず、チャネル別の現在幅を用いる処方でも救済しなかったと記す。ただし、バッチ尺度でbias比を抑えても全入力のrや応答が保たれなかった場合には、処方が相対位置の保持を実現しなかったことまでが結論である。全画像上でもrと応答の分散を保ったのに成績が落ちたなら、それらの保持だけで性能を保てるというCNNへの十分性の拡張がより直接に弱まる。幅s自体の消失、常時オンへの線形化、残る平均入力経路を別々に示す。現稿§3.2のMLP内の比較、§5.1の応答交換で成績が動いたという事実は、このCNNの陰性だけで反証とはならない。論文の適用範囲はCNNの痕跡と陰性結果までとし、CNNでも有効な処方を確立したとは書かない。

RESCUEDでも単一CNN・乱数ラベル・30課題・CH′＋B_widthの組合せに限る。MLPのCHBと同じ操作の移植成功とは呼ばず、同じ問題意識から幅に応じて作った介入の成功とする。4層のどのbias操作が運んだかはこの1腕では分からない。

### 6.7 S 検査

| S | 本物で要求 | 必ず落とす変異 |
|---|---|---|
| S-P183 | B無効化経路がP183のCHfと一致、参照のseed10–19/30課題・blob/hashを照合 | CHをCH′と称する／seed群を交換 |
| S-Hprime | EMAのshape・画像軸平均・β・更新順・保持が元H′と一致 | 空間位置も平均／EMAを課題ごとreset |
| S-scale | 幅が100倍違う2チャネル、位置平均だけ違うfixtureで、独立float64の画像内分散RMSと一致 | 層中央値の幅を全channelへ／画像×位置の全分散を使う |
| S-B | 独立参照のclipと一致、上限内は不変、s=0はb=0、小幅channelに小さい上限。W/f3/momentは通常どおり | 固定絶対bias上限／片方の層だけ除外／momentも縮小 |
| S-order | 前段のbias補正を反映した次層入力で尺度を測る。非零bias・非零momentを含むfixture | 全層の幅を補正前に一括測定／追加測定でEMA更新 |
| S-moments | m/s/r/Var_xの軸と0分母を明示、全画像とバッチ尺度を別列へ | 画像×位置分散をVar_xと呼ぶ／中央値の比をunitの比と称する |
| S-resume | 記録有無・再開でP/Adam/EMA/RNGと学習軌道が一致 | 再開時κ変更／loggerが学習RNGを消費 |
| S-verdict | KEPT数0/1/2/8/9/10、W=0.5ちょうど、欠測/発散の境界を確認 | >0.5へ変更／8/10を救済／欠測を除外 |

数値許容は演算の丸めから導出する。相対幅の検査では分母の小ささを固定epsilonで隠さず、絶対誤差による判定とs=0の明示分岐を用いる。
