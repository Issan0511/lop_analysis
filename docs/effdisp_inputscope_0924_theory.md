# 入力分布が変わる場合の実効変位の読み方

Codex、2026-09-24。再検証の本走前に整理した代数と適用域。実験結果・新規性の主張ではない。
前回の条件付き収縮モデルは `docs/effdisp_validation_0924_theory.md`。今回の登録は `specs/spec_effdisp_inputscope_0924*.md`。

## 1. 固定入力は何を固定するか

固定した中心化入力共分散Σでは、V=trWΣWᵀ、D=Wnext−Wprevとして

    ΔV = trDΣDᵀ + 2trWprevΣDᵀ = Q + 2X.

この恒等式は、Dの分布・Xの角度・学習能力・幅の定常性を保証しない。固定入力のRLでも、重み、optimizer moments、活性化の応答、適応αは変わる。
実験で入力固定を操作しても、それだけで供給qと削りaが定数になるわけではない。

## 2. SCRはΣ一定でも平均・支持点が変わる

課題tの入力を x_t=µ_t+ξ と書く。今回のCondAではξは同じ5ランダムbitの中心化変数で、Σ=diag(0×15,.25×5)は厳密に一定。
それでも z=Wµ_t+b+Wξ の平均側が動くため、非線形活性化の応答と誤差が変わる。中心化幅の帳簿には平均側は入らないが、実際の更新Dを決める勾配には影響し得る。

learner入力をµ_initial+ξへ固定する対照は、入力支持点を固定し、teacher側のµ_tを変えれば標的変化を残せる。
ただしpersistent bitsによる課題の手掛かりも失われ、同じ32点へ別の標的を割り当てる状況に変わる。入力平均だけを独立に操作した介入とは呼ばない。
今回の2×2は、learner入力contextとteacher評価contextを別々に動かし、この限定を明示して比較する。

## 3. 動くΣの帳簿は順序を明記する

現在taskのΣ1で学習更新を測ると、

    Q1=trDΣ1Dᵀ, X1=trW0Σ1Dᵀ,
    G_before=trW0(Σ1−Σ0)W0ᵀ,
    V1−V0=Q1+2X1+G_before.

前taskのΣ0で学習更新を測る別の正しい分解は

    V1−V0=Q0+2X0+G_after,
    G_after=trW1(Σ1−Σ0)W1ᵀ.

両者の配分差は

    (Q1+2X1)−(Q0+2X0)
      = trD(Σ1−Σ0)Dᵀ + 2trW0(Σ1−Σ0)Dᵀ
      = G_after−G_before.

したがってGの『寄与率』は採用した分解順序に依存する。V1−V0という全体の変化とは区別し、寄与率を介入による因果割合とは呼ばない。
今回の正本は現在Σでの更新とG_before。前回の正本は旧Σでの更新とG_after。同名のQ/Gとして混用しない。

実入力上の定常な二乗幅には E[Q1]+2E[X1]+E[G_before]=0 が必要だが、それだけでは安定性や到達を保証しない。
旧式 R=D/(2|c|)へGを落として代入することはできない。固定referenceの式は正しいが、実入力上の幅の定常性へ置き換えない。

## 4. 同じ潜在入力IDで前活性を比較する

x0,x1を同じ画像ID/bit supportに対応する課題前後の入力として

    A=(W1−W0)x1+(b1−b0),
    E=W0(x1−x0),
    W1x1+b1−(W0x0+b0)=A+E.

二乗量は E||A||² + E||E||² + 2E<A,E> に分かれる。
また E||A||²=Q1+||Dµ1+db||²。中心化されたDだけでmean/biasの変化を失わない。
この分解は比較するlatent IDの対応に依存する。今回は画像行IDとrandom supportを固定し、別画像同士の差を入力driftへ混ぜない。

## 5. Permutationで何が変わるか

列の並び替えpでx_t=x_base[:,p]とする場合、同じ前活性を元の画像座標で表す重みは U_t=W_t[:,argsort(p)]。
actual widthは trU_tΣ_baseU_tᵀ で書ける。しかしU_t−U_(t−1)には学習更新と入力の並び替えが両方入る。この差全体をoptimizerが生んだDとは呼べない。
共分散のrankや固有値が変わらなくても、Wとの相対的な向きが変われば実効幅は変わる。

同じbankの一様ランダムなpermutation Pを平均すると

    E[PΣPᵀ] = (a−b)I + b 11ᵀ,
    a=trΣ/d,
    b=(1ᵀΣ1−trΣ)/(d(d−1)),  d>1.

これは対角と非対角がそれぞれ等しくなることから出る代数的な式。
課題ごとのΣ_tが変わることと、そのpermutation生成法の確率分布が時刻で変わることは別である。
i.i.d.なpermutationなら、task条件付き分布は切り替わっても、環境の生成則自体は定常であり得る。SCRのcontextも有限状態の過程として扱える。

従って『入力が毎task変わるから平衡は存在しない』とも言えない。重み・context・optimizer・適応状態を含む確率過程の定常性と、今回有限地平で見る幅の頭打ちは別に検討する必要がある。

## 6. 再検証で結論できる範囲

固定入力・切替標的の条件でも平衡が出なければ、観測した地平では入力固定だけで十分でなかったと言える。
入力切替条件で学習更新と環境項が相殺して幅が止まれば、更新だけで説明した固定点と区別する。
固定入力/固定標的で更新が止まっても、新しい標的を学べないとは限らない。刺激を固定した対照と機能的な可塑性喪失を混同しない。
通常の適応Snake c=.6を主比較とし、c=.3と固定α=.05の比較は、前回観測した条件の限定を調べる補助とする。
## 7. 追補：動く釣り合いの高さ（0924・LR先行結果を見た後）

この節は事後の理論整理。事前予測の修正ではない。LR固定入力MNISTで、task41–50から121–150へDとD/(2|c|)が増えたことを受ける。数値はnon_snake_interim/summary.md末尾とthreshold_components_posthoc.csvを参照。

### 凍結した係数での固定点と、時間変化を分ける

R_t=√V_t、d_t=√Q_t、c_t<0とする。係数をその時刻で凍結した写像は

    F_t(V)=V+d_t²+2c_t d_t√V,
    V*_t=d_t²/(4c_t²).

V*_t付近の傾きはF'_t(V*_t)=1−2c_t²。d_t,c_tを外生的な時系列と仮定すれば、e_t=V_t−V*_tについて

    e_(t+1) ≈ (1−2c_t²)e_t − (V*_(t+1)−V*_t).

目安が上がると追従誤差は下側へずれる。ゆっくり変化する場合の準静的近似はe≈−ΔV*/(2c²)。幅Rで同じ一次近似を取れば相対遅れは概ねΔlogR*/(2c²)。

**適用条件は未検証。** 実際のd,cはWとoptimizer状態に依存する。観測されたcだけから真の収縮率を1−2c²と決めることはできず、状態微分d'(V),c'(V)も必要。同じ更新から得たR*=−RQ/(2X)への近さは収支の別表現であり、追従モデルの独立支持ではない。

### 高い相殺率だけでは有界性を保証しない

正確にΔV=Q(1−B)、B=−2X/Q。Bが1へ近づいても、Qの増加と残差の累積を抑えなければVは増え続ける。例えばQ=一定>0、B=一定<1ならVは線形成長する。

もう一つの条件付き例としてd(R)=kR^a、|c(R)|=hR^bが大きなRまで成り立つと仮定すると

    ΔV=k²R^(2a)−2hkR^(a+b+1).

a<b+1なら大きなRで負項が支配し、a>b+1なら正項が支配する。等号では係数次第。ただし有限範囲での観測回帰を、そのまま大きなRへの法則や因果関係として使わない。

この再検証で落ちたのは登録した有限時間のplateau判定と一定係数によるheldout予測。将来の頭打ちの不存在まで結論しない。次の理論的な課題は、更新量と方向の状態依存を、同時点の恒等式から独立に制約することである。

## 8. 追補：RLで収束するための候補機構（質問への条件付き回答）

以下はAdamの導出ではなく、十分条件が何かを示す模型。中心化した固定画像bank上の第一層前活性hをベクトル化し、populationの規格化によって||h||²=Vとする。

    h_(t+1)=(1−a)h_t+ξ_t,
    E[ξ_t | h_t]=0, E||ξ_t||²=q_ξ,
    aとq_ξは時間によらず一定、0<a<2。

すると

    E V_(t+1)=(1−a)² E V_t+q_ξ,
    E V_t → q_ξ/(2a−a²).

これは二乗幅の**期待値**の収束。個々の課題ごとの幅が同じ数に収束するという意味ではなく、非零の書き込みがあれば揺れは残る。
q_ξは新しい書き込みξのエネルギーであって、観測した全更新のQではない。実際、全更新Δh=−ah+ξなのでE Q=a² E V+q_ξ、E X=−a E Vとなる。

ランダムな再ラベルで古い課題に特有な成分が不要になることは、削る作用の候補説明になる。ただし固定入力・独立な再ラベルだけから、深いleaky網とAdamが上の一定a・一定q_ξ・無相関条件を満たすとは結論できない。
CondAでは入力contextと固定教師が課題間の構造を共有するため、独立再ラベルの候補説明もそのまま移せない。観測されたcの符号頻度は記述できるが、その符号頻度が生じる原因の証明とは分ける。

## 9. 追補：Adamの一歩の上界から得る条件付き有界性

これは§8のAR模型とは別の十分条件であり、RLの実際の軌道にその条件が成り立つという主張ではない。固定した半正定値の中心化入力共分散Σについて、第一層W∈R^(h×d)の幅R_t=||W_t||_Σを全taskで同じΣにより測る。Adamはmomentsを0から始め、β₁=.9、β₂=.999、学習率η、weight decayなし、各taskちょうどT更新とする。以下の計算は有限勾配を持つ実数演算で行う。ε>0なら通常の更新は定義される。ε=0でv̂=0となる座標には0/0を0更新と定義する場合に限り同じ上界を使える。実際の浮動小数点のoverflow・underflowまで保証するものではない。

任意の一座標について、時刻nの勾配をg_nとすると

    m_n=(1−β₁) Σ_(j=0)^(n−1) β₁^j g_(n−j),
    v_n=(1−β₂) Σ_(j=0)^(n−1) β₂^j g_(n−j)².

Cauchy–Schwarzにより、v_n>0では

    m_n²/v_n ≤ [(1−β₁)²/(1−β₂)] Σ_(j=0)^(n−1)(β₁²/β₂)^j
              ≤ [(1−β₁)²/(1−β₂)] / (1−β₁²/β₂).

ここでβ₁²<β₂が必要。bias補正後の比 |m̂_n|/√v̂_n にはさらに √(1−β₂^n)/(1−β₁^n) が掛かる。今回のβではβ₂=.999≥2β₁−β₁²=.99であり、n≥1について

    β₂^n ≥ [β₁(2−β₁)]^n ≥ β₁^n(2−β₁^n),

最後の不等式は (2−β₁)^n+β₁^n≥2 から従う。従って 1−β₂^n≤(1−β₁^n)²、bias補正因子は1以下。各座標のAdam更新量はε≥0の分母を含めても

    |Δw_n| ≤ ηK,
    K=(1−β₁)/√[(1−β₂)(1−β₁²/β₂)] ≈ 7.2703.

従ってtask末の差D_t=W_(t+1)−W_tには、三角不等式とΣの最大固有値λ_maxから

    d_t=||D_t||_Σ ≤ √λ_max ||D_t||_F
        ≤ TηK√(hd λ_max) =: D_max.

さらに**未検証の強い仮定**として、d_t>0かつR_t≥B:=D_max/(2c₀)の全taskで、c_t=⟨W_t,D_t⟩_Σ/(R_t d_t)≤−c₀、0<c₀≤1が一様に成り立つとする。このとき恒等式から

    R_(t+1)²−R_t²=d_t²+2c_tR_td_t
                   ≤ d_t(D_max−2c₀R_t) ≤ 0   (R_t≥B).

d_t=0なら幅は変わらない。R_t<Bならノルムの三角不等式でR_(t+1)≤R_t+d_t<B+D_max。ゆえに全時刻で

    R_t ≤ max{R_0, B+D_max}.

これは**条件付きの一様有界性**だけを示す。R_tやd_t/(2|c_t|)の点ごとの収束、定常分布の存在、c_t≤−c₀がRLで成立することは証明しない。c_tが未定義のゼロ更新は上記のように別扱いする。task間でΣが変われば幅の差に§3の環境項Gが入り、この固定Σの証明をそのまま適用できない。有限地平でc_tが負だったという観測も、将来の全taskで一様なc₀を得る根拠にはならない。
