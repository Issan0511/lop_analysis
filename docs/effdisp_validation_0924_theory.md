# 実効変位と幅：恒等式から予測モデルへ

Codex、2026-09-24。数式は今回の収支の定義からの導出。最適化器の機構や新規性の証明ではない。
以下の条件付きモデルを実験結果と照合する。元ノートの因果の一方通行を前提にしない。

## 1. 厳密に成り立つ範囲

入力の中心化共分散Σが固定なら、V_t=||W_t||_Σ²、D_t=W_(t+1)−W_t、
Q_t=||D_t||_Σ²、X_t=<W_t,D_t>_Σ として

    V_(t+1) − V_t = Q_t + 2 X_t.

Σが半正定値でも成立する。Σの零空間はこの尺度には現れないが、入力平均や別の課題に無害とは限らない。

一遷移でΔV=0、Q>0、c=X/sqrt(VQ)<0なら、R=sqrt(V)=sqrt(Q)/(2|c|)。これは収支の言い換え。
確率的な定常状態では正しい式は E[Q]+2E[X]=0 であり、平均の積へ無条件には分離できない。
例えば E[R]=E[sqrt(Q)]/(2|E[c]|) は一般には導けない。

入力が変わる場合は別項がある。

    V_(t+1)(Σ_(t+1)) − V_t(Σ_t)
      = Q_t(Σ_t) + 2 X_t(Σ_t)
        + tr[W_(t+1)(Σ_(t+1)−Σ_t)W_(t+1)ᵀ].

CondAは条件付きΣが固定でもµが動く。前活性の平均Wµ+bは別に追う必要がある。
PMはΣ自体が動くので、固定referenceの幅とactual widthを区別する。

さらに、同じ入力分布上での前活性の変化全体は

    E_x ||D x + Δb||² = ||D||_Σ² + ||Dµ + Δb||².

中心化された実効変位だけでは右辺第二項を測らない。CondAではpersistent bitが主として平均を変えるため、この区別が特に重要。
入力平均も動くとmean shift=(Dµ_t+Δb)+W_(t+1)(µ_(t+1)−µ_t)。環境による変化と重み更新による変化も同一視できない。

## 2. 何が分かれば固定点を予測できるか

Vを状態にした条件付きの供給と削りを

    q(v) = E[Q_t | V_t=v],
    a(v) = −E[X_t | V_t=v] / v

と置く。すると

    E[V_(t+1) | V_t=v] = v + q(v) − 2 a(v) v.

候補の固定点v*はq(v*)=2a(v*)v*。存在・安定性にはqとaが状態とともにどう変わるかが要る。
条件付き平均の写像の局所安定条件は

    |1 + q'(v*) − 2a(v*) − 2v*a'(v*)| < 1.

これは一階平均写像の条件で、確率過程全体の不変分布・有界性を保証しない。状態をV一個に閉じられるか、時刻依存が残るかも別の仮定。
今回の登録P3はqとaを前半の定数へ近似した予測であり、これらを更新則から導いた理論ではない。

元ノートに近い決定論的近似として、Dの長さd(R)=A R^p、負cosの大きさ|c(R)|=B R^sなら、

    R*^(1+s−p) = A/(2B).

局所的なRの写像の微分は、釣り合いでrho=d/Rとして

    F'(R*) = 1 − (1+s−p) rho*²/2.

従って安定条件は0<(1+s−p)rho*²<4。
「p<1なら固定点へ向かう」はs=0等の仮定を要する。p=1でもsが状態に依存すれば固定点を持ち得る。
観測時系列の回帰傾きpは、Rだけを介入したときの弾性とは同じではない。

## 3. 課題ごとの収縮と新しい供給というモデル

条件付きモデルとして

    W_(t+1) = (1−a) W_t + ξ_t,
    E[ξ_t | W_t] = 0,
    E[||ξ_t||_Σ² | W_t] = ν,

を置く。0<a<2、ν>0が一定なら

    E[V_(t+1)] = (1−a)² E[V_t] + ν,
    E[V]_stationary = ν / [a(2−a)].

課題に合わせ直す更新が前の重みをどれだけ減らすかをa、新しい供給の二乗量をνが表す。供給とWの内積は条件付き期待値で0であり、各実現で直交するとは仮定しない。
この表現だけではaやνがAdam・ε・入力非定常度からいくらになるかは導けない。

同じモデルの実変位はD=−aW+ξなので

    E[Q | V] = a² V + ν,
    E[X | V] = −a V.

DはWにも依存する。定常状態ではE[Q]=2aE[V]となり、RMSで定義した

    rho_rms = sqrt(E[Q]/E[V]) = sqrt(2a),
    c_aggregate = E[X]/sqrt(E[V]E[Q]) = −sqrt(a/2)

が成立する。元の釣り合い式を満たすことは、DがWから独立である証拠にはならない。

ただしa,νを固定してDのR依存を見ると、d(R)=sqrt(a²R²+ν)の弾性は

    d log d / d log R = a²R²/(a²R²+ν).

定常水準に代入するとa/2=c_aggregate²。小さな削り係数なら、DはWに依存しつつもその弾性は小さくなる。
元CIFARノートの|c|=.24–.35をこのモデルへ仮に対応させると、弾性は.058–.123。
この数値はモデル上の換算で、今回の新しい測定値でも独立した適合検定でもない。時間内の傾き.45を説明したことにもならない。

## 4. 素のノルムが育ち、幅だけが止まり得る理由

Σの固有方向jごとに、u_(j,t+1)=(1−a_j)u_(j,t)+ξ_(j,t)、innovation variance ν_jという条件付きモデルを置く。
0<a_j<2ならE[u_j²]はν_j/[a_j(2−a_j)]へ近づく。小さなa_jでは、tが緩和時間1/a_jより短いうちはほぼ線形成長に見える。

    raw energy = Σ_j E[u_j²],
    effective energy = Σ_j λ_j E[u_j²].

λ_jの小さい方向だけが遅く緩和すれば、rawは成長してもeffectiveへの寄与は小さい。
有限次元で全a_j>0なら、rawも十分先では止まり得る。有限地平でのsqrt(t)を無限時間の法則とは言わない。
a_j=0でν_j>0の方向は拡散する。λ_j=0なら条件付き幅には全く見えないが、CondAのpersistent方向のように平均には効き得る。

## 5. 活性化・適応系の位置づけ

この収支は活性化に依らず成立する。活性化は実際のDとX、すなわち供給と削りの条件を変える。
微分や学習能力が先に尽きると、非零の供給と削りが相殺する状態を観測する前に打ち切られ得る。
その停止をactive equilibriumの支持にも、一律の反証にも数えない。

適応Snakeはαを状態として持つため、V一個でq(v),a(v)を閉じる仮定がさらに強い。
Rに追随するαにより局所位相尺度αRを保てる可能性はあるが、平均・位相配置・optimizer momentsは残る。
今回の計測で幅と実効変位の関係が良く見えても、αを消去した普遍法則まで得たとはしない。

## 7. 入力次元の入り方と、複製による対照実験

以下はユーザーが追加した次元の議論を受けた数式上の整理。新しい次元介入の実測ではない。

Σ=Σ_j λ_j v_j v_jᵀ と分解すると、

    Q = ||D||_Σ² = Σ_j λ_j ||D v_j||².

必要なのは座標数dだけではなく、固有値λ_jと更新Dの向き。rankやparticipation ratio `(trΣ)²/tr(Σ²)` が同じでもQは変わり得る。
Dが入力固有方向に対して等方的という追加仮定の下では E[Q | ||D||_F]=||D||_F² trΣ/d。
各座標の更新分散がσ_D²、ユニット数hで固定ならE[Q]=h σ_D² trΣになる。
これらはDの分布を仮定した式で、Adamのtask全体のDがその仮定を満たすとは限らない。

### 画素複製はrankを保つが、無正規化では分散尺度を保たない

元の各特徴をq回複製する線形写像A∈R^(qd×d)についてAᵀA=qI。
入力をx'=s A x、初期第一層をW'=W Aᵀ/(q s)にすると、初期前活性W'x'=Wxを厳密に一致させられる。
共分散Σ'=s² AΣAᵀの非零固有値はq s² λ_j。

| 入力変換 | 生次元 | rank | 非零固有値・trΣ | 初期関数を揃える第一層 |
|---|---:|---:|---:|---|
| q回の単純複製 s=1 | qd | 同じ | q倍 | 各複製ブロックW/q |
| q回複製して1/√q倍 | qd | 同じ | 同じ | 各複製ブロックW/√q |

したがって、最近傍の2倍拡大はq=4に相当し、無正規化では『生次元だけ』の介入にならない。
補間方法を変える場合もAの形とAᵀAを確認する必要がある。グレー化や縮小は情報・共分散・課題難易度も変える。

### 初期関数と同じミニバッチを揃えたときの更新

第一層の元の勾配をgとすると、複製側の各ブロックの勾配はs g。
元入力に対する合成重みをW_eff=s W' Aとすると、SGDの一歩は

    ΔW_eff = −η' q s² g.

よって元の学習率ηと同じ関数更新にする第一層の学習率はη'=η/(q s²)。

Adamでは重み減衰なし、対応するモーメントm'=s m、v'=s²v（ゼロ初期状態も含む）、s>0なら、バイアス補正後も

    ΔW_eff = −η' q s m_hat / (sqrt(v_hat)+ε'/s).

元と同じ関数更新にはη'=η/(q s)、ε'=s εを使う。
この補正は第一層だけの学習率・ε設定を要する。全層共通の学習率を一括変更すると、他層の更新は一般に一致しない。
他層・バイアスの設定を保ち、複製間の対称性と同じミニバッチを保てば、この対応は一歩だけでなく軌道全体に延長できる。
浮動小数点の集計差を除く代数的な対応であり、独立初期化や重み減衰を入れた実験へ無条件には延長しない。

- 単純複製s=1では、同じ第一層学習率のSGDもAdamも合成更新がq倍になる。両者の倍率が必ず違うわけではない。
- 分散を保つs=1/√qでは、同じ学習率のSGDは一致する。Adamはεが無視できる範囲で合成更新が√q倍になる。正確に揃えるなら上の学習率とεの両方を変える。
- この対照で分けられるのは、情報量の変化と座標の重複・最適化器の座標依存性。画像サイズだけを比べるより解釈が限定しやすい。

Adamの各座標が常にη動くわけではない。勾配が持続するか・符号が変わるか・二次モーメント・εによる。
また『fan-inが増えると座標勾配が必ず小さくなる』とも言えない。無正規化複製の例では座標勾配は同じである。

### cと固定点について言える範囲

c=X/√(VQ)はW・D・Σの全てに依存する。次元変更がDの方向や課題構造を変えればcも変わり得る。
`rho=2|c|` はΔV=0でQ>0のときの関係で、cやrhoの次元不変性を保証しない。
上記のように関数軌道と共分散の対応を厳密に揃えた対照ではV,Q,Xが一致するためcも一致するが、これは対照の構成による。

μPのAdamの1/fan-in則は、隠れた重み行列の幅を増やす際のパラメータ化と組になった規則である。
入力画像の座標数を増やす本例へ、そのまま一般法則として移すことはできない。

今回の複製に関する式は上の連鎖律と更新式から導いたもので、これらの論文から引用した定理ではない。
