# 改訂役の予測（走の前に固定・0930）

対象: `twolayer_a6_probe.py`（2 層 RL-MNIST・両層 ELU・第 2 層・切替 2・3 は seed 0 と 1、切替 10 は seed 0）。
量: 開いた入力を持つ第 2 層の unit について、1 次の帳簿（自分 = Δw·μ1(0) + Δb、上流 = w(0)·Δμ1）の「上流 ÷（自分 + 上流）」を和の比で。
実はラベルを 16 回引き直した平均の 200 更新。予測は切替時の状態だけから出す A6 の 2 層版。

| 記号 | 予測 | 自分の賭け |

| PB5-a | A6 の 2 層版の τ=200 の上流の割合は、ラベル平均の実の 1 次の上流の割合と ±0.10 で合う（切替 2・3、2 seed の 4 点のうち 3 点以上） | 0.40 |

外れたときの読み: PB5-a と PB5-b がともに外れ、実の上流の割合の毎更新の値が最初の 30 更新で 0.6 前後から下がるなら、ずれは記憶ではなく「上流の期待の押しが自分より早く尽きる」（反証役の候補 (a)）。最初から低いなら、1 歩の期待の核が 1 回目から外れている（旧モーメント・1 回の引きの揺らぎ）。

## 枝: 読み出しの尺度（`branch_scale_probe.py`・1 層 ELU・seed 0・切替 10 と 20・起動前に固定）

仮説 H_erase [候補]: 押しは旧課題の予測（logit）を取り消し終わるまで続き、Adam では 1 歩の大きさが勾配の大きさによらないので、押しの長さ（転回点）と深さは取り消す量に比例して伸びる。取り消しの道は 2 本（読み出しが自分で動く・第 1 層が動いて v·Δa で logit を動かす）。
読み出しを c 倍（logit が c 倍）にし、第 1 層の Adam の状態を m×c・v×c² にそろえる（第 1 層の最初の一歩は基準と同じ）。

| 記号 | 予測（深さ・転回点はいずれも基準の腕に対する比、生きた unit の中央値） | 自分の賭け |
|---|---|---|
| PS-a | 読み出しが学習する腕: ro2 の深さの比 1.15〜2.0、ro0p5 は 0.5〜0.87（切替 10・20 の両方） | 0.45 |
| PS-b | 同じく転回点の比が深さの比と同じ向き（ro2 > 1、ro0p5 < 1） | 0.50 |
| PS-c | 読み出しを凍結した腕（basef・ro0p5f・ro2f）: 深さは c によらず、basef との比が 0.8〜1.25（第 1 層の一歩が logit を c 倍動かすので、取り消しの時間は変わらない。vault §8.37 と同じ向き） | 0.55 |
| PS-d | 全腕で、転回点は旧ラベルの余裕が切替時の 2 割に落ちる時刻の 0.67〜1.5 倍 | 0.35 |

H_erase の外れ方: PS-a が外れて深さが c によらないなら、押しの深さは旧予測の大きさでなく、網の状態（幅・開いた入力）の側で決まる。
