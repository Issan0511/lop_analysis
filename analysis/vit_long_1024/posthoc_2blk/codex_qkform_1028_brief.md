## 2. 答えてほしいもの（優先順）

### Q1. 成長則の分解と導出

block0 の実効 score 尺度（他 token の query を逆伝播で重みづけた実効 q-k ノルム、または固定 token での rms‖a(ξ)‖）の課題 10 → 100 の log 増加を、次の因子の積に分け、課題末ごと（t = 0〜10 の毎課題、20、…、100）の軌跡を両腕で出す。

1. ‖W_q‖‖W_k‖ の伸び（Adam の酔歩: 座標あたりの歩幅 c と更新数から導けるはず。c = m̂/√v̂ の rms を回し直しで測り、10 課題あたり 6.0・5.5 を再現する）。
2. γ1 の軌跡（R0L で縮む理由。γ の勾配の符号を導く: LN の gain は入力の尺度と重みの尺度の間で尺度不変の釣り合いにある。Adam のもとで γ が縮むのは…を導出で）。
3. ΔW と W の整合（A の歩幅 ÷ W の歩幅。ΔW_q ∝ Σ δq ξᵀ で δq ∈ span(key) なので、自動的に W_k とそろう。そろいの度合いは score の勾配の集中（飽和）で決まるはず）。
4. A の伸びが token の部分空間に残る割合（SL 1.55 で一定、R0L 0.98 へ逸れる）。これは逆伝播の信号 δq の部分空間が課題をまたいで持続するかどうかで決まるはず。
5. 入力 ξ の側（patch_embed・pos_embed の変化。前の解析で patch_embed は接核のトレースの 41% を持つ）。
6. b（query に依らない key の好み）。

各因子について、SL と R0L の差の log 寄与を表にする。導けるものは導き（仮定を表に）、導けないものは測った事実と書く。

### Q2. 課題の中のどこで伸びるか、何が歩を整合させるか

- 保存状態からの短い回し直し（≤ 1,500 更新、同時 1 本）で、block0 の qkv の Adam の歩の整合 c(t) = rms(m̂/√v̂)、score 尺度、A・a(ξ) の歩幅を毎更新〜25 更新ごとに記録する。状態: SL 課題 10・60・100、R0L 課題 10・100（Adam の保存がある課題末は保存を使う。無い課題末は `--fresh-adam` と明記）。
- 前の対照（SL10 の共有 vs head0）で伸びが更新 100〜500 に集中した理由を、損失の軌跡と c(t) で説明する。伸びの総量 ≈ lr × Σ_t c(t) × 整合、を数で照合する。
- 「SL は当てはめの尾が長い（整合した歩が多い）」が歩幅の差を運ぶのか、「飽和が勾配を集中させて歩を低階数にする」が運ぶのか、両方か。

### Q3. フィードバックの輪（飽和 → 集中 → 低階数の整合した歩 → 拡大 → 飽和）の検査

- SL の軌跡の中で、課題末の飽和率と、次の 10 課題の A の歩幅・ΔW の参加比・整合の相関。
- 反実仮想: SL 課題 100 から、注意を軟らかくした回し直し（前の `q4_temp4`、score を 1/4）と基準で、1 課題の A・a(ξ) の歩幅を比べる。予測を先に書く（輪が本物なら軟化で歩幅が減る）。
- 同じく、head を共有したままと head0（前の formation の対照）で、score の勾配の集中（上位 5% の token 対が持つ割合）と歩の階数を比べる。

### Q4. 腕の差の根: 読み出しの持続と特徴の潰れ

- 逆伝播で block0 の q・k に入る信号 δq・δk の部分空間（固定 256 枚、上位 k 主成分）を課題末ごとに取り、課題をまたぐ主角（principal angles）を両腕で比べる。予測: SL の部分空間は持続し（head の行と潰れた特徴が固定するため）、R0L は課題ごとに回る（head を 0 に戻し乱数ラベルで学び直すため）。
- この持続が因子 4（token の部分空間に残る）と因子 3（整合）を運ぶことを、数で示す。
- 「課題 100 では共有と head0 で差が無い（1.003）」を、特徴が潰れていれば新しい head も同じ向きを読む（ラチェット）で説明できるか。head0 から 100 更新後の新しい head の行と、共有 head の行の部分空間の主角で確かめる。

### Q5. 成長則をまとめる

- SL: 実効 score 尺度 S(t) の成長則（例: dS/dt = lr·c·ρ(S)·…、ρ は整合の度合いで S とともに増える → 加速）。R0L: γ の縮みと逸れで S ∝ t^α（α < 0.5）。係数を保存状態から当て、t = 20〜100 の実測と比べる。
- 飽和は尺度の帰結である（score の差が尺度に比例して開くので、任意の固定した向きの成長で softmax は飽和する）ことを一文で導く。
- 腕の違いが入る場所を一つの図式にする（装填 → 読み出しの持続 → 上流の勾配の部分空間の持続 → 整合した歩 → 尺度の拡大 → 飽和 → 勾配の集中 → 体の遅さ）。導出した段と測った段を分ける。
