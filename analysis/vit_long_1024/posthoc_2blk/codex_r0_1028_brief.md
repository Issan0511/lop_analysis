## 2. 答えてほしいもの（優先順）

### Q1. 共通成分の書き手と、CLS の残差の爆発

1. R0 の注意 1 の出力の token 平均を、「CLS への注意の重み × CLS の value」と「残り」に分ける（全 query の注意の重みのうち CLS の分、CLS の残差ノルム対パッチ token の残差ノルム、注意の最大重み）。課題末ごと（0〜10 の毎課題、20、…、100）に R0 と S で。予測を先に書く（例: R0 では CLS が attention sink になり、全 query が CLS を読み、CLS の巨大な残差がそのまま共通成分になる）。
2. CLS の残差がなぜ爆発するか。候補の導出: head を 0 に戻すと logit = W h の尺度を head（3,840 パラメータ、1 歩 lr）が担うより体（6 M パラメータ、各 1 歩 lr）が担うほうが速いので、課題の中で h の尺度が伸び、LN が無いと戻らない。S は head が大きい（2〜4.6）ので h は伸びなくてよい。R0L は LN が ‖h‖ を固定するので head が担う。検証: 課題ごとの logit の尺度を ‖W‖ と ‖h‖ に分けて 4 腕で比べる。課題の中の h の尺度の軌跡（R0 の課題 10・30 の回し直し）。
3. 共通成分の成長則: 書き手ごとの寄与の時間変化（1.2 の表を細かく）と、何が何を増幅するか（注意の value・proj の重みのノルム、CLS の残差、FFN0 の開いた割合と fc2 のノルム）。

### Q2. 行が共通成分に逆らう向きの導出

- 命題の候補: 損失が CE で、ラベルが一様乱数（各クラス 1/10）なら、unit j の出力の共通成分 a_j(m2) は全画像の logit に同じベクトル（fc2 の列 × head）を足す。その期待勾配は、クラス平均の logit のずれを消す向きで、w_j·m2 を減らす（または bias で消す）。共通成分が伸び続けると w_j·m2 を負に保つために w_j が m2 に逆らって回り、unit は沈む。これを式にして、符号と大きさ（cos の中央値 −0.14〜−0.35）を R0・S の保存状態で照合する。文字 GPT の L0 の結果（chargpt_l0carrier_1023: 沈み = 自分の重みを通る押しの累積 = 行が共通成分に逆らって回る 10/10 ＋ 共通成分の成長 9/10）が既知なので、同じ分解（Δ(w·m2) = Δw·m2 + w·Δm2 + Δw·Δm2）を課題ごとに出す。
- bias の分担（fc1 の bias が共通成分を消す分）も出す。

### Q3. T90 の崩れは死か尺度か（介入）

保存状態からの回し直し（1 課題 ≤ 5,000 更新、同時 1 本、予測を先に書く）:

1. R0 課題 25・30・40・60 末から、次の課題を (a) そのまま、(b) head だけ学習率を 1/10・1/100（Adam の lr を head のパラメータ群だけ変える）、(c) head に入る特徴を定数で縮める（h を c 倍。関数を変えるので注意書き）、(d) 体を凍結して head だけ（linear probe、lr を変えて）、で回す。暗記率の軌跡と T90。予測: 課題 25〜30 では (b)(d) で 0.9 に届く（尺度が直接の原因）、課題 60 では届かない（死＝応答の喪失が効く）。
2. 同じ介入を S 課題 30・60 末でも 1 本ずつ（S は死が先なので (b)(d) で届かないと予測）。
3. 死の反実仮想（split_more.py の (b) と同じ）: 状態 t の重みのまま、m2 だけを k 倍して死と開いた unit の数を数え直す。

### Q4. まとめ

- R0 と S の崩れの順序の違い（R0: 尺度 → 死、S: 死 → 尺度）を、書き手の違い（注意 1 対 FFN0）と head の違い（戻す対共有）から説明する図式。導出した段と測った段を分ける。
- 本稿の機構の鎖（① 装填 → ② 押し → ③ 上流の共通成分 → ④ 幅 → ⑤ 応答の喪失）のどの段が R0 で走り、どの段が別の経路（尺度の爆発 → head の不安定）かを一文ずつ。
- 文献: attention sink（Xiao ら 2023）、massive activations（Sun ら 2024）、pre-LN なしの残差の尺度（Xiong ら 2020）、rank collapse（Dong ら 2021、Noci ら 2022）、LN なしの ViT の可塑性喪失（Joudaki ら）。引くなら原典を確かめ、使った主張を一文で。
