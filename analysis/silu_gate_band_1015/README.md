# SiLU・GELU の幅の条件を読み出しの閾まで下げられるか（1015）

依頼: V12 v6.0.0 の持ち主のセッション（「位置更新と分布幅の条件」）から 2 件。Issa の提起「幅と変な分布でないことを仮定すれば SiLU・GELU も深い負まで沈降すると言えるのでは」を、V12 の主張の文に入れるための数。新しい走は無い。ガウス・K 一定の期待値の数値と、既存の実状態の集計の読み直しだけ。

## 結論

1. **幅の条件は読み出しの分の閾（SiLU 0.940・GELU 0.568）まで下げられる。** その幅で、ゲートの分の期待値が帯の中でも沈める側であるのに要る重みの条件は 1 − T̄ ≤ 3.05（SiLU）・2.93（GELU）。ω*(σ) は σ について単調に増えるので、閾より広い幅では条件はさらに緩い（σ = 1.35 で 8.06・62）。実測の 1 − T̄ は最大でも 0.596 で、閾の幅でも約 5 倍の余裕がある。[ガウス（K 一定）・数値 ＋ 実測]
2. **1 − T̄ ≤ 1 は半正定値だけからは出ない。** 出力の bias の項を核に入れても出ない（反例は下）。証明には、他の unit が入力の 1 次関数を表せるという核の構造が要り、一般には言えない。実測を仮定に残す。

## 1. ω*(σ) の細かい格子

定義: ゲートの分の期待値（定理 6）は N(μ_d − μ_o)·[門 1 + (1 − T̄)·門 2]。門 1 = Cov(φ″, φ′)、門 2 = E[φ″]E[φ′]（ガウス z ~ N(rσ, σ²)、K 一定）。門 2 は帯 (r₂, r_z) の中だけで負 [厳密。stage17 GAUSS_MAPS §4]。帯の中で期待値が負になるのは 1 − T̄ > 門 1/|門 2| のときだけなので、ω*(σ) = min_帯 門 1/|門 2| が重みの許容量。

計算: `omega_fine.py`（stage17_1014_silu_return/theory の `gm_core.mp_eval`（mpmath 34 桁）と `gm_band.band`・`band_depth` を読み込むだけで、そちらには書かない）。帯の中を 40 等分して黄金分割で詰めた。同じ格子で、r ∈ [−12, −0.05] の 60 点で門 1 ≥ 0 も確かめた（全点で正）。結果は `results/silu_gate_band_1015/omega_fine.json`。

## 2. 実測の 1 − T̄（既存の集計の読み直し）

stage17 real/REAL_STATES.md §5.10（`mc_kernel2.py`、生きた unit 全部、2 seed、課題 2〜41 の 8 時点）。全体の版の最大は SiLU 0.585（課題 41）・GELU 0.596（課題 41）。探り針の版も 0.585・0.596。中央値は課題とともに 0.04 から 0.58〜0.59 へ上がる。上がる理由は調べていない（同報告 §7 の 6）。実状態の幅は課題 2 以降で 1.35 以上（GAUSS_MAPS §1(d)）。

## 3. 1 − T̄ ≤ 1 は半正定値から出ない

恒等式: 1 − T̄ = 1ᵀM1 / (N(μ_d − μ_o)) = (N − 1)·1ᵀM1 / (N·tr M − 1ᵀM1)。よって 1 − T̄ ≤ 1 ⟺ 1ᵀM1 ≤ tr M ⟺ M の非対角の和 ≤ 0 ⟺ T̄ ≥ 0。

- 半正定値だけの反例: M = 11ᵀ + εI。1ᵀM1 = N² + εN > tr M = N + εN で、1 − T̄ = (N − 1)(N + ε)/ε と際限なく大きい。GAUSS_MAPS §4.8 の「半正定値からは上界が出ない」と同じ。
- 出力の bias を核に入れた場合: 𝒦 ⪰ I ⊗ 11ᵀ なので、v̂_i のブロック P は P ⪯ (λ + 11ᵀ)⁻¹ を満たす。これは 1 の向きを抑えるだけで、入力どうしの正の結合は残せる。P = c·uuᵀ + εI（u = e₁ + e₂、c と ε は (λ + N)⁻¹ の数分の 1）はこの上界を満たし、M = Θ ∘ P の非対角は 2cΘ₁₂ > 0（Θ の成分は正）なので 1 − T̄ > 1。
- 証明に要るもの: 他の unit が入力の 1 次関数（Θ の列の向き）を表せて、P がその向きを抑えること。leaky でも ReLU でも、死んだ unit の多い状態ではこれは一般に言えない。

## 文案（V12 用、持ち主のセッションに渡す）

「SiLU・GELU でも、ガウス・K 一定で幅が読み出しの分の閾（0.94・0.57）以上なら、読み出しの分は相対位置が負の全域で沈める側である。ゲートの分は、二つの重みの比 1 − T̄ が 3 以下なら、同じ全域で沈める側である。実状態の 1 − T̄ は最大 0.6 で、幅は課題 2 以降 1.35 以上なので、どちらの条件も余裕をもって満たす。したがって模型の中に止まる位置は無い [ガウス（K 一定）・数値 ＋ 実測（1 − T̄ ≤ 0.6）]。」

## 4. 相 1（補題 1）は SiLU・GELU にも成り立つか（1015 午後、Issa「SiLU・GELU も相 1 で普通に沈むことは言いたい」）

| | SiLU | GELU |
|---|---|---|

読み: 出発点（p ≈ 1/2、r ≈ 0）から r = 0 を割るまでの道は、どの幅でも沈める側にある。釣り合い（上の零点）は常に r = 0 より下（−0.464・−0.804 以下）なので、期待では半数未満へ越える。幅が 0.73・0.45 を超えると零点は無くなり、実網の幅は課題 2 以降 1.35 以上なので、相 1 の途中で釣り合いは消える。leaky の釣り合い −1.72 と違い、SiLU・GELU の釣り合いは幅とともに深くなって消える（1007 拡張ノート E4 と一致）。

### 4.1 押しの大きさの下界（1015 午後、持ち主のセッションの依頼）

### 4.1 訂正（1016 未明、照合役の指摘）

`phase1_q0.py` は r を 0.05 刻みで走査し、「Q0 < 0 の最大の格子点」を釣り合いとして報告していたため、零点より 0.04〜0.05 深い値になっていた（SiLU σ 0.3: −0.5 → 真の零点 −0.464、GELU: −0.85 → −0.804）。`phase1_zeros.py`（走査 0.01 ＋ 二分法 1e−9、同じ評価器）で零点を求め直し、`results/silu_gate_band_1015/phase1_zeros.json` に置いた。σ < 0.73・0.45 では零点が 2 つ（上が安定 = r₀*、下が不安定）あり、旧の走査範囲 r ≥ −1.5 の外にある下の零点（SiLU −4.45・GELU −2.70 at σ 0.3）は見えていなかった。V12 本体の「r > −0.5・−0.85」も −0.464・−0.804（安全側に −0.46・−0.80）に直す。
