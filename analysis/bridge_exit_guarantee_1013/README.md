# ランダム課題列による保持からの退出を、どこまで保証できるか

2026-10-13。前回の「退出確率が消えなければ、いつか出る」の条件を更新式から閉じる作業。

## 結論

**全課題を同じJacobianで線形化し、Gaussianラベルを課題ごとに引き直す二乗誤差模型では、実際の容量上の保持を確率1で有限課題数のうちに失う例を、証明と厳密計算で確定した。**
保持判定は線形近似せず、更新先のReLUパラメータから元の容量核を再計算する。
全保持状態の退出確率下限や、保持領域の有界性は仮定せず、更新式から必要な帰還と退出確率を導いた。

**元の実験のCE・Adam・有限10クラスについては、確率1での退出保証はまだ出ていない。**
Gaussian模型の保証を実験の保証へ読み替えることはできない。
同じ凍結線形化でも、新ラベルを有限集合にすると、任意のラベル列で課題末の保持が続く例を厳密に確認した。
これは実Adamの永久保持を示す反例ではなく、ラベル分布を変えて保証を移す推論への障害である。

## 1. 今回は退出確率を仮定せず、更新式から導いた

全課題を通じて $f_0+Ju$ を訓練する。$J$ は開始点の全パラメータJacobianであり、
読み出しと両biasを含む。ただし、更新に伴って $J$ を再計算しない。
各課題は新ラベル $Y_t\sim\mathcal N(0,\sigma^2I)$ を一度引き、そのラベルを $T$ 更新の間固定する。

無正則化二乗誤差、一定歩幅 $0<\alpha<2/\|J\|_{\rm op}^2$、固定された任意の有限 $T\ge1$ について、
課題末の変位は厳密に

$$u_{t+1}=M u_t+B(Y_t-f_0),\qquad M=I-BJ$$

となる。$B=J^Th_T(JJ^T)$、$h_T(s)=[1-(1-\alpha s)^T]/s$。
到達空間 $V=\operatorname{range}J^T$ では、$M$ の固有値は $(1-\alpha s)^T\in(-1,1)$。
従って、平均の固定点を引いた座標 $x_t$ は

$$x_{t+1}=M x_t+\xi_t,\qquad \|M\|_V<1,\quad\operatorname{Cov}(\xi_t)|_V\succ0$$

という安定な線形再帰になる。

ここから次の三段を証明する。

1. **際限なく遠ざかり続けない。** 更新式から $\sup_t\mathbb E\|x_t\|^2<\infty$ が出る。
   Markov不等式により、確率1で、ある有界な球へ無限回戻る。
2. **戻った先から、退出できる配置に届く。** 到達空間内に保持外の開球が一つあれば、
   有界な球からそこへ入る確率は、Gaussian密度から正の値で下から抑えられる。
3. **無限回の機会を全て逃す確率は0。** 帰還時刻ごとに条件付き確率を連鎖させる。
   これで確率1で有限課題数のうちにその退出球へ入る。

この証明は、全保持領域で一様な $\varepsilon$ があると先に置いていない。
戻る球は経路によって違ってよく、その球の中で必要な下限を導出する。
保持領域の形を直接線形化する必要もない。

一般定理の幾何条件として残るのは「$\theta_0+V$ に真の保持外の開球がある」だけ。
次節では、その点も実際の容量式で確認する。
完全な証明は [proof.md](proof.md)。課題開始点からの変位へのridgeを加える版も含む。

## 2. 保持外の配置を具体的に示したので、この例では保証が閉じる

以前の厳密な保持配置を用いる。5入力 $x_n=e_n$、3隠れReLU、読み出し $(1,1,1)$、
隠れbiasは0、出力biasは $-7$、容量診断の $\lambda_{\rm cap}=1$。

$$Z_0=\begin{pmatrix}-8&-8&-8\\-14&-8&-18\\4&8&2\\-16&-6&-18\\16&10&12\end{pmatrix}.$$

標的unit3では

$$A_3=-27/1325<0,\qquad S_3=84/1075>0.$$

この保持はhardゲートの同一区画内で読み出し特徴の経路が作るもの。
平滑ゲートの微分項によるH4の橋を、そのまま再現した配置ではない。

この状態の全パラメータJacobianを $J_0$ とし、到達空間内の具体的な変位

$$u_*=J_0^T\mathbf1_5$$

を取る。更新先の前活性、読み出し、出力biasは

$$
Z_*=\begin{pmatrix}-6&-6&-6\\-12&-6&-16\\7&11&5\\-14&-4&-16\\19&13&15\end{pmatrix},
\qquad v_*=(21,19,15),\qquad\beta_*=-2.
$$

ここで元の容量核を計算し直すと、厳密に

$$\boxed{A_3(\theta_0+u_*)=759/138256>0,\qquad
S_3(\theta_0+u_*)=2712/115957>0.}$$

全ゲートは元と同じ区画にあり、最小の閾値余裕は4。
容量式はこの近傍で連続なので、$u_*$ の周囲に真の保持外の開球がある。
Jacobianの階数は3、$\operatorname{tr}(J_0J_0^T)=601$ なので、例えば $\alpha=1/602$ は安定条件を厳密に満たす。

**従って、この保持点から開始し、同じ $J_0$ による線形出力を、毎課題独立なGaussianラベルで、
無正則化・歩幅 $1/602$・任意の固定有限 $T\ge1$ 更新ずつ学習すると、元の容量上の保持を確率1で有限課題数のうちに失う。**

これは「あるラベル列なら出る」だけの結論ではない。
ランダムな無限課題列について、保持を一度も失わない確率が0、という結論である。
ただし、短時間に出ること、永久に保持へ戻らないこと、以後沈降し続けることは含まない。

検算: [verify_reachable_exit.py](verify_reachable_exit.py)、[厳密な出力](reachable_exit_checks.json)。
丸め計算や訓練シミュレーションで退出を確認したのではなく、有理数の式が保証の幾何条件を満たしている。

## 3. 有限ラベルへは、そのまま移せない

同じ $\theta_0,J_0$ を使い、新ラベルを $Y\in\{-1,1\}^5$ に変える。
各課題で同じglobal線形模型を最小二乗解まで当てはめる極限では、

$$u_{t+1}=J_0^+(Y_t-f_0)+(I-J_0^+J_0)u_t=J_0^+(Y_t-f_0).$$

$u_t\in\operatorname{range}J_0^T$ なので、前課題の状態が右辺から消える。
到達する課題末は32個しかなく、その全てで元の容量核を厳密に計算すると

$$-0.029096<A_3<-0.026337<0,
\qquad 0.092539<S_3<0.097256$$

となる。表示値は範囲を外側へ丸めたもので、符号の確認自体は有理数で行った。
従って**任意の無限ラベル列について、全ての課題末で保持が続く。**

この結果は課題途中での退出・再進入を否定していない。
また $J_0$ の階数は3なので、5入力の任意ラベルに対する最小二乗残差が0になるとは限らない。
訓練も元の非線形網のSGDではない。
保証できない推論は、「Gaussian更新が退出球へ届くのだから、有限ラベルを引き続けても同じ退出が保証される」という移し方である。

課題末の保持は、最小二乗解までの無限更新だけに依存する現象でもない。
32個の中心 $c_y=J_0^+(y-f_0)$ は全てゲート境界から離れた厳密保持点なので、
各中心の閉球が保持内に収まる共通の半径 $r>0$ がある。
中心間の最大距離を $D$、$L=\max_y\|c_y\|$、一更新の到達空間での収縮率を $\rho<1$ とすると、

$$u_{t+1}=c_y+(I-\alpha J_0^TJ_0)^T(u_t-c_y).$$

$\rho^T\max\{L,D+r\}<r$ を満たす同じ有限 $T$ を全課題で使えば、
初回に閉球の合併へ入り、その後も合併内に残る。
従って、十分長い固定有限課題でも全課題末の保持が成立する。
この存在証明でも、課題中の途中退出は否定していない。

検算: [verify_discrete_task.py](verify_discrete_task.py)、[全32件](discrete_task_checks.json)。
Jacobian、疑似逆の恒等式、課題間の不変式、全到達点の $A<0<S$ を有理数で確認した。

## 4. 元の実験に対して残ったこと

P171の訓練コードと報告は、以下の設定である。

- 1,200入力、784–100–10（注入後は隠れ110）、hard leaky係数0.1。
- 各課題で一様な10クラスのラベルを一度引き、16入力のバッチで4,000更新。
- CE、Adam、一定学習率 $10^{-3}$、$\beta_1=0.9,\beta_2=0.999,\epsilon=10^{-8}$。
- 注入時にAdamを初期化し、その後の課題間では履歴を保持。
- weight decay、ridge、clipping、射影による状態制限はない。

この更新は、§1の固定した収縮行列とGaussian駆動の再帰ではない。
ランダム課題の有限列には正の発生確率があるが、そのことだけから、
真の保持の外へ届くことや、届く状態へ繰り返し戻ることは導けない。

**実CE・Adamについては、全到達保持状態からの退出保証も、永久保持の反例も、今回得られていない。**
学習率を総和有限に変える等の別設定の永久反例は、この固定学習率の設定への反証として使わない。
前回の相対配置の揺れの定理も通常SGDの一歩の結果であり、これらの未解決部分を埋めない。
