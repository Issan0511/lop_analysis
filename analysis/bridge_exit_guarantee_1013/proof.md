# 固定 J・課題内固定 Gaussian ラベルによる厳密診断からのほぼ確実な退出

## 0. 定理の対象

本定理の訓練模型は、全課題を通じて同じ線形出力写像を使う。実網の非線形更新や CE/Adam の定理ではない。一方、保持判定の関数は線形化する必要がなく、元の非線形な容量診断そのものを用いてよい。

固定したθ₀、f₀=f(θ₀)、J=Df(θ₀)を取り、パラメータ変位をu、出力を f₀+Ju とする。S=Ran Jᵀ、rank J=r≥1。u₀∈S。各課題tで独立なY_t~N(0,σ²I)、σ>0を一度引き、そのラベルを課題のT≥1更新を通じて固定する。

課題開始点u_tからの変位δについて

    ℓ_t(δ) = (1/2)||f₀+Ju_t+Jδ−Y_t||² + (λ_tr/2)||δ||²,
    δ₀=0,

を一定歩幅αでT回fullbatch GDし、u_{t+1}=u_t+δ_Tとする。λ_tr≥0、0<α<2/(λ_tr+||J||op²)。λ_tr>0のときは各課題の開始点へのridgeであり、原点への通常のweight decayではない。λ_tr=0の無正則化も含む。容量診断で使うλ_capとは区別する。

K=JJᵀ、

    h(s) = [1−(1−α(s+λ_tr))^T]/(s+λ_tr),
    B = Jᵀ h(K),
    A = I_S−BJ|_S.

λ_tr=0かつs=0では連続な延長h(0)=αTを使う。Jᵀがその固有空間を消すので、Bの値に任意性はない。

課題境界の更新は厳密に

    u_{t+1} = A u_t + B(Y_t−f₀).

保持領域Hはθ₀+S上の任意のBorel可測集合でよい。たとえば厳密な元容量指標を用いた

    H = { θ : A_i(θ)≤0, A_i^self(θ)>0 }

でもよい。仮定する幾何条件は、**退出集合 (θ₀+S)\H がSに相対的な非空の開球を含むこと**だけである。これは一点の厳密な退出 witness とその近傍の連続性で証明できる。保持集合の有界性、保持状態全域の退出確率下限、保持法線の全域非退化性は仮定しない。

**結論:** 上記の幾何条件が成り立てば、τ=inf{t≥0:θ₀+u_t∉H} は各有限初期点から確率1で有限である。さらに退出開球には確率1で無限回訪問する。ただし退出後の非再進入や、速い退出時間はこの結論に含めない。

## 1. 課題写像と安定性を更新則から導く

δ_{k+1}=[I−α(JᵀJ+λ_tr I)]δ_k+αJᵀ(Y_t−f₀−Ju_t)。有限等比和を取ればδ_T=B(Y_t−f₀−Ju_t)。

Kの正の固有値s>0に対応するSの固有方向では

    h(s)>0,
    A_s = 1−s h(s)
        = λ_tr/(s+λ_tr) + [s/(s+λ_tr)](1−α(s+λ_tr))^T.

歩幅の厳密不等号より−1<1−α(s+λ_tr)<1。λ_tr>0ではA_sは1とこのT乗の、両係数が正で和1の凸結合なので−1<A_s<1。λ_tr=0ではA_s=(1−αs)^Tで同じ結論になる。有限次元性からρ=||A||op,S<1。

ノイズξ_t=BY_tはS上のGaussianで

    Q=Cov(ξ_t)=σ²BBᵀ,
    Q_s=σ² s h(s)²>0.

対称行列Aの固有方向ごとにQも対角になるため、この収縮はユークリッドノルムで成立する。一般の非正規行列にスペクトル半径だけから同じノルム評価を適用しているわけではない。

したがってQはS上正定値。平均の固定点はμ=−J†f₀∈Sである（J†はMoore–Penrose逆）。x_t=u_t−μと置けば

    x_{t+1}=A x_t+ξ_t.

ここまでに保持条件は使っていない。

## 2. 有界な球への無限回の帰還

ξ_tは独立、平均0なので

    E||x_t||² = ||A^t x₀||² + Σ_{j=0}^{t−1} tr(A^j Q (Aᵀ)^j)
              ≤ ||x₀||² + tr(Q)/(1−ρ²) =: M <∞.

E_Rを「ある時刻以降、常に||x_t||>R」とする。任意nについて

    P(∀t≥n, ||x_t||>R) ≤ inf_{t≥n}P(||x_t||>R) ≤ M/R².

n→∞からP(E_R)≤M/R²。したがって

    P(||x_t||→∞) = P(∩_{R∈N} E_R) =0.

ゆえに確率1で、ある整数Rについて球C_R={||x||≤R}へ無限回帰還する。Rは経路に依存してよい。この段階で不変分布やMarkov連鎖の再帰定理を引用する必要はない。

## 3. 各球からの退出確率をGaussian密度から導く

中心化座標における退出開球をO=B_S(z,ε)とし、必要なら半径を縮めてその閉包も退出集合に含める。q_min=λ_min(Q|_S)>0。

||x||≤R、y∈Oなら

    ||y−Ax|| ≤ ||z||+ε+ρR =: D_R.

Q-Gaussianの密度から

    P(x_{t+1}∈O | x_t=x) ≥ q_R >0,
    q_R = Vol_r(B(0,ε)) (2π)^(-r/2) det(Q|_S)^(-1/2)
          × exp[−D_R²/(2 q_min)].

このq_Rは保持全体で仮定した下限ではなく、更新則と選んだ有界球から導いた下限である。Rが大きいと極端に小さくなり得る。

## 4. 帰還時刻での連鎖律

固定Rについて、τ₁をC_Rへの最初の帰還時刻、τ_{k+1}をτ_k+1以降での最初の帰還時刻とする。Y_tは過去から独立なので、有限な停止時刻τ_kでも

    P(x_{τ_k+1}∉O | ℱ_{τ_k}) ≤ 1−q_R.

「最初のk個の帰還時刻が有限で、それぞれの直後もOに入らなかった」という事象の確率は、条件付き期待値の反復で≤(1−q_R)^k。k→∞により、C_Rに無限回帰還しながらOを一度も訪れない確率は0。各整数Rの可算和と§2からP(τ<∞)=1。

同じ議論を任意の有限時刻n以降に適用し、nについて可算共通部分を取ればOへの無限回訪問も得る。これも全域の一様退出確率は使わない。

## 5. 元の非線形容量診断への適用方法

必要なのは reachable affine space θ₀+S 上の一点u_*で、厳密な診断が保持外にあること。たとえば

    A_i(θ₀+u_*)>0

を有理演算等で証明し、その点がhard gateの境界z=0を避け、λ_cap>0を固定すれば、同一gate chamber内でA_iは連続である。その近傍に退出開球が存在し、本定理が適用される。自分自身の項A_i^selfの符号を維持する必要はないが、維持すれば同じ生きたunitの支えが解けるという解釈になる。

注意: 全課題の更新に用いるJはθ₀で固定される一方、診断A_iはθ₀+u_tにおける元の核から再計算する。この組合せは明確に定義された代理模型である。実網を毎更新再線形化する方法や真のCE/Adamに同じ保証が付いたとは表現しない。

## 6. 固定した原点へのridgeを使う別模型

毎課題の目的関数をu自身へのλ_tr||u||²/2にすると、課題境界のAは[I−α(JᵀJ+λ_tr I)]^T|_Sとなり、定数項と平均も変わる。しかし同じ歩幅条件で安定、QはS上正定値なので§2–4の証明はそのまま通る。前回のδに対するB式と混同しない。
