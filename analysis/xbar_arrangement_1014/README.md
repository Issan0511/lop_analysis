## 0. 一枚で

1. **導出 [厳密]**: z_kn = m_k K_n/K̄ + u⊥_kn（位置と模様の直交分解、恒等式）、K_n ≥ 1（画素が非負）、開く条件は u⊥_kn/|x̃^⊥_n| > (|m_k|/|x̄|) cot θ_n（θ_n = 入力と平均入力の角）。位置の沈降がゲートに効く強さは明るさでなく cot θ_n で決まり、cot θ_n > 0 が全入力で成り立つ。
2. **模型 M′（データを通した等方の向き）[厳密・模型]**: 模様 u⊥_kn の広がりは |x̃^⊥_n| に比例、unit 間の模様の相関は平均 0・sd 1/√PR = 0.18。訓練後もこの 2 つは初期と同じ [実測: sd 0.150〜0.191 対 等方 0.170〜0.174; 尺度則 R² 0.6〜0.8]。
3. **命題 1〜3 [厳密・模型 M′ ＋ 実測で支持]**: 占有は cot θ_n の減少関数（12/12 ファイルで Spearman(f, cot θ) −0.41〜−0.64 は K より強い）。全 unit で m_k < 0 なら全入力で f_n < 1/2 で、unit 側と入力側の分水嶺は同時に越える（課題 1 末: p > 1/2 の unit 65〜85 個・f ≥ 1/2 の入力 1,013〜1,190、課題 2 末以降 0〜1、12/12）。閾値の入力の場所は選び方の規則を入れた模型が全ファイルで当てる。
4. **橋の数 [実測・測定 B]**: 模型 M′ のモンテカルロ（各 unit の向きを等方に引き直し、実際の m_k・s⊥_k を保つ）は、leaky 10 条件で橋の数 N_i の平均（比 0.82〜1.32）・Fano（a0.1 1.63 対 1.59、a0.3 1.97 対 1.96、a0.5 1.39 対 1.43）・最大 N（±2）を無調整で再現する。ELU 4 条件は等方だけでは平均が 1/4 で、訓練が作る階数 1 の共通の模様 ū⊥ を足すと閉じる（平均の比 0.97〜1.07、Fano 3.62 対 3.48・4.87 対 4.92、N ≥ 10 の件数 32 対 33・80 対 73）。明るさの層の中で並べ替える帰無（第 1 版の模型）は 4〜14 分の 1 で破れる。
5. **留め置きの割合 [数値・(N*) と模型 M′ のもと]**: 模型の同時刻平均 c_N(t) と状態ごとの n_β(i,t) で状態ごとに Cantelli を当てると、ρ_R(i) の最大は 8 条件で 0.0021〜0.0161、閾値（14・11・8%）を超える標的 0/800。実測の橋の数は使っていない。
6. **並びの不利さ [実測・下見、測定 C は本文]**: probe 版の 実際／期待 は閾値の入力の明るさと順位相関 +0.57〜+0.74。層化した期待値が閉じる割合は §3。
7. **破れる所 [実測・測定 D]**: 3 層 RL-CIFAR の第 2 層で K2 ≤ 0 の入力は占有の最上位（順位 ≥ 0.994、12/17 で f ≥ 1/2）だが、ELU raw の覆し 28 件はそこにはなく（0/84）、予測の強い形は不支持。
8. **残る穴**: (M′1)(M′2) が訓練で保たれる理由、共通成分の由来と ELU で大きい理由、(N*)、n_β。m_k < 0 は入力。

## 3. 並びの不利さ（測定 C、P149 の 6 状態: a0.1・0.3・0.5 × seed 0・1。REPORT_C）

P149 の再現は 6/6 一致（log の 5 行が同一、unit ごとの相対差 ≤ 5e−13）。明るさの十分位の中に制限した並べ替えの期待値 E_strat（閉じた形）が、一様な期待値 E_full から実際の側へ閉じる割合の中央値:

- 実際／期待の中央値（seed 0）: probe 0.59 → 0.75（a0.1）、0.70 → 0.72、0.71 → 0.70; full 0.21 → 0.27、0.47 → 0.50、0.58 → 0.56。
- 実際は層化した期待値をなお下回る: probe 565/573 unit、z_strat 中央値 −3.9・−3.8（a0.1）、−12.1・−12.6、−13.7・−14.1（層化で sd が 0.40〜0.69 倍に縮むため z は full より大きい）。
- 層数 5〜120 で割合は動かない（a0.1 s0 full 0.33 → 0.37、probe 0.56 → 0.59）。|x̃|² で層化すると閉じる割合は小さい（0.19 / 0.35）。
- 明るさに沿った構造: M の対角は最暗の十分位で平均の 0.43〜0.51 倍、最明で 1.66〜1.84 倍。a0.1 では e′ の 70〜78%・d − a の 80〜85% が暗い半分にあり、a0.5 では e′ は半々（0.48〜0.49）、d − a は 0.58。
