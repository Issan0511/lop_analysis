## 1. 問いと答え

**問い（Issa）**: 自己項がここまで優勢なら、なぜ訓練は自己項に長期間逆らう配置（留め置き）を作れないのか。非増加の保存量のような概念は無いか。

**答え**: 保存量ではなく、2 つの分水嶺の同時の越えと、幾何で固定された相関の幅。全 unit の位置が負（m_k < 0。負の偏り）で、全入力の明るさが正（K_n ≥ 1、ゆえに cot θ_n > 0）なので、位置の沈降はどの入力の占有も 1/2 の下に押さえ、残る占有は平均入力から離れた入力（cot θ 小）に集まる。留め置きの材料は候補の模様どうしの正の相関だが、その幅はデータの実効次元が決める 1/√PR = 0.18 で、訓練は広げない（leaky）。橋の数は「各 unit の向きを等方に引き直し、実際の位置と幅を保つ」模型のモンテカルロが無調整で再現し（leaky 10 条件）、ELU は訓練が作る 1 本の共通の模様を足して再現する。模型の同時刻平均と n_β を状態ごとに Cantelli に入れた留め置きの割合の上界は 0.002〜0.016 で、実測の橋の数を使わない。

模型の流れ（Φ の降下）には非増加の量 Φ があるが、留め置きはその停留点なので単調性は何も禁じない（P155・P157）。実訓練で留め置きを壊すのは Φ 降下でない部分（課題ごとのラベル依存の当てはめ）で、そこに単調な量は無い。この部分は本ノートの外（[[瞬間の逆向き状態は長続きしない_H4の厳密化_1007]] §1-6）。

## 4. 留め置きの割合 [数値・(N*) と模型 M′ のもと]

模型の同時刻平均 c_N(t)（Var ≤ E、draw の分散 ÷ 平均 0.85〜0.98）と cobirth_seeds の状態ごとの n_β(i,t) で、leaky 8 条件: ρ_model(i) の中央値 0.0004〜0.0014、最大 0.0021〜0.0161、閾値（14・11・8%）を超える標的 0/800。c_N の中央値は実測の μ_i と 0.189 対 0.180（a0.1）、0.290 対 0.284（a0.3）、1.11 対 0.84（a0.5）。n_β < 10 の状態で c_N が平均の 1.5〜4.0 倍になり、cobirth_seeds が「周辺形は保守的でない」とした実測の N/μ 1.4〜2.8 倍を模型が持つ。状態で条件づけるので「N の分布が n_β によらない」の仮定は要らない。

## 5. 並びの不利さ（定理 6 の 実際／期待 0.2〜0.6）[実測]

明るさの層の中に制限した並べ替えの期待値が閉じる割合は、probe 版で a0.1 46〜59%、a0.3 12〜18%、a0.5 −13〜−16%（full 版 23〜32%・8〜11%・−8〜−9%）。深い unit の不利さの半分は明るさ（閾値の入力と残りの被覆が同じ側に濃い）、浅い unit では無い。残りの候補は橋で効いたのと同じデータの幾何（標的の模様と残りの模様の相関）で、等方に引き直した期待値 E_iso との比較は repo README §3（測定 C の続き）。

## 6. 破れる所 [実測]

3 層 RL-CIFAR の第 2 層（入力 h1、K2_n = µ₂·h1_n + 1）: K2 ≤ 0 の入力（判定状態 17 個）は占有の最上位（順位 ≥ 0.994、12/17 で f ≥ 1/2）で補題 1 の破れの帰結どおりだが、ELU raw の覆し 28 件の閾値の入力は K2 ≤ 0 でなく（e′ ∝ K2 で除かれる）、暗い側への偏りも対照と大差ない（0.31 対 0.21）。覆しの機構は負の明るさではない。P178 のハブも K2 の最小側でない。
