## 0. 記号

x̃_n = (x_n, 1) ∈ R^785、x_n ∈ [0,1]^784。x̄ = (1/N) Σ_n x̃_n、明るさ K_n = x̃_n·x̄、K̄ = |x̄|² = mean_n K_n。直交成分 x̃^⊥_n = x̃_n − (K_n/K̄) x̄、Σ⊥ = (1/N) Σ_n x̃^⊥_n x̃^⊥_nᵀ、実効次元 PR = tr(Σ⊥)²/tr(Σ⊥²)（seed 0 で 31.1、seed 1 で 29.9。|x̄| = 5.93、tr Σ⊥ = 49.6）。入力と平均入力の角 θ_n: cot θ_n = K_n/(|x̄| |x̃^⊥_n|)（0.37〜1.94、中央値 0.83）。unit k: w̃_k = (w_k, b_k)、z_kn = w̃_k·x̃_n、位置 m_k = w̃_k·x̄ = mean_n z_kn、模様 u⊥_kn（§1）、s⊥_k = sd_n u⊥_kn。開いた入力 O_k = {n : z_kn > 0}、p_k = |O_k|/N、生きた unit = p_k > 0。占有 f_n = 生きた unit のうち n で開くものの割合。閾値の入力 T_i・橋・N_i・C_i・n_β は cobirth_seeds_1013 と同じ。

## 1. 厳密な部品

**補題 1（明るさの正値性）[厳密]。** K_n = x_n·x̄_pix + 1 ≥ 1（全成分が非負）。ゆえに cot θ_n > 0 が全入力で成り立つ。この箱では K: min 12.0・max 73.5・mean 35.1・sd 9.87（seed 1: 11.5・77.4・35.9・10.3）[実測]。

**補題 2（位置と模様の直交分解）[恒等式]。** w̃_k = (m_k/K̄) x̄ + w⊥_k、w⊥_k ⊥ x̄ と分けると
  z_kn = m_k (K_n/K̄) + u⊥_kn、 u⊥_kn := w⊥_k·x̃_n = w⊥_k·x̃^⊥_n、 Σ_n u⊥_kn = 0。
位置の向きの動き（w̃ → w̃ + t x̄）は m_k を tK̄ 変え u⊥ を変えない。z の変化は Δz_kn = t K_n で、補題 1 により全入力で同符号。検算: 残差 ≤ 3e−12 [検証役]。

**系 1（開いた集合は水準集合）[恒等式]。** k が n で開く ⟺ u⊥_kn/K_n > −m_k/K̄（符号によらない。m_k < 0 なら右辺は |m_k|/K̄ > 0、m_k = 0 なら 0）。位置だけが沈むと開いた集合は u⊥/K の順に縮む（L3′）。閾値の入力は u⊥_kn/K_n ≈ |m_k|/K̄ の入力。

**補題 3（平均 unit）[恒等式]。** z̄_n = mean_k z_kn = m̄ (K_n/K̄) + ū⊥_n、Σ_n ū⊥_n = 0。

**補題 4（角の恒等式）[恒等式]。** K_n/|x̃^⊥_n| = |x̄| cot θ_n。開く条件を模様の尺度 |x̃^⊥_n| で割ると u⊥_kn/|x̃^⊥_n| > (|m_k|/|x̄|) cot θ_n。**位置の沈降が入力 n のゲートに効く強さは、模様の自然な尺度で測ると明るさ K_n でなく cot θ_n で決まる。** 平均入力と直交する入力（θ = 90°）には位置の動きが効かず、K_n ≤ 0 の入力では沈降が前活性を上げる。

## 2. 模型 M′（データを通した等方の向き）と、その成り立ち

- (M′1) 各 unit の模様の向き w⊥_k は x̄ の直交補空間で等方（ガウス）。
- (M′2) unit 間で向きは独立。訓練が足す共通成分は別に扱う（§4）。

**補題 5（等方の向きの模様の統計）。** g ~ N(0, I_785)、w⊥ = σ P⊥ g（P⊥ = I − x̄x̄ᵀ/K̄）とすると
  (a) u⊥_kn = σ g·x̃^⊥_n ~ N(0, σ² |x̃^⊥_n|²) [厳密・模型 M′]。入力の上の分散 s⊥_k² の期待値は σ² tr(Σ⊥) で、相対 sd は √(2/PR) = 0.25（集中しない）。実現した s⊥_k で割った標準化 ξ_kn = u⊥_kn √tr(Σ⊥)/(s⊥_k |x̃^⊥_n|) は分散 1 で裾が軽い（P(ξ > 3) は Φ̄ の 0.66 倍）[模型 M′・主要項]。
  (b) 開く条件は ξ_kn > λ_k cot θ_n、λ_k := (−m_k/s⊥_k) · √tr(Σ⊥)/|x̄|（符号つき: m_k < 0 で正、m_k = 0 で 0、m_k > 0 で負）（unit の深さ × データ定数 1.19。a0.1 の相 2 で λ_k の中央値 3.2）[模型 M′・主要項]。
  (c) 独立な 2 unit の模様の入力の上の相関は平均 0、分散の主要項は tr(Σ⊥²)/tr(Σ⊥)² = 1/PR（H = 100 の等方の帰無では sd 0.170 = 0.95/√PR）[模型 M′・主要項]。

**成り立ち [実測]。** (a) の尺度則: 入力ごとの模様の広がりは |x̃^⊥_n| に比例する（初期重みで回帰の R² 0.79〜0.82・相対切片 +0.03〜+0.09。等方の MC でも傾き 0.98）。相 2 では比例より速く伸びる（R² 0.59〜0.81・相対切片 −0.42〜−0.62、帰無の切片は −0.03〜+0.11）。(c) の幅: 等方の帰無 0.170 に対し、実測の状態の中の sd は leaky で 0.148〜0.159、ELU で 0.182。**訓練は幅を leaky で 7〜13% 狭め、ELU で 6% 広げる**（帰無の外に出る状態は leaky 33/40、ELU 9/10）。幅の尺度（0.15〜0.19 = 1/√PR の 0.8〜1.1 倍）はデータの実効次元が決め、訓練はその 1 割前後を動かす。**(M′1) そのものは訓練後の w⊥ では破れている**: 等方性の指標 s⊥²/(|w⊥|² tr Σ⊥/785) の中央値は初期 0.97、T100 で 0.38（重みはデータの張る空間に寄る）[検証役 V4]。模型が近似として使えるのは、重み空間の等方性ではなく、入力の上に誘導された模様の統計（尺度則と幅）が等方の場合の 1〜3 割以内にあることによる。訓練がなぜそこに留まるかは [未導出]。読み出しの向きの cos とは無相関（Pearson ±0.1）[実測]。

## 3. 導出

**命題 1（占有は cot θ の減少関数）[模型 M′・主要項]。** λ_k を符号つきに取ると（補題 5 (b)）、入力 n の占有の期待は
  F(n) = (1/H) Σ_{k 生} Φ̄(λ_k cot θ_n)、
で、m_k < 0 の unit の項は cot θ_n の減少関数、m_k > 0 の unit の項は増加関数、m_k = 0 の項は定数 1/2。全 unit で m_k < 0 なら F は cot θ_n の減少関数（相 2 では m_k ≥ 0 の unit は a0.5 以外で 0、a0.5 で 0〜2 個）。暗い入力ほど cot θ が小さい（corr(cot θ, K) = 0.87）ので占有は暗い入力に偏る。
検算 [実測・測定 A]: 占有 f は 12 ファイル・全状態で K と負相関（Pearson −0.28〜−0.49）、cot θ との Spearman は 12/12 ファイル・89〜90/90 状態で K より強い（中央値 −0.41〜−0.64 対 −0.30〜−0.51）。等方の向きの MC（各 unit の実際の m_k・s⊥_k）は占有の八分位の形を比 0.54〜0.84（最暗）〜0.90〜1.14（最明）で近似する（Pearson(f, f_iso) 0.52〜0.70）。第 1 版の交換可能模型（広がりを入力によらないとした）は最暗を 2〜3 倍過大に見積もり 12/12 で破れた。ELU は等方の予測を明るい側ほど上回る（八分位 2〜8 で 1.2〜2.1 倍。§4 の共通成分）。最も混む入力は cot θ が全入力の最小側（順位 1077〜1199/1200）で、命題 1 の帰結。

**注釈 2′（入力側の鏡像。押しの向きの条件ではない）[厳密・模型 M′、期待値の文]。** λ_k を符号つきに取ると、unit の符号によらず
  F(n) − 1/2 = (1/H) Σ_k [Φ̄(λ_k cot θ_n) − 1/2] = −(1/H) [D₋(n) − D₊(n)]、
  D₋(n) := Σ_{m_k<0} [1/2 − Φ̄(λ_k cot θ_n)] ≥ 0（負の位置の unit の余白）、D₊(n) := Σ_{m_k>0} [Φ̄(λ_k cot θ_n) − 1/2] ≤ H₊/2（正の位置の unit の超過。H₊ = m_k > 0 の unit 数）。m_k = 0 の unit は 0 を足す。
ゆえに F(n) < 1/2 ⟺ D₋(n) > D₊(n)。「全 unit で m_k < 0」は D₊ ≡ 0 の特別な場合で、縁 m_k = 0 に余白の無い全か無かの前提は要らない。補題 1（cot θ_n > 0）により D₋(n) は cot θ_n の増加関数なので最悪の入力は cot θ の最小の入力（0.37・0.40）で、十分条件は H₊ < 2 D₋(n_min) =: H_crit。H_crit/H は、最悪の入力で F が 1/2 に届くまでに許される常時点灯 unit（超過 1/2）の割合。実測の重みから（12 ファイル、`fable_graded_prop2.py`）: 初期化 0.13（m ≥ 0 の unit 46〜48、D₋ ≈ D₊ で F の最大 0.48〜0.50。縁の上なので実現値の f ≥ 1/2 は 187・600 入力に散る）、課題 1 末 0.00〜0.04（m ≥ 0 の unit 41〜92、D₊ ≫ D₋、模型の F ≥ 1/2 は leaky で全 1,200 入力、実現値 643〜1,190）、課題 2 末 0.22〜0.36（m ≥ 0 の unit 0〜5 個が 7 ファイルに残るが D₊ ≤ 0.3 ≪ D₋ 11〜18、模型の F ≥ 1/2 は 0 入力、実現値 0〜1）、相 2 の 90 状態で 0.52〜0.86（a0.5 は 0.28〜0.40。a0.5 は 90 状態中 24・26 に m ≥ 0 の unit が 1〜2 個いるが D₊ は余白の 1% 未満）。**入力側の越え（期待値）は unit 側の余白の反転（D₊ > D₋）を必要とする**（逆は言えない）。注意 2 つ。(i) unit 側の変数は位置 m_k で、開いた割合 p_k ではない。位置のずれは明るさ K_n に比例するので m_k < 0 かつ p_k ≥ 1/2 の unit がある（課題 1 末 leaky 1〜3・ELU 8〜9、相 2 は a0.5 の 1・3 状態に 1 個）。(ii) 模型の F は共通成分を含まないので、相 2 の実現値で f ≥ 1/2 になる a0.5（35・6 状態）・ELU s1（1 状態）は命題 2′ でも説明されず、§4 の共通成分による。

**なぜ条件でないか（1014 夜 2、Issa「開いた側に偏っていても自己項に従って閉じる側に行く」）。** 自己項は位置によらず沈める側である: 定理 1 の自己項 Σ_n c_n d_in は c_n ≥ 0・d_in > 0 で常に正、読み出しの道の段 1 は Cov(φ′, φ) ≥ 0、切替の押しの自己形 Σ K d φ は r*₀ < 0 より上で正 [厳密]。位置で符号が変わる項は段 2 の残り（他 unit が z_i の 1 次式を作れると置いた期待）だけで、その固定点 p = 1/2 を現実は上から訪れない: p > 1/2 の unit がある唯一の状態（課題 1 末、p > 1/2 が 61〜89 unit）で段 2 はその 61〜74% を開く側と予測したが、実際は 99〜100% が沈んだ（1006 ノート。運んだのは H1 の切替の押しで、容量の押しは冗長な unit の間で 9 割打ち消す。G8）。入力側も同じで、できかけのゲートの自己項は多数派が開いた入力でも閉じる側なので、F(n) < 1/2 は押しの向きの条件ではなく、G7b の補題（leaky のゲートの中点 (1+a)/2）の十分条件にすぎない。問われるのは残り（その入力で開く他 unit の重み）対 n_β だけで、それが §3 の橋の数の文である。この注釈に残る中身は、恒等式「入力側の占有は K_n ≥ 1 を通して unit の位置に従う」と余白の数。
検算 [実測]: 課題 1 末（stoch の t = 2）は p > 1/2 の unit が 65〜85 個、f ≥ 1/2 の入力が 1,013〜1,190/1,200（ELU 643・758）、平均 r は +0.15〜+0.31。課題 2 末で f ≥ 1/2 は 0〜1、課題 3〜12 は 12 ファイル全部で 0。留め置きが課題 1 末にだけあること（P170・P177）はこの越えの時刻と一致する。**相 2 の実現値はこの文の外に出る**: a0.5 の 2 seed（35/90・6/90 状態、1〜3 入力、最大 0.58）と ELU s1（1/90）で f ≥ 1/2 になり、その 42 状態のうち 30 では m_k > 0 の unit が 0 個。超過は §4 の共通成分による（等方の帰無ではその入力の F 0.23〜0.33、共通成分を足すと 0.45〜0.63）[検証役 V6]。

**命題 3（閾値の入力の場所）[厳密・模型 M′ ＋ 選び方の規則]。** 入力 n が unit k の閾値（|z_kn| < δ）にある確率は 2δ φ(λ_k cot θ_n)/(s⊥_k |x̃^⊥_n|/√tr(Σ⊥)) に比例し、深い unit（λ 大）ほど cot θ の小さい入力に集まる。閾値の入力の選び方 e′_kn ∝ K_n s(1−s)/τ には明るさの因子 K_n が入るので、浅い unit（λ 小、a ≥ 0.2）では K_n の因子が勝ち、閾値の入力は明るい側に寄る。
検算 [実測・測定 A]: 「|z| 最小 3 つ」の規則では閾値の入力は全 12 ファイルで暗い側（中央値より暗い割合 0.60〜0.88、模型の予測と 0.03 以内）。cobirth の e′ の規則では a0.03 と ELU-E2 で暗い側（0.69〜0.73）、a0.1 と E1 で無偏（0.49〜0.56）、a ≥ 0.2 で明るい側（0.28 → 0.005）。規則を入れた模型の MC は全ファイルで向きと順序を当てる（実測 − 模型 −0.10〜+0.02）。

**系 2（並びが無作為より不利な側にある理由）[模型 → 測定 C]。** 定理 6 の期待値は標的の (e′, d) を入力の上で一様に並べ替える。残りの被覆（M の構造）は cot θ の小さい入力に濃く、深い標的の e′ と d も同じ側に濃い。両方が同じ入力に集まるので、実際の A^g は一様な並べ替えの期待値を下回る。
結果 [実測・測定 C、P149 の 6 状態、閉じた形の層化期待値、P149 の再現は 6/6 一致]: probe 版（unit 自身のゲートの道を除いた核。確率の文として厳密な版）の 実際／期待 は閾値の入力の明るさと順位相関 +0.74・+0.57・+0.67（a0.1・0.3・0.5、seed 0）。明るさの十分位の中に制限した並べ替えが一様な期待値から実際の側へ閉じる割合の中央値は、probe 版で a0.1 59%・46%、a0.3 12%・18%、a0.5 −13%・−16%（負 = 遠ざかる）、full 版で 32%・23%、8%・11%、−8%・−9%。層数 5〜120 で動かない。実際は層化した期待値をなお下回る（probe 565/573 unit）。**明るさは深い unit の不利さの半分を説明し、浅い unit では説明しない。** 残りはデータの幾何だった [実測・測定 C の続き、6 状態、150 回]: 標的の模様だけを「同じデータを通した等方な向き」（実際の m_i・s⊥_i を保つ）に引き直した期待値 E_iso（M は固定）は、一様な期待値から実際までの差を probe 版で 93%・78%・98%（seed 0）・93%・70%・110%（seed 1）閉じ、実際の値は |z_iso| ≤ 2 の帯に 85〜91% の unit で入る（z_iso の中央値 −0.7〜+0.3、実際 < E_iso は 40〜68%）。full 版（自身のゲートの道を含む）では 43〜68% で、残りは並びでなく自己遮蔽。読み出しの分は 63〜79% 閉じるが実際はなお下（z −1.1〜−5.5）。等方の標的は実際より少し広い（p 1.07〜1.16 倍）。**定理 6 の「実際の並びは無作為より −3.4〜−8.1 標準偏差不利」は、一様な並べ替えがデータの幾何を壊していたためで、訓練された標的の模様は同じデータを通した無作為な向きと比べて不利ではない（probe 版）。** 深い unit で明るさが半分を説明したのは、cot θ がその幾何の一部だから。

**命題 4（橋の数のモーメント）[厳密・模型 M′]。** 標的 i の閾値の 3 入力 T_i と開いた集合 O_i を与えると、模型 M′ では候補 k が橋である事象は k の向きの関数で unit 間で独立。ゆえに N_i | (T_i, O_i) は Poisson 二項（Var ≤ E）、C_i も同じ。課題を通して (T_i, O_i) が動くので、全分散の法則で Var_t N_i = E_t Var[N | T_i, O_i] + Var_t E[N | T_i(t), O_i(t)] ≤ E_t N + Var_t c_N(t)。過分散は、標的の閾値と開いた集合が「混んだ」入力に着地するかどうかの揺れから出る。「各 unit の向きを等方に引き直し、実際の m_k・s⊥_k を保つ」帰無（iso）はこの模型のモンテカルロで、明るさの層の中で各 unit のゲートの列を並べ替える帰無（strat、第 1 版の模型）は補題 5 (a)(c) の構造を壊す。

## 5. 何が変わるか・変わらないか

変わる:
- 配置の統計のうち、占有の形（命題 1。変数は明るさでなく cot θ_n）・入力側の占有が unit の位置に従うことと越えの時刻（注釈 2′。押しの向きの条件ではない）・閾値の入力の場所（命題 3）・最も混む入力の位置は、負の偏りと入力の幾何からの導出（模型 M′ の主要項）になった。
