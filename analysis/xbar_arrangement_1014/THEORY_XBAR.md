# x̄ 方向の沈降と入力の幾何が作る配置の統計 — 負の偏りを入力側で読む（Fable、1014、第 2 版）

進める段（1 行）: 「訓練された配置では残りが自己項を上回らない」の未導出部分のうち、配置の統計（占有が暗い入力に偏る・入力側の分水嶺・閾値の入力の場所・並びが無作為より不利な側・橋の数）を、全 unit の負の偏り（m_k < 0）・明るさの正値性（K_n ≥ 1）・入力の幾何（模様の広がりは入力の直交成分のノルムに比例し、unit 間の模様の相関の幅はデータの実効次元で決まる）から導く。新生の独立も Fano の上界も仮定しない。第 1 版（模様は入力の上で交換可能）は測定 A・B で破れたので、本版では模型を「データを通した無作為な向き」（等方の幾何）に差し替えた。

格: [厳密]・[恒等式]・[厳密・模型 M′]（模型を明示した上での厳密）・[実測]・[予測]・[未導出]。箱は 1 層 784-100-10・固定 1,200 入力・乱数ラベル 10 クラス・Adam。相 2 = 課題 11〜100。数は特記なければ seed 0。

## 0. 記号

x̃_n = (x_n, 1) ∈ R^785、x_n ∈ [0,1]^784。x̄ = (1/N) Σ_n x̃_n、明るさ K_n = x̃_n·x̄、K̄ = |x̄|² = mean_n K_n。直交成分 x̃^⊥_n = x̃_n − (K_n/K̄) x̄、その Gram の平均 Σ⊥ = (1/N) Σ_n x̃^⊥_n x̃^⊥_nᵀ、実効次元 PR = tr(Σ⊥)²/tr(Σ⊥²)。入力と平均入力の角 θ_n: cos θ_n = K_n/(|x̃_n||x̄|)、cot θ_n = K_n/(|x̄| |x̃^⊥_n|)。unit k: w̃_k = (w_k, b_k)、z_kn = w̃_k·x̃_n、位置 m_k = w̃_k·x̄ = mean_n z_kn、幅 s_k = sd_n z_kn、模様 u⊥_kn（§1）、s⊥_k = sd_n u⊥_kn。開いた入力 O_k = {n : z_kn > 0}、p_k = |O_k|/N、生きた unit = p_k > 0。占有 f_n = 生きた unit のうち n で開くものの割合。閾値の入力 T_i・橋・N_i・C_i・n_β は cobirth_seeds_1013 と同じ。

## 1. 厳密な部品

**補題 1（明るさの正値性）[厳密]。** K_n = x_n·x̄_pix + 1 ≥ 1（全成分が非負）。ゆえに cot θ_n > 0 が全入力で成り立つ。この箱では K: min 12.0・max 73.5・mean 35.1・sd 9.87（seed 1: 11.5・77.4・35.9・10.3）[実測]。

**補題 2（位置と模様の直交分解）[恒等式]。** w̃_k = (m_k/K̄) x̄ + w⊥_k、w⊥_k ⊥ x̄ と分けると
  z_kn = m_k (K_n/K̄) + u⊥_kn、 u⊥_kn := w⊥_k·x̃_n = w⊥_k·x̃^⊥_n、 Σ_n u⊥_kn = 0。
位置の向きの動き（w̃ → w̃ + t x̄）は m_k を tK̄ 変え u⊥ を変えない。z の変化は Δz_kn = t K_n で、補題 1 により全入力で同符号。検算: 恒等式の残差 ≤ 3.4e−13 [実測・測定 A]。

**系 1（開いた集合は水準集合）[恒等式]。** m_k < 0 のとき、k が n で開く ⟺ u⊥_kn/K_n > |m_k|/K̄。開いた集合は u⊥/K の超水準集合で、位置だけが沈むと u⊥/K の順に縮む（L3′）。閾値の入力は u⊥_kn/K_n ≈ |m_k|/K̄ の入力。

**補題 3（平均 unit）[恒等式]。** z̄_n = mean_k z_kn = m̄ (K_n/K̄) + ū⊥_n、Σ_n ū⊥_n = 0。

**補題 4（角の恒等式）[恒等式]。** K_n/|x̃^⊥_n| = |x̄| cot θ_n。開く条件 u⊥_kn > |m_k| K_n/K̄ を模様の尺度 |x̃^⊥_n| で割ると、u⊥_kn/|x̃^⊥_n| > (|m_k|/|x̄|) cot θ_n。**位置の沈降が入力 n のゲートに効く強さは、模様の自然な尺度で測ると明るさ K_n でなく cot θ_n（入力が平均入力にどれだけ揃っているか）で決まる。** 平均入力と直交する入力（θ = 90°）には位置の動きが効かず、K_n ≤ 0（θ ≥ 90°）の入力では沈降が前活性を上げる。

## 2. 模型 M′（データを通した等方の向き）

- (M′1) 各 unit の模様の向き w⊥_k は x̄ の直交補空間で等方（ガウス）。訓練は向きの分布を等方に保つ（leaky）。
- (M′2) unit 間で向きは独立。訓練が足す共通成分は別に扱う（§4）。

**補題 5（等方の向きの模様の統計）[厳密・模型 M′]。** g ~ N(0, I_785)、w⊥ = σ P⊥ g（P⊥ = I − x̄x̄ᵀ/K̄）とすると
  (a) u⊥_kn = σ g·x̃^⊥_n ~ N(0, σ² |x̃^⊥_n|²)。模様の広がりは入力の直交成分のノルムに比例し、入力の上の分散 s⊥_k² = σ² tr(Σ⊥) に集中する。ゆえに入力 n での標準化した模様 ξ_kn = u⊥_kn √tr(Σ⊥)/(s⊥_k |x̃^⊥_n|) は標準正規。
  (b) 開く条件は ξ_kn > λ_k cot θ_n、 λ_k := (|m_k|/s⊥_k) · √tr(Σ⊥)/|x̄|（unit の深さ × データ定数）。
  (c) 独立な 2 unit の模様の入力の上の相関 ρ_jk = g_jᵀΣ⊥g_k/√(g_jᵀΣ⊥g_j · g_kᵀΣ⊥g_k) は平均 0、分散は主要項で tr(Σ⊥²)/tr(Σ⊥)² = 1/PR。
検算 [実測]: (a) 入力ごとの模様の広がりは暗い八分位で 0.72〜0.76 s⊥、明るい八分位で 1.05〜1.11 s⊥、初期重みでも 0.78・1.04〜1.08（測定 A）。unit 平均の |u⊥| と |x̃^⊥_n| の相関 0.80〜0.87（下見）。(c) PR = 30.4 → 1/√PR = 0.18。実測の unit 間の模様の相関の sd は 0.147〜0.191、等方の帰無は 0.165〜0.173、初期重み 0.165〜0.174。q99 は実測 0.34〜0.39・帰無 0.38〜0.40（下見・測定 A）。**unit 間の模様の相関の幅は訓練でなくデータの実効次元が決める。** 読み出しの向きの cos とは無相関（Pearson ±0.1）[実測・下見]。

(M′1) の支え [実測 → 読み]: 初期化は文字どおり等方で、訓練後も (a) の尺度則と (c) の幅が初期と同じ。訓練が変えるのは向きの分布の平均（§4 の共通成分）で、分散ではない。

## 3. 導出

**命題 1（占有は cot θ の減少関数）[厳密・模型 M′]。** 入力 n の占有の期待は
  F(n) = (1/H) Σ_{k 生} Φ̄(λ_k cot θ_n)、
cot θ_n の減少関数。暗い入力ほど cot θ が小さい（corr(cot θ, K) = 0.87）ので占有は暗い入力に偏る。
検算 [実測]: 占有 f は 12 ファイル・全状態で K と負相関（Pearson −0.28〜−0.49）、cot θ との Spearman は K より強い（−0.50〜−0.69 対 −0.38〜−0.55、下見 4 状態）。等方の向きの模型のモンテカルロ（各 unit の実際の m_k・s⊥_k）は占有の八分位の形を比 0.65〜1.22（a0.1）・0.82〜1.03（a0.3）・0.84〜0.96（a0.5）で再現する。第 1 版の交換可能模型（広がりを入力によらないとした）は暗い側を 2〜3 倍過大に見積もり 12/12 で破れた（測定 A）。ELU は等方の予測を一様に 1.2〜1.7 倍上回る（§4 の共通成分）。

**命題 2（入力側の分水嶺）[厳密・模型 M′]。** 全ての生きた unit で m_k < 0（λ_k > 0）なら、補題 1（cot θ_n > 0）により各項 Φ̄(λ_k cot θ_n) < 1/2、ゆえに F(n) < 1/2 が全入力で成り立つ。ハブ（f_n ≥ 1/2）には m_k > 0 の unit の多数か cot θ_n ≤ 0 の入力が要る。逆に m_k > 0 なら各項 > 1/2。**unit 側の分水嶺（p = 1/2）と入力側の分水嶺（f = 1/2）は同時に越える。**
検算 [実測]: 課題 1 末（stoch の t = 2）は p > 1/2 の unit が 65〜85 個、f ≥ 1/2 の入力が 1,013〜1,190/1,200（ELU 643・758）、平均 r は +0.15〜+0.31。課題 2 末で f ≥ 1/2 は 0〜1、課題 3〜12 は 12 ファイル全部で 0。留め置きが課題 1 末にだけあること（P170・P177）はこの越えの時刻と一致する。相 2 で f ≥ 1/2 が出るのは a0.5 の 2 seed（35/90・6/90 状態、1〜3 入力、最大 0.58）と ELU s1（1/90）で、a0.5 には m > 0 の unit が 1〜2 個現れる。等方の模型自身は max 0.12〜0.36 で 1/2 に届かないので、この超過は模型の外（§4）。a0.5 で N ≥ 10 の塊が 1 入力の塊であること（cobirth）はこの同じ入力の話。

**命題 3（閾値の入力の場所）[厳密・模型 M′ ＋ 選び方の規則]。** 入力 n が unit k の閾値（|z_kn| < δ）にある確率は 2δ φ(λ_k cot θ_n)/(s⊥_k |x̃^⊥_n|/√tr(Σ⊥)) に比例し、深い unit（λ 大）ほど cot θ の小さい入力に集まる。ただし閾値の入力の選び方 e′_kn ∝ K_n s(1−s)/τ には明るさの因子 K_n が入るので、浅い unit（λ 小、a ≥ 0.2）では K_n の因子が勝ち、閾値の入力は明るい側に寄る。
検算 [実測・測定 A]: 「|z| 最小 3 つ」の規則では閾値の入力は全 12 ファイルで暗い側（中央値より暗い割合 0.60〜0.88、模型の予測と 0.03 以内）。cobirth の e′ の規則では a0.03 と ELU-E2 で暗い側（0.69〜0.73）、a0.1 と E1 で無偏（0.49〜0.56）、a ≥ 0.2 で明るい側（0.28 → 0.005）。規則を入れた模型のモンテカルロは全ファイルで向きと順序を当てる（実測 − 模型 −0.10〜+0.02）。

**系 2（並びが無作為より不利な側にある理由）[模型 → 予測 C]。** 定理 6 の期待値は標的の (e′, d) を入力の上で一様に並べ替える。残りの被覆（M の構造）は cot θ の小さい入力に濃く、深い標的の e′ と d も同じ側に濃い。両方が同じ入力に集まるので、実際の A^g は一様な並べ替えの期待値を下回る。下見 [実測]: P149 の probe 版（unit 自身のゲートの道を除いた核。確率の文として厳密な版）の 実際／期待 は、標的の閾値の入力の明るさと Spearman +0.74・+0.57・+0.67（a0.1・0.3・0.5）で並び、閾値の入力の占有とは −0.59・−0.33・−0.38。full 版（自身の道を含む）の比 0.21 は幅 p と並び（−0.39）、明るさとは並ばない（自己遮蔽で、並びの話でない）。**予測 C**: 明るさの十分位の中に制限した並べ替えの期待値 E_strat は E_full から実際の側へ動く。閉じる割合 (E_full − E_strat)/(E_full − 実際) を測る（測定 C）。
結果 [実測・測定 C、P149 の 6 状態（a0.1・0.3・0.5 × seed 0・1）、閉じた形の層化期待値、P149 の再現は一致]: 閉じる割合の中央値は probe 版で a0.1 59%・46%、a0.3 12%・18%、a0.5 −13%・−16%（負 = 層化で期待値が実際から遠ざかる）、full 版で 32%・23%、8%・11%、−8%・−9%。層数を 5〜120 に変えても動かない。実際は層化した期待値をなお下回り（probe 版で 565/573 unit、z_strat の中央値 −3.9・−12〜−14）、M の対角は明るい入力で大きい（最暗の十分位 0.43〜0.51 倍 → 最明 1.66〜1.84 倍）。**明るさは深い unit（a0.1）の不利さの半分を説明し、浅い unit では説明しない。** 残りは、橋の数で効いたのと同じ構造、すなわち定理 6 の一様な並べ替えが壊すデータの幾何（標的の模様と残りの模様の、データの実効次元による相関）にあると読める。標的の模様を等方な向きに引き直した期待値 E_iso（M は固定）との比較は測定 C の続きで、README に書く。

**命題 4（橋の数のモーメント）[厳密・模型 M′ → 予測 B]。** 標的 i の閾値の 3 入力 T_i と開いた集合 O_i を与えると、模型 M′ では候補 k が橋である事象は k の等方な向きの関数で、unit 間で独立。ゆえに N_i | (T_i, O_i) は Poisson 二項（Var ≤ E）、C_i も同じ。課題を通して (T_i, O_i) が動くので、
  Var_t N_i = E_t Var[N | T_i, O_i] + Var_t E[N | T_i(t), O_i(t)] ≤ E_t N + Var_t c_N(t)。
過分散は、標的の閾値と開いた集合が「混んだ」入力（cot θ の小さい、模様の相関の正の裾にいる候補の多い）に着地するかどうかの揺れだけから出る。**「各 unit の向きを等方に引き直し、実際の m_k・s⊥_k を保つ」帰無（iso）はこの模型のモンテカルロ**で、**予測 B**: iso は N_i・C_i の μ と Fano を再現する。明るさの層の中で各 unit のゲートの列を並べ替える帰無（strat、第 1 版の模型）は、補題 5 (a)(c) の構造（広がりの尺度則と unit 間の相関）を壊すので再現しない。
結果 [実測・測定 B、14 条件・各 20 回]:
- strat（第 1 版の模型）は N の平均を実測の 0.07〜0.23（leaky）・0.01〜0.04（ELU）、C を 0.12〜0.93・0.07〜0.11 にしか再現せず、Fano ≈ 1（実測 N 1.39〜2.03・ELU 2.22〜4.87）。第 1 版の模型は橋の統計について破れた。
- **iso（模型 M′ のモンテカルロ）は leaky の橋の統計を再現する。** プールした N の平均の比 iso/実測 0.82〜1.32（a0.03 0.82・a0.1 1.07〜1.15・a0.2 0.95〜1.09・a0.3 1.05〜1.14・a0.5 1.30〜1.32）、C は 0.89〜1.15。プールした Fano: a0.1 実測 1.631 対 iso 1.589 [1.50, 1.67]、1.559 対 1.529、a0.2 2.034 対 1.862、1.711 対 1.865、a0.3 1.966 対 1.957、1.754 対 1.795、a0.5 1.390 対 1.426、1.440 対 1.462、a0.03 1.587 対 1.334・1.644 対 1.353（a0.03 だけ下回る）。最大 N: 7 対 7、6 対 7、11 対 10、8 対 10、14 対 12、9 対 10、10 対 11、10 対 12、6 対 4、7 対 5。標的ごとの F_i が iso の 5〜95% 帯に入る割合 0.70〜0.82。iso の幅は実測より 1.10〜1.36 倍広い（a0.5 の平均の 1.3 倍はこれ）。
- **ELU は iso では足りず（平均の比 0.21〜0.24、Fano 1.5〜2.1 対 2.2〜4.9）、共通成分を足した iso＋common で閉じる**: 平均の比 1.01・1.07・0.97・1.02、Fano 3.620 対 3.477、2.218 対 2.198、4.866 対 4.916、2.863 対 2.986、最大 N 18 対 18・11 対 11・28 対 28・14 対 18、N ≥ 10 の件数 32 対 33・1 対 2・80 対 73・10 対 14。標的ごとの F_i が帯に入る割合 0.82〜0.84。同時刻の帰無の平均の系列が実測の N_i(t) の分散を 58〜76% 説明する（iso だけでは 5%）。
- 層化しない並べ替え（flat）は何も再現しない（0/14）。
これで、**橋の数の 1 次・2 次モーメントは、データの幾何（Σ⊥）と各 unit の位置と幅、ELU ではそれに加えて訓練が作る 1 本の共通の模様から、無調整で出る量**になった。cobirth_1013 が実測で置いていた (B′)「Fano ≤ F̄」と、その前の「新生の独立」は、どちらも模型 M′ の計算に替わる。

**定理（留め置きの課題の割合）[厳密・(N*) と模型 M′ のもと]。** 状態 (T_i(t), O_i(t)) を与えた N_i が Poisson 二項なら、状態ごとに
  P(N_i(t) ≥ n_β(i,t) | 状態) ≤ c_N(t)/(c_N(t) + (n_β(i,t) − c_N(t))²)、 ρ_R(i) ≤ (1/T) Σ_t（右辺）、
c_N(t) = E[N_i | T_i(t), O_i(t)] は模型から計算する量（iso の同時刻平均）。状態で条件づけるので、cobirth_seeds の時間平均の形が置いていた「N の分布が n_β によらない」は要らない。入力は入力の幾何・各 unit の (m_k, s⊥_k)・標的の閾値と開いた集合・核から出る n_β だけで、橋の数の実測のモーメントは使わない。
結果 [数値・fable_state_cantelli.py、n_β のある leaky 8 条件、iso の c_N]: ρ_model(i) の中央値 0.0004〜0.0014、90% 点 0.0008〜0.0026、最大 0.0021〜0.0161。閾値（a0.1・a0.2 14%、a0.3 11%、a0.5 8%）を超える標的 0/800。最悪の標的（a0.1 seed 1）で閾値の 1/9、a0.5 で 1/30。模型の c_N(t) は実測の μ_i と中央値で 0.189 対 0.180（a0.1 s0）、0.290 対 0.284（a0.3 s0）、1.11 対 0.84（a0.5 s0）、同時刻の実測 N_i(t) との順位相関 0.28〜0.50、draw の分散 ÷ 平均 0.85〜0.98（Poisson 二項の Var ≤ E を満たす）。cobirth_seeds が「保守的でない」とした「n_β < 10 の状態で N/μ が 2.5〜2.9 倍」は、模型の c_N(t) がその状態で 1.5〜4.0 倍になることで再現され、状態ごとの形はそれを含んでいる。実測の周辺モーメントで作った状態ごとの形（cobirth_seeds の値）は最大 0.003〜0.007 で同じ桁。

## 4. 訓練が足すもの: 1 本の共通成分 [実測・由来は未導出]

模型 M′ で説明できない実測は 1 つの量に帰着する。unit 間で共有される模様の成分 ū⊥（平均 unit の模様）である。
- unit 間の模様の相関の**平均**が訓練で正に育つ: a0.1 で T11 の 0.011〜0.016 → T100 の 0.080〜0.085、ELU で 0.15〜0.18、a0.5 では 0.002〜0.004（測定 A）。sd（1/√PR）は変わらない。
- 模様の相関行列の最大固有値 ÷ 等方の帰無: ELU で T100 に 1.76〜2.21（帰無を超える固有値はちょうど 1 本、全 unit 共通の向きとの |cos| 0.83〜0.93）、a0.03〜0.1 で 1.26〜1.57（T60〜80 から 1 本）、a ≥ 0.2 では帰無の内側（0.65〜1.17）。**共通成分は階数 1 で、ELU で強く、浅い leaky では無い**（測定 A2）。
- 大きさ sd(ū⊥)·√H/mean s⊥（独立なら ≈ 1）: 初期 0.94〜1.10 → T100 で a0.03〜0.1 2.9〜3.0、a0.2 2.1〜2.2、a0.3 1.4〜1.9、a0.5 1.2〜1.5、ELU 3.8〜4.3。模様の分散に占める割合は leaky 1〜6%、ELU 12〜13%。
- 向き: データの上位主成分とは揃わない（|cos| ≤ 0.08）。ELU では ū⊥_n が |x̃^⊥_n| と正に相関（Spearman +0.55〜+0.59）し、占有の等方からの超過が明るい側で大きい（f/f_iso が八分位 2〜8 で 1.2〜2.1）。
- 占有の最大値が等方の予測を上回る分（a0.1 0.176 対 0.131、ELU 0.22 対 0.08）はこの成分で、最も混む入力そのもの（seed 0 で K = 30.1）は cot θ が全入力で最小側（順位 1077〜1199/1200）にあり、命題 1 の帰結（幾何）である。
この成分が橋に効く量は測定 B の iso＋common が示した: ELU の平均・Fano・最大 N・N ≥ 10 の件数を閉じ、leaky では iso と差が無い。由来（勾配の unit 和 Σ_k (v_k·残差) d_kn x̃_n の同じ向きの部分がなぜ育ち、ELU でなぜ大きいか）は [未導出]。ELU は閉じた側の感度 e^z で全 unit が全入力から勾配を受けるので、共通の方向の勾配が消えにくい、は読み。

## 5. 何が変わるか・変わらないか

変わる:
- 配置の統計のうち、占有の形（命題 1。変数は明るさでなく cot θ_n）・入力側の分水嶺とその越えの時刻（命題 2）・閾値の入力の場所（命題 3）・最も混む入力の位置は、負の偏りと入力の幾何からの導出になった。
- **橋の数の 1 次・2 次モーメント（平均・Fano・最大 N）は、模型 M′ のモンテカルロが leaky 10 条件で無調整で再現し（平均の比 0.82〜1.32、Fano の差 中央値 2.6%、最大 N は ±2）、ELU 4 条件は訓練の共通成分を足して再現する（平均の比 0.97〜1.07、Fano の差 2.5%）。** H4 の (B′)「Fano ≤ F̄」と、その前の「新生の独立」は、どちらも計算できる量に替わった。残る仮定は模型 M′（向きの等方性と unit 間の独立）、(N*)、n_β。
- 留め置きの課題の割合の上界は、状態ごとの形で、模型の c_N(t) と核の n_β(i,t) だけから 0.002〜0.016（8 条件の最悪の標的）、閾値の 1/9〜1/30。実測の橋の数は使っていない。
- 「自己項が優勢なのになぜ長期間逆らえないか」の配置側の答えが 1 文になる: **全 unit の m_k < 0 と全入力の cot θ_n > 0 により、位置の沈降はどの入力の占有も 1/2 の下に押さえ、残る占有は平均入力から離れた入力に集まる。留め置きの材料（候補の模様の正の相関）はデータの実効次元が決める幅 1/√PR = 0.18 の裾で、訓練がそれを広げることはなく（leaky）、足すのは 1 本の共通成分だけである。橋の数はこの幾何と各 unit の位置・幅から計算でき、留め置きに要る本数 n_β には届かない。** 保存量ではなく、2 つの分水嶺の同時の越えと、幾何で固定された相関の幅。
- 「並びが無作為より不利な側にある理由」は、probe 版については閾値の入力の明るさで並ぶ（系 2）。割合は測定 C。
- 第 1 版の交換可能模型と、cobirth の「新生の独立」に替える素な量（cos×ω）の縛りは、どちらも破れたことが分かった。

変わらない:
- m_k < 0 は入力（期待値では定理 6・段 2、実現値は実測）。
- (M′1)(M′2) は模型。訓練が向きを等方に保つ理由（leaky）と、共通成分の由来（ELU で大）は未導出。模様の広がりの尺度則は相 2 で |x̃^⊥_n| に比例より速く伸び（切片が負、測定 A2）、模型は近似。iso の幅は実測より 10〜36% 広い。
- n_β・(N*)・留め置きの解消（1 課題で壊れる）は従来どおり。閾値 14・11・8% は seed 0 の累積の値。
- a0.5 では m > 0 の unit が 1〜2 個現れる状態があり、f ≥ 1/2 の入力が 1〜3 個出る（35/90・6/90 状態）。命題 2 の前提の外で、模型自身は 1/2 に届かない。

## 6. 破れる所

- 補題 1 が破れる箱: K_n ≤ 0（cot θ_n ≤ 0）の入力があると沈降がその入力の前活性を上げ、命題 2 の外。測定 D（3 層 RL-CIFAR の第 2 層、入力 h1、K2_n = µ₂·h1_n + 1）: K2 ≤ 0 の入力は 17 個（判定状態、ほぼ LR raw）、その占有の順位は全部 ≥ 0.994、12/17 で f ≥ 1/2、ある状態では最も混む入力の 9/12 が K2 ≤ 0 [実測・支持]。**逆は成り立たない**: f ≥ 1/2 の入力は K2 > 0 にもあり（LR raw 45 個中 K2 ≤ 0 は 11）、ELU raw の覆し 28 件の閾値の入力は K2 ≤ 0 でなく（0/84。e′ ∝ K2 で除かれる）、暗い側への偏りも対照群と大差ない（0.31 対 0.21）。P178 のハブは K2 の最小側ではない（std では最も明るい側）。**覆しの機構が負の明るさにあるという予測は不支持。** ELU raw の課題 1〜2 では占有が明るい側に寄る（Spearman +0.30・+0.76）が、これは m_k > 0 の unit が多い相 1 で命題 2 の逆向きの帰結。
- (M′2) が破れる箱: 共通成分が大きい（ELU）。平均 unit の余裕 max_n ū⊥_n/(|m̄|K_n/K̄) は leaky a ≤ 0.3 で 0.21〜0.31、ELU で 0.58〜0.68（最大 0.91）、a0.5 では 1 を超える状態がある（1.51・1.30）[実測・測定 A]。
- (M′1) が破れる箱: 模様の向きが等方でない入力表現。
