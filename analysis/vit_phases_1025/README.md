The training implementation is frozen at its original commit `6164a5ea61b873959d9442653005c30cb548bc22`; hashes are checked against each original provenance. Original checkpoint tar archives are read without modification. There are no optimizer steps. Source/archive references and raw per-unit results are retained outside worktrees.

`states.csv` records head alignment, rank, fit, and fixed-probe positions. `pressures.csv` records the signed gradient projections into mu, SD, and mu/SD; positive S means that gradient descent would lower the statistic. `comparisons.csv` compares P1/P2 predictions with actual switch and fit gradients. `observed_drift.csv` describes the actual saved-trajectory displacement; it is not an integral of the measured SGD pressures.

`adam_*` uses the saved, bias-corrected second-moment denominator at task 10/60 end, held fixed across all signals; momentum is excluded. Its switch signal is the expected gradient after independently relabeling the same images. `adam_next_*` uses the next task's images (11/61) with loading still derived from the old task (10/60). Task 61 is hypothetical and generated by the original task sampler; no task-61 training occurred. These end-state checks are not at the same boundaries as the base start-state checks (9→10 and 59→60).

Loading refers to the final classifier's label-aligned component transported through all downstream layers. This is not an independent decomposition of the alignment of every intermediate FFN's own output matrix. P1 and P2 are conditional predictors, not additive mechanistic components. The P2 extension uses a pseudoinverse because the 250 by 384 head feature matrix cannot have independent columns. Conclusions must preserve those limits.
