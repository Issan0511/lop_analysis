# 有限10クラス・CE・Adamでの橋の退出：再検討

2026-10-13。**依頼された「橋の保持領域から確率1で退出する」保証は未成立。**
Gaussianラベル、凍結Jacobian、二乗誤差への置換を用いずに調べ直した。
以下で証明するのは、実際の更新則における駆動の持続である。
橋の退出まで証明したものとして引用しない。

## 1. 対象を固定する

P171の仕様：有限の固定入力1200個、10クラス、1隠れ層、leaky slope 0.1、
CE、Adam（学習率0.001、β₁=0.9、β₂=0.999、ε=10⁻⁸）、batch 16。
各課題で入力ごとに独立な一様ラベルを引き、4000更新の間は固定する。
読み出し、隠れ層、両biasをすべて更新し、Adam履歴は課題間で持ち越す。
P171の注入開始時にはAdam履歴をゼロ初期化する。
減衰・射影・clippingはない。

以下の定理はこの更新則の**実数演算、無限のiid課題列**について述べる。
有限精度の丸め・overflowや、固定seedの有限PRNG列についての保証ではない。
これはラベル分布や訓練則を変更する近似ではなく、確率的更新則の数学的定式化である。

保持を Hᵢ = {Aᵢ ≤ 0 < Sᵢ} とする。Aᵢは全unitを含めた多クラス容量の
位置方向の係数、Sᵢは当該unit単独の係数（P138の`A`と`Aal`）。
退出は課題末だけでなく、課題内のいずれかの更新でも数える。
Sᵢ ≤ 0による退出とAᵢ > 0による相殺の喪失も区別する。

### 「橋」と「反例」の関係（ユーザーの指摘を受けて定義を再確認）

1005ノート§16.1–2では、先に補助unitを設計して留め置きの反例を作り、
設計された支え役に共通する開き方を「橋」と名付けている。
その開き方は「標的の閾値の入力と、標的の開いた入力をまたいで開く」という署名である。
橋という独立の実体が先にあり、後で反例になると分かった、という順序ではない。

- **反例として構成された配置**は「自己項が沈めるなら、個々の配置でも必ず沈める」
  という無条件の符号主張を実際に破る。Hᵢがその判定である。
- **橋という開き方の署名**だけでは、反例であることの十分条件にならない。
  支え役の数・強さ・読み出しなども効き、測定上の橋がいてもAᵢ>0の状態がある。
  全ての読み出し経路の留め置きにこの署名が必要かも、1007ノートL1′では未導出。
- **並びについての期待値の定理**とは両立する。個別配置の反例を、期待値の反例と呼ばない。
- **ランダムラベルでの実学習で永久に保持する反例**には、持続の証明がさらに必要。
  静的な反例や位置だけの流れの停留点だけでは、それを示したことにならない。

したがって「橋は繊細だから壊れる」は命名からは出ない。
今の問いは「構成済みの静的な反例が、実学習でも持続するか」である。
また「反例を作るものが無ければ反例は無い」という言い換えでは説明にならない。
幾何的な橋の条件を使うなら、保持との含意と、その条件が学習中どう変わるかを別々に示す必要がある。

## 2. ラベルを引き直すと、生勾配の揺れは必ず戻る

各課題の**最初のbatch**を対象に、過去の全状態と、そのbatchの入力を条件とする。
まだ新ラベルを使った更新はないので、予測pₙとAdam履歴は固定されている。
最初のbatchには異なる16入力が入り、その選択は新ラベルと独立である。出力biasの勾配は

\[
g_b=\bar p-\frac1B\sum_{n\in\mathrm{batch}} e_{Y_n},
\qquad B=16,
\]

したがって、u=1/Cとして

\[
E[g_b]=\bar p-u\mathbf1,\qquad
\operatorname{Cov}(g_b)=\frac1B
 \left(\frac1C I-\frac1{C^2}\mathbf1\mathbf1^\top\right).
\]

特に

\[
E\|g_b-Eg_b\|^2=\frac{C-1}{BC}=\frac9{160}.
\]

隠れ層と読み出しがどう動いてきたかには依存しない。
ただし、既に新ラベルを使った課題内の後続更新へ同じ条件付き式を流用しない。

## 3. Adamでも、一定幅の更新が無限回起こる

**命題。** 任意に固定した出力class cについて、各課題の最初の更新は

\[
\Pr\left(|\Delta b_c|\ge\gamma\mid\text{過去とbatch入力}\right)\ge q,
\quad
\gamma=\frac{\eta(1-\beta_1)}{2B(1+\varepsilon)},
\quad q=(1-1/C)^B.
\]

本設定では γ ≈ 3.125×10⁻⁶、q ≈ 0.1853。
これは測定値ではなく、有限ラベルの確率とAdamの式から出る下限である。

**証明。** batch内のclass cの個数をKとするとKはBinomial(B,1/C)で、
g_c = p̄_c − K/B。K=0とK=1に対応する更新後の一次momentは

\[
m^{(0)}=\beta_1m+(1-\beta_1)\bar p_c,\qquad
m^{(1)}=m^{(0)}-\frac{1-\beta_1}{B}.
\]

二つの距離は(1−β₁)/Bだから、少なくとも一方の絶対値はその半分以上。
全履歴で|g_c|≤1、ゼロ初期化より補正後の二次momentはv̂_c≤1。
一次momentのbias補正は絶対値を小さくしない。よってその事象で
|Δb_c|≥γとなる。

K=0の確率はq、K=1の確率はB/(C−1)倍のq。
本設定ではB=16≥C−1=9なので、どちらの事象も確率がq以上ある。
この下限は現在の予測・momentum・読み出し・隠れ層に一様である。□

任意の課題以降、次のr課題で一度もこの大きさの更新がない確率は
(1−q)ʳ以下。条件付き確率を順に掛ければよく、更新同士の独立性は要らない。
r→∞とし、開始課題の可算和を取ると、**この大きさの更新は確率1で無限回起こる。**
したがって、全更新時刻で有限のパラメータ配置へ収束することはない。
課題末の状態だけの収束を、この命題から否定することはできない。

これは共通logitの平行移動だけの話でもない。
各batchで∑c g_c=0、ゼロ初期化より∑c m_c=0が保たれる。
非零momentには反対符号のmomentがあり、Adamの分母は正なので更新にも反対符号がある。
よって上の事象では、P_C=I−11ᵀ/Cとして
\(\|P_C\Delta b\|_2\ge\gamma/\sqrt2\) も成立する。

## 4. それでも、橋の退出はまだ出ない

P138の多クラス核は、中心化されたclass空間で

\[
\mathcal K
=\sum_j v_jv_j^\top\otimes D_j\Theta D_j
 +I_{C-1}\otimes(FF^\top+\mathbf1\mathbf1^\top).
\]

ここには**出力biasの値が入らない**。出力biasのJacobianが作る最後の項は定数。
したがってAᵢとSᵢも出力biasの値に依存せず、Hᵢはその方向に無限に延びている。
§3で下限を与えたのは出力bias成分であり、その成分だけでは保持条件は変わらない。
将来の隠れ層・読み出しへの影響はあり得るが、それが保持外まで達することは別途必要。

「ラベルがランダムなら揺れが止まらない」は、§2–3の意味で実条件でも証明できた。
**「その揺れが必ず保持領域を横切る」は証明できていない。**
永久保持の反例も、本設定では構成できていない。

未解決なのは、許された有限10クラスの課題列が、課題内4000更新とAdam履歴を含む
実際の更新で、保持している隠れ層・読み出しの配置を保持外へ運べるか、である。
ある一点から退出する課題列が見つかっただけでは、他の保持状態や全軌道の保証にならない。
全状態で正の退出確率を示せても、その確率が時とともに小さくなる可能性を除く必要がある。

SGDの一歩での勾配方向の凸包から、4000更新の課題写像の到達可能性は従わない。
Adamのgから更新への写像は履歴依存かつ非線形なので、SGDの揺れの下限もそのまま移せない。
前回の凍結Jacobian・Gaussian模型の退出証明は、この未解決部分を埋めていない。

## 付録A. 有界なパラメータ領域には永久には留まれない

より長い時間についても、同じ有限ラベル設定で次が示せる。

\[
\Pr\left(\sup_s\|\theta_s\|_\infty<\infty\right)=0.
\]

**証明。** 全パラメータが箱[-R,R]内にある間は、固定有限入力に対するlogitが有界。
あるδ_R>0があり、全入力・classでp_c≤1−δ_Rとなる。
全入力のラベルが同じclass cである課題を連続させると、どのbatchでもg_c≤−δ_R。
一次momentはk更新後に

\[
m_{s+k,c}\le(1+\delta_R)\beta_1^k-\delta_R.
\]

有限のk_Rを選べば右辺は−δ_R/2以下で、以後、箱内にいる間は毎更新

\[
\Delta b_c\ge\frac{\eta\delta_R}{2(1+\varepsilon)}.
\]

従って、k_Rに加えて4R(1+ε)/(ηδ_R)より多い更新があれば箱を出る。
それを覆う有限の課題数L_Rを選ぶ。各課題内ではラベルを変えていない。
その全class-c課題列の確率は10^(−1200L_R)>0で、batch順序には条件を付けなくてよい。
独立な長さL_Rの課題ブロックを用いると、その列は確率1で現れる。
よって箱に永久に留まる事象の確率は0。整数Rの可算和を取れば結論を得る。□

これは極めて稀な課題列を用いた無限時間の結果で、実用的な退出時間の評価ではない。
ノルムが単調に増えること、ノルムが∞に収束すること、隠れ層の前活性幅が伸びること、
橋の退出、LoPのいずれも、この命題からは出ない。出力bias方向の非有界性だけでも
上の結論を満たせるため、保持Hᵢへそのまま適用できない。
