# T5を測る式と、実測から区別するもの

基準走の結果を見る前に追加した測定式。これは複製実験の実行specではない。複製数・継続長・実行条件を固定したspecとrunnerを別途commitしてから複製実験を始める。

**境界微分の訂正（1025・結果を見た後）:** 元実装は`clamp`でありz=0で微分1を採る。以下のχ=1[z>0]の式は厳密な開口gateについての式として保持する。実装の次の更新を厳密に再現する主台帳にはg=1[z>=0]を用い、χの台帳と差E[c1[z=0]]も別に保存する。開口率の定義は変更しない。[発見・検算・保全](../../results/vit_two_block_1025/t5_boundary_correction.md)、[修正spec](../../specs/spec_vit_two_block_t5_boundary_1025.md)。

## 固定入力・固定計量での正確な分解

対象FFNのfc1だけを学習し、それ以前の入力uと、それ以外のパラメータを固定する。複製rは同じ状態から標本抽出列だけを変えたものとする。固定画像n・token t・unit iで

- `z_rnti = w_ri·u_nt + b_ri`、`χ_rnti = 1[z_rnti>0]`。
- `c_rnti = ∂L_n/∂a_rnti`、`a=ReLU(z)`。L_nは1画像のCE。ViTの後段、残差、LayerNormを含めて逆伝播する。
- 平均を測るprobe（CLS入力）の平均をm、全複製共通の固定正対角計量をDとし、`K_nti = mᵀD_wi u_nt + D_bi`。

SGD（D=I）、または固定Dでの勾配降下なら、全画像にわたる次の期待更新は

`E_r Δμ_i = −η/N Σ_nt K_nti { E_r[c_rnti] E_r[χ_rnti] + Cov_r(c_rnti,χ_rnti) }`。

画像nは最後に足し合わせる対象で、共分散を取る軸は複製rだけである。勾配は画像数Nで割り、token数で割らない。CLSの平均を測る場合も、共有fc1の更新には全tokenからの勾配が入る。次の標本抽出が一様で独立なら、右辺は次の確率更新の条件付き期待値でもある。

`t5_ledger.py`は同じ画像chunkを複製間で集約し、平均場項・ゲート共分散項・合計をunit別に返す。有限複製で恒等式を保つため共分散の分母はR。母共分散の不偏推定値R/(R−1)倍を別に出す場合は、恒等式用の項と混ぜない。

CPUの独立なautograd検算で、token和・画像数・bias・非一様なDを含む全勾配と照合する。画像chunk分割で答えが変わらないこと、同一の複製を繰り返すと画像間の違いが大きくても共分散が0であることも確認する。この恒等式が通ること自体はT5仮説への実験的支持ではない。

## 何が検証され、何が残るか

1. `Cov_r(ReLU(z),χ)=(1−p)E_r[z⁺]≥0`は恒等式であり、揺らぎがあることだけを示す。実ViTで測るべき押しは`K Cov_r(c,χ)`の総和である。KはLayerNorm後の入力では正とは限らない。
2. 箱Aの固定v・二乗誤差なら`c=2vd`を自己と他のunitへ分けられ、自己の係数にv²が現れる。CE・LayerNorm・多層では同じ自己分解は未導出。正の活性–ゲート共分散だけを見て、自己が勝った、正味が沈む、とは言わない。
3. 同じ初期状態のfull-batchと標本抽出ありの継続の差は「雑音を入れた総効果」。ゲート共分散項そのものとは同じでない。複製の平均軌道・平均場項の変化も含む。
4. 上の式は生のμへの次の期待更新。`r=μ/σ`にはσの変化があるので、その有限変位は別に記録する。実Adamの分母・momentumは複製ごとに変わるため、共通固定Dの勾配分解を実Adamの因果寄与率として転記しない。
5. まずunit別の符号・大きさを提示する。合計が相殺で小さいときの`共分散項/全体`は不安定で100%を超えうる。負の成分だけの比率を出す場合も「下向き項の大きさの構成比」と明記し、通常学習による全沈降の因果割合とは呼ばない。

必要な比較は、同じ画像・同じ初期状態・入力固定で標本抽出だけを変えた複製とfull-batch、固定計量と実Adam、各ブロックのμとμ/σである。相1の整列が押すunitとの重なりを測るには、同じ起点・同じunit番号で別途整列介入を比較する。既存の6層の割合を2層へ転用しない。
