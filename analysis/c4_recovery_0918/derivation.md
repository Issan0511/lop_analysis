# C4 やり直し：Adam による回復時間の上界

2026-09-18 / Codex。元設計 C4 の訂正と独立の導出。
C1–C3 の登録条件・判定・実行コードには変更を加えていない。

**結論**：戻す勾配の符号と、その大きさが急変しない条件から、Adam の戻り幅の下限を導き、累積によって回復時間の上界を与える。二次モーメントの履歴と ε を残す。「微分が 0 でなく、持続する押しがなければ 6000 更新で十分」は成立しない。本導出はスカラーの前活性が閾値に戻る時間を扱い、網の再学習精度の回復を証明するものではない。

## 1. 何を回復と呼ぶか

前活性 z が z0 < z* ≤ 0 から z* に初めて戻る時刻
T = inf{s ≥ 0 : z_s ≥ z*} を扱う。ELU なら z* = log(τ) と置いて微分が τ 以上に戻る時刻と読める。

以下の単純なモデルでは z を直接 Adam で更新する。実験の平均前活性 zbar をそのままスカラー Adam の座標とみなしてはいけない。多座標・動く入力への接続は §7 に別記する。

## 2. 戻す力は損失から出す

単一 ELU、固定の出力重み a ∈ (0,1]、正例の binary cross entropy を考える。

φ(z) = exp(z) − 1,  z ≤ 0,
L(z) = log(1 + exp(−a φ(z))).

したがって

g(z) = L'(z) = −h(z),
h(z) = a exp(z) / [1 + exp(a(exp(z)−1))] > 0.

符号は仮置きではなく、この損失を微分した結果である。さらに

d log h / dz
= 1 − a exp(z) σ(a(exp(z)−1))
∈ [1−a/2, 1].

よって h は単調増加で、log h の Lipschitz 定数は Lh = 1。
負側の任意の有限区間では h(z) > 0。浮動小数点のゼロ床はこの実数の定理には含めない。

この損失が全ニューラルネットの代用になるとは主張しない。
網の CE では ∂ℓ/∂z_i = φ'(z_i) v_iᵀ(p−y) であり、
後半の残差投影の符号も大きさも一様には保証されない。
「φ' が残る」だけから、この h > 0 は導けない。

以下はこの例に限らず、z ≤ z* で
h > 0、0 ≤ d log h/dz ≤ Lh を満たす勾配 g = −h に適用できる。

## 3. Adam の履歴を含む上界

Adam の式は [Kingma & Ba, Algorithm 1](https://arxiv.org/pdf/1412.6980) と、既存 src/resp_ee_0917.py の train_task の実装に合わせる。以下の上界はここでの導出であり、同論文の回復定理の引用ではない。

衝撃解除時の大域ステップを t0、保存された未補正 moment を m0, v0 とする。
解除後 s 回目に g_s = −h(z_{s−1}) = −h_s を読み、

m_s = β1 m_{s−1} − (1−β1) h_s,
v_s = β2 v_{s−1} + (1−β2) h_s²,
z_s = z_{s−1} − α [m_s/(1−β1^(t0+s))]
                    / [sqrt(v_s/(1−β2^(t0+s)))+ε].

α はこのスカラー座標の学習率であり、網の η(||μ||1+1) を自動的に代入できない。
まず m0 ≤ 0、v0 ≥ 0、押しなしとする。m_s < 0 なので z は単調に戻る。
t0 = 0 の標準初期化なら m0 = v0 = 0。t0 > 0 では時計・moment を保持する。

h0 = h(z0) と置く。一歩の上限 U は次で取れる。

- m0 = 0 のとき U = α/sqrt(1−β2)。
- m0 < 0 のとき
  U = α max(1, |m0|/h0) / [(1−β1^(t0+1)) sqrt(1−β2)]。
- より一般に |m0| ≤ h(z0) が分かれば、max の項を 1 にできる。

これは補助計算である。目的はこの U と h の滑らかさから **戻る一歩の下限**を作ること。
次を定義する。

r = β1 exp(−Lh U),
A = (1−β1)/(1−r),

u_s = α A(1−r^s)
      / { sqrt([β2^s v0/h0² + 1−β2^s]/[1−β2^(t0+s)]) + ε/h0 }.

すると、閾値に到達するまで各更新で

z_s − z_{s−1} ≥ u_s > 0,

したがって **回復時間の上界**は

T ≤ min{N ≥ 1 : Σ_{s=1}^N u_s ≥ z*−z0}.                       (UB)

u_s → α A/(1+ε/h0) > 0 なので、右辺は有限。

### 証明

1. m0 = 0 なら −m_s ≤ (1−β1^s) h_s。大域の補正係数
   1−β1^(t0+s) ≥ 1−β1^s だから −mhat_s ≤ h_s。
   また v_s ≥ (1−β2) h_s²。
   これから z_s−z_{s−1} ≤ U。
   m0 < 0 でも −m_s ≤ max(|m0|,h_s) を使えば上記の一般 U が出る。

2. 一歩が U 以下で log h の傾きが Lh 以下なので
   h_{s−j} ≥ h_s exp(−Lh U j)。
   同符号の勾配履歴を足すと

   −m_s ≥ (1−β1) Σ_{j=0}^{s−1} β1^j h_{s−j}
         ≥ A(1−r^s) h_s.

   有利な初期 moment −β1^s m0 は捨てて下から抑えている。
   −mhat_s ≥ −m_s なのでこの下限は補正後にも成り立つ。

3. h は単調増加だから

   v_s ≤ β2^s v0 + (1−β2^s) h_s².

   これと 2 を更新式に代入し、h_s ≥ h0 を使うと u_s が出る。

4. N 更新しても未回復だと仮定すると、1–3 が N 回すべてに適用できる。
   z_N ≥ z0+Σu_s ≥ z* となり矛盾。これが (UB) の向きである。

Cauchy–Schwarz は使っていない。勾配履歴の符号が一致することと、
過去の勾配が現在値に比べて小さすぎないことを使って、
Adam の分子を下から、分母を上から抑えた。

### m0 がまだ押す向きの場合

m0 > 0、v0 > 0、β1 < sqrt(β2)、押しなしとする。
古い m0 による総後退量は

q = β1/sqrt(β2),
B = α m0/sqrt(v0) · q/[(1−q)(1−β1^(t0+1))]

以下。実際 m_s^+ ≤ β1^s m0、v_s ≥ β2^s v0 を各更新に代入して幾何級数を足せばよい。よって未回復中は z_s ≥ z0−B。
hmin = h(z0−B) とすると

m_s ≤ β1^s m0 − (1−β1^s) hmin.

したがって

K = ceil{ log[hmin/(2(m0+hmin))] / log β1 }

までに m_K ≤ −hmin/2 になる。
最初に m が負へ変わる更新で −m ≤ h、以後 z が増えるのでこの関係を保つ。
K 以前に回復していなければ、

z_K ≥ z0−B,
v_K ≤ β2^K v0 + (1−β2^K) h(z*)²,
|m_K| ≤ h(z_K).

これらの下限・上限から §3 を再開すれば、K + (UB の右辺) が有限上界になる。
ここで **optimizer を実際にリセットする操作はしない**。
証明が有利な一次 moment を捨て、未知の z_K と v_K を保守的に評価するだけである。
到達可能な通常の Adam state では v0=0 なら m0=0。手で作った m0>0,v0=0 はこの式の対象外。

## 4. 押しが続く場合の十分条件

外部からの負方向変位 p_s ≥ 0 を更新式に足して
z_s = z_{s−1} + Adamの戻り幅 − p_s とする。m0 ≤ 0 の場合を扱う。

既知の押しの列が各 s で p_s ≤ u_s を満たすなら、
「それまで z が単調増加」→ §3 の勾配履歴評価 → 正味変位 ≥ u_s−p_s ≥ 0
という帰納が成立する。従って

T ≤ min{N : Σ(u_s−p_s) ≥ z*−z0}.

例えば p_s ≤ (1−δ)u_s、δ>0 なら有限上界が得られる。
定数押しなら p < inf_s u_s が十分条件になる。
この条件を満たさないことは「戻れない」の証明ではない。

逆向きの十分条件もある。m0=0、ε>0 とし
一定の押し p ≥ α h(z0)/ε を与えると、z≤z0 で h(z)≤h(z0)、
−mhat≤h(z0)、Adam の戻り幅≤αh(z0)/ε≤p。
帰納的に z は増えず、z*>z0 に到達しない。
両条件の間には未判定域がある。厳密な臨界押しを同定したとは言わない。

C2 の γ 倍は前向き・逆伝播・全パラメータを同時に変える操作であり、
この加法的 p_s と同一ではない。適用には §7 の収支で評価し直す必要がある。

## 5. 数値検算

check_bounds.py は上の binary CE の Adam を Python float64 で逐次実行し、
到達前の **全更新**で実際の戻り幅 ≥ u_s と ≤ U を照合する。
非線形の実軌道を動かすコードと、式 (UB) を合算するコードを分けている。
反対向き m0 の例では総到達時刻も照合する。

z0=−16、z*=−1、β=(0.9,0.999)、ε=1e−8。
「105」は固定入力が全て 1 の 105 座標の対称モデルを意味する。
各座標の学習率 η=.001、同じ勾配・同じ moment なら
z=Σθ_j の更新は α=105η=.105 のスカラー式と**厳密に一致**する。
MNIST の ||μ||1≈104 を代入した実データ予測ではない。

| モデル・初期状態 | 実際の到達更新数 | 証明から得た上界 |
|---|---:|---:|
| 1 座標、m0=v0=0、t0=0 | 7,396 | 21,544 |
| 105 座標、m0=v0=0、t0=0 | 95 | 1,551 |
| 105 座標、m0=0、v0=1e−4、t0=30,000 | 12,775 | 22,914 |

これは **定理の検算用モデル**。C1–C3 の追試結果・事前登録された仮説検定ではない。
特に上界は保守的で、到達時刻の推定値ではない。
弱い出力の行は h0 を全区間で使う評価がかなり緩いことも示している。

## 6. 元の「6000 更新あれば十分」が成り立たない理由

上表の二次モーメントを残した行は、勾配が常に戻す向きで、
実数でも float64 でも非ゼロ、外から押していない。それでも 12,775 更新かかる。
履歴 v0/h0² が、押し解除後も Adam の戻り幅を小さくする。

さらに非ゼロ勾配から一様な有限上界は出せない。
同じ binary CE で固定出力重み a>0 を小さくする。
z≤0 では h(z)≤a/2、m0=0 なら −mhat≤a/2 なので

一歩の戻り幅 ≤ α a/(2ε),
T ≥ 2ε(z*−z0)/(α a).

任意の有限予算 N に対して a < 2ε(z*−z0)/(αN) と選べば、
勾配は常に正しい向きで非ゼロなのに N 更新以内には戻れない。
例えば a=1e−12、α=.105、深さ差15では少なくとも 2,857,143 更新。
これは上界の代わりとして下界を出しているのではなく、
**§3 の上界に h0・ε・履歴への依存が必要なことを示す反例**である。

「戻れない」を (i) 微分ゼロ、(ii) 継続する押し、の二択にしてはいけない。
有限予算内の未回復には、残差の方向・相殺、ε と勾配の比、
optimizer の履歴も入る。

## 7. 実ネットワークの C4 に残る接続

固定評価入力集合に対し、一つのユニットの平均前活性は
zbar = w·μ+b。a_t=(μ_t,1)、θ_t=(w_t,b_t) と置けば、厳密に

Δzbar_t
= −η a_tᵀ [mhat_t/(sqrt(vhat_t)+ε)]
  + w_{t+1}ᵀ(μ_{t+1}−μ_t).

第1項は方向を含むそのユニット自身の更新、第2項は入力が動く寄与。
γ が直接変わる時点は、その乗算の寄与も別に加える。

スカラー定理を実網へ移すには、少なくとも
(1) 残差投影が回復方向の勾配を作ること、
(2) 各座標の Adam 更新の μ 方向への投影が相殺されないこと、
(3) 過去の moment と現在の勾配の比、
(4) 上流入力による負の変位、
を拘束する必要がある。
n_eff と φ' の非ゼロ性だけでは (1)–(4) が決まらない。
タスク全体で全ミニバッチの符号を仮定するのも強い条件であり、
未検証のまま実網の定理にしてはいけない。

固定 μ の多座標版も明示できる。a=(μ,1)、σ_j=sign(a_j) とし、
各座標で g_sj=−σ_j h_sj、σ_j m0j≤0、h_sj≥γ_j>0、
h_sj は時間について非減少、h_(s−k)j≥h_sj exp(−λ_j k)
が未回復期間を通じて成り立つとする。a_j=0 の座標は除く。
これは「一歩が必ず c 以上」という結論の仮定ではなく、
**生勾配の方向・下限・履歴の変化率**についての条件である。

r_j=β1 exp(−λ_j)、A_j=(1−β1)/(1−r_j) と置けば同じ EMA の計算から

u_sj = η A_j(1−r_j^s)
       / {sqrt([β2^s v0j/γ_j²+1−β2^s]/[1−β2^(t0+s)])+ε/γ_j},

Δzbar_s ≥ Σ_j |a_j| u_sj.

従って Σ_s Σ_j |a_j|u_sj が深さ差を超える時刻が、
**多座標 Adam の平均前活性の回復時間の条件付き上界**である。
座標の符号が固定で |a_sj|≥a_min,j が保証される動く入力なら、
|a_j| を a_min,j に置き、上流による負方向変位の上限 P_s を引く。
累積 Σ_s(Σ_j a_min,j u_sj−P_s) が深さ差を超えればよい。
これも全条件が未回復期間で成り立つ必要がある。
ミニバッチで符号が入れ替わる実軌道に、期待勾配の符号だけで適用はできない。

従って現時点で導出できたのは、
**符号と変化率が制御された回復勾配に対する、履歴を保持した Adam の有限時間上界**。
C2 の実網について「6000 更新以内の回復」を保証する数値上界は未導出。
その不足を一歩の最大値の計算で埋めたことにはしない。
