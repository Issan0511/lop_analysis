## 1. 最優先：K7 の帰無仮説が成立しない

**問題。**
§5 K7 の「乱数 head に置き換えると S_exact の沈める側が 0.5 ± 0.1」は一般には成立しない。
置換後に π も再計算するなら、乱数 head と π は独立ではない。
一つの正の特徴 a と二クラス head `(u, −u)` の例では、`〈v,π〉 = u tanh(ua)` は u の符号によらず非負になる。
この例で K_n と g が正なら、乱数 head でも S_exact は沈める側になる。
π を置換前に固定すれば別の検査になるが、それは置換後の網の期待勾配ではない。
`|κ| < κ_lb/10` も乱数 head のノルムと F の大きさに依存する。
置換前の κ_lb は置換後の帰無分散ではない。
置換後の κ_lb は正である保証がない。

**直し方。**
K7 を「恒等的な変異検査」と「経験的な帰無分布」に分ける。
次の検査を K7a として追加する。

- `W5 = 0` にした複製状態では、bias の値によらず隠れ層の G_own と G_full が全て数値誤差内で 0 になる。
- 任意の共通行ベクトル q を head の全クラス行に加えても、κ、S_exact、G_own、G_full は変わらない。
- head の行と bias と旧ラベルのクラス番号を同じ置換で変えると、全測定量は変わらない。
- K_n > 0 の固定入力を持つ一 unit の leaky 網で、正の前活性と負の前活性の合成状態を作る。
- bias 0 の非零な中心化 head を用い、その二状態の G_own がそれぞれ正と負になることを独立式で確認する。
- この合成検査は CNN の学習や checkpoint の書き換えを伴わない。

次の文を K7b として置く。
「隠れ特徴と F を固定し、head の中心化行をランダムなクラス置換で入れ替えた κ の帰無分布を作る。」
「この操作で κ の帰無平均は 0 となる。」
「実測 κ の位置は帰無分位点で報告する。」
「多数の帰無標本の平均の誤差は Monte Carlo SE で評価する。」
「乱数 head の尺度は初期化尺度と学習済み head のノルム整合尺度を分ける。」
「乱数 head の S_exact の符号率には 0.5 を要求しない。」
「S_exact の変化そのものを学習済み状態との差として報告する。」

帰無標本数と検査族の有意水準を事前固定する。
例えば 1,000 標本と検査族全体 5% を登録し、多重性を考慮した SE または同時分位点を使う。

## 2. 最優先：G_own・G_full・G_up と適応 α の区別を完結させる

## 6. 高：補題は正しいが、成立条件と P2 の採点対象を追加する

**問題。**
§3 の κ 下界は、線形 head と通常の softmax CE について正しい。
CNN、Adam、30,000 更新、memo 1.0 はこの不等式の必要条件ではない。
旧ラベルが一様 iid であることも、この固定標本上の不等式には不要である。
一方で κ の分母が正である条件が書かれていない。
κ_lb が非正のときの `κ/κ_lb` は下界の緩さを表さない。
memo 1.0 は argmax 正解率であり、L が十分小さいことを保証しない。
B が大きければ、正解率が高くても下界は正にならない。

**直し方。**
§3「補題の検査」に次を追加する。
「同じ N 枚、同じ旧ラベル、同じ特徴、同じ head で F・A・B・L を計算する。」
「L は自然対数による温度 1 の標準 CE の標本平均である。」
「ラベル平滑化、クラス重み、正則化項を L に含めない。」
「logit は有限である。」
「κ は ‖F‖² が数値的に識別できる正の値の場合だけ定義する。」
「κ_lb の正値性には D = N(log K − L) − B > 0 を別に要求する。」
「比 κ/κ_lb は D が数値床を超えて正の状態でのみ報告する。」

次の隙間も保存する。

`J = Σ_n [logsumexp(ℓ_n) − mean_c ℓ_nc − log K] ≥ 0`

`A = D + J`

`κ/κ_lb = 1 + J/D`（D > 0）

この恒等式から P2 の上限撤廃は妥当である。
logit の広がりによって J が増える可能性はある。
ただし今回の CNN で広がりが増えるという理由は計算前の推測である。
`κ/κ_lb ≥ 2` は J ≥ D という別の経験予測である。
補題が保証するのは比が 1 以上ということだけである。
P2 の「破れ 0」は装置の整合性検査として採点する。
P2 の「比 2 以上」は後述の明示した集約規則で別に採点する。

固定 `1e−12` で κ の破れを数える代わりに、まず分子 A−D と J を照合する。
絶対許容差は独立計算・加算順変更で観測した誤差と浮動小数点の加算誤差尺度から定める。
数値床を跨ぐものは違反とも成功とも数えず不定として残す。
V12 の旧「有限回到達」の補題と、この CE の下界補題を混同しない。

## 8. 高：κ と自己形の「測定上の定義」と「H1 の模型」を分ける

**問題。**
κ の式は先行 `measure.py` と一致する。
しかしこれは `v^c` を F の一本の方向へ射影した係数である。
任意の既知 v⁰ を切片とする `v ≈ v⁰ + κF` の最小二乗係数は `〈v^c−(v⁰)^c,F〉/‖F‖²` になる。
§3 の括弧書きはこの二つを混同する。

V12 C.3 の自己形は、固定特徴・固定傾き・旧ラベル iid 一様・v⁰ と旧ラベルの無相関・自信ある正答極限を使った模型である。
学習済み CNN の特徴は旧ラベルに依存する。
射影で残差が F に直交することは、旧ラベルとの無相関を保証しない。
高い正解率だけでは π ≈ one-hot を保証しない。

**直し方。**
§3 の括弧書きを「κ は v^c の F 方向への原点を通る最小二乗射影係数」と置換する。
`v_res = v^c − κF` を定義する。
「‖κF‖/√H」は「現課題 F 方向の読み出し射影の大きさ」と呼ぶ。
「説明できる割合」は「中心化 head の二乗ノルムに対する射影割合」と呼ぶ。
これを予測精度の説明率とは呼ばない。

自己形の文末に「S_self は固定状態の S_exact と同一ではない」と追記する。
差を次の三段階に分ける。

`S_exact − S_self = (S_exact − S_oh) + (S_oh − S_proj) + (S_proj − S_self)`

ここで `S_proj,i = Σ_n K_n g_in (κF)_{y_n,i}` とする。
第一項は one-hot 近似の差である。
第二項は射影残差 head の寄与である。
第三項は旧ラベル間の非対角項である。
この三項は固定状態の帳簿として測れる。
第三項が平均で消えるという模型の仮定を、実測状態に自動適用しない。
最低限、S_exact−S_oh と S_oh−S_self を記録する。

f2 の x は leaky・Snake の出力なので、K_n ≥ 0 は一般には保証されない。
各状態で K_n の最小値、負の割合、分位点を保存する。
`mean K_n = ‖x̄‖²+1` も検査する。
平均が正であることと、全 K_n が正であることは別である。
「方向は活性化で決まる」は K・κ・残差・G_up を無視するため避ける。

ただし分母 ‖F‖² は現在のラベルで学習した特徴に依存する。
従って正規化後の κ_chance の期待が厳密に 0 だとは結論できない。

span > 1 の κ_feat と κ_read は、その期間に挟まる複数課題の変化を含む。
これは「課題 k の学習のうち特徴が担った割合」ではない。
span = 1 でも、二項は因果的な寄与ではない。
交差項をどちらへ入れるかは分解順に依存する。
例えば `〈Δv,F_ref〉 + 〈v,ΔF〉` という別の分解も同じ和になる。

**直し方。**
§3「分解」を「保存境界間の射影帳簿」と改称する。
κ_chance は「参照状態と現課題ラベルの偶然整列項」と呼ぶ。
κ_feat は「参照 head による特徴差項」と呼ぶ。
κ_read は「現特徴による head 差項」と呼ぶ。
各行に ref_task、task、span を必須列として保存する。
span=1 と span>1 を別表にする。
「課題ごとの再装填の内訳」という表題は span=1 に限定する。
厳密に毎課題の内訳が必要なら t−1 の状態を忠実再生で補う必要がある。
今回の費用を抑えるなら、疎な境界間の帳簿として解釈を限定する。
分解項を κ で割る場合は κ の零近傍を除外する。
各割合が負や 100% 超になりうることを記す。
κ の保持が特徴尺度の変化だけで生じていないかも確認する。
F を a 倍し head を 1/a 倍して logit を保つ再パラメータ化では、κ は 1/a² 倍になる。
従って κ 単独は関数の不変な指標ではない。
‖F‖、‖v^c‖、A、射影ノルムを κ と並べて保存する。
これは定義の誤りではなく、CNN へ解釈を移す際の注意点である。

## 10. 高：K1〜K6 は独立性・零近傍・非滑らかさの検査を補う

**問題。**
恒等式 K3・K4 は同じ誤ったラベルや特徴を両辺へ渡しても成立しうる。
K2 の c1・c2 照合だけでは、新設する f1・f2 の JVP の配線ミスを検出できない。
K2 の Snake の参照ファイルがない場合に PASS の扱いが未定義である。
K6 は符号が 90% 合えば通るため、N 倍の尺度誤りを通してしまう。
20 本と 2 SE の規則は、多数の unit を同時検査すると偶然の不合格を生みうる。
不定を除いた対象がゼロでも判定できる書き方になっている。
maxpool の同値勝者と ReLU の零点では、任意の有限差分方向と autograd の選ぶ枝が一致しないことがある。

**直し方。**
K1 には f1 の δ3 式と conv の平均パッチ式を追加する。
K2 には f1・f2 での独立な reverse-mode の `〈∇m_i,∇L_u〉` を数 unit 分追加する。
JVP へ渡す方向は全標本で集計した一つの ∇L_u とする。
chunk ごとの ∇m と同じ chunk の ∇L を内積して足す実装は禁止する。
後者は全標本間の交差項を落とす。

K2 の保存済みファイルは archive の実在パスと hash を登録する。
参照ファイルがなければ独立実装で照合し、「保存値との照合は未実施」と残す。
未実施を PASS に数えない。
検査状態は LR・R・Snake を含める。
負方向・零方向・相殺がある状態を含める。

K3 は `A = D+J` と class 中心化の和が 0 になる検査を追加する。
K4 は ref=current の合成対照で特徴差項と head 差項が 0 になることを確認する。
画像とラベルを同時並べ替えた測定が不変になることを確認する。
画像に対するラベルだけの置換では、κ と A は変わりうる一方で S_exact と G は不変になることを確認する。
この検査で旧ラベルと一様期待の混線を検出する。

K6 の主検査は L_u の決定論的 GD ステップにする。
η、η/2、η/4 で `−Δm/η` が G_full へ収束するかを大きさまで照合する。
固定 α と固定した pool 勝者・ReLU 枝で滑らかな部分の検算を先に行う。
実際の枝を動かした差分は別に残す。
MC の補助検査は、有限ステップではなく実ラベル勾配の方向微分の平均も用いる。
符号ではなく `MC平均 + ηG_full` の残差を SE で標準化する。
事前固定した検査族に対する同時区間を使う。
有効 unit 数と不定数を必ず報告する。

K1〜K4 の比較式は `|a−b| ≤ atol + rtol·max(|a|,|b|)` とする。
atol は値の単位ごとに独立実装差と加算誤差から較正する。
K2 の conv の最大差一つを f2 の S や Δm に流用しない。
S は G の N 倍なので、同じ数値床を共用しない。

## 11. 高：P1〜P9 の採点表を計算前に固定する

**問題。**
P1 以外の多くは、seed 平均か全 seed か全境界かが未指定である。
95% 区間の下端を使うのか点推定を使うのかも未指定である。
空の対象集合が成功扱いになる危険がある。
§6 の統計表示規則だけでは予測の採点規則にならない。

**直し方。**
§7 の冒頭に対象腕・対象境界・対象 unit・集約・判定量・欠測規則の列を持つ表を置く。
以下は採点可能にするための具体案である。
これらの規則の採用前に計算を始めない。

### P1：κ の保持

**問題。**
ほぼ採点可能だが、κ₁ ≤ 0 または零近傍の扱いがない。
「全境界」は保存境界であり、未保存の全課題ではない。

**直し方。**
「κ₁ が正で数値床を超える seed のみ比を定義する」と追加する。
必要な seed の比が未定義なら P1 は支持ではなく判定不能とする。
LR は全保存境界で 10/10 とする。
Snake は腕ごとに全保存境界で 8/10 以上とする。
t1 の比 1 は定義上自明なので採点の件数から外す。

### P2：下界と比

**問題。**
「比 2 以上」が最小値か中央値か不明である。
R の死後や初期値を含めると比が定義できない可能性がある。

**直し方。**
補題の破れは全状態の分子で検査する。
比の経験予測は LR と Snake の t≥1 で D>数値床の状態に限定する。
例えば「各腕・各保存境界で seed 間中央値が 2 以上」と明記する。
全状態の最小値を予測したいなら、そのように明記する。
この二案は異なる強さの予測なので計算後に選ばない。
対象数と D≤床の数を併記する。

### P3：各層の方向

**問題。**
Snake の「谷の則」は採点する量が定義されていない。
既知の c1 の方向は新規予測の成功件数に混ぜると水増しになる。

**直し方。**
数値帯は「各腕・各保存境界の seed 平均の点推定」に適用すると明記する。
全境界を満たす場合だけその腕の予測を支持とする。
区間は点推定の採点と別に表示する。
R は参照一走として別枠にする。
Snake c2 は seat=2αm による G_full>0 の AUC を登録する。
谷の周期と閾値を使うなら、その区間を事前に明記する。
AUC の帰無は状態内で unit 対応を置換して求める。
正負どちらか一方しかない状態では AUC を未定義にする。
既知の c1 と c2 の行は再現確認として採点する。

### P4：実際の一歩と 200 更新

**問題。**
再生する Snake の境界と静的測定の境界が異なる。
Δm の符号を G の数値床で除外してはいけない。

**直し方。**
対象を「再生対象の各腕・各境界における、step 0 で正側入力ありの f2 unit」とする。
分母を step 200 の生存集合へ替えない。
seed 平均の沈降割合について、一歩 ≥0.7 と 200 更新 ≥0.8 を別々に採点する。
旧帯 0.50〜0.65 も同じ平均で採点する。
Δm の誤差床は同じ状態の再評価差と forward 精度差から別に定める。
数値不定の unit を失敗や成功へ恣意的に振り分けない。

### P5：初期化の大きさ

**問題。**
§6 と合わせれば seed 間中央値だが、腕の範囲と t1 の分母集合が曖昧である。
初期化と t1 で生存集合を変えると、比に集合の選別が混じる。

**直し方。**
「LR と Snake の各腕について、seed ごとの `med_alive(0)|S_exact(0)| / med_alive(1)|S_exact(1)|` の seed 間中央値 ≤1/30」と明記する。
これは状態ごとに集合が変わる先行比較用の比と明記する。
全 100 unit での比と両状態に共通する正側入力あり集合での比も補記する。
分母が数値床以下なら未定義とする。

### P6：戻り

**問題。**
1% の分母が全 unit か一度沈んだ unit か不明である。
p⁺<1/2 と r<0 は一般の分布で同じ事象ではない。
同じ unit の複数回の戻りを重複計上する可能性がある。
保存境界が疎なので途中の戻りは見逃される。

**直し方。**
「腕×層ごとに、観測境界で一度閾値未満になった後に閾値以上へ戻った一意な seed-unit 数 / 全 seed-unit 数 ≤1%」を主判定にする。
一度閾値未満になり、かつ後続の観測がある unit 数をリスク集合として別に報告する。
リスク集合に対する戻り率も補記する。
p⁺基準と m<0 基準は別の二行で採点する。
s=0 のため r が未定義でも、m の符号は直接判定できる。
「観測された疎な境界での戻り」に結論を限定する。
MLP の毎課題末の率と比較するなら、MLP を同じ観測間隔に間引いた補助比較が必要である。

### P7：ダイヤル

**問題。**
「滑らか」「閾値なし」は四つの精度点から無条件には採点できない。
押しの集約と「下がり幅」が未定義である。

**直し方。**
現 spec では「未実施・採点対象外」とする。
追加実験の登録時に、横軸を d=log K−L、縦軸を固定集合の med|G_own| などと定義する。
隣接点の非減少を、draw 間雑音で定めた同時区間つきで検査する。
`max(Q_j/d_j)/min(Q_j/d_j) ≤3` のように三倍以内の意味を式で定義する。
d_j が床以下の点を除く規則を事前登録する。
「閾値なし」は「この標本点間隔と検出力で不連続な増加を検出しない」に狭める。
実際の滑らかさを主張するなら点の追加が必要である。

### P8：Snake の自己形

**問題。**
一致率 0.8 は両方の符号が偏るだけでも達成できる。
S_self<0 の unit がゼロなら「その中で多数」は採点できない。
活性化だけが向きを決めるという結論は、同じ状態の相関より強い。

**直し方。**
各腕・各境界で S_self と G_own の符号一致率を seed ごとに計算する。
その seed 平均 ≥0.8 を数値予測とする。
負の S_self の部分集合では、G_own<0 の条件付き割合 >0.5 を別に採点する。
負の対象数と対象のある seed 数を併記する。
対象なしは支持に数えない。
偶然一致率 `p_self p_own + (1−p_self)(1−p_own)` を併記する。
状態内の unit 対応の置換で、符号率を保持した帰無との差を評価する。
結論を「この四腕では射影係数が維持され、G_own の符号が自己形と対応した」に替える。
G_full の符号まで説明するには G_up の検査結果を別に要求する。

### P9：Keep

**問題。**
seed 集約が未定義である。
絶対値の保持は沈める方向の保持を意味しない。
生存集合が時点ごとに変わると、unit の入れ替わりだけでも比が維持されうる。

**直し方。**
「各腕・各保存境界で seed ごとの比の中央値 ≥0.3」と明記する。
f2 の G_full と G_own の二系列を別々に報告する。
LR c1 の「1 を割る境界がある」も同じ seed 間中央値で採点する。
全 unit と t1 固定集合による補表を出す。
絶対値 Keep と沈降率は別の結論として扱う。

## 12. 中：精度・計算量・生ログ・seed の扱いを具体化する

**問題。**
§2 の float64 GPU と TF32 off だけでは、元の float32 再生の演算規約を指定できない。
先行 summary は float32 cuDNN と float64 の z2 の差も報告している。
float64 化は元の実行との同一性を保証しない。
全 N の conv graph と unfold を一度に保持すると 4 GB 制限を圧迫する可能性がある。
これは推測であり、実際の peak メモリは実装に依存する。

K5 の全課題再生は小さな検査ではない。
LR 10 seed だけで 300,000 seed-update になる。
SNA 10 seed を加えると 600,000 seed-update になる。
四つの Snake 腕まで広げると LR と合わせて 1,500,000 seed-update になる。
これに対して指定された 200 更新の主再生は LR 70 と Snake 120 の計 190 区間なら 38,000 seed-update である。
束ねた実行の時間はこの数に単純比例しないが、検査の規模差は明示すべきである。

**直し方。**
§9 に静的測定、忠実度検査、200 更新再生、任意の長期再生の四つの費用枠を置く。
一状態で peak メモリと所要時間を測り、chunk を固定する。
本批評ではそのベンチマークも実行していない。
全画像の ∇L_u を chunk の標本数で重み付けして集計する。
その固定方向への JVP を別パスで流す。
232 unit の完全 Jacobian を必須にしない。
JVP の接線方向は detach し、不要な二階微分を作らない。
分散は cancellation を避ける二パス法か安定なオンライン法で計算する。
s は MLP に合わせて母標準偏差と明記する。

再生は元の grouped conv の束ね方、CUDA graph、cuDNN、TF32、PyTorch/CUDA の版を記録する。
静的 float64 測定の演算規約を再生へ無条件に移さない。
元の演算規約での bit 一致を優先する。
数値床は静的 G、S、κ、Δm、r のそれぞれで定める。

各状態の raw に κ・F のノルム・A・B・L・J・説明率を残す。
各 unit の raw に m・s・p⁺・alive・κ_i・G_own・G_up・G_full・S_exact・S_oh・S_self と各有効 mask を残す。
各再生 step に α・V の状態または再現可能な保存情報を残す。
κ_i の F 列ノルムが零近傍なら未定義とする。
未定義値を黙って除いた四分位だけを保存しない。

任意の g2 を実施する場合は `Δm_rest = m(30000)−m(200)` と明記する。
対象集合は step 0 で正側入力があり、step 200 までに有意に沈んだ unit に固定する。
総和の比は seed ごとに計算してから集約する。
総和の分母が床以下なら未定義とする。
「GPU の空きで」の採否は早期結果を見る前に決める。
g2 未実施の場合は課題内の戻りについて結論を出さない。

seed は画像部分集合、初期化、ラベル列、batch 列を束ねた反復単位として扱う。
腕間比較は同じ seed の対応を保つ。
境界や unit を独立な追加 seed に数えない。
R は 1 seed なので自由度 9 の t 区間を付けない。
R の初期化を含めるなら初期値は 50 でなく 51 腕-seed 状態になる。
R の初期化を省くなら §4 にそのことを明記する。
初期値の κ を計算するなら、F に使うラベルを課題 1 と事前指定する。
MLP の `measure.py` は t0 の κ を NaN にしているので、この点は「同じ定義のまま」ではない追加測定として記す。
