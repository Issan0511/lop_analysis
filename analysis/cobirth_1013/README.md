## 1. 定義

- **課題番号**。本 README は M1 の約束: 課題 T = 1..100、状態 = `end0[T−1]`、相 2 = T 11..100（90 状態）。他の文書との対応: stoch_bridges/p161/p170/M3 の t = T + 1（「課題 t」= `end0[t−2]`）、M2 の checkpoint e = T − 1、D1 の `--task-end T` = `end0[T−1]`。4 文書で 3 通りなので突き合わせはこの表で。
- **持ち上げ役（橋、緩い基準）** [P158/P161/P176 と同じ集合、`stoch_bridges.py bridges_at` の写し]。なめらかなゲート d = a + (1−a)σ(z/τ)、τ_i = 0.1·sd_n z_in + 1e−12、e′_in = K_n·∂d/∂z、閾値の入力 T_i = e′ の上位 3、開いた集合 O_i、k_i = |O_i|。候補 j ≠ i（両方生きている）が i の持ち上げ役 ⟺ **|O_j ∩ T_i| ≥ 2 かつ |O_j ∩ O_i| ≥ ⌈k_i/2⌉**（コードは need = (k_i+1)//2）。強さの重みは判定に入らない。「橋 = またいで開く unit」は署名であって経路ではない（自然な強さの橋の持ち上げの 57〜94% は読み出しの項、H4 L8 [既知]）。
- **N_i(T)**（presence）= T で i の持ち上げ役である j の数。**B_i(T)**（births、新生）= T で持ち上げ役かつ T−1 で持ち上げ役でない対の数。死んだ標的（k_i = 0）は統計から外す。寿命 1 課題が 88〜94% なので presence ≈ births。留め置きには N_i(t) ≥ n* が同時に要るので Cantelli の入力は presence。
- **共誕** = 同じ標的・同じ課題に 2 つ以上の候補が同時に新生すること。その 2 次モーメント = Var N_i、Fano F_i = Var N_i / E N_i、μ_i = E N_i、対の共分散の和 Δ_i = Σ_{j≠k}[P(X_j X_k) − P(X_j)P(X_k)] = s²_{ddof=0} − μ_i + Σ_j p̂_j² [恒等式]。
- **閾値のプール** C_i = #{j ≠ i 生きている : |O_j ∩ T_i| ≥ 2}。N_i ≤ C_i [厳密]。
- **n*_i**。留め置きに要る本数。H4-S の n* = 10 は P155 の構成の数で下界ではない [既知・未導出]。unit ごとの下界 n_β = need_b / max_k L_k（H4_bound 定理 3、`p172c_*_real.json`）: 最小 3.6・12.8・20.0、中央値 32.8・35.3・35.3。**3 状態のみ**（a0.1 課題 40 = T39 で生きていた 82 unit、残り 18 は中央値で埋める；a0.3・a0.5 課題 100）。n_β は L_k > 0 の全 unit（読み出しの項で閉じていても供給する unit）を数えるので、署名の集合 {j : H_ij} とは別の集合（§4）。
- **ρ_R(i)** = 課題のうち標的 i が留め置きにいる割合。(N*)「橋型の留め置きなら N_i ≥ n*_i」[仮定つき] のもとで ρ_R(i) ≤ 時間平均 P(N_i ≥ n*_i)。閾値 [恒等式＋実測、cumulative_push §3]: 累積の押しを 0 以下にするには ρ_R > ā₊/(ā₊ + c·自己項)、c = 1 で 32・26・19%、c = 2.8 で 14・11・8%。
- **素な量**: cos_jk（W2 から）、ω_jk(n) = Σ_m Θ_nm² d_jm d_km / √(Σ Θ_nm² d_jm² Σ Θ_nm² d_km)（W1・X・a から、硬いゲート）、ω̄_jk(T_i) = 標的の閾値 3 入力での平均。μ_i・n*_i・F_i は**結論の変数 N_i の統計**で素ではない。
- **測度**。時系列 = seed 0 の 1 軌道上の (標的, 課題) を標本にした経験量（M1〜M3）。引き直し = 課題 T 末の重みと replay の Adam 状態から、新ラベルとバッチ順だけを引き直して課題 T+1 を 4,000 歩走らせた分布（V1。本来のラベルで走らせると ref と bit 一致）。D1・H4-S の確率はこの引き直しの測度。両者を結ぶ定常性は [未導出]。

## 4. H4 への帰結

### 4.1 「新生の独立」に替えて置ける文

H4 第 3 版 §1-4「…標的の実現した状態を与えたとき各持ち上げ役の条件の生存が独立（実測の相関 c ≤ 1.1）で**新生が Poisson(λ_i) に支配されるなら**…」の後半、§5-5 の未導出「新生の独立」、総まとめ G7b「P(≥10 同時) ≈ 2e−12（新生の独立を仮定）」、cumulative_push §3「ρ_R の見積もりは 10⁻⁷ 以下 [仮定つき: 新生の独立]」に替えて置く文:

> **(B′)** [仮定つき・実測で支持] 課題 t−1 末の状態を与えた新ラベルの分布の下で、標的 i の持ち上げ役の数 N_i(t) は 2 次モーメントが有限で、Fano 因子 F_i = Var N_i / E N_i は F̄ を超えない。実測の F̄: 引き直しの測度（bit 一致、3 状態、R 300/300/200）で中央値 1.30・1.53・1.13・最大 3.0；時系列（90 課題）で中央値 1.39・1.64・1.33・最大 6.34。
> **(N*′)** [実測・3 状態] 留め置きに要る本数の下界 n*_i = n_β,i は E N_i を 3.5 以上上回る（n_β − μ_i の最小 3.49・12.46・19.31、μ_i の最大 0.45・0.64・1.47）。
> **帰結** [厳密・Cantelli、(N*) のもと]: P(N_i(t) ≥ n*_i) ≤ F̄μ_i/(F̄μ_i + (n*_i − μ_i)²)。標的ごとの実測 F で最大 0.016・0.0035・0.0044、一様に F̄ = 3 を置いて最大 0.028・0.0064・0.0074（a0.1 u17）、F̄ = 6.4 で 0.058・0.014・0.016。閾値（c = 2.8 で 14・11・8%、c = 1 で 32・26・19%）に対する余裕は a0.1 で ×2.4（F̄ 6.4）〜×5（F̄ 3）〜×9（実測 F）、a0.3 で ×8〜×31、a0.5 で ×5〜×18。Σ_i（1 課題に N_i ≥ n*_i となる標的数の期待の上界）は F̄ = 3 で 0.14・0.09・0.24。

この文は**結論の変数 N_i の 2 次モーメントについての仮定**であり、素な量（cos・ω・幅・Θ）についての仮定ではない。素な量から F を縛る模型 G（F ≤ 1 + μ·mean R(cos⁺·ω̄)）は a0.1・a0.3 の引き直しで 81%・75% の標的に破られ、記述としては REFUTED（§3.2）。したがって「独立の仮定を素な量の縛りに置き換えた」とは言えない。言えるのは:

- 独立（Poisson の裾）は使っていない [厳密]。代わりに使うのは Fano の有界性 [実測] と n*_i − μ_i の大きさ [実測]。独立を外した対価は Poisson → Cantelli の 3〜12 桁で、長期の形（ρ_R < 14〜32%）にはそれで足りる [数値]。
- 導出（1 歩の cos × ω）が最終数に寄与するのは F の因子 ×1.5〜3.6 まで。縛りの数を決めているのは (n*_i − μ_i)² ≫ μ_i F [数値]。
- 標的の実現した閾値のプール C_i を与えると残りの Fano は 0.85〜1.02 [実測]。これは H4-S が (I) を 𝒢_t（標的の実現した状態）で条件づけて置いた設計と向きが合う [読み]。(I) 自体の格は変わらない（仮定つき）。
