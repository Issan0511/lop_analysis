# 同時の新生を縛る — ラベル雑音による unit 間のゲートの共動は読み出しの cos × 重なりで抑えられる（Fable、1013）

進める段（1 行）: 未証明の文「訓練は n* 本の橋を同時に作らない（反例の課題の割合 ρ_R が小さい）」のうち、H4-S が仮定していた「新生の独立」を、同時にいる橋の本数 N_i の 2 次モーメントの上界に置き換える。上界の材料は素な量（読み出しの中心化ベクトルの cos、ゲートの重なり、幅）だけ。1 次モーメントは実測、独立は使わない。

## 1. どこが仮定だったか

H4-S（持続の縛り）と P161 の見積もりは、1 本の橋の新生率 λ ≈ 0.2〜0.3/標的/課題と寿命 1 課題から、n* 本が同時にある確率を Poisson の裾 λ^{n*}/n*! と置いた。ここで使っているのは「unit ごとの新生が独立」で、これは導出でなく仮定。塊の原因（ハブ入力・幅の広い unit・狭い標的への集中）は実測にある。

長期の形（cumulative_push_1013 §3）では要るのは ρ_R < 14〜32% だけなので、指数的な裾は要らない。片側 Chebyshev（Cantelli）

  P(N_i ≥ n*_i) ≤ σ_i² / (σ_i² + (n*_i − μ_i)²)   [厳密、μ_i = E N_i、σ_i² = Var N_i が有限なら]

で足りる。だから縛るべきは σ_i²、すなわち Σ_{j≠k} Cov(B_j, B_k)。以下はその共分散を unit 間の「ラベル雑音によるゲートの共動」で縛る。

## 2. 補題 1: ラベル雑音による 2 つの unit の前活性の変化の共分散 [厳密]

状態 θ を固定し、新ラベル Y で 1 歩（全データ SGD、歩幅 η）動かす。unit j の入力 n での前活性の変化は

  Δz_jn = −(η/N) Σ_m Θ_nm d_jm ⟨v_j, p_m − e_{Y_m}⟩ = μ_jn + ξ_jn,
  μ_jn := −(η/N) Σ_m Θ_nm d_jm ⟨v_j, p_m − u⟩（確信の分。状態だけの関数）,
  ξ_jn := (η/N) Σ_m Θ_nm d_jm ε_jm,  ε_jm := v_{j,Y_m} − v̄_j（ラベルの分。E ε = 0、m について独立）。

ε_jm と ε_km は同じ Y_m の関数で、E[ε_jm ε_km] = (1/K) Σ_c (v_jc − v̄_j)(v_kc − v̄_k) = (1/K)⟨v_j^c, v_k^c⟩。入力をまたぐ共分散は 0。よって

  **Cov_Y(ξ_jn, ξ_kn′) = (η²/(N²K)) ⟨v_j^c, v_k^c⟩ Σ_m Θ_nm Θ_n′m d_jm d_km.**   (1)

証明は上の 2 行で終わる。bridge_random_switch_1013 の (3) は j と i の相対運動 R = w̃_j − c w̃_i について同じ計算をしたもので、(1) はその 2 unit・2 入力の一般形。
- バッチ版: 和を m ∈ B（16 入力）に替え η/N を η/16 に替える。
- Adam 版 [厳密・模型（線形領域）]: 画素座標 c ごとに 1/√v⁰_jc で前処理されるので、Θ_nm を unit ごとの前処理した Gram Θ̃^{(j)}_nm = Σ_c x̃_nc x̃_mc /√(v⁰_jc/(1−β₂^k)) に替え、係数を (1−β₁)η_k にする。実状態は線形領域（cumulative_push_1013 §5.3: √v⁰/|μ| 1.8〜2.7、ラベルを平均で置いた一歩と期待の累積の比 1.00）。

## 3. 補題 2: 同じ入力での共動の相関は cos × 重なり [厳密]

同じ入力 n での相関係数は、(1) から

  ρ_jk(n) := Corr(ξ_jn, ξ_kn) = cos(v_j^c, v_k^c) · ω_jk(n),
  **ω_jk(n) := Σ_m Θ_nm² d_jm d_km / √(Σ_m Θ_nm² d_jm² · Σ_m Θ_nm² d_km²) ∈ (0, 1].**   (2)

ω ≤ 1 は Cauchy–Schwarz。d > 0（leaky）なので ω > 0。leaky では d = a + (1−a)·o（o = 開いた指標）と書けて、

  d_jm d_km = a² + a(1−a)(o_jm + o_km) + (1−a)² o_jm o_km,

ω_jk(n) は入力 n に似た入力（Θ_nm² の重み）の上で測った、開いた集合の重なりの重みつき Jaccard に a の床を足したもの。開いた集合が一致すれば ω = 1、重なりが無ければ ω は a の桁。

つまり**異なる unit は同じラベル雑音を別の読み出しの向きに射影するので、ゲートの共動の相関は読み出しの cos を超えない。** 複製（cos = 1 かつ同じゲート模様）では ρ = 1 で縛りは消える。これは既存の仮定 (B)「複製が無い」そのもの。

- 入力 n ≠ n′ の相関は Σ_m Θ_nm Θ_n′m d_jm d_km を同じ形で正規化したもので、やはり |·| ≤ |cos(v_j^c, v_k^c)|。
- 標的 i 自身と候補 j の共動も同じ式（v_i^c と v_j^c の cos）。標的の移動による「定義の変化（T_i が動く）」で生まれる新生も、この相関を通してしか候補どうしで揃わない。

## 4. 確信の分（ラベルによらない共通の動き）は相 2 で新生を作らない [厳密・模型、既存の補題を引く]

(1) の μ_jn は状態だけで決まる共通の動きで、ラベル雑音と独立。相 2 でこれが新しいゲートを開くか: 既存の補題（1005 §16.9・P161。ゲートの道の模型）で、閾値にあるゲートは入力 n の重みつき開いた割合 f_n < 1/2（T ≤ 1）なら閉じる側に押され、相 2 では全入力で f_n < 1/2 [実測 100%]。したがって共通の動きは新生の原因でなく、新生はラベルの分 ξ が運ぶ。塊の原因として残るのは ξ の unit 間相関で、それが補題 2 で cos × ω に縛られる。
- 言わない: 課題の中の 4,000 歩すべてで μ がラベルと独立であること（2 歩目以降の状態はラベルに依存する）。ここは次節の模型の境界。

## 5. 希な事象は相関を増幅する — 2 変量正規の閾値越えの共分散 [厳密・模型]

B_j はゲートの閾値越え（の組）で、1 unit あたりの確率 p_j は小さい（新生率 0.2〜0.3 を 99 候補で割って ≈ 0.003）。希な閾値越えでは、小さな相関でも同時確率が大きく膨らむ。これを定量化する。

模型 G: 課題を通して積もったラベル雑音の寄与 (ξ_jn)_{j,n} を、共分散が補題 1 の形（係数を課題に沿って足したもの）の多変量正規とみなし、B_j を ξ_jn の閾値越え 1[ξ_jn > a_j σ_j] とおく（a_j = Φ̄⁻¹(p_j) > 0）。

**補題 3（Plackett の恒等式）** [厳密]。標準 2 変量正規 (X, Y) の相関 ρ ≥ 0 について

  Cov(1[X > a], 1[Y > b]) = ∫_0^ρ φ₂(a, b; r) dr,  φ₂(a,b;r) = (2π√(1−r²))⁻¹ exp(−(a² − 2rab + b²)/(2(1−r²))).

a, b > 0、0 ≤ r ≤ ρ で 2ab ≤ a² + b² より a² − 2rab + b² ≥ (a²+b²)(1−r)、ゆえに

  **Cov(1[X>a], 1[Y>b]) ≤ ρ / (2π√(1−ρ²)) · exp(−(a²+b²)/(2(1+ρ))).**   (3)

Gordon の不等式 Φ̄(a) ≥ φ(a)·a/(1+a²) で p_a p_b を下から押さえると、同時確率の相対超過は

  **Cov / (p_a p_b) ≤ ρ (1+a²)(1+b²) / (ab √(1−ρ²)) · exp((a²+b²)ρ / (2(1+ρ))) =: R(ρ; a, b).**   (4)

数: p = 0.003（a = 2.75）で R(0.05) ≈ 0.7、R(0.15) ≈ 3.9、R(0.3) ≈ 17。相関 0.15 で同時確率は独立の 5 倍、0.3 で 18 倍。「独立」まで行かなくてよいが、ρ ≳ 0.3 では塊が立つ。

複数の閾値（T_i の 2/3 と O_i の半分）の組の事象には Slepian の補題を使う: 2 つの unit の成分の間の相関を全部 ρ̄_jk = max に置き換えると、直交体の確率（したがって同時確率）は増えるので上界になる。閉じた式にはせず、(4) を対ごとの上界の型として使う [模型]。

## 6. Fano の上界と ρ_R [厳密・模型 G]

Var N_i = Σ_j p_j(1−p_j) + Σ_{j≠k} Cov(B_j, B_k) ≤ μ_i + Σ_{j≠k} p_j p_k R(ρ̄_jk; a_j, a_k)。

ρ̄_jk ≤ |cos(v_j^c, v_k^c)| · ω̄_jk（補題 2。ω̄ は標的の入力の上での最大）。全対で ρ̄_jk ≤ ρ̄、a_j ≈ a なら

  **F_i := σ_i²/μ_i ≤ 1 + μ_i R(ρ̄; a, a),**   (5)

  **ρ_R(i) = P(N_i ≥ n*_i) ≤ μ_i F_i / (μ_i F_i + (n*_i − μ_i)²).**   (6)

数（μ = 0.3、p = 0.003）: ρ̄ = 0.15 → F ≤ 2.2、n* = 3.6（a0.1 の最小）で ρ_R ≤ 5.7%、n* = 33（中央値）で 0.06%。ρ̄ = 0.3 → F ≤ 6、ρ_R ≤ 14%（最小の n* でちょうど閾値）、中央値では 0.2%。独立（Poisson）なら 2×10⁻³（n* = 3.6）。

## 7. 条件の検査（トートロジーと基準点）

1. 素な量か: ρ̄ の材料は読み出しの cos と開いた集合の重なり（と Θ）、μ_i は新生率、n*_i は持ち上げの上界からの下界（H4 L8）。どれも N_i の分布を見ずに状態から計算できる。
2. 結論の移項か: (5) は結論 F の式ではなく、別の量（cos・ω）から F を押さえる。結論を含まない。
3. 条件の外に落ちる配置: cos ≈ 1 かつ ω ≈ 1 の組 = 複製。(B)「複製が無い」と一致する。新しい仮定は置いていない。
4. 閉じた側: 分解は unit 間の共分散で、同じ unit の a 倍の項を敵に数えていない。ω の床 a² は同じ unit の閉じた側で、相関を上げる側（複製に近づける）に入る。これは抑えの材料であって敵ではない。

6. 「緩い署名で数えた N は有効な持ち上げ役の上界なので保守的」→ n_β は読み出しの項で供給する unit（署名を満たさないものを含む）も数える下界なので、保守的なのは「署名が持ち上げの必要条件」（H4 L1′、未導出）の下だけ。

共誕の出どころ [実測・検証役と M3]: N_i ≤ C_i（標的の閾値の 3 入力のうち 2 つ以上で開いている unit の数）で、C_i を与えると残りの Fano は 0.85〜1.02（引き直し）・0.64〜0.94（時系列）。過分散は候補どうしの相関でなく、標的の実現した閾値の入力が混んでいるかという共通原因を通る。標的間の μ_i の不均一は Fano 単位 0.02〜0.04 で、H4_stoch §(5)「過分散は標的ごとの λ_i の不均一」は否定。

残る導出の的（1 つ）: Var(C_i)、すなわち標的の閾値の入力に同時に開いている unit の数の 2 次モーメントを、入力の占有 f_n の統計（暗い入力に偏る: Spearman(f, K) −0.45〜−0.51）と閾値の入力の選ばれ方から縛ること。候補どうしの相関（本ノートの補題 1・2）はこの箱では効いていない。
