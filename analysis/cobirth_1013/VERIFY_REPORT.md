1. **結論を見ずに測れる素な量か**: cos(v_j^c, v_k^c)（W2）と ω（W1・X）は素。**μ_i は E N_i で結論の変数の平均**、n*_i も p172c の 1 状態の値。D1 §5-1 の「どれも…状態から計算できる」は μ_i について偽（§3 #8）。縛りの数を決めているのはこの 2 つ（§5.1）。
2. **結論の移項か**: (4.5) は cos・ω から F を押さえるので移項ではない。ただし最終数 ρ_R は Cantelli μF/(μF + (n* − μ)²) で、実測の材料では (n* − μ)² ≫ μF なので ρ_R ≈ μF/(n* − μ)²。F の上界が 1.5〜3.6 なので、**導出の内容が最終数を動かすのは ×3.6 以内**（表 5.1 の「独立 F = 1」の列）。独立を外した対価（Poisson → Cantelli）は 3〜12 桁。「独立を使っていない」は正しいが、「独立の仮定を cos × ω に置き換えた」の中身は、ほぼ「n* ≫ μ なら Cantelli で足りる」。
3. **条件の外に落ちる配置**: D1「複製だけ」は REFUTED（§3 #7）。実際に落ちるのは (a) n*_i − μ_i ≲ √(μF)/√閾値 ≈ 2〜3 の標的、(b) ρ ∈ (0.3, 0.9) の対が多い状態。(a) は実データに無い（max N ≥ n_β の標的 0/100、3 腕）、(b) は実状態そのもの（R の質量の 64〜80%）で、縛りが空にならないのは (a) が無いから。
4. **閉じた側は敵でないか**: D1 は a² の床を「相関を上げる側の自分の項」と書く。敵に数えてはいない（memory closed-side-is-own-term-not-enemy の型は踏んでいない）。ただし「自分の項」の語は 1 unit の力の分解のもので、2 unit の相関には当たらない。実測の内容は「ω は床（a と幅）で決まる」で、a は係数として滑らかに入り、a で機構が変わる読みは D1 に無い（適切）。

## 9. 検証役として言える文・言わない文

**言える文**
- 補題 1〜3 と定理 4 の代数は正しい [厳密（模型の中）]。式 (1.3) は別の 3 状態で autograd MC と比 0.94〜0.98 で一致する [実測]。
- この箱では ω は a² の床で決まり、開いた集合の重なりは ω に 1.5% 以下しか入らない [実測]。ゆえに ρ = cos·ω の情報は cos の情報と同じで、M2 の順位相関 0.992〜0.999 はその帰結 [実測]。
- 実測の材料（cos・ω・M1 の μ_i・p172c の n_β）を (4.5)(4.6) に入れた ρ_R の上界は全標的で ≤ 1.5%、閾値 14〜32% の内側 [数値・模型 G ＋ (N*) ＋ 1 状態の n_β]。F = 1 の Cantelli との比は ×1.5〜3.6 [数値]。
- 状態を固定したラベルの引き直し（bit 一致の箱、a0.1 T40・a0.3 T17・a0.5 T70、300・300・200 本）で、持ち上げ役の数の Fano は 1.30・1.53・1.13（中央値）、独立（Poisson）は P(N≥5) で 1,000・124・7 倍破れる [実測]。模型 G をその仮定どおりに候補ごとの周辺で評価した F は 1.10・1.36・1.55 で、a0.1・a0.3 では 81%・75% の標的が超える（a0.5 は 1%）[実測]。等しい p の (4.5) の 1.52・2.20・2.86 が上にいるのは近似の緩さによる [数値]。
- 累積 Δz の unit 間相関は 1 歩の cos·ω の 1/4〜1/10（傾き 0.25・0.10・0.08）で、不等式 |ρ| ≤ |cos| は保たれる（破れ 0.3〜0.4%）が共誕の過分散を説明する大きさではない [実測]。
- 共誕の過分散は、標的の t+1 の閾値のプール C_i を与えると Poisson の水準（群内 Fano 中央値 0.85・1.02・0.95）[実測]。

**言わない文**
- 共誕の機構の導出（C_i の分布をラベルの引き直しから出すこと）[未導出]。
- (N*)（留め置きに N_loose ≥ n_β が要る）の正否。n_β の数える集合と署名の集合は別物で、方向は保守的と言えない [仮定つき]。
- ラベル引き直しの確率と 1 軌道の時間割合を結ぶ定常性 [未導出、D1・H4-S と同じ穴]。
- 1 seed・1 箱・3 状態の引き直しの外。

**罠の処理（事前に書いた）**: (i) 同じ状態で同じ MC を回さない → 別の 3 状態・autograd・別の入力。(ii) 時系列の F と模型 G の上界を直接比べて「模型の検証」と言わない → ラベル引き直しの測度を作って比べた。(iii) 等しい p の近似で縛りが上にいることを「成立」と読まない → (4.4) を実測の周辺で評価して比べた。(iv) 過分散を「標的の不均一」で片付けない → 1 状態・1 標的で F を測った。(v) 「条件の外は複製だけ」を信じない → R の質量の出どころと空になる n* − μ を数で示した。
