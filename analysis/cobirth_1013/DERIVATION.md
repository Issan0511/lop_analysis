## 1. 補題 1（a）: 新ラベルの 1 歩のゲートの動きの unit 間共分散 [厳密]

状態 θ を固定し、新ラベル Y で 1 歩動かす。平均 CE の勾配は ∂L/∂f_mc = (p_mc − 1[Y_m = c])/N、∂f_mc/∂z_jm = v_jc d_jm、∂z_jm/∂w̃_j = x̃_m。全データ SGD（歩幅 η）では

  Δw̃_j = −(η/N) Σ_m d_jm ⟨v_j, p_m − e_{Y_m}⟩ x̃_m,  Δz_jn = Δw̃_j·x̃_n = −(η/N) Σ_m Θ_nm d_jm ⟨v_j, p_m − e_{Y_m}⟩.   (1.1)

（入力ごとの力の形は既知: 0925 ノート §「入力ごとの力 [厳密]」Δz_{i,n} = −(η/B)Σ_m δ_{i,m}(x_m·x_n + 1)。ここでは 2 unit・2 入力の共分散を取る。）

**中心化の恒等式** [恒等式]。残差 r_m := p_m − e_{Y_m} は Σ_c r_mc = 0 なので ⟨v_j, r_m⟩ = ⟨P_C v_j, r_m⟩ = ⟨v_j^c, r_m⟩。第 1 層の勾配に入る読み出しは常に中心化した v_j^c である。これは 1 歩目に限らず**毎歩**成り立つ（softmax CE の残差は常に中心化されている）。

**分解**。E_Y[e_{Y_m}] = u1 だから r_m = (p_m − u1) − (e_{Y_m} − u1) と分け、

  Δz_jn = μ_jn + ξ_jn,
  μ_jn := −(η/N) Σ_m Θ_nm d_jm ⟨v_j^c, p_m − u1⟩  （ラベルによらない共通の分。状態だけの関数）,
  ξ_jn := (η/N) Σ_m Θ_nm d_jm ε_jm,  ε_jm := v_{j,Y_m} − v̄_j = (v_j^c)_{Y_m}  （ラベルの分。E ε_jm = 0、m について独立）.   (1.2)

同じ入力 m のラベルは unit をまたいで共有されるので E[ε_jm ε_km′] = δ_{mm′} (1/C) Σ_c (v_j^c)_c (v_k^c)_c = δ_{mm′} ⟨v_j^c, v_k^c⟩/C。ゆえに

  **Cov_Y(Δz_jn, Δz_kn′) = Cov_Y(ξ_jn, ξ_kn′) = (η²/(N²C)) ⟨v_j^c, v_k^c⟩ Σ_m Θ_nm Θ_n′m d_jm d_km.**   (1.3) [厳密]

証明は上の 2 行で終わる。読み出しも同時に更新されていてよい（右辺は更新前の値。Δz は第 1 層の変化だけで決まる）。bridge_random_switch_1013 (3) は j と i の相対運動 R = w̃_j − c w̃_i について同じ計算をしたもの（u_n = d_jn v_j − c d_in v_i の形）で、(1.3) はその一般形（2 unit・2 入力）。unit 間独立はどこにも仮定していない — 共有ラベルの相関は ⟨v_j^c, v_k^c⟩ に全部入っている。

**(1.3B) バッチ版** [厳密・バッチ B を与えて]。Σ_m を Σ_{m∈B}、η/N を η/|B| に替える: Cov_Y(·|B) = (η²/(|B|²C)) ⟨v_j^c, v_k^c⟩ Σ_{m∈B} Θ_nm Θ_n′m d_jm d_km。B も無作為（置換で切る）なら、全共分散 = E_B[Cov_Y(·|B)] + Cov_B(E_Y[·|B]) で、第 1 項は (1.3) の η²/N² を η²/(|B|N) にしたもの、第 2 項は共通の分 μ の**バッチ抜き出しの揺らぎ**で、符号は cos では制御されない [厳密・分解]。ただしこの箱はエポックごとの置換で切る（各入力はエポックに 1 回）ので、係数を凍結すれば 1 エポック（75 更新）の和では第 2 項は消え、全データの和に戻る [厳密・凍結模型]。

**(1.3A) Adam 線形領域版** [厳密・模型]。模型: 課題頭の Adam の 2 次モーメント v⁰_jc（画素座標 c ごと、前課題から持ち越し）を 1 歩の間固定し、ε を落とし、|g| ≪ √v⁰（線形領域。cumulative_push_1013 §5.3: √v⁰/|μ| 1.8〜2.7 [実測]）とする。1 次モーメントの持ち越し β₁ m⁰ はラベルによらない（共通の分へ）。すると Δw̃_jc = −η(1−β₁) g_jc/√v̂⁰_jc（bias 補正は定数）で、

## 2. 補題 2（b）: 相関は読み出しの cos × ゲートの重なり [厳密]

(1.3) から、同じ入力 n（または 2 入力 n, n′）での相関係数は

  **ρ_jk(n, n′) := Corr(ξ_jn, ξ_kn′) = cos(v_j^c, v_k^c) · ω_jk(n, n′),**
  **ω_jk(n, n′) := Σ_m Θ_nm Θ_n′m d_jm d_km / √(Σ_m Θ_nm² d_jm² · Σ_m Θ_n′m² d_km²).**   (2.1)

- |ω| ≤ 1 は Cauchy–Schwarz（ベクトル (Θ_nm d_jm)_m と (Θ_n′m d_km)_m の内積）。等号は (Θ_nm d_jm)_m ∝ (Θ_n′m d_km)_m のとき。n = n′ では d_j ∝ d_k、d ∈ {a,1} なので**ゲート模様が一致するとき**（一方が全部開き他方が全部閉じる退化を除く）。
- Θ_nm ≥ 1 > 0・d > 0（leaky）なので ω > 0。ゆえに **|ρ_jk(n,n′)| ≤ |cos(v_j^c, v_k^c)|**、符号は cos の符号 [厳密]。
- leaky の分解 [恒等式]: d = a + (1−a)o より d_jm d_km = a² + a(1−a)(o_jm + o_km) + (1−a)² o_jm o_km、d_jm² = a² + (1−a²) o_jm。ω は入力 n に似た入力（重み Θ_nm²）の上で測った開いた集合の重なりに、閉じた側の床 a² が足されたもの。床は同じ unit の閉じた側の自分の項で、相関を**上げる**側（複製に近づける）に入る。敵の項ではない（memory closed-side-is-own-term-not-enemy）。a は係数として滑らかに入り、a で機構は変わらない。
- 極限 [厳密・代数]:
  (i) **入力が直交**（Θ = diag）: Σ_m Θ_nm² d_jm d_km = Θ_nn² d_jn d_kn なので ω_jk(n,n) = 1、ω_jk(n,n′) = 0（n ≠ n′）。同じ入力では 2 unit は同じ 1 つのラベル ε_·n に駆動されるので相関は cos そのもので、開いた集合の重なりは入らない。課題文の「直交に近いとき Jaccard に結びつく」は**逆**で、直交極限では重なりの因子が消える。
  (ii) **平らな核**（Θ_nm ≈ Θ̄、明るい共通成分が支配）: ω = Σ_m d_jm d_km/√(Σ d_jm² Σ d_km²)。a → 0 で ω → |O_j ∩ O_k|/√(k_j k_k) =: S_c（Ochiai 係数）。Jaccard J = |∩|/|∪| との関係は **J ≤ S_c ≤ √J**（√(k_j k_k) ≤ (k_j+k_k)/2 ≤ |∪|、および (k_j−|∩|)(k_k−|∩|) ≥ 0）。a > 0 では床が足されて ω ≥ a²N/√((a²N + (1−a²)k_j)(a²N + (1−a²)k_k))。
  実状態（MNIST の raw 入力）は (ii) に近い: ω の分位（生きた unit の全対 × 24 入力、課題 40 末）は a 0.1 で 10/50/90% = 0.52/0.72/0.90（最小 0.28）、a 0.3 で 0.80/0.87/0.95、a 0.5 で 0.90/0.92/0.95 [実測]。**個数の Jaccard は正しい重なりの量ではない**: Codex の反例（1004 夜 §16.30 (4″)、Jaccard 1/6 の 2 unit が明るい入力 1 つの共有で容量を落とす）と同じく、効くのは Θ² で重みづけた 2 次モーメントの重なりで、(2.1) はそれを明示した形。
- |cos(v_j^c, v_k^c)| の分位（同じ状態、生きた unit の全対）: 10/50/90/99/100% = 0.045/0.23/0.53/0.76/0.98（3 腕ほぼ同じ）[実測]。9 次元の中心化クラス空間の無作為な向きの |cos| の典型は 1/3 なので、相関を主に下げているのは cos で、ω は 0.7〜0.9 の床を持つ。
- 符号つき ρ = cos·ω の分位（全対 × 24 入力）: a 0.1 で 10/50/90/99% = −0.31/−0.005/0.29/0.55、正の割合 0.49、ρ > 0.3 が 9.5%（a 0.3: 15%、a 0.5: 16%）[実測]。

**補題 2′（1 次元に落としても因数分解は保たれる）** [厳密]。重み α ∈ R^N を unit によらず固定し ζ_j := Σ_n α_n ξ_jn とおくと、Σ_{n,n′} α_n α_n′ Θ_nm Θ_n′m = ((Θα)_m)² なので

  Cov(ζ_j, ζ_k) = (η²/(N²C)) ⟨v_j^c, v_k^c⟩ ⟨g_j^α, g_k^α⟩,  g^α_jm := d_jm (Θα)_m,  **Corr(ζ_j, ζ_k) = cos(v_j^c, v_k^c) · cos(g_j^α, g_k^α).**   (2.2)

重みが unit ごとに違っても（α for j、β for k）Corr = cos(v) · cos(g_j^α, g_k^β) で |·| ≤ |cos(v)| のまま。これが §4 の模型 (G2) の土台。

**検算**: (2.1) の cos·ω と MC の相関係数の差は最大 0.088・中央値 0.014（MC の se ≈ 1/√2000 = 0.022）、(1.3) の厳密な共分散から作った相関と cos·ω の差は 2e−15（恒等式）[数値]。

**既知との関係**: H4_stoch_report §(2) 10 [実測] 「余裕を揃えた残りの増分の相関 +0.055・+0.038・+0.018（読み出しの cos ≥ 0.5 の組で +0.12・+0.10・+0.10）」は、cos で層別すると unit 間の増分の相関が上がるという測定で、(2.1) と向きが合う。式としての cos × ω は vault・BRIDGE_CONDITION.md・H4 の 3 報告に無い（grep: 共分散/Cov/cos(v/Fano/過分散/Cantelli/Slepian。§7 の表）。

## 3. （d）共通の分は共分散に入らない。新生を運ぶのはラベルの分

**(d1) [恒等式]** μ_jn（(1.2) の共通の分）は状態 θ だけの関数で、Y と独立。したがって Cov_Y(Δz_jn, Δz_kn′) に μ は一切入らない（(1.3) のとおり）。μ が効くのは各 unit の**閾値までの距離**、すなわち周辺確率 p_j = P(B_j)（= N_i の 1 次モーメント μ_i の材料）だけ。2 次モーメントの上界には μ の向きの情報は要らない。これが「1 次モーメントは実測、2 次モーメントは導出」という分担の根拠で、1 歩目については厳密。

**(d2) 向き [厳密・模型（ゲートの道・T ≤ 1）＋実測、既存の補題を引く]**。μ の向きが新生を助けるか: 1005 §16.9・P161 の補題「unit j の入力 n のゲートの押しは c_jn(d_jn − d̂_jn)、谷底 d̂_jn ≤ T(a + (1−a) f_n)（w ≥ 0、T = Σw、f_n = n を説明する重みのうち n で開いている unit に乗る割合）。閾値にあるゲート d = (1+a)/2 は T ≤ 1 なら f_n < 1/2 で閉じる向きに押される」。相 2 では強さで重みづけた f_n ≥ 1/2 の入力は 0%（最大 0.12〜0.34）[実測、P161]。**但し書き（H4_verifier_report §(2) 4・§(5)）**: 両方の層の核では谷底 = ゲートの分 ＋ 読み出しの特徴の分 ＋ bias の分で、後の 2 つは補題が縛らない（条件は T + r + β ≤ 1 に替わる [仮定つき]。反例 a14670ca n40: T 0.81・f⁺ 0.39 でも谷底 0.79 > (1+a)/2 = 0.65）。また補題の f は primal の重みの量で、測った強さ重みの f_n とは別の数（同 §(2) 3）。ゆえに (d2) の格は**ゲートの道の模型の中の厳密**で、「共通の分は相 2 で新生を作らない」を無条件には言えない。

**正確な言い方**: 新生 B_j は、状態で決まる距離（μ を含む）を、ラベルの分 ξ_j が越える事象。unit 間で同時に越える確率が独立の積から膨らむのは ξ の unit 間相関 ρ_jk を通してだけで、その相関は補題 2 で |cos| × ω に縛られる。共通の分が新生を「作る」か「潰す」かは p_j（1 次モーメント、[実測]）に吸収される。

**既知** [厳密]: 「一様な予測 ＋ 独立なラベルでは期待勾配は全方向で 0。実現したラベルの損失は一次で減るが模様の期待の増分は二次（E[Δs²] = η² E[hᵀMh] ≥ 0）」（memory push-direction-proof-0930、1001）。ξ は期待 0 で 2 次で効く、の同じ文。

## 4. （c）模型 G の下で、閾値越えの共分散 → Fano → Cantelli → ρ_R

### 4.1 なぜ 1 歩は厳密で課題は模型か

(1.3) は 1 歩目で厳密。課題（4,000 歩）を通した累積 ξ_j(T) = Σ_t ξ_j^{(t)} では
1. 2 歩目以降の係数 d_jm^{(t)}・v_j^{c(t)}・残差 r_m^{(t)} が Y の関数になる（適応の分 Gad。cumulative_push_1013 §5.2 では凍結の分と適応の分が同じ桁で逆向き [実測]）。

### 4.2 補題 3: 2 変量正規の閾値越えの共分散 [厳密]

標準 2 変量正規 (X, Y)、相関 r、a, b > 0。Plackett の恒等式 ∂Φ₂(a,b;r)/∂r = φ₂(a,b;r) から

  Cov(1[X>a], 1[Y>b]) = P(X>a, Y>b) − Φ̄(a)Φ̄(b) = ∫_0^ρ φ₂(a,b;r) dr,  φ₂(a,b;r) = exp(−(a² − 2rab + b²)/(2(1−r²)))/(2π√(1−r²)).   (4.1)

- ρ ≤ 0 なら Cov ≤ 0（Slepian。被積分関数が正）。以下 ρ⁺ := max(ρ, 0)。
- 0 ≤ r ≤ ρ で 2ab ≤ a² + b² より a² − 2rab + b² ≥ (a²+b²)(1−r)、ゆえに (a²−2rab+b²)/(2(1−r²)) ≥ (a²+b²)/(2(1+r)) ≥ (a²+b²)/(2(1+ρ))。

  **g(ρ; a, b) := Cov(1[X>a],1[Y>b]) ≤ ρ⁺/(2π√(1−ρ²)) · exp(−(a²+b²)/(2(1+ρ))).**   (4.2) [厳密]

- Gordon の不等式 Φ̄(a) ≥ φ(a)·a/(1+a²)（a > 0）で p_a p_b を下から押さえると、同時確率の相対超過は

  **R(ρ; a, b) := Cov/(p_a p_b) ≤ ρ (1+a²)(1+b²)/(ab√(1−ρ²)) · exp((a²+b²)ρ/(2(1+ρ))).**   (4.3) [厳密]

- 検算 [数値]: p = 0.003（a = 2.748）、2 変量正規 2×10⁶ 本の MC と (4.1) の数値積分は z スコア +0.17・+1.61・−1.93（ρ 0.05・0.15・0.3）で一致。上界 (4.2) は厳密値の 1.19・1.55・2.02 倍。R の厳密値 0.56・2.44・8.28、上界 (4.3) 0.69・3.93・17.4。**希な事象は相関を増幅する**: ρ = 0.15 で同時確率は独立の 3.4 倍、0.3 で 9.3 倍（厳密な正規）。
- 課題文の「arcsin 型」は a = b = 0 の Sheppard P(X>0,Y>0) = 1/4 + arcsin ρ/(2π) で (4.1) の特別な場合。閾値が正の希な事象では (4.1)〜(4.3) の形が要る。

### 4.3 定理 4（Fano の上界）[厳密・模型 G]

N_i = Σ_{j≠i} B_j、p_j = P(B_j)、μ_i = Σ p_j。

  Var N_i − μ_i = −Σ_j p_j² + Σ_{j≠k} Cov(B_j, B_k) ≤ Σ_{j≠k} g(ρ_jk⁺; a_j, a_k) ≤ Σ_{j≠k} p_j p_k R(ρ_jk⁺; a_j, a_k),   (4.4)

ρ_jk ≤ |cos(v_j^c, v_k^c)| · ω̄_jk（ω̄ は標的の入力の上の (2.2) の因子の上限 ≤ 1）。Fano 因子 F_i := σ_i²/μ_i は、p_j が等しいとき（p = μ_i/n_c、n_c = 候補数）

  **F_i ≤ 1 + μ_i · ((n_c−1)/n_c) · mean_{j≠k} R(ρ_jk⁺; a, a),  a = Φ̄⁻¹(μ_i/n_c).**   (4.5)

対の**平均**でよい（(4.4) は対について線形）。max を使う必要は無い。R は ρ ≤ 0 の対で 0。

### 4.4 系（Cantelli → ρ_R）[厳密・模型 G、(N*) のもと]

n*_i > μ_i のとき、片側 Chebyshev（Cantelli）

  **P(N_i ≥ n*_i) ≤ σ_i²/(σ_i² + (n*_i − μ_i)²) = μ_i F_i/(μ_i F_i + (n*_i − μ_i)²).**   (4.6)

(N*) より 1[留め置き_i(t)] ≤ 1[N_i(t) ≥ n*_i]、ゆえに E[ρ_R(i)] = (1/T)Σ_t P(留め置き_i(t)) ≤ (1/T)Σ_t (4.6)_t（各 t の μ・σ は課題 t−1 末の状態で条件づけた新ラベルの分布について）。実現した割合には Markov P(ρ_R ≥ x) ≤ E ρ_R/x。
- 測度: (4.6) は課題列（ラベルの引き直し）の確率、ρ_R は 1 本の軌道の時間割合。両者を結ぶには定常性が要る（H4-S (d) と同じ穴）[未導出]。
- 標的 i の状態での条件付け（H4-S の 𝒢_t）: 標的自身の ξ_i も候補と相関 ρ_ji = cos(v_j^c, v_i^c) ω_ji する。ξ_i を与えた条件つき相関は (ρ_jk − ρ_ji ρ_ki)/√((1−ρ_ji²)(1−ρ_ki²)) で、|·| ≤ (|ρ_jk| + |ρ_ji||ρ_ki|)/√(…)。条件付けると縛りは少し緩む [厳密・正規]。無条件（標的の新しい状態も確率変数）で書けば (4.6) のまま。

### 4.6 分布によらない道が閉じている理由 [厳密]

## 5. （e）条件の検査

1. **素な量か**: (4.4)〜(4.6) の材料は cos(v_j^c, v_k^c)（読み出し行列から）、ω_jk（Θ とゲート模様から）、p_j・μ_i（新生率、1 次モーメント [実測]）、n*_i（H4_bound の n_β [実測]）。どれも N_i の分布（結論）を見ずに状態から計算できる。
2. **結論の移項か**: 結論は F_i と P(N_i ≥ n*)。(4.5) は別の量（cos・ω）から F を押さえるので移項ではない。ただし μ_i を実測で入れる以上、「1 次モーメントが小さい」ことは仮定で、2 次モーメントの縛りだけが導出。μ_i が大きい標的（4.5 の表の μ = 1.5）では縛りは空になる — これは条件の外が実際にあることの印（3 の検査に通る）。
3. **条件の外に落ちる配置**: cos = 1 かつ ω = 1 の組（複製: 同じ読み出しの向き・同じゲート模様）は ρ = 1、g(1) = p(1−p)、F は n_c まで上がり縛りは消える。これは既存の仮定 (B)「複製が無い」（BRIDGE_CONDITION・H4）と**同じ配置**で、新しい仮定を足していない。中間（cos·ω ≈ 0.3〜0.5 の少数の組）が実状態の R の質量の 6〜8 割を担う（§4.5）。
4. **閉じた側は敵でない**: 分解は unit 間の共分散で、同じ unit の a 倍の項（閉じた側）は ω の床 a² として相関を上げる側に入る自分の項。a の大きさで「機構」は変わらず、変わるのは ω の床と、学習の結果としての開いた集合（a 0.1 で k 中央値 8、a 0.5 で 196 [実測]）。
5. **恒等式・平均への回帰の罠**（memory vacuous-balance-regression-traps）: (4.4) は定常の帳簿ではなく状態で条件づけた 1 歩先の分散の上界で、窓の値を無意味な値に替えても成り立つ形ではない（cos を無作為な向きの値に替えれば R̄ は変わる）。変異対照として使えるのは「読み出しを無作為に回した状態で同じ (4.5) を評価し、実状態との差が cos の分布の差で説明されるか」で、これは M の役に渡す [未実施]。
