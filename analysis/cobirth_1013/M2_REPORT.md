## 1. 定義と約束（コードどおり）

- 状態の番号: checkpoint e（0 始まり）= `end0[e]` = **課題 e+1 の末**。相 2 = 課題末 11..100（e = 10..99、90 状態）。新生は e−1 → e で判定（e = 10 は e = 9 = 課題末 10 を前の状態に使う）。H4/P161/stoch の「課題 t」= `end0[t−2]` とは 1 ずれる（stoch の t = 課題末 t−1）。再現検査: stoch の t = 10..100（e = 8..98）の橋対の数を同じ基準で数え直すと 1,511 / 2,836 / 7,712 で一致 [実測・再現]。
- 持ち上げ役（緩い橋、P158/P161/P176、`stoch_bridges.py bridges_at()` の写し）: Z = X̃W̃ᵀ、τ_i = 0.1 sd_n(z_in) + 1e−12、s = σ(z/τ)、Dp = (1−a)s(1−s)/τ、K_n = x̃_n·x̄̃、E = K_n Dp_in、T_i = E[:, i] の上位 3 入力、O_i = {n: z_in > 0}、k_i = |O_i|、need_i = (k_i+1)//2。**L_ij(t) = 1 ⟺ j ≠ i、両方生きている、|O_j ∩ T_i| ≥ 2 かつ |O_j ∩ O_i| ≥ need_i。** 強さは判定に入らない。
- 読み出し v_j = W2[:, j]（10 次元）、中心化 v_j^c = v_j − mean_c v_j、cos_jk = cos(v_j^c, v_k^c)。
- 開いた集合の Jaccard J_jk = |O_j ∩ O_k| / |O_j ∪ O_k|。
- 幾何の重なり（THEORY_FABLE 補題 2、硬いゲート d = a または 1、Θ = X̃X̃ᵀ）: g_jk(T_i) = Σ_{n∈T_i} Σ_m Θ_nm² d_jm d_km、ω_jk(i) = g_jk/√(g_jj g_kk) ∈ (0,1]、**ρ_jk(i) = cos_jk × ω_jk(i)**。
- 時間平均: |ρ̄_jk(i)|・ω̄・符号つき ρ̄ は標的 i が生きている相 2 の状態で平均、|cos̄|・符号つき cos̄・J̄ は相 2 の 90 状態で平均（i によらない）。
- 共在の超過（課題の指示どおり、T = 90）: c_ijk = Σ_t L_ij L_ik − (Σ_t L_ij)(Σ_t L_ik)/T。対は j < k（c は j,k について対称なので順序対は数えない）、j,k ≠ i。
  - exc_alive: T を「i が生きている状態数」に替えた版（a0.1 で死ぬ unit があるため）。
  - **exc_state（状態条件つき）**: 各 t の持ち上げ役の数 n_i(t) を固定し、unit の頻度 f_ij = Σ_t L_ij / Σ_t n_i(t) で置き換え可能な抽出をしたときの期待 Σ_t n_i(t)(n_i(t)−1) f_ij f_ik を引いた版。標的の状態の不均一さで出る分を除く帰無 [実測・帰無模型]。
- 同時の新生: B_ij(t) = L_ij(t) ∧ ¬L_ij(t−1)。超過は同じ式。
- 共在の機会のある対: Σ_t L_ij ≥ 1 かつ Σ_t L_ik ≥ 1（新生は Σ_t B ≥ 1）。順位相関（Spearman）と並べ替え検定はこの対の上で。並べ替え: 予測子の名札を対の間で 2,000 回入れ替える。p_global = 全対で入れ替え、**p_within = 同じ標的 i の対の中だけで入れ替え**（標的間の不均一さを固定）。片側（観測以上の順位相関の割合、(1+count)/(1+2000)）。
- 複製に近い対（課題の指示）: |cos_jk(t)| > 0.5 または J_jk(t) > 0.2（その時刻の値）。
- 注意 [恒等式]: 同じ標的の持ち上げ役の対は、T_i の 3 入力のうち ≥ 2 で開くことから少なくとも 1 つの閾値入力を共有し（鳩の巣）、O_i の半分以上ずつを覆う。よって J_jk と ω_jk(i) の共在対での高さには基準から機械的に出る分がある。cos には基準から出る分は無い。

## 3. 要点（数だけ。a0.1・a0.3 は完走。a0.5 は本報告の時点で並べ替え検定の途中 — §8）

1. **|cos̄|・|ρ̄|（= |cos| × ω の時間平均）は共在・共誕の超過を並べない [実測]。** Spearman: |ρ̄| 対 超過 c は +0.018（a0.1）・+0.001（a0.3）、共誕で +0.013・−0.001。|cos̄| は +0.006・−0.002、共誕 0.000・−0.004。標的内の名札入れ替え p は 0.13〜0.74（表 3a・3b）。|ρ̄| と |cos̄| の順位相関は 0.992・0.999 なので ρ̄ の情報は cos̄ の情報と同じ（表 4）。
2. **符号つき cos̄・ρ̄ は向きが逆（弱い負）[実測]。** 補題 1 の共動が共誕を作るなら正の cos で共誕が増えるはずだが、Spearman は −0.031・−0.011（共在）、−0.031・−0.009（共誕）。片側 p（観測以上）は 0.92〜1.00、つまり逆向きの側で 2,000 回中ほぼ最大。同じ標的で同時に生まれた対の cos の平均は −0.067（a0.1、538 対）・−0.036（a0.3、1,478 対）、その時刻の生きた対すべては −0.009・−0.009（表 7）。
3. **ω̄（標的の閾値入力に似た入力の上でのゲートの重なり）だけが正に並べる [実測]**: Spearman +0.163・+0.080（共在）、+0.178・+0.094（共誕）、exc_state でも +0.167・+0.066／+0.168・+0.075、p_within 0.0005（2,000 回で観測以上なし）。J̄ で条件付けた偏順位相関も同じ大きさ（+0.164・+0.079／+0.181・+0.090、表 4）。ただし ω̄ の値域は狭い（a0.1 で 0.69〜0.78、a0.3 で 0.85〜0.88）。
4. **J̄ は超過を並べない [実測]**（−0.022・−0.011／−0.017・−0.033）が、共在の回数 C とは正（+0.138・+0.075）。J ≥ 0.05 のビンは平均 c が 3〜4 倍（表 5）。新生の時刻では、同時に生まれた対の J は 0.084・0.113、生きた対 0.012・0.034、別の標的の新生との対 0.037・0.082（表 7）。J の高さには基準から機械的に出る分がある（§1 注意 [恒等式]）。
5. **複製に近い対の寄与 [実測]（表 6）**: 共在のうち |cos|>0.5 の対は 13.4%（a0.1）・14.3%（a0.3）、生きた対の基準は 13.3%・13.4% → 濃縮なし。J>0.2 の対は 4.7%・8.6%、基準 0.33%・0.25% → 14〜35 倍（機械的な分を含む）。両方を合わせた「複製型」は共在の 16.8%・21.4%、共誕の 17.1%・21.2%。残り 8 割前後は複製型でない対から。
6. **持ち上げ役 ≥ 7 の状態（a0.3 の 12 状態、最大 14）**: 持ち上げ役の対の |cos| は 0.25〜0.28（生きた対 0.26〜0.27）、|cos|>0.5 の割合 0.11〜0.22（基準 0.13〜0.14）、J は 0.06〜0.10（基準 0.03）、|ρ_i| は生きた対より低い（表 8）。持ち上げ役の幅 k_j は 23〜372 で標的（k_i 1〜4）より広い。

## 4. 読み（求められたときのため。未検証と明記）

- [読み] 補題 2 の縛り（ρ ≤ |cos| × ω）は不等式として成り立つが、実状態の共誕の分布は cos の軸では並ばず、開いた集合の重なり（ω・J）の軸だけで弱く並ぶ。模型 G が「同時の新生 = ラベル雑音の共動」と置くなら、その共動の相関（cos に比例）が共誕を予測しないことは模型 G の定量を支持しない。縛りが緩いことと模型が当てはまらないことは別で、どちらかは [未導出]。
- [読み] 符号つき cos が弱く負である理由は書かない [未導出]。
