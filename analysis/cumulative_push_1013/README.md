## 2. 恒等式

### 2.1 累積 [厳密]

E[q(θ_0) − q(θ_T)] = Σ_{t<T} E[b_t]（`verify_accounting.py` check 4: 有理数の Markov 連鎖で厳密一致、停止時刻版も成立）。これは期待値の文で、各軌道の退出は要らない（引き継ぎのとおり）。

### 2.2 CE の勾配の分解 [厳密]

f_n ∈ R^K を logit、f̄_n = (1/K)Σ_c f_nc として
- L_Y(θ) = (1/N)Σ_n [lse(f_n) − f_{n,Y_n}]、
- **L_U(θ) := (1/N)Σ_n [lse(f_n) − f̄_n] = (1/N)Σ_n KL(u ‖ p_n) + log K**（一様教師の損失）、
- **G_Y(θ) := (1/N)Σ_n ⟨e_{Y_n} − u, f_n⟩**（ラベルの分。one-hot について線形）。

L_Y = L_U − G_Y。各入力のラベルの周辺分布が一様なら、どの θ でも E_Y[G_Y(θ)] = 0、E_Y[∇G_Y(θ)] = 0、E_Y[∇L_Y(θ)] = ∇L_U(θ)。入力間の独立性は要らない（check 5: 全 27 ラベルの列挙で 2e−16、完全に相関したラベルでも 0）。
位置方向の成分（unit i、バッチ B）: F_i^Y = (1/|B|)Σ_{n∈B} K_n d_in ⟨v_i, p_n − e_{Y_n}⟩ = **F_i^U − F_i^{G,Y}**、F^U = (1/|B|)ΣK d⟨v, p − u⟩（確信の力。状態だけの関数）、F^{G,Y} = (1/|B|)ΣK d⟨v, e_Y − u⟩（ラベルの力。E_Y = 0）。全データなら F^U = S_i/N。

1001 ノート §1・§5 の「確信の分 C とラベルの分 G」と同じ分解。ここでは損失でなく**位置の力の経路積分**に使う。

### 2.3 一課題の力の経路積分の 2 つの分解 [恒等式]

課題 t のラベル Y を固定し、実際の軌道（Adam）θ_s、バッチ B_s（s = 0..3999）に沿って、各更新のバッチ平均の位置勾配 F_i(s) := (1/16)Σ_{n∈B_s} K_n d_in(s)⟨v_i(s), r_n(s)⟩、r_n(s) = p_n(θ_s) − e_{Y_n} を足す: **G := Σ_s F_i(s)**（力の経路積分）。普通の SGD なら D_t = η G。Adam では D_t ≠ η G だが、G は Adam の軌道に沿った勾配の経路積分として定義される（`replay_adam.py` の accF。float32 の逆伝播と相対 1e−6 で一致）。
1. **確信／ラベル**: G = G^U − G^G、G^U = Σ_s F^U(s)、G^G = Σ_s F^{G,Y}(s)。s = 0 では E_Y F^{G,Y} = 0、F^U = S_i^{B_0}(θ_t)。
2. **凍結／適応**: F_i(s) = F^{(0)}(s) + F^{ad}(s)、**F^{(0)}(s) := (1/16)Σ_{n∈B_s} K_n d_in(θ_t)⟨v_i(θ_t), r_n(s)⟩**（係数を課題の頭で凍結、残差は実際のもの）、F^{ad} = (1/16)Σ K_n ⟨d_in(s)v_i(s) − d_in(θ_t)v_i(θ_t), r_n(s)⟩。G = G0 + Gad。

分解 1 は課題末に向かって G^U と G^G が同じ大きさ（|G| の 20〜100 倍）で打ち消し合う（当てはめた後は p_n ≈ e_{Y_n} なので F^U ≈ F^G）。分解 2 は 2 つの分が unit を通して符号が揃う（§5.2）。1002 ノート §5 の「割り方で読みが変わる」は残差のクラスやゲートで割ったときの話で、係数の凍結で割る分解 2 は基準が 1 つしかない。

### 2.4 凍結の分の期待 [厳密]

バッチ列 (B_s) はラベルと独立に生成器で決まる。E_Y[e_{Y_n}] = u なので、p̄_n(s) := E_Y[p_n(θ_s^Y) | θ_t]（ラベルで平均した予測の経路）とおくと

  **E_Y[G0 | θ_t] = Σ_s (1/16)Σ_{n∈B_s} K_n d_in(θ_t) ⟨v_i(θ_t), p̄_n(s) − u⟩ = Σ_s S_i^{B_s}[θ_t; p̄(s)]**

（S^B[θ; p] = 凍結した unit の切替の押しを予測 p で評価したもの）。s = 0 で p̄ = p(θ_t)、当てはまるにつれて p̄_n(s) → u（E_Y e_{Y_n} = u）。つまり**凍結の分の期待は、古い自信が消えていく間に凍結した unit が受け続ける切替の押しの積算**で、その符号は p̄ の経路で決まる。
- 系 [仮定つき]: p̄_n(s) − u = λ_n(s)(p_n(θ_t) − u)、λ_n ≥ 0（古い自信が向きを変えず縮むだけ）なら E_Y[G0] = (1/16)Σ_n τ_n K_n d_in⟨v_i, p_n(θ_t) − u⟩、τ_n = Σ_{s: n∈B_s} λ_n(s) ≥ 0。τ で重みづけた切替の押し。
- 言わない: p̄ が縮むだけであること（出力 bias や隠れ層の平均の動きで回りうる）。実測では G0 の符号は全 unit の累積で沈める側（§5.2）。

### 2.5 鎖の恒等式 [恒等式]

課題 t の末（状態 θ_{t+1}、ラベル Y_t）で F_i^{Y_t}(θ_{t+1}) = F^U(θ_{t+1}) − F^{G,Y_t}(θ_{t+1}) であり、F^U(θ_{t+1}) = S_i(θ_{t+1})/N は**次の課題の切替の押し**。よって

  F^{G,Y_t}(θ_{t+1}) = S_i(θ_{t+1})/N − F^{Y_t}(θ_{t+1})

「課題末のラベルの力 = 次の切替の押し − 課題末の当て残しの位置勾配」。当て残しが 0 なら戻りの力は次の押しの値で終わる。この箱では課題末の正答率が 0.60〜0.75 で当て残しは小さくなく、|F^{Y_t}(θ_{t+1})|/|S(θ_{t+1})/N| の中央値は 0.75・0.88・0.91、符号は半々（正 49%）（§5.1）。

### 2.6 読み出しの適応は散逸 [厳密・模型]

特徴を凍結した読み出しだけの勾配流 v̇_i = −(1/N)Σ_n φ_in r_n(s) では、Δv_i(s) = v_i(s) − v_i(0) について (1/N)Σ_n φ_in⟨Δv_i(s), r_n(s)⟩ = −⟨Δv_i, v̇_i⟩ = −½ d|Δv_i|²/ds。よって **∫_0^T (1/N)Σ_n φ_in ⟨Δv_i(s), r_n(s)⟩ ds = −½|Δv_i(T)|² ≤ 0**: unit 自身の活性 φ_in を重みにした「読み出しの適応 × 残差」の積算は、読み出しの変位の二乗の −½ に厳密に等しく、浮かせる側。
位置の適応の分 Gad は重みが K_n d_in（φ_in = d_in z_in ではない）なので、この恒等式そのものではない。z_in = c m_i K_n + ζ_in（c = 1/|x̄̃|²、Σ_n ζ_in = 0）で K 重みと z 重みは結ばれるが、ζ の項の符号は出ない。実測では Gad は全 unit の累積で浮かせる側（§5.2）。[読み]: 開いた入力（φ > 0、d = 1）が適応を担う unit では K 重みの符号も同じ。

## 3. 瞬間の反例と累積 [恒等式]

a_t := A_i(θ_t)、反例の課題 R := {t : a_t ≤ 0} とすると Σ_{t<T} a_t = Σ_{t∉R} a_t − Σ_{t∈R}|a_t|。累積が正 ⟺ **反例の課題の |a| の和 < それ以外の課題の a の和**。T 課題の平均で書くと、反例にいる割合 ρ_R と反例の平均の大きさ ā_R、それ以外の平均 ā₊ について Σa > 0 ⟺ ρ_R ā_R < (1 − ρ_R) ā₊。
- これが「生成が解消を上回らない」の正しい形。橋の本数・形成回数・寿命は ρ_R と ā_R を通してしか入らない。
- 実測の ā₊/自己項 = 0.46・0.36・0.23（§5.1）、反例の大きさの実例は P171 の注入（1 出力で |A|/自己項 ≤ 0.003、多クラスで 0.027〜2.8）。ā_R = 自己項 × c とすると、累積を 0 以下にする条件は ρ_R > ā₊/(ā₊ + c·自己項)、c = 1 で 32・26・19%、c = 2.8 で 14・11・8% の課題で反例にいる必要がある。1 課題だけの反例は 90 課題の累積を 1〜4% 動かすだけ。
- 実測の ρ_R = 0（0/25,426 unit-task、相 2）。H4 の寿命（1 課題 88〜94%）と新生（0.2〜0.3 組/標的/課題、同時に ≥ 10 が要る）を入れると ρ_R の見積もりは 10^−7 以下 [仮定つき: 新生の独立]。（**1014 訂正**: 新生の独立は実測で否定された（同時にいる橋の数の Fano 1.3〜1.6、帰無 0.93〜1.01）。独立なしの Cantelli の時間平均の形では標的の最大 ≤ 0.011 [仮定つき]。[cobirth_seeds_1013](../cobirth_seeds_1013/README.md)）
- 言わない: ρ_R が 0 に留まることの導出。

## 4. Adam の最初の一歩の期待 [厳密]

状態 θ（課題 t の末）、unit i の座標 j = 1..785 の Adam のモーメント (m⁰_j, v⁰_j)、大域の更新回数 k、第 1 バッチ B（16 入力、ラベルと独立）。新ラベル Y_n iid 一様。バッチ平均の勾配は

  γ_j = μ_j − ξ_j、 μ_j = (1/16)Σ_{n∈B} x̃_nj d_in c_n、 c_n := ⟨v_i, p_n − u⟩、 ξ_j = (1/16)Σ_{n∈B} x̃_nj d_in ε_n、 ε_n := v_{i,Y_n} − v̄_i

（ε_n は入力ごと独立、10 個の値 {v_ic − v̄_i} を等確率にとり、平均 0）。PyTorch の Adam の一歩は Δw̃_ij = −η_k h_j(γ_j)、h_j(γ) = [β₁m⁰_j + (1−β₁)γ] / (√((β₂v⁰_j + (1−β₂)γ²)/(1−β₂^k)) + ε)、η_k = η/(1−β₁^k)。位置の一歩 Δm_i = Σ_j x̄̃_j Δw̃_ij。

**定理 4.1** [厳密]。E_Y[Δm_i | θ, B, Adam 状態] = −η_k Σ_j x̄̃_j E[h_j(μ_j − ξ_j)]。ξ_j の分布は 16 個の 10 点分布の畳み込みで有限。SGD なら E_Y[Δm_i] = −η Σ_j x̄̃_j μ_j = −η S_i^B。

**命題 4.2（2 つの領域）** [厳密・各極限]。
- 線形領域（(1−β₂)γ_j² ≪ β₂v⁰_j、新しい勾配が最近 1,000 更新の勾配の記憶より小さい）: h_j(γ) ≈ [β₁m⁰_j + (1−β₁)γ]/√(v⁰_j/(1−β₂^k)) は γ について線形なので E[Δm_i] ≈ −η_k(1−β₁)(1/16)Σ_{n∈B} d_in c_n **K̃_n** − η_k β₁Σ_j x̄̃_j m⁰_j/√(v⁰_j/(1−β₂^k))、**K̃_n := Σ_j x̄̃_j x̃_nj/√(v⁰_j/(1−β₂^k))**（前処理した明るさ）。切替の押しと同じ形で、明るさ K_n が画素ごとに 1/√v⁰ で重みづけられ、持ち越した運動量の位置成分が足される。
- 飽和領域（(1−β₂)γ_j² ≫ β₂v⁰_j、m⁰ ≈ 0）: h_j(γ) ≈ (1−β₁)√(1−β₂^k)/√(1−β₂) · sign γ ≈ 3.16 sign γ なので E[Δm_i] ≈ −3.16 η_k Σ_j x̄̃_j [2P(ξ_j < μ_j) − 1]。明るさで重みづけた**画素ごとの符号の投票**。

**命題 4.3（符号）** [厳密]。x̃ ≥ 0 なので、第 1 バッチの c_n（n ∈ B）が同符号なら全 μ_j が同符号。線形領域では各座標の期待は μ_j に線形なので（m⁰ = 0 のとき）Adam の期待の符号は S_i^B と一致する。飽和領域では一致しない場合がある: (a) μ_j の符号が画素で混ざると、SGD は大きさで足し、Adam は符号で数えるので、明るさで重みづけた多数決が和の符号と違いうる、(b) ξ_j の分布が歪んでいる（ε_n は 10 点で対称でない）と、|μ_j| が小さい座標で 2P(ξ_j < μ_j) − 1 の符号が μ_j と逆になりうる。`cnn_drive_1009/adam_stationary_b16.md` の固定駆動の反例はこの (b) の定常版。
実測（§5.3）: 相 2 の実状態は線形領域（√v⁰_j/|μ_j| の中央値 1.8〜2.7）。Adam の期待 − 運動量の持ち越し と SGD の期待の符号一致 98%、相関 0.95〜0.97。

## 6. 言えたこと・言えないこと

**言えた** [厳密・恒等式]: 累積の恒等式 (6)；L_Y = L_U − G_Y と E_Y∇G_Y = 0（一様な周辺分布だけで）；力の経路積分の 2 つの分解；凍結の分の期待 E_Y[G0 | θ_t] = Σ_s S^{B_s}[θ_t; p̄(s)]；鎖の恒等式；読み出しの適応の散逸（模型）；反例が累積に効く量（§3）；Adam の最初の一歩の厳密な期待と 2 つの領域と符号の条件（§4）。
**実測で閉じた**: (i)(ii)(iii) とも累積は全 unit で沈める側；相殺率は 0.54〜0.77 で安定；反例は 0/25,426；凍結の分が沈め適応の分が浮かせる（§5.2）；正味は押しの 2〜7% で幅の伸びが運ぶ。
**未導出**: (a) 相殺率 < 1 の機構（定理 6 の並びの期待値は無作為な並びの基準で、実際の並びは無作為より不利な側に 2〜5 倍寄っている。その倍率が 1/相殺率 を超えない理由）。(b) G0 − Gad > 0（課題内の釣り合い = r*）。(c) ρ_R = 0 の導出。(d) Adam の 2 歩目以降の期待（ラベルに依存した状態を条件にできない）。
**言い換えない**: (a)(b)(c) を新しい仮定の名前で包んで「保証できた」とは書かない。橋の退出保証に目標を戻さない。
