# 入力層の押しの向きが自己形から外れる理由 — 下流の層へ透過する項（導出ノート、1010）

作成: 2026-10-10 13:10（Claude Fable、計算前）/ 対象: RL-CIFAR CNN（`rlcifar_cnn_0908`）の入力 conv 層 c1、比較に深い conv 層 c2 と 3 層 MLP の第 1 層 / 検証: `specs/spec_c1_direction_1010.md`（予測を計算前に登録）/ 独立の導出・批評: Codex（`codex_derivation.md`）

> 格の印: [厳密]（恒等式・定義から出る）、[既知]（vault に登録済みの実測）、[仮定つき]（明記した近似の下）、[候補]（測定で決める読み）。押しの向きは「沈める側／浮かせる側」と書く。

## 0. 埋める穴

- `cnn_drive_verify_1009`: c1 では切替の押し G_j = E_new⟨∇m_j, ∇L_new⟩ の符号が自己形 S_j（92% 正 = 沈める側）に従わない。leaky（LR）の c1 は沈める側 0.50（t1）→ 0.10（t10）→ 0.11（t20）→ 0.40（t30）、Snake は 0.51 → 0.43。深い conv 層 c2 は従う（LR で t10 以降 1.00）。
- 3 層 MLP（vault `3層RL-CIFARへの拡張_層ごとの位置の座標と壁_1007` §2.3・§8）: 第 1 層の自己形は 100% 正なのに、実際の押しは raw で 84〜97%、**std で 37〜67%**。「W3 の成長 × 初期の W2 列の項」と名指しされたが [未導出]。
- V12 §4 の主張（期待値での必然）は 2 層の箱で閉じている。隠れ層に読まれる層（3 層の第 1 層・CNN の c1）で押しが自己形から外れる理由を導けば、CNN の節と 3 層ノート §8 の穴が同時に埋まる。

## 1. 記号と恒等式 [厳密]

画像 n = 1..N（1200）。c1 のチャネル j、位置 p（32×32）、pool 後の位置 q（16×16）。z1_j(n,p) = ⟨W1[j], x(n,p)⟩ + b1_j（x(n,p) は zero-pad 込みの 3×5×5 パッチ）、P1_j(n,q) = max_{p∈q} φ(z1_j(n,p))（勝者 p*(n,q)）。c2 のチャネル k、位置 q′（16×16）、pool 後 r（8×8）。z2_k(n,q′) = ⟨W2[k], P1patch(n,q′)⟩ + b2_k（P1patch は 16×5×5、zero-pad 込み）。fc1: z3 = W3 vec(P2) + b3。

新ラベルの期待損失 L_u = (1/N) Σ_n [logsumexp f_n − mean_c f_nc]。ラベルが一様 iid なので ∇L_u = E_new ∇L は厳密（verify の G の恒等式）。状態を固定して

- δ3 = ∂L_u/∂z3、H2_k = ∂L_u/∂P2_k = [W3ᵀ δ3]_k、δ2 = φ′(z2) ⊙ unpool(H2)、
- H1_j = ∂L_u/∂P1_j = Σ_k W2[k,j] ⋆ᵀ δ2_k（転置畳み込み）、δ1_j = φ′(z1_j) ⊙ unpool(H1_j)。

チャネル平均 m_j = mean_{n,p} z1_j(n,p) の勾配は u_j = (M, 1)（M = 平均パッチ、b1 の成分 1）で、u_j に沿った z1_j の接線は K1(n,p) = ⟨M, x(n,p)⟩ + 1（生の入力で ≈ |M|² + 1 = 15.3）。よって

  **G_j = Σ_{n,p} δ1_j(n,p) K1(n,p) = Σ_{n,q} γ_j(n,q) K1(n,p*) H1_j(n,q)**,  γ_j = φ′(z1_j(n,p*))　… (1)

自己形（段 0）は S_j = Σ_{n,q} γ_j K1 P1_j(n,q)（語の表: Σ K φ′ φ）。(1) と見比べると、**G と S の差は H1_j と P1_j の差だけ**。自己形は「読み出しの勾配 H1 が自分の出力 P1 に比例する」理想化である。

H1_j は W2[:, j] に線形（δ2 は状態で固定）。したがって W2 をどう割っても G_j はその和に割れる:

  W2 = W2⁰ + ΔW2^{drift} + ΔW2^{rest} ⇒ **G_j = G_j⁰ + G_j^{drift} + G_j^{rest}**　… (2)

ここで W2⁰ は初期値（`init_params(seed)`）、ΔW2 = W2 − W2⁰、ΔW2^{drift}[k] = ⟨ΔW2[k], µ̂₂⟩ µ̂₂（µ₂ = mean_{n,q′} P1patch(n,q′)、400 次元。z̄2_k = ⟨W2[k], µ₂⟩ + b2_k は厳密なので、これは c2 の平均を動かした成分 = **µ₂ 経路の成分**）、ΔW2^{rest} = ΔW2 − ΔW2^{drift}。c2 についても同じ: H2 は W3 に線形で、W3 = W3⁰ + ΔW3^{drift}（µ₃ = mean_n vec(P2) への射影）+ ΔW3^{rest} に割れる。

## 2. 2 層の箱で G が S に従う構造（既知の文の言い換え）[厳密な部分と仮定]

2 層 MLP では H_in = Σ_c W2_ci (p_nc − 1/K)。(i) 予測はクラスで釣り合う（Σ_n (p_nc − 1/K) ≈ 0）ので H の画像平均は ≈ 0。(ii) 読み出し W2[:, i] はラベルで育つ（W2_ci ∝ Σ_hist Σ_n′ (y − p)_{n′c} h1_{in′}）ので H_in ≈ Σ_n′ h1_{in′} κ(n′, n)、κ の対角（n′ = n: 自分の画像の当てはめの記憶）が正に残り、H ∝ h1。これが「自己形の向き = 押しの向き」の中身（総まとめ G8 の十分条件 (a)「勾配で育った読み出し」）。

## 3. 隠れ層に読まれる層で現れる項 — 透過項 [厳密な和 ＋ 既知の構造]

下流が隠れ層だと (i) が壊れる。δ2_k(n,q′) の画像・位置の和 D̄_k = Σ_{n,q′} δ2_k(n,q′) は **c2 のチャネル k 自身の bias の押し**で、k が沈む側なら D̄_k > 0（LR の c2 は t5 以降 0.84〜1.00 で沈める側 [既知]）。H1_j の全位置和は、境界項を除いて

  Σ_{n,q} H1_j(n,q) = Σ_k s_kj D̄_k,  s_kj = Σ_off W2[k,j,off]（カーネルの DC 和）　… (3)

なので、(1) のうち γ K1 を定数 γ̄K̄ と置いた部分（**透過項**）は γ̄K̄ Σ_k s_kj D̄_k。2 層ではこの項が D̄ ≈ 0 で消えていた。

s_kj の初期値は符号が無作為。学習で付く ΔW2 のうち µ₂ 方向の成分は、c2 の µ₂ 経路の沈降そのもので [既知: 3 層ノート §4「W2 の反平行成分の成長」、V12 §3.4 の µ 経路]、⟨ΔW2[k], µ̂₂⟩ = −c_k < 0。µ₂ の j ブロックは（平行移動で定常な特徴なら）P̄1_j × 1₅ₓ₅ なので、Δs_kj^{drift} ∝ −c_k P̄1_j。したがって

  **G_j^{drift} ≈ −P̄1_j · γ̄K̄ · Σ_k c_k D̄_k · (定数 > 0)**　… (4)

c_k > 0（蓄積した沈降）・D̄_k > 0（今の沈める押し）なら、**透過項の符号は −sign(P̄1_j)**。

- CNN の c1: P̄1_j > 0（max-pool 後の leaky の特徴）→ **浮かせる側**。蓄積 c_k とともに大きくなる（LR の沈める側の割合が t1 0.50 → t10 0.10 と減るのと整合）。深く沈んで P̄1_j ≤ 0 になったチャネルでは符号が戻る（t30 で 0.40 へ戻るのと整合する読み。P5 で試す）。
- 3 層 MLP raw の第 1 層: µ₂,i = h̄1_i < 0（leaky の閉じた側 a·z1、z1 ≪ 0。3 層ノート §4.2「LR raw: 閉じた側 −3.0 → −4.0 が µ₂ を担う」）→ 透過項は **沈める側**。自己形と同じ向きなので raw 84〜97%。
- 3 層 MLP std の第 1 層: µ₂,i > 0（開いた側の z1 の尺度が µ₂ を担う）→ 透過項は **浮かせる側**。自己形（沈める側）と競合して 37〜67%。
- 2 層: D̄ ≈ 0 で透過項なし。

これが「W3 の成長 × 初期の W2 列の項」の正体の候補: 初期の W2⁰ の項は符号が無作為（半々）、系統的な外れは ΔW2 の µ₂ 方向成分（反平行の漂流）× 下流の押し D̄ から来る、という割り方 [候補 → P1・P8 で判定]。

## 4. なぜ c2 は従うのか [候補]

c2 の下流 fc1 の重み W3 も µ₃ 方向に反平行に漂うはず（fc1 は z̄ −2.7 → −16 と深く沈む）なので、c2 にも浮かせる側の透過項がある。それでも c2 が沈める側 1.00 なのは、自己整合項（H2 ∝ P2 の部分、§2 の対角の記憶）が勝つから、と読む。根拠の候補: W3 は位置ごとに別の 102,400 個で画像ごとの記憶を持てるが、c1 を読む W2 は共有カーネル 6,400 個で画像ごとの記憶を持てず、自己整合項が弱い。→ P2 で「c2 は rest（自己整合側）が正で支配、drift は負だが小さい」を試す。

## 5. 課題の中（Q2 の読み）[候補]

切替で c2 が沈む（D_k > 0）→ (4) で c1 は浮く（LR の 10 更新目 +0.13〜+0.79 と整合）。当てはめで c2 が戻る（D_k < 0）→ c1 は沈む。c1 の正味が負になるには、結合 Σ_k |⟨ΔW2[k], µ̂₂⟩| が切替直後に強まる非対称（W2 の µ₂ 方向の押しが切替に集中する: MLP の「押しは切替の約 200 更新」の W2 版）が要る。P9 で試す。

## 5′. 追記（13:30、計算前）: 2 層の透過項の正確な大きさ [厳密]

2 層 MLP で H_in = Σ_c W2_ci (p_nc − 1/K) の画像和は Σ_n H_in = N Σ_c W2_ci (p̄_c − 1/K) = N ⟨W2[:, i], ∇_{b_out} L_u⟩（p̄_c = 予測確率のクラス平均）。つまり 2 層の透過項は**出力 bias の L_u 勾配**に比例し、厳密には 0 でない。当てはまった状態では p̄_c ≈ n_c/N（クラスの度数）なので |p̄_c − 1/K| は乱数ラベルの度数の揺らぎ √(0.1·0.9/1200) ≈ 0.009（1/K の 9%）の程度で、符号は無作為。隠れ層の D̄_k（unit k 自身の沈める押し、全 unit で同符号）とは大きさも揃いも違う。これが「2 層では透過項が無い」の正確な文。

## 6. 仮定と限界

- (3) は境界項（zero-pad で転置畳み込みが地図の外に出る分）を無視。(4) は γ K1 の位置・画像依存（cov(γK1, δ̃2)）を無視。両方とも測定では無視せず、(2) の厳密な分解で判定する（(3)(4) は読みの式）。
- Adam: 向きは SGD の期待勾配で論じる。Adam の最初の 1 歩がこれを逆にするのは稀（c1 ≤ 1.7%、既知）。
- 「反平行の漂流」の大きさ c_k・時間の形は導かない（既知の µ 経路の文に預ける）。
- Snake では γ = 1 + sin(2αz) が大きく変わるので γ̄ の定数化が粗い。P6 は弱い予測にする。
