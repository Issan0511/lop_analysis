## 問い

RL-CIFAR CNN（conv5×5 3→16 → φ → maxpool2 → conv5×5 16→16 → φ → maxpool2 → fc 1024→100 → φ → fc 100→100 → φ → fc 100→10、φ = leaky 0.1 または Snake、Adam 1e−3、batch 16、1200 枚、乱数ラベルを 400 epoch ごとに引き直す）で、入力 conv 層 c1 のチャネル平均 m_j の切替の押し G_j = E_new⟨∇m_j, ∇L_new⟩（G > 0 が沈める側）が、自己形 S_j = Σ_{n,q} γ K1 P1_j（> 0 が 92%）に従わない（leaky では t10 で沈める側 0.10、t30 で 0.40。深い conv 層 c2 は 1.00）。実測の詳細は `~/Projects/claude/proj_004_drift/results/cnn_drive_verify_1009/summary.md`。

Claude の候補（derivation.md §3）: 隠れ層に読まれる層では、下流の層の bias の押し D̄_k = Σ_{n,q′} δ2_k ≠ 0 が接続重みの DC 和（または µ₂ 方向成分）を通して上流の平均へ透過し、接続重みの µ₂ 方向成分は下流の µ₂ 経路の沈降で反平行（負）に育っているので、透過項の符号は −sign(P̄1_j)（上流の層の平均出力の符号の逆）になる。2 層の箱では読み出しの δ の画像和が ≈ 0 で透過項が無い。3 層 MLP の raw（µ₂ < 0 → 沈める側 84〜97%）と std（µ₂ > 0 → 37〜67%）もこれで読める。
