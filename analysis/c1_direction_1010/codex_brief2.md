## 頼むこと

1. **DC バケットの厳密な透過恒等式。** ΔW2[k,j,:] = (Δs_kj/25)·1₅ₓ₅ + AC（チャネル内で和 0）と割ったとき、c1 の押しの DC 部分は G^DC_j = Σ_k Δs_kj Ã_kj、Ã_kj = (1/25) Σ_{n,q} γ_j K1_j(n,q) (1 ⋆ᵀ δ2_k)(n,q)（境界は zero-pad の転置畳み込みに含まれる）で厳密か。Ã_kj と D̄_k の関係（ゲート重みと境界）を書く。AC 部分が平均の押しに寄与する経路（γK1 の空間パターンとの共分散）を式にする。現在の µ̂₂ への射影（drift）と DC バケットの差を式で書き、P̄1_j が符号を変えるときに drift がなぜ狭すぎる基底になるかを示す。
2. **Δs_kj の履歴の式。** カーネルの DC 和の勾配は Σ_off ∂L/∂W2[k,j,off] = Σ_{n,q′} δ2_k(n,q′) · (q′ の周りの 5×5 の P1_j の箱和)。これを課題の中（実ラベルの残差 p − y）と切替（p − 1/K）で積分したとき、Δs_kj の符号が何で決まるか。特に (a) 切替の押し（δ2 の和 D̄_k > 0・P1_j の箱和 > 0 → Δs_kj の押しは負）と、課題の中の戻り、(b) P̄1_j が負に転じた後も Δs_kj < 0 が 61〜73% 残る理由（履歴の蓄積か、箱和が P̄1_j と符号が違う（max-pool の正の裾）か、Adam の座標正規化か）。書けるところまで。測定で区別する量を 1 つ提案する。
3. **MLP の切片 = 透過の文。** H_in = Σ_k W2_ki δ2_kn を h1_in に回帰した切片 α_i は、unit i から見た H の平均水準で、G_i ⊃ α_i κ_i（κ_i = Σ_n K_n φ′(z1_in)）。これは 2 層に無い透過項の MLP 版と同じものか。α_i の符号と µ₂,i・Σ_k ΔW2_ki D̄_k の関係を式で書く。raw で 90% 沈める側・std で 18〜28% の差を、µ₂ の符号で説明できるか。
4. **V12 に書く一文の候補。** 「隠れ層に読まれる層の切替の押しは、自己整合の項（2 層と同じ）＋ 下流の層の押しが接続重みの平均方向（DC）成分を通して上流へ透過する項の和である。透過項の符号は上流の層の平均出力の符号の逆（×下流が沈める側であること）で、2 層では読み出しの δ の画像和が O(N^{−1/2}) なので現れない」— この文の各節に格を付け、言い過ぎを削った版を書く。
5. **DC バケット測定の盲検予測。** G^DC が c1 の全体の符号を担う割合（≥ 0.85 か）、|G^DC| > |G^AC| の割合、Ã_kj と D̄_k の符号一致、Σ_k Δs_kj D̄_k と G^DC の Spearman。外れると思う登録外の読み（spec §6.2 (iii)）があれば書く。
