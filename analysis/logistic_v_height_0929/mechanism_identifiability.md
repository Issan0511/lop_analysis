# 第5段「小さいv→規格化した上端」の機構はどこまで識別できたか

2026-09-29。ユーザーの「再現できることが嬉しいのではなく、理論から機構を特定したい」という指摘を受けた識別性の監査。新しい数値実験は行っていない。本書の介入案は未実施であり、結果を先取りしない。

## 結論

**元のELU実験の第5段の機構は、今回の模型ではまだ特定できていない。** 小vで上端が高くなる模型を作れたことは、観測された機構を同定した証拠にはならない。むしろ、同じ所見を異なる系で作れるため、「その所見だけでは機構を選べない」という限界が明確になった。

理論と実データを合わせて狭められた点はある。同じ入力集合・同じunitについて中心化した上端距離が変わっているので、**ノルムやbiasだけでなく、入力に対するwの方向が変わっている必要がある。** 未同定なのは、vの変更が、何を通して、その方向をどちらへ変えたかである。

以下は全てunitごとの入力重みwを指す。読み出しvの向きとは別物である。

## 1. 正確に説明対象を定める

説明対象を、同じseed・unit・入力集合の

\[
T_i=\frac{\max_n z_{ni}-\operatorname{median}_n z_{ni}}{s_i},\qquad
z_{ni}=w_i^\top x_n+b_i
\]

とする。raw maxやmax/sだけでは、幅・bias・裾の形が混ざる。

入力は1200枚で全task・全介入に共通である。保存データを同じunit・taskで対応づけると、c=.1対10のTの差は全unit比較でも95.70–97.08%のunit-taskで正。生存unitを選び直したことだけによる見かけの差ではない。これは2 seed内の記述統計であり、多数のunit-taskを独立反復として一般化する根拠にはしない。

入力共分散をΣとすると

\[
T_i=\frac{\max_n w_i^\top x_n-\operatorname{median}_n w_i^\top x_n}
{\sqrt{w_i^\top\Sigma w_i}}.
\]

bは消え、wを正の定数倍してもTは変わらない。Σの零空間の成分もTを変えない。従って、入力集合の中心化した張る空間でのwの方向変化は**必要条件**である。一方、方向が変わればTが必ず増えるわけではない。この必要条件を、それだけで符号を説明した機構と呼ばない。

## 2. 既存の介入で除外できる説・できない説

| 説 | 判定 | 根拠と限界 |
|---|---|---|
| 幅が一様に増えただけで規格化した裾は同じ | 除外 | Tは一様拡大に不変だが、同一unitでもTが変わる |
| hidden biasが動いただけ | 除外 | Tは平行移動に不変 |
| 生き残ったunitの選択だけ | 除外 | 全100unit・共通生存unit・介入前固定unit集合でも差が残る |
| 介入後にvの方向を学び直さなければTは変わらない | 必要条件としては除外 | 3凍結腕ではW2の方向を固定してもTが異なる。ただしtask50までに学んだ読み出し方向の存在は共通の前提 |
| Adamではvが約分されるから、vはwの分布へ一切影響しない | 除外 | 約分は勾配列全体が同じ定数倍となる対応系の性質。元実験では残差と既存momentsがその条件を満たさない |
| 損失が各unitの出力を同じ固定値に指定し、zを厳密に1/vへ運ぶ | 説明として不成立 | 複数unitと出力biasが寄与し、各unitの目標出力は指定されない。終端CEも介入間で異なる。全体的な1/v補償ならTは変わらない |
| 元の平均誤差を出力biasで消すことだけが第5段を作る | 未識別 | BFIXは主としてvのブレーキの平均成分を切り分ける操作。固定vでのw方向変化の経路を直接遮断していない |
| 残差が入力ごとの勾配寄与を組み替えてwを回す | 残る候補 | 多クラス残差・門・入力幾何の組合せが変わり得るが、保存データから符号・量を予測できていない |
| Adamの長い二次履歴が座標ごとの一歩を異なる比で抑え、wを回す | 残る候補 | 構成例で可能と示しただけ。実ネットワークでこの経路を切り分けていない |
| W2をc倍した瞬間に古いhidden momentsを保持したことが過渡を作る | 残る候補 | 元実験はmomentsをリセットもc/c²倍もしない。初期の数課題で高さが大きく変わるため、検討対象から外せない |
| ELUの開閉集合・閉側からの更新・他unitや出力biasとの競合が方向を決める | 残る候補 | logitの変更後の下流経路であり、vfreezeの介入効果の一部になり得る。現時点では媒介経路間を分けていない |

§8.42のブレーキ操作は、閉側の出力、共通勾配成分、Adam分母の扱い、vの大きさ、上端が結びつく証拠を与える。しかし**「vが小さくなった後、どの入力・方向のw更新が変わったか」を直接識別する操作ではない。** 上流の操作でvとTが同時に動いたことと、下流の機構が一意に定まったことは別である。

vfreezeはvの大きさを操作した総効果を示す。vの変更で出力誤差やbias学習も変わることは、通常の交絡というより、同時に動いてしまう**下流の媒介経路**である。総効果を否定する理由にはならないが、どの媒介経路が必要かを知るには追加の制御が要る。

EEQ対VF1だけから「vの向きの学び直しが効く」と単独で断定するのも強すぎる。凍結はvの方向とノルムの時間変化を両方止める。

## 3. 今回の模型が追加で除外したこと

### scalar

- ロジスティック損失だから小vほど高くなる、という一般則は成立しない。GDの有限時間解にはvに対する内点最大がある。εや時間にも依存する。
- 対称な二点模型はT=1が恒等的に固定されるので、第5段の規格化した裾の変化を説明する模型として除外できる。
- 分離可能な二点模型ではzが単調増加し、vを大きくした後にraw maxが下がる元の介入応答を説明できない。
- 非分離の有限目標模型ならzの上下両方向は作れるが、Tは依然として不変。この修正だけでも足りない。
- scalarのβ₂対照で二次履歴の効果を確認しても、元のELUでそれが必要だったと移してはいけない。

### shared inputs

- raw高さがvに強く依存しても、Tの変化は小さい・逆向き・データ依存となる例がある。「小v→大T」が有限時間Adamの普遍的帰結という説は除外できる。
- 線形logisticでは、logitパラメータθ=vuでの有効学習率とε、初期条件を揃えれば尺度対応がある。これは「同じlogit軌道のときshapeが変わらない」ことを意味する。実際のELUへそのまま適用できるわけではない。
- 決定論的な線形系でも方向・Tは変化し得る。したがって、同種の形の変化を一般に作るためにELU非同次性や標本雑音が論理的に必須、とは言えない。ただし元のELUの機構からそれらを除外する証拠ではない。

### anisotropic four atoms

- 残差履歴と座標別正規化からTの変化を作る十分な構造を提示した。
- **実ネットワークの候補のうちどれを排除したか、という意味ではほぼ増えていない。** 特に軸をAdam座標に合わせた分離可能な損失で、入力間競合、負側の本体、p⁺≈.02、途中のraw max下降はない。
- 同じv依存の符号を持つことは、現実の隠れた媒介変数が同じことを意味しない。「再現したので残差履歴が本体」という結論は不可。

## 4. 恒等式をもう一度『機構』と呼ばないための条件

例えば更新を入力別に書き直し、未知の残差列を残したまま「この項がwの方向を変える」と述べても、それは帳簿である。ΔTを∇Tと実測Δwの内積に分解して全変化を回収するだけでも、符号を予測する理論にはならない。

機構の識別に近づくには、少なくとも次が必要である。

1. **分解した量を独立に操作できる。** 例えば残差フィードバックを固定する、または二次momentのv依存だけを固定する。
2. **操作前に異なる予測を置く。** 同じ状態・同じバッチから、どの対照なら軌道が一致するべきか、どの候補ならv依存が残るべきかを先に固定する。単に終端Tに合う係数を後から選ばない。
3. **短期の符号と長期のTを混同しない。** 1歩の正確な反実仮想はその1歩だけを同定する。未来の残差を答えから与えて長期の機構を説明したことにしない。

次の3本は、未知量を記号に隠すための式ではなく、実際に更新則の経路を固定して競合する説明を分ける提案である。

## 5. 最小の介入対照（3本、いずれも未実施）

task50の同一状態からc=.1,1,10へ分岐し、同じ入力・ラベル・バッチ列を使う。W2は元実験通り凍結する。まずtask51–53の応答を対象にする。全200taskの再現を先に目標にしない。単に同じ終端CEへ揃える操作は予測状態を揃えたことにならないので使わない。

### 対照1：介入時の古いmomentの不整合を切り分ける

元の保持条件に対し、task51のhidden W1,b1の一次momentをc倍、二次momentをc²倍する腕を設ける。重み・bias・stepカウンタ・学習率・ε・ラベル列は各cの対照間で同じ。出力biasのmomentは変えない。これはmoment持ち越しの振幅不整合だけを操作する。リセットは履歴自体も全消去するため、主対照にはしない。

- 「古いmoment不整合だけが原因」なら、整合化によりc依存の主要な過渡が消えるはずである。
- 整合化後にも同じ符号のT変化が続けば、その純粋説は除外でき、変更後に生じる残差・ゲート・更新履歴が必要になる。
- 消えた場合でも不整合が唯一の原因とは断定しない。過渡の変更がその後の残差フィードバックを変えた可能性がある。初回からのΔwとTの応答で、どこから差が分かれたかを記録する。
- 元の二次momentの直接持ち越し項はβ₂^t倍で減る。ただし初期のw変化が残せるため、この項が小さくなれば過去の影響も全部消えたとは言わない。

### 対照2：残差フィードバックを切る厳密なゼロ予測

c=1の凍結基準腕を同時に走らせ、各step・各バッチのクラス残差e_refを他のcのbackwardへ与える。前向きの予測は計算しても、自分自身の残差をhidden gradientへ戻さない。hiddenの初期momentsをc/c²倍、hidden εもc倍し、他の状態とバッチ列を揃える。出力biasも共通のe_refで更新する。

比較する自然残差の腕にも同じmoment整合化とε変更を施す。自然腕とreplay腕の差に、moment初期値やεの変更を混ぜない。

この場合はELUでも厳密に

\[
g_c(t)=c g_1(t),\quad M_c(t)=cM_1(t),\quad S_c(t)=c^2S_1(t),\quad
\frac{M_c(t)}{\sqrt{S_c(t)}+c\epsilon}
=\frac{M_1(t)}{\sqrt{S_1(t)}+\epsilon}
\]

となり、同じhidden状態から帰納的に**全w,b,z,T軌道が一致する**。φの同次性は不要で、同じzに同じφ′が掛かるためである。bias correctionのstep番号も揃える。浮動小数点誤差は別に検査する。

これは結果から選んだQを残す分解ではなく、操作を先に指定した完全な零予測である。自然残差の腕でTが分かれ、残差replayで消えれば、vの明示的倍率だけではなく**変更された出力誤差が戻る経路**が必要だったと絞れる。ただし、この対照だけではその経路内の入力重み付け、ELUの開閉、他unit、出力bias、Adam履歴のどれかは選べない。

εのスケールも変えるのは、勾配振幅に対するε閾値という別経路を除去し、厳密な零予測を成立させるためである。原実験そのものの腕と呼ばない。

### 対照3：vごとに異なる二次履歴だけを固定する

残差は各腕の自然な前向きから計算し、一次momentも各腕で更新する。ただしhiddenのAdam分母は、c=1基準腕から保存した二次momentをc²倍してreplayする。εもc倍し、初期一次momentをc倍に整合する。バイアス補正のstep番号を共有する。基準c=1自身は元の更新と一致するべきである。

対になる通常分母の腕にも、同じε変更と初期momentのc/c²倍を適用する。両腕間で変えるのは二次momentを自然に更新するか基準からreplayするかだけとする。

この対照は、vの変更→残差の変化→勾配の向き・一次履歴という経路を残し、**vの変更→各座標の二次履歴の変化→前処理の変化**という経路だけを共通基準へ固定する。単にAdamをSGDに換えるより、何を変えたかが限定される。

- Tのc依存が残れば、vに依存する二次履歴の違いはその効果の必要条件ではない。残差に伴う入力間重み付け・一次履歴・開閉等の残る経路を優先する。
- Tのc依存が大きく減れば、二次履歴経路の因果的寄与が示される。ただし、それだけで「古い大残差がRMSに残る」という特定の時間像まで確定しない。勾配雑音によるRMSの増加でも同じ介入に反応し得るため、自然腕で残差の時間減衰とバッチ分散を別々に記録する必要がある。
- ある候補を『二次履歴が主因』と主張するなら、この対照に対するT差の減衰率・応答時刻を実行前に指定する。符号や大きさを何でも許す説では識別にならない。

いずれも人工的な媒介経路操作であり、元の損失の通常の勾配降下ではなくなる腕がある。何を固定したかを明示し、介入が自然な学習を再現したことではなく、どの経路の有無で効果が変わるかを評価する。

## 6. 必要な記録と到達できる結論

既存NPZにはfull W1/W2、入力別z/e、Adam momentsがないため、上の対照は保存統計だけでは実行できない。必要なのは同一task50状態、入力別margin・残差、hidden勾配、一次・二次moment、実際のΔw、同一unitのT、max/median入力IDとその変更である。全unit全stepの巨大保存が必須とは限らず、分岐を同時実行して必要な比較量を集計できる。

ただし、記録を細かくすれば自動的に機構が分かるわけではない。対照1–3で候補を順に減らし、その後に残った経路について、**task50の状態とラベル・入力幾何から、T変化の符号と大きさを予測する縮約モデル**を導く必要がある。未来の残差列を自由な入力として与えるだけなら閉じていない。

現時点の適切な主張は、**「ノルム補償という説明は足りず、入力に対するwの方向変化が必要だと絞れた。何がその方向を決めるかは未同定」**である。構成例はこの未同定部分の候補を具体化したが、その候補が元実験の答えだという証拠ではない。
