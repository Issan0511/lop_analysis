The gate is the diagnostic mode restricted to `--seeds 0 --tasks 10`, saved separately in the permanent archive. Each run verifies original source/checkpoint hashes. There are ten independent frozen starting states (five seeds at task 10/60 end); all layer and head comparisons within a state are paired. Task 61 is a hypothetical next task generated by the original sampler. Mini-batch continuations use the old task's images, either keeping or independently replacing labels. These are new 50-step continuations, not replays of an original 50-step trajectory.

`pressures.csv`: full-parameter projections into mu, SD, and mu/SD; positive means downward under gradient descent. `finite_steps.csv`: observed changes after one full-batch expected-gradient Adam step, including saved momentum and second moments. `rollouts.csv`: actual mini-batch Adam continuation trajectories. `comparisons.csv`: predictions evaluated on actual-gradient nonzero units, counting predicted zeros as sign errors. `states.csv`: rank, LS compatibility, Monte Carlo, and CE correction diagnostics. `heads.csv`: norm, alignment, probability, and loss controls.

The phase-2 formula predicts switching under an independent-old-label, frozen-feature joint-LS model. With changing inputs it must use the **old** feature Gram. Bias is included as a constant feature. Under the same assumptions, the old-task ordinary-learning gradient averages to zero. The task-specific LS residual and the exact fit-gap/CE ledger distinguish this issue from implementation failure. Agreement of the synthetic refit control verifies only the conditional model, not its applicability to the trained ViT.

No original checkpoint, optimizer, or running experiment is modified. Raw arrays, gate artifacts, and logs are stored outside the worktree under `/home/issan/Projects/obsidian-research-data/vit_mechanisms_1025/` and indexed by `backup_manifest.json`.
